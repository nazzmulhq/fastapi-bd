HTTP Basic Auth¶

🌐 AI এবং মানুষের যৌথ অনুবাদ

এই অনুবাদটি মানুষের নির্দেশনায় AI দিয়ে করা হয়েছে। 🤝

এতে মূল অর্থ ভুল বোঝা বা অস্বাভাবিক শোনানোর মতো ভুল থাকতে পারে। 🤖

ইংরেজি সংস্করণ

সবচেয়ে সহজ ক্ষেত্রগুলোর জন্য আপনি HTTP Basic Auth ব্যবহার করতে পারেন।

HTTP Basic Auth-এ অ্যাপ্লিকেশন একটি ইউজারনেম ও একটি পাসওয়ার্ড ধারণকারী একটি হেডার আশা করে।

এটি না পেলে এটি একটি HTTP 401 "Unauthorized" এরর রিটার্ন করে।

আর Basic ভ্যালু এবং একটি ঐচ্ছিক realm প্যারামিটারসহ একটি WWW-Authenticate হেডার রিটার্ন করে।

এটি ব্রাউজারকে ইউজারনেম ও পাসওয়ার্ডের জন্য অন্তর্নির্মিত প্রম্পট দেখাতে বলে।

তারপর আপনি সেই ইউজারনেম ও পাসওয়ার্ড লিখলে ব্রাউজার স্বয়ংক্রিয়ভাবে সেগুলো হেডারে পাঠায়।

সহজ HTTP Basic Auth¶

  • HTTPBasic ও HTTPBasicCredentials ইম্পোর্ট করুন।
  • HTTPBasic ব্যবহার করে একটি "security স্কিম" তৈরি করুন।
  • আপনার পাথ অপারেশনে একটি ডিপেন্ডেন্সির সাথে ওই security ব্যবহার করুন।
  • এটি HTTPBasicCredentials টাইপের একটি অবজেক্ট রিটার্ন করে:
    • এতে পাঠানো username ও password থাকে।
from typing import Annotated

from fastapi import Depends, FastAPI
from fastapi.security import HTTPBasic, HTTPBasicCredentials

app = FastAPI()

security = HTTPBasic()


@app.get("/users/me")
def read_current_user(credentials: Annotated[HTTPBasicCredentials, Depends(security)]):
    return {"username": credentials.username, "password": credentials.password}

ইউজারনেম যাচাই করুন¶

এখানে আরও সম্পূর্ণ একটি উদাহরণ দেওয়া হলো।

ইউজারনেম ও পাসওয়ার্ড সঠিক কিনা যাচাই করতে একটি ডিপেন্ডেন্সি ব্যবহার করুন।

এর জন্য ইউজারনেম ও পাসওয়ার্ড যাচাই করতে Python-এর স্ট্যান্ডার্ড মডিউল secrets ব্যবহার করুন।

secrets.compare_digest()-কে bytes বা এমন একটি str নিতে হয় যাতে কেবল ASCII অক্ষর (ইংরেজির অক্ষরগুলো) থাকে, এর মানে এটি Sebastián-এর á-এর মতো অক্ষরের সাথে কাজ করবে না।

এটি সামলাতে আমরা প্রথমে username ও password-কে UTF-8 দিয়ে এনকোড করে bytes-এ রূপান্তর করি।

তারপর আমরা secrets.compare_digest() ব্যবহার করে নিশ্চিত করতে পারি যে credentials.username হলো "stanleyjobson", এবং credentials.password হলো "swordfish"।

import secrets
from typing import Annotated

from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.security import HTTPBasic, HTTPBasicCredentials

app = FastAPI()

security = HTTPBasic()


def get_current_username(
    credentials: Annotated[HTTPBasicCredentials, Depends(security)],
):
    current_username_bytes = credentials.username.encode("utf8")
    correct_username_bytes = b"stanleyjobson"
    is_correct_username = secrets.compare_digest(
        current_username_bytes, correct_username_bytes
    )
    current_password_bytes = credentials.password.encode("utf8")
    correct_password_bytes = b"swordfish"
    is_correct_password = secrets.compare_digest(
        current_password_bytes, correct_password_bytes
    )
    if not (is_correct_username and is_correct_password):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Incorrect username or password",
            headers={"WWW-Authenticate": "Basic"},
        )
    return credentials.username


@app.get("/users/me")
def read_current_user(username: Annotated[str, Depends(get_current_username)]):
    return {"username": username}

Timing Attack¶

কিন্তু "timing attack" কী?

কল্পনা করা যাক কিছু আক্রমণকারী ইউজারনেম ও পাসওয়ার্ড অনুমান করার চেষ্টা করছে।

আর তারা johndoe ইউজারনেম ও love123 পাসওয়ার্ডসহ একটি রিকোয়েস্ট পাঠায়।

তাহলে আপনার অ্যাপ্লিকেশনের Python কোড এরকম কিছুর সমতুল্য হবে:

if "johndoe" == "stanleyjobson" and "love123" == "swordfish":
    ...

কিন্তু Python যে মুহূর্তে johndoe-এর প্রথম j-কে stanleyjobson-এর প্রথম s-এর সাথে তুলনা করে, ঠিক তখনই এটি False রিটার্ন করবে, কারণ এটি ইতিমধ্যে জানে যে দুটি স্ট্রিং একই নয়, এই ভেবে যে "বাকি অক্ষরগুলো তুলনা করে আর হিসাবের অপচয় করার দরকার নেই"। আর আপনার অ্যাপ্লিকেশন বলবে "Incorrect username or password"।

কিন্তু তারপর আক্রমণকারীরা stanleyjobsox ইউজারনেম ও love123 পাসওয়ার্ড দিয়ে চেষ্টা করে।

আর আপনার অ্যাপ্লিকেশন কোড এরকম কিছু করে:

if "stanleyjobsox" == "stanleyjobson" and "love123" == "swordfish":
    ...

দুটি স্ট্রিং যে একই নয় তা বোঝার আগে Python-কে stanleyjobsox ও stanleyjobson দুটিতেই পুরো stanleyjobso তুলনা করতে হবে। তাই "Incorrect username or password" উত্তর দিতে এটি কয়েক মাইক্রোসেকেন্ড বেশি সময় নেবে।

উত্তরের সময় আক্রমণকারীদের সাহায্য করে¶

সেই মুহূর্তে, সার্ভার "Incorrect username or password" রেসপন্স পাঠাতে কয়েক মাইক্রোসেকেন্ড বেশি সময় নিয়েছে তা লক্ষ করে আক্রমণকারীরা জেনে যাবে যে তারা কিছু একটা ঠিক পেয়েছে, শুরুর কিছু অক্ষর সঠিক ছিল।

আর তারপর তারা আবার চেষ্টা করতে পারে এই জেনে যে এটি সম্ভবত johndoe-এর চেয়ে stanleyjobsox-এর বেশি কাছাকাছি কিছু।

একটি "পেশাদার" আক্রমণ¶

অবশ্যই, আক্রমণকারীরা এসব হাতে চেষ্টা করবে না, তারা এটি করার জন্য একটি প্রোগ্রাম লিখবে, সম্ভবত প্রতি সেকেন্ডে হাজার হাজার বা লক্ষ লক্ষ পরীক্ষাসহ। আর তারা একবারে মাত্র একটি করে অতিরিক্ত সঠিক অক্ষর পাবে।

কিন্তু এভাবে করে, কয়েক মিনিট বা ঘণ্টার মধ্যে আক্রমণকারীরা আমাদের অ্যাপ্লিকেশনের "সাহায্যে", শুধু উত্তর দিতে লাগা সময় ব্যবহার করে সঠিক ইউজারনেম ও পাসওয়ার্ড অনুমান করে ফেলবে।

secrets.compare_digest() দিয়ে এটি ঠিক করুন¶

তবে আমাদের কোডে আমরা আসলে secrets.compare_digest() ব্যবহার করছি।

সংক্ষেপে, stanleyjobsox-কে stanleyjobson-এর সাথে তুলনা করতে যত সময় লাগবে, johndoe-কে stanleyjobson-এর সাথে তুলনা করতেও ঠিক ততটাই সময় লাগবে। আর পাসওয়ার্ডের ক্ষেত্রেও তাই।

এভাবে আপনার অ্যাপ্লিকেশন কোডে secrets.compare_digest() ব্যবহার করলে এটি এই পুরো পরিসরের সিকিউরিটি আক্রমণের বিরুদ্ধে নিরাপদ থাকবে।

এরর রিটার্ন করুন¶

ক্রেডেনশিয়াল ভুল তা শনাক্ত করার পরে, 401 স্ট্যাটাস কোডসহ (কোনো ক্রেডেনশিয়াল না দিলে যা রিটার্ন হয়) একটি HTTPException রিটার্ন করুন এবং ব্রাউজার যাতে আবার লগইন প্রম্পট দেখায় সেজন্য WWW-Authenticate হেডার যোগ করুন:

import secrets
from typing import Annotated

from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.security import HTTPBasic, HTTPBasicCredentials

app = FastAPI()

security = HTTPBasic()


def get_current_username(
    credentials: Annotated[HTTPBasicCredentials, Depends(security)],
):
    current_username_bytes = credentials.username.encode("utf8")
    correct_username_bytes = b"stanleyjobson"
    is_correct_username = secrets.compare_digest(
        current_username_bytes, correct_username_bytes
    )
    current_password_bytes = credentials.password.encode("utf8")
    correct_password_bytes = b"swordfish"
    is_correct_password = secrets.compare_digest(
        current_password_bytes, correct_password_bytes
    )
    if not (is_correct_username and is_correct_password):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Incorrect username or password",
            headers={"WWW-Authenticate": "Basic"},
        )
    return credentials.username


@app.get("/users/me")
def read_current_user(username: Annotated[str, Depends(get_current_username)]):
    return {"username": username}
