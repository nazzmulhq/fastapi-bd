Select API: select(), সাবকুয়েরি, CTE ও UNION¶

এই পেজে যা আছে

  • select() আর Select-এর প্রতিটি মেথড ও প্রপার্টি (৯৪টি), উদাহরণ ও তৈরি হওয়া SQL-সহ।
  • union(), union_all(), intersect(), except_() … আর CompoundSelect।
  • Subquery, CTE আর values() / Values।
  • ২.১-এর পরিবর্তন: distinct(কলাম) বাতিলের পথে, এর বদলে .ext(distinct_on(...)); নতুন ext(), into()।

select() দিয়ে বানানো স্টেটমেন্ট অপরিবর্তনীয় (immutable): প্রতিটি মেথড (where, order_by …) একটি নতুন স্টেটমেন্ট ফেরত দেয়, আগেরটি বদলায় না। তাই সবসময় stmt = stmt.where(...) লিখুন। স্টেটমেন্ট শুধু "চিরকুট"; চালাতে হয় session.execute() / session.scalars() দিয়ে। ধারণাগুলো ধাপে ধাপে শিখতে দেখুন কুয়েরি অধ্যায়।

উদাহরণগুলোর জন্য ধরে নেওয়া সেটআপ

Session API পেজের মতোই User (id, name, addresses) আর Address (id, email, user_id) মডেল, আর তিনজন ইউজার: রহিম (দুটি ঠিকানা), করিম, সুমি। print(stmt) দিলে SQLAlchemy যে SQL বানায় তা দেখা যায়; কমেন্টে সেটাই দেখানো হয়েছে। সব উদাহরণ PostgreSQL 16-এ চালিয়ে দেখা।

select()¶

from sqlalchemy import select

select(*entities)

ধরন: ফাংশন

একটি SELECT স্টেটমেন্ট বানায়। আর্গুমেন্টে দিন কী চাই: পুরো মডেল (User), কলাম (User.name), টেবিল, বা যেকোনো SQL এক্সপ্রেশন (func.count())। একাধিক দিলে প্রতিটি রো-তে সেগুলো পাশাপাশি আসে।

উদাহরণ:

stmt = select(User).where(User.name == "রহিম")
print(session.scalars(stmt).one().id)                         # 1
rows = session.execute(select(User.id, func.upper(User.name))).all()
print(len(rows))                                               # 3

Select¶

from sqlalchemy import Select

select() থেকে পাওয়া স্টেটমেন্ট অবজেক্ট। নিচের প্রায় সব মেথড "generative": নতুন একটি Select ফেরত দেয়, তাই চেইন করে লেখা যায়।

উদাহরণ:

stmt = (
    select(User.name, func.count(Address.id).label("n"))
    .join(User.addresses, isouter=True)
    .group_by(User.name)
    .order_by(User.name)
)
print(session.execute(stmt).all())   # [('করিম', 0), ('রহিম', 2), ('সুমি', 0)]

print(session.scalars(intersect(select(User.id), select(Address.user_id))).all())   # [1]

CompoundSelect¶

from sqlalchemy.sql.expression import CompoundSelect

union(), intersect(), except_() ইত্যাদি থেকে পাওয়া মিলিত SELECT। এর ওপরও order_by(), limit(), subquery() ইত্যাদি চলে (পুরো ফলাফলের ওপর)। বাকি মেথডগুলোর কাজ Select-এর মতো।

উদাহরণ:

stmt = union(select(User.name), select(Address.email)).order_by("name").limit(2)
print(session.scalars(stmt).all())   # ['rahim@example.com', 'rahim@work.com'] — ক্রম ডেটাবেসের collation অনুযায়ী

Subquery¶

from sqlalchemy.sql.expression import Subquery

stmt.subquery() থেকে পাওয়া নামযুক্ত সাবকুয়েরি, যা একটি টেবিলের মতো আচরণ করে: .c দিয়ে কলাম, join() দিয়ে জোড়া, আর অন্য select()-এর FROM-এ বসানো যায়।

উদাহরণ:

sub = select(User.id, User.name).where(User.id > 1).subquery("others")
print(session.execute(select(sub.c.name).order_by(sub.c.id)).scalars().all())   # ['করিম', 'সুমি']

সব মেথড ও অ্যাট্রিবিউট এক নজরে¶

সদস্য ধরন কাজ
alias() মেথড এই সাবকুয়েরির আরেকটি নামযুক্ত alias দেয়, যাতে একই সাবকুয়েরি একটি কুয়েরিতে দুবার ব্যবহার করা যায়।
allows_lambda অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এই ধরনের স্টেটমেন্ট lambda_stmt()-এর ভেতরে ব্যবহার করা যায় কি না।
as_scalar() মেথড ১.৪ থেকে বাতিলের পথে।
c প্রপার্টি সাবকুয়েরির কলামগুলো (columns-এর ছোট নাম)।
columns প্রপার্টি সাবকুয়েরির কলামের নাম-ভিত্তিক সংগ্রহ (ColumnCollection)।
compare() মেথড দুটি স্টেটমেন্টের গঠন হুবহু একই কি না তুলনা করে।
compile() মেথড স্টেটমেন্টকে SQL স্ট্রিংয়ে কম্পাইল করে।
corresponding_column() মেথড একটি মূল কলাম (যেমন User.__table__.c.id) দিলে এই স্টেটমেন্টের রপ্তানি করা কলামগুলোর মধ্যে সংশ্লিষ্টটি খুঁজে দেয়।
description প্রপার্টি ভেতরের একটি বর্ণনামূলক নাম (লগ/ডিবাগিংয়ের জন্য)।
entity_namespace প্রপার্টি filter_by()-এর মতো নাম দিয়ে খোঁজার সময় কোন এন্টিটির নাম-ভান্ডার ব্যবহার হবে, তার ভেতরের হুক।
exported_columns প্রপার্টি এই স্টেটমেন্ট যে কলামগুলো "রপ্তানি" করে (বাইরে থেকে পাওয়া যায়) তার সংগ্রহ।
foreign_keys প্রপার্টি এই সাবকুয়েরির কলামগুলো যেসব ফরেন কি রেফার করে তার সংগ্রহ (মূল টেবিল থেকে আসে)।
get_children() মেথড এই এক্সপ্রেশন-গাছের সরাসরি "সন্তান" উপাদানগুলো দেয়।
implicit_returning প্রপার্টি (internal) Table-এর সাথে সামঞ্জস্যের জন্য রাখা ভেতরের ফ্ল্যাগ; সাবকুয়েরিতে অর্থহীন।
inherit_cache অ্যাট্রিবিউট কাস্টম SQL কনস্ট্রাক্ট বানানোর সময় সাবক্লাস বেস ক্লাসের ক্যাশ-key ব্যবস্থা নেবে কি না তার ফ্ল্যাগ।
is_clause_element অ্যাট্রিবিউট ভেতরের টাইপ-ফ্ল্যাগ: এটি একটি SQL এক্সপ্রেশন উপাদান (True)।
is_derived_from() মেথড এই স্টেটমেন্ট একটি নির্দিষ্ট টেবিল/FROM থেকে তৈরি কি না দেখে।
is_dml অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: INSERT/UPDATE/DELETE কি না (Select-এ False)।
is_selectable অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এটি একটি selectable (রো দেয় এমন) কনস্ট্রাক্ট।
join() মেথড এই সাবকুয়েরি আর আরেকটি টেবিল/সাবকুয়েরির Join অবজেক্ট বানায় (টেবিলের join()-এর মতো), যা select_from()-এ বসানো যায়।
lateral() মেথড LATERAL সাবকুয়েরি বানায়: এটি বাম দিকের টেবিলের কলাম রেফার করতে পারে।
memoized_attribute অ্যাট্রিবিউট ভেতরের ডেকোরেটর (একবার হিসাব করে মনে রাখা প্রপার্টি)।
memoized_instancemethod() ক্লাস মেথড ভেতরের ডেকোরেটর (মেথডের ফল মনে রাখা)।
named_with_column অ্যাট্রিবিউট (internal) ভেতরের ফ্ল্যাগ: কলাম রেফার করার সময় এই FROM-এর নাম আগে বসবে কি না (sub.col)।
original প্রপার্টি (legacy) যে মূল SELECT থেকে সাবকুয়েরিটি বানানো, সেটি।
outerjoin() মেথড join()-এর মতো, কিন্তু LEFT OUTER JOIN দিয়ে Join অবজেক্ট বানায়।
params() মেথড bindparam() দিয়ে রাখা নামযুক্ত প্যারামিটারের মান বসিয়ে একটি কপি দেয়।
primary_key প্রপার্টি সাবকুয়েরির যে কলামগুলো মূল টেবিলের primary key থেকে এসেছে।
replace_selectable() মেথড ১.৪ থেকে বাতিলের পথে।
schema অ্যাট্রিবিউট (internal) Table-এর সাথে সামঞ্জস্যের জন্য; সাবকুয়েরিতে সবসময় None।
select() মেথড এই সাবকুয়েরি থেকে সব কলামসহ একটি নতুন SELECT * FROM (সাবকুয়েরি) বানায়।
selectable প্রপার্টি ভেতরের সামঞ্জস্য-প্রপার্টি; নিজেকেই দেয়।
self_group() মেথড বড় এক্সপ্রেশনে বসানোর সময় প্রয়োজনমতো বন্ধনী (( ... )) দেয়।
stringify_dialect অ্যাট্রিবিউট str(stmt) / print(stmt) করলে কোন ডায়ালেক্টে SQL দেখানো হবে (ডিফল্ট সাধারণ "default")।
supports_execution অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এই কনস্ট্রাক্ট সরাসরি execute() করা যায় (True)।
table_valued() মেথড পুরো রো-কে একটি কলাম হিসেবে উপস্থাপন করে (PostgreSQL-এ রো-টিকে একটি record/composite মান হিসেবে)।
tablesample() মেথড TABLESAMPLE দিয়ে টেবিলের এলোমেলো নমুনা (শতাংশ হিসেবে) নেওয়ার alias বানায়।
unique_params() মেথড params()-এর মতো, কিন্তু প্যারামিটারগুলোর নাম অনন্য (unique) করে দেয়, যাতে একই স্টেটমেন্টের কয়েকটি কপি এক কুয়েরিতে মেলানো যায়।
uses_inspection অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: inspect() এই অবজেক্টে কাজ করে কি না।
with_cols() মেথড (২.১-এ নতুন) শুধু টাইপ চেকারের জন্য: এই FROM-কে একটি নির্দিষ্ট TypedColumns ক্লাসের কলাম আছে বলে ঘোষণা করে।

Subquery.with_cols()¶

ধরন: মেথড

CTE¶

from sqlalchemy.sql.expression import CTE

stmt.cte() থেকে পাওয়া Common Table Expression (WITH নাম AS (...))। সাবকুয়েরির মতোই .c দিয়ে কলাম, আর FROM-এ বসানো যায়। recursive CTE-তে union_all() দিয়ে নিজের সাথে জোড়া হয়। পূর্ণ উদাহরণ: Recursive CTE।

উদাহরণ:

nums = select(literal(1).label("n")).cte("nums", recursive=True)
nums = nums.union_all(select(nums.c.n + 1).where(nums.c.n < 5))
print(session.execute(select(nums.c.n)).scalars().all())   # [1, 2, 3, 4, 5]

সব মেথড ও অ্যাট্রিবিউট এক নজরে¶

সদস্য ধরন কাজ
alias() মেথড এই সাবকুয়েরির আরেকটি নামযুক্ত alias দেয়, যাতে একই সাবকুয়েরি একটি কুয়েরিতে দুবার ব্যবহার করা যায়।
allows_lambda অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এই ধরনের স্টেটমেন্ট lambda_stmt()-এর ভেতরে ব্যবহার করা যায় কি না।
c প্রপার্টি সাবকুয়েরির কলামগুলো (columns-এর ছোট নাম)।
columns প্রপার্টি সাবকুয়েরির কলামের নাম-ভিত্তিক সংগ্রহ (ColumnCollection)।
compare() মেথড দুটি স্টেটমেন্টের গঠন হুবহু একই কি না তুলনা করে।
compile() মেথড স্টেটমেন্টকে SQL স্ট্রিংয়ে কম্পাইল করে।
corresponding_column() মেথড একটি মূল কলাম (যেমন User.__table__.c.id) দিলে এই স্টেটমেন্টের রপ্তানি করা কলামগুলোর মধ্যে সংশ্লিষ্টটি খুঁজে দেয়।
description প্রপার্টি ভেতরের একটি বর্ণনামূলক নাম (লগ/ডিবাগিংয়ের জন্য)।
entity_namespace প্রপার্টি filter_by()-এর মতো নাম দিয়ে খোঁজার সময় কোন এন্টিটির নাম-ভান্ডার ব্যবহার হবে, তার ভেতরের হুক।
exported_columns প্রপার্টি এই স্টেটমেন্ট যে কলামগুলো "রপ্তানি" করে (বাইরে থেকে পাওয়া যায়) তার সংগ্রহ।
foreign_keys প্রপার্টি এই সাবকুয়েরির কলামগুলো যেসব ফরেন কি রেফার করে তার সংগ্রহ (মূল টেবিল থেকে আসে)।
get_children() মেথড এই এক্সপ্রেশন-গাছের সরাসরি "সন্তান" উপাদানগুলো দেয়।
implicit_returning প্রপার্টি Table-এর সাথে সামঞ্জস্যের জন্য রাখা ভেতরের ফ্ল্যাগ; সাবকুয়েরিতে অর্থহীন।
inherit_cache অ্যাট্রিবিউট কাস্টম SQL কনস্ট্রাক্ট বানানোর সময় সাবক্লাস বেস ক্লাসের ক্যাশ-key ব্যবস্থা নেবে কি না তার ফ্ল্যাগ।
is_clause_element অ্যাট্রিবিউট ভেতরের টাইপ-ফ্ল্যাগ: এটি একটি SQL এক্সপ্রেশন উপাদান (True)।
is_derived_from() মেথড এই স্টেটমেন্ট একটি নির্দিষ্ট টেবিল/FROM থেকে তৈরি কি না দেখে।
is_dml অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: INSERT/UPDATE/DELETE কি না (Select-এ False)।
is_selectable অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এটি একটি selectable (রো দেয় এমন) কনস্ট্রাক্ট।
join() মেথড এই সাবকুয়েরি আর আরেকটি টেবিল/সাবকুয়েরির Join অবজেক্ট বানায় (টেবিলের join()-এর মতো), যা select_from()-এ বসানো যায়।
lateral() মেথড LATERAL সাবকুয়েরি বানায়: এটি বাম দিকের টেবিলের কলাম রেফার করতে পারে।
memoized_attribute অ্যাট্রিবিউট ভেতরের ডেকোরেটর (একবার হিসাব করে মনে রাখা প্রপার্টি)।
memoized_instancemethod() ক্লাস মেথড ভেতরের ডেকোরেটর (মেথডের ফল মনে রাখা)।
named_with_column অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: কলাম রেফার করার সময় এই FROM-এর নাম আগে বসবে কি না (sub.col)।
original প্রপার্টি যে মূল SELECT থেকে সাবকুয়েরিটি বানানো, সেটি।

prefix_with() মেথড SELECT শব্দের ঠিক পরে কিছু যোগ করে, যেমন MySQL-এর HIGH_PRIORITY বা optimizer hint।
primary_key প্রপার্টি সাবকুয়েরির যে কলামগুলো মূল টেবিলের primary key থেকে এসেছে।
replace_selectable() মেথড ১.৪ থেকে বাতিলের পথে।
schema অ্যাট্রিবিউট Table-এর সাথে সামঞ্জস্যের জন্য; সাবকুয়েরিতে সবসময় None।
select() মেথড এই সাবকুয়েরি থেকে সব কলামসহ একটি নতুন SELECT * FROM (সাবকুয়েরি) বানায়।
selectable প্রপার্টি ভেতরের সামঞ্জস্য-প্রপার্টি; নিজেকেই দেয়।
self_group() মেথড বড় এক্সপ্রেশনে বসানোর সময় প্রয়োজনমতো বন্ধনী (( ... )) দেয়।
stringify_dialect অ্যাট্রিবিউট str(stmt) / print(stmt) করলে কোন ডায়ালেক্টে SQL দেখানো হবে (ডিফল্ট সাধারণ "default")।
suffix_with() মেথড পুরো স্টেটমেন্টের শেষে কিছু যোগ করে (ডেটাবেস-নির্দিষ্ট অপশনের জন্য)।
supports_execution অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এই কনস্ট্রাক্ট সরাসরি execute() করা যায় (True)।
table_valued() মেথড পুরো রো-কে একটি কলাম হিসেবে উপস্থাপন করে (PostgreSQL-এ রো-টিকে একটি record/composite মান হিসেবে)।
tablesample() মেথড TABLESAMPLE দিয়ে টেবিলের এলোমেলো নমুনা (শতাংশ হিসেবে) নেওয়ার alias বানায়।
union() মেথড recursive CTE বানাতে: এই CTE-র anchor অংশের সাথে recursive অংশ UNION (ডুপ্লিকেট বাদ) দিয়ে জোড়ে।
union_all() মেথড recursive CTE-র সবচেয়ে প্রচলিত রূপ: anchor + recursive অংশ UNION ALL দিয়ে জোড়ে।
unique_params() মেথড params()-এর মতো, কিন্তু প্যারামিটারগুলোর নাম অনন্য (unique) করে দেয়, যাতে একই স্টেটমেন্টের কয়েকটি কপি এক কুয়েরিতে মেলানো যায়।
uses_inspection অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: inspect() এই অবজেক্টে কাজ করে কি না।
with_cols() মেথড (২.১-এ নতুন) শুধু টাইপ চেকারের জন্য: এই FROM-কে একটি নির্দিষ্ট TypedColumns ক্লাসের কলাম আছে বলে ঘোষণা করে।

CTE.union()¶

CTE.union(*other)

ধরন: মেথড

recursive CTE বানাতে: এই CTE-র anchor অংশের সাথে recursive অংশ UNION (ডুপ্লিকেট বাদ) দিয়ে জোড়ে।

উদাহরণ:

c = select(literal(1).label("n")).cte("c", recursive=True)
c = c.union(select(c.c.n + 1).where(c.c.n < 3))
print(session.execute(select(c.c.n)).scalars().all())   # [1, 2, 3]

values()¶

from sqlalchemy import values

values(*columns, name=None, literal_binds=False)

ধরন: ফাংশন

Python ডেটা থেকে একটি অস্থায়ী টেবিলের মতো VALUES (...), (...) কনস্ট্রাক্ট বানায়, যাকে টেবিলের মতো join বা select করা যায়। অনেক মান দিয়ে একসাথে মেলানো/আপডেট করতে কাজে লাগে।

উদাহরণ:

v = values(column("id", Integer), column("nick", String), name="nicks").data([(1, "রহি"), (2, "করি")])
stmt = select(User.name, v.c.nick).join(v, v.c.id == User.id).order_by(User.id)
print(session.execute(stmt).all())   # [('রহিম', 'রহি'), ('করিম', 'করি')]

Values¶

from sqlalchemy.sql.expression import Values

values() থেকে পাওয়া কনস্ট্রাক্ট। টেবিল/সাবকুয়েরির মতো আচরণ করে।

উদাহরণ:

v = values(column("n", Integer), name="v").data([(1,), (2,)])
print(session.execute(select(v.c.n)).scalars().all())   # [1, 2]

সব মেথড ও অ্যাট্রিবিউট এক নজরে¶

সদস্য ধরন কাজ
add_cte() মেথড স্টেটমেন্টের সাথে একটি বা একাধিক CTE স্পষ্টভাবে যুক্ত করে, মূল কুয়েরিতে সেটা ব্যবহার না হলেও।
alias() মেথড এই সাবকুয়েরির আরেকটি নামযুক্ত alias দেয়, যাতে একই সাবকুয়েরি একটি কুয়েরিতে দুবার ব্যবহার করা যায়।
allows_lambda অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এই ধরনের স্টেটমেন্ট lambda_stmt()-এর ভেতরে ব্যবহার করা যায় কি না।
c প্রপার্টি সাবকুয়েরির কলামগুলো (columns-এর ছোট নাম)।
columns প্রপার্টি সাবকুয়েরির কলামের নাম-ভিত্তিক সংগ্রহ (ColumnCollection)।
compare() মেথড দুটি স্টেটমেন্টের গঠন হুবহু একই কি না তুলনা করে।
compile() মেথড স্টেটমেন্টকে SQL স্ট্রিংয়ে কম্পাইল করে।
corresponding_column() মেথড একটি মূল কলাম (যেমন User.__table__.c.id) দিলে এই স্টেটমেন্টের রপ্তানি করা কলামগুলোর মধ্যে সংশ্লিষ্টটি খুঁজে দেয়।
cte() মেথড এই SELECT-কে একটি CTE (WITH নাম AS (...)) বানায়।
data() মেথড VALUES-এর রো-গুলো (tuple-এর তালিকা) দেয়, আর নতুন একটি Values ফেরত দেয়।
description প্রপার্টি ভেতরের একটি বর্ণনামূলক নাম (লগ/ডিবাগিংয়ের জন্য)।
entity_namespace প্রপার্টি filter_by()-এর মতো নাম দিয়ে খোঁজার সময় কোন এন্টিটির নাম-ভান্ডার ব্যবহার হবে, তার ভেতরের হুক।
exported_columns প্রপার্টি এই স্টেটমেন্ট যে কলামগুলো "রপ্তানি" করে (বাইরে থেকে পাওয়া যায়) তার সংগ্রহ।
foreign_keys প্রপার্টি এই সাবকুয়েরির কলামগুলো যেসব ফরেন কি রেফার করে তার সংগ্রহ (মূল টেবিল থেকে আসে)।
get_children() মেথড এই এক্সপ্রেশন-গাছের সরাসরি "সন্তান" উপাদানগুলো দেয়।
inherit_cache অ্যাট্রিবিউট কাস্টম SQL কনস্ট্রাক্ট বানানোর সময় সাবক্লাস বেস ক্লাসের ক্যাশ-key ব্যবস্থা নেবে কি না তার ফ্ল্যাগ।
is_clause_element অ্যাট্রিবিউট ভেতরের টাইপ-ফ্ল্যাগ: এটি একটি SQL এক্সপ্রেশন উপাদান (True)।
is_derived_from() মেথড এই স্টেটমেন্ট একটি নির্দিষ্ট টেবিল/FROM থেকে তৈরি কি না দেখে।
is_dml অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: INSERT/UPDATE/DELETE কি না (Select-এ False)।
is_selectable অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এটি একটি selectable (রো দেয় এমন) কনস্ট্রাক্ট।
join() মেথড এই সাবকুয়েরি আর আরেকটি টেবিল/সাবকুয়েরির Join অবজেক্ট বানায় (টেবিলের join()-এর মতো), যা select_from()-এ বসানো যায়।
lateral() মেথড VALUES-কে LATERAL হিসেবে চিহ্নিত করে, যাতে এটি বাম দিকের টেবিলের কলাম রেফার করতে পারে।
memoized_attribute অ্যাট্রিবিউট ভেতরের ডেকোরেটর (একবার হিসাব করে মনে রাখা প্রপার্টি)।
memoized_instancemethod() ক্লাস মেথড ভেতরের ডেকোরেটর (মেথডের ফল মনে রাখা)।
name_cte_columns অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: CTE বানানোর সময় কলামের নামগুলো WITH নাম(কলাম১, কলাম২) আকারে লেখা হবে কি না (values()-এর মতো কনস্ট্রাক্টে লাগে)।
named_with_column অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: কলাম রেফার করার সময় এই FROM-এর নাম আগে বসবে কি না (sub.col)।
outerjoin() মেথড join()-এর মতো, কিন্তু LEFT OUTER JOIN দিয়ে Join অবজেক্ট বানায়।
params() মেথড bindparam() দিয়ে রাখা নামযুক্ত প্যারামিটারের মান বসিয়ে একটি কপি দেয়।
primary_key প্রপার্টি সাবকুয়েরির যে কলামগুলো মূল টেবিলের primary key থেকে এসেছে।
replace_selectable() মেথড ১.৪ থেকে বাতিলের পথে।
scalar_values() মেথড এক কলামের VALUES-কে একটি scalar এক্সপ্রেশন বানায়, যেমন IN (VALUES (1), (2))-এ ব্যবহারের জন্য।
schema অ্যাট্রিবিউট Table-এর সাথে সামঞ্জস্যের জন্য; সাবকুয়েরিতে সবসময় None।
select() মেথড এই সাবকুয়েরি থেকে সব কলামসহ একটি নতুন SELECT * FROM (সাবকুয়েরি) বানায়।
selectable প্রপার্টি ভেতরের সামঞ্জস্য-প্রপার্টি; নিজেকেই দেয়।
self_group() মেথড বড় এক্সপ্রেশনে বসানোর সময় প্রয়োজনমতো বন্ধনী (( ... )) দেয়।
stringify_dialect অ্যাট্রিবিউট str(stmt) / print(stmt) করলে কোন ডায়ালেক্টে SQL দেখানো হবে (ডিফল্ট সাধারণ "default")।
supports_execution অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এই কনস্ট্রাক্ট সরাসরি execute() করা যায় (True)।
table_valued() মেথড পুরো রো-কে একটি কলাম হিসেবে উপস্থাপন করে (PostgreSQL-এ রো-টিকে একটি record/composite মান হিসেবে)।
tablesample() মেথড TABLESAMPLE দিয়ে টেবিলের এলোমেলো নমুনা (শতাংশ হিসেবে) নেওয়ার alias বানায়।
unique_params() মেথড params()-এর মতো, কিন্তু প্যারামিটারগুলোর নাম অনন্য (unique) করে দেয়, যাতে একই স্টেটমেন্টের কয়েকটি কপি এক কুয়েরিতে মেলানো যায়।
uses_inspection অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: inspect() এই অবজেক্টে কাজ করে কি না।
with_cols() মেথড (২.১-এ নতুন) শুধু টাইপ চেকারের জন্য: এই FROM-কে একটি নির্দিষ্ট TypedColumns ক্লাসের কলাম আছে বলে ঘোষণা করে।

  • select() অপরিবর্তনীয়: প্রতিটি মেথড নতুন স্টেটমেন্ট দেয়, তাই stmt = stmt.where(...)।
  • ফিল্টার: where() / filter_by(); জোড়া: join() / outerjoin(); দল: group_by() + having(); ক্রম ও পেজ: order_by(), limit(), offset(), slice()।
  • সাবকুয়েরি তিন রূপে: FROM-এ subquery(), একটি মান হিসেবে scalar_subquery(), শর্ত হিসেবে exists(); নাম দিয়ে আলাদা অংশ cte()।
  • সেট-অপারেশন: union() / union_all() / intersect() / except_()।
  • ২.১: distinct(কলাম) নয়, .ext(distinct_on(কলাম)); নতুন টেবিল বানাতে into()।
