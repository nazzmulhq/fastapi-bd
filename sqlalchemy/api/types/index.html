কলাম টাইপ API: String, Integer, Numeric, DateTime, Enum, JSON, ARRAY …¶

এই পেজে যা আছে

  • TypeEngine: সব টাইপের মূল ক্লাস ও তার সব মেথড (with_variant(), compile(), python_type, evaluates_none() …)।
  • সাধারণ (generic) টাইপ: String, Text, Unicode, UnicodeText, Integer, SmallInteger, BigInteger, Numeric, Float, Double, Boolean, Date, DateTime, Time, Interval, LargeBinary, Enum, JSON (আর JSON.Comparator), ARRAY (আর ARRAY.Comparator), PickleType, Uuid, TupleType, NullType, MatchType।
  • SQL স্ট্যান্ডার্ড টাইপ (বড় হাতের নাম): VARCHAR, CHAR, TEXT, CLOB, NVARCHAR, NCHAR, INTEGER, INT, SMALLINT, BIGINT, NUMERIC, DECIMAL, FLOAT, REAL, DOUBLE, DOUBLE_PRECISION, BOOLEAN, DATE, DATETIME, TIMESTAMP, TIME, BINARY, VARBINARY, BLOB, UUID।
  • মিক্সিন ও ২.১-এর নতুন: Concatenable, Indexable, NumericCommon, SchemaType, OperatorClass।

কোনটা ব্যবহার করবেন: সাধারণত CamelCase generic টাইপ (String, Integer, DateTime): SQLAlchemy প্রতিটি ডেটাবেসে সবচেয়ে উপযুক্ত আসল টাইপ বসায়। ঠিক কোন SQL টাইপ চান তা নিশ্চিত করতে বড় হাতের SQL-standard টাইপ (VARCHAR, TIMESTAMP)। আর ডেটাবেস-বিশেষ টাইপ আছে ডায়ালেক্ট পেজে: PostgreSQL (JSONB, ARRAY, HSTORE), PostgreSQL টাইপ (range, ENUM, INET, TSVECTOR …), MySQL, SQLite। ORM-এ Mapped[int], Mapped[str] লিখলে টাইপ নিজে থেকে বেছে নেওয়া হয় (Model অধ্যায়)।

উদাহরণগুলোর জন্য ধরে নেওয়া সেটআপ

  • rt(টাইপ, মান): একটি অস্থায়ী টেবিলে মানটি লিখে আবার পড়ে যা ফেরত আসে তা দেয় (round-trip)।
  • pgt(টাইপ): PostgreSQL-এর CREATE TABLE-এ টাইপটি কী নামে বসবে।

সব উদাহরণ PostgreSQL 16-এ চালিয়ে দেখা।

TypeEngine¶

from sqlalchemy.types import TypeEngine

সব SQL টাইপের মূল ক্লাস। একটি টাইপ তিনটি কাজ করে: DDL-এ কী নাম বসবে (compile()), Python মান কীভাবে ডেটাবেসে যাবে ও ফিরবে (bind_processor() / result_processor()), আর সেই টাইপের কলামে কোন অপারেটর চলবে (comparator_factory)। নিচের মেথডগুলো সব টাইপে আছে।

উদাহরণ:

t = String(50)
print(isinstance(t, TypeEngine), pgt(t), t.python_type)   # True VARCHAR(50) <class 'str'>

সদস্য ধরন কাজ
Comparator অ্যাট্রিবিউট টাইপ-স্তরের অপারেটর-ক্লাস; নিজের অপারেটর যোগ করতে সাবক্লাস করুন।

as_generic() মেথড ডায়ালেক্ট-নির্দিষ্ট টাইপের সবচেয়ে কাছের generic রূপ দেয় (reflection থেকে পাওয়া টাইপকে অন্য ডেটাবেসে কপি করতে)।
bind_expression() মেথড (override করার জন্য) প্যারামিটারকে SQL ফাংশনে মোড়ায়; ডিফল্টে None (মোড়ায় না)।
bind_processor() মেথড একটি ডায়ালেক্টের জন্য Python মান → DB-API মানের রূপান্তর-ফাংশন দেয় (দরকার না হলে None)।
coerce_compared_value() মেথড col <অপারেটর> Python-মান-এ ডান দিকের মানটি কোন টাইপে ধরা হবে।
column_expression() মেথড (override করার জন্য) SELECT-এ কলামকে SQL ফাংশনে মুড়িয়ে পড়ে; ডিফল্টে None।
comparator_factory অ্যাট্রিবিউট এই টাইপের কলামে অপারেটরগুলো যে Comparator ক্লাস থেকে আসে।
compare_values() মেথড দুটি Python মান এই টাইপের দৃষ্টিতে সমান কি না (ORM dirty-checking-এ: মান আসলে বদলেছে কি না)।
compile() মেথড টাইপটি একটি ডায়ালেক্টে (না দিলে ডিফল্ট) DDL-এ কী নামে বসবে তার স্ট্রিং।
copy() মেথড একই আর্গুমেন্টে টাইপের একটি কপি।
copy_value() মেথড (internal) ORM-এর জন্য একটি মানের কপি বানায় (mutable মানের "আগের অবস্থা" রাখতে)।
dialect_impl() মেথড একটি ডায়ালেক্টে এই টাইপের জন্য আসলে যে (ডায়ালেক্ট-নির্দিষ্ট) টাইপ অবজেক্ট ব্যবহার হবে।
evaluates_none() মেথড এমন একটি কপি দেয় যেখানে Python None-কে "কিছু দেওয়া হয়নি" না ধরে একটি মান হিসেবে ধরা হয়, ফলে INSERT-এ ডিফল্ট না বসে সরাসরি NULL যায়।
get_dbapi_type() মেথড (internal) DB-API ড্রাইভারের সংশ্লিষ্ট টাইপ-অবজেক্ট (কিছু ড্রাইভারে setinputsizes()-এর জন্য)।
hashable অ্যাট্রিবিউট এই টাইপের মান Python-এ hashable কি না।
literal_processor() মেথড মান যখন প্যারামিটার না হয়ে SQL-এ সরাসরি বসে (literal_binds), তখন মানটিকে SQL লেখায় রূপান্তরের ফাংশন।
operator_classes অ্যাট্রিবিউট (২.১-এ নতুন) এই টাইপে কোন ধরনের built-in অপারেটর বৈধ (OperatorClass flag-এর মিশ্রণ)।
python_type প্রপার্টি এই টাইপের কলাম থেকে সাধারণত যে Python টাইপ আসে।
render_bind_cast অ্যাট্রিবিউট (internal) কিছু ড্রাইভারে (asyncpg, psycopg 3) প্যারামিটারের পাশে ::টাইপ CAST বসাতে হবে কি না।
render_literal_cast অ্যাট্রিবিউট (internal) literal হিসেবে বসানো মানের পাশে CAST বসাতে হবে কি না।
repr_struct() মেথড (internal) টাইপের repr() বানানোর জন্য গঠন-তথ্য (Alembic autogenerate-এ টাইপ লিখতে কাজে লাগে)।
result_processor() মেথড ডেটাবেস থেকে আসা মান → Python মানের রূপান্তর-ফাংশন (দরকার না হলে None)।
should_evaluate_none অ্যাট্রিবিউট evaluates_none() প্রয়োগ হয়েছে কি না।
sort_key_function অ্যাট্রিবিউট ORM primary key হিসেবে এই টাইপের মান সাজানোর ফাংশন (যেমন Python Enum মান সরাসরি তুলনা করা যায় না বলে); না দিলে None।
with_variant() মেথড নির্দিষ্ট ডায়ালেক্টে ভিন্ন টাইপ ব্যবহারের কপি: যেমন সাধারণত JSON, কিন্তু PostgreSQL-এ JSONB।

m.create_all(engine)
from sqlalchemy.orm import Session, registry
class Row: pass
registry().map_imperatively(Row, t)
with Session(engine) as s:
    r = Row(); r.a = None; r.b = None
    s.add(r); s.commit()
    print(s.execute(select(t.c.a, t.c.b)).one())   # ('ডিফল্ট', None)
