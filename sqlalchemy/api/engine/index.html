Engine, Connection ও URL API: create_engine() থেকে Transaction¶

এই পেজে যা আছে

  • create_engine()-এর প্রতিটি অপশন (পুল, লগিং, isolation level, ক্যাশ, JSON …), আর engine_from_config(), create_mock_engine(), create_pool_from_url(), make_url()।
  • Engine, Connection-এর সব সদস্য।
  • Transaction, RootTransaction, NestedTransaction (SAVEPOINT), TwoPhaseTransaction।
  • URL (ডেটাবেস ঠিকানা) আর CreateEnginePlugin।

Engine হলো ডেটাবেসের সাথে যোগাযোগের কেন্দ্র: একটি কানেকশন পুল আর একটি ডায়ালেক্ট (কোন ডেটাবেস, কোন ড্রাইভার)। অ্যাপে একবারই বানান (মডিউল-স্তরে), প্রতি রিকোয়েস্টে নয়। Connection হলো পুল থেকে ধার নেওয়া একটি কানেকশন; কাজ শেষে with ব্লক থেকে বেরোলেই পুলে ফেরত যায়। ORM-এর Session ভেতরে এগুলোই ব্যবহার করে। async সংস্করণ (create_async_engine, AsyncEngine) আছে Async API পেজে।

উদাহরণগুলোর জন্য ধরে নেওয়া সেটআপ

URL_STR = "postgresql+psycopg2://postgres@127.0.0.1/apiref"
engine = create_engine(URL_STR)

md = MetaData()
users = Table("users", md, Column("id", Integer, primary_key=True), Column("name", String(50)))
md.create_all(engine)    # তিনজন ইউজার: রহিম, করিম, সুমি

count() টেবিলে কয়টি রো আছে দেখায় (নতুন কানেকশনে, অর্থাৎ শুধু commit হওয়া ডেটা)। সব উদাহরণ PostgreSQL 16-এ চালিয়ে দেখা।

Engine তৈরির ফাংশন¶

create_engine()¶

from sqlalchemy import create_engine

create_engine(url, **kwargs)

ধরন: ফাংশন

একটি ডেটাবেস URL থেকে Engine বানায়। URL-এর রূপ: ডায়ালেক্ট+ড্রাইভার://ইউজার:পাসওয়ার্ড@হোস্ট:পোর্ট/ডেটাবেস?অপশন। ২.১-এ পরিবর্তন: ড্রাইভার না লিখলে (postgresql://...) এখন psycopg 3 (psycopg) ব্যবহার হয়, আগে ছিল psycopg2; তাই ড্রাইভার সবসময় স্পষ্ট লিখুন (postgresql+psycopg2://, postgresql+psycopg://, postgresql+asyncpg://)। এখানে কোনো কানেকশন খোলে না; প্রথম connect()-এ খোলে। পাসওয়ার্ডে @, / ইত্যাদি থাকলে URL-এ সরাসরি না লিখে URL.create() ব্যবহার করুন।

উদাহরণ:

eng = create_engine(URL_STR, pool_size=5, max_overflow=10, pool_pre_ping=True, pool_recycle=1800)
with eng.connect() as conn:
    print(conn.scalar(text("SELECT 1 + 1")))   # 2
print(eng.dialect.name, eng.driver, type(eng.pool).__name__)   # postgresql psycopg2 QueuePool
eng.dispose()

create_engine()-এর সব প্যারামিটার¶

সব মেথড ও অ্যাট্রিবিউট এক নজরে¶

সদস্য ধরন কাজ
begin() মেথড স্পষ্টভাবে ট্রানজ্যাকশন শুরু করে (RootTransaction); context manager হিসেবে ব্লক শেষে commit/rollback।
begin_nested() মেথড ট্রানজ্যাকশনের ভেতরে একটি SAVEPOINT: শুধু এই অংশ rollback করা যায়, বাইরের কাজ থাকে।
begin_twophase() মেথড two-phase (XA) ট্রানজ্যাকশন শুরু করে: একাধিক ডেটাবেসে একসাথে commit নিশ্চিত করতে (prepare() তারপর commit())।
close() মেথড কানেকশন বন্ধ করে পুলে ফেরত দেয় (চলমান ট্রানজ্যাকশন rollback হয়)।
closed প্রপার্টি কানেকশন বন্ধ কি না।
commit() মেথড চলমান ট্রানজ্যাকশন commit করে।
commit_prepared() মেথড আগে prepare() করা একটি two-phase ট্রানজ্যাকশন (xid দিয়ে) commit করে; ক্র্যাশের পর পুনরুদ্ধারে।
connection প্রপার্টি নিচের DBAPI কানেকশন (পুল-মোড়ানো PoolProxiedConnection)।
default_isolation_level প্রপার্টি কানেকশন খোলার সময় ডেটাবেসের ডিফল্ট isolation level।
detach() মেথড কানেকশনটিকে পুল থেকে আলাদা করে: close() করলে পুলে না ফিরে আসলেই বন্ধ হয়।
dialect অ্যাট্রিবিউট ব্যবহৃত ডায়ালেক্ট।
engine অ্যাট্রিবিউট যে Engine থেকে কানেকশনটি এসেছে।
exec_driver_sql() মেথড একটি কাঁচা SQL স্ট্রিং সরাসরি ড্রাইভারে চালায় (SQLAlchemy-র কম্পাইল ছাড়া)।
execute() মেথড একটি স্টেটমেন্ট (select(), insert(), text() …) চালিয়ে CursorResult দেয়।
execution_options() মেথড এই কানেকশনের execution option সেট করে (জায়গাতেই): isolation_level, stream_results, yield_per, schema_translate_map, logging_token, compiled_cache ইত্যাদি।
get_execution_options() মেথড সেট করা execution option-গুলো।
get_isolation_level() মেথড ডেটাবেসে এই কানেকশনের বর্তমান isolation level (একটি কুয়েরি চালিয়ে জানে)।
get_nested_transaction() মেথড চলমান SAVEPOINT (NestedTransaction), না থাকলে None।
get_transaction() মেথড চলমান মূল ট্রানজ্যাকশন, না থাকলে None।
in_nested_transaction() মেথড SAVEPOINT চলছে কি না।
in_transaction() মেথড ট্রানজ্যাকশন চলছে কি না।
info প্রপার্টি নিচের DBAPI কানেকশনের সাথে যুক্ত dict: কানেকশন পুলে ফিরলেও থেকে যায়।
invalidate() মেথড কানেকশনটিকে "নষ্ট" ঘোষণা করে: পুল এটিকে আর ব্যবহার করবে না, পরের কাজে নতুন কানেকশন খুলবে।
invalidated প্রপার্টি কানেকশন invalidate হয়েছে কি না।
recover_twophase() মেথড ডেটাবেসে "prepared" অবস্থায় আটকে থাকা two-phase ট্রানজ্যাকশনগুলোর xid তালিকা দেয়।
rollback() মেথড চলমান ট্রানজ্যাকশন বাতিল করে।
rollback_prepared() মেথড prepare() করা two-phase ট্রানজ্যাকশন rollback করে।
scalar() মেথড স্টেটমেন্ট চালিয়ে প্রথম রো-র প্রথম কলাম দেয় (রো না থাকলে None)।
scalars() মেথড স্টেটমেন্ট চালিয়ে প্রতিটি রো-র প্রথম কলামের ScalarResult দেয়।
schema_for_object() মেথড একটি স্কিমা-অবজেক্টের আসল স্কিমা নাম দেয়, schema_translate_map হিসাবে নিয়ে (মাল্টি-টেন্যান্টে কাজে লাগে)।
should_close_with_result অ্যাট্রিবিউট (internal) (পুরোনো API-র অবশেষ) রেজাল্ট শেষ হলে কানেকশন বন্ধ হবে কি না; ২.০-তে সবসময় False।

CreateEnginePlugin¶

from sqlalchemy.engine import CreateEnginePlugin

create_engine()-এর আচরণ বদলানোর প্লাগিন (ট্রেসিং, মেট্রিক্স, কানেকশন অপশন যোগ)। URL-এ ?plugin=নাম বা create_engine(..., plugins=["নাম"]) দিয়ে চালু হয়; entry point হিসেবে নিবন্ধন করতে হয়।

উদাহরণ:

import sys, types
from sqlalchemy.dialects import plugins

class TagPlugin(CreateEnginePlugin):
    def update_url(self, url):
        return url.difference_update_query(["tag"])
    def engine_created(self, engine):
        engine.info_tag = self.url.query.get("tag")

mod = types.ModuleType("my_tag_plugin"); mod.TagPlugin = TagPlugin; sys.modules["my_tag_plugin"] = mod
plugins.register("tagplugin", "my_tag_plugin", "TagPlugin")    # সাধারণত setup.py/pyproject-এর entry point দিয়ে
eng = create_engine(URL_STR + "?plugin=tagplugin&tag=api")
print(eng.info_tag, eng.url)   # api postgresql+psycopg2://postgres@127.0.0.1/apiref
eng.dispose()

সংক্ষেপে মনে রাখুন

  • Engine অ্যাপে একটি; প্রোডাকশনে pool_pre_ping=True, প্রয়োজনে pool_recycle।
  • লেখার কাজ: with engine.begin() as conn: (নিজে commit/rollback); পড়া: with engine.connect() as conn:।
  • connect()-এ conn.commit() না ডাকলে কিছুই সেভ হয় না।
  • আংশিক rollback: conn.begin_nested() (SAVEPOINT)।
  • পাসওয়ার্ডে বিশেষ অক্ষর: URL.create(...); লগে URL দেখাতে render_as_string() (পাসওয়ার্ড লুকানো)।
  • অ্যাপ বন্ধে / fork-এর পর: engine.dispose()।
