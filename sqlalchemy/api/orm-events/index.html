ORM Event API: Session, Mapper, Instance ও Attribute event¶

এই পেজে যা আছে

ORM-এর সব event hook, প্রতিটির listener-সিগনেচার আর চালিয়ে দেখা উদাহরণ:

  • SessionEvents (২৫টি): flush, commit, rollback, অবজেক্টের অবস্থা-পরিবর্তন, আর সবচেয়ে শক্তিশালী do_orm_execute।
  • MapperEvents (১২টি): INSERT/UPDATE/DELETE-এর আগে-পরে, mapper configure।
  • InstanceEvents (৮টি): অবজেক্ট তৈরি, লোড, refresh, expire, pickle।
  • AttributeEvents (৯টি): অ্যাট্রিবিউট সেট, কালেকশনে যোগ/বাদ।
  • InstrumentationEvents (৩টি), ২.১-এর নতুন RegistryEvents (৩টি) আর পুরোনো QueryEvents (৩টি)।

event নিবন্ধনের নিয়ম (event.listen(), @event.listens_for) আর Core event আছে Core Event পেজে।

কোন কাজে কোন event

কাজ event
সব কুয়েরিতে soft-delete / tenant ফিল্টার SessionEvents.do_orm_execute + with_loader_criteria
সেভের আগে অবজেক্ট যাচাই বা হিসাব (slug, total) SessionEvents.before_flush
অডিট লগ: কোন অবজেক্ট বদলেছে before_flush (session.dirty) বা after_flush
commit সফল হলে ইমেইল/ক্যাশ ক্লিয়ার SessionEvents.after_commit (DB-তে কিছু লিখবেন না)
একটি মডেলের প্রতি INSERT-এ কিছু বসানো MapperEvents.before_insert
অ্যাট্রিবিউট বদলালে প্রতিক্রিয়া (normalize) AttributeEvents.set (retval=True)

সাধারণ ভুল

  • before_insert / after_update ইত্যাদি mapper event-এর ভেতরে session.add() বা অন্য অবজেক্ট বদলানো কাজ করে না (flush ততক্ষণে পরিকল্পিত)। সেসব কাজ before_flush-এ করুন; mapper event-এ শুধু নিজের অবজেক্টের কলাম বা connection.execute()।
  • async (AsyncSession)-এ listener বসান AsyncSession.sync_session_class-এ বা Session ক্লাসে; listener নিজে sync ফাংশন।

SessionEvents¶

from sqlalchemy.orm import SessionEvents

Session-এর event। টার্গেট: একটি Session অবজেক্ট, একটি sessionmaker, বা Session ক্লাস (সব session-এ)। উদাহরণে নিচের on() হেল্পার শুধু event.listen(), যা উদাহরণ শেষে listener সরিয়ে দেয়।

উদাহরণ:

for name in ["before_flush", "after_flush", "before_commit", "after_commit"]:
    on(session, name, lambda *a, n=name, **k: calls.append(n))
session.add(User(name="করিম")); session.commit()
print(calls)   # ['before_commit', 'before_flush', 'after_flush', 'after_commit']  (commit শুরু → নিজে থেকে flush → commit শেষ)

সব মেথড ও অ্যাট্রিবিউট এক নজরে¶

সদস্য ধরন কাজ
after_attach() মেথড একটি অবজেক্ট session-এ যুক্ত হওয়ার পরে (add(), cascade, merge())।
after_begin() মেথড session একটি কানেকশনে ট্রানজ্যাকশন শুরু করার পরে (প্রতি কানেকশনে একবার)।
after_bulk_delete() মেথড (legacy) পুরোনো Query.delete()-এর পরে।
after_bulk_update() মেথড (legacy) পুরোনো Query.update()-এর পরে।
after_commit() মেথড commit সফল হওয়ার পরে।
after_flush() মেথড flush শেষ হলে, কিন্তু session-এর অবস্থা (new, dirty, deleted) তখনো আগের মতো; কী কী সেভ হলো দেখার জায়গা (অডিট)।
after_flush_postexec() মেথড flush-এর পরে session-এর অবস্থা হালনাগাদ হয়ে যাওয়ার পর (তখন session.new খালি)।
after_rollback() মেথড আসল ডেটাবেস rollback হওয়ার পরে।
after_soft_rollback() মেথড যেকোনো rollback-এর পরে (nested বা "soft" rollback-সহ, যেখানে ডেটাবেসে কিছু নাও যেতে পারে)।
after_transaction_create() মেথড একটি নতুন SessionTransaction (মূল বা nested) তৈরি হলে।
after_transaction_end() মেথড একটি SessionTransaction শেষ হলে (commit/rollback/close)।
before_attach() মেথড অবজেক্ট session-এ যুক্ত হওয়ার আগে।
before_commit() মেথড commit-এর আগে (flush তখনো বাকি থাকতে পারে); শেষ মুহূর্তের যাচাই।
before_flush() মেথড flush শুরুর আগে: অবজেক্ট বদলানো, নতুন অবজেক্ট যোগ, যাচাই করার সঠিক জায়গা (session.new, session.dirty, session.deleted দেখে)।
deleted_to_detached() মেথড মোছা অবজেক্ট commit-এর পরে session থেকে বিচ্ছিন্ন হলে।
deleted_to_persistent() মেথড মোছা (flush হওয়া) অবজেক্ট rollback-এ আবার persistent হলে।
detached_to_persistent() মেথড detached অবজেক্ট আবার session-এ যুক্ত হলে (add())।
do_orm_execute() মেথড session-এর প্রতিটি ORM স্টেটমেন্ট চালানোর আগে (execute(), scalars(), lazy load, get() …)।
loaded_as_persistent() মেথড ডেটাবেস থেকে লোড হয়ে একটি অবজেক্ট persistent হলে।
pending_to_persistent() মেথড নতুন (pending) অবজেক্ট flush হয়ে persistent হলে (এখন primary key আছে)।
pending_to_transient() মেথড pending অবজেক্ট rollback বা expunge()-এ আবার transient হলে।
persistent_to_deleted() মেথড persistent অবজেক্টের DELETE flush হলে।
persistent_to_detached() মেথড persistent অবজেক্ট session থেকে বিচ্ছিন্ন হলে (expunge(), close())।
persistent_to_transient() মেথড persistent অবজেক্ট transient হলে (যেমন INSERT-এর পরে rollback, বা make_transient())।
transient_to_pending() মেথড নতুন অবজেক্ট add() হয়ে pending হলে।

after_configured() মেথড configure_mappers() শেষে একবার (সব mapper তৈরি)।
after_delete() মেথড অবজেক্টের DELETE চলার পরে।

after_mapper_constructed() মেথড (২.০.২) একটি mapper তৈরি হওয়ার পরপরই (configure-এর আগে)।

before_insert() মেথড INSERT-এর আগে: নিজের অবজেক্টের কলামে মান বসানো যায়।

instrument_class() মেথড ক্লাসটির mapper প্রথম তৈরি হওয়ার মুহূর্তে, অ্যাট্রিবিউট instrument হওয়ার আগে।
mapper_configured() মেথড একটি mapper-এর configure শেষ হলে (রিলেশনশিপ এখন প্রস্তুত); ক্লাস-ভিত্তিক সেটআপের জায়গা।

RegistryEvents¶

from sqlalchemy.orm import RegistryEvents

(২.১-এ নতুন) একটি registry-র (বা সরাসরি declarative Base ক্লাসের) event: annotation থেকে SQL টাইপ ঠিক করার সময় (resolve_type_annotation), আর সেই registry-র mapper configure হওয়ার আগে-পরে। টার্গেট Base দিলে তার registry নিজে খুঁজে নেয়।

উদাহরণ:

class B12(DeclarativeBase): pass
on(B12, "before_configured", lambda reg: calls.append(("before", type(reg).__name__)))
on(B12, "after_configured", lambda reg: calls.append(("after", type(reg).__name__)))
class T12(B12):
    __tablename__ = "t12"
    id: Mapped[int] = mapped_column(primary_key=True)
configure_mappers()
print(calls)   # [('before', 'registry'), ('after', 'registry')]

সদস্য ধরন কাজ

RegistryEvents.resolve_type_annotation()¶

RegistryEvents.resolve_type_annotation(resolve_type)

ধরন: মেথড

Mapped[X]-এর Python টাইপ X থেকে SQL টাইপ ঠিক করার সময় ডাকে, একটি TypeResolve অবজেক্ট দিয়ে। একটি SQL টাইপ ফেরত দিলে সেটাই ব্যবহার হয়; None দিলে সাধারণ নিয়ম (type_annotation_map) চলে। type_annotation_map-এ লেখা যায় না এমন টাইপের জন্য (যেমন NewType, PEP 695 type alias, নিজের নিয়ম)।

উদাহরণ:

import typing
from sqlalchemy import String
Email = typing.NewType("Email", str)
class B15(DeclarativeBase): pass
@on(B15, "resolve_type_annotation")
def resolve(rt):
    return String(320) if rt.resolved_type is Email else None
class Contact(B15):
    __tablename__ = "contacts"
    id: Mapped[int] = mapped_column(primary_key=True)
    email: Mapped[Email]
print(Contact.__table__.c.email.type)   # VARCHAR(320)
