Insert, Update, Delete ও text() API¶

এই পেজে যা আছে

  • insert(), update(), delete() আর Insert, Update, Delete-এর প্রতিটি মেথড।
  • raw SQL লেখার জন্য text(), TextClause আর TextualSelect।
  • ২.১-এ নতুন: Delete.using()।

এগুলোকে বলে DML (Data Manipulation Language): ডেটা ঢোকানো, বদলানো, মোছা। একটি একটি অবজেক্ট নিয়ে কাজ করলে session.add() / অ্যাট্রিবিউট বদল / session.delete() সহজ; কিন্তু অনেক রো একসাথে বদলাতে বা RETURNING চাইলে এই স্টেটমেন্টগুলো দ্রুত ও শক্তিশালী। ব্যবহারের ধরন শিখতে দেখুন CRUD ১ ও CRUD ২।

select()-এর মতো এগুলোও অপরিবর্তনীয়: প্রতিটি মেথড নতুন স্টেটমেন্ট দেয়। compile(), params(), cte(), execution_options(), prefix_with()-এর মতো সাধারণ মেথডগুলোর কাজ Select API-তে যেমন, এখানেও তেমন; সেগুলোর ব্যাখ্যা সেখানে লিংক করা।

Session API পেজের মতোই User / Address মডেল আর তিনজন ইউজার (রহিম, করিম, সুমি; রহিমের দুটি ঠিকানা)। উদাহরণগুলো PostgreSQL 16-এ চালিয়ে দেখা।

insert()¶

from sqlalchemy import insert

insert(table)

ধরন: ফাংশন

একটি INSERT স্টেটমেন্ট বানায়। লক্ষ্য হিসেবে মডেল (User) বা টেবিল দিন। মান দেওয়ার দুই উপায়: .values(...), অথবা চালানোর সময় dict / dict-এর তালিকা (বাল্ক insert, সবচেয়ে দ্রুত)।

উদাহরণ:

session.execute(insert(User).values(name="তানিয়া"))
session.execute(insert(User), [{"name": "অনু"}, {"name": "বিনু"}])      # বাল্ক
session.commit()
print(session.scalar(select(func.count()).select_from(User)))      # 6

Insert¶

from sqlalchemy import Insert

insert() থেকে পাওয়া স্টেটমেন্ট। ORM মডেল দিয়ে বানালে Python-side default প্রয়োগ হয়, আর returning(User) দিলে পুরো ORM অবজেক্টই ফেরত আসে।

উদাহরণ:

users = session.scalars(insert(User).returning(User), [{"name": "ক"}, {"name": "খ"}]).all()
print([(u.id, u.name) for u in users])   # [(4, 'ক'), (5, 'খ')]

Insert.from_select()¶

Insert.from_select(names, select, include_defaults=True)

ধরন: মেথড

INSERT INTO টেবিল (কলাম...) SELECT ... বানায়: একটি SELECT-এর ফলাফল সরাসরি টেবিলে ঢোকায়, Python-এ না এনে। include_defaults=False দিলে Python-side default কলামগুলো যোগ হয় না।

উদাহরণ:

copy = select(func.concat(User.name, "-কপি")).where(User.id == 1)
session.execute(insert(User).from_select(["name"], copy))
session.commit()
print(session.scalars(select(User.name).where(User.id == 4)).one())   # রহিম-কপি

Insert.returning()¶

Insert.returning(*cols, sort_by_parameter_order=False)

ধরন: মেথড

RETURNING যোগ করে: insert/update/delete হওয়া রো-গুলোর কলাম (বা ORM অবজেক্ট) সাথে সাথে ফেরত আসে, আলাদা SELECT ছাড়াই। PostgreSQL, SQLite, MariaDB, Oracle, SQL Server-এ চলে। বাল্ক insert-এ sort_by_parameter_order=True দিলে ফেরত রো দেওয়া প্যারামিটারের ক্রমে আসে।

উদাহরণ:

rows = session.execute(insert(User).returning(User.id, User.name), [{"name": "ক"}, {"name": "খ"}]).all()
print(rows)   # [(4, 'ক'), (5, 'খ')]

update()¶

from sqlalchemy import update

update(table)

ধরন: ফাংশন

একটি UPDATE স্টেটমেন্ট বানায়। .where() দিয়ে কোন রো, .values() দিয়ে নতুন মান। ORM-এ primary key-সহ dict-এর তালিকা দিয়ে চালালে প্রতিটি রো আলাদা মানে বদলায় ("bulk update by primary key")।

উদাহরণ:

session.execute(update(User).where(User.id > 1).values(name=User.name + " (সদস্য)"))
session.execute(update(User), [{"id": 1, "name": "রহিম খান"}])       # PK ধরে বাল্ক
session.commit()
print(session.scalars(select(User.name).order_by(User.id)).all())
# ['রহিম খান', 'করিম (সদস্য)', 'সুমি (সদস্য)']

Update¶

from sqlalchemy import Update

update() থেকে পাওয়া স্টেটমেন্ট। where(), filter(), filter_by() এখানে Select-এর মতোই WHERE বানায়।

উদাহরণ:

result = session.execute(update(User).where(User.name == "করিম").values(name="করিম উদ্দিন"))
print(result.rowcount)   # 1

সব মেথড ও অ্যাট্রিবিউট এক নজরে¶

সদস্য ধরন কাজ
add_cte() মেথড স্টেটমেন্টের সাথে একটি বা একাধিক CTE স্পষ্টভাবে যুক্ত করে, মূল কুয়েরিতে সেটা ব্যবহার না হলেও।
allows_lambda অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এই ধরনের স্টেটমেন্ট lambda_stmt()-এর ভেতরে ব্যবহার করা যায় কি না।
apply_syntax_extension_point() মেথড (২.১-এ নতুন) কাস্টম SQL syntax extension বানানোর সময় extension নিজে এটি ডাকে, স্টেটমেন্টের নির্দিষ্ট জায়গায় (যেমন WHERE-এর পরে) নিজেকে বসাতে।
argument_for() ক্লাস মেথড এই ধরনের কনস্ট্রাক্টে নতুন ডায়ালেক্ট-নির্দিষ্ট keyword argument নিবন্ধন করে (ক্লাস মেথড)।
compare() মেথড দুটি স্টেটমেন্টের গঠন হুবহু একই কি না তুলনা করে।
compile() মেথড স্টেটমেন্টকে SQL স্ট্রিংয়ে কম্পাইল করে।
corresponding_column() মেথড একটি মূল কলাম (যেমন User.__table__.c.id) দিলে এই স্টেটমেন্টের রপ্তানি করা কলামগুলোর মধ্যে সংশ্লিষ্টটি খুঁজে দেয়।
cte() মেথড এই SELECT-কে একটি CTE (WITH নাম AS (...)) বানায়।
description প্রপার্টি ভেতরের একটি বর্ণনামূলক নাম (লগ/ডিবাগিংয়ের জন্য)।
dialect_kwargs প্রপার্টি এই কনস্ট্রাক্টে দেওয়া ডায়ালেক্ট-নির্দিষ্ট অপশন (<ডায়ালেক্ট>_<নাম> আকারে)।
dialect_options প্রপার্টি dialect_kwargs-এর দুই স্তরের রূপ: [ডায়ালেক্ট][অপশন], ডিফল্ট মানসহ।
entity_description প্রপার্টি স্টেটমেন্টটি কোন মডেল/টেবিলের ওপর কাজ করছে তার বিবরণ (dict: name, type, entity, table …)।
entity_namespace প্রপার্টি filter_by()-এর মতো নাম দিয়ে খোঁজার সময় কোন এন্টিটির নাম-ভান্ডার ব্যবহার হবে, তার ভেতরের হুক।
execution_options() মেথড স্টেটমেন্টের সাথে চালানোর সময়ের অপশন যুক্ত করে, যেমন yield_per, populate_existing, synchronize_session।
exported_columns প্রপার্টি DML-এ এটি RETURNING কলামগুলোর সংগ্রহ (returning() না দিলে খালি)।
ext() মেথড (২.১-এ নতুন) ডেটাবেস-নির্দিষ্ট একটি SQL syntax extension যুক্ত করে, যেমন PostgreSQL-এর DISTINCT ON।
filter() মেথড where()-এর আরেক নাম।
filter_by() মেথড কলাম=মান keyword দিয়ে সহজ সমান-শর্ত যোগ করে।
get_children() মেথড এই এক্সপ্রেশন-গাছের সরাসরি "সন্তান" উপাদানগুলো দেয়।
get_dialect_option() মেথড একটি ডায়ালেক্ট-নির্দিষ্ট অপশনের মান দেয়, না থাকলে else_।
get_execution_options() মেথড execution_options() দিয়ে যোগ করা অপশনগুলো দেয়।
inherit_cache অ্যাট্রিবিউট কাস্টম SQL কনস্ট্রাক্ট বানানোর সময় সাবক্লাস বেস ক্লাসের ক্যাশ-key ব্যবস্থা নেবে কি না তার ফ্ল্যাগ।
inline() মেথড Column-এর Python default / onupdate মানগুলো আলাদা করে আগে না চালিয়ে সরাসরি SQL-এর ভেতরে বসায়।
is_clause_element অ্যাট্রিবিউট ভেতরের টাইপ-ফ্ল্যাগ: এটি একটি SQL এক্সপ্রেশন উপাদান (True)।

is_dml অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: INSERT/UPDATE/DELETE কি না (Select-এ False)।
is_from_statement অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: ORM-এর from_statement() থেকে তৈরি কি না।

from sqlalchemy import Delete

delete() থেকে পাওয়া স্টেটমেন্ট। ORM cascade বা event চালায় না; চাইল্ড মুছতে ডেটাবেসের ON DELETE CASCADE বা আগে আলাদা delete লাগবে।

সব মেথড ও অ্যাট্রিবিউট এক নজরে¶

সদস্য ধরন কাজ
add_cte() মেথড স্টেটমেন্টের সাথে একটি বা একাধিক CTE স্পষ্টভাবে যুক্ত করে, মূল কুয়েরিতে সেটা ব্যবহার না হলেও।

text()¶

from sqlalchemy import text

text(text)

ধরন: ফাংশন

নিজে লেখা SQL স্ট্রিং থেকে একটি স্টেটমেন্ট বানায়। প্যারামিটার লিখুন :নাম আকারে আর মান আলাদা দিন, তাহলে SQL injection হয় না। কখনো ইউজারের ইনপুট f-string দিয়ে SQL-এর ভেতরে বসাবেন না।

rows = session.execute(text("SELECT id, name FROM users WHERE id < :n ORDER BY id"), {"n": 3}).all()

add_cte() মেথড স্টেটমেন্টের সাথে একটি বা একাধিক CTE স্পষ্টভাবে যুক্ত করে, মূল কুয়েরিতে সেটা ব্যবহার না হলেও।
alias() মেথড subquery()-এর আরেক নাম: এই SELECT-কে একটি নামযুক্ত সাবকুয়েরি বানায়।
allows_lambda অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এই ধরনের স্টেটমেন্ট lambda_stmt()-এর ভেতরে ব্যবহার করা যায় কি না।
as_scalar() মেথড ১.৪ থেকে বাতিলের পথে।
bindparams() মেথড :নাম প্যারামিটারগুলোর মান বা টাইপ আগেই ঠিক করে দেয়, যাতে চালানোর সময় দিতে না হয়।
compare() মেথড দুটি স্টেটমেন্টের গঠন হুবহু একই কি না তুলনা করে।
compile() মেথড স্টেটমেন্টকে SQL স্ট্রিংয়ে কম্পাইল করে।
corresponding_column() মেথড একটি মূল কলাম (যেমন User.__table__.c.id) দিলে এই স্টেটমেন্টের রপ্তানি করা কলামগুলোর মধ্যে সংশ্লিষ্টটি খুঁজে দেয়।
cte() মেথড এই SELECT-কে একটি CTE (WITH নাম AS (...)) বানায়।
description প্রপার্টি ভেতরের একটি বর্ণনামূলক নাম (লগ/ডিবাগিংয়ের জন্য)।
entity_namespace প্রপার্টি filter_by()-এর মতো নাম দিয়ে খোঁজার সময় কোন এন্টিটির নাম-ভান্ডার ব্যবহার হবে, তার ভেতরের হুক।
execution_options() মেথড স্টেটমেন্টের সাথে চালানোর সময়ের অপশন যুক্ত করে, যেমন yield_per, populate_existing, synchronize_session।
exists() মেথড এই SELECT-কে EXISTS (...) এক্সপ্রেশন বানায়, যা where()-এ শর্ত হিসেবে বা কলাম হিসেবে ব্যবহার করা যায়।
exported_columns প্রপার্টি এই স্টেটমেন্ট যে কলামগুলো "রপ্তানি" করে (বাইরে থেকে পাওয়া যায়) তার সংগ্রহ।
get_children() মেথড এই এক্সপ্রেশন-গাছের সরাসরি "সন্তান" উপাদানগুলো দেয়।
get_execution_options() মেথড execution_options() দিয়ে যোগ করা অপশনগুলো দেয়।
get_label_style() মেথড বর্তমান label style (কলামের নামকরণের নিয়ম) দেয়।
inherit_cache অ্যাট্রিবিউট কাস্টম SQL কনস্ট্রাক্ট বানানোর সময় সাবক্লাস বেস ক্লাসের ক্যাশ-key ব্যবস্থা নেবে কি না তার ফ্ল্যাগ।
into() মেথড (২.১-এ নতুন) এই SELECT-এর ফল দিয়ে নতুন একটি টেবিল বানানোর CREATE TABLE ... AS SELECT ... স্টেটমেন্ট দেয়।
is_clause_element অ্যাট্রিবিউট ভেতরের টাইপ-ফ্ল্যাগ: এটি একটি SQL এক্সপ্রেশন উপাদান (True)।
is_delete অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এটি DELETE স্টেটমেন্ট কি না (Select-এ False)।
is_derived_from() মেথড এই স্টেটমেন্ট একটি নির্দিষ্ট টেবিল/FROM থেকে তৈরি কি না দেখে।
is_dml অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: INSERT/UPDATE/DELETE কি না (Select-এ False)।
is_from_statement অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: ORM-এর from_statement() থেকে তৈরি কি না।
is_insert অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: INSERT কি না।
is_select অ্যাট্রিবিউট এটি SELECT স্টেটমেন্ট হলে True।
is_selectable অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এটি একটি selectable (রো দেয় এমন) কনস্ট্রাক্ট।
is_text অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: text() থেকে তৈরি কি না।
is_update অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: UPDATE কি না।
label() মেথড এই SELECT-কে একটি নাম দেওয়া scalar সাবকুয়েরি বানায়, যাতে বাইরের SELECT-এ কলাম হিসেবে বসানো যায়।
lateral() মেথড LATERAL সাবকুয়েরি বানায়: এটি বাম দিকের টেবিলের কলাম রেফার করতে পারে।
memoized_attribute অ্যাট্রিবিউট ভেতরের ডেকোরেটর (একবার হিসাব করে মনে রাখা প্রপার্টি)।
memoized_instancemethod() ক্লাস মেথড ভেতরের ডেকোরেটর (মেথডের ফল মনে রাখা)।
name_cte_columns অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: CTE বানানোর সময় কলামের নামগুলো WITH নাম(কলাম১, কলাম২) আকারে লেখা হবে কি না (values()-এর মতো কনস্ট্রাক্টে লাগে)।
options() মেথড ORM অপশন যুক্ত করে, যেমন লোডিং অপশন (selectinload, joinedload, load_only)।
params() মেথড bindparam() দিয়ে রাখা নামযুক্ত প্যারামিটারের মান বসিয়ে একটি কপি দেয়।
replace_selectable() মেথড ১.৪ থেকে বাতিলের পথে।
scalar_subquery() মেথড এক রো, এক কলাম দেয় এমন SELECT-কে একটি মান হিসেবে (scalar) ব্যবহারযোগ্য করে, যাতে অন্য SELECT-এর কলামে বা WHERE-এ বসানো যায়।
selectable প্রপার্টি ভেতরের সামঞ্জস্য-প্রপার্টি; নিজেকেই দেয়।
selected_columns প্রপার্টি এই SELECT যে কলামগুলো ফেরত দেবে তার সংগ্রহ।
self_group() মেথড বড় এক্সপ্রেশনে বসানোর সময় প্রয়োজনমতো বন্ধনী (( ... )) দেয়।
set_label_style() মেথড ফলাফলের কলামগুলোর নাম কীভাবে হবে তা ঠিক করে।
stringify_dialect অ্যাট্রিবিউট str(stmt) / print(stmt) করলে কোন ডায়ালেক্টে SQL দেখানো হবে (ডিফল্ট সাধারণ "default")।
subquery() মেথড এই SELECT-কে FROM-এ বসানোর মতো একটি নামযুক্ত সাবকুয়েরি বানায়।
supports_execution অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: এই কনস্ট্রাক্ট সরাসরি execute() করা যায় (True)।
unique_params() মেথড params()-এর মতো, কিন্তু প্যারামিটারগুলোর নাম অনন্য (unique) করে দেয়, যাতে একই স্টেটমেন্টের কয়েকটি কপি এক কুয়েরিতে মেলানো যায়।
uses_inspection অ্যাট্রিবিউট ভেতরের ফ্ল্যাগ: inspect() এই অবজেক্টে কাজ করে কি না।

সংক্ষেপে মনে রাখুন

  • ঢোকানো: insert(Model).values(...) অথবা session.execute(insert(Model), [dict, ...]) (বাল্ক, দ্রুততম)।
  • বদলানো: update(Model).where(...).values(col=Model.col + 1) (atomic)। PK ধরে আলাদা মান: session.execute(update(Model), [{"id": .., ...}])।
