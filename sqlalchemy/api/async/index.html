Async API: সম্পূর্ণ রেফারেন্স¶

এই পেজে যা আছে

  • create_async_engine(), AsyncEngine, AsyncConnection, AsyncTransaction-এর প্রতিটি সদস্য।
  • async_sessionmaker, AsyncSession (FastAPI-তে সবচেয়ে বেশি ব্যবহৃত), AsyncSessionTransaction, AsyncAttrs, async_scoped_session।
  • async ফলাফল: AsyncResult, AsyncScalarResult, AsyncMappingResult, AsyncTupleResult।

async API আসলে sync API-র একটি পাতলা মোড়ক (wrapper)। ভেতরে সেই একই Session / Connection চলে, শুধু যেখানে ডেটাবেসে যেতে হয় সেখানে await লাগে। তাই এখানে অনেক মেথডের ব্যাখ্যা Session API বা Result API পেজের সংশ্লিষ্ট মেথডের সাথে লিংক করা। প্রতিটি মেথডের সিগনেচারের সামনে await দেখলে বুঝবেন সেটি await করতে হবে।

AsyncSession¶

from sqlalchemy.ext.asyncio import AsyncSession

Session-এর async রূপ, আর FastAPI-তে সবচেয়ে বেশি ব্যবহৃত ক্লাস। ভেতরে একটি সাধারণ Session (sync_session) চলে; ডেটাবেসে যেতে হয় এমন প্রতিটি মেথড এখানে coroutine, তাই await লাগে। add(), add_all(), expunge(), new, dirty জাতীয় কাজ, যেগুলো ডেটাবেসে যায় না, সেগুলো await ছাড়াই।

async-এর তিন নিয়ম: expire_on_commit=False, রিলেশনশিপ আগেভাগে লোড (selectinload), আর একটি সেশন একসাথে একাধিক কাজে (asyncio.gather) নয়। বিস্তারিত: MissingGreenlet।

উদাহরণ:

async with SessionLocal() as s:
    s.add(User(name="আসিফ"))
    await s.commit()
    users = (await s.scalars(select(User).options(selectinload(User.addresses)).order_by(User.id))).all()
    print([(u.name, len(u.addresses)) for u in users])

scalar() মেথড (async) একটি স্টেটমেন্ট চালিয়ে প্রথম রো-র প্রথম কলামের মানটি দেয় (না থাকলে None)।

result = await session.stream(select(User.id, User.name).order_by(User.id))
first_two = await result.fetchmany(2)

সদস্য ধরন কাজ

fetchall() মেথড (async) all()-এর পুরোনো নাম (DBAPI ধাঁচ)।
fetchmany() মেথড (async) পরের size-টি রো দেয়।
fetchone() মেথড (async) পরের একটি রো দেয়, শেষ হলে None।
first() মেথড (async) প্রথম রো দেয় (না থাকলে None), আর বাকি সব বাদ দিয়ে Result বন্ধ করে দেয়।
keys() মেথড প্রতিটি রো-র কলামের নামগুলো দেয়।
memoized_attribute অ্যাট্রিবিউট SQLAlchemy-র ভেতরের একটি ডেকোরেটর (একবার হিসাব করে মান মনে রাখা প্রপার্টি)।
memoized_instancemethod() ক্লাস মেথড ভেতরের আরেকটি ডেকোরেটর (মেথডের ফল মনে রাখে)।
one() মেথড (async) ঠিক একটি রো দেয়।
one_or_none() মেথড (async) শূন্য বা একটি রো দেয়: না থাকলে None, একাধিক হলে MultipleResultsFound।
partitions() মেথড (async iterator) রো-গুলোকে size আকারের টুকরোয় ভাগ করে একটি একটি টুকরো দেয়।
unique() মেথড একই রো (বা একই অবজেক্ট) একাধিকবার এলে একবারই রাখে।
yield_per() মেথড ডেটাবেস থেকে একবারে কতগুলো রো আনা হবে তা ঠিক করে (num)।
