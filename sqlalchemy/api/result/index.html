Result ও Row API: সম্পূর্ণ রেফারেন্স¶

এই পেজে যা আছে

  • session.execute() / connection.execute() যা ফেরত দেয়, সেই Result-এর প্রতিটি মেথড।
  • ScalarResult, MappingResult, TupleResult, Row, RowMapping, CursorResult, FrozenResult আর বাকি ফলাফল-ক্লাস।
  • SQLAlchemy 2.1-এর পরিবর্তন: Row এখন সরাসরি tuple-এর মতো, তাই .t / .tuples() বাতিলের পথে।

কুয়েরি চালালে যা ফেরত আসে তা হলো একটি Result। এটা অনেকটা দোকানের রসিদের বাক্সের মতো: সব রসিদ একসাথে নিতে পারেন (.all()), শুধু প্রথমটা (.first()), ঠিক একটা (.one()), বা একটা একটা করে (for row in result)। একবার যা বের করে নিয়েছেন তা আর বাক্সে থাকে না।

কোনটা কখন — এক নজরে

চাই লিখুন পাবেন
সব রো result.all() Row-এর তালিকা
সব অবজেক্ট / একটি কলামের সব মান result.scalars().all() মানের তালিকা
ঠিক একটি রো (না থাকলে বা বেশি হলে এরর) result.one() Row
শূন্য বা একটি result.one_or_none() / result.scalar_one_or_none() Row / মান / None
প্রথমটি, বাকিগুলো বাদ result.first() / result.scalar() Row / মান / None
dict হিসেবে result.mappings().all() RowMapping-এর তালিকা
ডুপ্লিকেট বাদ result.unique() একই ধরনের Result

এই পেজের উদাহরণগুলো Session API পেজের মতোই User / Address মডেল আর তিনজন ইউজার (রহিম, করিম, সুমি) ধরে লেখা, আর PostgreSQL-এ চালিয়ে দেখা হয়েছে।

Result¶

from sqlalchemy.engine import Result

একটি কুয়েরির ফলাফল। প্রতিটি আইটেম একটি Row (টাপলের মতো, নাম দিয়েও পড়া যায়)। Result একটি iterator: প্রতিটি রো একবারই পাওয়া যায়। ORM-এ session.execute() সাধারণত ফলাফল আগেই মেমরিতে এনে রাখে (buffered), তাই কানেকশন আটকে থাকে না।

উদাহরণ:

result = session.execute(select(User.id, User.name).order_by(User.id))
for row in result:
    print(row.id, row.name)       # নাম দিয়ে
# 1 রহিম / 2 করিম / 3 সুমি

সদস্য ধরন কাজ
all() মেথড বাকি থাকা সব রো একটি তালিকায় দেয়, আর Result শেষ করে দেয়।
close() মেথড Result পুরোপুরি বন্ধ করে, ভেতরের cursor ছেড়ে দেয়।
closed প্রপার্টি close() দিয়ে বন্ধ করা হলে True।
columns() মেথড প্রতিটি রো-তে কোন কলাম কোন ক্রমে থাকবে তা নতুন করে ঠিক করে, নাম বা অবস্থান (index) দিয়ে।
fetchall() মেথড all()-এর পুরোনো নাম (DBAPI ধাঁচ)।
fetchmany() মেথড পরের size-টি রো দেয়।
fetchone() মেথড পরের একটি রো দেয়, শেষ হলে None।
first() মেথড প্রথম রো দেয় (না থাকলে None), আর বাকি সব বাদ দিয়ে Result বন্ধ করে দেয়।
freeze() মেথড ফলাফলের একটি "জমানো" কপি (FrozenResult) বানায়, যেটা ডেকে যতবার খুশি নতুন Result পাওয়া যায়।
keys() মেথড প্রতিটি রো-র কলামের নামগুলো দেয়।
mappings() মেথড রো-গুলোকে dict-এর মতো RowMapping হিসেবে দেওয়ার জন্য একটি MappingResult দেয়।
memoized_attribute অ্যাট্রিবিউট (internal) SQLAlchemy-র ভেতরের একটি ডেকোরেটর (একবার হিসাব করে মান মনে রাখা প্রপার্টি)।
memoized_instancemethod() ক্লাস মেথড (internal) ভেতরের আরেকটি ডেকোরেটর (মেথডের ফল মনে রাখে)।
merge() মেথড একই কলামের কয়েকটি Result জুড়ে একটি Result বানায়, প্রথমটির রো শেষ হলে পরেরটির রো আসে।
one() মেথড ঠিক একটি রো দেয়।
one_or_none() মেথড শূন্য বা একটি রো দেয়: না থাকলে None, একাধিক হলে MultipleResultsFound।
partitions() মেথড রো-গুলোকে size আকারের টুকরোয় ভাগ করে একটি একটি টুকরো দেয়।
scalar() মেথড প্রথম রো-র প্রথম কলামের মান দেয় (না থাকলে None) আর Result বন্ধ করে।
scalar_one() মেথড ঠিক একটি রো-র প্রথম কলাম দেয়।
scalar_one_or_none() মেথড শূন্য বা একটি রো-র প্রথম কলাম: না থাকলে None, একাধিক হলে এরর।
scalars() মেথড প্রতিটি রো থেকে শুধু একটি কলাম (ডিফল্টে প্রথমটি) নিয়ে ScalarResult দেয়।
t প্রপার্টি ⚠️ deprecated টাইপ চেকারের জন্য রো-গুলোকে "typed tuple" হিসেবে চিহ্নিত করার পুরোনো উপায়।
tuples() মেথড ⚠️ deprecated t-এর মেথড রূপ; একইভাবে ২.১-এ বাতিলের পথে।
unique() মেথড একই রো (বা একই অবজেক্ট) একাধিকবার এলে একবারই রাখে।
yield_per() মেথড ডেটাবেস থেকে একবারে কতগুলো রো আনা হবে তা ঠিক করে (num)।

ভবিষ্যতের কোনো ভার্সনে এটি সরিয়ে ফেলা হবে। নতুন কোডে ব্যবহার করবেন না; বিকল্প নিচে বলা আছে।

টাইপ চেকারের জন্য রো-গুলোকে "typed tuple" হিসেবে চিহ্নিত করার পুরোনো উপায়। ২.১-এ বাতিলের পথে, কারণ Row এখন নিজেই tuple-এর মতো আচরণ করে আর টাইপসহ unpack করা যায়। সরাসরি for id_, name in result: লিখুন।

উদাহরণ:

for id_, name in session.execute(select(User.id, User.name).order_by(User.id)):
    print(id_, name)

Result.yield_per()¶

Result.yield_per(num)

ধরন: মেথড

result = session.execute(select(User.id).order_by(User.id)).yield_per(2)

ScalarResult¶

from sqlalchemy.engine import ScalarResult

Result-এর একটি মোড়ক, যেখানে প্রতিটি আইটেম একটি Row নয়, একটি একক মান (সাধারণত একটি ORM অবজেক্ট)। session.scalars() বা result.scalars() এটি দেয়।

users = session.scalars(select(User).order_by(User.id))

RowMapping¶

from sqlalchemy.engine import RowMapping

one() মেথড ঠিক একটি রো দেয়।
one_or_none() মেথড শূন্য বা একটি রো দেয়: না থাকলে None, একাধিক হলে MultipleResultsFound।
partitions() মেথড রো-গুলোকে size আকারের টুকরোয় ভাগ করে একটি একটি টুকরো দেয়।
postfetch_cols() মেথড যেসব কলামের মান ডেটাবেসে তৈরি হয়েছে আর পরে আলাদা করে আনতে হবে (server default/onupdate), সেগুলোর তালিকা।
prefetch_cols() মেথড যেসব কলামের মান SQL চালানোর আগেই Python-এ হিসাব করা হয়েছে (Python-side default), সেগুলোর তালিকা।
returned_defaults প্রপার্টি .return_defaults() দেওয়া insert/update-এর পর ডেটাবেস যে default মানগুলো ফেরত দিয়েছে, একটি Row হিসেবে।

rowcount প্রপার্টি UPDATE বা DELETE কয়টি রো-তে মিলেছে (match) তার সংখ্যা।
scalar() মেথড প্রথম রো-র প্রথম কলামের মান দেয় (না থাকলে None) আর Result বন্ধ করে।
scalar_one() মেথড ঠিক একটি রো-র প্রথম কলাম দেয়।
scalar_one_or_none() মেথড শূন্য বা একটি রো-র প্রথম কলাম: না থাকলে None, একাধিক হলে এরর।
scalars() মেথড প্রতিটি রো থেকে শুধু একটি কলাম (ডিফল্টে প্রথমটি) নিয়ে ScalarResult দেয়।
splice_horizontally() মেথড দুটি CursorResult-এর রো পাশাপাশি জোড়া দেয় (প্রথমটির কলাম + দ্বিতীয়টির কলাম)।
splice_vertically() মেথড দুটি CursorResult-এর রো ওপর-নিচে জোড়া দেয় (প্রথমটির রো, তারপর দ্বিতীয়টির)।
supports_sane_multi_rowcount() মেথড ড্রাইভার executemany-তেও সঠিক rowcount দিতে পারে কি না।
supports_sane_rowcount() মেথড ড্রাইভার সাধারণ UPDATE/DELETE-এ সঠিক rowcount দিতে পারে কি না।

tuples() মেথড t-এর মেথড রূপ; একইভাবে ২.১-এ বাতিলের পথে।

yield_per() মেথড ডেটাবেস থেকে একবারে কতগুলো রো আনা হবে তা ঠিক করে (num)।

FrozenResult¶

from sqlalchemy.engine import FrozenResult

Result.freeze() থেকে পাওয়া "জমানো" ফলাফল। অবজেক্টটিকে ফাংশনের মতো ডাকলে (frozen()) প্রতিবার একই রো-সহ একটি নতুন Result দেয়। ফলাফল ক্যাশ করতে (যেমন dogpile cache) ব্যবহৃত হয়।

উদাহরণ:

frozen = session.execute(select(User.id, User.name).order_by(User.id)).freeze()
print(frozen().all() == frozen().all())   # True

FrozenResult.with_new_rows(tuple_data)

fetchall() মেথড all()-এর পুরোনো নাম (DBAPI ধাঁচ)।

merge() মেথড একই কলামের কয়েকটি Result জুড়ে একটি Result বানায়, প্রথমটির রো শেষ হলে পরেরটির রো আসে।
one() মেথড ঠিক একটি রো দেয়।
one_or_none() মেথড শূন্য বা একটি রো দেয়: না থাকলে None, একাধিক হলে MultipleResultsFound।
partitions() মেথড রো-গুলোকে size আকারের টুকরোয় ভাগ করে একটি একটি টুকরো দেয়।
scalar() মেথড প্রথম রো-র প্রথম কলামের মান দেয় (না থাকলে None) আর Result বন্ধ করে।

yield_per() মেথড ডেটাবেস থেকে একবারে কতগুলো রো আনা হবে তা ঠিক করে (num)।

সব মেথড ও অ্যাট্রিবিউট এক নজরে¶

সদস্য ধরন কাজ
all() মেথড বাকি থাকা সব রো একটি তালিকায় দেয়, আর Result শেষ করে দেয়।
close() মেথড Result পুরোপুরি বন্ধ করে, ভেতরের cursor ছেড়ে দেয়।
closed অ্যাট্রিবিউট close() দিয়ে বন্ধ করা হলে True।
columns() মেথড প্রতিটি রো-তে কোন কলাম কোন ক্রমে থাকবে তা নতুন করে ঠিক করে, নাম বা অবস্থান (index) দিয়ে।
fetchall() মেথড all()-এর পুরোনো নাম (DBAPI ধাঁচ)।
fetchmany() মেথড পরের size-টি রো দেয়।
fetchone() মেথড পরের একটি রো দেয়, শেষ হলে None।
first() মেথড প্রথম রো দেয় (না থাকলে None), আর বাকি সব বাদ দিয়ে Result বন্ধ করে দেয়।
freeze() মেথড ফলাফলের একটি "জমানো" কপি (FrozenResult) বানায়, যেটা ডেকে যতবার খুশি নতুন Result পাওয়া যায়।
keys() মেথড প্রতিটি রো-র কলামের নামগুলো দেয়।
mappings() মেথড রো-গুলোকে dict-এর মতো RowMapping হিসেবে দেওয়ার জন্য একটি MappingResult দেয়।
memoized_attribute অ্যাট্রিবিউট SQLAlchemy-র ভেতরের একটি ডেকোরেটর (একবার হিসাব করে মান মনে রাখা প্রপার্টি)।
memoized_instancemethod() ক্লাস মেথড ভেতরের আরেকটি ডেকোরেটর (মেথডের ফল মনে রাখে)।
merge() মেথড একই কলামের কয়েকটি Result জুড়ে একটি Result বানায়, প্রথমটির রো শেষ হলে পরেরটির রো আসে।
one() মেথড ঠিক একটি রো দেয়।
one_or_none() মেথড শূন্য বা একটি রো দেয়: না থাকলে None, একাধিক হলে MultipleResultsFound।
partitions() মেথড রো-গুলোকে size আকারের টুকরোয় ভাগ করে একটি একটি টুকরো দেয়।
scalar() মেথড প্রথম রো-র প্রথম কলামের মান দেয় (না থাকলে None) আর Result বন্ধ করে।
scalar_one() মেথড ঠিক একটি রো-র প্রথম কলাম দেয়।
scalar_one_or_none() মেথড শূন্য বা একটি রো-র প্রথম কলাম: না থাকলে None, একাধিক হলে এরর।
scalars() মেথড প্রতিটি রো থেকে শুধু একটি কলাম (ডিফল্টে প্রথমটি) নিয়ে ScalarResult দেয়।
t প্রপার্টি টাইপ চেকারের জন্য রো-গুলোকে "typed tuple" হিসেবে চিহ্নিত করার পুরোনো উপায়।
tuples() মেথড t-এর মেথড রূপ; একইভাবে ২.১-এ বাতিলের পথে।
unique() মেথড একই রো (বা একই অবজেক্ট) একাধিকবার এলে একবারই রাখে।
yield_per() মেথড ডেটাবেস থেকে একবারে কতগুলো রো আনা হবে তা ঠিক করে (num)।
