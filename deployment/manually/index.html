ASGI সার্ভার¶

চলুন বিস্তারিত একটু গভীরে যাই।

FastAPI Python ওয়েব ফ্রেমওয়ার্ক ও সার্ভার তৈরির একটি স্ট্যান্ডার্ড ব্যবহার করে, যার নাম ASGI। FastAPI একটি ASGI ওয়েব ফ্রেমওয়ার্ক।

একটি রিমোট সার্ভার মেশিনে একটি FastAPI অ্যাপ্লিকেশন (বা অন্য যেকোনো ASGI অ্যাপ্লিকেশন) চালাতে আপনার প্রধানত যা দরকার তা হলো Uvicorn-এর মতো একটি ASGI সার্ভার প্রোগ্রাম, এটিই fastapi কমান্ডে ডিফল্টভাবে আসে।

বেশ কয়েকটি বিকল্প আছে, যার মধ্যে আছে:

  • Uvicorn: একটি উচ্চ পারফরম্যান্সের ASGI সার্ভার।
  • Hypercorn: অন্যান্য ফিচারের পাশাপাশি HTTP/2 ও Trio-র সাথে সামঞ্জস্যপূর্ণ একটি ASGI সার্ভার।
  • Daphne: Django Channels-এর জন্য তৈরি ASGI সার্ভার।
  • Granian: Python অ্যাপ্লিকেশনের জন্য একটি Rust HTTP সার্ভার।

সার্ভার মেশিন ও সার্ভার প্রোগ্রাম¶

নামের ব্যাপারে মনে রাখার মতো একটি ছোট বিষয় আছে। 💡

"সার্ভার" শব্দটি সাধারণত রিমোট/ক্লাউড কম্পিউটার (ফিজিক্যাল বা ভার্চুয়াল মেশিন) এবং ওই মেশিনে চলমান প্রোগ্রাম (যেমন Uvicorn) দুটোকেই বোঝাতে ব্যবহার হয়।

শুধু মনে রাখবেন, সাধারণভাবে "সার্ভার" পড়লে এটি ওই দুটির যেকোনো একটিকে বোঝাতে পারে।

রিমোট মেশিনকে বোঝাতে একে সার্ভার বলা প্রচলিত, তবে মেশিন, VM (ভার্চুয়াল মেশিন), নোড-ও বলা হয়। এগুলো সবই কোনো ধরনের রিমোট মেশিনকে বোঝায়, যা সাধারণত Linux চালায়, যেখানে আপনি প্রোগ্রাম চালান।

সার্ভার প্রোগ্রাম ইনস্টল করুন¶

আপনি যখন FastAPI ইনস্টল করেন, তখন এর সাথে একটি প্রোডাকশন সার্ভার Uvicorn আসে, এবং আপনি fastapi run কমান্ড দিয়ে এটি চালু করতে পারেন।

তবে আপনি ম্যানুয়ালি একটি ASGI সার্ভারও ইনস্টল করতে পারেন।

আপনার প্রজেক্টে সার্ভার অ্যাপ্লিকেশনটি যোগ করুন।

যেমন, Uvicorn ইনস্টল করতে:

$ uv add "uvicorn[standard]"

---> 100%

অন্য যেকোনো ASGI সার্ভার প্রোগ্রামের ক্ষেত্রেও একই রকম প্রক্রিয়া প্রযোজ্য।

পরামর্শ

standard যোগ করলে Uvicorn কিছু প্রস্তাবিত অতিরিক্ত ডিপেন্ডেন্সি ইনস্টল ও ব্যবহার করবে।

এর মধ্যে আছে uvloop, asyncio-এর উচ্চ পারফরম্যান্সের হুবহু বিকল্প, যা কনকারেন্সি পারফরম্যান্সে বড় উন্নতি দেয়।

আপনি যখন uv add "fastapi[standard]"-এর মতো কিছু দিয়ে FastAPI যোগ করেন, তখন আপনি ইতিমধ্যে uvicorn[standard]-ও পেয়ে যান।

সার্ভার প্রোগ্রাম চালান¶

আপনি যদি ম্যানুয়ালি একটি ASGI সার্ভার ইনস্টল করে থাকেন, তাহলে আপনার FastAPI অ্যাপ্লিকেশন ইম্পোর্ট করার জন্য সাধারণত এটিকে একটি বিশেষ ফরম্যাটে একটি ইম্পোর্ট স্ট্রিং দিতে হবে:

$ uv run uvicorn main:app --host 0.0.0.0 --port 80

<span style="color: green;">INFO</span>:     Uvicorn running on http://0.0.0.0:80 (Press CTRL+C to quit)

নোট

uvicorn main:app কমান্ডটি বোঝায়:

  • main: main.py ফাইল (Python "মডিউল")।
  • app: main.py-এর ভেতরে app = FastAPI() লাইন দিয়ে তৈরি অবজেক্ট।

এটি এর সমতুল্য:

from main import app

প্রতিটি বিকল্প ASGI সার্ভার প্রোগ্রামের একই রকম কমান্ড থাকবে, তাদের নিজ নিজ ডকুমেন্টেশনে আরও পড়তে পারেন।

সতর্কতা

Uvicorn ও অন্যান্য সার্ভার একটি --reload অপশন সাপোর্ট করে যা ডেভেলপমেন্টের সময় কাজের।

--reload অপশন অনেক বেশি রিসোর্স খরচ করে, বেশি অস্থিতিশীল, ইত্যাদি।

এটি ডেভেলপমেন্টের সময় অনেক সাহায্য করে, কিন্তু প্রোডাকশনে এটি ব্যবহার করা উচিত নয়।

ডিপ্লয়মেন্টের ধারণাসমূহ¶

এই উদাহরণগুলো সার্ভার প্রোগ্রাম (যেমন Uvicorn) চালায়, একটিমাত্র প্রসেস শুরু করে, একটি পূর্বনির্ধারিত পোর্টে (যেমন 80) সব IP-তে (0.0.0.0) শুনে।

এটিই মূল ধারণা। তবে আপনি সম্ভবত কিছু অতিরিক্ত বিষয়ের দিকে খেয়াল রাখতে চাইবেন, যেমন:

  • সিকিউরিটি - HTTPS
  • startup-এ চালু হওয়া
  • রিস্টার্ট
  • রেপ্লিকেশন (চলমান প্রসেসের সংখ্যা)
  • মেমরি
  • শুরুর আগের ধাপগুলো

পরের অধ্যায়গুলোতে আমি আপনাকে এই প্রতিটি ধারণা সম্পর্কে, সেগুলো নিয়ে কীভাবে ভাববেন, এবং সেগুলো সামলানোর কৌশলসহ কিছু বাস্তব উদাহরণ সম্পর্কে আরও বলব। 🚀
