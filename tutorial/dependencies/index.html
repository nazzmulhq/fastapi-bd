ডিপেন্ডেন্সি¶

🌐 AI এবং মানুষের যৌথ অনুবাদ

এই অনুবাদটি মানুষের নির্দেশনায় AI দিয়ে করা হয়েছে। 🤝

এতে মূল অর্থ ভুল বোঝা বা অস্বাভাবিক শোনানোর মতো ভুল থাকতে পারে। 🤖

ইংরেজি সংস্করণ

FastAPI-তে একটি খুবই শক্তিশালী অথচ সহজবোধ্য ডিপেন্ডেন্সি ইনজেকশন সিস্টেম আছে।

এটি এমনভাবে ডিজাইন করা যাতে ব্যবহার করা খুবই সহজ হয়, এবং যেকোনো ডেভেলপারের জন্য FastAPI-এর সাথে অন্যান্য কম্পোনেন্ট যুক্ত করা খুবই সহজ হয়।

"ডিপেন্ডেন্সি ইনজেকশন" কী¶

প্রোগ্রামিংয়ে "ডিপেন্ডেন্সি ইনজেকশন" মানে হলো, আপনার কোডের (এক্ষেত্রে আপনার পাথ অপারেশন ফাংশনগুলোর) কাজ করতে ও ব্যবহার করতে যা যা প্রয়োজন, অর্থাৎ "ডিপেন্ডেন্সি", তা ঘোষণা করার একটি উপায় আছে।

তারপর সেই সিস্টেম (এক্ষেত্রে FastAPI) আপনার কোডকে ওই প্রয়োজনীয় ডিপেন্ডেন্সিগুলো দিতে যা যা করা দরকার তা করার দায়িত্ব নেবে (ডিপেন্ডেন্সিগুলো "ইনজেক্ট" করবে)।

এটি খুবই কাজের যখন আপনার দরকার:

  • শেয়ার করা লজিক রাখা (একই কোড লজিক বারবার)।
  • ডেটাবেস কানেকশন শেয়ার করা।
  • সিকিউরিটি, অথেনটিকেশন, রোলের শর্ত ইত্যাদি প্রয়োগ করা।
  • আর আরও অনেক কিছু...

এর সবকিছুই, কোডের পুনরাবৃত্তি যথাসম্ভব কমিয়ে।

প্রথম ধাপ¶

চলুন একটি খুবই সহজ উদাহরণ দেখি। এটি এতই সহজ হবে যে আপাতত খুব একটা কাজের নয়।

তবে এভাবে আমরা ডিপেন্ডেন্সি ইনজেকশন সিস্টেম কীভাবে কাজ করে তাতে মনোযোগ দিতে পারব।

একটি ডিপেন্ডেন্সি, বা "dependable" তৈরি করুন¶

প্রথমে ডিপেন্ডেন্সিতে মনোযোগ দেওয়া যাক।

এটি শুধু একটি ফাংশন যা একটি পাথ অপারেশন ফাংশন যে সব প্যারামিটার নিতে পারে সেগুলোর সবই নিতে পারে:

from typing import Annotated

from fastapi import Depends, FastAPI

app = FastAPI()


async def common_parameters(q: str | None = None, skip: int = 0, limit: int = 100):
    return {"q": q, "skip": skip, "limit": limit}


@app.get("/items/")
async def read_items(commons: Annotated[dict, Depends(common_parameters)]):
    return commons


@app.get("/users/")
async def read_users(commons: Annotated[dict, Depends(common_parameters)]):
    return commons
🤓 Other versions and variants

Tip

Prefer to use the Annotated version if possible.

from fastapi import Depends, FastAPI

app = FastAPI()


async def common_parameters(q: str | None = None, skip: int = 0, limit: int = 100):
    return {"q": q, "skip": skip, "limit": limit}


@app.get("/items/")
async def read_items(commons: dict = Depends(common_parameters)):
    return commons


@app.get("/users/")
async def read_users(commons: dict = Depends(common_parameters)):
    return commons

ব্যস।

২ লাইন।

আর এর আকৃতি ও গঠন আপনার সব পাথ অপারেশন ফাংশনের মতোই।

আপনি এটিকে "ডেকোরেটর" ছাড়া (@app.get("/some-path") ছাড়া) একটি পাথ অপারেশন ফাংশন হিসেবে ভাবতে পারেন।

আর এটি আপনার ইচ্ছেমতো যেকোনো কিছু রিটার্ন করতে পারে।

এক্ষেত্রে এই ডিপেন্ডেন্সিটি আশা করে:

  • একটি ঐচ্ছিক কুয়েরি প্যারামিটার q, যা একটি str।
  • একটি ঐচ্ছিক কুয়েরি প্যারামিটার skip, যা একটি int, এবং ডিফল্টভাবে 0।
  • একটি ঐচ্ছিক কুয়েরি প্যারামিটার limit, যা একটি int, এবং ডিফল্টভাবে 100।

আর তারপর এটি শুধু ওই ভ্যালুগুলো ধারণকারী একটি dict রিটার্ন করে।

নোট

FastAPI ভার্সন 0.95.0-এ Annotated-এর সাপোর্ট যোগ করেছে (এবং এটি ব্যবহারের পরামর্শ দেওয়া শুরু করেছে)।

আপনার কাছে পুরোনো ভার্সন থাকলে Annotated ব্যবহার করতে গেলে এরর পাবেন।

Annotated ব্যবহারের আগে অবশ্যই FastAPI ভার্সন আপগ্রেড করুন, অন্তত 0.95.1-এ।

from typing import Annotated

"dependant"-এ ডিপেন্ডেন্সিটি ঘোষণা করুন¶

আপনার পাথ অপারেশন ফাংশনের প্যারামিটারে যেভাবে Body, Query ইত্যাদি ব্যবহার করেন, সেভাবেই একটি নতুন প্যারামিটারের সাথে Depends ব্যবহার করুন:

যদিও আপনার ফাংশনের প্যারামিটারে আপনি Body, Query ইত্যাদির মতোই Depends ব্যবহার করেন, Depends একটু ভিন্নভাবে কাজ করে।

Depends-কে আপনি কেবল একটিমাত্র প্যারামিটার দেন।

এই প্যারামিটারটি অবশ্যই একটি ফাংশনের মতো কিছু হতে হবে।

আপনি এটি সরাসরি কল করেন না (শেষে বন্ধনী যোগ করেন না), শুধু Depends()-এ প্যারামিটার হিসেবে দেন।

আর ওই ফাংশনটি পাথ অপারেশন ফাংশনের মতোই প্যারামিটার নেয়।

পরামর্শ

ফাংশন ছাড়া আর কোন কোন "জিনিস" ডিপেন্ডেন্সি হিসেবে ব্যবহার করা যায় তা পরের অধ্যায়ে দেখবেন।

যখনই একটি নতুন রিকোয়েস্ট আসে, FastAPI এই দায়িত্বগুলো নেবে:

  • সঠিক প্যারামিটার দিয়ে আপনার ডিপেন্ডেন্সি ("dependable") ফাংশনটি কল করা।
  • আপনার ফাংশন থেকে ফলাফল নেওয়া।
  • সেই ফলাফলটি আপনার পাথ অপারেশন ফাংশনের প্যারামিটারে অ্যাসাইন করা।

এভাবে আপনি শেয়ার করা কোড একবার লেখেন, আর আপনার পাথ অপারেশনগুলোর জন্য সেটি কল করার দায়িত্ব নেয় FastAPI।

পরামর্শ

লক্ষ করুন, আপনাকে কোনো বিশেষ ক্লাস তৈরি করে FastAPI-এর কোথাও দিয়ে সেটি "রেজিস্টার" করতে বা এরকম কিছু করতে হয় না।

আপনি শুধু এটি Depends-এ দেন, আর FastAPI জানে বাকিটা কীভাবে করতে হয়।

Annotated ডিপেন্ডেন্সি শেয়ার করুন¶

ওপরের উদাহরণগুলোতে আপনি দেখছেন যে একটু কোডের পুনরাবৃত্তি আছে।

যখন আপনাকে common_parameters() ডিপেন্ডেন্সিটি ব্যবহার করতে হয়, তখন টাইপ অ্যানোটেশন ও Depends()-সহ পুরো প্যারামিটারটি লিখতে হয়:

commons: Annotated[dict, Depends(common_parameters)]

কিন্তু যেহেতু আমরা Annotated ব্যবহার করছি, তাই আমরা ওই Annotated ভ্যালুটি একটি ভেরিয়েবলে রেখে একাধিক জায়গায় ব্যবহার করতে পারি:

from typing import Annotated

from fastapi import Depends, FastAPI

app = FastAPI()


async def common_parameters(q: str | None = None, skip: int = 0, limit: int = 100):
    return {"q": q, "skip": skip, "limit": limit}


CommonsDep = Annotated[dict, Depends(common_parameters)]


@app.get("/items/")
async def read_items(commons: CommonsDep):
    return commons


@app.get("/users/")
async def read_users(commons: CommonsDep):
    return commons

পরামর্শ

এটি শুধুই স্ট্যান্ডার্ড Python, একে বলা হয় "type alias", এটি আসলে FastAPI-এর নিজস্ব কিছু নয়।

তবে যেহেতু FastAPI Annotated-সহ Python স্ট্যান্ডার্ডগুলোর ওপর ভিত্তি করে তৈরি, তাই আপনি আপনার কোডে এই কৌশলটি ব্যবহার করতে পারেন। 😎

ডিপেন্ডেন্সিগুলো প্রত্যাশামতোই কাজ করে যাবে, আর সবচেয়ে ভালো দিক হলো টাইপের তথ্য অক্ষুণ্ণ থাকবে, অর্থাৎ আপনার এডিটর আপনাকে অটোকমপ্লিশন, ইনলাইন এরর ইত্যাদি দিয়ে যেতে পারবে। mypy-এর মতো অন্যান্য টুলের ক্ষেত্রেও তাই।

এটি বিশেষভাবে কাজে আসবে যখন আপনি এটি একটি বড় কোডবেসে ব্যবহার করবেন, যেখানে অনেক পাথ অপারেশনে বারবার একই ডিপেন্ডেন্সি ব্যবহার করেন।

async হবে নাকি হবে না¶

যেহেতু ডিপেন্ডেন্সিগুলোও FastAPI কল করবে (আপনার পাথ অপারেশন ফাংশনগুলোর মতোই), তাই আপনার ফাংশনগুলো সংজ্ঞায়িত করার সময় একই নিয়ম প্রযোজ্য।

আপনি async def বা সাধারণ def ব্যবহার করতে পারেন।

আর আপনি সাধারণ def পাথ অপারেশন ফাংশনের ভেতরে async def দিয়ে ডিপেন্ডেন্সি, বা async def পাথ অপারেশন ফাংশনের ভেতরে def ডিপেন্ডেন্সি ইত্যাদি ঘোষণা করতে পারেন।

এতে কিছু যায় আসে না। FastAPI জানবে কী করতে হবে।

নোট

আপনি যদি না জানেন, তাহলে ডকুমেন্টেশনে async ও await সম্পর্কে Async: "তাড়াহুড়োয় আছেন?" অংশটি দেখুন।

OpenAPI-এর সাথে যুক্ত¶

আপনার ডিপেন্ডেন্সিগুলোর (এবং সাব-ডিপেন্ডেন্সিগুলোর) সব রিকোয়েস্ট ঘোষণা, ভ্যালিডেশন ও প্রয়োজনীয়তা একই OpenAPI স্কিমায় যুক্ত হবে।

তাই ইন্টারঅ্যাকটিভ ডকুমেন্টেশনেও এই ডিপেন্ডেন্সিগুলোর সব তথ্য থাকবে:

সহজ ব্যবহার¶

খেয়াল করলে দেখবেন, পাথ অপারেশন ফাংশনগুলো ঘোষণা করা হয় যাতে যখনই কোনো পাথ ও অপারেশন মেলে তখন সেগুলো ব্যবহার হয়, আর তারপর FastAPI রিকোয়েস্ট থেকে ডেটা বের করে সঠিক প্যারামিটার দিয়ে ফাংশনটি কল করার দায়িত্ব নেয়।

আসলে সব (বা বেশিরভাগ) ওয়েব ফ্রেমওয়ার্কই এভাবে কাজ করে।

আপনি কখনো ওই ফাংশনগুলো সরাসরি কল করেন না। সেগুলো কল করে আপনার ফ্রেমওয়ার্ক (এক্ষেত্রে FastAPI)।

ডিপেন্ডেন্সি ইনজেকশন সিস্টেম দিয়ে আপনি FastAPI-কে এটাও জানাতে পারেন যে আপনার পাথ অপারেশন ফাংশন অন্য কিছুর ওপরও "নির্ভর করে" যা আপনার পাথ অপারেশন ফাংশনের আগে চালানো উচিত, আর FastAPI সেটি চালানো এবং ফলাফল "ইনজেক্ট" করার দায়িত্ব নেবে।

"ডিপেন্ডেন্সি ইনজেকশন"-এর এই একই ধারণার অন্যান্য প্রচলিত নাম হলো:

  • রিসোর্স
  • প্রোভাইডার
  • সার্ভিস
  • ইনজেক্টেবল
  • কম্পোনেন্ট

FastAPI প্লাগ-ইন¶

ডিপেন্ডেন্সি ইনজেকশন সিস্টেম ব্যবহার করে ইন্টিগ্রেশন ও "প্লাগ-ইন" তৈরি করা যায়। তবে আসলে "প্লাগ-ইন" তৈরির কোনো প্রয়োজনই নেই, কারণ ডিপেন্ডেন্সি ব্যবহার করে অসংখ্য ইন্টিগ্রেশন ও ইন্টারঅ্যাকশন ঘোষণা করা সম্ভব, যা আপনার পাথ অপারেশন ফাংশনগুলোর জন্য উপলব্ধ হয়ে যায়।

আর ডিপেন্ডেন্সি এমন খুবই সহজ ও সহজবোধ্য উপায়ে তৈরি করা যায় যে আপনি শুধু প্রয়োজনীয় Python প্যাকেজগুলো ইম্পোর্ট করে আক্ষরিক অর্থেই কয়েক লাইনের কোডে সেগুলো আপনার API ফাংশনগুলোর সাথে যুক্ত করতে পারেন।

পরের অধ্যায়গুলোতে রিলেশনাল ও NoSQL ডেটাবেস, সিকিউরিটি ইত্যাদি সম্পর্কে এর উদাহরণ দেখবেন।

FastAPI সামঞ্জস্য¶

ডিপেন্ডেন্সি ইনজেকশন সিস্টেমের সরলতা FastAPI-কে সামঞ্জস্যপূর্ণ করে তোলে:

  • সব রিলেশনাল ডেটাবেসের সাথে
  • NoSQL ডেটাবেসের সাথে
  • বাহ্যিক প্যাকেজের সাথে
  • বাহ্যিক API-এর সাথে
  • অথেনটিকেশন ও অথরাইজেশন সিস্টেমের সাথে
  • API ব্যবহার পর্যবেক্ষণ সিস্টেমের সাথে
  • রেসপন্স ডেটা ইনজেকশন সিস্টেমের সাথে
  • ইত্যাদি।

সহজ ও শক্তিশালী¶

হায়ারার্কিক্যাল ডিপেন্ডেন্সি ইনজেকশন সিস্টেমটি সংজ্ঞায়িত ও ব্যবহার করা খুবই সহজ হলেও এটি খুবই শক্তিশালী।

আপনি এমন ডিপেন্ডেন্সি সংজ্ঞায়িত করতে পারেন যেগুলো নিজেরাই আবার ডিপেন্ডেন্সি সংজ্ঞায়িত করতে পারে।

শেষ পর্যন্ত ডিপেন্ডেন্সির একটি হায়ারার্কিক্যাল ট্রি তৈরি হয়, আর ডিপেন্ডেন্সি ইনজেকশন সিস্টেম আপনার হয়ে এই সব ডিপেন্ডেন্সি (এবং সেগুলোর সাব-ডিপেন্ডেন্সি) সমাধান করার এবং প্রতিটি ধাপে ফলাফল সরবরাহ (ইনজেক্ট) করার দায়িত্ব নেয়।

যেমন, ধরা যাক আপনার ৪টি API এন্ডপয়েন্ট (পাথ অপারেশন) আছে:

  • /items/public/
  • /items/private/
  • /users/{user_id}/activate
  • /items/pro/

তাহলে শুধু ডিপেন্ডেন্সি ও সাব-ডিপেন্ডেন্সি দিয়েই আপনি এগুলোর প্রতিটির জন্য আলাদা অনুমতির শর্ত যোগ করতে পারেন:

OpenAPI-এর সাথে যুক্ত¶

এই সব ডিপেন্ডেন্সি তাদের প্রয়োজনীয়তা ঘোষণা করার পাশাপাশি আপনার পাথ অপারেশনগুলোতে প্যারামিটার, ভ্যালিডেশন ইত্যাদিও যোগ করে।

FastAPI এর সবকিছু OpenAPI স্কিমায় যোগ করার দায়িত্ব নেবে, যাতে তা ইন্টারঅ্যাকটিভ ডকুমেন্টেশন সিস্টেমগুলোতে দেখানো হয়।
