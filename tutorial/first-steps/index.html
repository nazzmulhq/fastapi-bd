প্রথম ধাপ¶

🌐 AI এবং মানুষের যৌথ অনুবাদ

এই অনুবাদটি মানুষের নির্দেশনায় AI দিয়ে করা হয়েছে। 🤝

এতে মূল অর্থ ভুল বোঝা বা অস্বাভাবিক শোনানোর মতো ভুল থাকতে পারে। 🤖

ইংরেজি সংস্করণ

সবচেয়ে সহজ FastAPI ফাইলটি দেখতে এরকম হতে পারে:

from fastapi import FastAPI

app = FastAPI()


@app.get("/")
async def root():
    return {"message": "Hello World"}

এটি main.py নামের একটি ফাইলে কপি করুন।

পরামর্শ

FastAPI-এর একটি VS Code-এর জন্য অফিসিয়াল এক্সটেনশন (এবং Cursor-এর জন্যও) আছে, যা অনেক ফিচার দেয়, যেমন পাথ অপারেশন এক্সপ্লোরার, পাথ অপারেশন সার্চ, টেস্টে CodeLens নেভিগেশন (টেস্ট থেকে সংজ্ঞায় চলে যাওয়া), এবং FastAPI Cloud ডিপ্লয়মেন্ট ও লগ, সবকিছুই আপনার এডিটর থেকে।

ইন্টারঅ্যাকটিভ API ডকুমেন্টেশন¶

এবার http://127.0.0.1:8000/docs-এ যান।

আপনি স্বয়ংক্রিয় ইন্টারঅ্যাকটিভ API ডকুমেন্টেশন দেখতে পাবেন (যা Swagger UI সরবরাহ করে):

বিকল্প API ডকুমেন্টেশন¶

আর এখন http://127.0.0.1:8000/redoc-এ যান।

আপনি বিকল্প স্বয়ংক্রিয় ডকুমেন্টেশন দেখতে পাবেন (যা ReDoc সরবরাহ করে):

OpenAPI¶

API সংজ্ঞায়িত করার OpenAPI স্ট্যান্ডার্ড ব্যবহার করে FastAPI আপনার পুরো API নিয়ে একটি "স্কিমা" তৈরি করে।

"স্কিমা"¶

"স্কিমা" হলো কোনো কিছুর একটি সংজ্ঞা বা বর্ণনা। যে কোড এটি বাস্তবায়ন করে তা নয়, শুধু একটি বিমূর্ত বর্ণনা।

API "স্কিমা"¶

এক্ষেত্রে, OpenAPI হলো একটি স্পেসিফিকেশন যা নির্ধারণ করে কীভাবে আপনার API-এর স্কিমা সংজ্ঞায়িত করতে হবে।

এই স্কিমা সংজ্ঞায় আপনার API-এর পাথগুলো, সেগুলো কী কী প্যারামিটার নিতে পারে ইত্যাদি থাকে।

ডেটা "স্কিমা"¶

"স্কিমা" শব্দটি দিয়ে কোনো ডেটার আকৃতিও বোঝানো হতে পারে, যেমন একটি JSON কনটেন্ট।

সেক্ষেত্রে এর মানে হবে JSON অ্যাট্রিবিউটগুলো, সেগুলোর ডেটা টাইপ ইত্যাদি।

OpenAPI ও JSON Schema¶

OpenAPI আপনার API-এর জন্য একটি API স্কিমা সংজ্ঞায়িত করে। আর সেই স্কিমায় আপনার API যে ডেটা পাঠায় ও গ্রহণ করে তার সংজ্ঞা (বা "স্কিমা") থাকে, যা JSON ডেটা স্কিমার স্ট্যান্ডার্ড JSON Schema ব্যবহার করে লেখা।

openapi.json দেখুন¶

কাঁচা OpenAPI স্কিমা দেখতে কেমন তা জানতে আপনি কৌতূহলী হলে জেনে রাখুন, FastAPI আপনার পুরো API-এর বর্ণনাসহ স্বয়ংক্রিয়ভাবে একটি JSON (স্কিমা) তৈরি করে।

আপনি এটি সরাসরি দেখতে পারেন এখানে: http://127.0.0.1:8000/openapi.json।

এটি এরকম কিছু দিয়ে শুরু হওয়া একটি JSON দেখাবে:

{
    "openapi": "3.1.0",
    "info": {
        "title": "FastAPI",
        "version": "0.1.0"
    },
    "paths": {
        "/items/": {
            "get": {
                "responses": {
                    "200": {
                        "description": "Successful Response",
                        "content": {
                            "application/json": {



...

OpenAPI কীসের জন্য¶

অন্তর্ভুক্ত দুটি ইন্টারঅ্যাকটিভ ডকুমেন্টেশন সিস্টেম চলে এই OpenAPI স্কিমার ওপর ভিত্তি করেই।

আর OpenAPI-ভিত্তিক আরও কয়েক ডজন বিকল্প আছে। FastAPI দিয়ে তৈরি আপনার অ্যাপ্লিকেশনে এই বিকল্পগুলোর যেকোনোটি আপনি সহজেই যোগ করতে পারেন।

আপনার API-এর সাথে যোগাযোগ করে এমন ক্লায়েন্টদের জন্য স্বয়ংক্রিয়ভাবে কোড তৈরি করতেও আপনি এটি ব্যবহার করতে পারেন। যেমন, ফ্রন্টএন্ড, মোবাইল বা IoT অ্যাপ্লিকেশন।

pyproject.toml-এ অ্যাপের entrypoint কনফিগার করুন¶

আপনার অ্যাপ কোথায় আছে তা একটি pyproject.toml ফাইলে এভাবে কনফিগার করতে পারেন:

[tool.fastapi]
entrypoint = "main:app"

ওই entrypoint fastapi কমান্ডকে জানাবে যে অ্যাপটি এভাবে ইম্পোর্ট করতে হবে:

from main import app

আপনার কোড যদি এভাবে সাজানো থাকত:

.
├── backend
│   ├── main.py
│   ├── __init__.py

তাহলে আপনি entrypoint সেট করতেন এভাবে:

[tool.fastapi]
entrypoint = "backend.main:app"

যা এর সমতুল্য হতো:

from backend.main import app

পাথসহ বা --entrypoint CLI অপশনসহ fastapi dev¶

আপনি fastapi dev কমান্ডে ফাইলের পাথও দিতে পারেন, আর এটি কোন FastAPI অ্যাপ অবজেক্ট ব্যবহার করতে হবে তা অনুমান করে নেবে:

$ uv run fastapi dev main.py

অথবা, আপনি fastapi dev কমান্ডে --entrypoint অপশনও দিতে পারেন:

$ uv run fastapi dev --entrypoint main:app

তবে প্রতিবার fastapi কমান্ড চালানোর সময় সঠিক পাথ\entrypoint দেওয়ার কথা আপনাকে মনে রাখতে হবে।

এছাড়া অন্যান্য টুল হয়তো এটি খুঁজে পাবে না, যেমন VS Code এক্সটেনশন বা FastAPI Cloud, তাই pyproject.toml-এ entrypoint ব্যবহার করার পরামর্শ দেওয়া হয়।

আপনার অ্যাপ ডিপ্লয় করুন (ঐচ্ছিক)¶

চাইলে আপনি একটিমাত্র কমান্ড দিয়ে আপনার FastAPI অ্যাপ FastAPI Cloud-এ ডিপ্লয় করতে পারেন। 🚀

$ uv run fastapi deploy

Deploying to FastAPI Cloud...

✅ Deployment successful!

🐔 Ready the chicken! Your app is ready at https://myapp.fastapicloud.dev

CLI স্বয়ংক্রিয়ভাবে আপনার FastAPI অ্যাপ্লিকেশন খুঁজে বের করে ক্লাউডে ডিপ্লয় করবে। আপনি লগ ইন করা না থাকলে অথেনটিকেশন প্রক্রিয়া সম্পন্ন করতে আপনার ব্রাউজার খুলবে।

ব্যস! এখন আপনি সেই URL-এ আপনার অ্যাপ অ্যাক্সেস করতে পারবেন। ✨

ধাপে ধাপে সংক্ষেপে¶

ধাপ ১: FastAPI ইম্পোর্ট করুন¶

from fastapi import FastAPI

app = FastAPI()


@app.get("/")
async def root():
    return {"message": "Hello World"}

FastAPI হলো একটি Python ক্লাস যা আপনার API-এর সব কার্যকারিতা দেয়।

কারিগরি বিবরণ

FastAPI হলো এমন একটি ক্লাস যা সরাসরি Starlette থেকে ইনহেরিট করে।

FastAPI-এর সাথেও আপনি Starlette-এর সব কার্যকারিতা ব্যবহার করতে পারেন।

ধাপ ২: একটি FastAPI "ইনস্ট্যান্স" তৈরি করুন¶

from fastapi import FastAPI

app = FastAPI()


@app.get("/")
async def root():
    return {"message": "Hello World"}

এখানে app ভেরিয়েবলটি হবে FastAPI ক্লাসের একটি "ইনস্ট্যান্স"।

আপনার পুরো API তৈরির জন্য এটিই হবে যোগাযোগের প্রধান কেন্দ্র।

ধাপ ৩: একটি পাথ অপারেশন তৈরি করুন¶

পাথ¶

এখানে "পাথ" বলতে URL-এর প্রথম / থেকে শুরু হওয়া শেষ অংশটিকে বোঝায়।

তাই এরকম একটি URL-এ:

https://example.com/items/foo

...পাথটি হবে:

/items/foo

নোট

"পাথ"-কে সাধারণত "এন্ডপয়েন্ট" বা "রাউট"-ও বলা হয়।

API তৈরির সময় "পাথ" হলো "দায়িত্ব" ও "রিসোর্স" আলাদা করার প্রধান উপায়।

অপারেশন¶

এখানে "অপারেশন" বলতে HTTP-এর "মেথডগুলোর" একটিকে বোঝায়।

এগুলোর একটি:

  • POST
  • GET
  • PUT
  • DELETE

...এবং আরও বিরল কয়েকটি:

  • OPTIONS
  • HEAD
  • PATCH
  • TRACE

HTTP প্রোটোকলে আপনি এই "মেথডগুলোর" এক (বা একাধিক) ব্যবহার করে প্রতিটি পাথের সাথে যোগাযোগ করতে পারেন।

API তৈরির সময় আপনি সাধারণত নির্দিষ্ট একটি কাজ করতে এই নির্দিষ্ট HTTP মেথডগুলো ব্যবহার করেন।

সাধারণত আপনি ব্যবহার করেন:

  • POST: ডেটা তৈরি করতে।
  • GET: ডেটা পড়তে।
  • PUT: ডেটা আপডেট করতে।
  • DELETE: ডেটা মুছতে।

তাই OpenAPI-তে প্রতিটি HTTP মেথডকে একটি "অপারেশন" বলা হয়।

আমরাও এগুলোকে "অপারেশন" বলব।

একটি পাথ অপারেশন ডেকোরেটর সংজ্ঞায়িত করুন¶

from fastapi import FastAPI

app = FastAPI()


@app.get("/")
async def root():
    return {"message": "Hello World"}

@app.get("/") FastAPI-কে জানায় যে ঠিক নিচের ফাংশনটি সেই রিকোয়েস্টগুলো সামলানোর দায়িত্বে আছে যেগুলো যায়:

  • / পাথে
  • একটি get অপারেশন ব্যবহার করে

@decorator সম্পর্কে তথ্য

Python-এর ওই @something সিনট্যাক্সকে বলা হয় "ডেকোরেটর"।

এটি আপনি একটি ফাংশনের ওপরে বসান। একটি সুন্দর সাজানো টুপির মতো (আমার ধারণা শব্দটি সেখান থেকেই এসেছে)।

একটি "ডেকোরেটর" নিচের ফাংশনটি নিয়ে তা দিয়ে কিছু একটা করে।

আমাদের ক্ষেত্রে, এই ডেকোরেটর FastAPI-কে জানায় যে নিচের ফাংশনটি get অপারেশনসহ / পাথের সাথে সম্পর্কিত।

এটিই হলো "পাথ অপারেশন ডেকোরেটর"।

আপনি অন্যান্য অপারেশনও ব্যবহার করতে পারেন:

  • @app.post()
  • @app.put()
  • @app.delete()

এবং আরও বিরলগুলো:

  • @app.options()
  • @app.head()
  • @app.patch()
  • @app.trace()

পরামর্শ

প্রতিটি অপারেশন (HTTP মেথড) আপনি যেভাবে খুশি ব্যবহার করতে পারেন।

FastAPI কোনো নির্দিষ্ট অর্থ চাপিয়ে দেয় না।

এখানের তথ্যগুলো একটি নির্দেশিকা হিসেবে দেওয়া হয়েছে, বাধ্যবাধকতা হিসেবে নয়।

যেমন, GraphQL ব্যবহার করার সময় সাধারণত আপনি শুধু POST অপারেশন দিয়েই সব কাজ করেন।

ধাপ ৪: পাথ অপারেশন ফাংশন সংজ্ঞায়িত করুন¶

এটি আমাদের "পাথ অপারেশন ফাংশন":

  • পাথ: হলো /।
  • অপারেশন: হলো get।
  • ফাংশন: হলো "ডেকোরেটরের" নিচের ফাংশনটি (@app.get("/")-এর নিচে)।
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
async def root():
    return {"message": "Hello World"}

এটি একটি Python ফাংশন।

যখনই FastAPI একটি GET অপারেশন ব্যবহার করে "/" URL-এ কোনো রিকোয়েস্ট পাবে, তখনই এটি এই ফাংশনটি কল করবে।

এক্ষেত্রে এটি একটি async ফাংশন।

আপনি এটিকে async def-এর বদলে একটি সাধারণ ফাংশন হিসেবেও সংজ্ঞায়িত করতে পারেন:

from fastapi import FastAPI

app = FastAPI()


@app.get("/")
def root():
    return {"message": "Hello World"}

নোট

আপনি যদি পার্থক্যটি না জানেন, তাহলে Async: "তাড়াহুড়োয় আছেন?" দেখুন।

ধাপ ৫: কনটেন্ট রিটার্ন করুন¶

from fastapi import FastAPI

app = FastAPI()


@app.get("/")
async def root():
    return {"message": "Hello World"}

আপনি একটি dict, list, কিংবা str, int ইত্যাদির মতো একক ভ্যালু রিটার্ন করতে পারেন।

আপনি Pydantic মডেলও রিটার্ন করতে পারেন (এ সম্পর্কে পরে আরও দেখবেন)।

আরও অনেক অবজেক্ট ও মডেল আছে যেগুলো স্বয়ংক্রিয়ভাবে JSON-এ রূপান্তরিত হবে (ORM ইত্যাদিসহ)। আপনার পছন্দেরগুলো ব্যবহার করে দেখুন, খুব সম্ভবত সেগুলো আগে থেকেই সাপোর্টেড।

ধাপ ৬: ডিপ্লয় করুন¶

একটি কমান্ড দিয়ে আপনার অ্যাপ FastAPI Cloud-এ ডিপ্লয় করুন: fastapi deploy। 🎉

FastAPI Cloud সম্পর্কে¶

FastAPI Cloud তৈরি করেছেন FastAPI-এর পেছনের একই লেখক ও টিম।

এটি খুব কম পরিশ্রমে একটি API তৈরি, ডিপ্লয় এবং অ্যাক্সেস করার প্রক্রিয়াকে সহজ করে।

FastAPI দিয়ে অ্যাপ তৈরির যে ডেভেলপার অভিজ্ঞতা, সেটিই এটি ক্লাউডে ডিপ্লয় করার ক্ষেত্রেও নিয়ে আসে। 🎉

FastAPI Cloud হলো FastAPI and friends ওপেন সোর্স প্রজেক্টগুলোর প্রধান স্পনসর ও অর্থায়নকারী। ✨

অন্যান্য ক্লাউড প্রোভাইডারে ডিপ্লয়¶

FastAPI ওপেন সোর্স এবং স্ট্যান্ডার্ড-ভিত্তিক। আপনি আপনার পছন্দের যেকোনো ক্লাউড প্রোভাইডারে FastAPI অ্যাপ ডিপ্লয় করতে পারেন।

আপনার ক্লাউড প্রোভাইডারে FastAPI অ্যাপ ডিপ্লয় করতে তাদের গাইড অনুসরণ করুন। 🤓

সংক্ষেপে¶

  • FastAPI ইম্পোর্ট করুন।
  • একটি app ইনস্ট্যান্স তৈরি করুন।
  • @app.get("/")-এর মতো ডেকোরেটর ব্যবহার করে একটি পাথ অপারেশন ডেকোরেটর লিখুন।
  • একটি পাথ অপারেশন ফাংশন সংজ্ঞায়িত করুন; যেমন, def root(): ...।
  • fastapi dev কমান্ড দিয়ে ডেভেলপমেন্ট সার্ভার চালান।
  • চাইলে fastapi deploy দিয়ে আপনার অ্যাপ ডিপ্লয় করুন।
