পাথ প্যারামিটার¶

🌐 সহজ বাংলায় ব্যাখ্যাসহ সংস্করণ

এটি শুধু অনুবাদ নয়: প্রতিটি পেজে সহজ ভাষায় ব্যাখ্যা, বাস্তব জীবনের উদাহরণ, কোডের লাইন-ধরে-ধরে ব্যাখ্যা, সাধারণ ভুল আর শেষে সারসংক্ষেপ যোগ করা হয়েছে। 🤝

কোড, প্যারামিটারের নাম আর কমান্ড ইংরেজিতেই রাখা হয়েছে, কারণ এগুলো ঠিক এভাবেই লিখতে হয়। অচেনা শব্দের মানে জানতে মেনুর "শিখুন" অংশে "সহজ শব্দকোষ" পেজটি দেখুন।

এটি মানুষের নির্দেশনায় AI দিয়ে তৈরি, তাই কোথাও ভুল থাকতে পারে। সন্দেহ হলে মূল ইংরেজি সংস্করণ মিলিয়ে নিন। 🤖

ইংরেজি সংস্করণ

এই পেজে যা শিখবেন

  • URL-এর পরিবর্তনশীল অংশ (যেমন /items/5-এর 5) কীভাবে ফাংশনে নেবেন।
  • টাইপ দিলে FastAPI কীভাবে নিজে রূপান্তর আর যাচাই করে।
  • একই রকম দেখতে পাথ থাকলে কেন ঘোষণার ক্রম জরুরি।
  • Enum দিয়ে কীভাবে আগে থেকে ঠিক করা কয়েকটি মানই কেবল গ্রহণ করবেন।
  • পুরো একটি ফাইল-পাথকে কীভাবে প্যারামিটার হিসেবে নেবেন।

পাথে "প্যারামিটার" বা "ভেরিয়েবল" ঘোষণা করা যায়, Python-এর ফরম্যাট স্ট্রিংয়ে যে সিনট্যাক্স ব্যবহার হয় সেই একই সিনট্যাক্সে, মানে দ্বিতীয় বন্ধনী { } দিয়ে:

from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id):
    return {"item_id": item_id}

পাথ প্যারামিটার item_id-এর মানটি আপনার ফাংশনে item_id আর্গুমেন্ট হিসেবে পাঠানো হবে।

তাই এই উদাহরণটি চালিয়ে http://127.0.0.1:8000/items/foo-এ গেলে এই রেসপন্স দেখবেন:

{"item_id":"foo"}

কোডটি সহজ ভাষায়

  • লাইন ৬: "/items/{item_id}"-এ {item_id} অংশটি একটি "খালি ঘর"। কেউ /items/foo পাঠালে এই ঘরে বসবে foo, /items/42 পাঠালে বসবে 42।
  • লাইন ৭: ফাংশনের প্যারামিটারের নামও item_id। নাম মিলে যাওয়াতেই FastAPI বোঝে যে পাথের ওই অংশটি এই প্যারামিটারে দিতে হবে।
  • লাইন ৮: মানটি ফেরত পাঠানো হলো।

মনে রাখবেন: { }-এর ভেতরের নাম আর ফাংশনের প্যারামিটারের নাম হুবহু এক হতে হবে।

টাইপসহ পাথ প্যারামিটার¶

সাধারণ Python টাইপ অ্যানোটেশন ব্যবহার করে ফাংশনে পাথ প্যারামিটারের টাইপ ঘোষণা করতে পারেন:

from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}

এই ক্ষেত্রে item_id-কে একটি int (পূর্ণসংখ্যা) হিসেবে ঘোষণা করা হয়েছে।

পরামর্শ

এতে আপনার ফাংশনের ভেতরে এডিটরের সাহায্য পাবেন: ভুল ধরা, কমপ্লিশন ইত্যাদি।

ডেটা রূপান্তর¶

এই উদাহরণটি চালিয়ে ব্রাউজারে http://127.0.0.1:8000/items/3 খুললে এই রেসপন্স দেখবেন:

{"item_id":3}

পরামর্শ

খেয়াল করুন, আপনার ফাংশন যে মানটি পেয়েছে (এবং রিটার্ন করেছে) সেটি 3, একটি Python int, টেক্সট "3" নয়।

তাই ওই টাইপ ঘোষণা থেকেই FastAPI আপনাকে স্বয়ংক্রিয় রিকোয়েস্ট "পার্সিং" দেয়।

কেন এটা জরুরি? URL-এর সবকিছুই আসলে টেক্সট। /items/3 পাঠালে সার্ভার পায় টেক্সট "3"। টাইপ না দিলে আপনাকে নিজে int("3") লিখে রূপান্তর করতে হতো, আর ভুল ইনপুট এলে সেই এরর নিজে সামলাতে হতো। FastAPI এই সব কাজ নিজেই করে।

ডেটা যাচাই (ভ্যালিডেশন)¶

কিন্তু ব্রাউজারে http://127.0.0.1:8000/items/foo-এ গেলে আপনি একটি সুন্দর HTTP এরর দেখবেন:

{
  "detail": [
    {
      "type": "int_parsing",
      "loc": [
        "path",
        "item_id"
      ],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "foo"
    }
  ]
}

কারণ পাথ প্যারামিটার item_id-এর মান ছিল "foo", যা একটি int নয়।

এররটি সহজ ভাষায়

  • "detail": এররের তালিকা (একসাথে একাধিক ভুল থাকলে সবগুলোই দেখায়)।
  • "type": "int_parsing": ভুলের ধরন, পূর্ণসংখ্যায় রূপান্তর করা যায়নি।
  • "loc": ["path", "item_id"]: ভুলটা কোথায়, পাথের item_id অংশে।
  • "msg": মানুষের পড়ার মতো বার্তা, "ইনপুট একটি বৈধ পূর্ণসংখ্যা হওয়া উচিত"।
  • "input": "foo": আসলে কী পাঠানো হয়েছিল।

এই রেসপন্সের স্ট্যাটাস কোড হয় 422 Unprocessable Content, মানে "রিকোয়েস্টটা বোঝা গেছে, কিন্তু ডেটা গ্রহণযোগ্য নয়"।

int-এর বদলে একটি float দিলেও একই এরর আসবে, যেমন: http://127.0.0.1:8000/items/4.2

পরামর্শ

তাই একই Python টাইপ ঘোষণা দিয়ে FastAPI আপনাকে ডেটা যাচাইও দেয়।

খেয়াল করুন, এররটি ঠিক কোন জায়গায় যাচাই ব্যর্থ হয়েছে তাও পরিষ্কারভাবে বলে দেয়।

আপনার API-এর সাথে কাজ করে এমন কোড লেখা ও ডিবাগ করার সময় এটি অবিশ্বাস্য রকমের সাহায্য করে।

আর ব্রাউজারে http://127.0.0.1:8000/docs খুললে এমন একটি স্বয়ংক্রিয়, ইন্টারঅ্যাকটিভ API ডকুমেন্টেশন দেখবেন:

পরামর্শ

আবারও, শুধু ওই একই Python টাইপ ঘোষণা দিয়ে FastAPI আপনাকে স্বয়ংক্রিয়, ইন্টারঅ্যাকটিভ ডকুমেন্টেশন দেয় (Swagger UI যুক্ত করে)।

খেয়াল করুন, পাথ প্যারামিটারটি যে একটি পূর্ণসংখ্যা (integer) তাও সেখানে লেখা আছে।

স্ট্যান্ডার্ড-ভিত্তিক সুবিধা, বিকল্প ডকুমেন্টেশন¶

আর যেহেতু তৈরি হওয়া স্কিমাটি OpenAPI স্ট্যান্ডার্ড অনুযায়ী, তাই অনেক সামঞ্জস্যপূর্ণ টুল আছে।

এ কারণে FastAPI নিজেই একটি বিকল্প API ডকুমেন্টেশন দেয় (ReDoc ব্যবহার করে), যা আপনি http://127.0.0.1:8000/redoc-এ দেখতে পারেন:

একইভাবে আরও অনেক সামঞ্জস্যপূর্ণ টুল আছে। যার মধ্যে অনেক প্রোগ্রামিং ভাষার জন্য কোড তৈরির টুলও আছে।

Pydantic¶

সব ডেটা যাচাই ভেতরে ভেতরে করে Pydantic, তাই এর সব সুবিধা আপনি পান। আর জানেন যে আপনি নির্ভরযোগ্য হাতে আছেন।

str, float, bool এবং আরও অনেক জটিল ডেটা টাইপ দিয়েও একইভাবে টাইপ ঘোষণা করতে পারেন।

এগুলোর কয়েকটি টিউটোরিয়ালের পরের অধ্যায়গুলোতে দেখানো হয়েছে।

ক্রম গুরুত্বপূর্ণ¶

পাথ অপারেশন তৈরির সময় এমন পরিস্থিতি আসতে পারে যেখানে একটি নির্দিষ্ট (স্থির) পাথ থাকে।

যেমন /users/me, ধরা যাক এটি বর্তমান (লগইন করা) ব্যবহারকারীর তথ্য পাওয়ার জন্য।

আবার নির্দিষ্ট একজন ব্যবহারকারীর আইডি দিয়ে তার তথ্য পেতে /users/{user_id} পাথও থাকতে পারে।

যেহেতু পাথ অপারেশনগুলো ক্রমানুসারে (ওপর থেকে নিচে) মিলিয়ে দেখা হয়, তাই নিশ্চিত করতে হবে যে /users/me-এর পাথটি /users/{user_id}-এর আগে ঘোষণা করা হয়েছে:

from fastapi import FastAPI

app = FastAPI()


@app.get("/users/me")
async def read_user_me():
    return {"user_id": "the current user"}


@app.get("/users/{user_id}")
async def read_user(user_id: str):
    return {"user_id": user_id}

নাহলে /users/{user_id}-এর পাথটি /users/me-এর সাথেও মিলে যেত, আর "ভাবত" যে এটি "me" মানসহ একটি user_id প্যারামিটার পাচ্ছে।

উদাহরণ দিয়ে বুঝি

ধরুন দারোয়ানের কাছে দুটি নির্দেশ আছে: "যে কেউ এলে সাধারণ অতিথিকক্ষে পাঠাও" আর "মালিক এলে তার নিজের ঘরে পাঠাও"। দারোয়ান যদি প্রথম নির্দেশটি আগে পড়ে, তাহলে মালিককেও অতিথিকক্ষে পাঠিয়ে দেবে। তাই নির্দিষ্ট নির্দেশটি ("মালিক", মানে /users/me) আগে রাখতে হয়, সাধারণটি (/users/{user_id}) পরে।

একইভাবে, একটি পাথ অপারেশন দুবার সংজ্ঞায়িত করা যায় না:

from fastapi import FastAPI

app = FastAPI()


@app.get("/users")
async def read_users():
    return ["Rick", "Morty"]


@app.get("/users")
async def read_users2():
    return ["Bean", "Elfo"]

এখানে সবসময় প্রথমটিই ব্যবহার হবে, কারণ পাথটি প্রথমেই মিলে যায়। দ্বিতীয়টি কখনো চলবে না।

আগে থেকে নির্ধারিত মান¶

আপনার যদি এমন একটি পাথ অপারেশন থাকে যা একটি পাথ প্যারামিটার নেয়, কিন্তু আপনি চান সেই পাথ প্যারামিটারের সম্ভাব্য বৈধ মানগুলো আগে থেকে ঠিক করা থাকুক, তাহলে Python-এর স্ট্যান্ডার্ড Enum ব্যবহার করতে পারেন।

যেমন একটি ড্রপডাউন মেনু, যেখানে শুধু কয়েকটি নির্দিষ্ট অপশন থেকেই বেছে নেওয়া যায়।

একটি Enum ক্লাস তৈরি করুন¶

Enum ইমপোর্ট করুন এবং একটি সাব-ক্লাস তৈরি করুন যা str ও Enum থেকে ইনহেরিট করে।

str থেকে ইনহেরিট করলে API ডকুমেন্টেশন বুঝতে পারবে যে মানগুলো অবশ্যই string টাইপের, আর সঠিকভাবে দেখাতে পারবে।

তারপর নির্দিষ্ট মানসহ ক্লাস অ্যাট্রিবিউট তৈরি করুন, যেগুলোই হবে উপলব্ধ বৈধ মান:

from enum import Enum

from fastapi import FastAPI


class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"


app = FastAPI()


@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model_name": model_name, "message": "Deep Learning FTW!"}

    if model_name.value == "lenet":
        return {"model_name": model_name, "message": "LeCNN all the images"}

    return {"model_name": model_name, "message": "Have some residuals"}

পরামর্শ

যদি ভাবেন, "AlexNet", "ResNet" আর "LeNet" হলো শুধু মেশিন লার্নিংয়ের কয়েকটি মডেলের নাম।

একটি পাথ প্যারামিটার ঘোষণা করুন¶

তারপর আপনার তৈরি করা enum ক্লাসটি (ModelName) টাইপ অ্যানোটেশন হিসেবে দিয়ে একটি পাথ প্যারামিটার তৈরি করুন:

from enum import Enum

from fastapi import FastAPI


class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"


app = FastAPI()


@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model_name": model_name, "message": "Deep Learning FTW!"}

    if model_name.value == "lenet":
        return {"model_name": model_name, "message": "LeCNN all the images"}

    return {"model_name": model_name, "message": "Have some residuals"}

এখন কেউ /models/alexnet, /models/resnet বা /models/lenet ছাড়া অন্য কিছু (যেমন /models/xyz) পাঠালে FastAPI নিজে থেকেই একটি এরর ফেরত দেবে, যেখানে বৈধ মানগুলোর তালিকাও থাকবে।

ডকুমেন্টেশন দেখুন¶

যেহেতু পাথ প্যারামিটারের সম্ভাব্য মানগুলো আগে থেকে নির্ধারিত, তাই ইন্টারঅ্যাকটিভ ডকুমেন্টেশন সেগুলো সুন্দরভাবে (ড্রপডাউন হিসেবে) দেখাতে পারে:

Python enumeration নিয়ে কাজ¶

পাথ প্যারামিটারের মানটি হবে একটি enumeration member (enum-এর একটি সদস্য)।

enumeration member তুলনা করুন¶

আপনার তৈরি enum ModelName-এর enumeration member-এর সাথে এটি তুলনা করতে পারেন:

from enum import Enum

from fastapi import FastAPI


class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"


app = FastAPI()


@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model_name": model_name, "message": "Deep Learning FTW!"}

    if model_name.value == "lenet":
        return {"model_name": model_name, "message": "LeCNN all the images"}

    return {"model_name": model_name, "message": "Have some residuals"}

enumeration-এর মান পান¶

আসল মানটি (এই ক্ষেত্রে একটি str) পেতে পারেন model_name.value দিয়ে, বা সাধারণভাবে your_enum_member.value দিয়ে:

from enum import Enum

from fastapi import FastAPI


class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"


app = FastAPI()


@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model_name": model_name, "message": "Deep Learning FTW!"}

    if model_name.value == "lenet":
        return {"model_name": model_name, "message": "LeCNN all the images"}

    return {"model_name": model_name, "message": "Have some residuals"}

পরামর্শ

"lenet" মানটি আপনি ModelName.lenet.value দিয়েও পেতে পারতেন।

enumeration member রিটার্ন করুন¶

আপনার পাথ অপারেশন থেকে enum member রিটার্ন করতে পারেন, এমনকি একটি JSON বডির ভেতরে (যেমন একটি dict-এর ভেতরে) রেখেও।

ক্লায়েন্টকে ফেরত পাঠানোর আগে এগুলো সংশ্লিষ্ট মানে (এই ক্ষেত্রে টেক্সটে) রূপান্তরিত হবে:

from enum import Enum

from fastapi import FastAPI


class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"


app = FastAPI()


@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model_name": model_name, "message": "Deep Learning FTW!"}

    if model_name.value == "lenet":
        return {"model_name": model_name, "message": "LeCNN all the images"}

    return {"model_name": model_name, "message": "Have some residuals"}

আপনার ক্লায়েন্টে এমন একটি JSON রেসপন্স পাবেন:

{
  "model_name": "alexnet",
  "message": "Deep Learning FTW!"
}

পুরো কোডটি সহজ ভাষায়

  • লাইন ৬-৯: ModelName নামে একটি enum, যাতে তিনটি মাত্র বৈধ মান: alexnet, resnet, lenet।
  • লাইন ১৫-১৬: /models/{model_name} পাথ, আর প্যারামিটারের টাইপ ModelName। তাই এই তিনটির বাইরে কিছু এলে এরর।
  • লাইন ১৭: model_name is ModelName.alexnet দিয়ে enum সদস্যের সাথে সরাসরি তুলনা।
  • লাইন ২০: model_name.value == "lenet" দিয়ে আসল টেক্সট মানের সাথে তুলনা। দুই উপায়েই কাজ হয়।
  • লাইন ১৮, ২১, ২৩: প্রতিটি ক্ষেত্রে আলাদা বার্তাসহ ডিকশনারি রিটার্ন। model_name নিজে enum সদস্য হলেও JSON-এ এটি টেক্সট "alexnet" হয়ে যায়।

পাথসহ পাথ প্যারামিটার¶

ধরা যাক আপনার /files/{file_path} পাথসহ একটি পাথ অপারেশন আছে।

কিন্তু আপনার দরকার যে file_path নিজেই একটি পাথ ধারণ করবে, যেমন home/johndoe/myfile.txt।

তাহলে ওই ফাইলের URL হবে এরকম: /files/home/johndoe/myfile.txt।

সমস্যা হলো, সাধারণ পাথ প্যারামিটার / চিহ্ন পর্যন্তই থামে। তাই {file_path} শুধু home পর্যন্ত ধরবে, বাকি অংশ নয়।

OpenAPI সাপোর্ট¶

OpenAPI-তে একটি পাথ প্যারামিটারের ভেতরে আরেকটি পাথ রাখার কথা ঘোষণা করার কোনো উপায় নেই, কারণ তাতে এমন পরিস্থিতি তৈরি হতে পারে যা পরীক্ষা ও সংজ্ঞায়িত করা কঠিন।

তবুও FastAPI-তে Starlette-এর একটি অভ্যন্তরীণ টুল ব্যবহার করে এটি করা যায়।

আর ডকুমেন্টেশনও কাজ করবে, যদিও প্যারামিটারটিতে যে একটি পাথ থাকা উচিত তা ডকুমেন্টেশনে লেখা থাকবে না।

পাথ কনভার্টার¶

Starlette-এর একটি অপশন সরাসরি ব্যবহার করে এমন URL দিয়ে পাথ ধারণকারী একটি পাথ প্যারামিটার ঘোষণা করতে পারেন:

/files/{file_path:path}

এই ক্ষেত্রে প্যারামিটারের নাম file_path, আর শেষ অংশ :path বলে দেয় যে প্যারামিটারটি যেকোনো পাথের সাথে মিলবে (/ চিহ্নসহ সবকিছু)।

তাই এভাবে ব্যবহার করতে পারেন:

from fastapi import FastAPI

app = FastAPI()


@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}

পরামর্শ

হয়তো আপনার দরকার প্যারামিটারটিতে /home/johndoe/myfile.txt থাকুক, শুরুতে একটি স্ল্যাশ (/) সহ।

সেক্ষেত্রে URL হবে: /files//home/johndoe/myfile.txt, যেখানে files আর home-এর মাঝে একটি ডাবল স্ল্যাশ (//)।

সংক্ষেপে¶

FastAPI-তে ছোট, সহজবোধ্য ও স্ট্যান্ডার্ড Python টাইপ ঘোষণা ব্যবহার করে আপনি পান:

  • এডিটরের সাহায্য: ভুল ধরা, অটোকমপ্লিশন ইত্যাদি।
  • ডেটা "পার্সিং"
  • ডেটা যাচাই
  • API অ্যানোটেশন ও স্বয়ংক্রিয় ডকুমেন্টেশন

আর এগুলো আপনাকে মাত্র একবার ঘোষণা করতে হয়।

বিকল্প ফ্রেমওয়ার্কগুলোর তুলনায় এটাই সম্ভবত FastAPI-এর সবচেয়ে চোখে পড়ার মতো সুবিধা (কাঁচা গতি বাদে)।

সংক্ষেপে মনে রাখুন

  • পাথে {name} লিখুন, আর ফাংশনে একই নামের প্যারামিটার দিন।
  • টাইপ দিন (item_id: int), FastAPI নিজে রূপান্তর ও যাচাই করবে, ভুল হলে 422 এরর।
  • স্থির পাথ (/users/me) সবসময় পরিবর্তনশীল পাথের (/users/{user_id}) আগে লিখুন।
  • নির্দিষ্ট কয়েকটি মান চাইলে str ও Enum থেকে একটি ক্লাস বানিয়ে টাইপ হিসেবে দিন।
  • / সহ পুরো পাথ নিতে {file_path:path} লিখুন।
