এরর সামলানো¶

🌐 সহজ বাংলায় ব্যাখ্যাসহ সংস্করণ

এটি শুধু অনুবাদ নয়: প্রতিটি পেজে সহজ ভাষায় ব্যাখ্যা, বাস্তব জীবনের উদাহরণ, কোডের লাইন-ধরে-ধরে ব্যাখ্যা, সাধারণ ভুল আর শেষে সারসংক্ষেপ যোগ করা হয়েছে। 🤝

কোড, প্যারামিটারের নাম আর কমান্ড ইংরেজিতেই রাখা হয়েছে, কারণ এগুলো ঠিক এভাবেই লিখতে হয়। অচেনা শব্দের মানে জানতে মেনুর "শিখুন" অংশে "সহজ শব্দকোষ" পেজটি দেখুন।

এটি মানুষের নির্দেশনায় AI দিয়ে তৈরি, তাই কোথাও ভুল থাকতে পারে। সন্দেহ হলে মূল ইংরেজি সংস্করণ মিলিয়ে নিন। 🤖

ইংরেজি সংস্করণ

এই পেজে যা শিখবেন

  • HTTPException দিয়ে ক্লায়েন্টকে এরর (যেমন 404) জানানো।
  • এররের সাথে কাস্টম হেডার পাঠানো।
  • নিজের এক্সেপশনের জন্য নিজস্ব হ্যান্ডলার বানানো।
  • FastAPI-এর ডিফল্ট এরর রেসপন্সের ধরন বদলানো।

অনেক পরিস্থিতিতে আপনার API ব্যবহারকারী একটি ক্লায়েন্টকে একটি এরর জানাতে হয়।

এই ক্লায়েন্ট হতে পারে ফ্রন্টএন্ডসহ একটি ব্রাউজার, অন্য কারও লেখা কোড, একটি IoT যন্ত্র ইত্যাদি।

আপনার হয়তো ক্লায়েন্টকে জানাতে হবে যে:

  • ক্লায়েন্টের ওই কাজের জন্য যথেষ্ট অনুমতি নেই।
  • ক্লায়েন্টের ওই রিসোর্সে প্রবেশাধিকার নেই।
  • ক্লায়েন্ট যে আইটেমটি দেখতে চাইছিল সেটি নেই।
  • ইত্যাদি।

এসব ক্ষেত্রে সাধারণত 400-এর ঘরের (400 থেকে 499) একটি HTTP স্ট্যাটাস কোড ফেরত দেওয়া হয়।

এটি 200-এর ঘরের HTTP স্ট্যাটাস কোডের (200 থেকে 299) মতো। ওই "200" স্ট্যাটাস কোডগুলোর মানে রিকোয়েস্টে কোনো না কোনোভাবে "সফলতা" এসেছে।

400-এর ঘরের স্ট্যাটাস কোডগুলোর মানে ক্লায়েন্টের দিক থেকে একটি ভুল হয়েছে।

সেই সব "404 Not Found" এরর (আর সেগুলো নিয়ে মজার কৌতুকগুলো) মনে আছে?

HTTPException ব্যবহার করুন¶

ক্লায়েন্টকে এররসহ HTTP রেসপন্স ফেরত দিতে HTTPException ব্যবহার করুন।

HTTPException ইমপোর্ট করুন¶

from fastapi import FastAPI, HTTPException

app = FastAPI()

items = {"foo": "The Foo Wrestlers"}


@app.get("/items/{item_id}")
async def read_item(item_id: str):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"item": items[item_id]}

আপনার কোডে একটি HTTPException রেইজ করুন¶

HTTPException হলো API-এর জন্য প্রাসঙ্গিক বাড়তি ডেটাসহ একটি সাধারণ Python এক্সেপশন।

যেহেতু এটি একটি Python এক্সেপশন, তাই এটিকে return করবেন না, raise করবেন (ছুড়ে দেবেন)।

এর আরও মানে, আপনি যদি এমন একটি সহায়ক ফাংশনের ভেতরে থাকেন যা আপনার পাথ অপারেশন ফাংশনের ভেতর থেকে ডাকা হচ্ছে, আর সেই সহায়ক ফাংশনের ভেতর থেকে HTTPException রেইজ করেন, তাহলে পাথ অপারেশন ফাংশনের বাকি কোড আর চলবে না। এটি সাথে সাথে ওই রিকোয়েস্ট শেষ করে HTTPException থেকে HTTP এররটি ক্লায়েন্টকে পাঠাবে।

উদাহরণ দিয়ে বুঝি

return হলো স্বাভাবিকভাবে কাজ শেষ করে ফল দেওয়া। raise হলো জরুরি থামার বোতাম চাপা: যত ভেতরের ফাংশনেই থাকুন না কেন, সাথে সাথে সব কাজ বন্ধ হয়ে এরর বার্তা ক্লায়েন্টের কাছে চলে যায়। তাই "আইটেম পাওয়া যায়নি" বা "অনুমতি নেই" এর মতো ক্ষেত্রে বারবার if দিয়ে ফলাফল ফেরত পাঠানোর ঝামেলা নেই।

একটি মান রিটার্ন করার চেয়ে এক্সেপশন রেইজ করার সুবিধাটা ডিপেন্ডেন্সি আর সিকিউরিটি নিয়ে অংশে আরও স্পষ্ট হবে।

এই উদাহরণে, ক্লায়েন্ট যখন এমন একটি ID দিয়ে একটি আইটেম চায় যা নেই, তখন 404 স্ট্যাটাস কোডসহ একটি এক্সেপশন রেইজ করুন:

from fastapi import FastAPI, HTTPException

app = FastAPI()

items = {"foo": "The Foo Wrestlers"}


@app.get("/items/{item_id}")
async def read_item(item_id: str):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"item": items[item_id]}

কোডটি সহজ ভাষায়

  • লাইন ৫: items হলো একটিমাত্র আইটেমসহ নকল ডেটাবেস ("foo")।
  • লাইন ১০: if item_id not in items: মানে চাওয়া আইটেম ডেটাবেসে নেই।
  • লাইন ১১: raise HTTPException(status_code=404, detail="Item not found"): ৪০৪ স্ট্যাটাস আর "Item not found" বার্তাসহ এরর ছোড়া হলো। এর নিচের লাইন আর চলবে না।
  • লাইন ১২: আইটেম থাকলে সেটি ফেরত দেওয়া হয়।

ফলাফলের রেসপন্স¶

ক্লায়েন্ট যদি http://example.com/items/foo চায় (item_id "foo"), তাহলে ক্লায়েন্ট HTTP স্ট্যাটাস কোড 200 পাবে, আর এই JSON রেসপন্স:

{
  "item": "The Foo Wrestlers"
}

কিন্তু ক্লায়েন্ট যদি http://example.com/items/bar চায় (অস্তিত্বহীন item_id "bar"), তাহলে ক্লায়েন্ট HTTP স্ট্যাটাস কোড 404 ("পাওয়া যায়নি" এরর) পাবে, আর এই JSON রেসপন্স:

{
  "detail": "Item not found"
}

পরামর্শ

HTTPException রেইজ করার সময় detail প্যারামিটার হিসেবে শুধু str নয়, JSON-এ রূপান্তরযোগ্য যেকোনো মান দিতে পারেন।

একটি dict, একটি list ইত্যাদি দিতে পারেন।

FastAPI এগুলো স্বয়ংক্রিয়ভাবে সামলায় আর JSON-এ রূপান্তর করে।

কাস্টম হেডার যোগ করুন¶

কিছু পরিস্থিতিতে HTTP এররে কাস্টম হেডার যোগ করতে পারা কাজে লাগে। যেমন কিছু ধরনের সিকিউরিটির ক্ষেত্রে।

সম্ভবত আপনার কোডে এটি সরাসরি ব্যবহার করার দরকার হবে না।

তবে কোনো উন্নত পরিস্থিতিতে দরকার হলে কাস্টম হেডার যোগ করতে পারেন:

from fastapi import FastAPI, HTTPException

app = FastAPI()

items = {"foo": "The Foo Wrestlers"}


@app.get("/items-header/{item_id}")
async def read_item_header(item_id: str):
    if item_id not in items:
        raise HTTPException(
            status_code=404,
            detail="Item not found",
            headers={"X-Error": "There goes my error"},
        )
    return {"item": items[item_id]}

কাস্টম এক্সেপশন হ্যান্ডলার যোগ করুন¶

Starlette-এর একই এক্সেপশন টুল দিয়ে কাস্টম এক্সেপশন হ্যান্ডলার যোগ করতে পারেন।

ধরা যাক আপনার একটি কাস্টম এক্সেপশন UnicornException আছে, যা আপনি (বা আপনার ব্যবহৃত কোনো লাইব্রেরি) raise করতে পারে।

আর আপনি FastAPI দিয়ে এই এক্সেপশনটি সবখানে (গ্লোবালি) এক জায়গা থেকে সামলাতে চান।

@app.exception_handler() দিয়ে একটি কাস্টম এক্সেপশন হ্যান্ডলার যোগ করতে পারেন:

from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse


class UnicornException(Exception):
    def __init__(self, name: str):
        self.name = name


app = FastAPI()


@app.exception_handler(UnicornException)
async def unicorn_exception_handler(request: Request, exc: UnicornException):
    return JSONResponse(
        status_code=418,
        content={"message": f"Oops! {exc.name} did something. There goes a rainbow..."},
    )


@app.get("/unicorns/{name}")
async def read_unicorn(name: str):
    if name == "yolo":
        raise UnicornException(name=name)
    return {"unicorn_name": name}

এখানে আপনি যদি /unicorns/yolo চান, তাহলে পাথ অপারেশন একটি UnicornException raise করবে।

কিন্তু সেটি সামলাবে unicorn_exception_handler।

তাই আপনি একটি পরিচ্ছন্ন এরর পাবেন, HTTP স্ট্যাটাস কোড 418 আর এই JSON বিষয়বস্তুসহ:

{"message": "Oops! yolo did something. There goes a rainbow..."}

কোডটি সহজ ভাষায়

  • লাইন ৫-৭: UnicornException নামে নিজের একটি এক্সেপশন ক্লাস, যা একটি name মনে রাখে।
  • লাইন ১৩: @app.exception_handler(UnicornException) বলে, "যখনই কোথাও UnicornException ছোড়া হবে, নিচের ফাংশন দিয়ে সামলাও"।
  • লাইন ১৪-১৮: হ্যান্ডলার ফাংশন রিকোয়েস্ট আর এক্সেপশনটি পায়, আর ৪১৮ স্ট্যাটাসসহ একটি JSON রেসপন্স বানিয়ে ফেরত দেয়।
  • লাইন ২৪: নাম "yolo" হলে এক্সেপশন ছোড়া হয়।

এতে একই ধরনের এরর সব পাথ অপারেশনে এক জায়গা থেকে, একই ফরম্যাটে সামলানো যায়।

কারিগরি বিবরণ

from starlette.requests import Request আর from starlette.responses import JSONResponse-ও ব্যবহার করতে পারতেন।

FastAPI ডেভেলপার হিসেবে আপনার সুবিধার জন্যই একই starlette.responses-কে fastapi.responses হিসেবে দেয়। কিন্তু উপলব্ধ বেশিরভাগ রেসপন্স সরাসরি Starlette থেকে আসে। Request-এর ক্ষেত্রেও একই কথা।

ডিফল্ট এক্সেপশন হ্যান্ডলার ওভাররাইড করুন¶

FastAPI-এর কিছু ডিফল্ট এক্সেপশন হ্যান্ডলার আছে।

আপনি যখন একটি HTTPException raise করেন, আর যখন রিকোয়েস্টে অবৈধ ডেটা থাকে, তখন ডিফল্ট JSON রেসপন্স ফেরত দেওয়ার দায়িত্ব এই হ্যান্ডলারগুলোর।

এই এক্সেপশন হ্যান্ডলারগুলো আপনি নিজেরগুলো দিয়ে ওভাররাইড (প্রতিস্থাপন) করতে পারেন।

রিকোয়েস্ট যাচাইয়ের এক্সেপশন ওভাররাইড করুন¶

একটি রিকোয়েস্টে অবৈধ ডেটা থাকলে FastAPI ভেতরে ভেতরে একটি RequestValidationError রেইজ করে।

আর এর জন্য একটি ডিফল্ট এক্সেপশন হ্যান্ডলারও আছে।

এটি ওভাররাইড করতে RequestValidationError ইমপোর্ট করুন, আর এক্সেপশন হ্যান্ডলারটি ডেকোরেট করতে @app.exception_handler(RequestValidationError) ব্যবহার করুন।

এক্সেপশন হ্যান্ডলার একটি Request আর এক্সেপশনটি পাবে।

from fastapi import FastAPI, HTTPException
from fastapi.exceptions import RequestValidationError
from fastapi.responses import PlainTextResponse
from starlette.exceptions import HTTPException as StarletteHTTPException

app = FastAPI()


@app.exception_handler(StarletteHTTPException)
async def http_exception_handler(request, exc):
    return PlainTextResponse(str(exc.detail), status_code=exc.status_code)


@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request, exc: RequestValidationError):
    message = "Validation errors:"
    for error in exc.errors():
        message += f"\nField: {error['loc']}, Error: {error['msg']}"
    return PlainTextResponse(message, status_code=400)


@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id == 3:
        raise HTTPException(status_code=418, detail="Nope! I don't like 3.")
    return {"item_id": item_id}

এখন, /items/foo-তে গেলে এই ডিফল্ট JSON এররের বদলে:

{
    "detail": [
        {
            "loc": [
                "path",
                "item_id"
            ],
            "msg": "value is not a valid integer",
            "type": "type_error.integer"
        }
    ]
}

আপনি একটি টেক্সট সংস্করণ পাবেন, এভাবে:

Validation errors:
Field: ('path', 'item_id'), Error: Input should be a valid integer, unable to parse string as an integer

কোডটি সহজ ভাষায় (লাইন ১৪-১৯)

  • exc.errors() সব যাচাই-এররের একটি তালিকা দেয়।
  • প্রতিটি এররের loc (কোথায়) আর msg (কী সমস্যা) নিয়ে একটি টেক্সট বার্তা বানানো হচ্ছে।
  • PlainTextResponse(message, status_code=400) দিয়ে JSON-এর বদলে সাধারণ টেক্সট, আর ৪২২-এর বদলে ৪০০ স্ট্যাটাস ফেরত দেওয়া হচ্ছে।

HTTPException এরর হ্যান্ডলার ওভাররাইড করুন¶

একইভাবে HTTPException হ্যান্ডলারও ওভাররাইড করতে পারেন।

যেমন, এই এররগুলোর জন্য JSON-এর বদলে একটি সাধারণ টেক্সট রেসপন্স ফেরত দিতে চাইতে পারেন:

from fastapi import FastAPI, HTTPException
from fastapi.exceptions import RequestValidationError
from fastapi.responses import PlainTextResponse
from starlette.exceptions import HTTPException as StarletteHTTPException

app = FastAPI()


@app.exception_handler(StarletteHTTPException)
async def http_exception_handler(request, exc):
    return PlainTextResponse(str(exc.detail), status_code=exc.status_code)


@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request, exc: RequestValidationError):
    message = "Validation errors:"
    for error in exc.errors():
        message += f"\nField: {error['loc']}, Error: {error['msg']}"
    return PlainTextResponse(message, status_code=400)


@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id == 3:
        raise HTTPException(status_code=418, detail="Nope! I don't like 3.")
    return {"item_id": item_id}

কারিগরি বিবরণ

from starlette.responses import PlainTextResponse-ও ব্যবহার করতে পারতেন।

FastAPI ডেভেলপার হিসেবে আপনার সুবিধার জন্যই একই starlette.responses-কে fastapi.responses হিসেবে দেয়। কিন্তু উপলব্ধ বেশিরভাগ রেসপন্স সরাসরি Starlette থেকে আসে।

সতর্কতা

মনে রাখবেন, RequestValidationError-এ যে ফাইল আর লাইনে যাচাই-এরর হয়েছে তার তথ্য থাকে, যাতে চাইলে প্রাসঙ্গিক তথ্যসহ আপনার লগে দেখাতে পারেন।

কিন্তু এর মানে, এটিকে সরাসরি একটি স্ট্রিংয়ে রূপান্তর করে ওই তথ্য ফেরত দিলে আপনার সিস্টেম সম্পর্কে কিছু তথ্য ফাঁস হয়ে যেতে পারে। সে কারণেই এখানে কোডটি প্রতিটি এরর আলাদাভাবে বের করে দেখায়।

RequestValidationError-এর বডি ব্যবহার করুন¶

RequestValidationError-এর ভেতরে অবৈধ ডেটাসহ পাওয়া body থাকে।

অ্যাপ বানানোর সময় বডিটি লগ করে ডিবাগ করতে, ব্যবহারকারীকে ফেরত দিতে ইত্যাদি কাজে এটি ব্যবহার করতে পারেন।

from fastapi import FastAPI, Request
from fastapi.encoders import jsonable_encoder
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from pydantic import BaseModel

app = FastAPI()


@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request: Request, exc: RequestValidationError):
    return JSONResponse(
        status_code=422,
        content=jsonable_encoder({"detail": exc.errors(), "body": exc.body}),
    )


class Item(BaseModel):
    title: str
    size: int


@app.post("/items/")
async def create_item(item: Item):
    return item

এবার এমন একটি অবৈধ আইটেম পাঠিয়ে দেখুন:

{
  "title": "towel",
  "size": "XL"
}

আপনি একটি রেসপন্স পাবেন যা বলবে ডেটা অবৈধ, আর তাতে পাওয়া বডিটিও থাকবে:

{
  "detail": [
    {
      "loc": [
        "body",
        "size"
      ],
      "msg": "value is not a valid integer",
      "type": "type_error.integer"
    }
  ],
  "body": {
    "title": "towel",
    "size": "XL"
  }
}

FastAPI-এর HTTPException বনাম Starlette-এর HTTPException¶

FastAPI-এর নিজস্ব HTTPException আছে।

আর FastAPI-এর HTTPException এরর ক্লাসটি Starlette-এর HTTPException এরর ক্লাস থেকে ইনহেরিট করে।

একমাত্র পার্থক্য হলো FastAPI-এর HTTPException detail ফিল্ডে JSON-যোগ্য যেকোনো ডেটা গ্রহণ করে, অথচ Starlette-এর HTTPException এতে শুধু স্ট্রিং গ্রহণ করে।

তাই আপনার কোডে স্বাভাবিকভাবে FastAPI-এর HTTPException-ই রেইজ করতে থাকতে পারেন।

কিন্তু যখন একটি এক্সেপশন হ্যান্ডলার রেজিস্টার করবেন, তখন সেটি Starlette-এর HTTPException-এর জন্য রেজিস্টার করা উচিত।

এতে Starlette-এর অভ্যন্তরীণ কোডের কোনো অংশ, বা কোনো Starlette এক্সটেনশন বা প্লাগ-ইন একটি Starlette HTTPException রেইজ করলেও আপনার হ্যান্ডলার সেটি ধরে সামলাতে পারবে। (যেমন অস্তিত্বহীন পাথে গেলে যে ৪০৪ এরর হয়, সেটি Starlette-ই ছোড়ে।)

এই উদাহরণে, একই কোডে দুটি HTTPException-ই রাখতে পারার জন্য Starlette-এর এক্সেপশনটির নাম বদলে StarletteHTTPException রাখা হয়েছে:

from starlette.exceptions import HTTPException as StarletteHTTPException

FastAPI-এর এক্সেপশন হ্যান্ডলার পুনরায় ব্যবহার করুন¶

আপনি যদি FastAPI-এর একই ডিফল্ট এক্সেপশন হ্যান্ডলারগুলোর সাথে এক্সেপশনটি ব্যবহার করতে চান, তাহলে fastapi.exception_handlers থেকে ডিফল্ট এক্সেপশন হ্যান্ডলারগুলো ইমপোর্ট করে পুনরায় ব্যবহার করতে পারেন:

from fastapi import FastAPI, HTTPException
from fastapi.exception_handlers import (
    http_exception_handler,
    request_validation_exception_handler,
)
from fastapi.exceptions import RequestValidationError
from starlette.exceptions import HTTPException as StarletteHTTPException

app = FastAPI()


@app.exception_handler(StarletteHTTPException)
async def custom_http_exception_handler(request, exc):
    print(f"OMG! An HTTP error!: {repr(exc)}")
    return await http_exception_handler(request, exc)


@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request, exc):
    print(f"OMG! The client sent invalid data!: {exc}")
    return await request_validation_exception_handler(request, exc)


@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id == 3:
        raise HTTPException(status_code=418, detail="Nope! I don't like 3.")
    return {"item_id": item_id}

এই উদাহরণে আপনি শুধু খুব অভিব্যক্তিপূর্ণ একটি বার্তাসহ এররটি প্রিন্ট করছেন, তবে ধারণাটা বুঝে গেছেন। আপনি এক্সেপশনটি ব্যবহার করে তারপর শুধু ডিফল্ট এক্সেপশন হ্যান্ডলারগুলো পুনরায় ব্যবহার করতে পারেন।

অর্থাৎ নিজের কিছু কাজ (যেমন লগ লেখা বা নোটিফিকেশন পাঠানো) করে, তারপর রেসপন্স বানানোর কাজটা FastAPI-এর পুরোনো হ্যান্ডলারকেই দিয়ে দিচ্ছেন।

সংক্ষেপে মনে রাখুন

  • ক্লায়েন্টকে এরর জানাতে raise HTTPException(status_code=404, detail="..."), return নয়।
  • detail-এ টেক্সট, ডিকশনারি বা লিস্ট দেওয়া যায়, আর headers দিয়ে হেডারও।
  • নিজের এক্সেপশন সামলাতে @app.exception_handler(MyException)।
  • ডিফল্ট যাচাই-এরর বদলাতে RequestValidationError-এর জন্য হ্যান্ডলার লিখুন।
  • HTTPException-এর হ্যান্ডলার রেজিস্টার করুন Starlette-এর HTTPException দিয়ে।
