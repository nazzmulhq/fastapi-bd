কুয়েরি প্যারামিটার ও স্ট্রিং ভ্যালিডেশন¶

🌐 AI এবং মানুষের যৌথ অনুবাদ

এই অনুবাদটি মানুষের নির্দেশনায় AI দিয়ে করা হয়েছে। 🤝

এতে মূল অর্থ ভুল বোঝা বা অস্বাভাবিক শোনানোর মতো ভুল থাকতে পারে। 🤖

ইংরেজি সংস্করণ

FastAPI আপনাকে আপনার প্যারামিটারগুলোর জন্য অতিরিক্ত তথ্য ও ভ্যালিডেশন ঘোষণা করতে দেয়।

উদাহরণ হিসেবে এই অ্যাপ্লিকেশনটি নেওয়া যাক:

from fastapi import FastAPI

app = FastAPI()


@app.get("/items/")
async def read_items(q: str | None = None):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results

কুয়েরি প্যারামিটার q-এর টাইপ str | None, অর্থাৎ এটি str টাইপের তবে None-ও হতে পারে, আর আসলেই এর ডিফল্ট ভ্যালু None, তাই FastAPI জানবে যে এটি আবশ্যক নয়।

নোট

ডিফল্ট ভ্যালু = None থাকার কারণে FastAPI জানবে যে q-এর ভ্যালু আবশ্যক নয়।

str | None থাকলে আপনার এডিটর আপনাকে আরও ভালো সাপোর্ট দিতে এবং এরর ধরতে পারবে।

অতিরিক্ত ভ্যালিডেশন¶

আমরা নিশ্চিত করব যে q ঐচ্ছিক হলেও, যখনই এটি দেওয়া হবে, এর দৈর্ঘ্য ৫০ অক্ষরের বেশি হবে না।

Query ও Annotated ইম্পোর্ট করুন¶

এটি করতে প্রথমে ইম্পোর্ট করুন:

  • fastapi থেকে Query
  • typing থেকে Annotated
from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/items/")
async def read_items(q: Annotated[str | None, Query(max_length=50)] = None):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results
🤓 Other versions and variants

Tip

Prefer to use the Annotated version if possible.

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/items/")
async def read_items(q: str | None = Query(default=None, max_length=50)):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results

নোট

FastAPI ভার্সন 0.95.0-এ Annotated-এর সাপোর্ট যোগ করেছে (এবং এটি ব্যবহারের পরামর্শ দেওয়া শুরু করেছে)।

আপনার কাছে পুরোনো ভার্সন থাকলে Annotated ব্যবহার করতে গেলে এরর পাবেন।

Annotated ব্যবহারের আগে অবশ্যই FastAPI ভার্সন আপগ্রেড করুন, অন্তত 0.95.1-এ।

q প্যারামিটারের টাইপে Annotated ব্যবহার করুন¶

মনে আছে, আগে Python টাইপ পরিচিতি-তে আমি বলেছিলাম যে আপনার প্যারামিটারে মেটাডেটা যোগ করতে Annotated ব্যবহার করা যায়?

এখন FastAPI-এর সাথে এটি ব্যবহারের সময়। 🚀

আমাদের এই টাইপ অ্যানোটেশন ছিল:

q: str | None = None

আমরা যা করব তা হলো এটিকে Annotated দিয়ে মুড়িয়ে দেব, ফলে এটি হবে:

q: Annotated[str | None] = None

দুটি ভার্সনেরই অর্থ একই, q এমন একটি প্যারামিটার যা একটি str বা None হতে পারে, এবং ডিফল্টভাবে এটি None।

এবার মজার অংশে যাওয়া যাক। 🎉

q প্যারামিটারের Annotated-এ Query যোগ করুন¶

এখন যেহেতু আমাদের কাছে এই Annotated আছে যেখানে আমরা আরও তথ্য (এক্ষেত্রে কিছু অতিরিক্ত ভ্যালিডেশন) রাখতে পারি, তাই Annotated-এর ভেতরে Query যোগ করুন এবং max_length প্যারামিটার 50-এ সেট করুন:

from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/items/")
async def read_items(q: Annotated[str | None, Query(max_length=50)] = None):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/items/")
async def read_items(q: str | None = Query(default=None, max_length=50)):

    if q:
        results.update({"q": q})
    return results

লক্ষ করুন, ডিফল্ট ভ্যালু এখনো None, তাই প্যারামিটারটি এখনো ঐচ্ছিক।

তবে এখন Annotated-এর ভেতরে Query(max_length=50) রেখে আমরা FastAPI-কে বলছি যে আমরা চাই এই ভ্যালুর জন্য অতিরিক্ত ভ্যালিডেশন থাকুক, আমরা চাই এতে সর্বোচ্চ ৫০টি অক্ষর থাকুক। 😎

পরামর্শ

এখানে আমরা Query() ব্যবহার করছি কারণ এটি একটি কুয়েরি প্যারামিটার। পরে আমরা Path(), Body(), Header() ও Cookie()-এর মতো অন্যগুলোও দেখব, যেগুলোও Query()-এর মতো একই আর্গুমেন্ট গ্রহণ করে।

এখন FastAPI:

  • সর্বোচ্চ দৈর্ঘ্য যে ৫০ অক্ষর তা নিশ্চিত করে ডেটা ভ্যালিডেট করবে
  • ডেটা বৈধ না হলে ক্লায়েন্টকে একটি স্পষ্ট এরর দেখাবে
  • OpenAPI স্কিমার পাথ অপারেশনে প্যারামিটারটি ডকুমেন্ট করবে (তাই এটি স্বয়ংক্রিয় ডকুমেন্টেশন UI-তে দেখা যাবে)

বিকল্প (পুরোনো): ডিফল্ট ভ্যালু হিসেবে Query¶

FastAPI-এর আগের ভার্সনগুলোতে (0.95.0-এর আগে) Query-কে Annotated-এ রাখার বদলে আপনার প্যারামিটারের ডিফল্ট ভ্যালু হিসেবে ব্যবহার করতে হতো। খুব সম্ভবত আপনি আশেপাশে এটি ব্যবহার করা কোড দেখবেন, তাই আমি এটি আপনাকে ব্যাখ্যা করছি।

পরামর্শ

নতুন কোডের জন্য এবং যখনই সম্ভব, ওপরে যেভাবে ব্যাখ্যা করা হয়েছে সেভাবে Annotated ব্যবহার করুন। এর একাধিক সুবিধা আছে (নিচে ব্যাখ্যা করা হয়েছে) এবং কোনো অসুবিধা নেই। 🍰

আপনার ফাংশন প্যারামিটারের ডিফল্ট ভ্যালু হিসেবে Query() এভাবে ব্যবহার করবেন, max_length প্যারামিটার ৫০-এ সেট করে:

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/items/")
async def read_items(q: str | None = Query(default=None, max_length=50)):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results

যেহেতু এক্ষেত্রে (Annotated ব্যবহার না করে) আমাদের ফাংশনের ডিফল্ট ভ্যালু None-কে Query() দিয়ে প্রতিস্থাপন করতে হয়, তাই এখন ডিফল্ট ভ্যালু সেট করতে হবে Query(default=None) প্যারামিটার দিয়ে, এটি ডিফল্ট ভ্যালু সংজ্ঞায়িত করার একই উদ্দেশ্য পূরণ করে (অন্তত FastAPI-এর জন্য)।

তাই:

q: str | None = Query(default=None)

...প্যারামিটারটিকে None ডিফল্ট ভ্যালুসহ ঐচ্ছিক করে, ঠিক এটির মতো:

q: str | None = None

তবে Query ভার্সনটি স্পষ্টভাবে ঘোষণা করে যে এটি একটি কুয়েরি প্যারামিটার।

তারপর আমরা Query-তে আরও প্যারামিটার দিতে পারি। এক্ষেত্রে, স্ট্রিংয়ের ক্ষেত্রে প্রযোজ্য max_length প্যারামিটার:

q: str | None = Query(default=None, max_length=50)

এটি ডেটা ভ্যালিডেট করবে, ডেটা বৈধ না হলে একটি স্পষ্ট এরর দেখাবে এবং OpenAPI স্কিমার পাথ অপারেশনে প্যারামিটারটি ডকুমেন্ট করবে।

ডিফল্ট ভ্যালু হিসেবে বা Annotated-এ Query¶

মনে রাখবেন, Annotated-এর ভেতরে Query ব্যবহার করলে আপনি Query-এর default প্যারামিটার ব্যবহার করতে পারবেন না।

তার বদলে ফাংশন প্যারামিটারের আসল ডিফল্ট ভ্যালু ব্যবহার করুন। নইলে এটি অসংগত হবে।

যেমন, এটি অনুমোদিত নয়:

q: Annotated[str, Query(default="rick")] = "morty"

...কারণ ডিফল্ট ভ্যালু "rick" হবে নাকি "morty" তা স্পষ্ট নয়।

তাই আপনি ব্যবহার করবেন (প্রাধান্য দিয়ে):

q: Annotated[str, Query()] = "rick"

...অথবা পুরোনো কোডবেসে আপনি দেখবেন:

q: str = Query(default="rick")

Annotated-এর সুবিধা¶

ফাংশন প্যারামিটারে ডিফল্ট ভ্যালুর বদলে Annotated ব্যবহার করার পরামর্শ দেওয়া হয়, এটি একাধিক কারণে ভালো। 🤓

ফাংশন প্যারামিটারের ডিফল্ট ভ্যালুই হলো আসল ডিফল্ট ভ্যালু, যা সাধারণভাবে Python-এর সাথে আরও সহজবোধ্য। 😌

আপনি একই ফাংশন FastAPI ছাড়া অন্য জায়গায় কল করতে পারবেন, আর এটি প্রত্যাশামতো কাজ করবে। যদি কোনো আবশ্যক প্যারামিটার (ডিফল্ট ভ্যালু ছাড়া) থাকে, আপনার এডিটর একটি এরর দিয়ে আপনাকে জানাবে, আর আবশ্যক প্যারামিটার না দিয়ে চালালে Python-ও আপত্তি জানাবে।

আপনি যখন Annotated ব্যবহার না করে (পুরোনো) ডিফল্ট ভ্যালু স্টাইল ব্যবহার করেন, তখন ওই ফাংশন FastAPI ছাড়া অন্য জায়গায় কল করলে সঠিকভাবে কাজ করার জন্য ফাংশনে আর্গুমেন্টগুলো দেওয়ার কথা আপনাকে মনে রাখতে হবে, নইলে ভ্যালুগুলো আপনার প্রত্যাশার চেয়ে আলাদা হবে (যেমন str-এর বদলে QueryInfo বা এরকম কিছু)। আর আপনার এডিটর আপত্তি জানাবে না, Python-ও ওই ফাংশন চালাতে আপত্তি জানাবে না, কেবল ভেতরের অপারেশনগুলোতে এরর হলেই সমস্যা ধরা পড়বে।

যেহেতু Annotated-এ একাধিক মেটাডেটা অ্যানোটেশন থাকতে পারে, তাই এখন আপনি একই ফাংশন অন্যান্য টুলের সাথেও ব্যবহার করতে পারেন, যেমন Typer। 🚀

আরও ভ্যালিডেশন যোগ করুন¶

আপনি একটি min_length প্যারামিটারও যোগ করতে পারেন:

from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/items/")
async def read_items(
    q: Annotated[str | None, Query(min_length=3, max_length=50)] = None,
):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results

রেগুলার এক্সপ্রেশন যোগ করুন¶

আপনি একটি রেগুলার এক্সপ্রেশন pattern সংজ্ঞায়িত করতে পারেন যার সাথে প্যারামিটারটিকে মিলতে হবে:

from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/items/")
async def read_items(
    q: Annotated[
        str | None, Query(min_length=3, max_length=50, pattern="^fixedquery$")
    ] = None,
):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results

এই নির্দিষ্ট রেগুলার এক্সপ্রেশন প্যাটার্নটি যাচাই করে যে প্রাপ্ত প্যারামিটার ভ্যালু:

  • ^: নিচের অক্ষরগুলো দিয়ে শুরু হয়, এর আগে কোনো অক্ষর নেই।
  • fixedquery: হুবহু fixedquery ভ্যালু ধারণ করে।
  • $: সেখানেই শেষ হয়, fixedquery-এর পরে আর কোনো অক্ষর নেই।

এসব "রেগুলার এক্সপ্রেশন" ধারণা নিয়ে আপনি দিশেহারা বোধ করলে চিন্তা করবেন না। অনেকের কাছেই এটি একটি কঠিন বিষয়। রেগুলার এক্সপ্রেশন ছাড়াও আপনি এখনো অনেক কিছু করতে পারবেন।

এখন আপনি জানেন যে যখনই এগুলো দরকার হবে, আপনি FastAPI-তে এগুলো ব্যবহার করতে পারবেন।

ডিফল্ট ভ্যালু¶

অবশ্যই আপনি None ছাড়া অন্য ডিফল্ট ভ্যালুও ব্যবহার করতে পারেন।

ধরা যাক আপনি q কুয়েরি প্যারামিটারটির min_length 3 এবং ডিফল্ট ভ্যালু "fixedquery" ঘোষণা করতে চান:

from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/items/")
async def read_items(q: Annotated[str, Query(min_length=3)] = "fixedquery"):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results

নোট

None-সহ যেকোনো টাইপের ডিফল্ট ভ্যালু থাকলে প্যারামিটারটি ঐচ্ছিক হয় (আবশ্যক নয়)।

আবশ্যক প্যারামিটার¶

যখন আমাদের আর কোনো ভ্যালিডেশন বা মেটাডেটা ঘোষণা করার দরকার নেই, তখন শুধু ডিফল্ট ভ্যালু ঘোষণা না করেই আমরা q কুয়েরি প্যারামিটারকে আবশ্যক করতে পারি, যেমন:

q: str

এটির বদলে:

q: str | None = None

কিন্তু এখন আমরা এটি Query দিয়ে ঘোষণা করছি, যেমন:

q: Annotated[str | None, Query(min_length=3)] = None

তাই Query ব্যবহারের সময় কোনো ভ্যালুকে আবশ্যক হিসেবে ঘোষণা করতে চাইলে, আপনি শুধু ডিফল্ট ভ্যালু ঘোষণা না করলেই হয়:

from typing import Annotated

from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/items/")
async def read_items(q: Annotated[str, Query(min_length=3)]):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results

কাস্টম ভ্যালিডেশন¶

এমন ক্ষেত্র থাকতে পারে যেখানে আপনাকে কিছু কাস্টম ভ্যালিডেশন করতে হবে যা ওপরে দেখানো প্যারামিটারগুলো দিয়ে করা যায় না।

সেসব ক্ষেত্রে আপনি একটি কাস্টম ভ্যালিডেটর ফাংশন ব্যবহার করতে পারেন, যা স্বাভাবিক ভ্যালিডেশনের পরে প্রয়োগ হয় (যেমন ভ্যালুটি একটি str কিনা তা ভ্যালিডেট করার পরে)।

Annotated-এর ভেতরে Pydantic-এর AfterValidator ব্যবহার করে আপনি এটি করতে পারেন।

পরামর্শ

Pydantic-এ BeforeValidator এবং অন্যান্যও আছে। 🤓

যেমন, এই কাস্টম ভ্যালিডেটরটি যাচাই করে যে আইটেম ID একটি ISBN বই নম্বরের জন্য isbn- দিয়ে, অথবা একটি IMDB মুভি URL ID-এর জন্য imdb- দিয়ে শুরু হয়েছে:

import random
from typing import Annotated

from fastapi import FastAPI
from pydantic import AfterValidator

app = FastAPI()

data = {
    "isbn-9781529046137": "The Hitchhiker's Guide to the Galaxy",
    "imdb-tt0371724": "The Hitchhiker's Guide to the Galaxy",
    "isbn-9781439512982": "Isaac Asimov: The Complete Stories, Vol. 2",
}


def check_valid_id(id: str):
    if not id.startswith(("isbn-", "imdb-")):
        raise ValueError('Invalid ID format, it must start with "isbn-" or "imdb-"')
    return id


@app.get("/items/")
async def read_items(
    id: Annotated[str | None, AfterValidator(check_valid_id)] = None,
):
    if id:
        item = data.get(id)
    else:
        id, item = random.choice(list(data.items()))
    return {"id": id, "name": item}

নোট

এটি Pydantic ভার্সন 2 বা তার ওপরে পাওয়া যায়। 😎

পরামর্শ

আপনার যদি এমন কোনো ধরনের ভ্যালিডেশন করতে হয় যাতে কোনো বাহ্যিক কম্পোনেন্টের সাথে যোগাযোগ করতে হয়, যেমন একটি ডেটাবেস বা অন্য কোনো API, তাহলে এর বদলে FastAPI ডিপেন্ডেন্সি ব্যবহার করা উচিত, যা আপনি পরে শিখবেন।

এই কাস্টম ভ্যালিডেটরগুলো এমন বিষয়ের জন্য যা রিকোয়েস্টে দেওয়া একই ডেটা দিয়ে শুধুমাত্র যাচাই করা যায়।

data.items() দিয়ে আমরা একটি ইটারেবল অবজেক্ট পাই, যাতে প্রতিটি ডিকশনারি আইটেমের কী ও ভ্যালু ধারণকারী টাপল থাকে।

list(data.items()) দিয়ে আমরা এই ইটারেবল অবজেক্টকে একটি যথাযথ list-এ রূপান্তর করি।

তারপর random.choice() দিয়ে আমরা লিস্ট থেকে একটি র‍্যান্ডম ভ্যালু পেতে পারি, অর্থাৎ আমরা (id, name)-সহ একটি টাপল পাই। এটি হবে এরকম কিছু: ("imdb-tt0371724", "The Hitchhiker's Guide to the Galaxy")।

from typing import Annotated

from fastapi import FastAPI
from pydantic import AfterValidator

app = FastAPI()

data = {
    "isbn-9781529046137": "The Hitchhiker's Guide to the Galaxy",
    "imdb-tt0371724": "The Hitchhiker's Guide to the Galaxy",
    "isbn-9781439512982": "Isaac Asimov: The Complete Stories, Vol. 2",
}


def check_valid_id(id: str):
    if not id.startswith(("isbn-", "imdb-")):
        raise ValueError('Invalid ID format, it must start with "isbn-" or "imdb-"')
    return id


@app.get("/items/")
async def read_items(
