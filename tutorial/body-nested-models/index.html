বডি - নেস্টেড মডেল¶

🌐 সহজ বাংলায় ব্যাখ্যাসহ সংস্করণ

এটি শুধু অনুবাদ নয়: প্রতিটি পেজে সহজ ভাষায় ব্যাখ্যা, বাস্তব জীবনের উদাহরণ, কোডের লাইন-ধরে-ধরে ব্যাখ্যা, সাধারণ ভুল আর শেষে সারসংক্ষেপ যোগ করা হয়েছে। 🤝

কোড, প্যারামিটারের নাম আর কমান্ড ইংরেজিতেই রাখা হয়েছে, কারণ এগুলো ঠিক এভাবেই লিখতে হয়। অচেনা শব্দের মানে জানতে মেনুর "শিখুন" অংশে "সহজ শব্দকোষ" পেজটি দেখুন।

এটি মানুষের নির্দেশনায় AI দিয়ে তৈরি, তাই কোথাও ভুল থাকতে পারে। সন্দেহ হলে মূল ইংরেজি সংস্করণ মিলিয়ে নিন। 🤖

ইংরেজি সংস্করণ

এই পেজে যা শিখবেন

  • মডেলের ভেতরে লিস্ট আর সেট রাখা।
  • একটি মডেলের ভেতরে আরেকটি মডেল (নেস্টেড বা স্তরে স্তরে সাজানো মডেল)।
  • HttpUrl-এর মতো বিশেষ টাইপ দিয়ে যাচাই।
  • বডি হিসেবে সরাসরি একটি লিস্ট বা ডিকশনারি গ্রহণ করা।

FastAPI দিয়ে যত গভীর স্তরেই সাজানো (নেস্টেড) মডেল হোক, সেগুলো সংজ্ঞায়িত, যাচাই, ডকুমেন্ট আর ব্যবহার করতে পারেন (Pydantic-এর কল্যাণে)।

"নেস্টেড" মানে একটির ভেতরে আরেকটি, যেমন রাশিয়ান পুতুলের ভেতরে পুতুল। একটি অর্ডারের ভেতরে অনেকগুলো পণ্য, প্রতিটি পণ্যের ভেতরে অনেকগুলো ছবি, এভাবে।

লিস্ট ফিল্ড¶

একটি অ্যাট্রিবিউটকে একটি সাব-টাইপ হিসেবে সংজ্ঞায়িত করতে পারেন। যেমন একটি Python list:

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: list = []


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item):
    results = {"item_id": item_id, "item": item}
    return results

এতে tags একটি লিস্ট হবে, যদিও লিস্টের উপাদানগুলোর টাইপ ঘোষণা করা হয়নি।

টাইপ প্যারামিটারসহ লিস্ট ফিল্ড¶

তবে ভেতরের টাইপ, বা "টাইপ প্যারামিটার"সহ লিস্ট ঘোষণার জন্য Python-এর একটি নির্দিষ্ট উপায় আছে:

টাইপ প্যারামিটারসহ একটি list ঘোষণা করুন¶

যেসব টাইপের টাইপ প্যারামিটার (ভেতরের টাইপ) থাকে, যেমন list, dict, tuple, সেগুলো ঘোষণা করতে তৃতীয় বন্ধনী [ আর ] দিয়ে ভেতরের টাইপ(গুলো) "টাইপ প্যারামিটার" হিসেবে দিন

my_list: list[str]

এটা পুরোপুরি টাইপ ঘোষণার স্ট্যান্ডার্ড Python সিনট্যাক্স।

ভেতরের টাইপসহ মডেলের অ্যাট্রিবিউটের জন্যও এই একই স্ট্যান্ডার্ড সিনট্যাক্স ব্যবহার করুন।

তাই আমাদের উদাহরণে tags-কে নির্দিষ্টভাবে একটি "স্ট্রিংয়ের লিস্ট" করা যায়:

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: list[str] = []


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item):
    results = {"item_id": item_id, "item": item}
    return results

সেট টাইপ¶

কিন্তু একটু ভাবলে বোঝা যায়, ট্যাগগুলো পুনরাবৃত্তি হওয়া উচিত নয়, সম্ভবত সেগুলো অনন্য (ইউনিক) স্ট্রিং হবে।

আর অনন্য জিনিসের সেটের জন্য Python-এর একটি বিশেষ ডেটা টাইপ আছে, set।

তাহলে tags-কে স্ট্রিংয়ের একটি সেট হিসেবে ঘোষণা করা যায়:

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item):
    results = {"item_id": item_id, "item": item}
    return results

এতে, পুনরাবৃত্ত ডেটাসহ রিকোয়েস্ট এলেও সেটি অনন্য জিনিসের একটি সেটে রূপান্তরিত হবে।

যেমন ক্লায়েন্ট "tags": ["বই", "নতুন", "বই"] পাঠালে আপনি পাবেন {"বই", "নতুন"}, দ্বিতীয় "বই" বাদ পড়ে যাবে।

আর যখনই ওই ডেটা আউটপুট দেবেন, উৎসে পুনরাবৃত্তি থাকলেও, এটি অনন্য জিনিসের সেট হিসেবেই আউটপুট হবে।

আর সেই অনুযায়ী এটি অ্যানোটেট / ডকুমেন্টও করা হবে।

নেস্টেড মডেল¶

একটি Pydantic মডেলের প্রতিটি অ্যাট্রিবিউটের একটি টাইপ আছে।

কিন্তু সেই টাইপ নিজেই আরেকটি Pydantic মডেল হতে পারে।

তাই নির্দিষ্ট অ্যাট্রিবিউটের নাম, টাইপ আর যাচাইসহ অনেক গভীর স্তরে সাজানো JSON "অবজেক্ট" ঘোষণা করতে পারেন।

এসবই, যত খুশি স্তরে।

একটি সাব-মডেল সংজ্ঞায়িত করুন¶

যেমন, আমরা একটি Image মডেল সংজ্ঞায়িত করতে পারি:

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class Image(BaseModel):
    url: str
    name: str


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()
    image: Image | None = None


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item):
    results = {"item_id": item_id, "item": item}
    return results

সাব-মডেলটিকে টাইপ হিসেবে ব্যবহার করুন¶

তারপর এটিকে একটি অ্যাট্রিবিউটের টাইপ হিসেবে ব্যবহার করতে পারি:

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class Image(BaseModel):
    url: str
    name: str


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()
    image: Image | None = None


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item):
    results = {"item_id": item_id, "item": item}
    return results

এর মানে FastAPI এরকম একটি বডি আশা করবে:

{
    "name": "Foo",
    "description": "The pretender",
    "price": 42.0,
    "tax": 3.2,
    "tags": ["rock", "metal", "bar"],
    "image": {
        "url": "http://example.com/baz.jpg",
        "name": "The Foo live"
    }
}

কোডটি সহজ ভাষায়

  • লাইন ৭-৯: Image মডেল, যাতে আছে একটি url আর একটি name।
  • লাইন ১৮: image: Image | None = None: Item-এর ভেতরে একটি ঐচ্ছিক image, যার আকার Image মডেলের মতো।
  • তাই JSON-এ "image" কী-এর ভেতরে আরেকটি অবজেক্ট ({"url": ..., "name": ...}) থাকে, আর FastAPI সেটিরও যাচাই করে। image-এর ভেতরে name না থাকলে এরর আসবে, আর এররের loc-এ লেখা থাকবে ["body", "image", "name"], মানে ঠিক কোন স্তরে সমস্যা।

আবারও, শুধু ওই ঘোষণাটুকু দিয়েই FastAPI-তে পাবেন:

  • এডিটরের সাহায্য (কমপ্লিশন ইত্যাদি), নেস্টেড মডেলের ক্ষেত্রেও
  • ডেটা রূপান্তর
  • ডেটা যাচাই
  • স্বয়ংক্রিয় ডকুমেন্টেশন

বিশেষ টাইপ ও যাচাই¶

str, int, float ইত্যাদির মতো সাধারণ একক টাইপ ছাড়াও আরও জটিল একক টাইপ ব্যবহার করতে পারেন, যেগুলো str থেকে ইনহেরিট করে।

আপনার কাছে কী কী অপশন আছে তা দেখতে Pydantic-এর টাইপের সারসংক্ষেপ দেখুন। পরের অধ্যায়ে কিছু উদাহরণ দেখবেন।

যেমন, Image মডেলে যেহেতু একটি url ফিল্ড আছে, তাই এটিকে str-এর বদলে Pydantic-এর HttpUrl-এর একটি ইনস্ট্যান্স হিসেবে ঘোষণা করতে পারি:

from fastapi import FastAPI
from pydantic import BaseModel, HttpUrl

app = FastAPI()


class Image(BaseModel):
    url: HttpUrl
    name: str


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()
    image: Image | None = None


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item):
    results = {"item_id": item_id, "item": item}
    return results

স্ট্রিংটি একটি বৈধ URL কিনা তা যাচাই করা হবে, এবং JSON Schema / OpenAPI-তেও সেভাবেই ডকুমেন্ট করা হবে।

যেমন "url": "hello" পাঠালে এরর আসবে, কিন্তু "url": "https://example.com/photo.jpg" ঠিক আছে।

সাব-মডেলের লিস্টসহ অ্যাট্রিবিউট¶

list, set ইত্যাদির সাব-টাইপ হিসেবেও Pydantic মডেল ব্যবহার করতে পারেন:

from fastapi import FastAPI
from pydantic import BaseModel, HttpUrl

app = FastAPI()


class Image(BaseModel):
    url: HttpUrl
    name: str


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()
    images: list[Image] | None = None


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item):
    results = {"item_id": item_id, "item": item}
    return results

এটি এমন একটি JSON বডি আশা করবে (রূপান্তর, যাচাই, ডকুমেন্ট ইত্যাদি করবে):

{
    "name": "Foo",
    "description": "The pretender",
    "price": 42.0,
    "tax": 3.2,
    "tags": [
        "rock",
        "metal",
        "bar"
    ],
    "images": [
        {
            "url": "http://example.com/baz.jpg",
            "name": "The Foo live"
        },
        {
            "url": "http://example.com/dave.jpg",
            "name": "The Baz"
        }
    ]
}

নোট

খেয়াল করুন, images কী-তে এখন ছবির অবজেক্টের একটি লিস্ট আছে।

গভীরভাবে নেস্টেড মডেল¶

যত গভীর স্তরেই চান, নেস্টেড মডেল সংজ্ঞায়িত করতে পারেন:

from fastapi import FastAPI
from pydantic import BaseModel, HttpUrl

app = FastAPI()


class Image(BaseModel):
    url: HttpUrl
    name: str


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()
    images: list[Image] | None = None


class Offer(BaseModel):
    name: str
    description: str | None = None
    price: float
    items: list[Item]


@app.post("/offers/")
async def create_offer(offer: Offer):
    return offer

নোট

খেয়াল করুন, Offer-এ Item-এর একটি লিস্ট আছে, আর সেগুলোর প্রতিটিতে আবার Image-এর একটি ঐচ্ছিক লিস্ট আছে।

উদাহরণ দিয়ে বুঝি

এটা একটি দোকানের "ঈদ অফার"-এর মতো:

  • Offer (অফার): নাম, বিবরণ, দাম, আর কয়েকটি পণ্যের তালিকা (items)।
  • প্রতিটি Item (পণ্য): নাম, দাম, ট্যাগ, আর কয়েকটি ছবির তালিকা (images)।
  • প্রতিটি Image (ছবি): URL আর নাম।

তিন স্তরের এই পুরো কাঠামো FastAPI একসাথে যাচাই করে।

শুধু লিস্টের বডি¶

আপনি যে JSON বডি আশা করছেন তার সবচেয়ে ওপরের মানটি যদি একটি JSON array (একটি Python list) হয়, তাহলে Pydantic মডেলের মতোই ফাংশনের প্যারামিটারে টাইপটি ঘোষণা করতে পারেন:

images: list[Image]

যেমন:

from fastapi import FastAPI
from pydantic import BaseModel, HttpUrl

app = FastAPI()


class Image(BaseModel):
    url: HttpUrl
    name: str


@app.post("/images/multiple/")
async def create_multiple_images(images: list[Image]):
    return images

এখানে বডিটি নিজেই একটি তালিকা, যেমন [{"url": "...", "name": "a"}, {"url": "...", "name": "b"}]। একসাথে অনেকগুলো ছবি আপলোডের তথ্য পাঠানোর মতো ক্ষেত্রে এটা কাজে লাগে।

সব জায়গায় এডিটরের সাহায্য¶

আর আপনি সব জায়গায় এডিটরের সাহায্য পান।

এমনকি লিস্টের ভেতরের জিনিসগুলোর ক্ষেত্রেও:

Pydantic মডেলের বদলে সরাসরি dict নিয়ে কাজ করলে এমন এডিটর সাহায্য পেতেন না।

তবে সেগুলো নিয়েও চিন্তা করতে হবে না, আসা ডিকশনারিগুলো স্বয়ংক্রিয়ভাবে রূপান্তরিত হয়, আর আপনার আউটপুটও স্বয়ংক্রিয়ভাবে JSON-এ রূপান্তরিত হয়।

যেকোনো dict-এর বডি¶

একটি বডিকে এমন একটি dict হিসেবেও ঘোষণা করতে পারেন, যার কী-গুলো এক টাইপের আর মানগুলো অন্য টাইপের।

এভাবে আপনাকে আগে থেকে জানতে হবে না বৈধ ফিল্ড/অ্যাট্রিবিউটের নামগুলো কী (যেমনটা Pydantic মডেলের ক্ষেত্রে হয়)।

যেসব কী আপনি আগে থেকে জানেন না, সেগুলো গ্রহণ করতে চাইলে এটি কাজে লাগবে।

আরেকটি কাজের ক্ষেত্র হলো যখন আপনি অন্য টাইপের কী চান (যেমন int)।

সেটিই আমরা এখানে দেখব।

এই ক্ষেত্রে, যেকোনো dict গ্রহণ করবেন, যতক্ষণ এর কী-গুলো int আর মানগুলো float:

from fastapi import FastAPI

app = FastAPI()


@app.post("/index-weights/")
async def create_index_weights(weights: dict[int, float]):
    return weights

পরামর্শ

মনে রাখবেন, JSON কী হিসেবে কেবল str সাপোর্ট করে।

কিন্তু Pydantic-এর স্বয়ংক্রিয় ডেটা রূপান্তর আছে।

এর মানে, আপনার API-এর ক্লায়েন্টরা কী হিসেবে কেবল স্ট্রিং পাঠাতে পারলেও, যতক্ষণ সেই স্ট্রিংগুলোতে শুধু পূর্ণসংখ্যা থাকে, Pydantic সেগুলো রূপান্তর আর যাচাই করবে।

আর weights হিসেবে আপনি যে dict পাবেন সেটিতে আসলে int কী আর float মান থাকবে।

যেমন ক্লায়েন্ট পাঠাল {"1": 0.5, "2": 0.8}, আপনি পাবেন {1: 0.5, 2: 0.8}।

সংক্ষেপে¶

FastAPI-তে আপনি Pydantic মডেলের দেওয়া সর্বোচ্চ নমনীয়তা পান, অথচ কোড থাকে সহজ, ছোট আর সুন্দর।

আর সাথে সব সুবিধা:

  • এডিটরের সাহায্য (সব জায়গায় কমপ্লিশন!)
  • ডেটা রূপান্তর (পার্সিং / সিরিয়ালাইজেশন নামেও পরিচিত)
  • ডেটা যাচাই
  • স্কিমা ডকুমেন্টেশন
  • স্বয়ংক্রিয় ডকুমেন্টেশন

সংক্ষেপে মনে রাখুন

  • লিস্ট: list[str], অনন্য মানের সংগ্রহ: set[str]।
  • একটি মডেলকে আরেকটি মডেলের অ্যাট্রিবিউটের টাইপ হিসেবে দিলেই নেস্টেড মডেল হয়ে যায়।
  • মডেলের লিস্ট: list[Image]।
  • URL যাচাই করতে HttpUrl এর মতো বিশেষ টাইপ ব্যবহার করুন।
  • অজানা কী-ওয়ালা ডেটার জন্য dict[int, float] এর মতো টাইপ।
