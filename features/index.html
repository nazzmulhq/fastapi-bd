বৈশিষ্ট্যসমূহ¶

🌐 সহজ বাংলায় ব্যাখ্যাসহ সংস্করণ

এটি শুধু অনুবাদ নয়: প্রতিটি পেজে সহজ ভাষায় ব্যাখ্যা, বাস্তব জীবনের উদাহরণ, কোডের লাইন-ধরে-ধরে ব্যাখ্যা, সাধারণ ভুল আর শেষে সারসংক্ষেপ যোগ করা হয়েছে। 🤝

কোড, প্যারামিটারের নাম আর কমান্ড ইংরেজিতেই রাখা হয়েছে, কারণ এগুলো ঠিক এভাবেই লিখতে হয়। অচেনা শব্দের মানে জানতে মেনুর "শিখুন" অংশে "সহজ শব্দকোষ" পেজটি দেখুন।

এটি মানুষের নির্দেশনায় AI দিয়ে তৈরি, তাই কোথাও ভুল থাকতে পারে। সন্দেহ হলে মূল ইংরেজি সংস্করণ মিলিয়ে নিন। 🤖

ইংরেজি সংস্করণ

এই পেজে যা জানবেন

  • FastAPI কী কী সুবিধা দেয়, আর প্রতিটি সুবিধা বাস্তবে আপনার কী কাজে আসে।
  • FastAPI কোন দুটি লাইব্রেরির (Starlette আর Pydantic) ওপর দাঁড়িয়ে আছে, আর তাদের কাছ থেকে কী পায়।

নতুন হলে চিন্তা নেই: প্রতিটি অংশে সহজ ব্যাখ্যা দেওয়া আছে, আর অচেনা শব্দের জন্য সহজ শব্দকোষ দেখুন।

FastAPI-এর বৈশিষ্ট্য¶

FastAPI আপনাকে নিচের সুবিধাগুলো দেয়:

খোলা স্ট্যান্ডার্ডের ওপর ভিত্তি করে¶

  • API তৈরির জন্য OpenAPI, যার মধ্যে আছে পাথ অপারেশন, প্যারামিটার, রিকোয়েস্ট বডি, নিরাপত্তা ইত্যাদির ঘোষণা।
  • JSON Schema দিয়ে ডেটা মডেলের স্বয়ংক্রিয় ডকুমেন্টেশন (কারণ OpenAPI নিজেই JSON Schema-র ওপর ভিত্তি করে তৈরি)।
  • যত্নশীল গবেষণার পরে এই স্ট্যান্ডার্ডগুলোকে কেন্দ্র করেই ডিজাইন করা। পরে ওপরে জুড়ে দেওয়া কোনো স্তর হিসেবে নয়।
  • এর ফলে অনেক ভাষায় স্বয়ংক্রিয়ভাবে ক্লায়েন্ট কোড তৈরি করাও সম্ভব হয়।

এর মানে আপনার জন্য কী

"স্ট্যান্ডার্ড" মানে সবাই মেনে চলে এমন নিয়ম, যেমন সব মোবাইল চার্জারে USB-C। যেহেতু FastAPI OpenAPI মেনে চলে, তাই হাজারো তৈরি টুল (ডকস পেজ, Postman, SDK জেনারেটর) আপনার API কোনো বাড়তি কাজ ছাড়াই বুঝতে পারে।

স্বয়ংক্রিয় ডকস¶

ইন্টারঅ্যাকটিভ API ডকুমেন্টেশন আর ঘুরে দেখার ওয়েব ইউজার ইন্টারফেস। যেহেতু ফ্রেমওয়ার্কটি OpenAPI-এর ওপর ভিত্তি করে, তাই একাধিক অপশন আছে, ডিফল্টভাবে ২টি যুক্ত।

  • Swagger UI, ইন্টারঅ্যাকটিভভাবে ঘুরে দেখার সুবিধাসহ, সরাসরি ব্রাউজার থেকে আপনার API কল আর টেস্ট করুন।

  • ReDoc দিয়ে বিকল্প API ডকুমেন্টেশন।

(অর্থাৎ কোড লিখলেই /docs আর /redoc ঠিকানায় সুন্দর ডকুমেন্টেশন তৈরি হয়ে যায়, আলাদা করে লিখতে হয় না।)

শুধু আধুনিক Python¶

এটি পুরোটাই স্ট্যান্ডার্ড Python টাইপ ঘোষণার ওপর ভিত্তি করে তৈরি (Pydantic-কে ধন্যবাদ)। নতুন কোনো সিনট্যাক্স শেখার দরকার নেই। শুধু স্ট্যান্ডার্ড আধুনিক Python।

Python টাইপ কীভাবে ব্যবহার করতে হয় তা ২ মিনিটে ঝালিয়ে নিতে চাইলে (এমনকি FastAPI ব্যবহার না করলেও), ছোট টিউটোরিয়ালটি দেখুন: Python টাইপ।

আপনি টাইপসহ স্ট্যান্ডার্ড Python লেখেন:

from datetime import date

from pydantic import BaseModel

# একটি ভেরিয়েবলকে str হিসেবে ঘোষণা করুন
# আর ফাংশনের ভেতরে এডিটরের সাহায্য পান
def main(user_id: str):
    return user_id


# একটি Pydantic মডেল
class User(BaseModel):
    id: int
    name: str
    joined: date

তারপর এটি এভাবে ব্যবহার করা যায়:

my_user: User = User(id=3, name="John Doe", joined="2018-07-19")

second_user_data = {
    "id": 4,
    "name": "Mary",
    "joined": "2018-11-30",
}

my_second_user: User = User(**second_user_data)

নোট

**second_user_data মানে:

second_user_data ডিকশনারির key আর value-গুলো সরাসরি key-value আর্গুমেন্ট হিসেবে দাও, যা এর সমতুল্য: User(id=4, name="Mary", joined="2018-11-30")

এডিটর সাপোর্ট¶

পুরো ফ্রেমওয়ার্কটি ব্যবহারে সহজ আর স্বাভাবিক হওয়ার জন্য ডিজাইন করা হয়েছে। সেরা ডেভেলপমেন্ট অভিজ্ঞতা নিশ্চিত করতে, ডেভেলপমেন্ট শুরুর আগেই সব সিদ্ধান্ত একাধিক এডিটরে পরীক্ষা করা হয়েছিল।

Python ডেভেলপারদের জরিপে স্পষ্ট যে সবচেয়ে বেশি ব্যবহৃত ফিচারগুলোর একটি হলো "autocompletion" (লেখার সময় এডিটর নিজেই বাকিটা প্রস্তাব করা)।

পুরো FastAPI ফ্রেমওয়ার্ক সেটি পূরণ করার জন্য ডিজাইন করা। সব জায়গায় autocompletion কাজ করে।

আপনাকে কদাচিৎ ডকসে ফিরে আসতে হবে।

আপনার এডিটর কীভাবে আপনাকে সাহায্য করতে পারে:

  • PyCharm-এ:

এমন কোডেও completion পাবেন যা আগে হয়তো অসম্ভব ভাবতেন। যেমন, রিকোয়েস্ট থেকে আসা একটি JSON বডির (যা নেস্টেড হতে পারত) ভেতরের price key।

আর ভুল key-এর নাম লেখা, বারবার ডকসে আসা-যাওয়া, বা শেষ পর্যন্ত username লিখেছিলেন নাকি user_name তা খুঁজতে ওপর-নিচ স্ক্রল করা, এসব আর নয়।

সংক্ষিপ্ত¶

সব কিছুর জন্য যুক্তিসঙ্গত ডিফল্ট আছে, আর সব জায়গায় ঐচ্ছিক কনফিগারেশন। আপনার যা দরকার তা করতে আর যে API দরকার তা নির্ধারণ করতে সব প্যারামিটার সূক্ষ্মভাবে ঠিক করে নেওয়া যায়।

কিন্তু ডিফল্টভাবে, সবকিছু "এমনিতেই কাজ করে"।

যাচাই (Validation)¶

  • বেশিরভাগ (নাকি সব?) Python ডেটা টাইপের যাচাই, যার মধ্যে আছে:

    • JSON অবজেক্ট (dict)।
    • আইটেমের টাইপ নির্ধারণসহ JSON অ্যারে (list)।
    • সর্বনিম্ন আর সর্বোচ্চ দৈর্ঘ্য নির্ধারণসহ স্ট্রিং (str) ফিল্ড।
    • সর্বনিম্ন আর সর্বোচ্চ মানসহ সংখ্যা (int, float), ইত্যাদি।

  • আরও বিশেষ ধরনের টাইপের যাচাই, যেমন:

    • URL।
    • Email।
    • UUID।
    • ...এবং আরও।

সব যাচাই সামলায় সুপ্রতিষ্ঠিত আর মজবুত Pydantic।

এর মানে আপনার জন্য কী

ধরুন কেউ বয়সের ঘরে "বিশ" লিখে পাঠাল, অথচ আপনি চেয়েছিলেন সংখ্যা। FastAPI নিজেই ধরে ফেলবে আর ক্লায়েন্টকে স্পষ্ট এরর বার্তা দেবে, আপনার কোড পর্যন্ত ভুল ডেটা পৌঁছাবেই না। এই যাচাইয়ের জন্য আপনাকে একটি if লিখতেও হয় না, শুধু টাইপ (age: int) লিখলেই হয়।

নিরাপত্তা আর অথেনটিকেশন¶

নিরাপত্তা আর অথেনটিকেশন সমন্বিত। ডেটাবেস বা ডেটা মডেল নিয়ে কোনো আপস ছাড়াই।

OpenAPI-তে সংজ্ঞায়িত সব নিরাপত্তা স্কিম, যার মধ্যে আছে:

  • HTTP Basic।
  • OAuth2 (JWT টোকেন-সহও)। JWT-সহ OAuth2 টিউটোরিয়ালটি দেখুন।
  • API key, যা থাকতে পারে:
    • হেডারে।
    • কোয়েরি প্যারামিটারে।
    • কুকিতে, ইত্যাদি।

সাথে Starlette-এর সব নিরাপত্তা ফিচার (সেশন কুকি-সহ)।

সবই পুনরায় ব্যবহারযোগ্য টুল আর কম্পোনেন্ট হিসেবে তৈরি, যা আপনার সিস্টেম, ডেটা স্টোর, রিলেশনাল আর NoSQL ডেটাবেস ইত্যাদির সাথে সহজে যুক্ত করা যায়।

ডিপেন্ডেন্সি ইনজেকশন¶

FastAPI-তে একটি অত্যন্ত সহজে ব্যবহারযোগ্য, কিন্তু অত্যন্ত শক্তিশালী ডিপেন্ডেন্সি ইনজেকশন ব্যবস্থা আছে।

  • এমনকি ডিপেন্ডেন্সিরও ডিপেন্ডেন্সি থাকতে পারে, যা একটি স্তরবিন্যাস বা ডিপেন্ডেন্সির "গ্রাফ" তৈরি করে।
  • সবই ফ্রেমওয়ার্ক স্বয়ংক্রিয়ভাবে সামলায়।
  • সব ডিপেন্ডেন্সি রিকোয়েস্ট থেকে ডেটা চাইতে পারে আর পাথ অপারেশনের শর্ত ও স্বয়ংক্রিয় ডকুমেন্টেশন বাড়াতে পারে।
  • ডিপেন্ডেন্সিতে সংজ্ঞায়িত পাথ অপারেশন প্যারামিটারেরও স্বয়ংক্রিয় যাচাই।
  • জটিল ইউজার অথেনটিকেশন ব্যবস্থা, ডেটাবেস সংযোগ ইত্যাদির সাপোর্ট।
  • ডেটাবেস, ফ্রন্টএন্ড ইত্যাদি নিয়ে কোনো আপস নেই। বরং সবগুলোর সাথে সহজ সংযোগ।

উদাহরণ দিয়ে বুঝি

ডিপেন্ডেন্সি ইনজেকশন হলো রেস্টুরেন্টের রাঁধুনির সহকারীদের মতো। রাঁধুনি (আপনার পাথ অপারেশন) শুধু বলে "আমার কাটা পেঁয়াজ আর গরম তেল লাগবে", আর সহকারীরা (ডিপেন্ডেন্সি) সেগুলো প্রস্তুত করে হাতে দেয়। প্রতিটি রান্নায় একই সহকারী আবার কাজে লাগানো যায়। FastAPI-তে "লগইন করা ইউজার দাও" বা "ডেটাবেস সংযোগ দাও" এভাবেই লেখা হয়: Depends(get_current_user)।

সীমাহীন "প্লাগ-ইন"¶

অথবা, অন্যভাবে বললে, এগুলোর দরকারই নেই, আপনার যে কোড দরকার তা ইমপোর্ট করে ব্যবহার করুন।

যেকোনো সংযোগ (ডিপেন্ডেন্সি দিয়ে) এতটাই সহজে ব্যবহারের জন্য ডিজাইন করা যে, আপনার পাথ অপারেশনে ব্যবহৃত একই কাঠামো আর সিনট্যাক্স দিয়ে মাত্র ২ লাইনের কোডে আপনার অ্যাপ্লিকেশনের জন্য একটি "প্লাগ-ইন" তৈরি করতে পারেন।

Starlette-এর বৈশিষ্ট্য¶

FastAPI Starlette-এর সাথে সম্পূর্ণ মানানসই (আর এর ওপর ভিত্তি করে তৈরি)। তাই আপনার কাছে থাকা যেকোনো বাড়তি Starlette কোডও কাজ করবে।

FastAPI আসলে Starlette-এর একটি সাব-ক্লাস। তাই যদি আপনি আগে থেকেই Starlette জানেন বা ব্যবহার করেন, বেশিরভাগ কার্যকারিতা একইভাবে কাজ করবে।

FastAPI দিয়ে আপনি Starlette-এর সব বৈশিষ্ট্য পান (কারণ FastAPI হলো আরও শক্তিশালী করা Starlette):

  • সত্যিই চমকপ্রদ পারফরম্যান্স। এটি উপলব্ধ দ্রুততম Python ফ্রেমওয়ার্কগুলোর একটি, NodeJS আর Go-এর সমপর্যায়ের।
  • WebSocket সাপোর্ট।
  • একই প্রসেসে ব্যাকগ্রাউন্ড টাস্ক।
  • চালু আর বন্ধ হওয়ার ইভেন্ট।
  • HTTPX-এর ওপর তৈরি টেস্ট ক্লায়েন্ট।
  • CORS, GZip, স্ট্যাটিক ফাইল, স্ট্রিমিং রেসপন্স।
  • সেশন আর কুকি সাপোর্ট।
  • ১০০% টেস্ট কভারেজ।
  • ১০০% টাইপ অ্যানোটেটেড কোডবেস।

সহজ ভাষায়

Starlette হলো FastAPI-এর "ইঞ্জিন": রিকোয়েস্ট গ্রহণ, রাউটিং, WebSocket, middleware এর মতো ওয়েবের মূল কাজগুলো এটি করে। FastAPI তার ওপর টাইপ, যাচাই, ডকস আর ডিপেন্ডেন্সি ইনজেকশন যোগ করে।

Pydantic-এর বৈশিষ্ট্য¶

FastAPI Pydantic-এর সাথে সম্পূর্ণ মানানসই (আর এর ওপর ভিত্তি করে তৈরি)। তাই আপনার কাছে থাকা যেকোনো বাড়তি Pydantic কোডও কাজ করবে।

এর মধ্যে আছে Pydantic-এর ওপর ভিত্তি করে তৈরি বাইরের লাইব্রেরিগুলোও, যেমন ডেটাবেসের জন্য ORM আর ODM।

এর মানে আরও, অনেক ক্ষেত্রে রিকোয়েস্ট থেকে পাওয়া একই অবজেক্ট আপনি সরাসরি ডেটাবেসে দিতে পারেন, কারণ সবকিছু স্বয়ংক্রিয়ভাবে যাচাই করা হয়।

উল্টো দিকেও একই কথা প্রযোজ্য, অনেক ক্ষেত্রে ডেটাবেস থেকে পাওয়া অবজেক্ট আপনি সরাসরি ক্লায়েন্টকে দিতে পারেন।

FastAPI দিয়ে আপনি Pydantic-এর সব বৈশিষ্ট্য পান (কারণ সব ডেটা সামলানোর জন্য FastAPI Pydantic-এর ওপর নির্ভর করে):

  • মাথা খারাপ করার কিছু নেই:
    • নতুন কোনো স্কিমা-সংজ্ঞার ছোট ভাষা শিখতে হয় না।
    • Python টাইপ জানলে আপনি Pydantic ব্যবহার করতে জানেন।
  • আপনার IDE/linter/মস্তিষ্কের সাথে চমৎকার মানিয়ে চলে:
    • কারণ Pydantic ডেটা স্ট্রাকচার শুধু আপনার সংজ্ঞায়িত ক্লাসের ইনস্ট্যান্স; তাই যাচাই করা ডেটার সাথে autocompletion, linting, mypy আর আপনার অন্তর্জ্ঞান সবই ঠিকঠাক কাজ করবে।
  • জটিল কাঠামো যাচাই করুন:
    • স্তরবিন্যস্ত Pydantic মডেল, Python typing-এর List আর Dict ইত্যাদির ব্যবহার।
    • আর validator দিয়ে জটিল ডেটা স্কিমা স্পষ্ট আর সহজভাবে সংজ্ঞায়িত, যাচাই আর JSON Schema হিসেবে ডকুমেন্ট করা যায়।
    • গভীরভাবে নেস্টেড JSON অবজেক্ট রাখতে পারেন, আর সবগুলোই যাচাই আর অ্যানোটেট করা থাকবে।
  • বাড়ানো যায়:
    • Pydantic কাস্টম ডেটা টাইপ সংজ্ঞায়িত করতে দেয়, অথবা validator ডেকোরেটর দিয়ে সাজানো মডেলের মেথড দিয়ে যাচাই বাড়াতে পারেন।
  • ১০০% টেস্ট কভারেজ।

সহজ ভাষায়

Pydantic হলো FastAPI-এর "ডেটা পরীক্ষক": আপনি একটি ক্লাসে লিখে দেন ডেটা দেখতে কেমন হবে (নাম str, বয়স int), আর Pydantic আসা ডেটা যাচাই করে, রূপান্তর করে, আর JSON-এ বদলায়। FastAPI এই ক্লাস দেখেই ডকুমেন্টেশনও তৈরি করে।

সংক্ষেপে মনে রাখুন

  • FastAPI = Starlette (ওয়েবের ইঞ্জিন) + Pydantic (ডেটা যাচাই) + টাইপ-ভিত্তিক সহজ লেখা।
  • শুধু Python টাইপ লিখলেই যাচাই, রূপান্তর, এডিটরে autocompletion আর /docs ডকুমেন্টেশন সব একসাথে পান।
  • নিরাপত্তা, ডিপেন্ডেন্সি ইনজেকশন, WebSocket, টেস্ট ক্লায়েন্ট সব তৈরি অবস্থায় আছে।
