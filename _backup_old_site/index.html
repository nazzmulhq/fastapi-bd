শিখুন - FastAPI¶

এখানে রয়েছে FastAPI শেখার পূর্ণাঙ্গ ১০৭টি বিষয়ভিত্তিক ধারাবাহিক টিউটোরিয়াল ও রেফারেন্স।

আপনি এটিকে একটি বই 📖, একটি পূর্ণাঙ্গ কোর্স 🎓, এবং FastAPI শেখার অফিসিয়াল ও সর্বাধিক সুপারিশকৃত উপায় হিসেবে বিবেচনা করতে পারেন। 😎

বামের সাইডবারে অফিশিয়াল ডকুমেন্টেশনের অনুরূপ FastAPI Tutorial, Dependencies, Security, Other Tutorial Topics, Advanced, Deployment এবং Reference-এর সম্পূর্ণ ১০৭টি বিষয় সাজানো হয়েছে। যেকোনো শিরোনামে ক্লিক করে সরাসরি সেই বিষয়ে যেতে পারেন।

FastAPI টিউটোরিয়াল - ইউজার গাইড (Tutorial)¶

১. প্রথম পদক্ষেপ (First Steps)

সবচেয়ে সহজ একটি FastAPI ফাইল তৈরি করা যাক। একটি নতুন ফাইল main.py তৈরি করুন:

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "স্বাগতম! এটি আমাদের প্রথম FastAPI অ্যাপ্লিকেশন"}

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "স্বাগতম! এটি আমাদের প্রথম FastAPI অ্যাপ্লিকেশন"}

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "স্বাগতম! এটি আমাদের প্রথম FastAPI অ্যাপ্লিকেশন"}

২. পাথ প্যারামিটার (Path Parameters)

পাথ থেকে সরাসরি ভেরিয়েবল গ্রহণ করতে ফরম্যাট স্ট্রিং সিনট্যাক্স ব্যবহার করুন:

@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}

৩. কুয়েরি প্যারামিটার (Query Parameters)

যেসব প্যারামিটার পাথে ডিক্লেয়ার করা নেই, সেগুলো কুয়েরি প্যারামিটার হিসেবে গণ্য হয়:

@app.get("/items/")
async def read_items(skip: int = 0, limit: int = 10):
    return {"skip": skip, "limit": limit}

৪. রিকোয়েস্ট বডি (Request Body)

ক্লায়েন্ট থেকে JSON ডেটা গ্রহণ করতে Pydantic BaseModel ব্যবহার করুন:

from pydantic import BaseModel

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float

@app.post("/items/")
async def create_item(item: Item):
    return item

৫. কুয়েরি প্যারামিটার ও স্ট্রিং ভ্যালিডেশন (String Validations)

Query() ফাংশন ব্যবহার করে min_length, max_length, এবং রেগুলার এক্সপ্রেশন pattern প্রয়োগ করা যায়:

from fastapi import Query

@app.get("/items/")
async def read_items(q: str | None = Query(default=None, min_length=3, max_length=50)):
    return {"q": q}

৬. পাথ প্যারামিটার ও নিউমেরিক ভ্যালিডেশন (Numeric Validations)

Path() ব্যবহার করে ge (Greater than or equal) এবং le (Less than or equal) সংখ্যা ভ্যালিডেশন:

from fastapi import Path

@app.get("/items/{item_id}")
async def read_item(item_id: int = Path(title="আইটেম আইডি", ge=1, le=1000)):
    return {"item_id": item_id}

৭. কুয়েরি প্যারামিটার মডেল (Query Parameter Models)

একাধিক কুয়েরি প্যারামিটারকে একটি Pydantic মডেলে গুছিয়ে নিতে পারেন:

class FilterParams(BaseModel):
    limit: int = 100
    offset: int = 0
    order_by: str = "created_at"

@app.get("/items/")
async def read_items(: FilterParams = Query()):
    return {"params": filter_query}

৮. বডি – একাধিক প্যারামিটার (Body – Multiple Parameters)

একই এন্ডপয়েন্টে একাধিক বডি মডেল বা প্রাইমিটিভ বডি প্যারামিটার (Body()) একসাথে গ্রহণ করা যায়:

from fastapi import Body

@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item, importance: int = Body(gt=0)):
    return {"item_id": item_id, "item": item, "importance": importance}

৯. বডি – ফিল্ডস (Body – Fields)

Pydantic মডেলে Field() ব্যবহার করে ফিল্ড লেভেলে ভ্যালিডেশন এবং মেটাডাটা যুক্ত করুন:

from pydantic import Field

class Item(BaseModel):
    name: str
    description: str | None = Field(default=None, max_length=300)
    price: float = Field(gt=0, description="মূল্য শূন্যের বেশি হতে হবে")

১০. বডি – নেস্টেড মডেল (Body – Nested Models)

গভীরভাবে নেস্টেড JSON স্কিমা সমর্থন করে:

class Image(BaseModel):
    url: str
    name: str

class Item(BaseModel):
    name: str
    image: Image | None = None

১১. রিকোয়েস্ট এক্সাম্পল ডেটা (Declare Example Data)

সোয়েগার ডক্সে মডেলের উদাহরণ প্রদর্শন করতে examples=[{"name": "Foo", "price": 35.4}] যুক্ত করুন।

১২. অতিরিক্ত ডেটা টাইপস (Extra Data Types)

UUID, datetime, date, timedelta, frozenset, bytes সরাসরি সমর্থন করে।

১৩. কুকি প্যারামিটার (Cookie Parameters)

Cookie() ব্যবহার করে ব্রাউজারের সেশন কুকি রিড করুন: ads_id: str | None = Cookie(default=None)।

১৪. হেডার প্যারামিটার (Header Parameters)

Header() ব্যবহার করে রিকোয়েস্ট হেডার রিড করুন: user_agent: str | None = Header(default=None)।

১৫. কুকি প্যারামিটার মডেল & ১৬. হেডার প্যারামিটার মডেল

কুকি এবং হেডার সমূহকে Pydantic মডেলে গ্রুপ করে ডিক্লেয়ার করার সুবিধা।

১৭. রেসপন্স মডেল – রিটার্ন টাইপ (Response Model)

পাথ অপারেশনের আউটপুট ফিল্টার এবং ভ্যালিডেট করতে response_model=ItemOut ডিক্লেয়ার করুন। পাসওয়ার্ড বা সংবেদনশীল ফিল্ড স্বয়ংক্রিয়ভাবে ফিল্টার হয়ে যাবে।

১৮. অতিরিক্ত মডেলস & ১৯. রেসপন্স স্ট্যাটাস কোড

এইচটিটিপি স্ট্যাটাস কোড যেমন status_code=status.HTTP_201_CREATED নির্ধারণের নিয়মাবলী।

২০. ফর্ম ডেটা & ২১. ফর্ম মডেলস (Form Data & Models)

Form() ব্যবহার করে application/x-www-form-urlencoded ডেটা পার্সিং।

২২. রিকোয়েস্ট ফাইলস & ২৩. ফর্মস ও ফাইলস (Request Files)

UploadFile এবং File() দিয়ে নিরাপদ ও মেমোরি-দক্ষ ফাইল আপলোড।

২৪. এরর হ্যান্ডলিং (Handling Errors)

raise HTTPException(status_code=404, detail="আইটেম পাওয়া যায়নি") দ্বারা পরিষ্কার JSON এরর রেসপন্স প্রদান।

২৫. পাথ অপারেশন কনফিগারেশন

tags=["আইটেমস"], summary="আইটেম তৈরি", description="বিস্তারিত বিবরণ" এবং deprecated=True।

২৬. JSON কম্প্যাটিবল এনকোডার

jsonable_encoder() ফাংশন দিয়ে যেকোনো জটিল অবজেক্ট বা ডেটাটাইমকে JSON-উপযোগী ডিকশনারিতে রূপান্তর।

২৭. বডি – আপডেটস (Body – Updates)

PATCH মেথড দিয়ে আংশিক ডেটা আপডেট করার জন্য item.model_dump(exclude_unset=True) প্যাটার্ন।

ডিপেন্ডেন্সিস (Dependencies - Topics 28 to 33)¶

২৮. ডিপেন্ডেন্সিস পরিচিতি (Dependencies)

FastAPI-এর সবচেয়ে শক্তিশালী বৈশিষ্ট্য হলো এর ডিপেন্ডেন্সি ইনজেকশন সিস্টেম Depends()।

from fastapi import Depends, FastAPI

app = FastAPI()

async def common_params(q: str | None = None, skip: int = 0, limit: int = 100):
    return {"q": q, "skip": skip, "limit": limit}

@app.get("/items/")
async def read_items(commons: dict = Depends(common_params)):
    return commons

২৯. ক্লাস ডিপেন্ডেন্সি (Classes as Dependencies)

ফাংশনের পরিবর্তে পাইথন ক্লাসকে সরাসরি ডিপেন্ডেন্সি হিসেবে ব্যবহার করা যায়: Depends(CommonQueryParams)।

৩০. সাব-ডিপেন্ডেন্সিস (Sub-dependencies)

একটি ডিপেন্ডেন্সি অন্য আরেকটি ডিপেন্ডেন্সির ওপর নির্ভর করতে পারে। FastAPI স্বয়ংক্রিয়ভাবে একটি নির্ভরতার ট্রি তৈরি করে সমাধান করে।

৩১. পাথ অপারেশন ডেকোরেটরে ডিপেন্ডেন্সিস

যদি রিটার্ন ভ্যালুর প্রয়োজন না থাকে তবে সরাসরি ডেকোরেটরে যুক্ত করুন: @app.get("/items/", dependencies=[Depends(verify_token)])।

৩২. গ্লোবাল ডিপেন্ডেন্সিস (Global Dependencies)

পুরো অ্যাপ্লিকেশনের প্রতিটি রাউটে একবারে প্রয়োগ করতে: app = FastAPI(dependencies=[Depends(verify_key)])।

৩৩. `yield` সহ ডিপেন্ডেন্সিস (Dependencies with yield)

ডাটাবেস কানেকশন খোলা এবং রিকোয়েস্ট শেষে তা বন্ধ (cleanup) করার জন্য পাইথনের yield ব্যবহার:

async def get_db():
    db = DBSession()
    try:
        yield db
    finally:
        db.close()

সিকিউরিটি ও প্রমাণীকরণ (Security - Topics 34 to 37)¶

৩৪. সিকিউরিটি – প্রথম পদক্ষেপ (Security First Steps)

FastAPI-তে রয়েছে স্ট্যান্ডার্ড OAuth2PasswordBearer ইন্টিগ্রেশন যা সোয়েগার ডক্সে অথেনটিকেশন বাটন যোগ করে।

৩৫. বর্তমান ব্যবহারকারী যাচাই (Get Current User)

ইনকামিং রিকোয়েস্টের টোকেন ডিকোড করে ডেটাবেস থেকে ব্যবহারকারী তথ্য রিড করার সাধারণ ডিপেন্ডেন্সি।

৩৬. সিম্পল OAuth2 Password ও Bearer

ইউজারনেম ও পাসওয়ার্ড দিয়ে অথেনটিকেশন এবং ক্লায়েন্টকে Bearer টোকেন রিটার্ন।

৩৭. OAuth2 Hashing & JWT Tokens

Passlib / bcrypt দিয়ে পাসওয়ার্ড হ্যাশ করা এবং PyJWT দিয়ে নিরাপদ সইযুক্ত এক্সেস টোকেন তৈরি ও যাচাই।

অন্যান্য টিউটোরিয়াল বিষয় (Topics 38 to 49)¶

৩৮. মিডলওয়্যার (Middleware)

প্রতিটি রিকোয়েস্ট প্রসেস হওয়ার আগে এবং রেসপন্স ফেরত পাঠানোর পরে কাস্টম লজিক রান করা:

@app.middleware("http")
async def add_process_time_header(request, call_next):
    response = await call_next(request)
    response.headers["X-Process-Time"] = "0.001s"
    return response

৩৯. CORS (Cross-Origin Resource Sharing)

অন্য ডোমেইন বা পোর্ট (যেমন React বা Vue ফ্রন্টএন্ড) থেকে এপিআই অ্যাক্সেস করার অনুমতি প্রদান:

from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

৪০. SQL রিলেশনাল ডাটাবেস (SQL Databases)

SQLAlchemy এবং SQLModel ব্যবহার করে PostgreSQL, MySQL বা SQLite ডাটাবেসে ডেটা সংরক্ষণ ও কোয়েরি।

৪১. বড় অ্যাপ্লিকেশন – একাধিক ফাইল (Multiple Files)

APIRouter ব্যবহার করে প্রজেক্টকে বিভিন্ন মডিউল বা প্যাকেজে সুশৃঙ্খলভাবে বিভক্ত করা।

৪২. স্ট্রিম JSON লাইনস (Stream JSON Lines)

বড় ডেটাসেট একসাথে মেমোরিতে না এনে লাইন-বাই-লাইন ক্লায়েন্টে স্ট্রিম করে পাঠানো।

৪৩. সার্ভার-সেন্ট ইভেন্টস (SSE)

রিয়েল-টাইম একমুখী ইভেন্ট ব্রডকাস্ট করার প্রযুক্তি।

৪৪. ব্যাকগ্রাউন্ড টাস্ক (Background Tasks)

BackgroundTasks অবজেক্টের সাহায্যে ইমেইল পাঠানো বা লগ লেখার মতো কাজগুলো রেসপন্স শেষ হওয়ার পর ব্যাকগ্রাউন্ডে সম্পন্ন করা।

৪৫. মেটাডাটা ও ডক্স ইউআরএল (Metadata & Docs)

Swagger UI-এর টাইটেল, ডেসক্রিপশন, লাইসেন্স, টার্মস অফ সার্ভিস এবং ট্যাগ ডেসক্রিপশন কাস্টমাইজ করা।

৪৬. ফ্রন্টএন্ড & ৪৭. স্ট্যাটিক ফাইলস (Static Files)

StaticFiles মাউন্ট করে CSS, JavaScript এবং ইমেজ ফাইল সরবরাহ করা।

৪৮. টেস্টিং & ৪৯. ডিবাগিং (Testing with pytest)

pytest এবং httpx.AsyncClient ব্যবহার করে এপিআই-এর অটোমেটেড ইউনিট ও ইন্টিগ্রেশন টেস্ট পরিচালনা।

অ্যাডভান্সড গাইড (Advanced User Guide - Topics 50 to 82)¶

এই বিভাগে FastAPI-এর গভীর ও উন্নত আর্কিটেকচারাল ফিচারসমূহ অন্তর্ভুক্ত রয়েছে:

  • ৫০. Stream Data: মেমোরি ছাড়াই অডিও, ভিডিও বা বড় ডেটা স্ট্রিম করা।
  • ৫১. Path Operation Advanced Config: OpenAPI অপারেশন আইডি, রুট নেম এবং কাস্টম স্কিমা মেটাডাটা।
  • ৫২. Additional Status Codes: OpenAPI-তে একাধিক ভিন্ন এরর স্ট্যাটাস কোড ও রেসপন্স মডেল ডিক্লেয়ার করা।
  • ৫৩-৫৪. Direct & Custom Response: সরাসরি HTMLResponse, PlainTextResponse, বা বাইনারি রেসপন্স ফেরত দেওয়া।
  • ৫৫-৫৮. Response Cookies & Headers: রেসপন্সে কাস্টম কুকি সেট করা এবং হেডার পরিবর্তন করা।
  • ৫৯-৬০. Advanced Dependencies & OAuth2 Scopes: সূক্ষ্ম পারমিশন কন্ট্রোল ও স্কোপ ম্যানেজমেন্ট।
  • ৬১. HTTP Basic Auth: সাধারণ ব্রাউজার পপআপ বেসিক অথেনটিকেশন।
  • ৬২-৬৩. Request Object & Dataclasses: সরাসরি Starlette রিকোয়েস্ট অবজেক্ট ও পাইথন dataclass সমর্থন।
  • ৬৪-৬৬. Advanced Middleware, Sub-Apps & Proxies: সাব-অ্যাপ্লিকেশন মাউন্ট করা এবং রিভার্স প্রক্সি হ্যান্ডলিং।
  • ৬৭-৬৮. Templates & WebSockets: Jinja2 এইচটিএমএল টেমপ্লেটিং এবং দ্বিমুখী রিয়েল-টাইম ওয়েবসকেট কমিউনিকেশন।
  • ৬৯-৭৪. Lifespan, Testing Overrides & Async Tests: আধুনিক লাইফস্প্যান হ্যান্ডলার এবং অ্যাসিঙ্ক টেস্ট স্যুট।
  • ৭৫-৮২. Settings, OpenAPI Callbacks & Strict Types: pydantic-settings দিয়ে এনভায়রনমেন্ট ভেরিয়েবল লোড এবং উন্নত টাইপ সেফটি।

ডিপ্লয়মেন্ট গাইড (Deployment - Topics 83 to 90)¶

প্রোডাকশনে FastAPI অ্যাপ্লিকেশন স্থাপন করার পদ্ধতি:

  • ৮৩. About FastAPI Versions: সেম্যান্টিক ভার্সনিং এবং আপগ্রেড নিরাপত্তা।
  • ৮৪. FastAPI Cloud: অফিশিয়াল ক্লাউড প্ল্যাটফর্মে এক ক্লিকে অ্যাপ্লিকেশন ডিপ্লয়।
  • ৮৫. About HTTPS: TLS/SSL সার্টিফিকেট ও নিরাপদ ট্রাফিক এনক্রিপশন।
  • ৮৬-৮৭. Run a Server Manually & Concepts: প্রোডাকশনে পোর্ট বাইন্ডিং, প্রসেস ম্যানেজার এবং রিসোর্স অ্যালোকেশন।
  • ৮৮. Cloud Providers: AWS, Google Cloud, DigitalOcean, Railway ও Render-এ স্থাপনের নির্দেশিকা।
  • ৮৯. Server Workers: মাল্টিপল সিপিইউ কোর ব্যবহারের জন্য Uvicorn Workers: uvicorn main:app --workers 4।
  • ৯০. Docker Containers: অফিশিয়াল ডকার বেস ইমেজ এবং কনটেইনারাইজড ডিপ্লয়মেন্ট।
