Python টাইপের পরিচিতি¶

🌐 সহজ বাংলায় ব্যাখ্যাসহ সংস্করণ

এটি শুধু অনুবাদ নয়: প্রতিটি পেজে সহজ ভাষায় ব্যাখ্যা, বাস্তব জীবনের উদাহরণ, কোডের লাইন-ধরে-ধরে ব্যাখ্যা, সাধারণ ভুল আর শেষে সারসংক্ষেপ যোগ করা হয়েছে। 🤝

কোড, প্যারামিটারের নাম আর কমান্ড ইংরেজিতেই রাখা হয়েছে, কারণ এগুলো ঠিক এভাবেই লিখতে হয়। অচেনা শব্দের মানে জানতে মেনুর "শিখুন" অংশে "সহজ শব্দকোষ" পেজটি দেখুন।

এটি মানুষের নির্দেশনায় AI দিয়ে তৈরি, তাই কোথাও ভুল থাকতে পারে। সন্দেহ হলে মূল ইংরেজি সংস্করণ মিলিয়ে নিন। 🤖

ইংরেজি সংস্করণ

এই পেজে যা শিখবেন

  • "টাইপ হিন্ট" কী, আর কেন এটি লিখলে কোড লেখা সহজ হয়।
  • str, int, list, dict এর মতো টাইপ কীভাবে লিখতে হয়।
  • একটি মান "এটা অথবা ওটা" বা "হয়তো কিছুই না" (None) হলে কীভাবে লিখবেন।
  • Pydantic মডেল কী, আর Annotated কী।
  • FastAPI কীভাবে এই টাইপগুলো দেখে আপনার অনেক কাজ নিজেই করে দেয়।

Python-এ ঐচ্ছিকভাবে "টাইপ হিন্ট" (type hints) লেখার সুবিধা আছে। এগুলোকে "টাইপ অ্যানোটেশন"-ও বলা হয়।

এই "টাইপ হিন্ট" হলো একটি বিশেষ লেখার ধরন, যা দিয়ে একটি ভেরিয়েবলের টাইপ ঘোষণা করা যায়। টাইপ মানে ডেটার ধরন: টেক্সট (str), পূর্ণসংখ্যা (int), দশমিক সংখ্যা (float), সত্য/মিথ্যা (bool) ইত্যাদি।

ভেরিয়েবলের টাইপ লিখে দিলে আপনার এডিটর ও অন্যান্য টুল আপনাকে আরও ভালোভাবে সাহায্য করতে পারে।

এটি Python টাইপ হিন্ট নিয়ে একটি ছোট টিউটোরিয়াল বা ঝালিয়ে নেওয়া মাত্র। এখানে FastAPI-তে ব্যবহারের জন্য যতটুকু দরকার কেবল ততটুকুই আছে... যা আসলে খুবই সামান্য।

FastAPI পুরোপুরি এই টাইপ হিন্টের ওপর তৈরি। এগুলো থেকেই FastAPI তার বেশিরভাগ সুবিধা পায়।

তবে আপনি কখনো FastAPI ব্যবহার না করলেও এগুলো একটু শিখে রাখলে লাভবান হবেন।

নোট

আপনি যদি Python-এ দক্ষ হন এবং টাইপ হিন্ট সম্পর্কে সবকিছু আগে থেকেই জানেন, তাহলে পরের অধ্যায়ে চলে যান।

কেন দরকার¶

একটি সহজ উদাহরণ দিয়ে শুরু করা যাক:

def get_full_name(first_name, last_name):
    full_name = first_name.title() + " " + last_name.title()
    return full_name


print(get_full_name("john", "doe"))

প্রোগ্রামটি চালালে আউটপুট আসে:

John Doe

ফাংশনটি যা করে:

  • একটি first_name আর একটি last_name নেয়।
  • title() দিয়ে প্রতিটির প্রথম অক্ষর বড় হাতের (ক্যাপিটাল) করে। যেমন "john" হয়ে যায় "John"।
  • মাঝখানে একটি স্পেস দিয়ে দুটিকে জোড়া লাগায়।
def get_full_name(first_name, last_name):
    full_name = first_name.title() + " " + last_name.title()
    return full_name


print(get_full_name("john", "doe"))

কোডটি সহজ ভাষায়

  • লাইন ১: get_full_name নামে একটি ফাংশন, যা দুটি ইনপুট নেয়।
  • লাইন ২ (হাইলাইট করা): দুটি নামের প্রথম অক্ষর বড় করে মাঝে স্পেস দিয়ে জোড়া হলো। + চিহ্ন টেক্সট জোড়া লাগায়।
  • লাইন ৩: ফলাফল ফেরত দেওয়া হলো।
  • লাইন ৬: "john" ও "doe" দিয়ে ফাংশনটি ডেকে ফলাফল প্রিন্ট করা হলো, তাই দেখায় John Doe।

লিখতে গিয়ে সমস্যা¶

এটি খুবই সহজ একটি প্রোগ্রাম।

কিন্তু এবার কল্পনা করুন, আপনি এটি একদম শুরু থেকে লিখছেন।

এক পর্যায়ে আপনি ফাংশনটি লেখা শুরু করেছেন, প্যারামিটারগুলোও তৈরি...

কিন্তু এবার আপনাকে "প্রথম অক্ষর বড় হাতের করার সেই মেথডটা" ডাকতে হবে।

ওটা কি upper ছিল? নাকি uppercase? first_uppercase? capitalize?

তখন আপনি প্রোগ্রামারদের পুরোনো বন্ধু, এডিটরের অটোকমপ্লিশন (লেখার সময় সাজেশন দেখানো) দিয়ে চেষ্টা করেন।

ফাংশনের প্রথম প্যারামিটার first_name লেখেন, তারপর একটি ডট (.), তারপর কমপ্লিশন দেখাতে Ctrl+Space চাপেন।

কিন্তু দুঃখের বিষয়, কাজের কিছুই আসে না:

কারণ এডিটর জানে না first_name কী ধরনের জিনিস। এটা টেক্সট নাকি সংখ্যা নাকি অন্য কিছু, এডিটরের কাছে কোনো তথ্য নেই। তাই কোন মেথডগুলো সাজেস্ট করবে, তাও জানে না।

টাইপ যোগ করুন¶

আগের কোডের শুধু একটি লাইন বদলানো যাক।

ঠিক এই অংশটুকু, মানে ফাংশনের প্যারামিটারগুলো, এটি থেকে:

    first_name, last_name

এটিতে বদলাব:

    first_name: str, last_name: str

ব্যাস, এটুকুই।

এগুলোই হলো "টাইপ হিন্ট"। first_name: str মানে "first_name একটি টেক্সট (string)":

def get_full_name(first_name: str, last_name: str):
    full_name = first_name.title() + " " + last_name.title()
    return full_name


print(get_full_name("john", "doe"))

এটি ডিফল্ট মান দেওয়ার মতো নয়, যেমনটা হতো এভাবে লিখলে:

    first_name="john", last_name="doe"

দুটো আলাদা জিনিস।

টাইপ হিন্টে আমরা কোলন (:) ব্যবহার করছি, সমান চিহ্ন (=) নয়। কোলন বলে "এটি কোন ধরনের", আর সমান চিহ্ন বলে "কিছু না দিলে এই মান নাও"।

আর সাধারণত টাইপ হিন্ট যোগ করলে প্রোগ্রাম চলার সময় কোনো পার্থক্য হয় না। Python নিজে এগুলো যাচাই করে না। এগুলো মূলত এডিটর আর টুলগুলোর জন্য তথ্য।

কিন্তু এবার আবার কল্পনা করুন, আপনি টাইপ হিন্টসহ ফাংশনটি লিখছেন।

একই জায়গায় Ctrl+Space দিয়ে অটোকমপ্লিট চালালে দেখবেন:

এবার আপনি স্ক্রল করে অপশনগুলো দেখতে পারেন, যতক্ষণ না পরিচিত মনে হয় এমন একটি পান:

উদাহরণ দিয়ে বুঝি

ধরুন আপনাকে একটি বাক্স দেওয়া হলো, কিন্তু গায়ে কিছু লেখা নেই। ভেতরে কী আছে না জেনে আপনি বুঝবেন না এটা দিয়ে কী করা যায়। বাক্সের গায়ে "বই" লেখা থাকলে সাথে সাথে বোঝেন: পড়া যায়, পাতা উল্টানো যায়। টাইপ হিন্ট হলো সেই লেবেল। এডিটর লেবেল দেখে বোঝে কোন কোন কাজ করা যাবে।

আরও একটি কারণ¶

এই ফাংশনটি দেখুন, এতে আগে থেকেই টাইপ হিন্ট আছে:

def get_name_with_age(name: str, age: int):
    name_with_age = name + " is this old: " + age
    return name_with_age

এডিটর যেহেতু ভেরিয়েবলগুলোর টাইপ জানে, তাই আপনি শুধু কমপ্লিশনই পান না, ভুল ধরার সুবিধাও পান:

এখানে সমস্যা হলো, age একটি সংখ্যা (int), আর টেক্সটের সাথে সরাসরি সংখ্যা + দিয়ে জোড়া যায় না। প্রোগ্রাম চালানোর আগেই এডিটর এটি দেখিয়ে দিল।

এখন আপনি জানেন যে এটি ঠিক করতে হবে। str(age) দিয়ে age-কে টেক্সটে রূপান্তর করুন:

def get_name_with_age(name: str, age: int):
    name_with_age = name + " is this old: " + str(age)
    return name_with_age

টাইপ ঘোষণা করা¶

টাইপ হিন্ট ঘোষণার প্রধান জায়গাটি আপনি এইমাত্র দেখলেন: ফাংশনের প্যারামিটার।

FastAPI-তেও আপনি মূলত এই জায়গাতেই এগুলো ব্যবহার করবেন।

সাধারণ টাইপ¶

শুধু str নয়, Python-এর সব সাধারণ টাইপই ঘোষণা করতে পারেন।

যেমন:

  • int: পূর্ণসংখ্যা, যেমন 5, -12।
  • float: দশমিক সংখ্যা, যেমন 3.14।
  • bool: সত্য বা মিথ্যা, True অথবা False।
  • bytes: কাঁচা বাইট ডেটা, যেমন ফাইলের ভেতরের ডেটা।
def get_items(item_a: str, item_b: int, item_c: float, item_d: bool, item_e: bytes):
    return item_a, item_b, item_c, item_d, item_e

typing মডিউল¶

কিছু বিশেষ ক্ষেত্রে আপনাকে Python-এর স্ট্যান্ডার্ড লাইব্রেরির typing মডিউল থেকে কিছু জিনিস ইমপোর্ট করতে হতে পারে। যেমন আপনি যদি বলতে চান কোনো কিছু "যেকোনো টাইপের" হতে পারে, তাহলে typing থেকে Any ব্যবহার করতে পারেন:

from typing import Any


def some_function(data: Any):
    print(data)

জেনেরিক টাইপ¶

কিছু টাইপ তৃতীয় বন্ধনীর ([ ]) ভেতরে "টাইপ প্যারামিটার" নিতে পারে, যা দিয়ে বলা যায় এর ভেতরে কী ধরনের জিনিস থাকবে। যেমন "স্ট্রিংয়ের একটি লিস্ট" লেখা হয় list[str]।

যেসব টাইপ এভাবে টাইপ প্যারামিটার নিতে পারে, সেগুলোকে বলে জেনেরিক টাইপ বা জেনেরিক।

Python-এর এই বিল্ট-ইন টাইপগুলো জেনেরিক হিসেবে (তৃতীয় বন্ধনী আর ভেতরে টাইপসহ) ব্যবহার করা যায়:

  • list: তালিকা, ক্রম অনুযায়ী সাজানো।
  • tuple: নির্দিষ্ট সংখ্যক জিনিসের অপরিবর্তনীয় তালিকা।
  • set: সেট, যেখানে একই জিনিস দুবার থাকে না।
  • dict: ডিকশনারি, "কী: মান" জোড়ার সংগ্রহ।

লিস্ট¶

যেমন, একটি ভেরিয়েবলকে str-এর একটি list হিসেবে সংজ্ঞায়িত করা যাক।

একই কোলন (:) দিয়ে ভেরিয়েবলটি ঘোষণা করুন।

টাইপ হিসেবে লিখুন list।

লিস্ট যেহেতু এমন একটি টাইপ যার ভেতরে আরও কিছু টাইপ থাকে, তাই সেগুলো তৃতীয় বন্ধনীর ভেতরে লিখুন:

def process_items(items: list[str]):
    for item in items:
        print(item)

নোট

তৃতীয় বন্ধনীর ভেতরের ওই টাইপগুলোকে বলে "টাইপ প্যারামিটার"।

এই ক্ষেত্রে str হলো list-কে দেওয়া টাইপ প্যারামিটার।

এর মানে: "items ভেরিয়েবলটি একটি list, আর এই লিস্টের প্রতিটি জিনিস একটি str"।

এটি লিখলে লিস্টের জিনিসগুলো নিয়ে কাজ করার সময়েও আপনার এডিটর সাহায্য করতে পারে:

টাইপ ছাড়া এটা প্রায় অসম্ভব।

লক্ষ করুন, item ভেরিয়েবলটি items লিস্টের একটি উপাদান।

তবুও এডিটর জানে এটি একটি str, এবং সেই অনুযায়ী সাহায্য করে। কারণ আপনি বলে দিয়েছেন লিস্টের প্রতিটি জিনিস str।

টাপল ও সেট¶

tuple ও set ঘোষণা করতেও একই কাজ করবেন:

def process_items(items_t: tuple[int, int, str], items_s: set[bytes]):
    return items_t, items_s

এর মানে:

  • items_t ভেরিয়েবলটি ৩টি জিনিসের একটি tuple: একটি int, আরেকটি int, আর একটি str। টাপলে প্রতিটি অবস্থানের টাইপ আলাদা করে লেখা যায়।
  • items_s ভেরিয়েবলটি একটি set, এবং এর প্রতিটি জিনিস bytes টাইপের।

ডিকশনারি¶

একটি dict সংজ্ঞায়িত করতে কমা দিয়ে আলাদা করে ২টি টাইপ প্যারামিটার দিন।

প্রথম টাইপ প্যারামিটারটি dict-এর কী-গুলোর (keys) জন্য।

দ্বিতীয় টাইপ প্যারামিটারটি dict-এর মানগুলোর (values) জন্য:

def process_items(prices: dict[str, float]):
    for item_name, item_price in prices.items():
        print(item_name)
        print(item_price)

এর মানে:

  • prices ভেরিয়েবলটি একটি dict:
    • এই dict-এর কী-গুলো str টাইপের (ধরা যাক প্রতিটি জিনিসের নাম)।
    • এই dict-এর মানগুলো float টাইপের (ধরা যাক প্রতিটি জিনিসের দাম)।

যেমন {"কলম": 10.5, "খাতা": 45.0} এমন একটি ডিকশনারি।

ইউনিয়ন¶

আপনি ঘোষণা করতে পারেন যে একটি ভেরিয়েবল কয়েকটি টাইপের যেকোনো একটি হতে পারে, যেমন একটি int অথবা একটি str।

এটি লিখতে দুটি টাইপের মাঝে খাড়া দাগ (|) দিন। এখানে | মানে "অথবা"।

একে বলে "ইউনিয়ন", কারণ ভেরিয়েবলটি ওই দুই ধরনের টাইপের মিলিত সেটের যেকোনোটি হতে পারে।

def process_item(item: int | str):
    print(item)

এর মানে item একটি int অথবা একটি str হতে পারে।

হয়তো None¶

আপনি ঘোষণা করতে পারেন যে একটি মানের একটি টাইপ আছে, যেমন str, কিন্তু এটি None-ও হতে পারে। None মানে "কোনো মান নেই"।

def say_hi(name: str | None = None):
    if name is not None:
        print(f"Hey {name}!")
    else:
        print("Hello World")

কোডটি সহজ ভাষায়

  • name: str | None = None: name একটি টেক্সট হতে পারে, অথবা None। আর কিছু না দিলে এর মান হবে None।
  • if name is not None: যদি নাম দেওয়া থাকে, তাহলে Hey <নাম>! প্রিন্ট হবে।
  • নাহলে (else) প্রিন্ট হবে Hello World।

FastAPI-তে ঠিক এই ধরনটি দিয়েই ঐচ্ছিক প্যারামিটার বানানো হয়।

শুধু str-এর বদলে str | None লিখলে এডিটর সেই ভুলগুলো ধরতে সাহায্য করবে, যেখানে আপনি ধরে নিচ্ছেন মানটি সবসময় str, অথচ আসলে এটি None-ও হতে পারে।

ক্লাসকে টাইপ হিসেবে ব্যবহার¶

আপনি একটি ক্লাসকেও একটি ভেরিয়েবলের টাইপ হিসেবে ঘোষণা করতে পারেন।

ধরা যাক আপনার একটি Person ক্লাস আছে, যার একটি নাম আছে:

class Person:
    def __init__(self, name: str):
        self.name = name


def get_person_name(one_person: Person):
    return one_person.name

তারপর আপনি একটি ভেরিয়েবলকে Person টাইপের হিসেবে ঘোষণা করতে পারেন:

class Person:
    def __init__(self, name: str):
        self.name = name


def get_person_name(one_person: Person):
    return one_person.name

তারপর, আবারও, আপনি এডিটরের পুরো সাহায্য পান:

লক্ষ করুন, এর মানে হলো "one_person হলো Person ক্লাসের একটি ইনস্ট্যান্স", অর্থাৎ ওই ছাঁচ থেকে বানানো একজন নির্দিষ্ট মানুষ।

এর মানে এই নয় যে "one_person নিজেই Person নামের ক্লাস"।

উদাহরণ দিয়ে বুঝি

ক্লাস হলো বাড়ির নকশা (ব্লুপ্রিন্ট), আর ইনস্ট্যান্স হলো সেই নকশা দেখে বানানো একটি আসল বাড়ি। একটি নকশা থেকে অনেক বাড়ি বানানো যায়, প্রতিটির নিজস্ব ঠিকানা (এখানে নিজস্ব name)।

Pydantic মডেল¶

Pydantic হলো ডেটা যাচাই (ভ্যালিডেশন) করার একটি Python লাইব্রেরি।

আপনি ডেটার "আকার" ঘোষণা করেন অ্যাট্রিবিউটসহ ক্লাস হিসেবে।

আর প্রতিটি অ্যাট্রিবিউটের একটি টাইপ থাকে।

তারপর আপনি কিছু মান দিয়ে ওই ক্লাসের একটি ইনস্ট্যান্স বানান। Pydantic মানগুলো যাচাই করবে, দরকার হলে সঠিক টাইপে রূপান্তর করবে, এবং সব ডেটাসহ আপনাকে একটি অবজেক্ট দেবে।

আর সেই অবজেক্ট নিয়ে কাজ করার সময় আপনি এডিটরের পুরো সাহায্য পাবেন।

অফিসিয়াল Pydantic ডকুমেন্টেশনের একটি উদাহরণ:

from datetime import datetime

from pydantic import BaseModel


class User(BaseModel):
    id: int
    name: str = "John Doe"
    signup_ts: datetime | None = None
    friends: list[int] = []


external_data = {
    "id": "123",
    "signup_ts": "2017-06-01 12:22",
    "friends": [1, "2", b"3"],
}
user = User(**external_data)
print(user)
# > User id=123 name='John Doe' signup_ts=datetime.datetime(2017, 6, 1, 12, 22) friends=[1, 2, 3]
print(user.id)
# > 123

কোডটি সহজ ভাষায়

  • লাইন ৬-১০: User নামে একটি মডেল। এতে আছে:
    • id: int: আবশ্যক, পূর্ণসংখ্যা।
    • name: str = "John Doe": টেক্সট, না দিলে "John Doe"।
    • signup_ts: datetime | None = None: সাইনআপের সময়, ঐচ্ছিক।
    • friends: list[int] = []: বন্ধুদের আইডির তালিকা, না দিলে খালি তালিকা।
  • লাইন ১৩-১৭: বাইরে থেকে আসা ডেটা। লক্ষ করুন, "id" এখানে টেক্সট "123", সময়টাও টেক্সট, আর friends-এ মিশ্র জিনিস (1, "2", b"3")।
  • লাইন ১৮: User(**external_data) ডিকশনারির সব মান দিয়ে মডেল বানায়। (** মানে ডিকশনারির প্রতিটি "কী: মান" আলাদা আর্গুমেন্ট হিসেবে পাঠানো।)
  • লাইন ২০ ও ২২-এর মন্তব্য দেখায় ফলাফল: id হয়ে গেছে সংখ্যা 123, সময় হয়ে গেছে আসল datetime, আর friends হয়ে গেছে [1, 2, 3]। Pydantic নিজেই সব রূপান্তর করেছে।
  • যদি রূপান্তর সম্ভব না হতো (যেমন "id": "abc"), Pydantic একটি পরিষ্কার এরর দিত।

নোট

আরও জানতে Pydantic-এর ডকুমেন্টেশন দেখুন।

FastAPI পুরোপুরি Pydantic-এর ওপর তৈরি। রিকোয়েস্টের বডি যাচাই আর রেসপন্স তৈরিতে FastAPI ঠিক এই কাজটিই করে।

এসব বাস্তবে আরও অনেক বেশি দেখবেন টিউটোরিয়াল - ইউজার গাইডে।

মেটাডেটাসহ টাইপ হিন্ট (Annotated)¶

Python-এ Annotated ব্যবহার করে এই টাইপ হিন্টগুলোর সাথে অতিরিক্ত মেটাডেটা যোগ করার সুবিধাও আছে। মেটাডেটা মানে মূল জিনিসের সাথে জুড়ে দেওয়া বাড়তি তথ্য।

Annotated আপনি typing থেকে ইমপোর্ট করতে পারেন।

from typing import Annotated


def say_hello(name: Annotated[str, "this is just metadata"]) -> str:
    return f"Hello {name}"

Python নিজে এই Annotated দিয়ে কিছুই করে না। আর এডিটর ও অন্যান্য টুলের কাছে টাইপটি এখনো str।

কিন্তু Annotated-এর এই জায়গাটুকু ব্যবহার করে আপনি FastAPI-কে বাড়তি তথ্য দিতে পারেন যে আপনার অ্যাপ্লিকেশন কেমন আচরণ করুক। যেমন পরে দেখবেন, Annotated[str, Query(max_length=50)] লিখে বলা যায় "এটি একটি টেক্সট, আর এর দৈর্ঘ্য সর্বোচ্চ ৫০"।

মনে রাখার জরুরি বিষয় হলো, Annotated-কে দেওয়া প্রথম টাইপ প্যারামিটার-টিই হলো আসল টাইপ। বাকিগুলো অন্য টুলের জন্য কেবল মেটাডেটা।

আপাতত শুধু জেনে রাখুন যে Annotated আছে, এবং এটি স্ট্যান্ডার্ড Python। 😎

পরে দেখবেন এটি কতটা শক্তিশালী হতে পারে।

পরামর্শ

এটি স্ট্যান্ডার্ড Python হওয়ার মানে হলো, আপনার এডিটরে, কোড বিশ্লেষণ ও রিফ্যাক্টর করার টুলগুলোতে, আপনি তবুও সবচেয়ে ভালো ডেভেলপার অভিজ্ঞতা পাবেন। ✨

আর আপনার কোড অন্য অনেক Python টুল ও লাইব্রেরির সাথে খুব ভালোভাবে মিলে যাবে। 🚀

FastAPI-তে টাইপ হিন্ট¶

FastAPI এই টাইপ হিন্টগুলো কাজে লাগিয়ে অনেকগুলো কাজ করে।

FastAPI-তে টাইপ হিন্টসহ প্যারামিটার ঘোষণা করলে আপনি পান:

  • এডিটরের সাহায্য।
  • টাইপ যাচাই।

...আর FastAPI একই ঘোষণা ব্যবহার করে:

  • প্রয়োজনীয়তা নির্ধারণ করে: রিকোয়েস্টের পাথ প্যারামিটার, কুয়েরি প্যারামিটার, হেডার, বডি, ডিপেন্ডেন্সি ইত্যাদি থেকে কী কী লাগবে।
  • ডেটা রূপান্তর করে: রিকোয়েস্ট থেকে আসা ডেটাকে প্রয়োজনীয় টাইপে।
  • ডেটা যাচাই করে: প্রতিটি রিকোয়েস্টের সাথে আসা ডেটা:
    • ডেটা ভুল হলে ক্লায়েন্টকে স্বয়ংক্রিয় এরর পাঠায়।
  • OpenAPI ব্যবহার করে API-এর ডকুমেন্টেশন তৈরি করে:
    • যা পরে স্বয়ংক্রিয় ইন্টারঅ্যাকটিভ ডকুমেন্টেশনের পেজগুলো ব্যবহার করে।

এসব হয়তো এখন একটু বিমূর্ত শোনাচ্ছে। চিন্তা করবেন না। টিউটোরিয়াল - ইউজার গাইডে এসব হাতে-কলমে দেখবেন।

মূল কথা হলো, শুধু এক জায়গায় সাধারণ Python টাইপ ব্যবহার করে (আলাদা ক্লাস, ডেকোরেটর ইত্যাদি যোগ না করে) FastAPI আপনার অনেক কাজ করে দেবে।

নোট

আপনি যদি পুরো টিউটোরিয়াল শেষ করে টাইপ সম্পর্কে আরও জানতে ফিরে আসেন, তাহলে একটি ভালো উৎস হলো mypy-এর "চিট শিট"।

সংক্ষেপে মনে রাখুন

  • টাইপ হিন্ট লেখা হয় কোলন দিয়ে: name: str, age: int।
  • ভেতরে কী থাকবে তা বলতে তৃতীয় বন্ধনী: list[str], dict[str, float]।
  • "এটা অথবা ওটা" বলতে |: int | str। ঐচ্ছিক মান: str | None = None।
  • Pydantic মডেল (BaseModel থেকে তৈরি ক্লাস) ডেটা যাচাই ও রূপান্তর করে।
  • Annotated[টাইপ, বাড়তি তথ্য]-এ প্রথমটি আসল টাইপ, বাকিটা FastAPI-এর জন্য বাড়তি তথ্য।
  • FastAPI এই টাইপগুলো দেখেই যাচাই, রূপান্তর আর ডকুমেন্টেশনের কাজ করে।
