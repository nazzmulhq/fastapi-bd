Python টাইপ পরিচিতি¶

🌐 AI এবং মানুষের যৌথ অনুবাদ

এই অনুবাদটি মানুষের নির্দেশনায় AI দিয়ে করা হয়েছে। 🤝

এতে মূল অর্থ ভুল বোঝা বা অস্বাভাবিক শোনানোর মতো ভুল থাকতে পারে। 🤖

ইংরেজি সংস্করণ

Python-এ ঐচ্ছিক "টাইপ হিন্ট" (যাকে "টাইপ অ্যানোটেশন"-ও বলা হয়) সাপোর্ট করে।

এই "টাইপ হিন্ট" বা অ্যানোটেশন হলো একটি বিশেষ সিনট্যাক্স, যা দিয়ে একটি ভেরিয়েবলের টাইপ ঘোষণা করা যায়।

আপনার ভেরিয়েবলগুলোর টাইপ ঘোষণা করলে এডিটর ও টুলগুলো আপনাকে আরও ভালো সাপোর্ট দিতে পারে।

এটি Python টাইপ হিন্ট নিয়ে কেবল একটি ছোট টিউটোরিয়াল / ঝালাই। এতে FastAPI-এর সাথে এগুলো ব্যবহারের জন্য ন্যূনতম যতটুকু দরকার কেবল ততটুকুই আছে... যা আসলে খুবই সামান্য।

FastAPI পুরোটাই এই টাইপ হিন্টগুলোর ওপর ভিত্তি করে তৈরি, এগুলো একে অনেক সুবিধা ও উপকারিতা দেয়।

তবে আপনি কখনো FastAPI ব্যবহার না করলেও এগুলো সম্পর্কে একটু শিখে রাখলে উপকৃত হবেন।

নোট

আপনি যদি Python বিশেষজ্ঞ হন এবং টাইপ হিন্ট সম্পর্কে সবকিছু আগে থেকেই জানেন, তাহলে পরের অধ্যায়ে চলে যান।

প্রেরণা¶

একটি সহজ উদাহরণ দিয়ে শুরু করা যাক:

def get_full_name(first_name, last_name):
    full_name = first_name.title() + " " + last_name.title()
    return full_name


print(get_full_name("john", "doe"))

এই প্রোগ্রামটি চালালে আউটপুট আসে:

John Doe

ফাংশনটি নিচের কাজগুলো করে:

  • একটি first_name ও একটি last_name নেয়।
  • title() দিয়ে প্রতিটির প্রথম অক্ষর বড় হাতের করে।
  • মাঝখানে একটি স্পেস রেখে দুটিকে জোড়া লাগায়।
def get_full_name(first_name, last_name):
    full_name = first_name.title() + " " + last_name.title()
    return full_name


print(get_full_name("john", "doe"))

সম্পাদনা করুন¶

এটি খুবই সহজ একটি প্রোগ্রাম।

কিন্তু এবার কল্পনা করুন, আপনি এটি একদম শুরু থেকে লিখছেন।

একসময় আপনি ফাংশনটি সংজ্ঞায়িত করা শুরু করলেন, প্যারামিটারগুলোও তৈরি...

কিন্তু তারপর আপনাকে "সেই মেথডটি যেটা প্রথম অক্ষর বড় হাতের করে" কল করতে হবে।

সেটা কি upper ছিল? নাকি uppercase? first_uppercase? capitalize?

তখন আপনি প্রোগ্রামারের পুরোনো বন্ধু, এডিটরের অটোকমপ্লিশন দিয়ে চেষ্টা করলেন।

আপনি ফাংশনের প্রথম প্যারামিটার first_name লিখলেন, তারপর একটি ডট (.) দিলেন, তারপর কমপ্লিশন চালু করতে Ctrl+Space চাপলেন।

কিন্তু দুঃখের বিষয়, কাজের কিছুই পেলেন না:

টাইপ যোগ করুন¶

আগের ভার্সন থেকে শুধু একটি লাইন পরিবর্তন করা যাক।

আমরা ঠিক এই অংশটি, অর্থাৎ ফাংশনের প্যারামিটারগুলো পরিবর্তন করব, এটি থেকে:

    first_name, last_name

এটিতে:

    first_name: str, last_name: str

ব্যস।

এগুলোই হলো "টাইপ হিন্ট":

def get_full_name(first_name: str, last_name: str):
    full_name = first_name.title() + " " + last_name.title()
    return full_name


print(get_full_name("john", "doe"))

এটি ডিফল্ট ভ্যালু ঘোষণা করার মতো নয়, যেমনটা হতো এভাবে:

    first_name="john", last_name="doe"

এটি একটি ভিন্ন জিনিস।

আমরা কোলন (:) ব্যবহার করছি, সমান চিহ্ন (=) নয়।

আর টাইপ হিন্ট যোগ করলে সাধারণত যা ঘটত তার কোনো পরিবর্তন হয় না, টাইপ হিন্ট ছাড়াও ঠিক তাই ঘটত।

কিন্তু এবার কল্পনা করুন, আপনি আবার সেই ফাংশন তৈরির মাঝপথে আছেন, তবে এবার টাইপ হিন্টসহ।

একই জায়গায় এসে আপনি Ctrl+Space দিয়ে অটোকমপ্লিট চালু করার চেষ্টা করলেন এবং দেখলেন:

এর সাহায্যে আপনি অপশনগুলো দেখতে দেখতে স্ক্রল করতে পারেন, যতক্ষণ না এমন একটি পান যেটা দেখে "মনে পড়ে যায়":

আরও প্রেরণা¶

এই ফাংশনটি দেখুন, এতে আগে থেকেই টাইপ হিন্ট আছে:

def get_name_with_age(name: str, age: int):
    name_with_age = name + " is this old: " + age
    return name_with_age

যেহেতু এডিটর ভেরিয়েবলগুলোর টাইপ জানে, তাই আপনি শুধু কমপ্লিশনই পান না, এরর চেকও পান:

এখন আপনি জানেন যে এটি ঠিক করতে হবে, str(age) দিয়ে age-কে একটি স্ট্রিংয়ে রূপান্তর করুন:

def get_name_with_age(name: str, age: int):
    name_with_age = name + " is this old: " + str(age)
    return name_with_age

টাইপ ঘোষণা¶

আপনি এইমাত্র টাইপ হিন্ট ঘোষণা করার প্রধান জায়গাটি দেখলেন: ফাংশনের প্যারামিটার হিসেবে।

FastAPI-এর সাথেও এগুলো আপনি প্রধানত এখানেই ব্যবহার করবেন।

সাধারণ টাইপ¶

আপনি শুধু str নয়, সব স্ট্যান্ডার্ড Python টাইপ ঘোষণা করতে পারেন।

যেমন, আপনি ব্যবহার করতে পারেন:

  • int
  • float
  • bool
  • bytes
def get_items(item_a: str, item_b: int, item_c: float, item_d: bool, item_e: bytes):
    return item_a, item_b, item_c, item_d, item_e

typing মডিউল¶

কিছু অতিরিক্ত ক্ষেত্রে আপনাকে স্ট্যান্ডার্ড লাইব্রেরির typing মডিউল থেকে কিছু জিনিস ইম্পোর্ট করতে হতে পারে। যেমন, আপনি যখন ঘোষণা করতে চান যে কোনো কিছুর "যেকোনো টাইপ" হতে পারে, তখন typing থেকে Any ব্যবহার করতে পারেন:

from typing import Any


def some_function(data: Any):
    print(data)

জেনেরিক টাইপ¶

কিছু টাইপ তাদের ভেতরের টাইপ নির্ধারণ করতে বর্গাকার বন্ধনীতে "টাইপ প্যারামিটার" নিতে পারে। যেমন, "স্ট্রিংয়ের একটি লিস্ট" ঘোষণা করা হবে list[str] হিসেবে।

যেসব টাইপ টাইপ প্যারামিটার নিতে পারে, সেগুলোকে বলা হয় জেনেরিক টাইপ বা জেনেরিক।

একই বিল্টইন টাইপগুলো আপনি জেনেরিক হিসেবে ব্যবহার করতে পারেন (বর্গাকার বন্ধনী ও ভেতরে টাইপসহ):

  • list
  • tuple
  • set
  • dict

লিস্ট¶

যেমন, একটি ভেরিয়েবলকে str-এর একটি list হিসেবে সংজ্ঞায়িত করা যাক।

একই কোলন (:) সিনট্যাক্স দিয়ে ভেরিয়েবলটি ঘোষণা করুন।

টাইপ হিসেবে list দিন।

যেহেতু লিস্ট এমন একটি টাইপ যার ভেতরে কিছু টাইপ থাকে, সেগুলো বর্গাকার বন্ধনীতে দিন:

def process_items(items: list[str]):
    for item in items:
        print(item)

নোট

বর্গাকার বন্ধনীর ভেতরের ওই টাইপগুলোকে বলা হয় "টাইপ প্যারামিটার"।

এক্ষেত্রে str হলো list-এ পাঠানো টাইপ প্যারামিটার।

এর মানে: "items ভেরিয়েবলটি একটি list, এবং এই লিস্টের প্রতিটি আইটেম একটি str"।

এভাবে করলে লিস্টের আইটেমগুলো প্রসেস করার সময়ও আপনার এডিটর সাপোর্ট দিতে পারে:

টাইপ ছাড়া এটি অর্জন করা প্রায় অসম্ভব।

লক্ষ করুন, item ভেরিয়েবলটি items লিস্টের একটি উপাদান।

তবুও এডিটর জানে যে এটি একটি str, এবং সেই অনুযায়ী সাপোর্ট দেয়।

টাপল ও সেট¶

tuple ও set ঘোষণা করতেও আপনি একই কাজ করবেন:

def process_items(items_t: tuple[int, int, str], items_s: set[bytes]):
    return items_t, items_s

এর মানে:

  • items_t ভেরিয়েবলটি ৩টি আইটেমসহ একটি tuple: একটি int, আরেকটি int, এবং একটি str।
  • items_s ভেরিয়েবলটি একটি set, এবং এর প্রতিটি আইটেমের টাইপ bytes।

ডিক্ট¶

একটি dict সংজ্ঞায়িত করতে কমা দিয়ে আলাদা করা ২টি টাইপ প্যারামিটার দিন।

প্রথম টাইপ প্যারামিটারটি dict-এর কী-গুলোর জন্য।

দ্বিতীয় টাইপ প্যারামিটারটি dict-এর ভ্যালুগুলোর জন্য:

def process_items(prices: dict[str, float]):
    for item_name, item_price in prices.items():
        print(item_name)
        print(item_price)

এর মানে:

  • prices ভেরিয়েবলটি একটি dict:
    • এই dict-এর কী-গুলোর টাইপ str (ধরা যাক, প্রতিটি আইটেমের নাম)।
    • এই dict-এর ভ্যালুগুলোর টাইপ float (ধরা যাক, প্রতিটি আইটেমের দাম)।

ইউনিয়ন¶

আপনি ঘোষণা করতে পারেন যে একটি ভেরিয়েবল একাধিক টাইপের যেকোনোটি হতে পারে, যেমন একটি int বা একটি str।

এটি সংজ্ঞায়িত করতে দুটি টাইপকে আলাদা করতে খাড়া দাগ (|) ব্যবহার করুন।

একে বলা হয় "ইউনিয়ন", কারণ ভেরিয়েবলটি ওই দুই সেট টাইপের ইউনিয়নের যেকোনো কিছু হতে পারে।

def process_item(item: int | str):
    print(item)

এর মানে item একটি int অথবা একটি str হতে পারে।

সম্ভবত None¶

আপনি ঘোষণা করতে পারেন যে একটি ভ্যালুর একটি টাইপ থাকতে পারে, যেমন str, তবে এটি None-ও হতে পারে।

def say_hi(name: str | None = None):
    if name is not None:
        print(f"Hey {name}!")
    else:
        print("Hello World")

শুধু str-এর বদলে str | None ব্যবহার করলে এডিটর আপনাকে এমন ভুল ধরতে সাহায্য করবে, যেখানে আপনি ধরে নিচ্ছেন যে একটি ভ্যালু সবসময় str, অথচ আসলে এটি None-ও হতে পারে।

ক্লাসকে টাইপ হিসেবে¶

আপনি একটি ক্লাসকেও একটি ভেরিয়েবলের টাইপ হিসেবে ঘোষণা করতে পারেন।

ধরা যাক, আপনার কাছে নামসহ একটি Person ক্লাস আছে:

class Person:
    def __init__(self, name: str):
        self.name = name


def get_person_name(one_person: Person):
    return one_person.name

তাহলে আপনি একটি ভেরিয়েবলকে Person টাইপের হিসেবে ঘোষণা করতে পারেন:

class Person:
    def __init__(self, name: str):
        self.name = name


def get_person_name(one_person: Person):
    return one_person.name

আর তারপর, আবারও, আপনি সব এডিটর সাপোর্ট পান:

লক্ষ করুন, এর মানে "one_person হলো Person ক্লাসের একটি ইনস্ট্যান্স"।

এর মানে এই নয় যে "one_person হলো Person নামের ক্লাস"।

Pydantic মডেল¶

Pydantic হলো ডেটা ভ্যালিডেশন করার একটি Python লাইব্রেরি।

আপনি ডেটার "আকৃতি" ঘোষণা করেন অ্যাট্রিবিউটসহ ক্লাস হিসেবে।

আর প্রতিটি অ্যাট্রিবিউটের একটি টাইপ থাকে।

তারপর আপনি কিছু ভ্যালু দিয়ে ওই ক্লাসের একটি ইনস্ট্যান্স তৈরি করেন, আর এটি ভ্যালুগুলো ভ্যালিডেট করবে, (প্রয়োজন হলে) উপযুক্ত টাইপে রূপান্তর করবে এবং সব ডেটাসহ একটি অবজেক্ট দেবে।

আর সেই ফলাফলের অবজেক্টের সাথে আপনি সব এডিটর সাপোর্ট পান।

অফিসিয়াল Pydantic ডকুমেন্টেশন থেকে একটি উদাহরণ:

from datetime import datetime

from pydantic import BaseModel


class User(BaseModel):
    id: int
    name: str = "John Doe"
    signup_ts: datetime | None = None
    friends: list[int] = []


external_data = {
    "id": "123",
    "signup_ts": "2017-06-01 12:22",
    "friends": [1, "2", b"3"],
}
user = User(**external_data)
print(user)
# > User id=123 name='John Doe' signup_ts=datetime.datetime(2017, 6, 1, 12, 22) friends=[1, 2, 3]
print(user.id)
# > 123

নোট

আরও জানতে Pydantic-এর ডকুমেন্টেশন দেখুন।

FastAPI পুরোটাই Pydantic-এর ওপর ভিত্তি করে তৈরি।

টিউটোরিয়াল - ইউজার গাইড-এ আপনি এর সবকিছু বাস্তবে আরও অনেক বেশি দেখতে পাবেন।

মেটাডেটা অ্যানোটেশনসহ টাইপ হিন্ট¶

Python-এ এমন একটি ফিচারও আছে যা দিয়ে Annotated ব্যবহার করে এই টাইপ হিন্টগুলোতে অতিরিক্ত মেটাডেটা রাখা যায়।

আপনি typing থেকে Annotated ইম্পোর্ট করতে পারেন।

from typing import Annotated


def say_hello(name: Annotated[str, "this is just metadata"]) -> str:
    return f"Hello {name}"

Python নিজে এই Annotated দিয়ে কিছুই করে না। আর এডিটর ও অন্যান্য টুলের কাছে টাইপটি এখনো str।

তবে আপনার অ্যাপ্লিকেশন কেমন আচরণ করবে সে সম্পর্কে FastAPI-কে অতিরিক্ত মেটাডেটা দিতে আপনি Annotated-এর এই জায়গাটি ব্যবহার করতে পারেন।

মনে রাখার মতো গুরুত্বপূর্ণ বিষয় হলো, Annotated-এ আপনি যে প্রথম টাইপ প্যারামিটার দেন সেটিই আসল টাইপ। বাকিগুলো অন্যান্য টুলের জন্য কেবল মেটাডেটা।

আপাতত আপনার শুধু এটুকু জানলেই চলবে যে Annotated আছে, এবং এটি স্ট্যান্ডার্ড Python। 😎

পরে আপনি দেখবেন এটি কতটা শক্তিশালী হতে পারে।

পরামর্শ

এটি স্ট্যান্ডার্ড Python হওয়ার মানে হলো, আপনার এডিটরে, কোড বিশ্লেষণ ও রিফ্যাক্টর করার টুলগুলোতে ইত্যাদিতে আপনি এখনো সম্ভাব্য সেরা ডেভেলপার অভিজ্ঞতা পাবেন। ✨

আর এটাও যে আপনার কোড আরও অনেক Python টুল ও লাইব্রেরির সাথে খুব ভালোভাবে সামঞ্জস্যপূর্ণ থাকবে। 🚀

FastAPI-তে টাইপ হিন্ট¶

FastAPI এই টাইপ হিন্টগুলোর সুবিধা নিয়ে বেশ কয়েকটি কাজ করে।

FastAPI-তে আপনি টাইপ হিন্টসহ প্যারামিটার ঘোষণা করেন এবং পান:

  • এডিটর সাপোর্ট।
  • টাইপ চেক।

...আর FastAPI একই ঘোষণাগুলো ব্যবহার করে:

  • প্রয়োজনীয়তা নির্ধারণ করে: রিকোয়েস্টের পাথ প্যারামিটার, কুয়েরি প্যারামিটার, হেডার, বডি, ডিপেন্ডেন্সি ইত্যাদি থেকে।
  • ডেটা রূপান্তর করে: রিকোয়েস্ট থেকে প্রয়োজনীয় টাইপে।
  • ডেটা ভ্যালিডেট করে: প্রতিটি রিকোয়েস্ট থেকে আসা ডেটা:
    • ডেটা অবৈধ হলে ক্লায়েন্টকে ফেরত পাঠানোর জন্য স্বয়ংক্রিয় এরর তৈরি করে।
  • OpenAPI ব্যবহার করে API ডকুমেন্ট করে:
    • যা পরে স্বয়ংক্রিয় ইন্টারঅ্যাকটিভ ডকুমেন্টেশনের ইউজার ইন্টারফেসগুলো ব্যবহার করে।

এসব হয়তো বিমূর্ত শোনাচ্ছে। চিন্তা করবেন না। টিউটোরিয়াল - ইউজার গাইড-এ আপনি এর সবকিছু বাস্তবে দেখতে পাবেন।

গুরুত্বপূর্ণ বিষয় হলো, এক জায়গাতেই স্ট্যান্ডার্ড Python টাইপ ব্যবহার করে (আরও ক্লাস, ডেকোরেটর ইত্যাদি যোগ করার বদলে) FastAPI আপনার অনেক কাজ করে দেবে।
