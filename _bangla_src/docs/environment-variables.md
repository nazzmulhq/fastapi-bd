# এনভায়রনমেন্ট ভেরিয়েবল { #environment-variables }

/// note | এই পেজে যা শিখবেন

* এনভায়রনমেন্ট ভেরিয়েবল কী, আর কেন পাসওয়ার্ডের মতো জিনিস কোডে না লিখে এখানে রাখা হয়।
* Linux, macOS ও Windows-এ কীভাবে এনভায়রনমেন্ট ভেরিয়েবল তৈরি ও পড়বেন।
* Python কোড থেকে কীভাবে এগুলো পড়বেন।
* `PATH` নামের বিশেষ এনভায়রনমেন্ট ভেরিয়েবলটি কী কাজ করে।

///

একটি **এনভায়রনমেন্ট ভেরিয়েবল** (সংক্ষেপে **env var**) হলো এমন একটি মান, যা আপনার Python কোডের বাইরে, অপারেটিং সিস্টেমে থাকে। আপনার অ্যাপ্লিকেশন এবং অন্যান্য প্রোগ্রাম এটি পড়তে পারে।

FastAPI অ্যাপ্লিকেশনগুলো সাধারণত কনফিগারেশনের (সেটিংসের) জন্য এনভায়রনমেন্ট ভেরিয়েবল ব্যবহার করে, যেমন ডেটাবেসের URL, ইমেইল পাঠানোর ক্রেডেনশিয়াল (ইউজারনেম-পাসওয়ার্ড) আর সিক্রেট কী।

/// tip | কেন কোডে না লিখে এখানে রাখি?

* **নিরাপত্তা**: কোড প্রায়ই GitHub-এ বা অন্যদের সাথে শেয়ার হয়। কোডে পাসওয়ার্ড লিখলে সবাই দেখে ফেলবে। এনভায়রনমেন্ট ভেরিয়েবল থাকে শুধু যে কম্পিউটারে অ্যাপ চলছে সেখানে।
* **একই কোড, ভিন্ন জায়গা**: আপনার কম্পিউটারে হয়তো পরীক্ষার ডেটাবেস, আর সার্ভারে আসল ডেটাবেস। কোড না বদলে শুধু এনভায়রনমেন্ট ভেরিয়েবল বদলে দিলেই হয়।

অনেকটা দোকানের তালার চাবির মতো: তালা (কোড) সবাই দেখতে পারে, কিন্তু চাবি (পাসওয়ার্ড) রাখা থাকে মালিকের পকেটে (এনভায়রনমেন্টে)।

///

অ্যাপ্লিকেশন কনফিগারেশনের জন্য এগুলো কীভাবে ব্যবহার করতে হয় তা আপনি [সেটিংস ও এনভায়রনমেন্ট ভেরিয়েবল](advanced/settings.md)-এ শিখবেন।

## টার্মিনালে তৈরি ও পড়া { #bn-create-and-read }

নিচের উদাহরণে `MY_NAME` নামে একটি এনভায়রনমেন্ট ভেরিয়েবল তৈরি করে তারপর পড়া হচ্ছে।

//// tab | Linux, macOS, Windows Bash

<div class="termy">

```console
// MY_NAME নামে একটি এনভায়রনমেন্ট ভেরিয়েবল তৈরি করুন
$ export MY_NAME="Wade Wilson"

// তারপর অন্য প্রোগ্রামে এটি ব্যবহার করুন, যেমন
$ echo "Hello $MY_NAME"

Hello Wade Wilson
```

</div>

////

//// tab | Windows PowerShell

<div class="termy">

```console
// MY_NAME নামে একটি এনভায়রনমেন্ট ভেরিয়েবল তৈরি করুন
$ $Env:MY_NAME = "Wade Wilson"

// তারপর অন্য প্রোগ্রামে এটি ব্যবহার করুন, যেমন
$ echo "Hello $Env:MY_NAME"

Hello Wade Wilson
```

</div>

////

খেয়াল রাখবেন: এভাবে তৈরি করা এনভায়রনমেন্ট ভেরিয়েবল শুধু ওই টার্মিনাল উইন্ডো খোলা থাকা পর্যন্ত থাকে। টার্মিনাল বন্ধ করলে মুছে যায়।

## Python থেকে পড়া { #bn-read-in-python }

Python-এর `os` মডিউল দিয়ে এনভায়রনমেন্ট ভেরিয়েবল পড়া যায়:

```Python
import os

name = os.getenv("MY_NAME", "World")
print(f"Hello {name} from Python")
```

/// info | কোডটি সহজ ভাষায়

* `import os`: অপারেটিং সিস্টেমের সাথে কাজ করার মডিউলটি আনা হলো।
* `os.getenv("MY_NAME", "World")`: `MY_NAME` নামের এনভায়রনমেন্ট ভেরিয়েবলের মান পড়ে। এটি না থাকলে দ্বিতীয় মানটি, মানে `"World"`, ডিফল্ট হিসেবে নেয়।
* তাই `MY_NAME` সেট করা থাকলে প্রিন্ট হবে `Hello Wade Wilson from Python`, না থাকলে `Hello World from Python`।

///

একটি প্রোগ্রাম চালানোর সময় শুধু সেই প্রোগ্রামের জন্যও এনভায়রনমেন্ট ভেরিয়েবল দেওয়া যায়, একই লাইনে আগে লিখে (Linux/macOS):

<div class="termy">

```console
$ MY_NAME="Wade Wilson" python main.py

Hello Wade Wilson from Python
```

</div>

/// warning | সাধারণ ভুল

এনভায়রনমেন্ট ভেরিয়েবল সবসময় **টেক্সট (স্ট্রিং)** হিসেবে আসে। আপনি `PORT=8000` লিখলেও Python-এ এটি `"8000"` টেক্সট। সংখ্যা দরকার হলে `int(os.getenv("PORT", "8000"))` লিখে রূপান্তর করতে হবে। FastAPI-এর [সেটিংস](advanced/settings.md) পেজে Pydantic দিয়ে এই রূপান্তর স্বয়ংক্রিয়ভাবে করার উপায় দেখানো হয়েছে।

///

## `PATH` এনভায়রনমেন্ট ভেরিয়েবল { #bn-path }

`PATH` একটি বিশেষ এনভায়রনমেন্ট ভেরিয়েবল। এতে কয়েকটি ফোল্ডারের তালিকা থাকে। আপনি টার্মিনালে `python` বা `fastapi` এর মতো কোনো কমান্ড লিখলে, অপারেটিং সিস্টেম এই ফোল্ডারগুলোতে একে একে খুঁজে দেখে কোথায় ওই নামের প্রোগ্রাম আছে, আর প্রথম যেটা পায় সেটা চালায়।

ভার্চুয়াল এনভায়রনমেন্ট "অ্যাক্টিভেট" করলে আসলে এই `PATH`-এর একদম শুরুতে ভার্চুয়াল এনভায়রনমেন্টের ফোল্ডারটি যোগ হয়। তাই তখন `python` লিখলে সেই প্রজেক্টের Python-টাই চলে। বিস্তারিত দেখুন [ভার্চুয়াল এনভায়রনমেন্ট](virtual-environments.md) পেজে।

## আরও জানুন { #learn-more }

বিস্তারিত, সব অপারেটিং সিস্টেমের জন্য ব্যাখ্যা পেতে [এনভায়রনমেন্ট ভেরিয়েবল গাইড](https://tiangolo.com/guides/environment-variables/) (ইংরেজিতে) পড়ুন। সেখানে এনভায়রনমেন্ট ভেরিয়েবল তৈরি ও পড়া আর `PATH` এনভায়রনমেন্ট ভেরিয়েবল কীভাবে কাজ করে তা আরও বিস্তারিত আছে।

/// check | সংক্ষেপে মনে রাখুন

* এনভায়রনমেন্ট ভেরিয়েবল হলো কোডের বাইরে, অপারেটিং সিস্টেমে রাখা মান।
* পাসওয়ার্ড, সিক্রেট কী, ডেটাবেস URL কোডে না লিখে এখানে রাখুন।
* Linux/macOS-এ `export NAME="value"`, PowerShell-এ `$Env:NAME = "value"`।
* Python-এ পড়ুন `os.getenv("NAME", "ডিফল্ট")` দিয়ে, আর মনে রাখুন মানটি সবসময় টেক্সট।
* `PATH` বলে দেয় কমান্ড লিখলে কোন ফোল্ডারে প্রোগ্রাম খোঁজা হবে।
