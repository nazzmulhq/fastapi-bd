# সহজ শব্দকোষ { #glossary }

/// note | এই পেজটি কেন?

FastAPI ডকুমেন্টেশনে অনেক ইংরেজি কারিগরি শব্দ আসে, যেমন রিকোয়েস্ট, রেসপন্স, ডিপেন্ডেন্সি। এই পেজে প্রতিটি শব্দের মানে সহজ বাংলায়, ছোট উদাহরণসহ বুঝিয়ে দেওয়া হয়েছে।

কোনো পেজ পড়তে গিয়ে অপরিচিত শব্দ পেলে এখানে এসে দেখে নিন। ওপরে ডান দিকের সার্চ বক্সেও শব্দটি লিখে খুঁজতে পারেন।

///

## ওয়েব ও নেটওয়ার্কের মূল ধারণা { #web-basics }

### সার্ভার (Server) { #server }

যে কম্পিউটার বা প্রোগ্রাম অন্যদের অনুরোধ গ্রহণ করে উত্তর পাঠায়। আপনি যখন FastAPI অ্যাপ চালান, তখন আপনার অ্যাপটিই একটি সার্ভার। রেস্তোরাঁর উদাহরণে সার্ভার হলো রান্নাঘর।

### ক্লায়েন্ট (Client) { #client }

যে প্রোগ্রাম সার্ভারের কাছে অনুরোধ পাঠায়। যেমন ব্রাউজার, মোবাইল অ্যাপ, অথবা অন্য কোনো সার্ভার। রেস্তোরাঁর উদাহরণে ক্লায়েন্ট হলো খেতে আসা অতিথি।

### API { #api }

**Application Programming Interface**। দুটি প্রোগ্রাম একে অপরের সাথে কীভাবে কথা বলবে, তার নির্দিষ্ট নিয়ম ও ঠিকানার তালিকা। যেমন "`/users/5` ঠিকানায় `GET` পাঠালে ৫ নম্বর ইউজারের তথ্য পাবে"। রেস্তোরাঁর উদাহরণে API হলো মেনুকার্ড আর ওয়েটার: কী অর্ডার করা যায় আর কীভাবে খাবার আসবে।

### ওয়েব API { #web-api }

ইন্টারনেট বা নেটওয়ার্কের মাধ্যমে HTTP ব্যবহার করে কাজ করা API। FastAPI দিয়ে আপনি এই ধরনের API বানান।

### HTTP ও HTTPS { #http }

**HTTP** হলো ক্লায়েন্ট ও সার্ভারের মধ্যে কথা বলার ভাষা বা নিয়ম (প্রোটোকল)। **HTTPS** হলো একই জিনিস, কিন্তু এনক্রিপ্টেড (তালাবদ্ধ), যাতে মাঝপথে কেউ তথ্য পড়তে বা বদলাতে না পারে। ব্রাউজারের ঠিকানার পাশে তালার চিহ্ন মানে HTTPS।

### URL { #url }

ইন্টারনেটে কোনো কিছুর পূর্ণ ঠিকানা। যেমন `https://example.com:8000/items/5?q=book`। এর অংশগুলো:

* `https`: প্রোটোকল।
* `example.com`: ডোমেইন, মানে কোন সার্ভার।
* `8000`: পোর্ট।
* `/items/5`: পাথ।
* `?q=book`: কুয়েরি।

### ডোমেইন (Domain) { #domain }

সার্ভারের মনে রাখার মতো নাম, যেমন `example.com`। আসলে সার্ভারের ঠিকানা একটি সংখ্যা (IP ঠিকানা), DNS নামের ব্যবস্থা নামকে সংখ্যায় বদলে দেয়।

### পোর্ট (Port) { #port }

একটি কম্পিউটারে অনেক প্রোগ্রাম একসাথে নেটওয়ার্ক ব্যবহার করতে পারে। পোর্ট নম্বর দিয়ে বোঝা যায় কোন প্রোগ্রামের সাথে কথা হচ্ছে। একটি বাড়ির (কম্পিউটার) অনেকগুলো দরজার (পোর্ট) মতো। FastAPI ডেভেলপমেন্টে সাধারণত `8000` পোর্টে চলে। HTTP-এর ডিফল্ট পোর্ট `80`, HTTPS-এর `443`।

### localhost ও 127.0.0.1 { #localhost }

দুটোরই মানে "এই কম্পিউটার নিজেই"। `http://127.0.0.1:8000` মানে আপনার নিজের কম্পিউটারের ৮০০০ নম্বর পোর্টে চলা প্রোগ্রাম। এটি শুধু আপনার কম্পিউটার থেকেই দেখা যায়।

### পাথ (Path) { #path }

URL-এ ডোমেইন ও পোর্টের পরের অংশ, যা `/` দিয়ে শুরু হয়। যেমন `https://example.com/items/foo`-এর পাথ হলো `/items/foo`। পাথ দিয়ে বোঝা যায় ক্লায়েন্ট সার্ভারের কোন অংশ বা কোন তথ্য চাইছে। একে **এন্ডপয়েন্ট** বা **রাউট**-ও বলা হয়।

### এন্ডপয়েন্ট ও রাউট (Endpoint, Route) { #endpoint }

API-এর একটি নির্দিষ্ট ঠিকানা (পাথ) আর মেথডের জোড়া, যেখানে রিকোয়েস্ট পাঠানো যায়। যেমন "`GET /items/{item_id}`" একটি এন্ডপয়েন্ট। FastAPI-তে একে **পাথ অপারেশন** বলা হয়।

### রিকোয়েস্ট (Request) { #request }

ক্লায়েন্ট সার্ভারের কাছে যে অনুরোধ পাঠায়। এতে থাকে মেথড (যেমন `GET`), পাথ, হেডার, আর কখনো কখনো বডি (ডেটা)। রেস্তোরাঁর উদাহরণে রিকোয়েস্ট হলো আপনার অর্ডার।

### রেসপন্স (Response) { #response }

রিকোয়েস্টের উত্তরে সার্ভার যা ফেরত পাঠায়। এতে থাকে স্ট্যাটাস কোড (সফল হলো কিনা), হেডার, আর বডি (সাধারণত JSON ডেটা)। রেস্তোরাঁর উদাহরণে রেসপন্স হলো আপনার টেবিলে আসা খাবার।

### HTTP মেথড (Method) { #http-methods }

রিকোয়েস্টের সাথে বলে দেওয়া হয় আপনি কী ধরনের কাজ করতে চান। এগুলোকে HTTP মেথড বা "অপারেশন" বলে:

* `GET`: তথ্য পড়া। যেমন পণ্যের তালিকা দেখা।
* `POST`: নতুন তথ্য তৈরি করা। যেমন নতুন অ্যাকাউন্ট খোলা।
* `PUT`: কোনো তথ্য পুরোপুরি বদলে দেওয়া (আপডেট)।
* `PATCH`: কোনো তথ্যের অংশবিশেষ বদলানো।
* `DELETE`: তথ্য মুছে ফেলা।

এছাড়াও আছে `OPTIONS`, `HEAD`, `TRACE`, এগুলো কম ব্যবহৃত।

### স্ট্যাটাস কোড (Status Code) { #status-code }

রেসপন্সের সাথে আসা একটি তিন অঙ্কের সংখ্যা, যা বলে রিকোয়েস্টের ফলাফল কী হলো:

* `2xx` (যেমন `200 OK`, `201 Created`): সফল।
* `3xx`: অন্য ঠিকানায় যেতে বলা (রিডাইরেক্ট)।
* `4xx` (যেমন `404 Not Found`, `422`): ক্লায়েন্টের ভুল, যেমন ভুল ঠিকানা বা ভুল ডেটা।
* `5xx` (যেমন `500`): সার্ভারের ভেতরে সমস্যা।

### হেডার (Header) { #header }

রিকোয়েস্ট বা রেসপন্সের সাথে পাঠানো অতিরিক্ত তথ্য, "নাম: মান" আকারে। যেমন `Content-Type: application/json` জানায় বডিতে JSON আছে। চিঠির খামের ওপর লেখা ঠিকানা ও তথ্যের মতো, ভেতরের চিঠিটা হলো বডি।

### বডি (Body) { #body }

রিকোয়েস্ট বা রেসপন্সের মূল ডেটা অংশ। রিকোয়েস্টে সাধারণত `POST` বা `PUT`-এর সাথে বডিতে JSON পাঠানো হয়, যেমন নতুন পণ্যের নাম ও দাম।

### কুয়েরি প্যারামিটার (Query Parameter) { #query-parameter }

URL-এ `?` চিহ্নের পরে `নাম=মান` আকারে থাকা অতিরিক্ত তথ্য, একাধিক হলে `&` দিয়ে আলাদা। যেমন `/items/?skip=0&limit=10`। সাধারণত খোঁজা, ফিল্টার বা পৃষ্ঠা ভাগ করার জন্য ব্যবহার হয়।

### পাথ প্যারামিটার (Path Parameter) { #path-parameter }

পাথের ভেতরের পরিবর্তনশীল অংশ। যেমন `/items/{item_id}` পাথে `{item_id}` একটি পাথ প্যারামিটার, তাই `/items/5` বা `/items/42` দুটোই কাজ করে।

### কুকি (Cookie) { #cookie }

সার্ভার ব্রাউজারে যে ছোট তথ্য রেখে দেয়, এবং ব্রাউজার পরের প্রতিটি রিকোয়েস্টে সেটি ফেরত পাঠায়। যেমন আপনি লগইন করা আছেন কিনা তা মনে রাখতে।

### JSON { #json }

**JavaScript Object Notation**। ডেটা আদান-প্রদানের একটি জনপ্রিয় টেক্সট ফরম্যাট, দেখতে Python ডিকশনারির মতো:

```JSON
{"name": "কলম", "price": 10.5, "tags": ["অফিস", "লেখা"]}
```

প্রায় সব প্রোগ্রামিং ভাষা JSON বোঝে, তাই API-তে এটিই সবচেয়ে বেশি ব্যবহার হয়।

### ফর্ম ডেটা (Form Data) { #form-data }

HTML ফর্ম (যেমন লগইন ফর্ম) জমা দিলে ব্রাউজার যে ফরম্যাটে ডেটা পাঠায়। এটি JSON নয়, আলাদা ফরম্যাট। ফাইল আপলোডও এভাবে হয়।

### REST { #rest }

ওয়েব API ডিজাইনের একটি জনপ্রিয় ধারা: প্রতিটি জিনিসের (যেমন ইউজার, পণ্য) একটি পাথ থাকে, আর কাজ বোঝাতে HTTP মেথড ব্যবহার হয়। যেমন `GET /users` (সব ইউজার), `POST /users` (নতুন ইউজার)।

### CORS { #cors }

**Cross-Origin Resource Sharing**। ব্রাউজারের একটি নিরাপত্তা নিয়ম: এক ডোমেইনের ওয়েবসাইট (যেমন `myapp.com`) অন্য ডোমেইনের API-তে (যেমন `api.myapp.com`) রিকোয়েস্ট পাঠাতে পারবে কিনা, তা সার্ভারকে অনুমতি দিতে হয়। FastAPI-তে `CORSMiddleware` দিয়ে এই অনুমতি দেওয়া হয়।

### WebSocket { #websocket }

ক্লায়েন্ট ও সার্ভারের মধ্যে একবার সংযোগ খুলে সেটি খোলা রাখার ব্যবস্থা, যাতে দুই পক্ষই যেকোনো সময় বার্তা পাঠাতে পারে। চ্যাট অ্যাপ বা লাইভ নোটিফিকেশনে ব্যবহার হয়। সাধারণ HTTP-তে প্রতিবার নতুন রিকোয়েস্ট লাগে।

### প্রক্সি ও রিভার্স প্রক্সি (Proxy) { #proxy }

ক্লায়েন্ট ও আপনার অ্যাপের মাঝখানে বসা একটি প্রোগ্রাম, যা রিকোয়েস্ট গ্রহণ করে আপনার অ্যাপের কাছে পৌঁছে দেয়। যেমন Nginx বা Traefik। এটি HTTPS সামলানো, একাধিক অ্যাপে রিকোয়েস্ট ভাগ করে দেওয়া ইত্যাদি কাজ করে।

## Python-এর ধারণা { #python-basics }

### টাইপ হিন্ট (Type Hint) { #type-hints }

কোনো ভেরিয়েবল বা প্যারামিটার কোন ধরনের ডেটা, তা কোডে লিখে দেওয়া। যেমন `name: str` (টেক্সট), `age: int` (পূর্ণসংখ্যা), `price: float` (দশমিক সংখ্যা)। Python নিজে এগুলো বাধ্যতামূলক করে না, কিন্তু এডিটর ও FastAPI এগুলো দেখে সাহায্য করে। বিস্তারিত: [Python টাইপের পরিচিতি](../python-types.md)।

### ফাংশন, প্যারামিটার ও আর্গুমেন্ট { #function }

**ফাংশন** হলো নাম দেওয়া একটি কোডের টুকরো, যা ডাকলে চলে (`def` দিয়ে লেখা হয়)। **প্যারামিটার** হলো ফাংশন যে ইনপুট নেয় তার নাম, আর **আর্গুমেন্ট** হলো ডাকার সময় দেওয়া আসল মান। যেমন `def greet(name: str)`-এ `name` প্যারামিটার, আর `greet("রহিম")`-এ `"রহিম"` আর্গুমেন্ট।

### ডেকোরেটর (Decorator) { #decorator }

`@` চিহ্ন দিয়ে ফাংশনের ঠিক ওপরে লেখা একটি বিশেষ লাইন, যা ওই ফাংশনের সাথে অতিরিক্ত কিছু যুক্ত করে। FastAPI-তে `@app.get("/")` লিখলে নিচের ফাংশনটি `/` পাথের `GET` রিকোয়েস্টের সাথে যুক্ত হয়ে যায়।

### ক্লাস ও অবজেক্ট (Class, Object) { #class }

**ক্লাস** হলো একটি নকশা বা ছাঁচ, আর **অবজেক্ট** (বা ইনস্ট্যান্স) হলো সেই ছাঁচ থেকে বানানো আসল জিনিস। যেমন `Item` একটি ক্লাস, আর `Item(name="কলম", price=10)` একটি অবজেক্ট।

### অ্যাট্রিবিউট (Attribute) { #attribute }

অবজেক্টের ভেতরে থাকা মান, ডট (`.`) দিয়ে পাওয়া যায়। যেমন `item.name`, `item.price`।

### ডিকশনারি (`dict`) ও লিস্ট (`list`) { #dict-list }

**ডিকশনারি** হলো "কী: মান" জোড়ার সংগ্রহ, যেমন `{"name": "কলম", "price": 10}`। **লিস্ট** হলো ক্রম অনুযায়ী সাজানো মানের তালিকা, যেমন `[1, 2, 3]`। JSON-এর অবজেক্ট ও অ্যারে Python-এ এভাবেই আসে।

### `None` { #none }

Python-এ "কোনো মান নেই" বোঝাতে `None` ব্যবহার হয়। FastAPI-তে `q: str | None = None` মানে `q` ঐচ্ছিক, না দিলে এর মান `None`।

### মডিউল, প্যাকেজ ও ইমপোর্ট { #module }

**মডিউল** হলো একটি Python ফাইল (যেমন `main.py`)। **প্যাকেজ** হলো একাধিক মডিউলের একটি ফোল্ডার, অথবা ইন্টারনেট থেকে ইনস্টল করা লাইব্রেরি (যেমন `fastapi`)। **ইমপোর্ট** (`import` / `from ... import ...`) দিয়ে অন্য মডিউল বা প্যাকেজের কোড নিজের ফাইলে ব্যবহার করা হয়।

### `async` ও `await` { #async-await }

একসাথে অনেক কাজ সামলানোর একটি কৌশল। কোনো কাজে অপেক্ষা করতে হলে (যেমন ডেটাবেস বা অন্য API-এর উত্তর), `await` লিখলে প্রোগ্রাম অপেক্ষার সময়টা বসে না থেকে অন্য রিকোয়েস্টের কাজ করে। `async def` দিয়ে এমন ফাংশন লেখা হয়। বিস্তারিত: [কনকারেন্সি ও async / await](../async.md)।

### জেনারেটর ও `yield` { #yield }

`return` একবারে একটি মান দিয়ে ফাংশন শেষ করে। `yield` একটি মান দিয়ে ফাংশনকে থামিয়ে রাখে, পরে আবার সেখান থেকে চালানো যায়। FastAPI-তে `yield` ব্যবহার হয় এমন ডিপেন্ডেন্সিতে যেগুলোর কাজ শেষে কিছু পরিষ্কার করতে হয় (যেমন ডেটাবেস সংযোগ বন্ধ করা), আর ডেটা ধাপে ধাপে স্ট্রিম করতে।

### এক্সেপশন (Exception) { #exception }

প্রোগ্রাম চলার সময় হওয়া এরর, যা `raise` দিয়ে ছোড়া হয়। FastAPI-তে `raise HTTPException(status_code=404)` লিখলে ক্লায়েন্ট একটি 404 এরর রেসপন্স পায়।

### ভার্চুয়াল এনভায়রনমেন্ট (Virtual Environment) { #virtual-environment }

প্রতিটি প্রজেক্টের জন্য আলাদা একটি জায়গা, যেখানে সেই প্রজেক্টের প্যাকেজগুলো ইনস্টল হয়। এতে এক প্রজেক্টের প্যাকেজ আরেক প্রজেক্টে ঝামেলা করে না। বিস্তারিত: [ভার্চুয়াল এনভায়রনমেন্ট](../virtual-environments.md)।

### এনভায়রনমেন্ট ভেরিয়েবল (Environment Variable) { #environment-variable }

কোডের বাইরে, অপারেটিং সিস্টেমে রাখা একটি মান, যা প্রোগ্রাম পড়তে পারে। পাসওয়ার্ড বা ডেটাবেস ঠিকানার মতো গোপন সেটিংস কোডে না লিখে এখানে রাখা হয়। বিস্তারিত: [এনভায়রনমেন্ট ভেরিয়েবল](../environment-variables.md)।

### `uv` ও `pip` { #uv-pip }

Python প্যাকেজ ইনস্টল ও সামলানোর টুল। `pip` হলো পুরোনো ও প্রচলিত টুল, `uv` নতুন ও অনেক দ্রুত, আর প্রজেক্ট ও ভার্চুয়াল এনভায়রনমেন্টও নিজে সামলায়।

### টার্মিনাল ও কমান্ড (Terminal) { #terminal }

যে প্রোগ্রামে লিখে লিখে কম্পিউটারকে নির্দেশ দেওয়া হয়। Windows-এ PowerShell, macOS ও Linux-এ Terminal। ডকুমেন্টেশনে `$` চিহ্ন দিয়ে শুরু হওয়া লাইনগুলো টার্মিনালে লেখার কমান্ড (`$` নিজে লিখবেন না)।

## FastAPI-এর ধারণা { #fastapi-concepts }

### ফ্রেমওয়ার্ক (Framework) { #framework }

আগে থেকে তৈরি টুল ও নিয়মের একটি কাঠামো, যার ভেতরে আপনি শুধু নিজের অংশটুকু লেখেন। ঘর বানানোর সময় তৈরি করা কাঠামোর মতো, আপনি শুধু দেয়াল রঙ করেন আর আসবাব সাজান।

### পাথ অপারেশন (Path Operation) { #path-operation }

একটি পাথ আর একটি HTTP মেথডের জোড়া, যেমন `GET /items/`। FastAPI-তে ডেকোরেটর (`@app.get("/items/")`) দিয়ে এটি ঘোষণা করা হয়।

### পাথ অপারেশন ফাংশন (Path Operation Function) { #path-operation-function }

ডেকোরেটরের ঠিক নিচের ফাংশন, যা ওই পাথ অপারেশনে রিকোয়েস্ট এলে চলে। এর রিটার্ন করা মানই রেসপন্স হয়ে ক্লায়েন্টের কাছে যায়।

### মডেল (Pydantic Model) { #model }

ডেটার আকার কেমন হবে তার একটি ক্লাস, `BaseModel` থেকে তৈরি। যেমন একটি `Item` মডেলে `name: str` আর `price: float`। FastAPI মডেল দেখে রিকোয়েস্টের বডি যাচাই করে, রূপান্তর করে, আর ডকুমেন্টেশনে দেখায়।

### ভ্যালিডেশন (Validation) { #validation }

আসা ডেটা ঠিক আছে কিনা যাচাই করা। যেমন বয়স সংখ্যা কিনা, ইমেইল সঠিক ফরম্যাটে কিনা, নাম খুব বেশি লম্বা কিনা। ভুল হলে FastAPI নিজে থেকে `422` স্ট্যাটাস কোডসহ পরিষ্কার এরর পাঠায়।

### সিরিয়ালাইজেশন ও পার্সিং (Serialization, Parsing) { #serialization }

**পার্সিং** মানে বাইরের ডেটাকে (যেমন JSON টেক্সট) Python ডেটায় রূপান্তর করা। **সিরিয়ালাইজেশন** মানে উল্টোটা, Python ডেটাকে পাঠানোর উপযোগী রূপে (যেমন JSON) রূপান্তর করা। FastAPI দুটোই নিজে করে।

### স্কিমা ও JSON Schema (Schema) { #schema }

ডেটার আকার ও নিয়মের একটি বিবরণ, যেমন "একটি বস্তু, যার `name` টেক্সট ও আবশ্যক"। **JSON Schema** হলো এই বিবরণ লেখার একটি স্ট্যান্ডার্ড ফরম্যাট। FastAPI আপনার মডেল থেকে স্বয়ংক্রিয়ভাবে JSON Schema বানায়।

### OpenAPI { #openapi }

একটি স্ট্যান্ডার্ড, যা দিয়ে একটি API-এর পুরো বিবরণ লেখা হয়: কোন কোন পাথ আছে, কী প্যারামিটার নেয়, কী রেসপন্স দেয়। FastAPI এটি স্বয়ংক্রিয়ভাবে বানায় এবং `/openapi.json` ঠিকানায় দেখায়।

### Swagger UI ও ReDoc { #swagger-ui }

OpenAPI বিবরণ পড়ে সুন্দর ডকুমেন্টেশন পেজ দেখানোর দুটি টুল। Swagger UI (`/docs`) থেকে সরাসরি API চালিয়ে দেখা যায়, ReDoc (`/redoc`) পড়ার জন্য সুবিধাজনক।

### ডিপেন্ডেন্সি ও ডিপেন্ডেন্সি ইনজেকশন (Dependency Injection) { #dependency-injection }

এখানে **ডিপেন্ডেন্সি** মানে এমন একটি ফাংশন বা জিনিস, যা আপনার পাথ অপারেশনের কাজ করতে লাগে। যেমন বর্তমান ইউজার খুঁজে বের করা বা ডেটাবেস সংযোগ। **ডিপেন্ডেন্সি ইনজেকশন** মানে আপনি শুধু `Depends(...)` লিখে বলে দেন কী লাগবে, আর FastAPI নিজে সেটি চালিয়ে ফলাফল আপনার ফাংশনে দিয়ে দেয়। একই ডিপেন্ডেন্সি অনেক জায়গায় ব্যবহার করা যায়। নোট: Python প্যাকেজ অর্থে "ডিপেন্ডেন্সি" (যেমন FastAPI-এর ডিপেন্ডেন্সি Starlette) আলাদা জিনিস।

### মিডলওয়্যার (Middleware) { #middleware }

এমন কোড যা প্রতিটি রিকোয়েস্ট আপনার পাথ অপারেশনে পৌঁছানোর আগে আর প্রতিটি রেসপন্স বেরোনোর আগে চলে। যেমন প্রতিটি রিকোয়েস্টে কত সময় লাগল মাপা। অফিসের প্রবেশদ্বারের নিরাপত্তারক্ষীর মতো, যার সামনে দিয়ে সবাইকে ঢুকতে ও বেরোতে হয়।

### APIRouter { #apirouter }

বড় অ্যাপকে একাধিক ফাইলে ভাগ করার ব্যবস্থা। প্রতিটি ফাইলে একটি `APIRouter` বানিয়ে পাথ অপারেশনগুলো রাখা হয়, তারপর মূল অ্যাপে সেগুলো যুক্ত করা হয়।

### ব্যাকগ্রাউন্ড টাস্ক (Background Task) { #background-task }

রেসপন্স পাঠানোর পরে পেছনে চালানো কাজ, যাতে ক্লায়েন্টকে অপেক্ষা করতে না হয়। যেমন রেজিস্ট্রেশনের পরে স্বাগত ইমেইল পাঠানো।

### লাইফস্প্যান (Lifespan) { #lifespan }

অ্যাপ চালু হওয়ার সময় একবার আর বন্ধ হওয়ার সময় একবার যে কোড চলে। যেমন শুরুতে একটি মেশিন লার্নিং মডেল লোড করা আর শেষে মেমরি খালি করা।

### রেসপন্স মডেল (Response Model) { #response-model }

রেসপন্সে কোন ডেটা কী আকারে যাবে, তা ঠিক করে দেওয়া মডেল। এতে ভুল করে পাসওয়ার্ডের মতো গোপন তথ্য পাঠানো আটকানো যায়।

### Starlette ও Pydantic { #starlette-pydantic }

FastAPI যে দুটি লাইব্রেরির ওপর তৈরি। **Starlette** ওয়েবের কাজ (রিকোয়েস্ট, রেসপন্স, রাউটিং) করে, আর **Pydantic** ডেটার কাজ (যাচাই, রূপান্তর) করে।

### ASGI ও Uvicorn { #asgi-uvicorn }

**ASGI** হলো Python ওয়েব অ্যাপ ও সার্ভার প্রোগ্রামের মধ্যে কথা বলার একটি স্ট্যান্ডার্ড। **Uvicorn** একটি ASGI সার্ভার প্রোগ্রাম, যা নেটওয়ার্ক থেকে রিকোয়েস্ট নিয়ে আপনার FastAPI অ্যাপকে দেয় আর রেসপন্স ফেরত পাঠায়। `fastapi dev` ও `fastapi run` ভেতরে Uvicorn চালায়।

### অটো-রিলোড (Auto-reload) { #auto-reload }

কোড বদলে সেভ করলেই সার্ভার নিজে নতুন কোড লোড করে নেয়। শুধু ডেভেলপমেন্টে ব্যবহার করা হয় (`fastapi dev`), প্রোডাকশনে নয়।

## সিকিউরিটি { #security }

### অথেনটিকেশন ও অথরাইজেশন (Authentication, Authorization) { #authentication }

**অথেনটিকেশন** মানে "আপনি কে?" যাচাই করা, যেমন ইউজারনেম-পাসওয়ার্ড দিয়ে লগইন। **অথরাইজেশন** মানে "আপনার কী করার অনুমতি আছে?" যাচাই করা, যেমন শুধু অ্যাডমিন ইউজার মুছতে পারবে।

### টোকেন (Token) { #token }

লগইনের পরে সার্ভার ক্লায়েন্টকে যে একটি গোপন স্ট্রিং দেয়। পরের প্রতিটি রিকোয়েস্টে ক্লায়েন্ট সেটি পাঠিয়ে প্রমাণ করে যে সে লগইন করা। সিনেমা হলের টিকিটের মতো, একবার কিনলে বারবার দেখালেই ঢোকা যায়।

### JWT { #jwt }

**JSON Web Token**। একটি নির্দিষ্ট ফরম্যাটের টোকেন, যার ভেতরে তথ্য (যেমন ইউজারের নাম, মেয়াদ শেষের সময়) থাকে এবং সার্ভারের গোপন চাবি দিয়ে সই করা থাকে। ফলে কেউ বদলালে ধরা পড়ে যায়।

### OAuth2 { #oauth2 }

অথেনটিকেশন ও অথরাইজেশনের একটি বহুল ব্যবহৃত স্ট্যান্ডার্ড। "Google দিয়ে লগইন করুন" ধরনের ব্যবস্থা এর ওপর তৈরি। FastAPI-তে এর জন্য তৈরি টুল আছে।

### Scope { #scope }

OAuth2-তে একটি টোকেনকে কী কী কাজের অনুমতি দেওয়া হয়েছে তার তালিকা, যেমন `items:read` (পণ্য দেখা) বা `items:write` (পণ্য বদলানো)।

### হ্যাশিং (Hashing) { #hashing }

পাসওয়ার্ডকে এমন একটি অর্থহীন দেখতে স্ট্রিংয়ে রূপান্তর করা, যা থেকে আসল পাসওয়ার্ড ফেরত বের করা যায় না। ডেটাবেসে পাসওয়ার্ড কখনো সরাসরি রাখা উচিত নয়, হ্যাশ করে রাখতে হয়।

## ডেটাবেস ও টেস্টিং { #database-testing }

### ডেটাবেস ও SQL { #database }

**ডেটাবেস** হলো সাজিয়ে তথ্য সংরক্ষণের ব্যবস্থা, যেমন PostgreSQL, MySQL, SQLite। **SQL** হলো এমন ডেটাবেসের সাথে কথা বলার ভাষা।

### ORM { #orm }

**Object-Relational Mapping**। ডেটাবেসের টেবিলকে Python ক্লাস হিসেবে ব্যবহার করার টুল, যাতে SQL না লিখে Python কোড দিয়ে ডেটাবেসে কাজ করা যায়। যেমন SQLModel, SQLAlchemy।

### টেস্ট (Test) ও pytest { #testing }

**টেস্ট** হলো এমন কোড, যা আপনার অ্যাপ ঠিকমতো কাজ করছে কিনা স্বয়ংক্রিয়ভাবে যাচাই করে। **pytest** হলো Python-এ টেস্ট লেখা ও চালানোর সবচেয়ে জনপ্রিয় টুল। FastAPI-এর `TestClient` দিয়ে সার্ভার না চালিয়েই API টেস্ট করা যায়।

## ডিপ্লয়মেন্ট { #deployment }

### ডিপ্লয় (Deploy) { #deploy }

আপনার অ্যাপকে নিজের কম্পিউটার থেকে একটি সার্ভারে তুলে চালু করা, যাতে ব্যবহারকারীরা ব্যবহার করতে পারে।

### ডেভেলপমেন্ট ও প্রোডাকশন (Development, Production) { #production }

**ডেভেলপমেন্ট** মানে নিজের কম্পিউটারে কোড লেখা ও পরীক্ষার পর্যায়। **প্রোডাকশন** মানে আসল ব্যবহারকারীদের জন্য চালু থাকা অ্যাপ, যেখানে নিরাপত্তা, গতি ও স্থিতিশীলতা সবচেয়ে গুরুত্বপূর্ণ।

### প্রসেস ও ওয়ার্কার (Process, Worker) { #worker }

**প্রসেস** হলো কম্পিউটারে চলমান একটি প্রোগ্রাম। **ওয়ার্কার** হলো আপনার অ্যাপের একাধিক কপির প্রতিটি, যারা একসাথে চলে রিকোয়েস্ট ভাগ করে সামলায়। এতে কম্পিউটারের সব CPU কোর কাজে লাগে।

### CPU ও RAM { #cpu-ram }

**CPU** হলো কম্পিউটারের "মস্তিষ্ক", যা হিসাব-নিকাশ করে। **RAM** (মেমরি) হলো কাজ চলাকালীন তথ্য রাখার অস্থায়ী জায়গা।

### Docker, ইমেজ ও কন্টেইনার { #docker }

**Docker** হলো এমন একটি টুল, যা আপনার অ্যাপ আর তার চলার জন্য দরকারি সবকিছু একটি প্যাকেটে ভরে দেয়। এই প্যাকেটকে বলে **ইমেজ**, আর ইমেজ থেকে চালু হওয়া অ্যাপকে বলে **কন্টেইনার**। এতে যেকোনো সার্ভারে অ্যাপ একইভাবে চলে।

### TLS ও সার্টিফিকেট { #tls-certificate }

**TLS** হলো HTTPS-এর পেছনের এনক্রিপশন প্রযুক্তি। **সার্টিফিকেট** হলো একটি ডিজিটাল প্রমাণপত্র, যা প্রমাণ করে যে এই সার্ভারটিই আসলে ওই ডোমেইনের মালিক। Let's Encrypt বিনামূল্যে সার্টিফিকেট দেয়।

### লোড ব্যালান্সার (Load Balancer) { #load-balancer }

আসা রিকোয়েস্টগুলোকে একাধিক সার্ভার বা ওয়ার্কারের মধ্যে ভাগ করে দেওয়ার ব্যবস্থা, যাতে কোনো একটির ওপর বেশি চাপ না পড়ে।

### ক্লাউড (Cloud) { #cloud }

অন্য কোম্পানির (যেমন AWS, Google Cloud, FastAPI Cloud) সার্ভার ভাড়া নিয়ে সেখানে অ্যাপ চালানো। নিজের সার্ভার কিনে রক্ষণাবেক্ষণ করতে হয় না।
