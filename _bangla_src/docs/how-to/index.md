# কীভাবে করবেন - রেসিপি { #how-to-recipes }

/// note | এই অংশটি কী

এটি একটি "রেসিপির বই"। প্রতিটি পেজ একটি নির্দিষ্ট সমস্যার সমাধান দেখায়, যেমন: GraphQL কীভাবে যুক্ত করবেন, Swagger UI কীভাবে সাজাবেন, Pydantic v1 থেকে v2-তে কীভাবে যাবেন। ধারাবাহিকভাবে পড়ার দরকার নেই, যখন যেটা দরকার তখন সেটা দেখুন।

///

এখানে আপনি **বিভিন্ন বিষয়ে** নানা রেসিপি বা "কীভাবে করবেন" গাইড দেখবেন।

এই ধারণাগুলোর বেশিরভাগই কমবেশি **স্বাধীন**, আর বেশিরভাগ ক্ষেত্রে আপনাকে এগুলো শুধু তখনই পড়তে হবে যখন এগুলো সরাসরি **আপনার প্রজেক্টে** প্রযোজ্য।

যদি কিছু আপনার প্রজেক্টের জন্য আকর্ষণীয় আর উপকারী মনে হয়, তাহলে দেখে নিন, নইলে সম্ভবত এগুলো এড়িয়ে যেতে পারেন।

/// tip | পরামর্শ

যদি আপনি সুশৃঙ্খলভাবে **FastAPI শিখতে** চান (যা সুপারিশ করা হয়), তাহলে এর বদলে [টিউটোরিয়াল - ব্যবহারকারী গাইড](../tutorial/index.md) অধ্যায় ধরে ধরে পড়ুন।
