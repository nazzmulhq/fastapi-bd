# OpenAPI বাড়ানো { #extending-openapi }

/// note | এই পেজে যা শিখবেন

* FastAPI কীভাবে OpenAPI স্কিমা তৈরি করে, ভেতরের ধাপগুলো।
* `get_openapi()` দিয়ে নিজের মতো স্কিমা তৈরি আর পরিবর্তন করা।
* ReDoc-এ নিজের লোগো যোগ করার উদাহরণ।
* স্কিমা একবার তৈরি করে cache-এ রাখা।

///

কিছু ক্ষেত্রে আপনাকে তৈরি হওয়া OpenAPI স্কিমা পরিবর্তন করতে হতে পারে।

এই অংশে দেখবেন কীভাবে।

(OpenAPI স্কিমা হলো আপনার API-র একটি মেশিন-পাঠযোগ্য বিবরণ, JSON আকারে। `/docs` আর `/redoc` এটি পড়েই ডকুমেন্টেশন দেখায়।)

## স্বাভাবিক প্রক্রিয়া { #the-normal-process }

স্বাভাবিক (ডিফল্ট) প্রক্রিয়াটি এরকম।

একটি `FastAPI` অ্যাপ্লিকেশনের (ইনস্ট্যান্সের) একটি `.openapi()` মেথড আছে, যা OpenAPI স্কিমা ফেরত দেবে বলে আশা করা হয়।

অ্যাপ্লিকেশন অবজেক্ট তৈরির অংশ হিসেবে, `/openapi.json`-এর জন্য (বা আপনার `openapi_url` যা সেট করেছেন তার জন্য) একটি *পাথ অপারেশন* নিবন্ধিত হয়।

এটি শুধু অ্যাপ্লিকেশনের `.openapi()` মেথডের ফলাফলসহ একটি JSON রেসপন্স ফেরত দেয়।

ডিফল্টভাবে, `.openapi()` মেথড যা করে তা হলো `.openapi_schema` প্রপার্টিতে কিছু আছে কিনা দেখা আর থাকলে তা ফেরত দেওয়া।

না থাকলে, এটি `fastapi.openapi.utils.get_openapi`-এর ইউটিলিটি ফাংশন ব্যবহার করে সেগুলো তৈরি করে।

আর সেই `get_openapi()` ফাংশনটি প্যারামিটার হিসেবে নেয়:

* `title`: OpenAPI শিরোনাম, ডকসে দেখানো হয়।
* `version`: আপনার API-র সংস্করণ, যেমন `2.5.0`।
* `openapi_version`: ব্যবহৃত OpenAPI স্পেসিফিকেশনের সংস্করণ। ডিফল্টভাবে সর্বশেষটি: `3.1.0`।
* `summary`: API-র একটি সংক্ষিপ্ত সারসংক্ষেপ।
* `description`: আপনার API-র বর্ণনা, এতে markdown থাকতে পারে আর এটি ডকসে দেখানো হবে।
* `routes`: অ্যাপ্লিকেশনের রাউটগুলো, `app.routes` থেকে নেওয়া। FastAPI এগুলো দিয়ে নিবন্ধিত *পাথ অপারেশনগুলো* সংগ্রহ করে, যুক্ত করা রাউটারগুলোরগুলোসহ।

/// tip | কারিগরি বিবরণ

`app.routes` হলো একটি নিচু-স্তরের রাউট ট্রি। এতে এমন রাউট প্রার্থীও থাকতে পারে যা FastAPI যুক্ত রাউটারগুলোর জন্য ভেতরে ভেতরে ব্যবহার করে, শুধু চূড়ান্ত `APIRoute` অবজেক্ট নয়।

তবুও আপনি `get_openapi()`-তে `app.routes` দিতে পারেন। FastAPI কার্যকর পাথ অপারেশনগুলো সংগ্রহ করতে সেই রাউট ট্রি ঘুরে দেখবে।

///

/// note | নোট

`summary` প্যারামিটারটি OpenAPI 3.1.0 ও তার পরে পাওয়া যায়, FastAPI 0.99.0 ও তার পরের সংস্করণ এটি সাপোর্ট করে।

///

/// tip | উদাহরণ দিয়ে বুঝি

`.openapi()` হলো একটি দোকানের ক্যাটালগ ছাপার মেশিন। প্রথমবার কেউ ক্যাটালগ চাইলে মেশিন ছেপে দেয় আর একটি কপি তাকে রেখে দেয় (`.openapi_schema`)। পরে কেউ চাইলে আবার না ছেপে সেই কপিটিই দেয়। এই পেজে আমরা মেশিনটাকে নিজের মতো বানাব, যাতে ক্যাটালগে নিজের লোগো থাকে।

ওপরের তথ্য ব্যবহার করে, আপনি একই ইউটিলিটি ফাংশন দিয়ে OpenAPI স্কিমা তৈরি করে যে অংশগুলো দরকার সেগুলো ওভাররাইড করতে পারেন।

### OpenAPI স্কিমা cache করুন { #cache-the-openapi-schema }

আপনার তৈরি করা স্কিমা সংরক্ষণ করতে `.openapi_schema` প্রপার্টিটি একটি "cache" হিসেবে ব্যবহার করতে পারেন।

এভাবে, কোনো ব্যবহারকারী যতবার আপনার API ডকস খুলবে ততবার আপনার অ্যাপ্লিকেশনকে স্কিমা তৈরি করতে হবে না।

এটি শুধু একবার তৈরি হবে, তারপর পরের রিকোয়েস্টগুলোর জন্য একই cache করা স্কিমা ব্যবহার হবে।

/// info | পুরো কোডটি সহজ ভাষায়

* লাইন ১৩–১৪: স্কিমা আগেই তৈরি হয়ে থাকলে (`app.openapi_schema`) সেটিই ফেরত দাও।

* লাইন ২৯: `app.openapi = custom_openapi` দিয়ে FastAPI-এর ডিফল্ট মেথড বদলে আমাদেরটা বসানো।
