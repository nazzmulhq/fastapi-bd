# কুকি প্যারামিটার { #cookie-parameters }

/// note | এই পেজে যা শিখবেন

* কুকি কী, আর রিকোয়েস্টের সাথে আসা কুকি কীভাবে পড়বেন।
* কেন `/docs` থেকে কুকি পাঠিয়ে পরীক্ষা করা যায় না।

///

**কুকি** হলো ছোট ছোট তথ্য, যা একটি ওয়েবসাইট আপনার ব্রাউজারে রেখে দেয়। পরে ওই সাইটে যতবার রিকোয়েস্ট পাঠান, ব্রাউজার নিজে থেকেই সেই কুকিগুলো সাথে পাঠায়। যেমন আপনি লগইন করা আছেন কিনা, কোন ভাষা বেছে নিয়েছেন, কার্টে কী আছে, এসব মনে রাখতে কুকি ব্যবহার হয়।

`Query` আর `Path` প্যারামিটার যেভাবে সংজ্ঞায়িত করেন, কুকি প্যারামিটারও ঠিক সেভাবেই সংজ্ঞায়িত করতে পারেন।

/// info | কোডটি সহজ ভাষায়

`ads_id: Annotated[str | None, Cookie()] = None` মানে: রিকোয়েস্টের সাথে আসা কুকিগুলোর মধ্যে `ads_id` নামের কুকিটি খুঁজে এর মান দাও। না থাকলে `None`। প্যারামিটারের নামই কুকির নাম।

///

/// note | কারিগরি বিবরণ

`Cookie` হলো `Path` আর `Query`-র একটি "বোন" ক্লাস। এটিও একই সাধারণ `Param` ক্লাস থেকে ইনহেরিট করে।

তবে মনে রাখবেন, `fastapi` থেকে `Query`, `Path`, `Cookie` ইত্যাদি ইমপোর্ট করলে সেগুলো আসলে এমন ফাংশন যা বিশেষ ক্লাস রিটার্ন করে।

///

/// note | নোট

কুকি ঘোষণা করতে `Cookie` ব্যবহার করতেই হবে, নইলে প্যারামিটারগুলো কুয়েরি প্যারামিটার হিসেবে ধরা হবে।

///

/// note | নোট

মনে রাখবেন, **ব্রাউজার কুকি** বিশেষভাবে আর পর্দার আড়ালে **সামলায়**, তাই **JavaScript**-কে সহজে এগুলোতে হাত দিতে **দেয় না**।

`/docs`-এর **API ডকুমেন্টেশন UI**-তে গেলে আপনার *পাথ অপারেশনগুলোর* কুকির **ডকুমেন্টেশন** দেখতে পাবেন।

কিন্তু **ডেটা পূরণ করে** "Execute" চাপলেও, যেহেতু ডকুমেন্টেশন UI **JavaScript** দিয়ে চলে, তাই কুকিগুলো পাঠানো হবে না, আর আপনি এমন একটি **এরর** বার্তা দেখবেন যেন কোনো মানই লেখেননি।

কুকিসহ পরীক্ষা করতে `curl`, Postman বা টেস্ট কোড (`TestClient`) ব্যবহার করুন। যেমন:

```console
$ curl http://127.0.0.1:8000/items/ --cookie "ads_id=abc123"
```

///

## সংক্ষেপে { #recap }

`Query` আর `Path`-এর মতো একই সাধারণ ধরন ব্যবহার করে `Cookie` দিয়ে কুকি ঘোষণা করুন।

/// check | সংক্ষেপে মনে রাখুন

* কুকি পড়তে: `name: Annotated[str | None, Cookie()] = None`।
* `Cookie()` না দিলে প্যারামিটারটি কুয়েরি প্যারামিটার ধরা হবে।
* `/docs` থেকে কুকি পাঠানো যায় না, পরীক্ষার জন্য `curl` বা টেস্ট ব্যবহার করুন।
