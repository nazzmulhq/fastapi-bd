# পাথ অপারেশন কনফিগারেশন { #path-operation-configuration }

/// note | এই পেজে যা শিখবেন

* ডেকোরেটরে কিছু প্যারামিটার দিয়ে পাথ অপারেশন সাজানো: স্ট্যাটাস কোড, ট্যাগ, সারাংশ, বিবরণ।
* ফাংশনের docstring থেকে স্বয়ংক্রিয় বিবরণ।
* একটি পাথ অপারেশনকে deprecated চিহ্নিত করা।

///

আপনার *পাথ অপারেশন ডেকোরেটরকে* কনফিগার করতে এতে কয়েকটি প্যারামিটার দিতে পারেন। এগুলো মূলত `/docs`-এর ডকুমেন্টেশন সুন্দর ও গোছানো করতে কাজে লাগে।

/// warning | সতর্কতা

খেয়াল করুন, এই প্যারামিটারগুলো সরাসরি *পাথ অপারেশন ডেকোরেটরে* দেওয়া হয়, আপনার *পাথ অপারেশন ফাংশনে* নয়।

///

## রেসপন্স স্ট্যাটাস কোড { #response-status-code }

আপনার *পাথ অপারেশনের* রেসপন্সে ব্যবহারের জন্য (HTTP) `status_code` সংজ্ঞায়িত করতে পারেন।

সরাসরি `404`-এর মতো `int` কোড দিতে পারেন।

কিন্তু প্রতিটি সংখ্যা কোড কীসের জন্য তা মনে না থাকলে `status`-এর শর্টকাট কনস্ট্যান্টগুলো ব্যবহার করতে পারেন:

{* ../../docs_src/path_operation_configuration/tutorial001_py310.py hl[1,15] *}

ওই স্ট্যাটাস কোড রেসপন্সে ব্যবহার হবে আর OpenAPI স্কিমাতে যোগ হবে।

/// note | কারিগরি বিবরণ

`from starlette import status`-ও ব্যবহার করতে পারতেন।

**FastAPI** ডেভেলপার হিসেবে আপনার সুবিধার জন্যই একই `starlette.status`-কে `fastapi.status` হিসেবে দেয়। কিন্তু এটি সরাসরি Starlette থেকে আসে।

///

## ট্যাগ { #tags }

আপনার *পাথ অপারেশনে* ট্যাগ যোগ করতে পারেন। `tags` প্যারামিটারে `str`-এর একটি `list` দিন (সাধারণত শুধু একটি `str`):

{* ../../docs_src/path_operation_configuration/tutorial002_py310.py hl[15,20,25] *}

সেগুলো OpenAPI স্কিমাতে যোগ হবে, আর স্বয়ংক্রিয় ডকুমেন্টেশন ইন্টারফেস সেগুলো ব্যবহার করবে:

<img src="/img/tutorial/path-operation-configuration/image01.png">

ট্যাগ হলো লাইব্রেরির তাকের লেবেলের মতো। একই ট্যাগের পাথ অপারেশনগুলো `/docs`-এ একসাথে একটি দলে দেখায়, যেমন "items" দলে পণ্য-সংক্রান্ত সব, "users" দলে ব্যবহারকারী-সংক্রান্ত সব। বড় API-তে খুঁজে পাওয়া সহজ হয়।

### Enum দিয়ে ট্যাগ { #tags-with-enums }

আপনার অ্যাপ্লিকেশন বড় হলে হয়তো **অনেকগুলো ট্যাগ** জমে যাবে, আর আপনি নিশ্চিত হতে চাইবেন যে সম্পর্কিত *পাথ অপারেশনগুলোর* জন্য সবসময় **একই ট্যাগ** ব্যবহার করছেন।

এসব ক্ষেত্রে ট্যাগগুলো একটি `Enum`-এ রাখা যুক্তিসঙ্গত হতে পারে।

**FastAPI** সাধারণ স্ট্রিংয়ের মতোই এটি সাপোর্ট করে:

{* ../../docs_src/path_operation_configuration/tutorial002b_py310.py hl[1,8:10,13,18] *}

এতে বানান ভুলের ঝুঁকি থাকে না: `"itmes"` লিখলে কেউ ধরবে না, কিন্তু `Tags.itmes` লিখলে এডিটর সাথে সাথে এরর দেখাবে।

## docstring থেকে বিবরণ { #description-from-docstring }

যেহেতু বিবরণ সাধারণত লম্বা হয় আর একাধিক লাইনে ছড়িয়ে থাকে, তাই আপনি *পাথ অপারেশনের* বিবরণ ফাংশনের <dfn title="ডকুমেন্টেশনের জন্য ব্যবহৃত, ফাংশনের ভেতরের প্রথম এক্সপ্রেশন হিসেবে থাকা (কোনো ভেরিয়েবলে না বসানো) একটি বহু-লাইনের স্ট্রিং">docstring</dfn>-এ ঘোষণা করতে পারেন, আর **FastAPI** সেখান থেকে পড়ে নেবে।

docstring-এ [Markdown](https://en.wikipedia.org/wiki/Markdown) লিখতে পারেন, এটি সঠিকভাবে বুঝে দেখানো হবে (docstring-এর ইনডেন্টেশন বিবেচনায় রেখে)। Markdown মানে `**মোটা**`, `- তালিকা` এর মতো সহজ চিহ্ন দিয়ে লেখা সাজানো।

/// note | নোট

খেয়াল করুন, `response_description` বিশেষভাবে রেসপন্সকে বোঝায়, আর `description` সাধারণভাবে পুরো *পাথ অপারেশনকে* বোঝায়।

///

/// tip | পরামর্শ

OpenAPI অনুযায়ী প্রতিটি *পাথ অপারেশনে* একটি রেসপন্স বিবরণ থাকতে হবে।

তাই আপনি না দিলে **FastAPI** স্বয়ংক্রিয়ভাবে "Successful response" (সফল রেসপন্স) লিখে একটি তৈরি করে দেবে।

## একটি *পাথ অপারেশন* deprecated করা { #deprecate-a-path-operation }

একটি *পাথ অপারেশনকে* সরিয়ে না ফেলে <dfn title="পুরোনো, ব্যবহার না করার পরামর্শ দেওয়া হয়">deprecated</dfn> হিসেবে চিহ্নিত করতে চাইলে `deprecated` প্যারামিটার দিন:

ইন্টারঅ্যাকটিভ ডকুমেন্টেশনে এটি স্পষ্টভাবে deprecated হিসেবে চিহ্নিত থাকবে:

<img src="/img/tutorial/path-operation-configuration/image04.png">

deprecated আর deprecated নয় এমন *পাথ অপারেশনগুলো* দেখতে কেমন তা দেখুন:

<img src="/img/tutorial/path-operation-configuration/image05.png">

ধরুন আপনি একটি নতুন, ভালো পাথ বানিয়েছেন, কিন্তু পুরোনোটি এখনো কিছু মোবাইল অ্যাপ ব্যবহার করছে। হঠাৎ মুছে দিলে সেগুলো ভেঙে যাবে। তাই কিছুদিন deprecated চিহ্ন দিয়ে রাখেন, যাতে সবাই জানে এটি শিগগিরই বাদ যাবে।

## সংক্ষেপে { #recap }

*পাথ অপারেশন ডেকোরেটরে* প্যারামিটার দিয়ে সহজেই আপনার *পাথ অপারেশনগুলো* কনফিগার করতে আর মেটাডেটা যোগ করতে পারেন।

/// check | সংক্ষেপে মনে রাখুন

* এগুলো সব ডেকোরেটরের প্যারামিটার: `@app.post("/items/", ...)`।
* `status_code`, `tags`, `summary`, `description`, `response_description`, `deprecated`।
* লম্বা বিবরণ ফাংশনের docstring-এ (`"""..."""`) লিখুন, Markdown চলবে।
