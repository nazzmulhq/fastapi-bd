# রিকোয়েস্ট ফাইল { #request-files }

/// note | এই পেজে যা শিখবেন

* ক্লায়েন্টের আপলোড করা ফাইল কীভাবে গ্রহণ করবেন।
* `bytes` আর `UploadFile`-এর পার্থক্য, আর কখন কোনটি ব্যবহার করবেন।
* ঐচ্ছিক ফাইল আর একসাথে একাধিক ফাইল আপলোড।

///

ক্লায়েন্ট যে ফাইল আপলোড করবে তা `File` দিয়ে সংজ্ঞায়িত করতে পারেন। যেমন প্রোফাইল ছবি, PDF ডকুমেন্ট, Excel ফাইল ইত্যাদি।

/// note | নোট

আপলোড করা ফাইল গ্রহণ করতে প্রথমে [`python-multipart`](https://github.com/Kludex/python-multipart) ইনস্টল করুন।

আপনার প্রজেক্টে এটি যোগ করুন:

```console
$ uv add python-multipart
```

এর কারণ, আপলোড করা ফাইল "ফর্ম ডেটা" হিসেবে পাঠানো হয়।

///

ফাইলগুলো "ফর্ম ডেটা" হিসেবে আপলোড হবে।

আপনার *পাথ অপারেশন ফাংশনের* প্যারামিটারের টাইপ `bytes` ঘোষণা করলে **FastAPI** আপনার হয়ে ফাইলটি পড়বে, আর আপনি বিষয়বস্তু `bytes` হিসেবে পাবেন।

মনে রাখবেন, এর মানে পুরো বিষয়বস্তু মেমরিতে (RAM-এ) রাখা হবে। ছোট ফাইলের জন্য এটি ভালো কাজ করবে।

কিন্তু অনেক ক্ষেত্রে `UploadFile` ব্যবহার করলে আপনার সুবিধা হতে পারে।

## `UploadFile`-সহ ফাইল প্যারামিটার { #file-parameters-with-uploadfile }

`UploadFile` টাইপ দিয়ে একটি ফাইল প্যারামিটার সংজ্ঞায়িত করুন:

{* ../../docs_src/request_files/tutorial001_an_py310.py hl[14] *}

/// info | কোডটি সহজ ভাষায়

* লাইন ৯-১০: `file: Annotated[bytes, File()]`: পুরো ফাইল একবারে বাইট হিসেবে পাওয়া যায়। `len(file)` দিয়ে ফাইলের আকার (বাইটে) ফেরত দেওয়া হচ্ছে।
* লাইন ১৪-১৫: `file: UploadFile`: একটি ফাইল অবজেক্ট পাওয়া যায়, যা থেকে নাম (`file.filename`), ধরন, আর বিষয়বস্তু আলাদাভাবে পাওয়া যায়। এখানে শুধু নাম ফেরত দেওয়া হচ্ছে।

`/docs`-এ গেলে এই দুটি পাথে "Choose File" বাটন দেখবেন, সেখান থেকে ফাইল বেছে আপলোড করে দেখতে পারেন।

///

`bytes`-এর তুলনায় `UploadFile` ব্যবহারের অনেকগুলো সুবিধা আছে:

* প্যারামিটারের ডিফল্ট মানে `File()` ব্যবহার করতে হয় না।
* এটি একটি "spooled" ফাইল ব্যবহার করে:
    * একটি নির্দিষ্ট সর্বোচ্চ আকার পর্যন্ত ফাইলটি মেমরিতে রাখা হয়, আর সেই সীমা পার হলে ডিস্কে রাখা হয়।
* এর মানে ছবি, ভিডিও, বড় বাইনারি ইত্যাদির মতো বড় ফাইলের জন্যও এটি সব মেমরি খরচ না করে ভালো কাজ করবে।
* আপলোড করা ফাইল থেকে মেটাডেটা (যেমন নাম, ধরন) পাওয়া যায়।
* এর একটি [ফাইলের মতো](https://docs.python.org/3/glossary.html#term-file-like-object) `async` ইন্টারফেস আছে।
* এটি একটি আসল Python [`SpooledTemporaryFile`](https://docs.python.org/3/library/tempfile.html#tempfile.SpooledTemporaryFile) অবজেক্ট দেয়, যা আপনি সরাসরি এমন অন্য লাইব্রেরিতে পাঠাতে পারেন যেগুলো একটি ফাইলের মতো অবজেক্ট আশা করে।

/// tip | কখন কোনটি

* ছোট ফাইল (কয়েক KB), আর শুধু বিষয়বস্তু দরকার: `bytes`।
* ছবি, ভিডিও, বড় ফাইল, বা ফাইলের নাম/ধরন দরকার: `UploadFile`। সন্দেহ থাকলে `UploadFile` বেছে নিন।

///

### `UploadFile` { #uploadfile }

`UploadFile`-এর এই অ্যাট্রিবিউটগুলো আছে:

* `filename`: আপলোড করা মূল ফাইলের নামসহ একটি `str` (যেমন `myimage.jpg`)।
* `content_type`: কনটেন্ট টাইপসহ (MIME টাইপ / মিডিয়া টাইপ) একটি `str` (যেমন `image/jpeg`)। এটি দেখে বোঝা যায় ফাইলটি ছবি, PDF নাকি অন্য কিছু।
* `file`: একটি [`SpooledTemporaryFile`](https://docs.python.org/3/library/tempfile.html#tempfile.SpooledTemporaryFile) (একটি [ফাইলের মতো](https://docs.python.org/3/glossary.html#term-file-like-object) অবজেক্ট)। এটিই আসল Python ফাইল অবজেক্ট, যা আপনি সরাসরি এমন অন্য ফাংশন বা লাইব্রেরিতে পাঠাতে পারেন যেগুলো একটি "ফাইলের মতো" অবজেক্ট আশা করে।

`UploadFile`-এর এই `async` মেথডগুলো আছে। এগুলো সবাই ভেতরে ভেতরে সংশ্লিষ্ট ফাইল মেথডগুলো ডাকে (অভ্যন্তরীণ `SpooledTemporaryFile` ব্যবহার করে)।

* `write(data)`: ফাইলে `data` (`str` বা `bytes`) লেখে।
* `read(size)`: ফাইলের `size` (`int`) সংখ্যক বাইট/অক্ষর পড়ে।
* `seek(offset)`: ফাইলের `offset` (`int`) বাইট অবস্থানে যায়।
    * যেমন, `await myfile.seek(0)` ফাইলের শুরুতে চলে যাবে।
    * এটি বিশেষভাবে কাজের যদি আপনি একবার `await myfile.read()` চালান আর তারপর আবার বিষয়বস্তু পড়তে হয়। (একবার পড়ার পরে "কার্সর" ফাইলের শেষে চলে যায়, তাই আবার পড়তে শুরুতে ফিরতে হয়।)
* `close()`: ফাইলটি বন্ধ করে।

যেহেতু এই সব মেথড `async` মেথড, তাই এগুলোকে "await" করতে হবে।

যেমন, একটি `async` *পাথ অপারেশন ফাংশনের* ভেতরে এভাবে বিষয়বস্তু পেতে পারেন:

```Python
contents = await myfile.read()
```

আপনি যদি একটি সাধারণ `def` *পাথ অপারেশন ফাংশনের* ভেতরে থাকেন, তাহলে সরাসরি `UploadFile.file` ব্যবহার করতে পারেন, যেমন:

```Python
contents = myfile.file.read()
```

/// note | `async` কারিগরি বিবরণ

আপনি যখন `async` মেথডগুলো ব্যবহার করেন, **FastAPI** ফাইল মেথডগুলো একটি থ্রেডপুলে চালিয়ে সেগুলোর জন্য await করে।

///

/// note | Starlette কারিগরি বিবরণ

**FastAPI**-এর `UploadFile` সরাসরি **Starlette**-এর `UploadFile` থেকে ইনহেরিট করে, তবে **Pydantic** আর FastAPI-এর অন্য অংশগুলোর সাথে সামঞ্জস্যপূর্ণ করতে কিছু প্রয়োজনীয় অংশ যোগ করে।

## "ফর্ম ডেটা" কী { #what-is-form-data }

HTML ফর্ম (`<form></form>`) যেভাবে সার্ভারে ডেটা পাঠায়, তাতে সাধারণত ওই ডেটার জন্য একটি "বিশেষ" এনকোডিং ব্যবহার হয়, যা JSON থেকে আলাদা।

**FastAPI** নিশ্চিত করবে যে ওই ডেটা JSON-এর বদলে সঠিক জায়গা থেকে পড়া হচ্ছে।

/// note | কারিগরি বিবরণ

ফর্মে ফাইল না থাকলে ফর্মের ডেটা সাধারণত "মিডিয়া টাইপ" `application/x-www-form-urlencoded` দিয়ে এনকোড করা হয়।

কিন্তু ফর্মে ফাইল থাকলে এটি `multipart/form-data` হিসেবে এনকোড হয়। আপনি `File` ব্যবহার করলে **FastAPI** জানবে যে বডির সঠিক অংশ থেকে ফাইলগুলো নিতে হবে।

এই এনকোডিং আর ফর্ম ফিল্ড নিয়ে আরও পড়তে চাইলে [`POST`-এর জন্য <abbr title="Mozilla Developer Network">MDN</abbr> ওয়েব ডকুমেন্টেশনে](https://developer.mozilla.org/en-US/docs/Web/HTTP/Methods/POST) যান।

///

/// warning | সতর্কতা

একটি *পাথ অপারেশনে* একাধিক `File` আর `Form` প্যারামিটার ঘোষণা করতে পারেন, কিন্তু একই সাথে JSON হিসেবে গ্রহণের জন্য `Body` ফিল্ড ঘোষণা করতে পারবেন না। কারণ রিকোয়েস্টের বডি তখন `application/json`-এর বদলে `multipart/form-data` দিয়ে এনকোড করা থাকবে।

এটি **FastAPI**-এর কোনো সীমাবদ্ধতা নয়, এটি HTTP প্রোটোকলেরই অংশ।

এটি ব্যবহার করতে `bytes` বা `UploadFile`-এর একটি লিস্ট ঘোষণা করুন:

/// info | কোডটি সহজ ভাষায়

* লাইন ১০-১১: `list[bytes]`: সব ফাইল বাইট হিসেবে, প্রতিটির আকার ফেরত দেওয়া হচ্ছে।
* লাইন ১৫-১৬: `list[UploadFile]`: সব ফাইল অবজেক্ট হিসেবে, প্রতিটির নাম ফেরত দেওয়া হচ্ছে। `[file.filename for file in files]` হলো "লিস্ট কম্প্রিহেনশন", মানে প্রতিটি ফাইলের নাম নিয়ে নতুন একটি তালিকা।
* লাইন ১৯-৩৩: `/` পাথে একটি ছোট HTML পেজ ফেরত দেওয়া হচ্ছে, যাতে দুটি ফর্ম আছে। `enctype="multipart/form-data"` ফাইল পাঠানোর জন্য জরুরি, আর `multiple` দিয়ে একসাথে কয়েকটি ফাইল বেছে নেওয়া যায়। ব্রাউজারে `http://127.0.0.1:8000/` খুলে সরাসরি পরীক্ষা করতে পারবেন।

## সংক্ষেপে { #recap }

রিকোয়েস্টে আপলোড হওয়া ফাইল, যা ফর্ম ডেটা হিসেবে পাঠানো হয়, ঘোষণা করতে `File`, `bytes` আর `UploadFile` ব্যবহার করুন।

/// check | সংক্ষেপে মনে রাখুন

* ফাইল আপলোডের জন্য `python-multipart` লাগে।
* ছোট ফাইল: `Annotated[bytes, File()]`, বড় ফাইল বা নাম/ধরন দরকার হলে: `UploadFile`।
* `UploadFile`-এ আছে `filename`, `content_type`, আর `await file.read()`।
* একাধিক ফাইল: `list[UploadFile]`। ঐচ্ছিক ফাইল: `UploadFile | None = None`।
* ফাইলের সাথে JSON বডি একসাথে পাঠানো যায় না, ফর্ম ফিল্ড (`Form`) পাঠানো যায়।
