# হেডার প্যারামিটার { #header-parameters }

/// note | এই পেজে যা শিখবেন

* রিকোয়েস্টের হেডার কীভাবে পড়বেন।
* কেন Python-এ `user_agent` লিখলেও FastAPI `User-Agent` হেডার খোঁজে।
* একই নামের একাধিক হেডার কীভাবে লিস্ট হিসেবে নেবেন।

///

**হেডার** হলো রিকোয়েস্টের সাথে পাঠানো বাড়তি তথ্য, "নাম: মান" আকারে। যেমন `User-Agent` জানায় কোন ব্রাউজার বা প্রোগ্রাম রিকোয়েস্ট পাঠাচ্ছে, `Authorization`-এ থাকে লগইন টোকেন, `Accept-Language` জানায় পছন্দের ভাষা।

`Query`, `Path` আর `Cookie` প্যারামিটার যেভাবে সংজ্ঞায়িত করেন, হেডার প্যারামিটারও ঠিক সেভাবেই সংজ্ঞায়িত করতে পারেন।

ডিফল্ট মানের পাশাপাশি বাড়তি সব যাচাই বা অ্যানোটেশন প্যারামিটারও সংজ্ঞায়িত করতে পারেন:

{* ../../docs_src/header_params/tutorial001_an_py310.py hl[9] *}

/// info | কোডটি সহজ ভাষায়

`user_agent: Annotated[str | None, Header()] = None` মানে: রিকোয়েস্টের `User-Agent` হেডারের মান দাও। ব্রাউজার থেকে `/items/` খুললে দেখবেন এরকম কিছু: `"Mozilla/5.0 (Macintosh; ...)"`, মানে আপনার ব্রাউজারের পরিচয়।

///

/// note | কারিগরি বিবরণ

`Header` হলো `Path`, `Query` আর `Cookie`-র একটি "বোন" ক্লাস। এটিও একই সাধারণ `Param` ক্লাস থেকে ইনহেরিট করে।

তবে মনে রাখবেন, `fastapi` থেকে `Query`, `Path`, `Header` ইত্যাদি ইমপোর্ট করলে সেগুলো আসলে এমন ফাংশন যা বিশেষ ক্লাস রিটার্ন করে।

///

/// note | নোট

হেডার ঘোষণা করতে `Header` ব্যবহার করতেই হবে, নইলে প্যারামিটারগুলো কুয়েরি প্যারামিটার হিসেবে ধরা হবে।

///

## স্বয়ংক্রিয় রূপান্তর { #automatic-conversion }

`Path`, `Query` আর `Cookie`-র দেওয়া সুবিধার ওপরে `Header`-এর একটু বাড়তি কার্যকারিতা আছে।

বেশিরভাগ স্ট্যান্ডার্ড হেডারের নামের শব্দগুলো একটি "হাইফেন" অক্ষর দিয়ে আলাদা থাকে, যাকে "বিয়োগ চিহ্ন" (`-`)-ও বলা হয়।

কিন্তু `user-agent`-এর মতো একটি ভেরিয়েবল Python-এ অবৈধ।

তাই ডিফল্টভাবে `Header` প্যারামিটারের নামের আন্ডারস্কোর (`_`) অক্ষরকে হাইফেনে (`-`) রূপান্তর করে হেডারগুলো বের করে আর ডকুমেন্ট করে।

এছাড়া HTTP হেডার বড় হাতের/ছোট হাতের অক্ষরের পার্থক্য মানে না (case-insensitive), তাই এগুলো সাধারণ Python ধরনে (যাকে "snake_case"-ও বলে) ঘোষণা করতে পারেন।

অর্থাৎ Python কোডে সাধারণত যেমন লেখেন তেমনই `user_agent` ব্যবহার করতে পারেন, প্রথম অক্ষরগুলো বড় হাতের করে `User_Agent` বা এরকম কিছু লেখার দরকার নেই।

| Python-এ লিখবেন | FastAPI যে হেডার খুঁজবে |
|---|---|
| `user_agent` | `user-agent` (যেমন `User-Agent`) |
| `x_token` | `x-token` (যেমন `X-Token`) |
| `accept_language` | `accept-language` |

কোনো কারণে আন্ডারস্কোর থেকে হাইফেনে স্বয়ংক্রিয় রূপান্তর বন্ধ করতে চাইলে `Header`-এর `convert_underscores` প্যারামিটার `False` সেট করুন:

## পুনরাবৃত্ত হেডার { #duplicate-headers }

একই হেডার একাধিকবার আসা সম্ভব। মানে একই হেডারের একাধিক মান।

এসব ক্ষেত্র টাইপ ঘোষণায় একটি লিস্ট ব্যবহার করে সংজ্ঞায়িত করতে পারেন।

পুনরাবৃত্ত হেডারের সব মান একটি Python `list` হিসেবে পাবেন।

যেমন, একাধিকবার আসতে পারে এমন একটি `X-Token` হেডার ঘোষণা করতে লিখতে পারেন:

{* ../../docs_src/header_params/tutorial003_an_py310.py hl[9] *}

ওই *পাথ অপারেশনে* যদি এরকম দুটি HTTP হেডার পাঠান:

```
X-Token: foo
X-Token: bar
```

তাহলে রেসপন্স হবে এমন:

```JSON
{
    "X-Token values": [
        "bar",
        "foo"
    ]
}
```

## সংক্ষেপে { #recap }

`Query`, `Path` আর `Cookie`-র মতো একই সাধারণ ধরন ব্যবহার করে `Header` দিয়ে হেডার ঘোষণা করুন।

আর ভেরিয়েবলের নামের আন্ডারস্কোর নিয়ে চিন্তা করবেন না, **FastAPI** সেগুলো রূপান্তরের দায়িত্ব নেবে।

/// check | সংক্ষেপে মনে রাখুন

* হেডার পড়তে: `user_agent: Annotated[str | None, Header()] = None`।
* Python-এর `_` স্বয়ংক্রিয়ভাবে হেডারের `-` হয়ে যায়, বড়/ছোট হাতের অক্ষর কোনো ব্যাপার না।
* একই হেডার একাধিকবার আসলে `list[str]` টাইপ দিন।
