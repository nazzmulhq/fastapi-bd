# বডি - একাধিক প্যারামিটার { #body-multiple-parameters }

/// note | এই পেজে যা শিখবেন

* `Path`, `Query` আর বডি প্যারামিটার একসাথে মেশানো, আর বডিকে ঐচ্ছিক করা।
* একটি রিকোয়েস্টে একাধিক মডেল (যেমন `item` আর `user`) গ্রহণ করা।
* `Body` দিয়ে একক মান (যেমন একটি সংখ্যা) বডির অংশ হিসেবে নেওয়া।
* `embed=True` দিয়ে একটিমাত্র মডেলকেও একটি কী-এর ভেতরে রাখা।

///

`Path` আর `Query` কীভাবে ব্যবহার করতে হয় তা দেখার পর, এবার রিকোয়েস্ট বডি ঘোষণার আরও উন্নত ব্যবহার দেখা যাক।

## `Path`, `Query` আর বডি প্যারামিটার মেশানো { #mix-path-query-and-body-parameters }

প্রথমত, অবশ্যই আপনি `Path`, `Query` আর রিকোয়েস্ট বডি প্যারামিটারের ঘোষণা ইচ্ছামতো মেশাতে পারেন, **FastAPI** জানবে কী করতে হবে।

আর ডিফল্ট মান `None` দিয়ে বডি প্যারামিটারকেও ঐচ্ছিক ঘোষণা করতে পারেন:

/// note | নোট

খেয়াল করুন, এই ক্ষেত্রে বডি থেকে আসা `item` ঐচ্ছিক, কারণ এর ডিফল্ট মান `None`।

///

/// info | কোডটি সহজ ভাষায় (লাইন ১৮-২০)

* `item_id`: পাথ থেকে, ০ থেকে ১০০০ এর মধ্যে।
* `q`: ঐচ্ছিক কুয়েরি প্যারামিটার।
* `item: Item | None = None`: বডি থেকে, কিন্তু ঐচ্ছিক। ক্লায়েন্ট বডি না পাঠালেও রিকোয়েস্ট সফল হবে, তখন `item` হবে `None`।

///

## একাধিক বডি প্যারামিটার { #multiple-body-parameters }

আগের উদাহরণে *পাথ অপারেশনগুলো* একটি `Item`-এর অ্যাট্রিবিউটসহ JSON বডি আশা করত, এভাবে:

```JSON
{
    "name": "Foo",
    "description": "The pretender",
    "price": 42.0,
    "tax": 3.2
}
```

কিন্তু একাধিক বডি প্যারামিটারও ঘোষণা করতে পারেন, যেমন `item` আর `user`:

{* ../../docs_src/body_multiple_params/tutorial002_py310.py hl[20] *}

এই ক্ষেত্রে **FastAPI** খেয়াল করবে যে ফাংশনে একাধিক বডি প্যারামিটার আছে (দুটি প্যারামিটার Pydantic মডেল)।

তাই এটি প্যারামিটারের নামগুলোকে বডির কী (ফিল্ডের নাম) হিসেবে ব্যবহার করবে, আর এমন একটি বডি আশা করবে:

```JSON
{
    "item": {
        "name": "Foo",
        "description": "The pretender",
        "price": 42.0,
        "tax": 3.2
    },
    "user": {
        "username": "dave",
        "full_name": "Dave Grohl"
    }
}
```

/// note | নোট

খেয়াল করুন, `item` আগের মতো একইভাবে ঘোষণা করা হলেও এখন এটি বডির ভেতরে `item` কী-এর নিচে থাকবে বলে আশা করা হয়।

///

/// tip | উদাহরণ দিয়ে বুঝি

একটি রিকোয়েস্টে বডি থাকে মাত্র একটিই, একটি খামের মতো। একটিমাত্র চিঠি (মডেল) থাকলে সরাসরি খামে রাখা হয়। দুটি চিঠি (`item` আর `user`) পাঠাতে হলে খামের ভেতরে দুটি লেবেল করা ভাঁজ রাখা হয়: একটিতে লেখা "item", আরেকটিতে "user"। FastAPI ঠিক এভাবেই JSON-এ প্যারামিটারের নামগুলো কী হিসেবে ব্যবহার করে।

///

**FastAPI** রিকোয়েস্ট থেকে স্বয়ংক্রিয়ভাবে রূপান্তর করবে, যাতে `item` প্যারামিটার তার নির্দিষ্ট বিষয়বস্তু পায়, আর `user`-ও তারটা পায়।

এটি এই যৌগিক ডেটার যাচাই করবে, আর OpenAPI স্কিমা ও স্বয়ংক্রিয় ডকুমেন্টেশনেও এভাবেই লিখবে।

## বডিতে একক মান { #singular-values-in-body }

কুয়েরি আর পাথ প্যারামিটারের বাড়তি তথ্য সংজ্ঞায়িত করতে যেমন `Query` আর `Path` আছে, তেমনই **FastAPI** একটি সমতুল্য `Body` দেয়।

যেমন, আগের মডেলটি বাড়িয়ে আপনি ঠিক করতে পারেন যে একই বডিতে `item` আর `user`-এর পাশাপাশি `importance` (গুরুত্ব) নামে আরেকটি কী চান।

এটি যেমন আছে তেমন ঘোষণা করলে, যেহেতু এটি একটি একক মান (`int`), তাই **FastAPI** ধরে নেবে এটি একটি কুয়েরি প্যারামিটার।

কিন্তু `Body` ব্যবহার করে আপনি **FastAPI**-কে বলে দিতে পারেন যে এটিকে বডির আরেকটি কী হিসেবে ধরতে:

{* ../../docs_src/body_multiple_params/tutorial003_an_py310.py hl[23] *}

এই ক্ষেত্রে **FastAPI** এমন একটি বডি আশা করবে:

```JSON
{
    "item": {
        "name": "Foo",
        "description": "The pretender",
        "price": 42.0,
        "tax": 3.2
    },
    "user": {
        "username": "dave",
        "full_name": "Dave Grohl"
    },
    "importance": 5
}
```

আবারও, এটি ডেটা টাইপ রূপান্তর করবে, যাচাই করবে, ডকুমেন্টেশন রাখবে ইত্যাদি।

## একাধিক বডি প্যারামিটার ও কুয়েরি { #multiple-body-params-and-query }

অবশ্যই, যেকোনো বডি প্যারামিটারের পাশাপাশি দরকার হলে বাড়তি কুয়েরি প্যারামিটারও ঘোষণা করতে পারেন।

যেহেতু ডিফল্টভাবে একক মানগুলো কুয়েরি প্যারামিটার হিসেবে ধরা হয়, তাই স্পষ্টভাবে `Query` যোগ করার দরকার নেই, শুধু এভাবে লিখতে পারেন:

```Python
q: str | None = None
```

যেমন:

{* ../../docs_src/body_multiple_params/tutorial004_an_py310.py hl[28] *}

/// info | কোডটি সহজ ভাষায়

* লাইন ২৩: `*` থাকায় পরের প্যারামিটারগুলো যেকোনো ক্রমে রাখা যায়।
* লাইন ২৪: `item_id` পাথ থেকে।
* লাইন ২৫-২৬: `item` আর `user` বডি থেকে (দুটি মডেল)।
* লাইন ২৭: `importance` বডি থেকে (`Body`), আর `gt=0` মানে শূন্যের চেয়ে বড় হতে হবে।
* লাইন ২৮: `q` কুয়েরি থেকে, ঐচ্ছিক।

///

/// note | নোট

`Query`, `Path` এবং পরে দেখবেন এমন অন্যগুলোর মতোই `Body`-তেও বাড়তি যাচাই ও মেটাডেটার একই সব প্যারামিটার আছে।

///

## একটিমাত্র বডি প্যারামিটার এমবেড করুন { #embed-a-single-body-parameter }

ধরা যাক আপনার কাছে Pydantic মডেল `Item` থেকে কেবল একটিমাত্র `item` বডি প্যারামিটার আছে।

ডিফল্টভাবে **FastAPI** তখন সরাসরি এর বডিটিই আশা করবে।

কিন্তু আপনি যদি চান যে এটি `item` কী-সহ একটি JSON আশা করুক, যার ভেতরে মডেলের বিষয়বস্তু থাকবে, যেমনটা বাড়তি বডি প্যারামিটার ঘোষণা করলে হয়, তাহলে `Body`-র বিশেষ প্যারামিটার `embed` ব্যবহার করতে পারেন:

```Python
item: Annotated[Item, Body(embed=True)]
```

যেমন:

{* ../../docs_src/body_multiple_params/tutorial005_an_py310.py hl[17] *}

এই ক্ষেত্রে **FastAPI** এমন একটি বডি আশা করবে:

```JSON hl_lines="2"
{
    "item": {
        "name": "Foo",
        "description": "The pretender",
        "price": 42.0,
        "tax": 3.2
    }
}
```

এটির বদলে:

```JSON
{
    "name": "Foo",
    "description": "The pretender",
    "price": 42.0,
    "tax": 3.2
}
```

"এমবেড" মানে "ভেতরে বসানো"। কখনো কখনো ক্লায়েন্ট বা অন্য কোনো সিস্টেম আগে থেকেই এই আকারে ডেটা পাঠায়, তখন এটি কাজে লাগে।

## সংক্ষেপে { #recap }

আপনার *পাথ অপারেশন ফাংশনে* একাধিক বডি প্যারামিটার যোগ করতে পারেন, যদিও একটি রিকোয়েস্টে কেবল একটিই বডি থাকতে পারে।

কিন্তু **FastAPI** এটি সামলাবে, আপনার ফাংশনে সঠিক ডেটা দেবে, আর *পাথ অপারেশনে* সঠিক স্কিমা যাচাই ও ডকুমেন্ট করবে।

একক মানও বডির অংশ হিসেবে গ্রহণ করার জন্য ঘোষণা করতে পারেন।

আর কেবল একটি প্যারামিটার ঘোষণা করা থাকলেও **FastAPI**-কে বডিটি একটি কী-এর ভেতরে এমবেড করতে বলতে পারেন।

/// check | সংক্ষেপে মনে রাখুন

* একাধিক মডেল প্যারামিটার থাকলে FastAPI প্যারামিটারের নামগুলো JSON-এর কী হিসেবে ব্যবহার করে।
* একক মান (`int`, `str`) বডিতে চাইলে `Annotated[int, Body()]`, নইলে সেটি কুয়েরি ধরা হবে।
* একটিমাত্র মডেলকেও কী-এর ভেতরে চাইলে `Body(embed=True)`।
* বডিকে ঐচ্ছিক করতে `item: Item | None = None`।
