# Pydantic People { #pydantic-people }

/// note | এই পেজে যা পাবেন

Pydantic-কে এগিয়ে নেওয়া মানুষেরা: রক্ষণাবেক্ষণকারী (maintainer), অন্যদের প্রশ্নের উত্তর দেওয়া বিশেষজ্ঞ, সবচেয়ে বেশি অবদান রাখা আর সবচেয়ে বেশি পর্যালোচনা (review) করা মানুষ।

///

Pydantic-এর রয়েছে অবদানকারী, পর্যালোচক আর বিশেষজ্ঞদের এক অসাধারণ কমিউনিটি, যারা প্রজেক্টটিকে এগিয়ে নিয়ে যান।
এখানে আমরা সেই মানুষদের আর তাদের অবদান উদযাপন করি।

/// tip | আপনিও এই তালিকায় আসতে পারেন

GitHub-এ অন্যদের প্রশ্নের উত্তর দিন, ডকুমেন্টেশন ঠিক করুন, বা pull request পর্যালোচনা করুন। কীভাবে শুরু করবেন: [Pydantic-কে সাহায্য করা](help_with_pydantic.md) আর [অবদান রাখা](contributing.md)।

///

## তথ্য নিয়ে { #about-the-data }

ওপরে দেখানো তথ্য প্রতি মাসে Github GraphQL API দিয়ে হিসাব করা হয় (দেখুন
[source code](https://github.com/pydantic/pydantic/tree/main/.github/actions/people/people.py);
যে script-এর ভিত্তিতে এই যুক্তি তৈরি, তার জন্য [Sebastián Ramírez](https://github.com/tiangolo)-কে অনেক ধন্যবাদ)।

পরিস্থিতির পরিবর্তন অনুযায়ী, বিভিন্ন ধরনের অবদানকারীর মানদণ্ড ভবিষ্যতে বদলাতে পারে।
