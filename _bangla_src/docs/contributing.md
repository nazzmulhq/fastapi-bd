# অবদান রাখা { #contributing }

/// note | এই পেজটি কী

"অবদান রাখা" (contributing) মানে FastAPI প্রজেক্টে নিজে কোড, ডকুমেন্টেশন বা অনুবাদ জমা দিয়ে সাহায্য করা। ওপেন সোর্স প্রজেক্ট সারা বিশ্বের স্বেচ্ছাসেবীদের অবদানেই এগিয়ে চলে।

///

প্রথমে, আপনি হয়তো [FastAPI-কে সাহায্য করা আর সাহায্য পাওয়ার](help-fastapi.md) মৌলিক উপায়গুলো দেখতে চাইবেন।

## ডেভেলপ করা { #developing }

প্রজেক্টে কোড দিয়ে অবদান রাখতে, অনুগ্রহ করে [tiangolo.com - Contributing](https://tiangolo.com/open-source/contributing/)-এর নির্দেশিকা অনুসরণ করুন।

/// tip | শুরু করার সহজ উপায়

* প্রথমে GitHub-এ অন্যদের প্রশ্নের উত্তর দিয়ে বা ডকুমেন্টেশনের ছোটখাটো ভুল ঠিক করে শুরু করুন।
* বড় পরিবর্তনের আগে একটি Discussion খুলে আলোচনা করে নিন, যাতে আপনার পরিশ্রম বৃথা না যায়।
* অবদানের নিয়ম (কোড স্টাইল, টেস্ট) ওপরের লিংকে বিস্তারিত দেওয়া আছে।

///
