# FastAPI Cloud { #fastapi-cloud }

/// note | এই পেজে যা শিখবেন

* মাত্র এক কমান্ডে আপনার FastAPI অ্যাপ ইন্টারনেটে তোলা।
* FastAPI Cloud আপনার হয়ে কী কী দায়িত্ব নেয়।
* অন্য ক্লাউড বা নিজের সার্ভারে ডিপ্লয়ের বিকল্প।

///

মাত্র **একটি কমান্ড** দিয়ে আপনার FastAPI অ্যাপ [FastAPI Cloud](https://fastapicloud.com)-এ ডিপ্লয় করতে পারেন। 🚀

<div class="termy">

```console
$ uv run fastapi deploy

Deploying to FastAPI Cloud...

✅ Deployment successful!

🐔 Ready the chicken! Your app is ready at https://myapp.fastapicloud.dev
```

</div>

CLI স্বয়ংক্রিয়ভাবে আপনার FastAPI অ্যাপ্লিকেশন খুঁজে বের করে ক্লাউডে ডিপ্লয় করবে। আপনি লগইন করা না থাকলে, অথেনটিকেশন প্রক্রিয়া সম্পূর্ণ করতে আপনার ব্রাউজার খুলবে।

ব্যস! এখন সেই URL-এ গিয়ে আপনার অ্যাপ ব্যবহার করতে পারেন। ✨

/// tip | উদাহরণ দিয়ে বুঝি

নিজে সার্ভার চালানো মানে নিজের জমিতে বাড়ি বানানো: জমি কেনা, বিদ্যুৎ-পানির লাইন, তালা, পাহারাদার সব নিজেকে সামলাতে হয়। FastAPI Cloud হলো সাজানো-গোছানো অ্যাপার্টমেন্টে ওঠার মতো: চাবি নিন আর থাকা শুরু করুন। নিরাপত্তা (HTTPS), লিফট (ভিড় বাড়লে বেশি সার্ভার) সবই বিল্ডিং কর্তৃপক্ষ সামলায়।

///

## FastAPI Cloud সম্পর্কে { #about-fastapi-cloud }

**[FastAPI Cloud](https://fastapicloud.com)** তৈরি করেছেন **FastAPI**-এর পেছনের একই লেখক আর দল।

এটি খুব কম পরিশ্রমে একটি API **তৈরি**, **ডিপ্লয়** আর **ব্যবহার** করার প্রক্রিয়াকে সহজ করে।

FastAPI দিয়ে অ্যাপ তৈরির যে **ডেভেলপার অভিজ্ঞতা**, সেটিই এটি ক্লাউডে **ডিপ্লয়** করার ক্ষেত্রেও নিয়ে আসে। 🎉

অ্যাপ ডিপ্লয় করার সময় আপনার যা যা দরকার হতো, তার বেশিরভাগই এটি সামলাবে, যেমন:

* HTTPS
* রেপ্লিকেশন (একাধিক কপি চালানো), রিকোয়েস্টের ভিত্তিতে স্বয়ংক্রিয়ভাবে বাড়ানো-কমানো (autoscaling)
* ইত্যাদি

FastAPI Cloud হলো *FastAPI and friends* ওপেন সোর্স প্রজেক্টগুলোর প্রধান স্পনসর আর অর্থায়নকারী। ✨

## অন্য ক্লাউড প্রোভাইডারে ডিপ্লয় { #deploy-to-other-cloud-providers }

FastAPI ওপেন সোর্স আর স্ট্যান্ডার্ডের ওপর ভিত্তি করে তৈরি। আপনার পছন্দের যেকোনো ক্লাউড প্রোভাইডারে FastAPI অ্যাপ ডিপ্লয় করতে পারেন।

তাদের সাথে FastAPI অ্যাপ ডিপ্লয় করতে আপনার ক্লাউড প্রোভাইডারের গাইড অনুসরণ করুন। 🤓

## নিজের সার্ভারে ডিপ্লয় { #deploy-your-own-server }

এই **ডিপ্লয়মেন্ট** গাইডে পরে আমি আপনাকে সব বিস্তারিতও শেখাব, যাতে আপনি বুঝতে পারেন কী ঘটছে, কী কী হওয়া দরকার, বা কীভাবে নিজে, নিজের সার্ভারেও FastAPI অ্যাপ ডিপ্লয় করবেন। 🤓

/// check | সংক্ষেপে মনে রাখুন

* সবচেয়ে সহজ পথ: FastAPI Cloud, এক কমান্ডে ডিপ্লয়, HTTPS আর autoscaling নিজে থেকেই।
* FastAPI কোনো নির্দিষ্ট ক্লাউডে আটকে নেই, যেকোনো জায়গায় চালানো যায়।
* নিজের সার্ভারে চালাতে চাইলে এই অধ্যায়ের পরের পেজগুলো পড়ুন।
