# ডিপ্লয়মেন্ট { #deployment }

/// note | এই অধ্যায়ে যা শিখবেন

* "ডিপ্লয়" করা মানে আসলে কী।
* ডিপ্লয় করার বিভিন্ন কৌশল: নিজে সার্ভার চালানো, ক্লাউড সার্ভিস, ইত্যাদি।
* পরের পেজগুলোতে: HTTPS, সার্ভার চালানো, ওয়ার্কার, Docker, আর কিছু গুরুত্বপূর্ণ ধারণা।

///

একটি **FastAPI** অ্যাপ্লিকেশন ডিপ্লয় করা তুলনামূলকভাবে সহজ।

## ডিপ্লয়মেন্ট মানে কী { #what-does-deployment-mean }

একটি অ্যাপ্লিকেশন **ডিপ্লয়** করা মানে এটিকে **ব্যবহারকারীদের জন্য উপলব্ধ** করতে দরকারি ধাপগুলো সম্পন্ন করা।

একটি **ওয়েব API**-এর জন্য, এর মানে সাধারণত এটিকে একটি **দূরের মেশিনে** (সার্ভারে) বসানো, এমন একটি **সার্ভার প্রোগ্রামসহ** যা ভালো পারফরম্যান্স, স্থিতিশীলতা ইত্যাদি দেয়, যাতে আপনার **ব্যবহারকারীরা** দক্ষভাবে, কোনো বাধা বা সমস্যা ছাড়াই অ্যাপ্লিকেশনটি **ব্যবহার** করতে পারেন।

এটি **ডেভেলপমেন্ট** পর্যায়ের বিপরীত, যেখানে আপনি ক্রমাগত কোড বদলাচ্ছেন, ভাঙছেন আর ঠিক করছেন, ডেভেলপমেন্ট সার্ভার বন্ধ করছেন আর আবার চালু করছেন, ইত্যাদি।

/// tip | উদাহরণ দিয়ে বুঝি

বাড়ির রান্নাঘরে নতুন রেসিপি পরীক্ষা করা হলো **ডেভেলপমেন্ট**: ভুল হলে আবার রাঁধেন, চুলা বন্ধ-চালু করেন, কেউ কিছু মনে করে না। রেস্টুরেন্ট খুলে প্রতিদিন শত শত গ্রাহককে খাবার পরিবেশন করা হলো **ডিপ্লয়মেন্ট**: এখানে চুলা সবসময় জ্বলতে হবে, খাবার সময়মতো আসতে হবে, কিছু নষ্ট হলে দ্রুত ঠিক করতে হবে। এই অধ্যায় সেই "রেস্টুরেন্ট চালানো" শেখায়।

///

## ডিপ্লয়মেন্টের কৌশল { #deployment-strategies }

আপনার নির্দিষ্ট প্রয়োজন আর আপনার ব্যবহৃত টুলের ওপর নির্ভর করে এটি করার কয়েকটি উপায় আছে।

আপনি কয়েকটি টুল মিলিয়ে নিজেই একটি **সার্ভার ডিপ্লয়** করতে পারেন, এমন একটি **ক্লাউড সার্ভিস** ব্যবহার করতে পারেন যা আপনার হয়ে কাজের একটি অংশ করে দেয়, অথবা আরও অন্যান্য সম্ভাব্য অপশন আছে।

যেমন, আমরা, FastAPI-এর পেছনের দলটি, তৈরি করেছি [**FastAPI Cloud**](https://fastapicloud.com), যাতে FastAPI অ্যাপ ক্লাউডে ডিপ্লয় করা যতটা সম্ভব সহজ হয়, FastAPI নিয়ে কাজ করার মতোই ডেভেলপার অভিজ্ঞতাসহ।

একটি **FastAPI** অ্যাপ্লিকেশন ডিপ্লয় করার সময় সম্ভবত যে প্রধান ধারণাগুলো মাথায় রাখা উচিত, তার কয়েকটি আমি আপনাকে দেখাব (যদিও এর বেশিরভাগই অন্য যেকোনো ধরনের ওয়েব অ্যাপ্লিকেশনের ক্ষেত্রেও প্রযোজ্য)।

পরের অংশগুলোতে মাথায় রাখার মতো আরও বিস্তারিত আর এটি করার কিছু কৌশল দেখবেন। ✨
