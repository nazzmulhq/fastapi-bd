# সাহায্য পাওয়া { #getting-help }

/// note | এই পেজে যা শিখবেন

Pydantic AI নিয়ে প্রশ্ন বা সমস্যা হলে কোথায় সাহায্য পাবেন: Slack আর GitHub Issues।

///

Pydantic AI শুরু করতে বা অ্যাডভান্সড ব্যবহারে সাহায্য দরকার হলে, নিচের উৎসগুলো কাজে লাগতে পারে।

## Slack { #slack }

প্রশ্ন করতে, সাহায্য পেতে আর Pydantic AI নিয়ে আলাপ করতে [Pydantic Slack][slack]-এর `#pydantic-ai` চ্যানেলে যোগ দিন। Pydantic, Logfire আর FastUI-এর জন্যও চ্যানেল আছে।

আপনি [Logfire][logfire] Pro প্ল্যানে থাকলে, আমাদের সাথে একটি নিজস্ব ব্যক্তিগত Slack সহযোগিতা চ্যানেলও পেতে পারেন।

## GitHub Issues { #github-issues }

প্রশ্ন করা আর আমাদের মতামত দেওয়ার জন্য [Pydantic AI GitHub Issues][github-issues] একটি দারুণ জায়গা।

/// tip | ভালো প্রশ্ন করার নিয়ম

* সমস্যাটি দেখায় এমন সবচেয়ে ছোট চালানো যায় এমন কোড দিন।
* কোন মডেল আর প্রোভাইডার ব্যবহার করছেন, আর `pip show pydantic-ai` থেকে সংস্করণ লিখুন।
* পুরো এরর বার্তা (traceback) দিন, আর API key বা ব্যক্তিগত তথ্য মুছে দিন।
* আগে [সমস্যা সমাধান](troubleshooting.md) পেজটি দেখে নিন।
