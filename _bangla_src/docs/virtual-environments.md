# ভার্চুয়াল এনভায়রনমেন্ট { #virtual-environments }

/// note | এই পেজে যা শিখবেন

* ভার্চুয়াল এনভায়রনমেন্ট কী, আর প্রতিটি প্রজেক্টের জন্য কেন আলাদা একটি দরকার।
* `uv` দিয়ে কীভাবে একটি FastAPI প্রজেক্ট তৈরি করবেন ও চালাবেন।
* `uv` ছাড়া, `python -m venv` আর `pip` দিয়ে কীভাবে একই কাজ করবেন।

///

Python প্রজেক্টে কাজ করার সময় প্রতিটি প্রজেক্টে ইনস্টল করা প্যাকেজগুলো আলাদা রাখতে আপনার একটি **ভার্চুয়াল এনভায়রনমেন্ট** ব্যবহার করা উচিত।

/// tip | উদাহরণ দিয়ে বুঝি

ধরুন আপনার দুটি প্রজেক্ট আছে। প্রজেক্ট "ক"-এর লাগে একটি লাইব্রেরির পুরোনো সংস্করণ, আর প্রজেক্ট "খ"-এর লাগে নতুন সংস্করণ। সব প্যাকেজ যদি কম্পিউটারের একই জায়গায় ইনস্টল হয়, তাহলে একটির জন্য ইনস্টল করলে আরেকটি নষ্ট হয়ে যাবে।

ভার্চুয়াল এনভায়রনমেন্ট হলো প্রতিটি প্রজেক্টের নিজস্ব একটি আলমারি। প্রজেক্ট "ক"-এর জিনিস তার আলমারিতে, "খ"-এর জিনিস তার আলমারিতে। কেউ কারও জিনিসে হাত দেয় না। আসলে এটি প্রজেক্ট ফোল্ডারের ভেতরে `.venv` নামের একটি ফোল্ডার, যেখানে ওই প্রজেক্টের Python আর প্যাকেজগুলো থাকে।

///

FastAPI প্রজেক্টের জন্য আমি (FastAPI-এর লেখক) প্রজেক্ট, এর ডিপেন্ডেন্সি এবং এর ভার্চুয়াল এনভায়রনমেন্ট পরিচালনা করতে [uv](https://docs.astral.sh/uv/) ব্যবহারের সুপারিশ করি। `uv` খুব দ্রুত, আর এই সব কাজ নিজেই সামলায়।

## একটি প্রজেক্ট তৈরি করুন { #create-a-project }

[অফিসিয়াল ইনস্টলেশন গাইড](https://docs.astral.sh/uv/getting-started/installation/) অনুসরণ করে `uv` ইনস্টল করুন, তারপর একটি প্রজেক্ট তৈরি করুন:

<div class="termy">

```console
$ uv init awesome-project --bare
$ cd awesome-project
$ uv add "fastapi[standard]"
```

</div>

/// info | কমান্ডগুলো সহজ ভাষায়

* `uv init awesome-project --bare`: `awesome-project` নামে একটি নতুন প্রজেক্ট ফোল্ডার তৈরি করে। `--bare` মানে শুধু দরকারি ন্যূনতম ফাইল (যেমন `pyproject.toml`, যেখানে প্রজেক্টের তথ্য আর ডিপেন্ডেন্সির তালিকা থাকে)।
* `cd awesome-project`: ওই ফোল্ডারের ভেতরে ঢোকা।
* `uv add "fastapi[standard]"`: প্রজেক্টে FastAPI যোগ করা। `uv` নিজে থেকেই `.venv` ভার্চুয়াল এনভায়রনমেন্ট বানায়, সেখানে FastAPI ইনস্টল করে, আর `pyproject.toml`-এ লিখে রাখে।

///

`uv` প্রজেক্টের জন্য স্বয়ংক্রিয়ভাবে একটি ভার্চুয়াল এনভায়রনমেন্ট তৈরি করে। আপনাকে নিজে এটি তৈরি বা অ্যাক্টিভেট করতে হবে না।

প্রজেক্ট এনভায়রনমেন্টের ভেতরে `uv run` দিয়ে কমান্ড চালান, যেমন:

<div class="termy">

```console
$ uv run fastapi dev
```

</div>

`uv run` মানে "এই প্রজেক্টের ভার্চুয়াল এনভায়রনমেন্ট ব্যবহার করে কমান্ডটি চালাও"। তাই এখানে যে `fastapi` চলবে, সেটি এই প্রজেক্টের `.venv` থেকে আসবে।

## `uv` ছাড়া: `venv` ও `pip` { #bn-venv-and-pip }

আপনি যদি `uv` ব্যবহার করতে না চান, তাহলে Python-এর নিজস্ব `venv` আর `pip` দিয়েও একই কাজ করতে পারেন। ধাপগুলো:

**১. প্রজেক্ট ফোল্ডারে ভার্চুয়াল এনভায়রনমেন্ট তৈরি করুন:**

<div class="termy">

```console
$ python -m venv .venv
```

</div>

এটি প্রজেক্ট ফোল্ডারের ভেতরে `.venv` নামে একটি ফোল্ডার বানায়।

**২. অ্যাক্টিভেট করুন** (প্রতিবার নতুন টার্মিনাল খুললে এটা করতে হবে):

//// tab | Linux, macOS

<div class="termy">

```console
$ source .venv/bin/activate
```

</div>

////

//// tab | Windows PowerShell

<div class="termy">

```console
$ .venv\Scripts\Activate.ps1
```

</div>

////

অ্যাক্টিভেট হলে সাধারণত টার্মিনালের শুরুতে `(.venv)` লেখা দেখা যায়। এর মানে এখন `python` আর `pip` এই প্রজেক্টেরগুলোই চলবে। ভেতরে ভেতরে যা হয়: [`PATH` এনভায়রনমেন্ট ভেরিয়েবলের](environment-variables.md) শুরুতে `.venv`-এর ফোল্ডারটি যোগ হয়।

**৩. প্যাকেজ ইনস্টল করুন:**

<div class="termy">

```console
$ pip install "fastapi[standard]"
```

</div>

**৪. কাজ শেষে চাইলে ডিঅ্যাক্টিভেট করুন:**

<div class="termy">

```console
$ deactivate
```

</div>

/// warning | সাধারণ ভুল

* অ্যাক্টিভেট না করেই `pip install` চালানো। তখন প্যাকেজ প্রজেক্টে নয়, পুরো কম্পিউটারের Python-এ ইনস্টল হয়ে যায়।
* `.venv` ফোল্ডারটি Git-এ কমিট করা। এটি বড় আর প্রতিটি কম্পিউটারে আলাদা, তাই `.gitignore` ফাইলে `.venv` লিখে রাখুন (`uv` নিজেই এটা করে)।

///

## আরও জানুন { #learn-more }

ভার্চুয়াল এনভায়রনমেন্ট ভেতরে কীভাবে কাজ করে তা জানতে [ভার্চুয়াল এনভায়রনমেন্ট গাইড](https://tiangolo.com/guides/virtual-environments/) (ইংরেজিতে) পড়ুন। সেখানে অ্যাক্টিভেশন এবং বিকল্প `python -m venv` ও `pip` ওয়ার্কফ্লো আরও বিস্তারিত আছে।

/// check | সংক্ষেপে মনে রাখুন

* প্রতিটি প্রজেক্টের জন্য আলাদা ভার্চুয়াল এনভায়রনমেন্ট রাখুন, যাতে প্যাকেজগুলো একে অপরের সাথে ঝামেলা না করে।
* সবচেয়ে সহজ: `uv init`, `uv add "fastapi[standard]"`, তারপর `uv run fastapi dev`।
* `uv` ছাড়া: `python -m venv .venv`, অ্যাক্টিভেট, তারপর `pip install`।
* `.venv` ফোল্ডার Git-এ রাখবেন না।
