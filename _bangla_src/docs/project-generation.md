# Full Stack FastAPI টেমপ্লেট { #full-stack-fastapi-template }

/// note | এই পেজে যা জানবেন

* "টেমপ্লেট" কী, আর কেন একটি তৈরি টেমপ্লেট দিয়ে শুরু করলে অনেক সময় বাঁচে।
* অফিসিয়াল Full Stack FastAPI টেমপ্লেটে কী কী প্রযুক্তি আগে থেকেই সাজানো আছে।

///

টেমপ্লেটগুলো সাধারণত একটি নির্দিষ্ট সেটআপ নিয়ে এলেও, এগুলো নমনীয় আর নিজের মতো বদলানোর জন্যই ডিজাইন করা। এতে আপনি আপনার প্রজেক্টের প্রয়োজন অনুযায়ী এগুলো বদলে মানিয়ে নিতে পারেন, ফলে এগুলো শুরু করার জন্য চমৎকার একটি জায়গা। 🏁

শুরু করতে আপনি এই টেমপ্লেটটি ব্যবহার করতে পারেন, কারণ এতে প্রাথমিক সেটআপ, নিরাপত্তা, ডেটাবেস আর কিছু API এন্ডপয়েন্টের অনেকখানি কাজ আগে থেকেই করা আছে।

GitHub রিপোজিটরি: [Full Stack FastAPI Template](https://github.com/fastapi/full-stack-fastapi-template)

/// tip | উদাহরণ দিয়ে বুঝি

শূন্য থেকে প্রজেক্ট শুরু করা মানে খালি জমিতে বাড়ি বানানো: ভিত, দেয়াল, বিদ্যুৎ, পানি সব নিজে করতে হয়। টেমপ্লেট হলো তৈরি কাঠামোর একটি ফ্ল্যাট: দেয়াল, তার, পাইপ সব বসানো, আপনি শুধু নিজের মতো সাজাবেন। লগইন, পাসওয়ার্ড রিসেট, ডেটাবেস, ফ্রন্টএন্ড, Docker সব এখানে প্রস্তুত।

///

## Full Stack FastAPI টেমপ্লেট - প্রযুক্তি এবং বৈশিষ্ট্য { #full-stack-fastapi-template-technology-stack-and-features }

- ⚡ Python ব্যাকএন্ড API-র জন্য [**FastAPI**](https://fastapi.tiangolo.com)।
  - 🧰 Python-এ SQL ডেটাবেসের সাথে কাজ করার জন্য (ORM) [SQLModel](https://sqlmodel.tiangolo.com)।
  - 🔍 ডেটা যাচাই আর সেটিংস ব্যবস্থাপনার জন্য [Pydantic](https://pydantic.dev/docs/), যা FastAPI ব্যবহার করে।
  - 💾 SQL ডেটাবেস হিসেবে [PostgreSQL](https://www.postgresql.org)।
- 🚀 ফ্রন্টএন্ডের জন্য [React](https://react.dev)।
  - 💃 TypeScript, hooks, Vite আর আধুনিক ফ্রন্টএন্ডের অন্যান্য অংশ ব্যবহার করে।
  - 🎨 ফ্রন্টএন্ড কম্পোনেন্টের জন্য [Tailwind CSS](https://tailwindcss.com) আর [shadcn/ui](https://ui.shadcn.com)।
  - 🤖 স্বয়ংক্রিয়ভাবে তৈরি একটি ফ্রন্টএন্ড ক্লায়েন্ট।
  - 🧪 End-to-End (শুরু থেকে শেষ পর্যন্ত পুরো ব্যবহার) টেস্টের জন্য [Playwright](https://playwright.dev)।
  - 🦇 ডার্ক মোড সাপোর্ট।
- 🐋 ডেভেলপমেন্ট আর প্রোডাকশনের জন্য [Docker Compose](https://www.docker.com)।
- 🔒 ডিফল্টভাবেই নিরাপদ পাসওয়ার্ড হ্যাশিং।
- 🔑 JWT (JSON Web Token) অথেনটিকেশন।
- 📫 ইমেইলের মাধ্যমে পাসওয়ার্ড পুনরুদ্ধার।
- ✅ [Pytest](https://pytest.org) দিয়ে টেস্ট।
- 📞 রিভার্স প্রক্সি / লোড ব্যালান্সার হিসেবে [Traefik](https://traefik.io)।
- 🚢 Docker Compose ব্যবহার করে ডিপ্লয়মেন্টের নির্দেশনা, স্বয়ংক্রিয় HTTPS সার্টিফিকেট সামলাতে একটি সামনের Traefik প্রক্সি কীভাবে সেটআপ করবেন তা সহ।
- 🏭 GitHub Actions-ভিত্তিক CI (continuous integration, প্রতিবার কোড পুশে স্বয়ংক্রিয় টেস্ট) আর CD (continuous deployment, স্বয়ংক্রিয় ডিপ্লয়)।

/// check | সংক্ষেপে মনে রাখুন

* নতুন বড় প্রজেক্ট শুরু করতে অফিসিয়াল টেমপ্লেটটি দারুণ শুরুর জায়গা।
* এতে FastAPI + SQLModel + PostgreSQL (ব্যাকএন্ড), React (ফ্রন্টএন্ড), Docker, Traefik, টেস্ট আর CI/CD সব সাজানো।
* টেমপ্লেট নিজের মতো বদলানোর জন্যই, প্রয়োজন না হলে কোনো অংশ বাদও দিতে পারেন।
