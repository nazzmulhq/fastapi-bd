# অনুবাদ { #translations }

/// note | এই পেজটি কী

FastAPI-এর অফিসিয়াল ডকুমেন্টেশন বিভিন্ন ভাষায় কীভাবে অনুবাদ করা হয়, আর আপনি কীভাবে অনুবাদ উন্নত করতে বা নতুন ভাষা যোগ করতে সাহায্য করতে পারেন।

///

অনুবাদের pull request তৈরি করে LLM (বড় ভাষা মডেল, যেমন AI), যা পথ দেখানো হয় প্রম্পট দিয়ে। এই প্রম্পটগুলো FastAPI দল প্রতিটি সমর্থিত ভাষার মাতৃভাষী কমিউনিটির সাথে মিলে ডিজাইন করে।

## প্রতিটি ভাষার জন্য LLM প্রম্পট { #llm-prompt-per-language }

প্রতিটি ভাষার একটি ডিরেক্টরি আছে: [https://github.com/fastapi/fastapi/tree/master/docs](https://github.com/fastapi/fastapi/tree/master/docs), সেখানে `llm-prompt.md` নামে একটি ফাইল দেখতে পাবেন, যাতে সেই ভাষার জন্য নির্দিষ্ট প্রম্পট আছে।

যেমন, স্প্যানিশের জন্য প্রম্পটটি আছে: [`docs/es/llm-prompt.md`](https://github.com/fastapi/fastapi/blob/master/docs/es/llm-prompt.md)-এ।

যদি আপনার ভাষায় ভুল দেখেন, তাহলে আপনার ভাষার সেই ফাইলের প্রম্পটে পরামর্শ দিতে পারেন, আর পরিবর্তনের পরে যে নির্দিষ্ট পেজগুলো আবার তৈরি করতে চান সেগুলোর অনুরোধ করতে পারেন।

ভাষা-নির্দিষ্ট LLM প্রম্পটে পরামর্শসহ PR-এর জন্য অন্তত একজন মাতৃভাষীর অনুমোদন লাগে। এখানে আপনার সাহায্য খুবই প্রশংসিত হবে!

/// tip | উদাহরণ দিয়ে বুঝি

প্রম্পট হলো AI অনুবাদকের জন্য একটি "নির্দেশিকা খাতা": কোন ইংরেজি শব্দের বাংলা কী হবে, কোন শব্দ ইংরেজিই থাকবে, লেখার ভঙ্গি কেমন হবে। খাতায় একটি নিয়ম ঠিক করলে, সেই নিয়ম সব পেজের অনুবাদে একসাথে প্রয়োগ হয়।

///

## নতুন ভাষার অনুরোধ { #request-a-new-language }

ধরা যাক আপনি এমন একটি ভাষার অনুবাদ চান যা এখনো অনুবাদ করা হয়নি, এমনকি কয়েকটি পেজও নয়। যেমন, ল্যাটিন।

* প্রথম ধাপ হবে আরও ২ জন মানুষ খুঁজে বের করা, যারা আপনার সাথে সেই ভাষার অনুবাদ PR রিভিউ করতে রাজি।
* যখন অন্তত ৩ জন মানুষ সেই ভাষা রক্ষণাবেক্ষণে সাহায্য করতে প্রতিশ্রুতি দিতে রাজি হবেন, তখন পরের ধাপগুলোতে যেতে পারেন।
* টেমপ্লেট অনুসরণ করে একটি নতুন discussion তৈরি করুন।
* ভাষায় সাহায্য করবেন এমন অন্য ২ জনকে ট্যাগ করুন, আর মন্তব্যে নিশ্চিত করতে বলুন যে তারা সাহায্য করবেন।

discussion-এ কয়েকজন মানুষ যুক্ত হলে, FastAPI দল এটি মূল্যায়ন করে একটি অফিসিয়াল অনুবাদ হিসেবে চালু করতে পারে।

তারপর ডকস স্বয়ংক্রিয়ভাবে LLM দিয়ে অনুবাদ হবে, আর মাতৃভাষীদের দল অনুবাদ রিভিউ করতে পারবেন, আর LLM প্রম্পট ঠিকঠাক করতে সাহায্য করতে পারবেন।

একবার নতুন অনুবাদ এলে, যেমন যদি ডকস আপডেট হয় বা নতুন কোনো অংশ আসে, তাহলে একই discussion-এ রিভিউ করার জন্য নতুন অনুবাদের লিংকসহ একটি মন্তব্য আসবে।

/// info | এই সাইট সম্পর্কে

আপনি এখন যে সহজ বাংলা সংস্করণটি পড়ছেন, সেটি অফিসিয়াল FastAPI ডকুমেন্টেশনের একটি ব্যাখ্যামূলক রূপ: শুধু অনুবাদ নয়, প্রতিটি পেজে সহজ ভাষায় ব্যাখ্যা, উদাহরণ আর সারসংক্ষেপ যোগ করা হয়েছে।
