# অ্যাডভান্সড Python টাইপ { #advanced-python-types }

/// note | এই পেজে যা শিখবেন

* `Union` আর `Optional` কী, আর কখন `|`-এর বদলে এগুলো লাগে।
* কেন "Optional" নামটি বিভ্রান্তিকর হতে পারে।
* "ঐচ্ছিক (optional)" আর "`None` হতে পারে" এর পার্থক্য।

///

Python টাইপ নিয়ে কাজ করার সময় কাজে লাগতে পারে এমন কিছু বাড়তি ধারণা এখানে দেওয়া হলো।

(Python টাইপের মৌলিক বিষয়গুলো জানতে আগে [Python টাইপের পরিচিতি](../python-types.md) পড়ে নিন।)

## `Union` বা `Optional` ব্যবহার করা { #using-union-or-optional }

যদি কোনো কারণে আপনার কোডে `|` ব্যবহার করা না যায়, যেমন যদি এটি টাইপ অ্যানোটেশনে না থেকে `response_model=` এর মতো কোথাও থাকে, তাহলে উল্লম্ব দাগ (`|`) ব্যবহারের বদলে `typing` থেকে `Union` ব্যবহার করতে পারেন।

যেমন, আপনি ঘোষণা করতে পারেন যে কোনো কিছু একটি `str` অথবা `None` হতে পারে:

```python
from typing import Union


def say_hi(name: Union[str, None]):
        print(f"Hi {name}!")
```

কোনো কিছু `None` হতে পারে, তা ঘোষণা করার একটি সংক্ষিপ্ত উপায়ও `typing`-এ আছে: `Optional`।

এখানে আমার খুবই **ব্যক্তিগত** দৃষ্টিকোণ থেকে একটি পরামর্শ:

* 🚨 `Optional[SomeType]` ব্যবহার এড়িয়ে চলুন
* এর বদলে ✨ **`Union[SomeType, None]` ব্যবহার করুন** ✨।

দুটোই সমতুল্য আর ভেতরে একই জিনিস, কিন্তু আমি `Optional`-এর বদলে `Union` সুপারিশ করব, কারণ "**optional**" (ঐচ্ছিক) শব্দটি শুনে মনে হয় মানটি দেওয়া ঐচ্ছিক, অথচ এর আসল মানে "এটি `None` হতে পারে", এমনকি যদি এটি ঐচ্ছিক না হয়ে বাধ্যতামূলকও থাকে।

আমার মনে হয় `Union[SomeType, None]` এর অর্থ আরও স্পষ্টভাবে প্রকাশ করে।

এটি শুধু শব্দ আর নামের ব্যাপার। কিন্তু ওই শব্দগুলো আপনি আর আপনার সহকর্মীরা কোড নিয়ে কীভাবে ভাবেন তা প্রভাবিত করতে পারে।

উদাহরণ হিসেবে এই ফাংশনটি নিই:

```python
from typing import Optional


def say_hi(name: Optional[str]):
    print(f"Hey {name}!")
```

`name` প্যারামিটারটি `Optional[str]` হিসেবে সংজ্ঞায়িত, কিন্তু এটি **ঐচ্ছিক নয়**, প্যারামিটার ছাড়া ফাংশনটি কল করা যাবে না:

```Python
say_hi()  # হায় হায়, এটি এরর দেয়! 😱
```

`name` প্যারামিটারটি **এখনো বাধ্যতামূলক** (*ঐচ্ছিক* নয়), কারণ এর কোনো ডিফল্ট মান নেই। তবুও, `name` মান হিসেবে `None` গ্রহণ করে:

```Python
say_hi(name=None)  # এটি কাজ করে, None বৈধ 🎉
```

/// tip | উদাহরণ দিয়ে বুঝি

একটি ফর্মে "দ্বিতীয় ফোন নম্বর" ঘর আছে, যেখানে লেখা "না থাকলে 'নেই' লিখুন"। ঘরটি খালি রেখে জমা দেওয়া যাবে না (বাধ্যতামূলক), কিন্তু "নেই" লেখা চলবে (`None` বৈধ)। `Optional[str]` ঠিক এমন ঘর: নাম শুনে ঐচ্ছিক মনে হলেও আসলে বাধ্যতামূলক, শুধু "নেই" (`None`) মান গ্রহণ করে। সত্যিই ঐচ্ছিক করতে হলে ডিফল্ট মান দিতে হয়, যেমন `name: str | None = None`।

///

সুখবর হলো, বেশিরভাগ ক্ষেত্রে আপনি টাইপের union সংজ্ঞায়িত করতে সহজভাবেই `|` ব্যবহার করতে পারবেন:

```python
def say_hi(name: str | None):
    print(f"Hey {name}!")
```

তাই সাধারণত `Optional` আর `Union` এর মতো নাম নিয়ে আপনাকে চিন্তা করতে হবে না। 😎

/// check | সংক্ষেপে মনে রাখুন

* `str | None`, `Union[str, None]` আর `Optional[str]` তিনটিই একই অর্থ: "`str` অথবা `None`"।
* "`None` হতে পারে" মানে "ঐচ্ছিক" নয়। প্যারামিটার ঐচ্ছিক হয় শুধু ডিফল্ট মান (`= None`) দিলে।
* সম্ভব হলে `|` ব্যবহার করুন, যেখানে চলে না সেখানে `Union`।
