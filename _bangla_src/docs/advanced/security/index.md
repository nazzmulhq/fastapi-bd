# উন্নত সিকিউরিটি { #advanced-security }

/// note | এই অংশে যা পাবেন

টিউটোরিয়ালের সিকিউরিটি অধ্যায়ের বাইরে বাড়তি সুবিধা: OAuth2 scope দিয়ে সূক্ষ্ম অনুমতি ব্যবস্থা, আর HTTP Basic Auth।

///

## বাড়তি ফিচার { #additional-features }

[টিউটোরিয়াল - ইউজার গাইড: সিকিউরিটি](../../tutorial/security/index.md)-এ যা আলোচনা করা হয়েছে, তার বাইরেও সিকিউরিটি সামলানোর কিছু বাড়তি ফিচার আছে।

/// tip | পরামর্শ

পরের অংশগুলো **যে খুব "অ্যাডভান্সড" (কঠিন) তা কিন্তু নয়**।

আর হতে পারে আপনার নির্দিষ্ট প্রয়োজনের সমাধান এগুলোর কোনো একটিতেই আছে।

///

## আগে টিউটোরিয়াল পড়ুন { #read-the-tutorial-first }

পরের অংশগুলো ধরে নেয় যে আপনি মূল [টিউটোরিয়াল - ইউজার গাইড: সিকিউরিটি](../../tutorial/security/index.md) ইতিমধ্যে পড়েছেন।

এগুলো সবই একই ধারণার ওপর তৈরি, তবে কিছু বাড়তি কার্যকারিতা দেয়।
