# সরাসরি Request ব্যবহার { #using-the-request-directly }

/// note | এই পেজে যা শিখবেন

* কখন আর কীভাবে সরাসরি `Request` অবজেক্ট ব্যবহার করবেন (যেমন ক্লায়েন্টের IP ঠিকানা জানতে)।
* সরাসরি ব্যবহারের সীমাবদ্ধতা।

///

এখন পর্যন্ত আপনি রিকোয়েস্টের যে অংশগুলো দরকার সেগুলো তাদের টাইপসহ ঘোষণা করছিলেন।

ডেটা নিচ্ছিলেন:

* প্যারামিটার হিসেবে পাথ থেকে।
* হেডার থেকে।
* কুকি থেকে।
* ইত্যাদি।

আর এভাবে করায় **FastAPI** ওই ডেটা যাচাই করছে, রূপান্তর করছে আর স্বয়ংক্রিয়ভাবে আপনার API-এর ডকুমেন্টেশন তৈরি করছে।

কিন্তু এমন পরিস্থিতি থাকতে পারে যেখানে আপনাকে সরাসরি `Request` অবজেক্ট ব্যবহার করতে হতে পারে।

## `Request` অবজেক্ট সম্পর্কে বিস্তারিত { #details-about-the-request-object }

যেহেতু **FastAPI** আসলে ভেতরে **Starlette**, ওপরে কয়েকটি টুলের একটি স্তরসহ, তাই দরকার হলে সরাসরি Starlette-এর [`Request`](https://starlette.dev/requests/) অবজেক্ট ব্যবহার করতে পারেন।

এর মানে আরও হলো, আপনি যদি সরাসরি `Request` অবজেক্ট থেকে ডেটা নেন (যেমন বডি পড়েন), তাহলে FastAPI সেটি যাচাই, রূপান্তর বা ডকুমেন্ট (OpenAPI দিয়ে, স্বয়ংক্রিয় API ইউজার ইন্টারফেসের জন্য) করবে না।

তবে স্বাভাবিকভাবে ঘোষিত অন্য যেকোনো প্যারামিটার (যেমন Pydantic মডেলসহ বডি) তখনও যাচাই, রূপান্তর, অ্যানোটেট ইত্যাদি হবে।

কিন্তু নির্দিষ্ট কিছু ক্ষেত্রে `Request` অবজেক্ট পাওয়া কাজে লাগে।

## সরাসরি `Request` অবজেক্ট ব্যবহার করুন { #use-the-request-object-directly }

ধরা যাক আপনি আপনার *পাথ অপারেশন ফাংশনের* ভেতরে ক্লায়েন্টের IP ঠিকানা/হোস্ট জানতে চান।

এর জন্য সরাসরি রিকোয়েস্টে প্রবেশ করতে হবে।

{* ../../docs_src/using_request_directly/tutorial001_py310.py hl[1,7:8] *}

`Request` টাইপসহ একটি *পাথ অপারেশন ফাংশনের* প্যারামিটার ঘোষণা করলে **FastAPI** জানবে ওই প্যারামিটারে `Request` দিতে হবে।

/// info | কোডটি সহজ ভাষায়

* লাইন ৭: `item_id: str` সাধারণ পাথ প্যারামিটার, আর `request: Request` পুরো রিকোয়েস্ট অবজেক্ট।
* লাইন ৮: `request.client.host` রিকোয়েস্ট পাঠানো কম্পিউটারের IP ঠিকানা। নিজের কম্পিউটার থেকে পাঠালে দেখাবে `127.0.0.1`।

`request`-এ আরও অনেক কিছু পাওয়া যায়: `request.url`, `request.headers`, `request.cookies`, `request.method`, আর `await request.body()` দিয়ে কাঁচা বডি।

///

/// tip | পরামর্শ

খেয়াল করুন, এই ক্ষেত্রে আমরা রিকোয়েস্ট প্যারামিটারের পাশাপাশি একটি পাথ প্যারামিটারও ঘোষণা করছি।

তাই পাথ প্যারামিটারটি বের করা, যাচাই করা, নির্দিষ্ট টাইপে রূপান্তর করা আর OpenAPI দিয়ে অ্যানোটেট করা হবে।

একইভাবে, অন্য যেকোনো প্যারামিটার স্বাভাবিকভাবেই ঘোষণা করতে পারেন, আর বাড়তি হিসেবে `Request`-ও পেতে পারেন।

///

/// warning | মনে রাখুন

অ্যাপ যদি Nginx বা Traefik-এর মতো একটি প্রক্সির পেছনে চলে, তাহলে `request.client.host`-এ ব্যবহারকারীর আসল IP-এর বদলে প্রক্সির IP আসতে পারে। এ নিয়ে দেখুন [প্রক্সির পেছনে](behind-a-proxy.md)।

///

## `Request` ডকুমেন্টেশন { #request-documentation }

[অফিসিয়াল Starlette ডকুমেন্টেশন সাইটে `Request` অবজেক্ট](https://starlette.dev/requests/) সম্পর্কে আরও বিস্তারিত পড়তে পারেন।

/// note | কারিগরি বিবরণ

`from starlette.requests import Request`-ও ব্যবহার করতে পারতেন।

**FastAPI** ডেভেলপার হিসেবে আপনার সুবিধার জন্যই সরাসরি এটি দেয়। কিন্তু এটি সরাসরি Starlette থেকে আসে।

///

/// check | সংক্ষেপে মনে রাখুন

* প্যারামিটারে `request: Request` দিলে পুরো রিকোয়েস্ট অবজেক্ট পাওয়া যায়।
* এর থেকে সরাসরি পড়া ডেটা FastAPI যাচাই বা ডকুমেন্ট করে না।
* যতটা সম্ভব টাইপসহ সাধারণ প্যারামিটার ব্যবহার করুন, শুধু বিশেষ দরকারে `Request`।
