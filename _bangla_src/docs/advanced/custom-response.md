# কাস্টম রেসপন্স - HTML, Stream, File ও অন্যান্য { #custom-response-html-stream-file-others }

/// note | এই পেজে যা শিখবেন

* JSON ছাড়া অন্য ধরনের রেসপন্স: HTML, সাধারণ টেক্সট, রিডাইরেক্ট, স্ট্রিম, ফাইল।
* `response_class` দিয়ে রেসপন্সের ধরন ঘোষণা করা, যাতে ডকুমেন্টেশনেও সঠিক ধরন দেখায়।
* নিজের রেসপন্স ক্লাস বানানো আর পুরো অ্যাপের ডিফল্ট রেসপন্স ক্লাস বদলানো।

///

ডিফল্টভাবে **FastAPI** JSON রেসপন্স ফেরত দেয়।

[সরাসরি একটি Response ফেরত দিন](response-directly.md)-এ দেখানো উপায়ে, সরাসরি একটি `Response` ফেরত দিয়ে এটি ওভাররাইড করতে পারেন।

কিন্তু সরাসরি একটি `Response` (বা `JSONResponse`-এর মতো এর যেকোনো সাব-ক্লাস) ফেরত দিলে ডেটা স্বয়ংক্রিয়ভাবে রূপান্তরিত হবে না (এমনকি `response_model` ঘোষণা করলেও), আর ডকুমেন্টেশন স্বয়ংক্রিয়ভাবে তৈরি হবে না (যেমন, তৈরি হওয়া OpenAPI-এর অংশ হিসেবে HTTP হেডার `Content-Type`-এ নির্দিষ্ট "মিডিয়া টাইপ" অন্তর্ভুক্ত থাকবে না)।

তবে আপনি যে `Response` ব্যবহার করতে চান (যেমন যেকোনো `Response` সাব-ক্লাস), সেটি *পাথ অপারেশন ডেকোরেটরে* `response_class` প্যারামিটার দিয়েও ঘোষণা করতে পারেন।

আপনার *পাথ অপারেশন ফাংশন* থেকে ফেরত দেওয়া বিষয়বস্তু ওই `Response`-এর ভেতরে রাখা হবে।

/// tip | "মিডিয়া টাইপ" সহজ ভাষায়

মিডিয়া টাইপ (বা MIME টাইপ) হলো ব্রাউজারকে বলে দেওয়া যে রেসপন্সে কী আছে: `application/json` (JSON ডেটা), `text/html` (ওয়েবপেজ), `text/plain` (সাধারণ লেখা), `image/png` (ছবি)। এটা দেখেই ব্রাউজার ঠিক করে কীভাবে দেখাবে।

///

/// note | নোট

আপনি যদি মিডিয়া টাইপ ছাড়া একটি রেসপন্স ক্লাস ব্যবহার করেন, তাহলে FastAPI ধরে নেবে আপনার রেসপন্সে কোনো বিষয়বস্তু নেই, তাই তৈরি হওয়া OpenAPI ডকুমেন্টেশনে রেসপন্সের ফরম্যাট ডকুমেন্ট করবে না।

///

## JSON রেসপন্স { #json-responses }

ডিফল্টভাবে FastAPI JSON রেসপন্স ফেরত দেয়।

আপনি যদি একটি [রেসপন্স মডেল](../tutorial/response-model.md) ঘোষণা করেন, তাহলে FastAPI এটি ব্যবহার করে Pydantic দিয়ে ডেটা JSON-এ সিরিয়ালাইজ করবে।

রেসপন্স মডেল ঘোষণা না করলে FastAPI [JSON-সামঞ্জস্যপূর্ণ এনকোডার](../tutorial/encoder.md)-এ বোঝানো `jsonable_encoder` ব্যবহার করবে, আর ফলাফল একটি `JSONResponse`-এ রাখবে।

আপনি যদি JSON মিডিয়া টাইপসহ (`application/json`) একটি `response_class` ঘোষণা করেন, যেমনটা `JSONResponse`-এর ক্ষেত্রে, তাহলে আপনার ফেরত দেওয়া ডেটা *পাথ অপারেশন ডেকোরেটরে* ঘোষিত যেকোনো Pydantic `response_model` দিয়ে স্বয়ংক্রিয়ভাবে রূপান্তরিত (আর ফিল্টার) হবে। কিন্তু ডেটা Pydantic দিয়ে JSON বাইটে সিরিয়ালাইজ হবে না, বরং `jsonable_encoder` দিয়ে রূপান্তরিত হয়ে `JSONResponse` ক্লাসে যাবে, যা Python-এর স্ট্যান্ডার্ড JSON লাইব্রেরি দিয়ে এটিকে বাইটে সিরিয়ালাইজ করবে।

## HTML রেসপন্স { #html-response }

**FastAPI** থেকে সরাসরি HTML-সহ একটি রেসপন্স ফেরত দিতে `HTMLResponse` ব্যবহার করুন।

* `HTMLResponse` ইমপোর্ট করুন।
* আপনার *পাথ অপারেশন ডেকোরেটরের* `response_class` প্যারামিটার হিসেবে `HTMLResponse` দিন।

{* ../../docs_src/custom_response/tutorial002_py310.py hl[2,7] *}

ব্রাউজারে `/items/` খুললে JSON নয়, একটি সাধারণ ওয়েবপেজ দেখাবে, বড় করে লেখা "Look ma! HTML!"।

/// note | নোট

`response_class` প্যারামিটারটি রেসপন্সের "মিডিয়া টাইপ" সংজ্ঞায়িত করতেও ব্যবহার হবে।

এই ক্ষেত্রে HTTP হেডার `Content-Type` সেট হবে `text/html`।

আর OpenAPI-তেও সেভাবেই ডকুমেন্ট করা হবে।

### OpenAPI-তে ডকুমেন্ট করা আর `Response` ওভাররাইড করা { #document-in-openapi-and-override-response }

আপনি যদি ফাংশনের ভেতর থেকে রেসপন্স ওভাররাইড করতে চান, কিন্তু একই সাথে OpenAPI-তে "মিডিয়া টাইপ"-ও ডকুমেন্ট করতে চান, তাহলে `response_class` প্যারামিটার ব্যবহার করতে পারেন আর একটি `Response` অবজেক্টও ফেরত দিতে পারেন।

তখন `response_class` শুধু OpenAPI *পাথ অপারেশন* ডকুমেন্ট করতে ব্যবহার হবে, কিন্তু আপনার `Response` যেমন আছে তেমনই ব্যবহার হবে।

## উপলব্ধ রেসপন্সগুলো { #available-responses }

এখানে উপলব্ধ কয়েকটি রেসপন্স দেওয়া হলো।

মনে রাখবেন, অন্য যেকোনো কিছু ফেরত দিতে `Response` ব্যবহার করতে পারেন, এমনকি একটি কাস্টম সাব-ক্লাসও তৈরি করতে পারেন।

/// note | কারিগরি বিবরণ

`from starlette.responses import HTMLResponse`-ও ব্যবহার করতে পারতেন।

**FastAPI** ডেভেলপার হিসেবে আপনার সুবিধার জন্যই একই `starlette.responses`-কে `fastapi.responses` হিসেবে দেয়। কিন্তু উপলব্ধ বেশিরভাগ রেসপন্স সরাসরি Starlette থেকে আসে।

### `Response` { #response }

মূল `Response` ক্লাস, বাকি সব রেসপন্স এটি থেকে ইনহেরিট করে।

এটি সরাসরি ফেরত দিতে পারেন।

এটি এই প্যারামিটারগুলো গ্রহণ করে:

* `content` - একটি `str` বা `bytes`।
* `status_code` - একটি `int` HTTP স্ট্যাটাস কোড।
* `headers` - স্ট্রিংয়ের একটি `dict`।
* `media_type` - মিডিয়া টাইপ জানানো একটি `str`। যেমন `"text/html"`।

FastAPI (আসলে Starlette) স্বয়ংক্রিয়ভাবে একটি Content-Length হেডার যোগ করবে। `media_type`-এর ভিত্তিতে আর টেক্সট টাইপের জন্য একটি charset জুড়ে দিয়ে একটি Content-Type হেডারও যোগ করবে।

### `JSONResponse` { #jsonresponse }

কিছু ডেটা নিয়ে একটি `application/json` এনকোড করা রেসপন্স ফেরত দেয়।

ওপরে যেমন পড়েছেন, **FastAPI**-তে এটিই ডিফল্টভাবে ব্যবহৃত রেসপন্স।

/// note | কারিগরি বিবরণ

তবে আপনি যদি একটি রেসপন্স মডেল বা রিটার্ন টাইপ ঘোষণা করেন, তাহলে ডেটা JSON-এ সিরিয়ালাইজ করতে সরাসরি সেটিই ব্যবহার হবে, আর `JSONResponse` ক্লাস ব্যবহার না করেই JSON-এর সঠিক মিডিয়া টাইপসহ একটি রেসপন্স সরাসরি ফেরত দেওয়া হবে।

সেরা পারফরম্যান্স পেতে এটিই আদর্শ উপায়।

/// note | কারিগরি বিবরণ

একটি `async` টাস্ক কেবল তখনই বাতিল করা যায় যখন এটি একটি `await`-এ পৌঁছায়। কোনো `await` না থাকলে জেনারেটর (`yield`-ওয়ালা ফাংশন) সঠিকভাবে বাতিল করা যায় না, আর বাতিলের অনুরোধের পরেও চলতে থাকতে পারে।

যেহেতু এই ছোট উদাহরণে কোনো `await` স্টেটমেন্টের দরকার নেই, তাই বাতিল সামলানোর সুযোগ ইভেন্ট লুপকে দিতে আমরা একটি `await anyio.sleep(0)` যোগ করি।

বড় বা অসীম স্ট্রিমের ক্ষেত্রে এটি আরও বেশি জরুরি হবে। (যেমন ব্যবহারকারী ব্রাউজার বন্ধ করে দিলেও স্ট্রিম চলতেই থাকা।)

///

সরাসরি একটি `StreamingResponse` ফেরত না দিয়ে সম্ভবত আপনার [ডেটা স্ট্রিম করা](./stream-data.md)-র ধরন অনুসরণ করা উচিত, এটি অনেক বেশি সুবিধাজনক আর পর্দার আড়ালে বাতিল সামলায়।

আপনি যদি JSON Lines স্ট্রিম করেন, তাহলে [JSON Lines স্ট্রিম করা](../tutorial/stream-json-lines.md) টিউটোরিয়াল অনুসরণ করুন।

### `FileResponse` { #fileresponse }

রেসপন্স হিসেবে অ্যাসিঙ্ক্রোনাসভাবে একটি ফাইল স্ট্রিম করে।

অন্য রেসপন্স টাইপগুলোর চেয়ে তৈরি করার জন্য এটি একটু ভিন্ন আর্গুমেন্ট নেয়:

* `path` - স্ট্রিম করার ফাইলের পাথ।
* `headers` - যেকোনো কাস্টম হেডার, একটি ডিকশনারি হিসেবে।
* `media_type` - মিডিয়া টাইপ জানানো একটি স্ট্রিং। সেট না থাকলে ফাইলের নাম বা পাথ দেখে মিডিয়া টাইপ অনুমান করা হবে।
* `filename` - সেট থাকলে এটি রেসপন্সের `Content-Disposition`-এ অন্তর্ভুক্ত হবে। (এতে ব্রাউজার ফাইলটি এই নামে ডাউনলোড করার প্রস্তাব দেয়।)

ফাইল রেসপন্সে যথাযথ `Content-Length`, `Last-Modified` আর `ETag` হেডার থাকবে।

## কাস্টম রেসপন্স ক্লাস { #custom-response-class }

`Response` থেকে ইনহেরিট করে নিজের কাস্টম রেসপন্স ক্লাস তৈরি করে ব্যবহার করতে পারেন।

যেমন, ধরা যাক আপনি কিছু সেটিংসসহ [`orjson`](https://github.com/ijl/orjson) ব্যবহার করতে চান।

ধরা যাক আপনি চান এটি ইনডেন্ট করা আর সাজানো JSON ফেরত দিক, তাই orjson-এর অপশন `orjson.OPT_INDENT_2` ব্যবহার করতে চান।

আপনি একটি `CustomORJSONResponse` তৈরি করতে পারেন। মূল যে কাজটি করতে হবে তা হলো একটি `Response.render(content)` মেথড তৈরি করা, যা বিষয়বস্তু `bytes` হিসেবে ফেরত দেয়:

{* ../../docs_src/custom_response/tutorial009c_py310.py hl[9:14,17] *}

এখন এটা ফেরত দেওয়ার বদলে:

```json
{"message": "Hello World"}
```

...এই রেসপন্স ফেরত দেবে:

```json
{
  "message": "Hello World"
}
```

অবশ্যই, JSON সাজানোর চেয়ে এর আরও অনেক ভালো ব্যবহার আপনি সম্ভবত খুঁজে পাবেন। 😉

### `orjson` নাকি রেসপন্স মডেল { #orjson-or-response-model }

আপনি যদি পারফরম্যান্স খোঁজেন, তাহলে সম্ভবত একটি `orjson` রেসপন্সের চেয়ে একটি [রেসপন্স মডেল](../tutorial/response-model.md) ব্যবহার করাই ভালো।

একটি রেসপন্স মডেল দিয়ে FastAPI মাঝখানের কোনো ধাপ ছাড়াই, যেমন `jsonable_encoder` দিয়ে রূপান্তর (যা অন্য যেকোনো ক্ষেত্রে ঘটত), Pydantic দিয়ে ডেটা JSON-এ সিরিয়ালাইজ করবে।

আর ভেতরে ভেতরে JSON-এ সিরিয়ালাইজ করতে Pydantic `orjson`-এর মতোই Rust-ভিত্তিক ব্যবস্থা ব্যবহার করে, তাই একটি রেসপন্স মডেল দিয়েই আপনি সেরা পারফরম্যান্স পাবেন।

## ডিফল্ট রেসপন্স ক্লাস { #default-response-class }

একটি **FastAPI** ক্লাস ইনস্ট্যান্স বা একটি `APIRouter` তৈরির সময় ডিফল্টভাবে কোন রেসপন্স ক্লাস ব্যবহার হবে তা নির্দিষ্ট করতে পারেন।

এটি সংজ্ঞায়িত করার প্যারামিটার হলো `default_response_class`।

নিচের উদাহরণে **FastAPI** সব *পাথ অপারেশনে* JSON-এর বদলে ডিফল্টভাবে `HTMLResponse` ব্যবহার করবে।

## বাড়তি ডকুমেন্টেশন { #additional-documentation }

`responses` ব্যবহার করে OpenAPI-তে মিডিয়া টাইপ আর আরও অনেক খুঁটিনাটি ঘোষণা করতে পারেন: [OpenAPI-তে বাড়তি রেসপন্স](additional-responses.md)।

/// check | সংক্ষেপে মনে রাখুন

* ডেকোরেটরে `response_class=HTMLResponse` (বা `PlainTextResponse`, `RedirectResponse`, `FileResponse`, `StreamingResponse`) দিন, তাহলে ফাংশন থেকে শুধু বিষয়বস্তু ফেরত দিলেই হয়, ডকুমেন্টেশনেও সঠিক ধরন দেখায়।
* `RedirectResponse(url)` দিয়ে অন্য ঠিকানায় পাঠান, `FileResponse(path)` দিয়ে ফাইল পাঠান।
* নিজের ক্লাস: `Response` থেকে ইনহেরিট করে `media_type` আর `render()` লিখুন।
* JSON-এর সেরা গতির জন্য রেসপন্স মডেলই যথেষ্ট।
