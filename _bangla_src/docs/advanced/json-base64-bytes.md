# Base64 হিসেবে Bytes-সহ JSON { #json-with-bytes-as-base64 }

/// note | এই পেজে যা শিখবেন

* বাইনারি ডেটা (bytes) কেন সরাসরি JSON-এ রাখা যায় না।
* base64 কী, আর কখন এটি ব্যবহার করা উচিত (আর কখন নয়)।
* Pydantic-এর `val_json_bytes` আর `ser_json_bytes` দিয়ে স্বয়ংক্রিয়ভাবে base64 ডিকোড ও এনকোড করা।

///

যদি আপনার অ্যাপকে JSON ডেটা গ্রহণ আর পাঠাতে হয়, কিন্তু এর মধ্যে বাইনারি ডেটা রাখতে হয়, তাহলে সেটিকে base64 হিসেবে এনকোড করতে পারেন।

/// tip | উদাহরণ দিয়ে বুঝি

JSON হলো একটি চিঠি, যাতে শুধু পড়ার মতো অক্ষর লেখা যায়। একটি ছবি বা ফাইলের বাইনারি ডেটা অনেকটা কাঁচা যন্ত্রাংশের মতো, চিঠির খামে সরাসরি ভরা যায় না। base64 সেই যন্ত্রাংশকে শুধু অক্ষর (A–Z, a–z, 0–9, `+`, `/`, `=`) দিয়ে লেখা একটি দীর্ঘ "কোড"-এ রূপান্তর করে, যা চিঠিতে লেখা যায়। প্রাপক আবার সেই কোড থেকে আসল যন্ত্রাংশ ফিরিয়ে আনে। যেমন `hello` এর base64 হলো `aGVsbG8=`।

///

## Base64 বনাম ফাইল { #base64-vs-files }

প্রথমে ভেবে দেখুন, JSON-এ এনকোড করার বদলে বাইনারি ডেটা আপলোডের জন্য [রিকোয়েস্ট ফাইল](../tutorial/request-files.md) আর বাইনারি ডেটা পাঠানোর জন্য [কাস্টম রেসপন্স - FileResponse](./custom-response.md#fileresponse) ব্যবহার করতে পারেন কিনা।

JSON-এ শুধু UTF-8 এনকোড করা স্ট্রিং থাকতে পারে, তাই এতে কাঁচা bytes রাখা যায় না।

Base64 বাইনারি ডেটাকে স্ট্রিংয়ে এনকোড করতে পারে, কিন্তু তা করতে মূল বাইনারি ডেটার চেয়ে বেশি অক্ষর লাগে, তাই এটি সাধারণত নিয়মিত ফাইলের চেয়ে কম দক্ষ হয়।

শুধু তখনই base64 ব্যবহার করুন, যখন JSON-এ বাইনারি ডেটা রাখা একেবারেই জরুরি আর এর জন্য ফাইল ব্যবহার করা সম্ভব নয়।

/// warning | সাধারণ ভুল

বড় ছবি বা ভিডিও base64 করে JSON-এ পাঠাবেন না। base64 ডেটার আকার প্রায় এক-তৃতীয়াংশ বাড়িয়ে দেয়, আর পুরো JSON মেমোরিতে রাখতে হয়। বড় ফাইলের জন্য ফাইল আপলোড/ডাউনলোডই সঠিক পথ।

///

## Pydantic `bytes` { #pydantic-bytes }

আপনি `bytes` ফিল্ডসহ একটি Pydantic মডেল ঘোষণা করে, মডেল কনফিগে `val_json_bytes` দিয়ে বলে দিতে পারেন যে ইনপুট JSON ডেটা *যাচাই (validate)* করার সময় base64 ব্যবহার করতে হবে। সেই যাচাইয়ের অংশ হিসেবে এটি base64 স্ট্রিংকে bytes-এ ডিকোড করবে।

{* ../../docs_src/json_base64_bytes/tutorial001_py310.py ln[1:9,29:35] hl[9] *}

/// info | কোডটি সহজ ভাষায়

* লাইন ৫–৭: `DataInput` মডেলে `data: bytes` ফিল্ড।
* লাইন ৯: `model_config = {"val_json_bytes": "base64"}` মানে "ইনপুট JSON-এ `data` একটি base64 স্ট্রিং হিসেবে আসবে, সেটিকে bytes-এ ডিকোড করো।"
* লাইন ৩২–৩৫: পাথ অপারেশনে `body.data` ইতিমধ্যে আসল bytes। `.decode("utf-8")` দিয়ে সেটিকে আবার টেক্সটে রূপান্তর করে ফেরত দেওয়া হচ্ছে।

`/docs` দেখলে দেখাবে যে `data` ফিল্ডটি base64 এনকোড করা bytes আশা করে:

আপনি এমন একটি রিকোয়েস্ট পাঠাতে পারেন:

```json
{
    "description": "Some data",
    "data": "aGVsbG8="
}
```

/// tip | পরামর্শ

`aGVsbG8=` হলো `hello`-এর base64 এনকোডিং।

///

তারপর Pydantic base64 স্ট্রিংটি ডিকোড করে মডেলের `data` ফিল্ডে আপনাকে মূল bytes দেবে।

আপনি এমন একটি রেসপন্স পাবেন:

```json
{
  "description": "Some data",
  "content": "hello"
}
```

## আউটপুট ডেটার জন্য Pydantic `bytes` { #pydantic-bytes-for-output-data }

আউটপুট ডেটার জন্যও মডেল কনফিগে `ser_json_bytes`-সহ `bytes` ফিল্ড ব্যবহার করতে পারেন, তখন JSON রেসপন্স তৈরির সময় Pydantic bytes-কে base64 হিসেবে *সিরিয়ালাইজ* করবে।

/// info | কোডটি সহজ ভাষায়

* লাইন ১৬: `"ser_json_bytes": "base64"` মানে "JSON-এ পাঠানোর সময় bytes-কে base64 স্ট্রিং বানাও।"
* লাইন ৩৮–৪১: `"hello".encode("utf-8")` দিয়ে bytes তৈরি করে `DataOutput`-এ রাখা হয়। ক্লায়েন্ট পাবে `"data": "aGVsbG8="`।

///

## ইনপুট আর আউটপুট দুটোর জন্য Pydantic `bytes` { #pydantic-bytes-for-input-and-output-data }

আর অবশ্যই, JSON ডেটা গ্রহণ ও পাঠানোর সময় base64 ব্যবহারের জন্য কনফিগার করা একই মডেল দিয়ে `val_json_bytes` দিয়ে ইনপুট (*যাচাই*) আর `ser_json_bytes` দিয়ে আউটপুট (*সিরিয়ালাইজ*) দুটোই সামলাতে পারেন।

{* ../../docs_src/json_base64_bytes/tutorial001_py310.py ln[1:2,19:26,29,44:46] hl[23:26] *}

/// check | সংক্ষেপে মনে রাখুন

* JSON-এ কাঁচা bytes রাখা যায় না, base64 দিয়ে টেক্সটে রূপান্তর করতে হয়।
* ইনপুটে base64 → bytes: `"val_json_bytes": "base64"`। আউটপুটে bytes → base64: `"ser_json_bytes": "base64"`।
* সম্ভব হলে base64-এর বদলে সাধারণ ফাইল আপলোড/রেসপন্স ব্যবহার করুন, এটি বেশি দক্ষ।
