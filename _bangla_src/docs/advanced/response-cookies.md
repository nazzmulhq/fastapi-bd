# রেসপন্সে কুকি { #response-cookies }

/// note | এই পেজে যা শিখবেন

* রেসপন্সের মাধ্যমে ব্রাউজারে কুকি সেট করা।
* `Response` প্যারামিটার ব্যবহার, আর সরাসরি `Response` ফেরত দেওয়া, দুই উপায়ই।

///

আগে আমরা ক্লায়েন্টের পাঠানো কুকি *পড়েছিলাম*। এখানে আমরা নিজেরা ব্রাউজারে কুকি *সেট* করব, যেমন লগইনের পরে একটি সেশন আইডি রেখে দেওয়া।

## একটি `Response` প্যারামিটার ব্যবহার করুন { #use-a-response-parameter }

আপনার *পাথ অপারেশন ফাংশনে* `Response` টাইপের একটি প্যারামিটার ঘোষণা করতে পারেন।

তারপর ওই *অস্থায়ী* রেসপন্স অবজেক্টে কুকি সেট করতে পারেন।

{* ../../docs_src/response_cookies/tutorial002_py310.py hl[1, 8:9] *}

তারপর সাধারণত যেমন করেন, তেমনই প্রয়োজনীয় যেকোনো অবজেক্ট ফেরত দিতে পারেন (একটি `dict`, একটি ডেটাবেস মডেল ইত্যাদি)।

আর আপনি যদি একটি `response_model` ঘোষণা করে থাকেন, তাহলে ফেরত দেওয়া অবজেক্টটি ফিল্টার আর রূপান্তর করতে এটি তখনও ব্যবহার হবে।

**FastAPI** ওই *অস্থায়ী* রেসপন্স থেকে কুকিগুলো (হেডার আর স্ট্যাটাস কোডও) বের করে, আর আপনার ফেরত দেওয়া মানসহ চূড়ান্ত রেসপন্সে সেগুলো রাখবে, যেকোনো `response_model` দিয়ে ফিল্টার করে।

/// info | কোডটি সহজ ভাষায়

* লাইন ৭: `response: Response` প্যারামিটার, FastAPI একটি খালি "খসড়া" রেসপন্স দেয়।
* লাইন ৮: `response.set_cookie(key=..., value=...)` দিয়ে খসড়ায় একটি কুকি যোগ।
* লাইন ৯: সাধারণ ডিকশনারি ফেরত। FastAPI এটিকে JSON বানিয়ে, খসড়ার কুকিসহ চূড়ান্ত রেসপন্স পাঠায়।

এরপর ব্রাউজার প্রতিটি রিকোয়েস্টে `fakesession` কুকি নিজে থেকেই পাঠাবে।

///

ডিপেন্ডেন্সিতেও `Response` প্যারামিটার ঘোষণা করে সেখানে কুকি (আর হেডার) সেট করতে পারেন।

## সরাসরি একটি `Response` ফেরত দিন { #return-a-response-directly }

আপনার কোডে সরাসরি একটি `Response` ফেরত দেওয়ার সময়ও কুকি তৈরি করতে পারেন।

এটি করতে [সরাসরি একটি Response ফেরত দিন](response-directly.md)-এ বর্ণিত উপায়ে একটি রেসপন্স তৈরি করতে পারেন।

তারপর এতে কুকি সেট করে ফেরত দিন:

/// tip | পরামর্শ

মনে রাখবেন, `Response` প্যারামিটার ব্যবহার না করে সরাসরি একটি রেসপন্স ফেরত দিলে FastAPI সেটি সরাসরিই ফেরত দেবে।

তাই আপনাকে নিশ্চিত করতে হবে যে আপনার ডেটা সঠিক টাইপের। যেমন, একটি `JSONResponse` ফেরত দিলে তা JSON-এর সাথে সামঞ্জস্যপূর্ণ।

আর এটাও নিশ্চিত করতে হবে যে এমন কোনো ডেটা পাঠাচ্ছেন না, যা একটি `response_model` দিয়ে ফিল্টার হওয়া উচিত ছিল।

///

### আরও তথ্য { #more-info }

/// note | কারিগরি বিবরণ

`from starlette.responses import Response` বা `from starlette.responses import JSONResponse`-ও ব্যবহার করতে পারতেন।

**FastAPI** ডেভেলপার হিসেবে আপনার সুবিধার জন্যই একই `starlette.responses`-কে `fastapi.responses` হিসেবে দেয়। কিন্তু উপলব্ধ বেশিরভাগ রেসপন্স সরাসরি Starlette থেকে আসে।

আর যেহেতু হেডার আর কুকি সেট করতে `Response` প্রায়ই ব্যবহার হতে পারে, তাই **FastAPI** এটিকে `fastapi.Response`-এও দেয়।

///

সব উপলব্ধ প্যারামিটার আর অপশন দেখতে [Starlette-এর ডকুমেন্টেশন](https://starlette.dev/responses/#set-cookie) দেখুন। (যেমন `max_age` দিয়ে কুকির মেয়াদ, `httponly=True` দিয়ে JavaScript থেকে কুকি লুকানো, `secure=True` দিয়ে শুধু HTTPS-এ পাঠানো।)

/// check | সংক্ষেপে মনে রাখুন

* প্যারামিটারে `response: Response` নিন, তারপর `response.set_cookie(key="...", value="...")`।
* বা সরাসরি `JSONResponse` বানিয়ে তাতে `set_cookie` করে ফেরত দিন।
* নিরাপত্তার জন্য সেশন কুকিতে `httponly=True` আর `secure=True` ব্যবহারের কথা ভাবুন।
