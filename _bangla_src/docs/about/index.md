# সম্পর্কে { #about }

FastAPI সম্পর্কে, এর ডিজাইন, অনুপ্রেরণা এবং আরও অনেক কিছু। 🤓

/// note | এই অংশে যা পাবেন

* [বিকল্প, অনুপ্রেরণা এবং তুলনা](../alternatives.md): FastAPI তৈরির আগে কোন কোন টুল ছিল, আর প্রতিটি থেকে FastAPI কী শিখেছে।
* [ইতিহাস, ডিজাইন এবং ভবিষ্যৎ](../history-design-future.md): FastAPI কেন আর কীভাবে তৈরি হলো।
* [বেঞ্চমার্ক](../benchmarks.md): FastAPI কতটা দ্রুত, আর বেঞ্চমার্ক তুলনা কীভাবে সঠিকভাবে পড়তে হয়।
* [রিপোজিটরি ব্যবস্থাপনা](../management.md): FastAPI প্রজেক্ট কে, কীভাবে পরিচালনা করেন।

FastAPI শেখার জন্য এগুলো পড়া জরুরি নয়, তবে "কেন এভাবে ডিজাইন করা" বুঝতে চাইলে খুব কাজের।
