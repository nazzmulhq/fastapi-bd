# এনভায়রনমেন্ট ভেরিয়েবল { #environment-variables }

একটি **এনভায়রনমেন্ট ভেরিয়েবল** (যাকে **env var**-ও বলা হয়) হলো এমন একটি ভ্যালু যা আপনার Python কোডের বাইরে, অপারেটিং সিস্টেমে থাকে, এবং আপনার অ্যাপ্লিকেশন ও অন্যান্য প্রোগ্রাম এটি পড়তে পারে।

FastAPI অ্যাপ্লিকেশনগুলো সাধারণত ডেটাবেস URL, ইমেইল ক্রেডেনশিয়াল ও সিক্রেট কী-এর মতো কনফিগারেশনের জন্য এনভায়রনমেন্ট ভেরিয়েবল ব্যবহার করে।

অ্যাপ্লিকেশন কনফিগারেশনের জন্য এগুলো কীভাবে ব্যবহার করতে হয় তা আপনি [সেটিংস ও এনভায়রনমেন্ট ভেরিয়েবল](advanced/settings.md)-এ শিখবেন।

## আরও জানুন { #learn-more }

বিস্তারিত, ক্রস-প্ল্যাটফর্ম ব্যাখ্যার জন্য [এনভায়রনমেন্ট ভেরিয়েবল গাইড](https://tiangolo.com/guides/environment-variables/) পড়ুন, যেখানে এনভায়রনমেন্ট ভেরিয়েবল কীভাবে তৈরি ও পড়তে হয় এবং `PATH` এনভায়রনমেন্ট ভেরিয়েবল কীভাবে কাজ করে তা আছে।
