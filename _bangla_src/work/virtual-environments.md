# ভার্চুয়াল এনভায়রনমেন্ট { #virtual-environments }

Python প্রজেক্টে কাজ করার সময় প্রতিটি প্রজেক্টের জন্য ইনস্টল করা প্যাকেজগুলো আলাদা রাখতে আপনার একটি **ভার্চুয়াল এনভায়রনমেন্ট** ব্যবহার করা উচিত।

FastAPI প্রজেক্টের জন্য আমি প্রজেক্ট, এর ডিপেন্ডেন্সি এবং এর ভার্চুয়াল এনভায়রনমেন্ট পরিচালনা করতে [uv](https://docs.astral.sh/uv/) ব্যবহারের সুপারিশ করি।

## আরও জানুন { #learn-more }

ভার্চুয়াল এনভায়রনমেন্ট ভেতরে কীভাবে কাজ করে তা জানতে [ভার্চুয়াল এনভায়রনমেন্ট গাইড](https://tiangolo.com/guides/virtual-environments/) পড়ুন, যেখানে অ্যাক্টিভেশন এবং বিকল্প `python -m venv` ও `pip` ওয়ার্কফ্লো আছে।
