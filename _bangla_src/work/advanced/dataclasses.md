# ডেটাক্লাস ব্যবহার { #using-dataclasses }

FastAPI তৈরি হয়েছে **Pydantic**-এর ওপর ভিত্তি করে, আর আমি আপনাকে দেখিয়ে এসেছি কীভাবে রিকোয়েস্ট ও রেসপন্স ঘোষণা করতে Pydantic মডেল ব্যবহার করতে হয়।

তবে FastAPI একইভাবে [`dataclasses`](https://docs.python.org/3/library/dataclasses.html) ব্যবহারও সাপোর্ট করে:

{* ../../docs_src/dataclasses_/tutorial001_py310.py hl[1,6:11,18:19] *}

এটি সাপোর্টেড **Pydantic**-এর কল্যাণে, কারণ এতে [`dataclasses`-এর অভ্যন্তরীণ সাপোর্ট](https://pydantic.dev/docs/validation/latest/concepts/dataclasses/#usage-of-stdlib-dataclasses-with-basemodel) আছে।

তাই ওপরের কোডটি স্পষ্টভাবে Pydantic ব্যবহার না করলেও, ওই স্ট্যান্ডার্ড ডেটাক্লাসগুলোকে Pydantic-এর নিজস্ব ধরনের ডেটাক্লাসে রূপান্তর করতে FastAPI Pydantic ব্যবহার করছে।

আর অবশ্যই এটি একই জিনিসগুলো সাপোর্ট করে:

* ডেটা ভ্যালিডেশন
* ডেটা সিরিয়ালাইজেশন
* ডেটা ডকুমেন্টেশন ইত্যাদি।

এটি Pydantic মডেলের মতোই কাজ করে। আর ভেতরে ভেতরে আসলে একইভাবে, Pydantic ব্যবহার করেই এটি অর্জিত হয়।

/// note | নোট

মনে রাখবেন, Pydantic মডেল যা যা করতে পারে ডেটাক্লাস তার সবকিছু করতে পারে না।

তাই আপনাকে হয়তো তবুও Pydantic মডেল ব্যবহার করতে হতে পারে।

তবে আপনার কাছে যদি একগাদা ডেটাক্লাস পড়ে থাকে, তাহলে FastAPI দিয়ে একটি ওয়েব API চালাতে সেগুলো ব্যবহারের জন্য এটি একটি চমৎকার কৌশল। 🤓

## নেস্টেড ডেটা স্ট্রাকচারে ডেটাক্লাস { #dataclasses-in-nested-data-structures }

নেস্টেড ডেটা স্ট্রাকচার তৈরি করতে আপনি অন্যান্য টাইপ অ্যানোটেশনের সাথে `dataclasses` একত্রিতও করতে পারেন।

কিছু ক্ষেত্রে আপনাকে হয়তো তবুও Pydantic-এর `dataclasses` ভার্সন ব্যবহার করতে হতে পারে। যেমন, যদি স্বয়ংক্রিয়ভাবে তৈরি হওয়া API ডকুমেন্টেশনে আপনার এরর হয়।

সেক্ষেত্রে আপনি শুধু স্ট্যান্ডার্ড `dataclasses`-কে `pydantic.dataclasses` দিয়ে বদলে দিতে পারেন, যা হুবহু বিকল্প হিসেবে বসানো যায়:

{* ../../docs_src/dataclasses_/tutorial003_py310.py hl[1,4,7:10,13:16,22:24,27] *}

1. আমরা এখনো স্ট্যান্ডার্ড `dataclasses` থেকে `field` ইম্পোর্ট করি।

2. `pydantic.dataclasses` হলো `dataclasses`-এর একটি হুবহু বিকল্প।

3. `Author` ডেটাক্লাসে `Item` ডেটাক্লাসের একটি লিস্ট আছে।

4. `Author` ডেটাক্লাসটি `response_model` প্যারামিটার হিসেবে ব্যবহার হয়।

5. রিকোয়েস্ট বডি হিসেবে আপনি ডেটাক্লাসের সাথে অন্যান্য স্ট্যান্ডার্ড টাইপ অ্যানোটেশন ব্যবহার করতে পারেন।

    এক্ষেত্রে এটি `Item` ডেটাক্লাসের একটি লিস্ট।

6. এখানে আমরা এমন একটি ডিকশনারি রিটার্ন করছি যাতে `items` আছে, যা ডেটাক্লাসের একটি লিস্ট।

    FastAPI তখনও ডেটাকে JSON-এ <dfn title="ডেটাকে এমন একটি ফরম্যাটে রূপান্তর করা যা পাঠানো যায়">সিরিয়ালাইজ</dfn> করতে সক্ষম।

7. এখানে `response_model` `Author` ডেটাক্লাসের একটি লিস্টের টাইপ অ্যানোটেশন ব্যবহার করছে।

    আবারও, আপনি স্ট্যান্ডার্ড টাইপ অ্যানোটেশনের সাথে `dataclasses` একত্রিত করতে পারেন।

8. লক্ষ করুন, এই *পাথ অপারেশন ফাংশনটি* `async def`-এর বদলে সাধারণ `def` ব্যবহার করে।

    বরাবরের মতো, FastAPI-তে আপনি প্রয়োজনমতো `def` ও `async def` মেশাতে পারেন।

    কখন কোনটি ব্যবহার করবেন তা ঝালিয়ে নিতে চাইলে [`async` ও `await`](../async.md#in-a-hurry) সম্পর্কিত ডকুমেন্টেশনে _"তাড়াহুড়োয় আছেন?"_ অংশটি দেখুন।

9. এই *পাথ অপারেশন ফাংশনটি* ডেটাক্লাস রিটার্ন করছে না (যদিও করতে পারত), বরং অভ্যন্তরীণ ডেটাসহ ডিকশনারির একটি লিস্ট রিটার্ন করছে।

    রেসপন্স রূপান্তর করতে FastAPI `response_model` প্যারামিটার (যাতে ডেটাক্লাস আছে) ব্যবহার করবে।

জটিল ডেটা স্ট্রাকচার তৈরি করতে আপনি অন্যান্য টাইপ অ্যানোটেশনের সাথে `dataclasses` অনেক ভিন্ন ভিন্ন সমন্বয়ে একত্রিত করতে পারেন।

আরও নির্দিষ্ট বিবরণ দেখতে ওপরের কোডের ভেতরের অ্যানোটেশন টিপসগুলো দেখুন।

## আরও জানুন { #learn-more }

আপনি অন্যান্য Pydantic মডেলের সাথে `dataclasses` একত্রিত করতে, সেগুলো থেকে ইনহেরিট করতে, নিজের মডেলে অন্তর্ভুক্ত করতে ইত্যাদিও পারেন।

আরও জানতে [ডেটাক্লাস নিয়ে Pydantic ডকুমেন্টেশন](https://pydantic.dev/docs/validation/latest/concepts/dataclasses/) দেখুন।
