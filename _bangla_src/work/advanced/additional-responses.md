# OpenAPI-তে অতিরিক্ত রেসপন্স { #additional-responses-in-openapi }

/// warning | সতর্কতা

এটি বেশ অ্যাডভান্সড একটি বিষয়।

আপনি যদি সবে **FastAPI** শুরু করে থাকেন, তাহলে হয়তো এটি আপনার দরকার নেই।

///

আপনি অতিরিক্ত স্ট্যাটাস কোড, মিডিয়া টাইপ, বিবরণ ইত্যাদিসহ অতিরিক্ত রেসপন্স ঘোষণা করতে পারেন।

ওই অতিরিক্ত রেসপন্সগুলো OpenAPI স্কিমায় অন্তর্ভুক্ত হবে, তাই সেগুলো API ডকুমেন্টেশনেও দেখা যাবে।

তবে ওই অতিরিক্ত রেসপন্সগুলোর জন্য আপনাকে নিশ্চিত করতে হবে যে আপনি আপনার স্ট্যাটাস কোড ও কনটেন্টসহ সরাসরি `JSONResponse`-এর মতো একটি `Response` রিটার্ন করছেন।

## `model`-সহ অতিরিক্ত রেসপন্স { #additional-response-with-model }

আপনার *পাথ অপারেশন ডেকোরেটরে* আপনি `responses` নামে একটি প্যারামিটার দিতে পারেন।

এটি একটি `dict` গ্রহণ করে: কী-গুলো হলো প্রতিটি রেসপন্সের স্ট্যাটাস কোড (যেমন `200`), আর ভ্যালুগুলো হলো প্রতিটির তথ্যসহ অন্যান্য `dict`।

ওই প্রতিটি রেসপন্স `dict`-এ `response_model`-এর মতোই একটি Pydantic মডেল ধারণকারী `model` কী থাকতে পারে।

**FastAPI** সেই মডেলটি নিয়ে এর JSON Schema তৈরি করবে এবং OpenAPI-এর সঠিক জায়গায় অন্তর্ভুক্ত করবে।

যেমন, `404` স্ট্যাটাস কোড ও একটি Pydantic মডেল `Message`-সহ আরেকটি রেসপন্স ঘোষণা করতে আপনি লিখতে পারেন:

/// note | নোট

///

/// note | নোট

`model` কী OpenAPI-এর অংশ নয়।

**FastAPI** সেখান থেকে Pydantic মডেলটি নিয়ে JSON Schema তৈরি করবে এবং সঠিক জায়গায় রাখবে।

সঠিক জায়গাটি হলো:

* `content` কী-তে, যার ভ্যালু আরেকটি JSON অবজেক্ট (`dict`), যাতে থাকে:
    * মিডিয়া টাইপসহ একটি কী, যেমন `application/json`, যার ভ্যালু আরেকটি JSON অবজেক্ট, যাতে থাকে:
        * একটি `schema` কী, যার ভ্যালু হলো মডেল থেকে তৈরি JSON Schema, এটিই সঠিক জায়গা।
            * **FastAPI** এটি সরাসরি অন্তর্ভুক্ত না করে এখানে আপনার OpenAPI-এর অন্য একটি জায়গায় থাকা গ্লোবাল JSON Schema-গুলোর একটি রেফারেন্স যোগ করে। এভাবে অন্যান্য অ্যাপ্লিকেশন ও ক্লায়েন্ট সরাসরি ওই JSON Schema-গুলো ব্যবহার করতে পারে, আরও ভালো কোড জেনারেশন টুল দিতে পারে, ইত্যাদি।

## প্রধান রেসপন্সের জন্য অতিরিক্ত মিডিয়া টাইপ { #additional-media-types-for-the-main-response }

একই প্রধান রেসপন্সের জন্য ভিন্ন ভিন্ন মিডিয়া টাইপ যোগ করতে আপনি এই একই `responses` প্যারামিটার ব্যবহার করতে পারেন।

যেমন, আপনি `image/png`-এর একটি অতিরিক্ত মিডিয়া টাইপ যোগ করতে পারেন, ঘোষণা করে যে আপনার *পাথ অপারেশন* একটি JSON অবজেক্ট (মিডিয়া টাইপ `application/json`-সহ) বা একটি PNG ছবি রিটার্ন করতে পারে:

///

/// note | নোট

আপনি যদি আপনার `responses` প্যারামিটারে স্পষ্টভাবে ভিন্ন কোনো মিডিয়া টাইপ উল্লেখ না করেন, তাহলে FastAPI ধরে নেবে যে রেসপন্সটির মিডিয়া টাইপ প্রধান রেসপন্স ক্লাসের মতোই (ডিফল্ট `application/json`)।

তবে আপনি যদি `None` মিডিয়া টাইপসহ একটি কাস্টম রেসপন্স ক্লাস উল্লেখ করে থাকেন, তাহলে সংশ্লিষ্ট মডেল আছে এমন যেকোনো অতিরিক্ত রেসপন্সের জন্য FastAPI `application/json` ব্যবহার করবে।

## তথ্য একত্রিত করা { #combining-information }

আপনি `response_model`, `status_code` ও `responses` প্যারামিটারসহ একাধিক জায়গা থেকে রেসপন্সের তথ্য একত্রিতও করতে পারেন।

আপনি ডিফল্ট স্ট্যাটাস কোড `200` (বা দরকার হলে একটি কাস্টম কোড) ব্যবহার করে একটি `response_model` ঘোষণা করতে পারেন, তারপর সরাসরি OpenAPI স্কিমায় `responses`-এ ওই একই রেসপন্সের জন্য অতিরিক্ত তথ্য ঘোষণা করতে পারেন।

**FastAPI** `responses`-এর অতিরিক্ত তথ্য রেখে দেবে, এবং আপনার মডেলের JSON Schema-র সাথে একত্রিত করবে।

যেমন, আপনি `404` স্ট্যাটাস কোডসহ একটি রেসপন্স ঘোষণা করতে পারেন যা একটি Pydantic মডেল ব্যবহার করে এবং যার একটি কাস্টম `description` আছে।

আর `200` স্ট্যাটাস কোডসহ একটি রেসপন্স যা আপনার `response_model` ব্যবহার করে, তবে একটি কাস্টম `example` অন্তর্ভুক্ত করে:

## OpenAPI রেসপন্স সম্পর্কে আরও তথ্য { #more-information-about-openapi-responses }

রেসপন্সে ঠিক কী কী অন্তর্ভুক্ত করতে পারেন তা দেখতে OpenAPI স্পেসিফিকেশনের এই অংশগুলো দেখতে পারেন:

* [OpenAPI Responses Object](https://github.com/OAI/OpenAPI-Specification/blob/main/versions/3.1.0.md#responses-object), এতে `Response Object` অন্তর্ভুক্ত।
* [OpenAPI Response Object](https://github.com/OAI/OpenAPI-Specification/blob/main/versions/3.1.0.md#response-object), এখান থেকে যেকোনো কিছু আপনি সরাসরি আপনার `responses` প্যারামিটারের ভেতরের প্রতিটি রেসপন্সে অন্তর্ভুক্ত করতে পারেন। যার মধ্যে আছে `description`, `headers`, `content` (এর ভেতরেই আপনি বিভিন্ন মিডিয়া টাইপ ও JSON Schema ঘোষণা করেন) এবং `links`।
