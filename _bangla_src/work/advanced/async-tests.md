# অ্যাসিঙ্ক টেস্ট { #async-tests }

আপনি ইতিমধ্যে দেখেছেন কীভাবে দেওয়া `TestClient` ব্যবহার করে আপনার **FastAPI** অ্যাপ্লিকেশন টেস্ট করতে হয়। এ পর্যন্ত আপনি কেবল `async` ফাংশন ব্যবহার না করে সিঙ্ক্রোনাস টেস্ট লেখা দেখেছেন।

আপনার টেস্টে অ্যাসিঙ্ক্রোনাস ফাংশন ব্যবহার করতে পারা কাজে আসতে পারে, যেমন যখন আপনি অ্যাসিঙ্ক্রোনাসভাবে আপনার ডেটাবেস কুয়েরি করছেন। কল্পনা করুন আপনি আপনার FastAPI অ্যাপ্লিকেশনে রিকোয়েস্ট পাঠানো টেস্ট করতে চান এবং তারপর যাচাই করতে চান যে আপনার ব্যাকএন্ড একটি async ডেটাবেস লাইব্রেরি ব্যবহার করে ডেটাবেসে সফলভাবে সঠিক ডেটা লিখেছে।

চলুন দেখি কীভাবে এটি কাজ করানো যায়।

## pytest.mark.anyio { #pytest-mark-anyio }

আমরা যদি আমাদের টেস্টে অ্যাসিঙ্ক্রোনাস ফাংশন কল করতে চাই, তাহলে আমাদের টেস্ট ফাংশনগুলোকে অ্যাসিঙ্ক্রোনাস হতে হবে। AnyIO এর জন্য একটি চমৎকার প্লাগইন দেয়, যা আমাদের উল্লেখ করতে দেয় যে কিছু টেস্ট ফাংশন অ্যাসিঙ্ক্রোনাসভাবে কল করতে হবে।

## HTTPX { #httpx }

আপনার **FastAPI** অ্যাপ্লিকেশন `async def`-এর বদলে সাধারণ `def` ফাংশন ব্যবহার করলেও এটি ভেতরে ভেতরে তবুও একটি `async` অ্যাপ্লিকেশন।

স্ট্যান্ডার্ড pytest ব্যবহার করে আপনার সাধারণ `def` টেস্ট ফাংশনে অ্যাসিঙ্ক্রোনাস FastAPI অ্যাপ্লিকেশন কল করতে `TestClient` ভেতরে কিছু জাদু করে। কিন্তু আমরা যখন এটি অ্যাসিঙ্ক্রোনাস ফাংশনের ভেতরে ব্যবহার করি তখন সেই জাদু আর কাজ করে না। আমাদের টেস্টগুলো অ্যাসিঙ্ক্রোনাসভাবে চালালে আমরা আর আমাদের টেস্ট ফাংশনের ভেতরে `TestClient` ব্যবহার করতে পারি না।

`TestClient` [HTTPX](https://www.python-httpx.org)-এর ওপর ভিত্তি করে তৈরি, আর সৌভাগ্যবশত API টেস্ট করতে আমরা সরাসরি এটি ব্যবহার করতে পারি।

## অন্যান্য অ্যাসিঙ্ক্রোনাস ফাংশন কল { #other-asynchronous-function-calls }

যেহেতু টেস্টিং ফাংশনটি এখন অ্যাসিঙ্ক্রোনাস, তাই আপনার টেস্টে আপনার FastAPI অ্যাপ্লিকেশনে রিকোয়েস্ট পাঠানো ছাড়াও এখন অন্যান্য `async` ফাংশন কল (এবং `await`) করতে পারেন, ঠিক যেভাবে আপনার কোডের অন্য যেকোনো জায়গায় কল করতেন।

/// tip | পরামর্শ

আপনার টেস্টে অ্যাসিঙ্ক্রোনাস ফাংশন কল যুক্ত করার সময় যদি একটি `RuntimeError: Task attached to a different loop` পান (যেমন [MongoDB-র MotorClient](https://stackoverflow.com/questions/41584243/runtimeerror-task-attached-to-a-different-loop) ব্যবহারের সময়), তাহলে মনে রাখবেন যে ইভেন্ট লুপ দরকার এমন অবজেক্টগুলো কেবল async ফাংশনের ভেতরেই ইনস্ট্যান্সিয়েট করবেন, যেমন একটি `@app.on_event("startup")` কলব্যাকে।
