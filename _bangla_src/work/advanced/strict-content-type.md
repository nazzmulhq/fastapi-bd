# কঠোর Content-Type যাচাই { #strict-content-type-checking }

ডিফল্টভাবে **FastAPI** JSON রিকোয়েস্ট বডির জন্য কঠোর `Content-Type` হেডার যাচাই ব্যবহার করে, এর মানে বডিকে JSON হিসেবে পার্স করার জন্য JSON রিকোয়েস্টে **অবশ্যই** একটি বৈধ `Content-Type` হেডার (যেমন `application/json`) থাকতে হবে।

## CSRF ঝুঁকি { #csrf-risk }

এই ডিফল্ট আচরণ খুবই নির্দিষ্ট একটি পরিস্থিতিতে এক শ্রেণির **Cross-Site Request Forgery (CSRF)** আক্রমণ থেকে সুরক্ষা দেয়।

এই আক্রমণগুলো এই সত্যের সুযোগ নেয় যে ব্রাউজারগুলো স্ক্রিপ্টকে কোনো CORS প্রিফ্লাইট যাচাই ছাড়াই রিকোয়েস্ট পাঠাতে দেয়, যখন সেগুলো:

* কোনো `Content-Type` হেডার রাখে না (যেমন একটি `Blob` বডিসহ `fetch()` ব্যবহার করে)
* এবং কোনো অথেনটিকেশন ক্রেডেনশিয়াল পাঠায় না।

এ ধরনের আক্রমণ প্রধানত প্রাসঙ্গিক যখন:

* অ্যাপ্লিকেশনটি লোকালি (যেমন `localhost`-এ) বা একটি অভ্যন্তরীণ নেটওয়ার্কে চলছে
* এবং অ্যাপ্লিকেশনটির কোনো অথেনটিকেশন নেই, এটি আশা করে যে একই নেটওয়ার্কের যেকোনো রিকোয়েস্ট বিশ্বাস করা যায়।

তারপর ফ্রন্টএন্ড ব্যবহার করে আপনি AI এজেন্টকে দিয়ে আপনার পক্ষে কাজ করাতে পারেন।

যেহেতু এটি ওপেন ইন্টারনেটে নয়, **লোকালি** চলছে, তাই আপনি ঠিক করলেন **কোনো অথেনটিকেশন** সেট আপ করবেন না, শুধু লোকাল নেটওয়ার্কের অ্যাক্সেসের ওপর ভরসা করবেন।

তারপর আপনার কোনো একজন ইউজার এটি ইনস্টল করে লোকালি চালাতে পারেন।

তারপর তিনি একটি ক্ষতিকর ওয়েবসাইট খুলতে পারেন, যেমন এরকম কিছু

⟦CODE3⟧

⟦CODE4⟧

ক্ষতিকর ওয়েবসাইট ও লোকাল অ্যাপের হোস্ট ভিন্ন হলেও ব্রাউজার একটি CORS প্রিফ্লাইট রিকোয়েস্ট চালু করবে না, কারণ:

* এটি কোনো অথেনটিকেশন ছাড়া চলছে, এটিকে কোনো ক্রেডেনশিয়াল পাঠাতে হয় না।
* ব্রাউজার মনে করে এটি JSON পাঠাচ্ছে না (অনুপস্থিত `Content-Type` হেডারের কারণে)।

তারপর ক্ষতিকর ওয়েবসাইটটি লোকাল AI এজেন্টকে দিয়ে ইউজারের সাবেক বসকে রাগী মেসেজ পাঠাতে পারে... বা আরও খারাপ কিছু। 😅

## ওপেন ইন্টারনেট { #open-internet }

আপনার অ্যাপ যদি ওপেন ইন্টারনেটে থাকে, তাহলে আপনি "নেটওয়ার্কের ওপর ভরসা" করে যে কাউকে অথেনটিকেশন ছাড়া বিশেষাধিকারপ্রাপ্ত রিকোয়েস্ট পাঠাতে দেবেন না।

আক্রমণকারীরা শুধু একটি স্ক্রিপ্ট চালিয়ে আপনার API-তে রিকোয়েস্ট পাঠাতে পারত, ব্রাউজারের কোনো ভূমিকার দরকার নেই, তাই আপনি সম্ভবত ইতিমধ্যে যেকোনো বিশেষাধিকারপ্রাপ্ত এন্ডপয়েন্ট সুরক্ষিত করছেন।

সেক্ষেত্রে **এই আক্রমণ / ঝুঁকি আপনার জন্য প্রযোজ্য নয়**।

এই ঝুঁকি ও আক্রমণ প্রধানত প্রাসঙ্গিক যখন অ্যাপটি **লোকাল নেটওয়ার্কে** চলে এবং সেটিই **একমাত্র ধরে নেওয়া সুরক্ষা**।
