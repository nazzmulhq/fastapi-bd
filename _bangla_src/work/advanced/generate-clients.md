# SDK তৈরি করা { #generating-sdks }

যেহেতু **FastAPI** **OpenAPI** স্পেসিফিকেশনের ওপর ভিত্তি করে তৈরি, তাই এর API-গুলো এমন একটি স্ট্যান্ডার্ড ফরম্যাটে বর্ণনা করা যায় যা অনেক টুল বোঝে।

এতে হালনাগাদ **ডকুমেন্টেশন**, একাধিক ভাষায় ক্লায়েন্ট লাইব্রেরি (<abbr title="Software Development Kits - সফটওয়্যার ডেভেলপমেন্ট কিট">**SDK**</abbr>), এবং আপনার কোডের সাথে সামঞ্জস্য রেখে চলা **টেস্টিং** বা **অটোমেশন ওয়ার্কফ্লো** তৈরি করা সহজ হয়।

এই গাইডে আপনি শিখবেন কীভাবে আপনার FastAPI ব্যাকএন্ডের জন্য একটি **TypeScript SDK** তৈরি করতে হয়।

## ওপেন সোর্স SDK জেনারেটর { #open-source-sdk-generators }

একটি বহুমুখী অপশন হলো [OpenAPI Generator](https://openapi-generator.tech/), যা **অনেক প্রোগ্রামিং ভাষা** সাপোর্ট করে এবং আপনার OpenAPI স্পেসিফিকেশন থেকে SDK তৈরি করতে পারে।

**TypeScript ক্লায়েন্টের** জন্য [Hey API](https://heyapi.dev/) একটি বিশেষভাবে তৈরি সমাধান, যা TypeScript ইকোসিস্টেমের জন্য একটি অপটিমাইজড অভিজ্ঞতা দেয়।

আরও SDK জেনারেটর খুঁজে পেতে পারেন [OpenAPI.Tools](https://openapi.tools/categories/sdk-generators)-এ।

/// tip | পরামর্শ

FastAPI স্বয়ংক্রিয়ভাবে **OpenAPI 3.1** স্পেসিফিকেশন তৈরি করে, তাই আপনি যে টুলই ব্যবহার করুন তাকে অবশ্যই এই ভার্সন সাপোর্ট করতে হবে।

...কারণ ক্লায়েন্ট জেনারেটর প্রতিটি *পাথ অপারেশনের* জন্য OpenAPI-এর অভ্যন্তরীণ **operation ID** ব্যবহার করে।

OpenAPI দাবি করে যে প্রতিটি operation ID সব *পাথ অপারেশন* জুড়ে অনন্য হবে, তাই FastAPI সেই operation ID তৈরি করতে **ফাংশনের নাম**, **পাথ** এবং **HTTP মেথড/অপারেশন** ব্যবহার করে, কারণ এভাবে এটি নিশ্চিত করতে পারে যে operation ID-গুলো অনন্য।

তবে এরপর আমি আপনাকে দেখাব কীভাবে এটি উন্নত করা যায়। 🤓

## কাস্টম Operation ID ও আরও ভালো মেথডের নাম { #custom-operation-ids-and-better-method-names }

এই operation ID-গুলো যেভাবে **তৈরি হয়** তা আপনি **পরিবর্তন** করতে পারেন, যাতে সেগুলো আরও সহজ হয় এবং ক্লায়েন্টে **আরও সহজ মেথডের নাম** থাকে।

এক্ষেত্রে আপনাকে অন্য কোনো উপায়ে নিশ্চিত করতে হবে যে প্রতিটি operation ID **অনন্য**।

যেমন, আপনি নিশ্চিত করতে পারেন যে প্রতিটি *পাথ অপারেশনের* একটি ট্যাগ আছে, এবং তারপর **ট্যাগ** ও *পাথ অপারেশনের* **নাম** (ফাংশনের নাম)-এর ভিত্তিতে operation ID তৈরি করতে পারেন।

### কাস্টম Generate Unique ID ফাংশন { #custom-generate-unique-id-function }

FastAPI প্রতিটি *পাথ অপারেশনের* জন্য একটি **অনন্য ID** ব্যবহার করে, যা **operation ID** এবং রিকোয়েস্ট বা রেসপন্সের জন্য প্রয়োজনীয় যেকোনো কাস্টম মডেলের নামের জন্যও ব্যবহার হয়।

আপনি ওই ফাংশনটি কাস্টমাইজ করতে পারেন। এটি একটি `APIRoute` নেয় এবং একটি স্ট্রিং আউটপুট দেয়।

যেমন, এখানে এটি প্রথম ট্যাগ (আপনার সম্ভবত কেবল একটি ট্যাগ থাকবে) এবং *পাথ অপারেশনের* নাম (ফাংশনের নাম) ব্যবহার করছে।

তারপর আপনি ওই কাস্টম ফাংশনটি **FastAPI**-তে `generate_unique_id_function` প্যারামিটার হিসেবে দিতে পারেন:

### ক্লায়েন্ট জেনারেটরের জন্য OpenAPI স্পেসিফিকেশন আগে থেকে প্রসেস করুন { #preprocess-the-openapi-specification-for-the-client-generator }

তৈরি হওয়া কোডে এখনো কিছু **পুনরাবৃত্ত তথ্য** আছে।

আমরা ইতিমধ্যে জানি যে এই মেথডটি **items**-এর সাথে সম্পর্কিত, কারণ শব্দটি `ItemsService`-এ আছে (ট্যাগ থেকে নেওয়া), কিন্তু মেথডের নামের শুরুতেও এখনো ট্যাগের নাম আছে। 😕

আমরা সম্ভবত সাধারণভাবে OpenAPI-এর জন্য এটি রেখে দিতে চাইব, কারণ এটি নিশ্চিত করবে যে operation ID-গুলো **অনন্য**।

তবে তৈরি হওয়া ক্লায়েন্টের জন্য আমরা ক্লায়েন্ট তৈরির ঠিক আগে OpenAPI operation ID-গুলো **পরিবর্তন** করতে পারি, শুধু ওই মেথডের নামগুলো আরও সুন্দর ও **পরিচ্ছন্ন** করতে।

## সুবিধা { #benefits }

স্বয়ংক্রিয়ভাবে তৈরি ক্লায়েন্ট ব্যবহার করলে আপনি এগুলোর জন্য **অটোকমপ্লিশন** পাবেন:

* মেথড।
* বডিতে রিকোয়েস্ট পেলোড, কুয়েরি প্যারামিটার ইত্যাদি।
* রেসপন্স পেলোড।

সবকিছুর জন্য আপনি **ইনলাইন এররও** পাবেন।

আর যখনই আপনি ব্যাকএন্ড কোড আপডেট করে ফ্রন্টএন্ড **পুনরায় তৈরি** করবেন, তখন এতে যেকোনো নতুন *পাথ অপারেশন* মেথড হিসেবে পাওয়া যাবে, পুরোনোগুলো সরে যাবে, এবং অন্য যেকোনো পরিবর্তন তৈরি হওয়া কোডে প্রতিফলিত হবে। 🤓

এর মানে এটাও যে কিছু পরিবর্তন হলে তা স্বয়ংক্রিয়ভাবে ক্লায়েন্ট কোডে **প্রতিফলিত** হবে। আর আপনি যদি ক্লায়েন্ট **বিল্ড** করেন, তাহলে ব্যবহৃত ডেটায় কোনো **অমিল** থাকলে এটি এরর দেবে।

তাই প্রোডাকশনে আপনার চূড়ান্ত ইউজারদের কাছে এরর দেখা দেওয়ার অপেক্ষা করে তারপর সমস্যা কোথায় তা ডিবাগ করার চেষ্টা না করে, ডেভেলপমেন্ট চক্রের খুব শুরুতেই আপনি **অনেক এরর ধরে ফেলবেন**। ✨
