# রেসপন্স - স্ট্যাটাস কোড পরিবর্তন { #response-change-status-code }

আপনি সম্ভবত আগে পড়েছেন যে একটি ডিফল্ট [রেসপন্স স্ট্যাটাস কোড](../tutorial/response-status-code.md) সেট করা যায়।

তবে কিছু ক্ষেত্রে আপনাকে ডিফল্ট থেকে ভিন্ন একটি স্ট্যাটাস কোড রিটার্ন করতে হয়।

## ব্যবহারের ক্ষেত্র { #use-case }

যেমন, কল্পনা করুন আপনি ডিফল্টভাবে "OK" `200` HTTP স্ট্যাটাস কোড রিটার্ন করতে চান।

কিন্তু ডেটা না থাকলে আপনি সেটি তৈরি করতে চান, এবং "CREATED" `201` HTTP স্ট্যাটাস কোড রিটার্ন করতে চান।

কিন্তু তবুও আপনি একটি `response_model` দিয়ে আপনার রিটার্ন করা ডেটা ফিল্টার ও রূপান্তর করতে চান।

এসব ক্ষেত্রে আপনি একটি `Response` প্যারামিটার ব্যবহার করতে পারেন।

## একটি `Response` প্যারামিটার ব্যবহার করুন { #use-a-response-parameter }

আপনার *পাথ অপারেশন ফাংশনে* আপনি `Response` টাইপের একটি প্যারামিটার ঘোষণা করতে পারেন (যেমনটা কুকি ও হেডারের জন্য করতে পারেন)।

তারপর ওই *অস্থায়ী* রেসপন্স অবজেক্টে আপনি `status_code` সেট করতে পারেন।

{* ../../docs_src/response_change_status_code/tutorial001_py310.py hl[1,9,12] *}

তারপর আপনি স্বাভাবিকভাবেই যেকোনো প্রয়োজনীয় অবজেক্ট রিটার্ন করতে পারেন (একটি `dict`, একটি ডেটাবেস মডেল ইত্যাদি)।

আর আপনি যদি একটি `response_model` ঘোষণা করে থাকেন, তাহলে আপনার রিটার্ন করা অবজেক্ট ফিল্টার ও রূপান্তর করতে সেটি তখনও ব্যবহার হবে।

**FastAPI** ওই *অস্থায়ী* রেসপন্স থেকে স্ট্যাটাস কোড (এবং কুকি ও হেডারও) বের করবে, এবং সেগুলো চূড়ান্ত রেসপন্সে রাখবে, যাতে যেকোনো `response_model` দিয়ে ফিল্টার করা আপনার রিটার্ন করা ভ্যালুটি থাকবে।

আপনি ডিপেন্ডেন্সিতেও `Response` প্যারামিটার ঘোষণা করে সেগুলোতে স্ট্যাটাস কোড সেট করতে পারেন। তবে মনে রাখবেন, সবশেষে যেটি সেট করা হবে সেটিই কার্যকর হবে।
