# টেমপ্লেট { #templates }

**FastAPI**-এর সাথে আপনি আপনার পছন্দের যেকোনো টেমপ্লেট ইঞ্জিন ব্যবহার করতে পারেন।

একটি প্রচলিত পছন্দ হলো Jinja2, Flask ও অন্যান্য টুল যেটি ব্যবহার করে।

এটি সহজে কনফিগার করার জন্য ইউটিলিটি আছে যা আপনি সরাসরি আপনার **FastAPI** অ্যাপ্লিকেশনে ব্যবহার করতে পারেন (Starlette সরবরাহ করে)।

## `Jinja2Templates` ব্যবহার { #using-jinja2templates }

* `Jinja2Templates` ইম্পোর্ট করুন।
* একটি `templates` অবজেক্ট তৈরি করুন যা পরে পুনরায় ব্যবহার করতে পারবেন।
* যে *পাথ অপারেশন* একটি টেমপ্লেট রিটার্ন করবে তাতে একটি `Request` প্যারামিটার ঘোষণা করুন।
* একটি `TemplateResponse` রেন্ডার করে রিটার্ন করতে আপনার তৈরি `templates` ব্যবহার করুন, টেমপ্লেটের নাম, রিকোয়েস্ট অবজেক্ট এবং Jinja2 টেমপ্লেটের ভেতরে ব্যবহারের জন্য কী-ভ্যালু জোড়াসহ একটি "context" ডিকশনারি দিন।
