# OpenAPI ওয়েবহুক { #openapi-webhooks }

এমন ক্ষেত্র আছে যেখানে আপনি আপনার API-এর **ইউজারদের** জানাতে চান যে আপনার অ্যাপ কিছু ডেটাসহ *তাদের* অ্যাপ কল করতে (একটি রিকোয়েস্ট পাঠিয়ে) পারে, সাধারণত কোনো ধরনের **ইভেন্ট** সম্পর্কে **জানাতে**।

এর মানে আপনার ইউজারদের আপনার API-তে রিকোয়েস্ট পাঠানোর সাধারণ প্রক্রিয়ার বদলে, **আপনার API** (বা আপনার অ্যাপ) **তাদের সিস্টেমে** (তাদের API, তাদের অ্যাপে) **রিকোয়েস্ট পাঠাতে** পারে।

একে সাধারণত **ওয়েবহুক** বলা হয়।

## ওয়েবহুকের ধাপগুলো { #webhooks-steps }

প্রক্রিয়াটি সাধারণত হলো, **আপনি** আপনার কোডে **সংজ্ঞায়িত করেন** কোন মেসেজটি পাঠাবেন, অর্থাৎ **রিকোয়েস্টের বডি**।

আপনি কোনো এক উপায়ে এটাও সংজ্ঞায়িত করেন যে কোন **মুহূর্তে** আপনার অ্যাপ ওই রিকোয়েস্ট বা ইভেন্টগুলো পাঠাবে।

আর **আপনার ইউজাররা** কোনো এক উপায়ে (যেমন কোথাও একটি ওয়েব ড্যাশবোর্ডে) সেই **URL** সংজ্ঞায়িত করেন যেখানে আপনার অ্যাপের ওই রিকোয়েস্টগুলো পাঠানো উচিত।

ওয়েবহুকের URL কীভাবে রেজিস্টার করতে হবে তার সব **লজিক** এবং আসলে ওই রিকোয়েস্টগুলো পাঠানোর কোড আপনার ওপর নির্ভর করে। আপনি **নিজের কোডে** যেভাবে খুশি তা লেখেন।

## **FastAPI** ও OpenAPI দিয়ে ওয়েবহুক ডকুমেন্ট করা { #documenting-webhooks-with-fastapi-and-openapi }

**FastAPI**-তে OpenAPI ব্যবহার করে আপনি এই ওয়েবহুকগুলোর নাম, আপনার অ্যাপ কোন ধরনের HTTP অপারেশন পাঠাতে পারে (যেমন `POST`, `PUT` ইত্যাদি) এবং আপনার অ্যাপ যে রিকোয়েস্ট **বডি** পাঠাবে তা সংজ্ঞায়িত করতে পারেন।

এতে আপনার **ওয়েবহুক** রিকোয়েস্ট গ্রহণ করতে আপনার ইউজারদের **তাদের API বাস্তবায়ন করা** অনেক সহজ হতে পারে, তারা এমনকি তাদের নিজস্ব API কোডের কিছু অংশ স্বয়ংক্রিয়ভাবে তৈরিও করতে পারেন।

/// note | নোট

ওয়েবহুক OpenAPI 3.1.0 ও তার ওপরে উপলব্ধ, FastAPI `0.99.0` ও তার ওপরে সাপোর্টেড।

///

## ওয়েবহুকসহ একটি অ্যাপ { #an-app-with-webhooks }

আপনি যখন একটি **FastAPI** অ্যাপ্লিকেশন তৈরি করেন, তখন একটি `webhooks` অ্যাট্রিবিউট থাকে যা দিয়ে আপনি *ওয়েবহুক* সংজ্ঞায়িত করতে পারেন, *পাথ অপারেশন* যেভাবে সংজ্ঞায়িত করতেন সেভাবেই, যেমন `@app.webhooks.post()` দিয়ে।

{* ../../docs_src/openapi_webhooks/tutorial001_py310.py hl[9:12,15:20] *}

আপনার সংজ্ঞায়িত ওয়েবহুকগুলো **OpenAPI** স্কিমায় এবং স্বয়ংক্রিয় **ডকুমেন্টেশন UI**-তে চলে যাবে।

/// note | নোট

`app.webhooks` অবজেক্টটি আসলে শুধু একটি `APIRouter`, একাধিক ফাইল দিয়ে আপনার অ্যাপ সাজানোর সময় যে টাইপ ব্যবহার করতেন সেটিই।

///

লক্ষ করুন, ওয়েবহুকের ক্ষেত্রে আপনি আসলে একটি *পাথ* (যেমন `/items/`) ঘোষণা করছেন না, সেখানে আপনি যে টেক্সট দেন তা শুধু ওয়েবহুকের একটি **শনাক্তকারী** (ইভেন্টের নাম), যেমন `@app.webhooks.post("new-subscription")`-এ ওয়েবহুকের নাম হলো `new-subscription`।

কারণ আশা করা হয় যে **আপনার ইউজাররা** অন্য কোনো উপায়ে (যেমন একটি ওয়েব ড্যাশবোর্ডে) আসল **URL পাথ** সংজ্ঞায়িত করবেন যেখানে তারা ওয়েবহুক রিকোয়েস্ট পেতে চান।

### ডকুমেন্টেশন দেখুন { #check-the-docs }
