## স্ট্যান্ডার্ড-ভিত্তিক সুবিধা, বিকল্প ডকুমেন্টেশন { #standards-based-benefits-alternative-documentation }

আর যেহেতু তৈরি হওয়া স্কিমাটি [OpenAPI](https://github.com/OAI/OpenAPI-Specification/blob/main/versions/3.1.0.md) স্ট্যান্ডার্ড থেকে আসে, তাই অনেক সামঞ্জস্যপূর্ণ টুল আছে।

এ কারণে **FastAPI** নিজেই একটি বিকল্প API ডকুমেন্টেশন (ReDoc ব্যবহার করে) দেয়, যা আপনি [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)-এ অ্যাক্সেস করতে পারেন:

<img src="/img/tutorial/path-params/image02.png">

একইভাবে আরও অনেক সামঞ্জস্যপূর্ণ টুল আছে। এর মধ্যে অনেক ভাষার জন্য কোড জেনারেশন টুলও রয়েছে।

## Pydantic { #pydantic }

সব ডেটা ভ্যালিডেশন ভেতরে ভেতরে [Pydantic](https://pydantic.dev/docs/) করে, তাই আপনি এর সব সুবিধা পান। আর আপনি জানেন যে আপনি নির্ভরযোগ্য হাতে আছেন।

`str`, `float`, `bool` এবং আরও অনেক জটিল ডেটা টাইপের সাথে আপনি একই টাইপ ঘোষণা ব্যবহার করতে পারেন।

টিউটোরিয়ালের পরের অধ্যায়গুলোতে এগুলোর কয়েকটি নিয়ে আলোচনা করা হয়েছে।

## ক্রম গুরুত্বপূর্ণ { #order-matters }

*পাথ অপারেশন* তৈরির সময় এমন পরিস্থিতি আসতে পারে যেখানে আপনার একটি নির্দিষ্ট (স্থির) পাথ থাকে।

যেমন `/users/me`, ধরা যাক এটি বর্তমান ইউজারের ডেটা পাওয়ার জন্য।

আর তারপর কোনো ইউজার ID দিয়ে নির্দিষ্ট একজন ইউজারের ডেটা পাওয়ার জন্য আপনার `/users/{user_id}` পাথও থাকতে পারে।

যেহেতু *পাথ অপারেশনগুলো* ক্রমানুসারে মূল্যায়ন করা হয়, তাই আপনাকে নিশ্চিত করতে হবে যে `/users/me`-এর পাথটি `/users/{user_id}`-এর পাথের আগে ঘোষণা করা হয়েছে:

একইভাবে, আপনি একটি পাথ অপারেশন পুনরায় সংজ্ঞায়িত করতে পারবেন না:

## পাথ ধারণকারী পাথ প্যারামিটার { #path-parameters-containing-paths }

ধরা যাক আপনার `/files/{file_path}` পাথসহ একটি *পাথ অপারেশন* আছে।

কিন্তু আপনার দরকার যে `file_path` নিজেই একটি *পাথ* ধারণ করুক, যেমন `home/johndoe/myfile.txt`।

তাহলে ওই ফাইলের URL হবে এরকম কিছু: `/files/home/johndoe/myfile.txt`।

### OpenAPI সাপোর্ট { #openapi-support }

একটি *পাথ প্যারামিটারের* ভেতরে একটি *পাথ* ধারণ করার কথা ঘোষণা করার কোনো উপায় OpenAPI সাপোর্ট করে না, কারণ তাতে এমন পরিস্থিতি তৈরি হতে পারে যা টেস্ট ও সংজ্ঞায়িত করা কঠিন।

তবুও Starlette-এর একটি অভ্যন্তরীণ টুল ব্যবহার করে **FastAPI**-তে আপনি এটি করতে পারেন।

আর ডকুমেন্টেশনও কাজ করবে, যদিও প্যারামিটারটিতে যে একটি পাথ থাকা উচিত তা জানিয়ে কোনো ডকুমেন্টেশন যোগ হবে না।

আপনার হয়তো দরকার হতে পারে যে প্যারামিটারটিতে শুরুতে একটি স্ল্যাশসহ (`/`) `/home/johndoe/myfile.txt` থাকুক।

সেক্ষেত্রে URL হবে: `/files//home/johndoe/myfile.txt`, যেখানে `files` ও `home`-এর মাঝে একটি ডাবল স্ল্যাশ (`//`) থাকবে।

## সংক্ষেপে { #recap }

**FastAPI**-তে সংক্ষিপ্ত, সহজবোধ্য ও স্ট্যান্ডার্ড Python টাইপ ঘোষণা ব্যবহার করে আপনি পান:

* এডিটর সাপোর্ট: এরর চেক, অটোকমপ্লিশন ইত্যাদি
* ডেটা "<dfn title="HTTP রিকোয়েস্ট থেকে আসা স্ট্রিংকে Python ডেটায় রূপান্তর করা">পার্সিং</dfn>"
* ডেটা ভ্যালিডেশন
* API অ্যানোটেশন ও স্বয়ংক্রিয় ডকুমেন্টেশন

আর এগুলো আপনাকে কেবল একবারই ঘোষণা করতে হয়।

বিকল্প ফ্রেমওয়ার্কগুলোর তুলনায় এটিই সম্ভবত **FastAPI**-এর প্রধান দৃশ্যমান সুবিধা (কাঁচা পারফরম্যান্স ছাড়াও)।
