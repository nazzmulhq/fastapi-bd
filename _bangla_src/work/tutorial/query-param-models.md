# কুয়েরি প্যারামিটার মডেল { #query-parameter-models }

আপনার যদি পরস্পর সম্পর্কিত একদল **কুয়েরি প্যারামিটার** থাকে, তাহলে সেগুলো ঘোষণা করতে আপনি একটি **Pydantic মডেল** তৈরি করতে পারেন।

এতে আপনি **মডেলটি** **একাধিক জায়গায়** **পুনরায় ব্যবহার** করতে পারবেন, আর সব প্যারামিটারের জন্য একবারে ভ্যালিডেশন ও মেটাডেটাও ঘোষণা করতে পারবেন। 😎

/// note | নোট

এটি FastAPI ভার্সন `0.115.0` থেকে সাপোর্টেড। 🤓

///

## Pydantic মডেলসহ কুয়েরি প্যারামিটার { #query-parameters-with-a-pydantic-model }

{* ../../docs_src/query_param_models/tutorial001_an_py310.py hl[9:13,17] *}

**FastAPI** রিকোয়েস্টের **কুয়েরি প্যারামিটার** থেকে **প্রতিটি ফিল্ডের** ডেটা **বের করে** আপনার সংজ্ঞায়িত Pydantic মডেলটি আপনাকে দেবে।

## অতিরিক্ত কুয়েরি প্যারামিটার নিষিদ্ধ করুন { #forbid-extra-query-parameters }

কিছু বিশেষ ক্ষেত্রে (সম্ভবত খুব একটা প্রচলিত নয়) আপনি যে কুয়েরি প্যারামিটারগুলো গ্রহণ করতে চান সেগুলো **সীমিত** করতে চাইতে পারেন।

যেকোনো `extra` ফিল্ড `forbid` করতে আপনি Pydantic-এর মডেল কনফিগারেশন ব্যবহার করতে পারেন:
