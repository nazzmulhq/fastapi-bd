# রেসপন্স স্ট্যাটাস কোড { #response-status-code }

যেভাবে আপনি একটি রেসপন্স মডেল নির্দিষ্ট করতে পারেন, সেভাবেই যেকোনো *পাথ অপারেশনে* `status_code` প্যারামিটার দিয়ে রেসপন্সের জন্য ব্যবহৃত HTTP স্ট্যাটাস কোডও ঘোষণা করতে পারেন:

* `@app.get()`
* `@app.post()`
* `@app.put()`
* `@app.delete()`
* ইত্যাদি।

{* ../../docs_src/response_status_code/tutorial001_py310.py hl[6] *}

/// note | নোট

লক্ষ করুন, `status_code` হলো "ডেকোরেটর" মেথডের (`get`, `post` ইত্যাদি) একটি প্যারামিটার। সব প্যারামিটার ও বডির মতো আপনার *পাথ অপারেশন ফাংশনের* নয়।

///

`status_code` প্যারামিটার HTTP স্ট্যাটাস কোডসহ একটি সংখ্যা গ্রহণ করে।

/// note | নোট

`status_code` বিকল্প হিসেবে একটি `IntEnum`-ও গ্রহণ করতে পারে, যেমন Python-এর [`http.HTTPStatus`](https://docs.python.org/3/library/http.html#http.HTTPStatus)।

///

এটি:

* রেসপন্সে ওই স্ট্যাটাস কোড রিটার্ন করবে।
* OpenAPI স্কিমায় (এবং ফলে ইউজার ইন্টারফেসগুলোতে) সেভাবেই ডকুমেন্ট করবে:

<img src="/img/tutorial/response-status-code/image01.png">

/// note | নোট

কিছু রেসপন্স কোড (পরের অংশ দেখুন) নির্দেশ করে যে রেসপন্সের কোনো বডি নেই।

FastAPI এটি জানে, এবং এমন OpenAPI ডকুমেন্টেশন তৈরি করবে যাতে লেখা থাকবে যে কোনো রেসপন্স বডি নেই।

## HTTP স্ট্যাটাস কোড সম্পর্কে { #about-http-status-codes }

/// note | নোট

HTTP স্ট্যাটাস কোড কী তা যদি আপনি আগে থেকেই জানেন, তাহলে পরের অংশে চলে যান।

///

HTTP-তে আপনি রেসপন্সের অংশ হিসেবে ৩ অঙ্কের একটি সংখ্যাসূচক স্ট্যাটাস কোড পাঠান।

এই স্ট্যাটাস কোডগুলো চেনার সুবিধার জন্য এগুলোর সাথে একটি নাম জুড়ে থাকে, তবে গুরুত্বপূর্ণ অংশ হলো সংখ্যাটি।

সংক্ষেপে:

* `100 - 199` "তথ্য"-এর জন্য। এগুলো আপনি কদাচিৎ সরাসরি ব্যবহার করেন। এই স্ট্যাটাস কোডসহ রেসপন্সে বডি থাকতে পারে না।
* **`200 - 299`** "সফল" রেসপন্সের জন্য। এগুলোই আপনি সবচেয়ে বেশি ব্যবহার করবেন।
    * `200` হলো ডিফল্ট স্ট্যাটাস কোড, যার মানে সবকিছু "OK" ছিল।
    * আরেকটি উদাহরণ হবে `201`, "Created"। ডেটাবেসে নতুন রেকর্ড তৈরির পরে এটি সাধারণত ব্যবহার হয়।
    * একটি বিশেষ ক্ষেত্র হলো `204`, "No Content"। ক্লায়েন্টকে রিটার্ন করার মতো কোনো কনটেন্ট না থাকলে এই রেসপন্স ব্যবহার হয়, তাই রেসপন্সে অবশ্যই কোনো বডি থাকবে না।
* **`300 - 399`** "রিডাইরেকশন"-এর জন্য। এই স্ট্যাটাস কোডসহ রেসপন্সে বডি থাকতেও পারে, নাও পারে, শুধু `304`, "Not Modified" ছাড়া, যাতে অবশ্যই বডি থাকবে না।
* **`400 - 499`** "ক্লায়েন্ট এরর" রেসপন্সের জন্য। এগুলো হলো দ্বিতীয় ধরন যা আপনি সম্ভবত সবচেয়ে বেশি ব্যবহার করবেন।
    * একটি উদাহরণ হলো `404`, একটি "Not Found" রেসপন্সের জন্য।
    * ক্লায়েন্টের সাধারণ এররের জন্য আপনি শুধু `400` ব্যবহার করতে পারেন।
* `500 - 599` সার্ভার এররের জন্য। এগুলো আপনি প্রায় কখনোই সরাসরি ব্যবহার করেন না। আপনার অ্যাপ্লিকেশন কোডের কোনো অংশে বা সার্ভারে কিছু ভুল হলে এটি স্বয়ংক্রিয়ভাবে এই স্ট্যাটাস কোডগুলোর একটি রিটার্ন করবে।

/// tip | পরামর্শ

প্রতিটি স্ট্যাটাস কোড এবং কোন কোড কীসের জন্য তা সম্পর্কে আরও জানতে [HTTP স্ট্যাটাস কোড নিয়ে <abbr title="Mozilla Developer Network - মোজিলা ডেভেলপার নেটওয়ার্ক">MDN</abbr> ডকুমেন্টেশন](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status) দেখুন।

///

## নামগুলো মনে রাখার শর্টকাট { #shortcut-to-remember-the-names }

আগের উদাহরণটি আবার দেখা যাক:

{* ../../docs_src/response_status_code/tutorial001_py310.py hl[6] *}

`201` হলো "Created"-এর স্ট্যাটাস কোড।

তবে এই কোডগুলোর প্রতিটির অর্থ আপনাকে মুখস্থ করতে হবে না।

আপনি `fastapi.status` থেকে সুবিধাজনক ভেরিয়েবলগুলো ব্যবহার করতে পারেন।

এগুলো শুধুই সুবিধার জন্য, এগুলোতে একই সংখ্যা থাকে, তবে এভাবে আপনি এডিটরের অটোকমপ্লিট ব্যবহার করে এগুলো খুঁজে নিতে পারেন:

<img src="/img/tutorial/response-status-code/image02.png">

/// note | কারিগরি বিবরণ

আপনি `from starlette import status`-ও ব্যবহার করতে পারতেন।

**FastAPI** শুধু আপনার, অর্থাৎ ডেভেলপারের সুবিধার জন্য একই `starlette.status`-কে `fastapi.status` হিসেবে দেয়। তবে এটি সরাসরি Starlette থেকে আসে।
