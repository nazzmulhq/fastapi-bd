`Header` হলো `Path`, `Query` ও `Cookie`-এর একটি "সহোদর" ক্লাস। এটিও একই সাধারণ `Param` ক্লাস থেকে ইনহেরিট করে।

## স্বয়ংক্রিয় রূপান্তর { #automatic-conversion }

`Path`, `Query` ও `Cookie` যা দেয় তার ওপর `Header`-এর একটু অতিরিক্ত কার্যকারিতা আছে।

বেশিরভাগ স্ট্যান্ডার্ড হেডার একটি "হাইফেন" অক্ষর দিয়ে আলাদা করা থাকে, যা "মাইনাস চিহ্ন" (`-`) নামেও পরিচিত।

কিন্তু `user-agent`-এর মতো একটি ভেরিয়েবল Python-এ অবৈধ।

তাই ডিফল্টভাবে, হেডারগুলো বের করতে ও ডকুমেন্ট করতে `Header` প্যারামিটারের নামের অক্ষরগুলো আন্ডারস্কোর (`_`) থেকে হাইফেনে (`-`) রূপান্তর করবে।

এছাড়া HTTP হেডার কেস-ইনসেনসিটিভ, তাই আপনি এগুলো স্ট্যান্ডার্ড Python স্টাইলে (যা "snake_case" নামেও পরিচিত) ঘোষণা করতে পারেন।

তাই প্রথম অক্ষরগুলো `User_Agent` বা এরকম কিছুর মতো বড় হাতের করার বদলে, আপনি Python কোডে সাধারণত যেভাবে লেখেন সেভাবেই `user_agent` ব্যবহার করতে পারেন।

কোনো কারণে আন্ডারস্কোর থেকে হাইফেনে স্বয়ংক্রিয় রূপান্তর বন্ধ করতে চাইলে `Header`-এর `convert_underscores` প্যারামিটার `False` সেট করুন:

## সংক্ষেপে { #recap }

`Query`, `Path` ও `Cookie`-এর মতো একই সাধারণ প্যাটার্ন ব্যবহার করে `Header` দিয়ে হেডার ঘোষণা করুন।

আর আপনার ভেরিয়েবলের আন্ডারস্কোর নিয়ে চিন্তা করবেন না, **FastAPI** সেগুলো রূপান্তরের দায়িত্ব নেবে।
