# টেস্টিং { #testing }

[Starlette](https://starlette.dev/testclient/)-এর কল্যাণে **FastAPI** অ্যাপ্লিকেশন টেস্ট করা সহজ ও আনন্দদায়ক।

এটি [HTTPX](https://www.python-httpx.org)-এর ওপর ভিত্তি করে তৈরি, যা আবার Requests-এর ওপর ভিত্তি করে ডিজাইন করা, তাই এটি খুবই পরিচিত ও সহজবোধ্য।

এটি দিয়ে আপনি সরাসরি **FastAPI**-এর সাথে [pytest](https://docs.pytest.org/) ব্যবহার করতে পারেন।

তারপর আপনি বর্ধিত টেস্টসহ `test_main.py` আপডেট করতে পারেন:

যখনই আপনার দরকার হয় ক্লায়েন্ট রিকোয়েস্টে কোনো তথ্য পাঠাক এবং আপনি জানেন না কীভাবে, তখন `httpx`-এ কীভাবে করতে হয়, অথবা এমনকি `requests` দিয়ে কীভাবে করতে হয় তা খুঁজে (Google করে) দেখতে পারেন, কারণ HTTPX-এর ডিজাইন Requests-এর ডিজাইনের ওপর ভিত্তি করে তৈরি।

তারপর আপনার টেস্টেও ঠিক তাই করুন।

যেমন:

* একটি *পাথ* বা *কুয়েরি* প্যারামিটার পাঠাতে এটি URL-এই যোগ করুন।
* একটি JSON বডি পাঠাতে `json` প্যারামিটারে একটি Python অবজেক্ট (যেমন একটি `dict`) দিন।
* JSON-এর বদলে যদি *ফর্ম ডেটা* পাঠাতে হয়, তাহলে এর বদলে `data` প্যারামিটার ব্যবহার করুন।
* *হেডার* পাঠাতে `headers` প্যারামিটারে একটি `dict` ব্যবহার করুন।
* *কুকির* জন্য `cookies` প্যারামিটারে একটি `dict`।

ব্যাকএন্ডে কীভাবে ডেটা পাঠাতে হয় (`httpx` বা `TestClient` ব্যবহার করে) সে সম্পর্কে আরও তথ্যের জন্য [HTTPX ডকুমেন্টেশন](https://www.python-httpx.org) দেখুন।

/// note | নোট

লক্ষ করুন, `TestClient` JSON-এ রূপান্তরযোগ্য ডেটা গ্রহণ করে, Pydantic মডেল নয়।

আপনার টেস্টে যদি একটি Pydantic মডেল থাকে এবং টেস্টিংয়ের সময় এর ডেটা অ্যাপ্লিকেশনে পাঠাতে চান, তাহলে [JSON সামঞ্জস্যপূর্ণ এনকোডার](encoder.md)-এ বর্ণিত `jsonable_encoder` ব্যবহার করতে পারেন।
