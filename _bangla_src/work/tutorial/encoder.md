# JSON সামঞ্জস্যপূর্ণ এনকোডার { #json-compatible-encoder }

কিছু ক্ষেত্রে আপনাকে একটি ডেটা টাইপকে (যেমন একটি Pydantic মডেল) JSON-এর সাথে সামঞ্জস্যপূর্ণ কিছুতে (যেমন একটি `dict`, `list` ইত্যাদি) রূপান্তর করতে হতে পারে।

যেমন, আপনাকে যদি এটি একটি ডেটাবেসে সংরক্ষণ করতে হয়।

এর জন্য **FastAPI** একটি `jsonable_encoder()` ফাংশন দেয়।

## `jsonable_encoder` ব্যবহার { #using-the-jsonable-encoder }

কল্পনা করা যাক আপনার একটি ডেটাবেস `fake_db` আছে যা কেবল JSON সামঞ্জস্যপূর্ণ ডেটা গ্রহণ করে।

যেমন, এটি `datetime` অবজেক্ট গ্রহণ করে না, কারণ সেগুলো JSON-এর সাথে সামঞ্জস্যপূর্ণ নয়।

তাই একটি `datetime` অবজেক্টকে [ISO ফরম্যাটে](https://en.wikipedia.org/wiki/ISO_8601) ডেটা ধারণকারী একটি `str`-এ রূপান্তর করতে হবে।

একইভাবে, এই ডেটাবেস কোনো Pydantic মডেল (অ্যাট্রিবিউটসহ একটি অবজেক্ট) গ্রহণ করবে না, কেবল একটি `dict` গ্রহণ করবে।

এর জন্য আপনি `jsonable_encoder` ব্যবহার করতে পারেন।

এটি একটি অবজেক্ট নেয়, যেমন একটি Pydantic মডেল, এবং একটি JSON সামঞ্জস্যপূর্ণ ভার্সন রিটার্ন করে:

{* ../../docs_src/encoder/tutorial001_py310.py hl[4,21] *}

এই উদাহরণে এটি Pydantic মডেলটিকে একটি `dict`-এ, আর `datetime`-কে একটি `str`-এ রূপান্তর করবে।

এটি কল করার ফলাফল এমন কিছু যা Python-এর স্ট্যান্ডার্ড [`json.dumps()`](https://docs.python.org/3/library/json.html#json.dumps) দিয়ে এনকোড করা যায়।

এটি JSON ফরম্যাটে (একটি স্ট্রিং হিসেবে) ডেটা ধারণকারী একটি বড় `str` রিটার্ন করে না। এটি একটি Python স্ট্যান্ডার্ড ডেটা স্ট্রাকচার (যেমন একটি `dict`) রিটার্ন করে, যার ভ্যালু ও সাব-ভ্যালুগুলো সবই JSON-এর সাথে সামঞ্জস্যপূর্ণ।

/// note | নোট

ডেটা রূপান্তর করতে **FastAPI** আসলে ভেতরে ভেতরে `jsonable_encoder` ব্যবহার করে। তবে আরও অনেক পরিস্থিতিতে এটি কাজে আসে।
