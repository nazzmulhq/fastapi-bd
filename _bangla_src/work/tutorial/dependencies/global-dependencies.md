# গ্লোবাল ডিপেন্ডেন্সি { #global-dependencies }

কিছু ধরনের অ্যাপ্লিকেশনের ক্ষেত্রে আপনি হয়তো পুরো অ্যাপ্লিকেশনে ডিপেন্ডেন্সি যোগ করতে চাইবেন।

যেভাবে আপনি [*পাথ অপারেশন ডেকোরেটরে* `dependencies` যোগ করতে পারেন](dependencies-in-path-operation-decorators.md), সেভাবেই এগুলো `FastAPI` অ্যাপ্লিকেশনে যোগ করতে পারেন।

সেক্ষেত্রে এগুলো অ্যাপ্লিকেশনের সব *পাথ অপারেশনে* প্রয়োগ হবে:

আর [*পাথ অপারেশন ডেকোরেটরে* `dependencies` যোগ করা](dependencies-in-path-operation-decorators.md) সম্পর্কিত অংশের সব ধারণা এখানেও প্রযোজ্য, তবে এক্ষেত্রে অ্যাপের সব *পাথ অপারেশনের* জন্য।

## কয়েকদল *পাথ অপারেশনের* জন্য ডিপেন্ডেন্সি { #dependencies-for-groups-of-path-operations }

পরে, বড় অ্যাপ্লিকেশন কীভাবে সাজাতে হয় ([বড় অ্যাপ্লিকেশন - একাধিক ফাইল](../../tutorial/bigger-applications.md)) সে বিষয়ে পড়ার সময়, সম্ভবত একাধিক ফাইলসহ, আপনি শিখবেন কীভাবে একদল *পাথ অপারেশনের* জন্য একটিমাত্র `dependencies` প্যারামিটার ঘোষণা করতে হয়।
