# পাথ অপারেশন ডেকোরেটরে ডিপেন্ডেন্সি { #dependencies-in-path-operation-decorators }

কিছু ক্ষেত্রে আপনার *পাথ অপারেশন ফাংশনের* ভেতরে একটি ডিপেন্ডেন্সির রিটার্ন ভ্যালু আসলে দরকার হয় না।

অথবা ডিপেন্ডেন্সিটি কোনো ভ্যালু রিটার্ন করে না।

কিন্তু তবুও এটি এক্সিকিউট/সমাধান হওয়া দরকার।

এসব ক্ষেত্রে `Depends` দিয়ে একটি *পাথ অপারেশন ফাংশনের* প্যারামিটার ঘোষণা করার বদলে আপনি *পাথ অপারেশন ডেকোরেটরে* `dependencies`-এর একটি `list` যোগ করতে পারেন।

## *পাথ অপারেশন ডেকোরেটরে* `dependencies` যোগ করুন { #add-dependencies-to-the-path-operation-decorator }

*পাথ অপারেশন ডেকোরেটর* একটি ঐচ্ছিক আর্গুমেন্ট `dependencies` গ্রহণ করে।

এটি `Depends()`-এর একটি `list` হওয়া উচিত:

{* ../../docs_src/dependencies/tutorial006_an_py310.py hl[19] *}

এই ডিপেন্ডেন্সিগুলো সাধারণ ডিপেন্ডেন্সির মতোই এক্সিকিউট/সমাধান হবে। কিন্তু এগুলোর ভ্যালু (যদি কিছু রিটার্ন করে) আপনার *পাথ অপারেশন ফাংশনে* পাঠানো হবে না।

/// tip | পরামর্শ

কিছু এডিটর অব্যবহৃত ফাংশন প্যারামিটার যাচাই করে এবং সেগুলোকে এরর হিসেবে দেখায়।

*পাথ অপারেশন ডেকোরেটরে* এই `dependencies` ব্যবহার করে আপনি এডিটর/টুলিংয়ের এরর এড়িয়েও নিশ্চিত করতে পারেন যে এগুলো এক্সিকিউট হচ্ছে।

এটি নতুন ডেভেলপারদের বিভ্রান্তি এড়াতেও সাহায্য করতে পারে, যারা আপনার কোডে একটি অব্যবহৃত প্যারামিটার দেখে ভাবতে পারেন এটি অপ্রয়োজনীয়।

///

/// note | নোট

এই উদাহরণে আমরা বানানো কাস্টম হেডার `X-Key` ও `X-Token` ব্যবহার করছি।

তবে বাস্তব ক্ষেত্রে, সিকিউরিটি বাস্তবায়নের সময়, অন্তর্ভুক্ত [সিকিউরিটি ইউটিলিটি (পরের অধ্যায়)](../security/index.md) ব্যবহার করে আপনি আরও বেশি সুবিধা পাবেন।

## একদল *পাথ অপারেশনের* জন্য ডিপেন্ডেন্সি { #dependencies-for-a-group-of-path-operations }

পরে, বড় অ্যাপ্লিকেশন কীভাবে সাজাতে হয় ([বড় অ্যাপ্লিকেশন - একাধিক ফাইল](../../tutorial/bigger-applications.md)) সে বিষয়ে পড়ার সময়, সম্ভবত একাধিক ফাইলসহ, আপনি শিখবেন কীভাবে একদল *পাথ অপারেশনের* জন্য একটিমাত্র `dependencies` প্যারামিটার ঘোষণা করতে হয়।

## গ্লোবাল ডিপেন্ডেন্সি { #global-dependencies }

এরপর আমরা দেখব কীভাবে পুরো `FastAPI` অ্যাপ্লিকেশনে ডিপেন্ডেন্সি যোগ করতে হয়, যাতে সেগুলো প্রতিটি *পাথ অপারেশনে* প্রযোজ্য হয়।
