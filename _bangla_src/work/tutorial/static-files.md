# স্ট্যাটিক ফাইল { #static-files }

`StaticFiles` ব্যবহার করে আপনি একটি ডিরেক্টরি থেকে স্বয়ংক্রিয়ভাবে স্ট্যাটিক ফাইল সার্ভ করতে পারেন।

/// tip | পরামর্শ

আপনার যদি একটি ফ্রন্টএন্ড হোস্ট করতে হয়, তাহলে এর বদলে `app.frontend()` ব্যবহার করুন, এ সম্পর্কে পড়ুন [ফ্রন্টএন্ড](frontend.md)-এ।

`app.frontend()` ভেতরে ভেতরে `StaticFiles` ব্যবহার করে, সাথে ফ্রন্টএন্ডের জন্য বেশ কিছু অতিরিক্ত সুবিধা দেয়, যেমন ক্লায়েন্ট-সাইড রাউটিং সামলানো।

///

## `StaticFiles` ব্যবহার করুন { #use-staticfiles }

* `StaticFiles` ইম্পোর্ট করুন।
* একটি নির্দিষ্ট পাথে একটি `StaticFiles()` ইনস্ট্যান্স "মাউন্ট" করুন।

**FastAPI** শুধু আপনার, অর্থাৎ ডেভেলপারের সুবিধার জন্য একই `starlette.staticfiles`-কে `fastapi.staticfiles` হিসেবে দেয়। তবে এটি আসলে সরাসরি Starlette থেকে আসে।

### "মাউন্টিং" কী { #what-is-mounting }

"মাউন্টিং" মানে একটি নির্দিষ্ট পাথে একটি সম্পূর্ণ "স্বাধীন" অ্যাপ্লিকেশন যোগ করা, যা তারপর সব সাব-পাথ সামলানোর দায়িত্ব নেয়।

এটি একটি `APIRouter` ব্যবহারের থেকে আলাদা, কারণ একটি মাউন্ট করা অ্যাপ্লিকেশন সম্পূর্ণ স্বাধীন। আপনার মূল অ্যাপ্লিকেশনের OpenAPI ও ডকুমেন্টেশনে মাউন্ট করা অ্যাপ্লিকেশনের কিছুই অন্তর্ভুক্ত হবে না, ইত্যাদি।

এ সম্পর্কে আরও পড়তে পারেন [অ্যাডভান্সড ইউজার গাইডে](../advanced/index.md)।

## বিবরণ { #details }

প্রথম `"/static"` সেই সাব-পাথকে বোঝায় যেখানে এই "সাব-অ্যাপ্লিকেশন" "মাউন্ট" হবে। তাই `"/static"` দিয়ে শুরু হওয়া যেকোনো পাথ এটি সামলাবে।

`directory="static"` সেই ডিরেক্টরির নামকে বোঝায় যাতে আপনার স্ট্যাটিক ফাইলগুলো আছে।

`name="static"` এটিকে একটি নাম দেয় যা **FastAPI** ভেতরে ভেতরে ব্যবহার করতে পারে।

এই সব প্যারামিটার "`static`" ছাড়া অন্য কিছুও হতে পারে, আপনার নিজের অ্যাপ্লিকেশনের প্রয়োজন ও নির্দিষ্ট বিবরণ অনুযায়ী এগুলো ঠিক করে নিন।
