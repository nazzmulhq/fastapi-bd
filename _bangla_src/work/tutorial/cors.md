# CORS (ক্রস-অরিজিন রিসোর্স শেয়ারিং) { #cors-cross-origin-resource-sharing }

[CORS বা "Cross-Origin Resource Sharing"](https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS) বলতে সেই পরিস্থিতিগুলোকে বোঝায় যখন একটি ব্রাউজারে চলমান ফ্রন্টএন্ডে এমন JavaScript কোড থাকে যা একটি ব্যাকএন্ডের সাথে যোগাযোগ করে, আর ব্যাকএন্ডটি ফ্রন্টএন্ড থেকে ভিন্ন একটি "অরিজিন"-এ থাকে।

## অরিজিন { #origin }

একটি অরিজিন হলো প্রোটোকল (`http`, `https`), ডোমেইন (`myapp.com`, `localhost`, `localhost.tiangolo.com`) এবং পোর্টের (`80`, `443`, `8080`) সমন্বয়।

তাই এগুলো সবই ভিন্ন অরিজিন:

* `http://localhost`
* `https://localhost`
* `http://localhost:8080`

এগুলো সবই `localhost`-এ হলেও ভিন্ন প্রোটোকল বা পোর্ট ব্যবহার করে, তাই এগুলো ভিন্ন "অরিজিন"।

## ধাপগুলো { #steps }

ধরা যাক আপনার ব্রাউজারে `http://localhost:8080`-এ একটি ফ্রন্টএন্ড চলছে, আর এর JavaScript `http://localhost`-এ চলমান একটি ব্যাকএন্ডের সাথে যোগাযোগের চেষ্টা করছে (যেহেতু আমরা কোনো পোর্ট উল্লেখ করিনি, ব্রাউজার ডিফল্ট পোর্ট `80` ধরে নেবে)।

তখন ব্রাউজার `:80`-ব্যাকএন্ডে একটি HTTP `OPTIONS` রিকোয়েস্ট পাঠাবে, আর ব্যাকএন্ড যদি এই ভিন্ন অরিজিন (`http://localhost:8080`) থেকে যোগাযোগের অনুমতি দিয়ে উপযুক্ত হেডার পাঠায়, তাহলে `:8080`-ব্রাউজার ফ্রন্টএন্ডের JavaScript-কে `:80`-ব্যাকএন্ডে তার রিকোয়েস্ট পাঠাতে দেবে।

এটি অর্জন করতে `:80`-ব্যাকএন্ডের কাছে "অনুমোদিত অরিজিনের" একটি লিস্ট থাকতে হবে।

এক্ষেত্রে `:8080`-ফ্রন্টএন্ড সঠিকভাবে কাজ করার জন্য লিস্টে `http://localhost:8080` থাকতে হবে।

## ওয়াইল্ডকার্ড { #wildcards }

সবাই অনুমোদিত বোঝাতে লিস্টটিকে `"*"` (একটি "ওয়াইল্ডকার্ড") হিসেবেও ঘোষণা করা সম্ভব।

তবে তাতে কেবল নির্দিষ্ট কিছু ধরনের যোগাযোগ অনুমোদিত হবে, ক্রেডেনশিয়াল জড়িত সবকিছু বাদ দিয়ে: কুকি, Bearer টোকেনের সাথে ব্যবহৃত Authorization হেডারের মতো হেডার ইত্যাদি।

তাই সবকিছু সঠিকভাবে কাজ করার জন্য অনুমোদিত অরিজিনগুলো স্পষ্টভাবে উল্লেখ করাই ভালো।

## `CORSMiddleware` ব্যবহার করুন { #use-corsmiddleware }

আপনার **FastAPI** অ্যাপ্লিকেশনে `CORSMiddleware` ব্যবহার করে আপনি এটি কনফিগার করতে পারেন।

* `CORSMiddleware` ইম্পোর্ট করুন।
* অনুমোদিত অরিজিনের একটি লিস্ট তৈরি করুন (স্ট্রিং হিসেবে)।
* এটিকে আপনার **FastAPI** অ্যাপ্লিকেশনে একটি "মিডলওয়্যার" হিসেবে যোগ করুন।

আপনার ব্যাকএন্ড এগুলো অনুমোদন করে কিনা তাও উল্লেখ করতে পারেন:

* ক্রেডেনশিয়াল (Authorization হেডার, কুকি ইত্যাদি)।
* নির্দিষ্ট HTTP মেথড (`POST`, `PUT`) বা ওয়াইল্ডকার্ড `"*"` দিয়ে সবগুলো।
* নির্দিষ্ট HTTP হেডার বা ওয়াইল্ডকার্ড `"*"` দিয়ে সবগুলো।

`CORSMiddleware` বাস্তবায়নে ব্যবহৃত ডিফল্ট প্যারামিটারগুলো ডিফল্টভাবে কঠোর, তাই ক্রস-ডোমেইন প্রেক্ষাপটে ব্রাউজারগুলোকে নির্দিষ্ট অরিজিন, মেথড বা হেডার ব্যবহারের অনুমতি দিতে আপনাকে সেগুলো স্পষ্টভাবে চালু করতে হবে।

নিচের আর্গুমেন্টগুলো সাপোর্টেড:

* `allow_origins` - যেসব অরিজিনকে ক্রস-অরিজিন রিকোয়েস্ট করার অনুমতি দেওয়া উচিত তাদের একটি লিস্ট। যেমন `['https://example.org', 'https://www.example.org']`। যেকোনো অরিজিন অনুমোদন করতে আপনি `['*']` ব্যবহার করতে পারেন।
* `allow_origin_regex` - যেসব অরিজিনকে ক্রস-অরিজিন রিকোয়েস্ট করার অনুমতি দেওয়া উচিত তাদের সাথে মেলানোর জন্য একটি regex স্ট্রিং। যেমন `'https://.*\.example\.org'`।
* `allow_methods` - ক্রস-অরিজিন রিকোয়েস্টের জন্য অনুমোদিত হওয়া উচিত এমন HTTP মেথডের একটি লিস্ট। ডিফল্ট `['GET']`। সব স্ট্যান্ডার্ড মেথড অনুমোদন করতে আপনি `['*']` ব্যবহার করতে পারেন।
* `allow_headers` - ক্রস-অরিজিন রিকোয়েস্টের জন্য সাপোর্টেড হওয়া উচিত এমন HTTP রিকোয়েস্ট হেডারের একটি লিস্ট। ডিফল্ট `[]`। সব হেডার অনুমোদন করতে আপনি `['*']` ব্যবহার করতে পারেন। [সাধারণ CORS রিকোয়েস্টের](https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS#simple_requests) জন্য `Accept`, `Accept-Language`, `Content-Language` ও `Content-Type` হেডার সবসময় অনুমোদিত।
* `allow_credentials` - ক্রস-অরিজিন রিকোয়েস্টের জন্য কুকি সাপোর্টেড হওয়া উচিত কিনা নির্দেশ করে। ডিফল্ট `False`।

    `allow_credentials` `True` সেট করা থাকলে `allow_origins`, `allow_methods` ও `allow_headers`-এর কোনোটিকেই `['*']` সেট করা যাবে না। সবগুলোকে অবশ্যই [স্পষ্টভাবে উল্লেখ করতে হবে](https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS#credentialed_requests_and_wildcards)।

* `expose_headers` - যেসব রেসপন্স হেডার ব্রাউজারের কাছে অ্যাক্সেসযোগ্য করা উচিত সেগুলো নির্দেশ করে। ডিফল্ট `[]`।
* `max_age` - ব্রাউজারগুলো CORS রেসপন্স সর্বোচ্চ কত সেকেন্ড ক্যাশ করবে তা সেট করে। ডিফল্ট `600`।

মিডলওয়্যারটি দুটি নির্দিষ্ট ধরনের HTTP রিকোয়েস্টে রেসপন্স করে...

### CORS প্রিফ্লাইট রিকোয়েস্ট { #cors-preflight-requests }

এগুলো হলো `Origin` ও `Access-Control-Request-Method` হেডারসহ যেকোনো `OPTIONS` রিকোয়েস্ট।

এক্ষেত্রে মিডলওয়্যারটি আগত রিকোয়েস্টটি আটকে উপযুক্ত CORS হেডারসহ রেসপন্স করবে, এবং তথ্যের উদ্দেশ্যে একটি `200` বা `400` রেসপন্স দেবে।

### সাধারণ রিকোয়েস্ট { #simple-requests }

`Origin` হেডারসহ যেকোনো রিকোয়েস্ট। এক্ষেত্রে মিডলওয়্যারটি রিকোয়েস্টটি স্বাভাবিকভাবে পাস করে দেবে, তবে রেসপন্সে উপযুক্ত CORS হেডার যুক্ত করবে।
