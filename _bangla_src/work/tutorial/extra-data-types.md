# অতিরিক্ত ডেটা টাইপ { #extra-data-types }

এ পর্যন্ত আপনি সাধারণ ডেটা টাইপ ব্যবহার করে এসেছেন, যেমন:

* `int`
* `float`
* `str`
* `bool`

তবে আপনি আরও জটিল ডেটা টাইপও ব্যবহার করতে পারেন।

আর এ পর্যন্ত যে ফিচারগুলো দেখেছেন, সেগুলো তখনও পাবেন:

* চমৎকার এডিটর সাপোর্ট।
* আগত রিকোয়েস্ট থেকে ডেটা রূপান্তর।
* রেসপন্স ডেটার জন্য ডেটা রূপান্তর।
* ডেটা ভ্যালিডেশন।
* স্বয়ংক্রিয় অ্যানোটেশন ও ডকুমেন্টেশন।

## অন্যান্য ডেটা টাইপ { #other-data-types }

আপনি ব্যবহার করতে পারেন এমন কিছু অতিরিক্ত ডেটা টাইপ এখানে দেওয়া হলো:

* `UUID`:
    * একটি স্ট্যান্ডার্ড "Universally Unique Identifier", যা অনেক ডেটাবেস ও সিস্টেমে ID হিসেবে প্রচলিত।
    * রিকোয়েস্ট ও রেসপন্সে এটি একটি `str` হিসেবে উপস্থাপিত হবে।
* `datetime.datetime`:
    * একটি Python `datetime.datetime`।
    * রিকোয়েস্ট ও রেসপন্সে এটি ISO 8601 ফরম্যাটে একটি `str` হিসেবে উপস্থাপিত হবে, যেমন: `2008-09-15T15:53:00+05:00`।
* `datetime.date`:
    * Python `datetime.date`।
    * রিকোয়েস্ট ও রেসপন্সে এটি ISO 8601 ফরম্যাটে একটি `str` হিসেবে উপস্থাপিত হবে, যেমন: `2008-09-15`।
* `datetime.time`:
    * একটি Python `datetime.time`।
    * রিকোয়েস্ট ও রেসপন্সে এটি ISO 8601 ফরম্যাটে একটি `str` হিসেবে উপস্থাপিত হবে, যেমন: `14:23:55.003`।
* `datetime.timedelta`:
    * একটি Python `datetime.timedelta`।
    * রিকোয়েস্ট ও রেসপন্সে এটি মোট সেকেন্ডের একটি `float` হিসেবে উপস্থাপিত হবে।
    * Pydantic এটিকে একটি "ISO 8601 time diff encoding" হিসেবেও উপস্থাপন করতে দেয়, [আরও তথ্যের জন্য ডকুমেন্টেশন দেখুন](https://pydantic.dev/docs/validation/latest/concepts/serialization/#custom-serializers)।
* `frozenset`:
    * রিকোয়েস্ট ও রেসপন্সে একটি `set`-এর মতোই গণ্য করা হয়:
        * রিকোয়েস্টে একটি লিস্ট পড়া হবে, পুনরাবৃত্তি বাদ দিয়ে সেটিকে একটি `set`-এ রূপান্তর করা হবে।
        * রেসপন্সে `set`-টিকে একটি `list`-এ রূপান্তর করা হবে।
        * তৈরি হওয়া স্কিমায় উল্লেখ থাকবে যে `set`-এর ভ্যালুগুলো অনন্য (JSON Schema-র `uniqueItems` ব্যবহার করে)।
* `bytes`:
    * স্ট্যান্ডার্ড Python `bytes`।
    * রিকোয়েস্ট ও রেসপন্সে `str` হিসেবে গণ্য করা হবে।
    * তৈরি হওয়া স্কিমায় উল্লেখ থাকবে যে এটি `binary` "ফরম্যাট"-সহ একটি `str`।
* `Decimal`:
    * স্ট্যান্ডার্ড Python `Decimal`।
    * রিকোয়েস্ট ও রেসপন্সে একটি `float`-এর মতোই সামলানো হয়।
* সব বৈধ Pydantic ডেটা টাইপ আপনি এখানে দেখতে পারেন: [Pydantic ডেটা টাইপ](https://pydantic.dev/docs/validation/latest/concepts/types/)।
