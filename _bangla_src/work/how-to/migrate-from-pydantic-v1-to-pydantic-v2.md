# Pydantic v1 থেকে Pydantic v2-তে মাইগ্রেট করুন { #migrate-from-pydantic-v1-to-pydantic-v2 }

আপনার যদি একটি পুরোনো FastAPI অ্যাপ থাকে, তাহলে আপনি হয়তো Pydantic ভার্সন 1 ব্যবহার করছেন।

FastAPI ভার্সন 0.100.0-এ Pydantic v1 বা v2 যেকোনোটির সাপোর্ট ছিল। আপনার যেটি ইনস্টল করা থাকত সেটিই ব্যবহার করত।

v2-তে মাইগ্রেশন সহজ করতে FastAPI ভার্সন 0.119.0 Pydantic v2-এর ভেতর থেকে Pydantic v1-এর (`pydantic.v1` হিসেবে) আংশিক সাপোর্ট চালু করেছিল।

FastAPI 0.126.0 Pydantic v1-এর সাপোর্ট বাদ দিয়েছিল, তবে কিছুদিনের জন্য `pydantic.v1` সাপোর্ট রেখেছিল।

FastAPI 0.128.0 `pydantic.v1`-এর সাপোর্টও বাদ দিয়েছে, তাই FastAPI-এর সর্বশেষ ভার্সনগুলোতে Pydantic v2 আবশ্যক।

/// warning | সতর্কতা

Pydantic টিম **Python 3.14** থেকে শুরু করে Python-এর সর্বশেষ ভার্সনগুলোর জন্য Pydantic v1-এর সাপোর্ট বন্ধ করেছে।

এর মধ্যে `pydantic.v1`-ও আছে, যা Python 3.14 ও তার ওপরে আর সাপোর্টেড নয়।

আপনি যদি Python-এর সর্বশেষ ফিচারগুলো ব্যবহার করতে চান, তাহলে আপনাকে নিশ্চিত করতে হবে যে আপনি Pydantic v2 ব্যবহার করছেন।

///

আপনার যদি Pydantic v1-সহ একটি পুরোনো FastAPI অ্যাপ থাকে, তাহলে এখানে আমি আপনাকে দেখাব কীভাবে এটিকে Pydantic v2-তে মাইগ্রেট করতে হয়, এবং ধাপে ধাপে মাইগ্রেশনে আপনাকে সাহায্য করার জন্য **FastAPI 0.119.0-এর ফিচারগুলো**।

## অফিসিয়াল গাইড { #official-guide }

Pydantic-এর v1 থেকে v2-তে একটি অফিসিয়াল [মাইগ্রেশন গাইড](https://pydantic.dev/docs/validation/latest/get-started/migration/) আছে।

এতে কী কী বদলেছে, ভ্যালিডেশন এখন কীভাবে আরও সঠিক ও কঠোর, সম্ভাব্য সতর্কতা ইত্যাদিও আছে।

কী বদলেছে তা আরও ভালোভাবে বুঝতে আপনি এটি পড়তে পারেন।

## টেস্ট { #tests }

নিশ্চিত করুন যে আপনার অ্যাপের জন্য [টেস্ট](../tutorial/testing.md) আছে এবং আপনি সেগুলো continuous integration (CI)-তে চালান।

এভাবে আপনি আপগ্রেড করে নিশ্চিত হতে পারবেন যে সবকিছু এখনো প্রত্যাশামতো কাজ করছে।

## `bump-pydantic` { #bump-pydantic }

অনেক ক্ষেত্রে, আপনি যখন কাস্টমাইজেশন ছাড়া সাধারণ Pydantic মডেল ব্যবহার করেন, তখন Pydantic v1 থেকে Pydantic v2-তে মাইগ্রেশনের বেশিরভাগ প্রক্রিয়া স্বয়ংক্রিয় করতে পারবেন।

একই Pydantic টিমের তৈরি [`bump-pydantic`](https://github.com/pydantic/bump-pydantic) ব্যবহার করতে পারেন।

এই টুলটি পরিবর্তন করা দরকার এমন বেশিরভাগ কোড স্বয়ংক্রিয়ভাবে পরিবর্তন করতে আপনাকে সাহায্য করবে।

এরপর আপনি টেস্টগুলো চালিয়ে দেখতে পারেন সবকিছু কাজ করছে কিনা। যদি করে, তাহলে আপনার কাজ শেষ। 😎

## v2-তে Pydantic v1 { #pydantic-v1-in-v2 }

Pydantic v2-তে একটি সাবমডিউল `pydantic.v1` হিসেবে Pydantic v1-এর সবকিছু অন্তর্ভুক্ত আছে। তবে Python 3.13-এর ওপরের ভার্সনগুলোতে এটি আর সাপোর্টেড নয়।

এর মানে আপনি Pydantic v2-এর সর্বশেষ ভার্সন ইনস্টল করে এই সাবমডিউল থেকে পুরোনো Pydantic v1-এর কম্পোনেন্টগুলো ইম্পোর্ট করে ব্যবহার করতে পারেন, যেন আপনার পুরোনো Pydantic v1 ইনস্টল করা আছে।

### v2-তে Pydantic v1-এর জন্য FastAPI সাপোর্ট { #fastapi-support-for-pydantic-v1-in-v2 }

/// warning | সতর্কতা

`pydantic.v1` মডেলের জন্য এই FastAPI সাপোর্ট **FastAPI 0.119.0**-এ যোগ করা হয়েছিল এবং **FastAPI 0.128.0**-এ সরিয়ে দেওয়া হয়েছে। এটি Pydantic v2-তে মাইগ্রেশনের জন্য একটি অস্থায়ী সহায়তা হিসেবে ছিল।

FastAPI-এর বর্তমান ভার্সনগুলোতে আপনার অ্যাপে একটি `pydantic.v1` মডেল ব্যবহার করলে একটি এরর রেইজ হবে।

এই অংশের বাকিটুকু কেবল ওই পুরোনো ভার্সনগুলোতে উপলব্ধ অস্থায়ী সাপোর্ট বর্ণনা করে।

///

FastAPI 0.119.0 থেকে v2-তে মাইগ্রেশন সহজ করতে Pydantic v2-এর ভেতর থেকে Pydantic v1-এর আংশিক সাপোর্টও আছে।

তাই আপনি Pydantic-কে সর্বশেষ ভার্সন 2-এ আপগ্রেড করে `pydantic.v1` সাবমডিউল ব্যবহার করতে ইম্পোর্টগুলো বদলাতে পারতেন, আর অনেক ক্ষেত্রে এটি এমনিতেই কাজ করত।

মনে রাখবেন, যেহেতু Pydantic টিম Python 3.14 থেকে শুরু করে Python-এর সাম্প্রতিক ভার্সনগুলোতে আর Pydantic v1 সাপোর্ট করে না, তাই Python 3.14 ও তার ওপরে `pydantic.v1` ব্যবহারও সাপোর্টেড নয়।

### ধাপে ধাপে মাইগ্রেট করুন { #migrate-in-steps }

/// warning | সতর্কতা

নিচে বর্ণিত একই অ্যাপে Pydantic v1 ও v2 দুই ধরনের মডেল ব্যবহার করে ধাপে ধাপে মাইগ্রেশন কেবল **FastAPI 0.119.0 থেকে 0.127.x**-এ কাজ করে। **FastAPI 0.128.0**-এ এটি সরিয়ে দেওয়া হয়েছে, সর্বশেষ ভার্সনগুলোতে **Pydantic v2** মডেল আবশ্যক।

///

/// tip | পরামর্শ

প্রথমে `bump-pydantic` দিয়ে চেষ্টা করুন, আপনার টেস্টগুলো পাস করলে এবং এটি কাজ করলে, এক কমান্ডেই আপনার কাজ শেষ। ✨

///

`bump-pydantic` যদি আপনার ব্যবহারের ক্ষেত্রে কাজ না করে, তাহলে ধাপে ধাপে Pydantic v2-তে মাইগ্রেশন করতে একই অ্যাপে Pydantic v1 ও v2 দুই ধরনের মডেলের সাপোর্ট ব্যবহার করতে পারেন।

আপনি প্রথমে Pydantic-কে সর্বশেষ ভার্সন 2 ব্যবহারের জন্য আপগ্রেড করে আপনার সব মডেলের জন্য `pydantic.v1` ব্যবহার করতে ইম্পোর্টগুলো বদলাতে পারেন।

তারপর আপনি দলে দলে, ধাপে ধাপে আপনার মডেলগুলো Pydantic v1 থেকে v2-তে মাইগ্রেট করা শুরু করতে পারেন। 🚶
