# ডেটাবেস টেস্ট করা { #testing-a-database }

/// note | এই পেজটি কী

এই পেজটি আপনাকে SQLModel-এর ডকুমেন্টেশনের দিকে নির্দেশ করে, যেখানে FastAPI-র সাথে ডেটাবেস ব্যবহার আর টেস্ট করার বিস্তারিত গাইড আছে।

///

ডেটাবেস, SQL আর SQLModel সম্পর্কে পড়াশোনা করতে পারেন [SQLModel ডকসে](https://sqlmodel.tiangolo.com/)। 🤓

সেখানে [FastAPI-র সাথে SQLModel ব্যবহারের একটি ছোট টিউটোরিয়াল](https://sqlmodel.tiangolo.com/tutorial/fastapi/) আছে। ✨

সেই টিউটোরিয়ালে [SQL ডেটাবেস টেস্ট করা](https://sqlmodel.tiangolo.com/tutorial/fastapi/tests/) নিয়ে একটি অংশ আছে। 😎

/// tip | সংক্ষেপে মূল ধারণা

ডেটাবেস টেস্টের সাধারণ পদ্ধতি হলো: টেস্টের জন্য আলাদা একটি ছোট ডেটাবেস (যেমন মেমোরিতে থাকা SQLite) ব্যবহার করা, আর [ডিপেন্ডেন্সি ওভাররাইড](../advanced/testing-dependencies.md) দিয়ে আসল ডেটাবেস সেশনের বদলে সেই টেস্ট ডেটাবেসের সেশন দেওয়া। এতে আসল ডেটা নষ্ট হয় না আর প্রতিটি টেস্ট পরিষ্কার অবস্থা থেকে শুরু হয়।

///
