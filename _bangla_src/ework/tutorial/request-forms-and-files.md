# রিকোয়েস্টে ফর্ম ও ফাইল একসাথে { #request-forms-and-files }

/// note | এই পেজে যা শিখবেন

* একই রিকোয়েস্টে ফাইল আর ফর্ম ফিল্ড একসাথে গ্রহণ করা।

///

`File` আর `Form` ব্যবহার করে একই সাথে ফাইল আর ফর্ম ফিল্ড সংজ্ঞায়িত করতে পারেন।

যেমন একটি চাকরির আবেদন ফর্ম: নাম, ফোন নম্বর (ফর্ম ফিল্ড) আর সাথে CV-এর PDF (ফাইল), সব একবারে জমা হয়।

/// note | নোট

আপলোড করা ফাইল এবং/অথবা ফর্ম ডেটা গ্রহণ করতে প্রথমে [`python-multipart`](https://github.com/Kludex/python-multipart) ইনস্টল করুন।

আপনার প্রজেক্টে এটি যোগ করুন:

```console
$ uv add python-multipart
```

## `File` আর `Form` প্যারামিটার সংজ্ঞায়িত করুন { #define-file-and-form-parameters }

`Body` বা `Query`-র মতো একইভাবে ফাইল আর ফর্ম প্যারামিটার তৈরি করুন:

{* ../../docs_src/request_forms_and_files/tutorial001_an_py310.py hl[10:12] *}

ফাইল আর ফর্ম ফিল্ডগুলো ফর্ম ডেটা হিসেবে আপলোড হবে, আর আপনি ফাইল ও ফর্ম ফিল্ডগুলো পাবেন।

আর কিছু ফাইল `bytes` হিসেবে আর কিছু `UploadFile` হিসেবে ঘোষণা করতে পারেন।

/// info | কোডটি সহজ ভাষায়

* `file: Annotated[bytes, File()]`: প্রথম ফাইল, বাইট হিসেবে।
* `fileb: Annotated[UploadFile, File()]`: দ্বিতীয় ফাইল, `UploadFile` হিসেবে।
* `token: Annotated[str, Form()]`: একটি সাধারণ টেক্সট ফর্ম ফিল্ড।
* রেসপন্সে প্রথম ফাইলের আকার, টোকেন আর দ্বিতীয় ফাইলের ধরন (`content_type`) ফেরত যায়।

///

/// warning | সতর্কতা

একটি *পাথ অপারেশনে* একাধিক `File` আর `Form` প্যারামিটার ঘোষণা করতে পারেন, কিন্তু একই সাথে JSON হিসেবে গ্রহণের জন্য `Body` ফিল্ড ঘোষণা করতে পারবেন না। কারণ রিকোয়েস্টের বডি তখন `application/json`-এর বদলে `multipart/form-data` দিয়ে এনকোড করা থাকবে।

এটি **FastAPI**-এর কোনো সীমাবদ্ধতা নয়, এটি HTTP প্রোটোকলেরই অংশ।

## সংক্ষেপে { #recap }

একই রিকোয়েস্টে ডেটা আর ফাইল গ্রহণ করতে হলে `File` আর `Form` একসাথে ব্যবহার করুন।

/// check | সংক্ষেপে মনে রাখুন

* ফাইলের জন্য `File()`/`UploadFile`, টেক্সট ঘরের জন্য `Form()`, দুটোই একই ফাংশনে রাখা যায়।
* তখন JSON বডি (`Body`) ব্যবহার করা যাবে না।
