# ব্যাকগ্রাউন্ড টাস্ক { #background-tasks }

/// note | এই পেজে যা শিখবেন

* রেসপন্স পাঠিয়ে দেওয়ার *পরে* পেছনে কোনো কাজ চালানো (যেমন ইমেইল পাঠানো)।
* `BackgroundTasks` আর `.add_task()` এর ব্যবহার।
* ডিপেন্ডেন্সি থেকেও ব্যাকগ্রাউন্ড টাস্ক যোগ করা।
* কখন এর বদলে Celery-এর মতো বড় টুল লাগে।

///

রেসপন্স ফেরত দেওয়ার *পরে* চালানোর জন্য ব্যাকগ্রাউন্ড টাস্ক সংজ্ঞায়িত করতে পারেন।

এটি এমন কাজের জন্য কাজে লাগে, যা একটি রিকোয়েস্টের পরে ঘটতে হবে, কিন্তু রেসপন্স পাওয়ার আগে ক্লায়েন্টকে আসলে ওই কাজ শেষ হওয়া পর্যন্ত অপেক্ষা করার দরকার নেই।

এর মধ্যে আছে, যেমন:

* কোনো কাজ করার পরে পাঠানো ইমেইল নোটিফিকেশন:
    * যেহেতু একটি ইমেইল সার্ভারে যুক্ত হয়ে ইমেইল পাঠানো সাধারণত "ধীর" (কয়েক সেকেন্ড), তাই আপনি সাথে সাথে রেসপন্স ফেরত দিয়ে ব্যাকগ্রাউন্ডে ইমেইল নোটিফিকেশন পাঠাতে পারেন।
* ডেটা প্রসেস করা:
    * যেমন, ধরা যাক আপনি একটি ফাইল পেলেন যা একটি ধীর প্রক্রিয়ার মধ্য দিয়ে যেতে হবে। আপনি "Accepted" (HTTP 202, মানে "গ্রহণ করা হয়েছে") রেসপন্স ফেরত দিয়ে ব্যাকগ্রাউন্ডে ফাইলটি প্রসেস করতে পারেন।

/// tip | উদাহরণ দিয়ে বুঝি

অনলাইনে অর্ডার দেওয়ার পরে সাথে সাথে স্ক্রিনে দেখায় "অর্ডার সফল হয়েছে"। আপনাকে ইমেইলে রসিদ আসা পর্যন্ত স্ক্রিনের সামনে বসে থাকতে হয় না। রসিদের ইমেইলটি পেছনে (ব্যাকগ্রাউন্ডে) পাঠানো হয়।

///

## `BackgroundTasks` ব্যবহার { #using-backgroundtasks }

প্রথমে `BackgroundTasks` ইমপোর্ট করুন আর আপনার *পাথ অপারেশন ফাংশনে* `BackgroundTasks` টাইপ ঘোষণাসহ একটি প্যারামিটার সংজ্ঞায়িত করুন:

{* ../../docs_src/background_tasks/tutorial001_py310.py hl[1,13] *}

**FastAPI** আপনার জন্য `BackgroundTasks` টাইপের অবজেক্টটি তৈরি করে ওই প্যারামিটার হিসেবে দেবে।

## একটি টাস্ক ফাংশন তৈরি করুন { #create-a-task-function }

ব্যাকগ্রাউন্ড টাস্ক হিসেবে চালানোর জন্য একটি ফাংশন তৈরি করুন।

এটি শুধু একটি সাধারণ ফাংশন, যা প্যারামিটার নিতে পারে।

এটি একটি `async def` বা সাধারণ `def` ফাংশন হতে পারে, **FastAPI** জানবে কীভাবে এটি সঠিকভাবে সামলাতে হয়।

এই ক্ষেত্রে টাস্ক ফাংশনটি একটি ফাইলে লিখবে (ইমেইল পাঠানোর অভিনয় হিসেবে)।

আর যেহেতু লেখার কাজটি `async` আর `await` ব্যবহার করে না, তাই আমরা ফাংশনটি সাধারণ `def` দিয়ে সংজ্ঞায়িত করি:

## ব্যাকগ্রাউন্ড টাস্ক যোগ করুন { #add-the-background-task }

আপনার *পাথ অপারেশন ফাংশনের* ভেতরে, `.add_task()` মেথড দিয়ে আপনার টাস্ক ফাংশনটি *ব্যাকগ্রাউন্ড টাস্ক* অবজেক্টে দিন:

{* ../../docs_src/background_tasks/tutorial001_py310.py hl[14] *}

`.add_task()` আর্গুমেন্ট হিসেবে নেয়:

* ব্যাকগ্রাউন্ডে চালানোর জন্য একটি টাস্ক ফাংশন (`write_notification`)।
* টাস্ক ফাংশনে ক্রমানুসারে পাঠানোর যেকোনো আর্গুমেন্ট (`email`)।
* টাস্ক ফাংশনে পাঠানোর যেকোনো কিওয়ার্ড আর্গুমেন্ট (`message="some notification"`)।

/// info | পুরো কোডটি সহজ ভাষায়

* লাইন ৬-৯: `write_notification` ফাংশন `log.txt` ফাইলে একটি বার্তা লেখে (আসল প্রজেক্টে এখানে ইমেইল পাঠানো হতো)।
* লাইন ১৩: `background_tasks: BackgroundTasks`: FastAPI এই অবজেক্টটি দেয়।
* লাইন ১৪: "রেসপন্স পাঠানোর পরে `write_notification(email, message="some notification")` চালাও" বলে তালিকায় রাখা হলো। এখনই চলছে না!
* লাইন ১৫: সাথে সাথে রেসপন্স ফেরত যায়। তারপর FastAPI পেছনে টাস্কটি চালায়।

খেয়াল করুন, `add_task`-এ ফাংশনের নাম দেওয়া হয়, ডাকা হয় না (`write_notification`, `write_notification()` নয়)।

## ডিপেন্ডেন্সি ইনজেকশন { #dependency-injection }

`BackgroundTasks` ডিপেন্ডেন্সি ইনজেকশন ব্যবস্থার সাথেও কাজ করে। আপনি একাধিক স্তরে `BackgroundTasks` টাইপের প্যারামিটার ঘোষণা করতে পারেন: একটি *পাথ অপারেশন ফাংশনে*, একটি ডিপেন্ডেন্সিতে (dependable), একটি সাব-ডিপেন্ডেন্সিতে ইত্যাদি।

**FastAPI** জানে প্রতিটি ক্ষেত্রে কী করতে হবে আর কীভাবে একই অবজেক্ট পুনরায় ব্যবহার করতে হবে, যাতে সব ব্যাকগ্রাউন্ড টাস্ক একসাথে মিলে যায় আর পরে ব্যাকগ্রাউন্ডে চলে:

{* ../../docs_src/background_tasks/tutorial002_an_py310.py hl[13,15,22,25] *}

এই উদাহরণে বার্তাগুলো রেসপন্স পাঠানোর *পরে* `log.txt` ফাইলে লেখা হবে।

রিকোয়েস্টে যদি একটি কুয়েরি থাকে, তাহলে সেটি একটি ব্যাকগ্রাউন্ড টাস্কে লগে লেখা হবে।

তারপর *পাথ অপারেশন ফাংশনে* তৈরি আরেকটি ব্যাকগ্রাউন্ড টাস্ক `email` পাথ প্যারামিটার ব্যবহার করে একটি বার্তা লিখবে।

/// info | কোডটি সহজ ভাষায়

* লাইন ১৩-১৭: ডিপেন্ডেন্সি `get_query`-ও `BackgroundTasks` চায়, আর `q` থাকলে একটি টাস্ক যোগ করে।
* লাইন ২২-২৫: পাথ অপারেশন নিজেও আরেকটি টাস্ক যোগ করে।
* দুই জায়গায় একই `BackgroundTasks` অবজেক্ট আসে, তাই রেসপন্সের পরে দুটো টাস্কই একে একে চলে।

## কারিগরি বিবরণ { #technical-details }

`BackgroundTasks` ক্লাসটি সরাসরি আসে [`starlette.background`](https://starlette.dev/background/) থেকে।

এটি সরাসরি FastAPI-তে ইমপোর্ট/অন্তর্ভুক্ত করা হয়েছে, যাতে আপনি এটি `fastapi` থেকে ইমপোর্ট করতে পারেন আর ভুল করে `starlette.background` থেকে বিকল্প `BackgroundTask` (শেষে `s` ছাড়া) ইমপোর্ট না করেন।

শুধু `BackgroundTasks` ব্যবহার করে (আর `BackgroundTask` নয়), এটিকে একটি *পাথ অপারেশন ফাংশনের* প্যারামিটার হিসেবে ব্যবহার করা যায়, আর বাকিটা **FastAPI** আপনার হয়ে সামলায়, ঠিক `Request` অবজেক্ট সরাসরি ব্যবহারের মতো।

FastAPI-তে শুধু `BackgroundTask`-ও ব্যবহার করা সম্ভব, তবে তখন আপনাকে নিজের কোডে অবজেক্টটি তৈরি করে সেটিসহ একটি Starlette `Response` ফেরত দিতে হবে।

[Starlette-এর ব্যাকগ্রাউন্ড টাস্কের অফিসিয়াল ডকুমেন্টেশনে](https://starlette.dev/background/) আরও বিবরণ দেখতে পারেন।

## সতর্কতা { #caveat }

আপনার যদি ভারী ব্যাকগ্রাউন্ড হিসাব করতে হয়, আর এটি একই প্রসেসে চালানো জরুরি না হয় (যেমন মেমরি, ভেরিয়েবল ইত্যাদি ভাগাভাগি করার দরকার নেই), তাহলে [Celery](https://docs.celeryq.dev)-এর মতো অন্য বড় টুল ব্যবহার করে লাভবান হতে পারেন।

এগুলোতে সাধারণত আরও জটিল কনফিগারেশন লাগে, RabbitMQ বা Redis-এর মতো একটি বার্তা/কাজের সারি (queue) ম্যানেজার লাগে, কিন্তু এগুলো একাধিক প্রসেসে, আর বিশেষ করে একাধিক সার্ভারে ব্যাকগ্রাউন্ড টাস্ক চালাতে দেয়।

কিন্তু আপনার যদি একই **FastAPI** অ্যাপের ভেরিয়েবল আর অবজেক্ট ব্যবহার করতে হয়, বা ছোট ব্যাকগ্রাউন্ড টাস্ক (যেমন একটি ইমেইল নোটিফিকেশন পাঠানো) করতে হয়, তাহলে সহজেই শুধু `BackgroundTasks` ব্যবহার করতে পারেন।

/// warning | মনে রাখুন

`BackgroundTasks` একই সার্ভার প্রসেসে চলে। সার্ভার রিস্টার্ট হলে বা ক্র্যাশ করলে অসম্পূর্ণ টাস্ক হারিয়ে যেতে পারে। টাস্কটি কোনোভাবেই হারানো চলবে না (যেমন পেমেন্ট প্রসেস), এমন হলে Celery-এর মতো সারি-ভিত্তিক টুল ব্যবহার করুন।

///

## সংক্ষেপে { #recap }

ব্যাকগ্রাউন্ড টাস্ক যোগ করতে *পাথ অপারেশন ফাংশন* আর ডিপেন্ডেন্সির প্যারামিটারে `BackgroundTasks` ইমপোর্ট করে ব্যবহার করুন।

/// check | সংক্ষেপে মনে রাখুন

* প্যারামিটারে `background_tasks: BackgroundTasks` দিন।
* `background_tasks.add_task(ফাংশন, আর্গুমেন্ট...)` দিয়ে কাজ যোগ করুন, রেসপন্স পাঠানোর পরে চলবে।
* ছোট কাজের জন্য আদর্শ, ভারী বা কোনোভাবেই হারানো চলবে না এমন কাজের জন্য Celery-এর মতো টুল।
