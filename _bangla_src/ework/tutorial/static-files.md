# স্ট্যাটিক ফাইল { #static-files }

/// note | এই পেজে যা শিখবেন

* `StaticFiles` দিয়ে একটি ফোল্ডারের ছবি, CSS, JavaScript ইত্যাদি সার্ভ করা।
* "mount" করা মানে কী।

///

`StaticFiles` ব্যবহার করে একটি ফোল্ডার থেকে স্বয়ংক্রিয়ভাবে স্ট্যাটিক ফাইল সার্ভ করতে পারেন। স্ট্যাটিক ফাইল মানে যেসব ফাইল যেমন আছে তেমনই পাঠানো হয়, কোনো হিসাব-নিকাশ ছাড়া: ছবি, CSS, JavaScript, PDF ইত্যাদি।

/// tip | পরামর্শ

আপনার যদি একটি ফ্রন্টএন্ড হোস্ট করতে হয়, তাহলে এর বদলে `app.frontend()` ব্যবহার করুন, এ নিয়ে পড়ুন [ফ্রন্টএন্ড](frontend.md)-এ।

`app.frontend()` ভেতরে `StaticFiles` ব্যবহার করে, ফ্রন্টএন্ডের জন্য আরও কয়েকটি সুবিধাসহ, যেমন ক্লায়েন্ট-সাইড রাউটিং সামলানো।

///

## `StaticFiles` ব্যবহার করুন { #use-staticfiles }

* `StaticFiles` ইমপোর্ট করুন।
* একটি নির্দিষ্ট পাথে একটি `StaticFiles()` ইনস্ট্যান্স "mount" করুন।

{* ../../docs_src/static_files/tutorial001_py310.py hl[2,6] *}

এখন প্রজেক্টে `static` নামে একটি ফোল্ডার বানিয়ে তাতে যেমন `logo.png` রাখলে সেটি পাওয়া যাবে `http://127.0.0.1:8000/static/logo.png` ঠিকানায়।

/// note | কারিগরি বিবরণ

`from starlette.staticfiles import StaticFiles`-ও ব্যবহার করতে পারতেন।

**FastAPI** ডেভেলপার হিসেবে আপনার সুবিধার জন্যই একই `starlette.staticfiles`-কে `fastapi.staticfiles` হিসেবে দেয়। কিন্তু এটি আসলে সরাসরি Starlette থেকে আসে।

///

### "Mount" করা কী { #what-is-mounting }

"Mount" করা মানে একটি নির্দিষ্ট পাথে একটি সম্পূর্ণ "স্বাধীন" অ্যাপ্লিকেশন যোগ করা, যা তারপর ওই পাথের নিচের সব সাব-পাথ সামলানোর দায়িত্ব নেয়।

এটি একটি `APIRouter` ব্যবহার করা থেকে আলাদা, কারণ mount করা অ্যাপ্লিকেশন সম্পূর্ণ স্বাধীন। আপনার মূল অ্যাপ্লিকেশনের OpenAPI আর ডকুমেন্টেশনে mount করা অ্যাপ্লিকেশনের কিছুই অন্তর্ভুক্ত হবে না, ইত্যাদি।

/// tip | উদাহরণ দিয়ে বুঝি

একটি শপিং মলের ভেতরে আলাদা একটি দোকান ভাড়া দেওয়ার মতো। দোকানের নিজস্ব নিয়ম, নিজস্ব কর্মী। মলের তালিকায় (OpenAPI) দোকানের ভেতরের জিনিসের হিসাব থাকে না। `/static` ঠিকানার নিচে যা কিছু আসে, সবই ওই দোকান (`StaticFiles`) সামলায়।

## বিস্তারিত { #details }

প্রথম `"/static"` বোঝায় সেই সাব-পাথ, যেখানে এই "সাব-অ্যাপ্লিকেশন" "mount" হবে। তাই `"/static"` দিয়ে শুরু হওয়া যেকোনো পাথ এটি সামলাবে।

`directory="static"` বোঝায় আপনার স্ট্যাটিক ফাইলগুলো যে ফোল্ডারে আছে তার নাম।

`name="static"` এটিকে একটি নাম দেয়, যা **FastAPI** ভেতরে ব্যবহার করতে পারে (যেমন টেমপ্লেটে `url_for('static', path='/styles.css')` দিয়ে ঠিকানা বানাতে)।

এই সব প্যারামিটার "`static`" থেকে আলাদা হতে পারে, আপনার নিজের অ্যাপ্লিকেশনের প্রয়োজন আর নির্দিষ্ট খুঁটিনাটি অনুযায়ী সাজিয়ে নিন।
