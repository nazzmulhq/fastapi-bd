# JSON-সামঞ্জস্যপূর্ণ এনকোডার { #json-compatible-encoder }

/// note | এই পেজে যা শিখবেন

* `jsonable_encoder()` দিয়ে Pydantic মডেল, `datetime` ইত্যাদিকে JSON-এ রাখার উপযোগী সাধারণ ডেটায় রূপান্তর করা।

///

কিছু ক্ষেত্রে আপনাকে একটি ডেটা টাইপকে (যেমন একটি Pydantic মডেল) JSON-এর সাথে সামঞ্জস্যপূর্ণ কিছুতে (যেমন একটি `dict`, `list` ইত্যাদি) রূপান্তর করতে হতে পারে।

যেমন, যদি এটি একটি ডেটাবেসে সংরক্ষণ করতে হয়।

এর জন্য **FastAPI** একটি `jsonable_encoder()` ফাংশন দেয়।

## `jsonable_encoder` ব্যবহার { #using-the-jsonable-encoder }

ধরা যাক আপনার একটি ডেটাবেস `fake_db` আছে, যা কেবল JSON-সামঞ্জস্যপূর্ণ ডেটা গ্রহণ করে।

যেমন, এটি `datetime` অবজেক্ট গ্রহণ করে না, কারণ সেগুলো JSON-এর সাথে সামঞ্জস্যপূর্ণ নয়। (JSON-এ শুধু টেক্সট, সংখ্যা, true/false, null, তালিকা আর অবজেক্ট থাকতে পারে, "তারিখ" নামে কোনো আলাদা টাইপ নেই।)

তাই একটি `datetime` অবজেক্টকে [ISO ফরম্যাটে](https://en.wikipedia.org/wiki/ISO_8601) ডেটাসহ একটি `str`-এ রূপান্তর করতে হবে।

একইভাবে, এই ডেটাবেস একটি Pydantic মডেল (অ্যাট্রিবিউটসহ একটি অবজেক্ট) গ্রহণ করবে না, শুধু একটি `dict` গ্রহণ করবে।

এর জন্য `jsonable_encoder` ব্যবহার করতে পারেন।

এটি একটি অবজেক্ট নেয়, যেমন একটি Pydantic মডেল, আর একটি JSON-সামঞ্জস্যপূর্ণ সংস্করণ রিটার্ন করে:

{* ../../docs_src/encoder/tutorial001_py310.py hl[4,21] *}

এই উদাহরণে এটি Pydantic মডেলটিকে একটি `dict`-এ আর `datetime`-কে একটি `str`-এ রূপান্তর করবে।

/// info | কোডটি সহজ ভাষায়

* লাইন ৭: `fake_db = {}` হলো একটি খালি ডিকশনারি, নকল ডেটাবেস।
* লাইন ১০-১৩: `Item` মডেলে আছে একটি `datetime` (`timestamp`)।
* লাইন ২১: `jsonable_encoder(item)` মডেলকে রূপান্তর করে এমন কিছু বানায়: `{"title": "...", "timestamp": "2024-01-15T10:00:00", "description": None}`। এখানে সময়টি এখন সাধারণ টেক্সট।
* লাইন ২২: সেটি ডেটাবেসে `id` কী-এর নিচে রাখা হলো।

///

এটি ডাকার ফলাফল এমন কিছু, যা Python-এর স্ট্যান্ডার্ড [`json.dumps()`](https://docs.python.org/3/library/json.html#json.dumps) দিয়ে এনকোড করা যায়।

এটি JSON ফরম্যাটে ডেটাসহ একটি বড় `str` (একটি স্ট্রিং হিসেবে) রিটার্ন করে না। এটি একটি Python স্ট্যান্ডার্ড ডেটা কাঠামো (যেমন একটি `dict`) রিটার্ন করে, যার সব মান আর উপ-মান JSON-এর সাথে সামঞ্জস্যপূর্ণ।

/// note | নোট

`jsonable_encoder` আসলে **FastAPI** ভেতরে ভেতরে ডেটা রূপান্তরের জন্য ব্যবহার করে। কিন্তু অন্য অনেক পরিস্থিতিতেও এটি কাজে লাগে।

///

/// check | সংক্ষেপে মনে রাখুন

* `jsonable_encoder(obj)` যেকোনো অবজেক্টকে JSON-উপযোগী `dict`/`list`/টেক্সট/সংখ্যায় রূপান্তর করে।
* `datetime` টেক্সট হয়ে যায়, Pydantic মডেল ডিকশনারি হয়ে যায়।
* ফলাফল JSON স্ট্রিং নয়, Python ডেটা, যা সরাসরি ডেটাবেসে রাখা বা `json.dumps()` করা যায়।
