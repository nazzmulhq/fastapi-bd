# JSON Lines স্ট্রিম করা { #stream-json-lines }

/// note | এই পেজে যা শিখবেন

* "স্ট্রিমিং" কী, আর কখন পুরো ফলাফল একবারে না পাঠিয়ে ধাপে ধাপে পাঠানো ভালো।
* JSON Lines ফরম্যাট কী।
* `yield` দিয়ে FastAPI-তে ডেটা স্ট্রিম করা।

///

আপনার কাছে যদি এমন ডেটার একটি ক্রম থাকে যা একটি "**স্ট্রিম**" (ধারা) আকারে পাঠাতে চান, তাহলে **JSON Lines** দিয়ে তা করতে পারেন।

FastAPI 0.134.0-এ যোগ হয়েছে।

## স্ট্রিম কী? { #what-is-a-stream }

ডেটা "**স্ট্রিম**" করার মানে, আপনার অ্যাপ পুরো ক্রমের সব জিনিস তৈরি হওয়ার জন্য অপেক্ষা না করেই ক্লায়েন্টকে ডেটা পাঠানো শুরু করবে।

তাই এটি প্রথম জিনিসটি পাঠাবে, ক্লায়েন্ট সেটি পেয়ে প্রসেস করা শুরু করবে, আর হয়তো আপনি তখনও পরের জিনিসটি তৈরি করছেন।

⟦CODE1⟧

এমনকি এটি একটি অসীম স্ট্রিমও হতে পারে, যেখানে আপনি ক্রমাগত ডেটা পাঠাতে থাকেন।

/// tip | উদাহরণ দিয়ে বুঝি

YouTube-এ ভিডিও দেখার কথা ভাবুন। পুরো ভিডিও ডাউনলোড হওয়া পর্যন্ত অপেক্ষা করতে হয় না, অল্প একটু এলেই দেখা শুরু হয়, বাকিটা পেছনে আসতে থাকে। ChatGPT-এর মতো AI যখন উত্তর শব্দে শব্দে লিখে দেখায়, সেটাও স্ট্রিমিং।

///

## JSON Lines { #json-lines }

এসব ক্ষেত্রে "**JSON Lines**" পাঠানো প্রচলিত, এটি এমন একটি ফরম্যাট যেখানে প্রতি লাইনে একটি করে JSON অবজেক্ট পাঠানো হয়।

একটি রেসপন্সের কনটেন্ট টাইপ হবে `application/jsonl` (`application/json`-এর বদলে), আর বডি হবে এরকম কিছু:

⟦CODE2⟧

এটি একটি JSON অ্যারের (Python লিস্টের সমতুল্য) খুবই কাছাকাছি, কিন্তু `[]`-এর ভেতরে মোড়া আর জিনিসগুলোর মাঝে `,` থাকার বদলে এতে **প্রতি লাইনে একটি JSON অবজেক্ট** থাকে, এরা একটি নতুন-লাইন অক্ষর দিয়ে আলাদা।

/// note | নোট

জরুরি বিষয় হলো, ক্লায়েন্ট যখন আগের লাইনগুলো ব্যবহার করছে, তখনই আপনার অ্যাপ একে একে প্রতিটি লাইন তৈরি করতে পারবে।

///

/// note | কারিগরি বিবরণ

যেহেতু প্রতিটি JSON অবজেক্ট একটি নতুন লাইন দিয়ে আলাদা, তাই এদের বিষয়বস্তুতে আক্ষরিক নতুন-লাইন অক্ষর থাকতে পারে না, তবে এস্কেপ করা নতুন লাইন (`\n`) থাকতে পারে, যা JSON স্ট্যান্ডার্ডেরই অংশ।

তবে সাধারণত এ নিয়ে আপনাকে চিন্তা করতে হবে না, এটি স্বয়ংক্রিয়ভাবে হয়, পড়তে থাকুন। 🤓

///

## ব্যবহারের ক্ষেত্র { #use-cases }

একটি **AI LLM** সার্ভিস, **লগ** বা **টেলিমেট্রি**, বা **JSON** আকারে সাজানো যায় এমন অন্যান্য ধরনের ডেটা স্ট্রিম করতে এটি ব্যবহার করতে পারেন।

/// tip | পরামর্শ

আপনি যদি বাইনারি ডেটা স্ট্রিম করতে চান, যেমন ভিডিও বা অডিও, তাহলে অ্যাডভান্সড গাইড দেখুন: [ডেটা স্ট্রিম করা](../advanced/stream-data.md)।

## FastAPI দিয়ে JSON Lines স্ট্রিম করুন { #stream-json-lines-with-fastapi }

FastAPI দিয়ে JSON Lines স্ট্রিম করতে আপনার *পাথ অপারেশন ফাংশনে* `return` ব্যবহারের বদলে, একে একে প্রতিটি জিনিস তৈরি করতে `yield` ব্যবহার করতে পারেন।

{* ../../docs_src/stream_json_lines/tutorial001_py310.py ln[1:24] hl[24] *}

আপনি যে প্রতিটি JSON জিনিস ফেরত পাঠাতে চান সেটি যদি `Item` টাইপের (একটি Pydantic মডেল) হয় আর এটি একটি async ফাংশন হয়, তাহলে রিটার্ন টাইপ `AsyncIterable[Item]` হিসেবে ঘোষণা করতে পারেন:

{* ../../docs_src/stream_json_lines/tutorial001_py310.py ln[1:24] hl[9:11,22] *}

/// info | কোডটি সহজ ভাষায়

* লাইন ১৪-১৮: তিনটি আইটেমের তালিকা।
* লাইন ২২: `-> AsyncIterable[Item]` মানে "এই ফাংশন একে একে `Item` দিতে থাকবে"।
* লাইন ২৩-২৪: লুপের প্রতিটি ঘুরতে `yield item` একটি আইটেম পাঠায়। FastAPI প্রতিটিকে JSON-এর একটি লাইন বানিয়ে সাথে সাথে ক্লায়েন্টের কাছে পাঠিয়ে দেয়।

বাস্তবে প্রতিটি আইটেম হয়তো ডেটাবেস বা AI মডেল থেকে একটু দেরিতে আসবে, কিন্তু ক্লায়েন্ট যতটুকু তৈরি ততটুকু সাথে সাথে পেয়ে যাবে।

///

রিটার্ন টাইপ ঘোষণা করলে FastAPI এটি ব্যবহার করে ডেটা **যাচাই** করবে, OpenAPI-তে **ডকুমেন্ট** করবে, **ফিল্টার** করবে, আর Pydantic দিয়ে **সিরিয়ালাইজ** করবে।

/// tip | পরামর্শ

যেহেতু Pydantic এটি **Rust**-এর দিকে সিরিয়ালাইজ করবে, তাই রিটার্ন টাইপ ঘোষণা না করার চেয়ে অনেক বেশি **পারফরম্যান্স** পাবেন।

## Server-Sent Events (SSE) { #server-sent-events-sse }

FastAPI-তে Server-Sent Events (SSE)-এরও পূর্ণাঙ্গ সাপোর্ট আছে, যা প্রায় একই রকম কিন্তু কয়েকটি বাড়তি খুঁটিনাটিসহ। পরের অধ্যায়ে এগুলো সম্পর্কে শিখতে পারবেন: [Server-Sent Events (SSE)](server-sent-events.md)। 🤓
