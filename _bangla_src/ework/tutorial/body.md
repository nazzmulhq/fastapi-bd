# রিকোয়েস্ট বডি { #request-body }

/// note | এই পেজে যা শিখবেন

* রিকোয়েস্ট বডি কী, আর কখন এটি পাঠানো হয়।
* Pydantic মডেল দিয়ে কীভাবে বডির আকার ঠিক করবেন।
* FastAPI বডি নিয়ে কী কী কাজ নিজে করে দেয়।
* বডি, পাথ ও কুয়েরি প্যারামিটার একসাথে ব্যবহার, আর FastAPI কীভাবে বোঝে কোনটা কোথা থেকে আসবে।

///

ক্লায়েন্ট (ধরা যাক একটি ব্রাউজার) থেকে আপনার API-তে ডেটা পাঠাতে হলে সেটি **রিকোয়েস্ট বডি** হিসেবে পাঠানো হয়।

**রিকোয়েস্ট** বডি হলো ক্লায়েন্ট আপনার API-তে যে ডেটা পাঠায়। **রেসপন্স** বডি হলো আপনার API ক্লায়েন্টকে যে ডেটা পাঠায়।

আপনার API-কে প্রায় সবসময়ই একটি **রেসপন্স** বডি পাঠাতে হয়। কিন্তু ক্লায়েন্টকে সবসময় **রিকোয়েস্ট বডি** পাঠাতে হয় না। কখনো কখনো ক্লায়েন্ট শুধু একটি পাথ চায়, হয়তো কিছু কুয়েরি প্যারামিটারসহ, কোনো বডি পাঠায় না।

/// tip | উদাহরণ দিয়ে বুঝি

চিঠি পাঠানোর কথা ভাবুন। খামের ওপরের ঠিকানা হলো পাথ, ঠিকানার পাশে ছোট নোট হলো কুয়েরি প্যারামিটার, আর খামের ভেতরের চিঠিটা হলো বডি। একটি অনলাইন ফর্মে নাম, ফোন নম্বর, ঠিকানা লিখে "জমা দিন" চাপলে সেই সব তথ্য বডিতে করে সার্ভারে যায়।

///

**রিকোয়েস্ট** বডি ঘোষণা করতে [Pydantic](https://pydantic.dev/docs/) মডেল ব্যবহার করা হয়, এর সব শক্তি ও সুবিধাসহ।

/// note | নোট

ডেটা পাঠাতে এগুলোর একটি ব্যবহার করা উচিত: `POST` (সবচেয়ে প্রচলিত), `PUT`, `DELETE` অথবা `PATCH`।

`GET` রিকোয়েস্টের সাথে বডি পাঠালে কী হবে তা স্পেসিফিকেশনে নির্ধারিত নয়। তবুও FastAPI এটি সাপোর্ট করে, কেবল খুবই জটিল/অস্বাভাবিক ক্ষেত্রের জন্য।

যেহেতু এটি নিরুৎসাহিত, তাই `GET` ব্যবহার করলে Swagger UI-এর ইন্টারঅ্যাকটিভ ডকুমেন্টেশন বডির বিবরণ দেখাবে না, আর মাঝখানের প্রক্সিগুলোও হয়তো এটি সাপোর্ট করবে না।

## ফলাফল { #results }

শুধু ওই Python টাইপ ঘোষণা দিয়েই **FastAPI**:

* রিকোয়েস্টের বডি JSON হিসেবে পড়বে।
* দরকার হলে সংশ্লিষ্ট টাইপে রূপান্তর করবে।
* ডেটা যাচাই করবে।
    * ডেটা ভুল হলে একটি সুন্দর ও পরিষ্কার এরর ফেরত দেবে, যেখানে ঠিক কোথায় আর কোন ডেটা ভুল ছিল তা বলা থাকবে।
* পাওয়া ডেটা আপনাকে `item` প্যারামিটারে দেবে।
    * যেহেতু ফাংশনে আপনি এটিকে `Item` টাইপের বলে ঘোষণা করেছেন, তাই এর সব অ্যাট্রিবিউট ও তাদের টাইপের জন্য এডিটরের পুরো সাহায্যও (কমপ্লিশন ইত্যাদি) পাবেন।
* আপনার মডেলের জন্য [JSON Schema](https://json-schema.org) সংজ্ঞা তৈরি করবে। আপনার প্রজেক্টে দরকার হলে এগুলো অন্য যেকোনো জায়গাতেও ব্যবহার করতে পারবেন।
* ওই স্কিমাগুলো তৈরি হওয়া OpenAPI স্কিমার অংশ হবে, এবং স্বয়ংক্রিয় ডকুমেন্টেশনের <abbr title="User Interfaces - ইউজার ইন্টারফেস">UI</abbr>-গুলো এগুলো ব্যবহার করবে।

/// info | কোডটি সহজ ভাষায়

* লাইন ১৭: `item.model_dump()` মডেলটিকে একটি সাধারণ Python ডিকশনারিতে রূপান্তর করে, যাতে নতুন কী যোগ করা যায়।

## রিকোয়েস্ট বডি + পাথ প্যারামিটার { #request-body-path-parameters }

একই সাথে পাথ প্যারামিটার আর রিকোয়েস্ট বডি ঘোষণা করতে পারেন।

**FastAPI** বুঝবে যে যেসব ফাংশন প্যারামিটার পাথ প্যারামিটারের সাথে মেলে সেগুলো **পাথ থেকে নিতে হবে**, আর যেসব ফাংশন প্যারামিটার Pydantic মডেল হিসেবে ঘোষণা করা সেগুলো **রিকোয়েস্ট বডি থেকে নিতে হবে**।

{* ../../docs_src/body/tutorial003_py310.py hl[15:16] *}

এখানে `{"item_id": item_id, **item.model_dump()}` লেখায় `**` চিহ্নটি ডিকশনারির সব "কী: মান" জোড়া এই নতুন ডিকশনারিতে ঢেলে দেয়। তাই রেসপন্সে `item_id` আর পণ্যের সব তথ্য একসাথে থাকে।

## রিকোয়েস্ট বডি + পাথ + কুয়েরি প্যারামিটার { #request-body-path-query-parameters }

**বডি**, **পাথ** আর **কুয়েরি** প্যারামিটার, সবগুলো একই সাথে ঘোষণা করতে পারেন।

**FastAPI** প্রতিটিকে চিনবে এবং সঠিক জায়গা থেকে ডেটা নেবে।

{* ../../docs_src/body/tutorial004_py310.py hl[16] *}

ফাংশনের প্যারামিটারগুলো এভাবে চেনা হবে:

* প্যারামিটারটি যদি **পাথেও** ঘোষণা করা থাকে, তাহলে এটি পাথ প্যারামিটার হিসেবে ব্যবহার হবে।
* প্যারামিটারটি যদি **একক টাইপের** হয় (যেমন `int`, `float`, `str`, `bool` ইত্যাদি), তাহলে এটি **কুয়েরি** প্যারামিটার হিসেবে ধরা হবে।
* প্যারামিটারটি যদি একটি **Pydantic মডেলের** টাইপ হিসেবে ঘোষণা করা হয়, তাহলে এটি রিকোয়েস্ট **বডি** হিসেবে ধরা হবে।

/// tip | এক নজরে: FastAPI কীভাবে বোঝে

| প্যারামিটার | কেন | কোথা থেকে আসে |
|---|---|---|
| `item_id: int` | পাথে `{item_id}` আছে | পাথ (`/items/5`) |
| `q: str \| None = None` | একক টাইপ, পাথে নেই | কুয়েরি (`?q=...`) |
| `item: Item` | Pydantic মডেল | বডি (JSON) |

///

/// note | নোট

`= None` ডিফল্ট মানের কারণে FastAPI জানবে যে `q`-এর মান আবশ্যক নয়।

মানটি আবশ্যক নয় তা বোঝার জন্য FastAPI `str | None` ব্যবহার করে না। এটি বোঝে কারণ এর ডিফল্ট মান `= None`।

তবে টাইপ অ্যানোটেশন যোগ করলে আপনার এডিটর আরও ভালো সাহায্য করতে আর ভুল ধরতে পারবে।

///

## Pydantic ছাড়া { #without-pydantic }

আপনি যদি Pydantic মডেল ব্যবহার করতে না চান, তাহলে **Body** প্যারামিটারও ব্যবহার করতে পারেন। দেখুন [বডি - একাধিক প্যারামিটার: বডিতে একক মান](body-multiple-params.md#singular-values-in-body)।

/// check | সংক্ষেপে মনে রাখুন

* রিকোয়েস্ট বডি হলো ক্লায়েন্টের পাঠানো মূল ডেটা, সাধারণত `POST`/`PUT`-এর সাথে JSON আকারে।
* বডির আকার ঠিক করতে `BaseModel` থেকে একটি ক্লাস বানান, ডিফল্ট ছাড়া অ্যাট্রিবিউট আবশ্যক।
* ফাংশনে `item: Item` লিখলেই FastAPI বডি পড়ে, যাচাই করে, রূপান্তর করে আর ডকুমেন্টেশন বানায়।
* মডেলের মান পেতে `item.name`, পুরো ডিকশনারি পেতে `item.model_dump()`।
* পাথে থাকলে পাথ প্যারামিটার, একক টাইপ হলে কুয়েরি, Pydantic মডেল হলে বডি।
