# এরর সামলানো { #handling-errors }

/// note | এই পেজে যা শিখবেন

* `HTTPException` দিয়ে ক্লায়েন্টকে এরর (যেমন 404) জানানো।
* এররের সাথে কাস্টম হেডার পাঠানো।
* নিজের এক্সেপশনের জন্য নিজস্ব হ্যান্ডলার বানানো।
* FastAPI-এর ডিফল্ট এরর রেসপন্সের ধরন বদলানো।

///

অনেক পরিস্থিতিতে আপনার API ব্যবহারকারী একটি ক্লায়েন্টকে একটি এরর জানাতে হয়।

এই ক্লায়েন্ট হতে পারে ফ্রন্টএন্ডসহ একটি ব্রাউজার, অন্য কারও লেখা কোড, একটি IoT যন্ত্র ইত্যাদি।

আপনার হয়তো ক্লায়েন্টকে জানাতে হবে যে:

* ক্লায়েন্টের ওই কাজের জন্য যথেষ্ট অনুমতি নেই।
* ক্লায়েন্টের ওই রিসোর্সে প্রবেশাধিকার নেই।
* ক্লায়েন্ট যে আইটেমটি দেখতে চাইছিল সেটি নেই।
* ইত্যাদি।

এসব ক্ষেত্রে সাধারণত **400**-এর ঘরের (400 থেকে 499) একটি **HTTP স্ট্যাটাস কোড** ফেরত দেওয়া হয়।

এটি 200-এর ঘরের HTTP স্ট্যাটাস কোডের (200 থেকে 299) মতো। ওই "200" স্ট্যাটাস কোডগুলোর মানে রিকোয়েস্টে কোনো না কোনোভাবে "সফলতা" এসেছে।

400-এর ঘরের স্ট্যাটাস কোডগুলোর মানে ক্লায়েন্টের দিক থেকে একটি ভুল হয়েছে।

সেই সব **"404 Not Found"** এরর (আর সেগুলো নিয়ে মজার কৌতুকগুলো) মনে আছে?

### আপনার কোডে একটি `HTTPException` রেইজ করুন { #raise-an-httpexception-in-your-code }

`HTTPException` হলো API-এর জন্য প্রাসঙ্গিক বাড়তি ডেটাসহ একটি সাধারণ Python এক্সেপশন।

যেহেতু এটি একটি Python এক্সেপশন, তাই এটিকে `return` করবেন না, `raise` করবেন (ছুড়ে দেবেন)।

এর আরও মানে, আপনি যদি এমন একটি সহায়ক ফাংশনের ভেতরে থাকেন যা আপনার *পাথ অপারেশন ফাংশনের* ভেতর থেকে ডাকা হচ্ছে, আর সেই সহায়ক ফাংশনের ভেতর থেকে `HTTPException` রেইজ করেন, তাহলে *পাথ অপারেশন ফাংশনের* বাকি কোড আর চলবে না। এটি সাথে সাথে ওই রিকোয়েস্ট শেষ করে `HTTPException` থেকে HTTP এররটি ক্লায়েন্টকে পাঠাবে।

/// tip | উদাহরণ দিয়ে বুঝি

`return` হলো স্বাভাবিকভাবে কাজ শেষ করে ফল দেওয়া। `raise` হলো জরুরি থামার বোতাম চাপা: যত ভেতরের ফাংশনেই থাকুন না কেন, সাথে সাথে সব কাজ বন্ধ হয়ে এরর বার্তা ক্লায়েন্টের কাছে চলে যায়। তাই "আইটেম পাওয়া যায়নি" বা "অনুমতি নেই" এর মতো ক্ষেত্রে বারবার `if` দিয়ে ফলাফল ফেরত পাঠানোর ঝামেলা নেই।

## কাস্টম এক্সেপশন হ্যান্ডলার যোগ করুন { #install-custom-exception-handlers }

[Starlette-এর একই এক্সেপশন টুল](https://starlette.dev/exceptions/) দিয়ে কাস্টম এক্সেপশন হ্যান্ডলার যোগ করতে পারেন।

ধরা যাক আপনার একটি কাস্টম এক্সেপশন `UnicornException` আছে, যা আপনি (বা আপনার ব্যবহৃত কোনো লাইব্রেরি) `raise` করতে পারে।

আর আপনি FastAPI দিয়ে এই এক্সেপশনটি সবখানে (গ্লোবালি) এক জায়গা থেকে সামলাতে চান।

`@app.exception_handler()` দিয়ে একটি কাস্টম এক্সেপশন হ্যান্ডলার যোগ করতে পারেন:

{* ../../docs_src/handling_errors/tutorial003_py310.py hl[5:7,13:18,24] *}

এখানে আপনি যদি `/unicorns/yolo` চান, তাহলে *পাথ অপারেশন* একটি `UnicornException` `raise` করবে।

কিন্তু সেটি সামলাবে `unicorn_exception_handler`।

তাই আপনি একটি পরিচ্ছন্ন এরর পাবেন, HTTP স্ট্যাটাস কোড `418` আর এই JSON বিষয়বস্তুসহ:

```JSON
{"message": "Oops! yolo did something. There goes a rainbow..."}
```

/// info | কোডটি সহজ ভাষায়

* লাইন ৫-৭: `UnicornException` নামে নিজের একটি এক্সেপশন ক্লাস, যা একটি `name` মনে রাখে।
* লাইন ১৩: `@app.exception_handler(UnicornException)` বলে, "যখনই কোথাও `UnicornException` ছোড়া হবে, নিচের ফাংশন দিয়ে সামলাও"।
* লাইন ১৪-১৮: হ্যান্ডলার ফাংশন রিকোয়েস্ট আর এক্সেপশনটি পায়, আর ৪১৮ স্ট্যাটাসসহ একটি JSON রেসপন্স বানিয়ে ফেরত দেয়।
* লাইন ২৪: নাম `"yolo"` হলে এক্সেপশন ছোড়া হয়।

এতে একই ধরনের এরর সব পাথ অপারেশনে এক জায়গা থেকে, একই ফরম্যাটে সামলানো যায়।

## ডিফল্ট এক্সেপশন হ্যান্ডলার ওভাররাইড করুন { #override-the-default-exception-handlers }

**FastAPI**-এর কিছু ডিফল্ট এক্সেপশন হ্যান্ডলার আছে।

আপনি যখন একটি `HTTPException` `raise` করেন, আর যখন রিকোয়েস্টে অবৈধ ডেটা থাকে, তখন ডিফল্ট JSON রেসপন্স ফেরত দেওয়ার দায়িত্ব এই হ্যান্ডলারগুলোর।

এই এক্সেপশন হ্যান্ডলারগুলো আপনি নিজেরগুলো দিয়ে ওভাররাইড (প্রতিস্থাপন) করতে পারেন।

### রিকোয়েস্ট যাচাইয়ের এক্সেপশন ওভাররাইড করুন { #override-request-validation-exceptions }

একটি রিকোয়েস্টে অবৈধ ডেটা থাকলে **FastAPI** ভেতরে ভেতরে একটি `RequestValidationError` রেইজ করে।

আর এর জন্য একটি ডিফল্ট এক্সেপশন হ্যান্ডলারও আছে।

এটি ওভাররাইড করতে `RequestValidationError` ইমপোর্ট করুন, আর এক্সেপশন হ্যান্ডলারটি ডেকোরেট করতে `@app.exception_handler(RequestValidationError)` ব্যবহার করুন।

#### FastAPI-এর `HTTPException` বনাম Starlette-এর `HTTPException` { #fastapis-httpexception-vs-starlettes-httpexception }

**FastAPI**-এর নিজস্ব `HTTPException` আছে।

আর **FastAPI**-এর `HTTPException` এরর ক্লাসটি Starlette-এর `HTTPException` এরর ক্লাস থেকে ইনহেরিট করে।

একমাত্র পার্থক্য হলো **FastAPI**-এর `HTTPException` `detail` ফিল্ডে JSON-যোগ্য যেকোনো ডেটা গ্রহণ করে, অথচ Starlette-এর `HTTPException` এতে শুধু স্ট্রিং গ্রহণ করে।

তাই আপনার কোডে স্বাভাবিকভাবে **FastAPI**-এর `HTTPException`-ই রেইজ করতে থাকতে পারেন।

কিন্তু যখন একটি এক্সেপশন হ্যান্ডলার রেজিস্টার করবেন, তখন সেটি Starlette-এর `HTTPException`-এর জন্য রেজিস্টার করা উচিত।

এতে Starlette-এর অভ্যন্তরীণ কোডের কোনো অংশ, বা কোনো Starlette এক্সটেনশন বা প্লাগ-ইন একটি Starlette `HTTPException` রেইজ করলেও আপনার হ্যান্ডলার সেটি ধরে সামলাতে পারবে। (যেমন অস্তিত্বহীন পাথে গেলে যে ৪০৪ এরর হয়, সেটি Starlette-ই ছোড়ে।)

এই উদাহরণে, একই কোডে দুটি `HTTPException`-ই রাখতে পারার জন্য Starlette-এর এক্সেপশনটির নাম বদলে `StarletteHTTPException` রাখা হয়েছে:

```Python
from starlette.exceptions import HTTPException as StarletteHTTPException
```

### **FastAPI**-এর এক্সেপশন হ্যান্ডলার পুনরায় ব্যবহার করুন { #reuse-fastapis-exception-handlers }

আপনি যদি **FastAPI**-এর একই ডিফল্ট এক্সেপশন হ্যান্ডলারগুলোর সাথে এক্সেপশনটি ব্যবহার করতে চান, তাহলে `fastapi.exception_handlers` থেকে ডিফল্ট এক্সেপশন হ্যান্ডলারগুলো ইমপোর্ট করে পুনরায় ব্যবহার করতে পারেন:

{* ../../docs_src/handling_errors/tutorial006_py310.py hl[2:5,15,21] *}

এই উদাহরণে আপনি শুধু খুব অভিব্যক্তিপূর্ণ একটি বার্তাসহ এররটি প্রিন্ট করছেন, তবে ধারণাটা বুঝে গেছেন। আপনি এক্সেপশনটি ব্যবহার করে তারপর শুধু ডিফল্ট এক্সেপশন হ্যান্ডলারগুলো পুনরায় ব্যবহার করতে পারেন।

অর্থাৎ নিজের কিছু কাজ (যেমন লগ লেখা বা নোটিফিকেশন পাঠানো) করে, তারপর রেসপন্স বানানোর কাজটা FastAPI-এর পুরোনো হ্যান্ডলারকেই দিয়ে দিচ্ছেন।

/// check | সংক্ষেপে মনে রাখুন

* ক্লায়েন্টকে এরর জানাতে `raise HTTPException(status_code=404, detail="...")`, `return` নয়।
* `detail`-এ টেক্সট, ডিকশনারি বা লিস্ট দেওয়া যায়, আর `headers` দিয়ে হেডারও।
* নিজের এক্সেপশন সামলাতে `@app.exception_handler(MyException)`।
* ডিফল্ট যাচাই-এরর বদলাতে `RequestValidationError`-এর জন্য হ্যান্ডলার লিখুন।
* `HTTPException`-এর হ্যান্ডলার রেজিস্টার করুন Starlette-এর `HTTPException` দিয়ে।
