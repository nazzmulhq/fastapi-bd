# ডিবাগিং { #debugging }

/// note | এই পেজে যা শিখবেন

* এডিটরের ডিবাগার (VS Code, PyCharm) দিয়ে FastAPI অ্যাপ ধাপে ধাপে চালানো।
* `if __name__ == "__main__":` কী আর কেন লাগে।

///

আপনার এডিটরে ডিবাগার যুক্ত করতে পারেন, যেমন Visual Studio Code বা PyCharm-এ।

**ডিবাগার** হলো এমন টুল, যা দিয়ে প্রোগ্রাম চলার মাঝখানে নির্দিষ্ট লাইনে থামিয়ে (breakpoint) দেখা যায় সেই মুহূর্তে কোন ভেরিয়েবলে কী মান আছে। বাগ খুঁজে বের করতে এটি `print` লেখার চেয়ে অনেক শক্তিশালী।

## `uvicorn` ডাকুন { #call-uvicorn }

আপনার FastAPI অ্যাপ্লিকেশনে সরাসরি `uvicorn` ইমপোর্ট করে চালান:

/// info | কোডটি সহজ ভাষায়

* লাইন ১: `uvicorn` (সার্ভার প্রোগ্রাম) ইমপোর্ট।
* লাইন ৯-১০: কিছু ভেরিয়েবল, যেখানে breakpoint দিয়ে মান দেখার চর্চা করতে পারেন।
* লাইন ১৪-১৫: ফাইলটি সরাসরি চালালে `uvicorn.run(...)` সার্ভার চালু করে। `host="0.0.0.0"` মানে নেটওয়ার্কের সব ঠিকানা থেকে রিকোয়েস্ট গ্রহণ, `port=8000` পোর্ট নম্বর।

### `__name__ == "__main__"` সম্পর্কে { #about-name-main }

`__name__ == "__main__"`-এর মূল উদ্দেশ্য হলো এমন কিছু কোড রাখা, যা আপনার ফাইলটি এভাবে ডাকা হলে চলবে:

<div class="termy">

```console
$ uv run python myapp.py
```

</div>

কিন্তু অন্য কোনো ফাইল এটিকে ইমপোর্ট করলে চলবে না, যেমন:

```Python
from myapp import app
```

#### আরও বিস্তারিত { #more-details }

ধরা যাক আপনার ফাইলের নাম `myapp.py`।

আপনি যদি এটি এভাবে চালান:

<div class="termy">

```console
$ uv run python myapp.py
```

</div>

তাহলে আপনার ফাইলে Python-এর স্বয়ংক্রিয়ভাবে তৈরি করা অভ্যন্তরীণ ভেরিয়েবল `__name__`-এর মান হবে স্ট্রিং `"__main__"`।

তাই এই অংশটি:

```Python
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

চলবে।

---

আপনি যদি ওই মডিউলটি (ফাইল) ইমপোর্ট করেন, তাহলে এটা ঘটবে না।

তাই, যদি আপনার আরেকটি ফাইল `importer.py` থাকে, যাতে আছে:

```Python
from myapp import app

# আরও কিছু কোড
```

সেক্ষেত্রে `myapp.py`-এর ভেতরে স্বয়ংক্রিয়ভাবে তৈরি ভেরিয়েবল `__name__`-এর মান `"__main__"` হবে না।

তাই এই লাইনটি:

```Python
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

চলবে না।

/// tip | উদাহরণ দিয়ে বুঝি

`__name__` হলো ফাইলের "পরিচয় কার্ড"। ফাইলটি নিজেই প্রধান হিসেবে চালানো হলে কার্ডে লেখা থাকে `"__main__"` ("আমিই প্রধান")। অন্য কেউ ইমপোর্ট করলে কার্ডে থাকে ফাইলের নাম (`"myapp"`)। তাই `if __name__ == "__main__":` মানে "শুধু যদি আমাকেই সরাসরি চালানো হয়, তবেই সার্ভার চালু করো"। এতে টেস্ট বা অন্য ফাইল ইমপোর্ট করলে ভুল করে সার্ভার চালু হয়ে যায় না।

///

/// note | নোট

আরও তথ্যের জন্য [অফিসিয়াল Python ডকুমেন্টেশন](https://docs.python.org/3/library/__main__.html) দেখুন।

## ডিবাগার দিয়ে আপনার কোড চালান { #run-your-code-with-your-debugger }

যেহেতু আপনি আপনার কোড থেকে সরাসরি Uvicorn সার্ভার চালাচ্ছেন, তাই ডিবাগার থেকে সরাসরি আপনার Python প্রোগ্রাম (আপনার FastAPI অ্যাপ্লিকেশন) ডাকতে পারেন।

---

যেমন, Visual Studio Code-এ আপনি:

* "Debug" প্যানেলে যান।
* "Add configuration..." চাপুন।
* "Python" বেছে নিন।
* "`Python: Current File (Integrated Terminal)`" অপশন দিয়ে ডিবাগার চালান।

তখন এটি আপনার **FastAPI** কোডসহ সার্ভার চালু করবে, আপনার breakpoint-গুলোতে থামবে, ইত্যাদি।

এটি দেখতে এমন হতে পারে:

---

আপনি যদি PyCharm ব্যবহার করেন, তাহলে:

* "Run" মেনু খুলুন।
* "Debug..." অপশন বেছে নিন।
* তখন একটি কনটেক্সট মেনু দেখাবে।
* ডিবাগ করার ফাইলটি বেছে নিন (এই ক্ষেত্রে `main.py`)।

তখন এটি আপনার **FastAPI** কোডসহ সার্ভার চালু করবে, আপনার breakpoint-গুলোতে থামবে, ইত্যাদি।

/// tip | breakpoint কীভাবে দেবেন

কোডের লাইন নম্বরের বাম পাশে ক্লিক করলে একটি লাল বিন্দু আসে, সেটাই breakpoint। ডিবাগার চালিয়ে ব্রাউজারে ওই পাথে রিকোয়েস্ট পাঠালে প্রোগ্রাম ওই লাইনে থামবে, আর এডিটরের পাশে সব ভেরিয়েবলের মান দেখাবে। তারপর "Step Over" দিয়ে এক লাইন করে এগোনো যায়।

/// check | সংক্ষেপে মনে রাখুন

* ফাইলের শেষে `if __name__ == "__main__": uvicorn.run(app, ...)` রাখুন।
* তারপর এডিটরের ডিবাগার দিয়ে ফাইলটি চালান, breakpoint-এ থেমে ভেরিয়েবল দেখুন।
* `__name__ == "__main__"` শুধু সরাসরি চালালে সত্য হয়, ইমপোর্ট করলে নয়।
