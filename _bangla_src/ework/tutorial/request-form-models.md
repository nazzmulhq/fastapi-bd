# ফর্ম মডেল { #form-models }

/// note | এই পেজে যা শিখবেন

* ফর্মের ফিল্ডগুলো একটি Pydantic মডেলে একসাথে গ্রহণ করা।
* অপরিচিত বাড়তি ফর্ম ফিল্ড নিষেধ করা।

///

FastAPI-তে **ফর্ম ফিল্ড** ঘোষণা করতে **Pydantic মডেল** ব্যবহার করতে পারেন।

/// note | নোট

ফর্ম ব্যবহার করতে প্রথমে [`python-multipart`](https://github.com/Kludex/python-multipart) ইনস্টল করুন।

আপনার প্রজেক্টে এটি যোগ করুন:

```console
$ uv add python-multipart
```

///

/// note | নোট

এটি FastAPI সংস্করণ `0.113.0` থেকে সাপোর্টেড। 🤓

///

## ফর্মের জন্য Pydantic মডেল { #pydantic-models-for-forms }

আপনি যে ফিল্ডগুলো **ফর্ম ফিল্ড** হিসেবে গ্রহণ করতে চান সেগুলো দিয়ে একটি **Pydantic মডেল** ঘোষণা করুন, তারপর প্যারামিটারটিকে `Form` হিসেবে ঘোষণা করুন:

{* ../../docs_src/request_form_models/tutorial001_an_py310.py hl[9:11,15] *}

**FastAPI** রিকোয়েস্টের **ফর্ম ডেটা** থেকে **প্রতিটি ফিল্ডের** ডেটা **বের করে** আপনার সংজ্ঞায়িত Pydantic মডেলটি দেবে।

/// info | কোডটি সহজ ভাষায়

* লাইন ৯-১১: `FormData` মডেলে দুটি ফিল্ড, `username` আর `password`।
* লাইন ১৫: `Annotated[FormData, Form()]`: `Form()` বলে দেয় যে মডেলের ফিল্ডগুলো JSON নয়, ফর্ম ডেটা থেকে আসবে। ফাংশনের ভেতরে `data.username`, `data.password` দিয়ে মান পাবেন।

## বাড়তি ফর্ম ফিল্ড নিষেধ করুন { #forbid-extra-form-fields }

কিছু বিশেষ ক্ষেত্রে (সম্ভবত খুব প্রচলিত নয়), আপনি হয়তো ফর্ম ফিল্ডগুলোকে শুধু Pydantic মডেলে ঘোষিতগুলোর মধ্যেই **সীমিত** রাখতে চাইবেন। আর যেকোনো **বাড়তি** ফিল্ড **নিষেধ** করতে চাইবেন।

/// note | নোট

এটি FastAPI সংস্করণ `0.114.0` থেকে সাপোর্টেড। 🤓

///

যেকোনো `extra` (বাড়তি) ফিল্ড `forbid` (নিষেধ) করতে Pydantic-এর মডেল কনফিগারেশন ব্যবহার করতে পারেন:

{* ../../docs_src/request_form_models/tutorial002_an_py310.py hl[12] *}

কোনো ক্লায়েন্ট যদি কিছু বাড়তি ডেটা পাঠানোর চেষ্টা করে, তাহলে সে একটি **এরর** রেসপন্স পাবে।

যেমন, ক্লায়েন্ট যদি এই ফর্ম ফিল্ডগুলো পাঠানোর চেষ্টা করে:

* `username`: `Rick`
* `password`: `Portal Gun`
* `extra`: `Mr. Poopybutthole`

তাহলে সে একটি এরর রেসপন্স পাবে, যেখানে বলা থাকবে যে `extra` ফিল্ডটি অনুমোদিত নয়:

## সারাংশ { #summary }

FastAPI-তে ফর্ম ফিল্ড ঘোষণা করতে Pydantic মডেল ব্যবহার করতে পারেন। 😎

/// check | সংক্ষেপে মনে রাখুন

* ফর্মের কয়েকটি ফিল্ড একসাথে: একটি মডেল বানিয়ে `Annotated[ModelName, Form()]`।
* অজানা ফিল্ড আটকাতে `model_config = {"extra": "forbid"}`।
