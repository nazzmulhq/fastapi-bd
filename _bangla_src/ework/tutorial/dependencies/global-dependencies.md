# গ্লোবাল ডিপেন্ডেন্সি { #global-dependencies }

/// note | এই পেজে যা শিখবেন

* পুরো অ্যাপের প্রতিটি পাথ অপারেশনে একসাথে ডিপেন্ডেন্সি যোগ করা।

///

কিছু ধরনের অ্যাপ্লিকেশনে আপনি হয়তো পুরো অ্যাপ্লিকেশনে ডিপেন্ডেন্সি যোগ করতে চাইবেন।

যেমন একটি অভ্যন্তরীণ অফিস API, যেখানে প্রতিটি রিকোয়েস্টে একটি গোপন কী থাকতেই হবে। প্রতিটি পাথ অপারেশনে আলাদা করে লেখার বদলে একবারেই সবখানে প্রয়োগ করা যায়।

যেভাবে [*পাথ অপারেশন ডেকোরেটরে* `dependencies` যোগ করতে](dependencies-in-path-operation-decorators.md) পারেন, সেভাবেই `FastAPI` অ্যাপ্লিকেশনেও যোগ করতে পারেন।

সেক্ষেত্রে সেগুলো অ্যাপ্লিকেশনের সব *পাথ অপারেশনে* প্রয়োগ হবে:

{* ../../docs_src/dependencies/tutorial012_an_py310.py hl[17] *}

/// info | কোডটি সহজ ভাষায়

লাইন ১৭: `app = FastAPI(dependencies=[Depends(verify_token), Depends(verify_key)])`। এখন `/items/` আর `/users/` দুটোতেই রিকোয়েস্ট পাঠাতে হলে সঠিক `X-Token` আর `X-Key` হেডার লাগবে, যদিও পাথ অপারেশনগুলোতে কিছুই লেখা হয়নি।

///

আর [*পাথ অপারেশন ডেকোরেটরে* `dependencies` যোগ করা](dependencies-in-path-operation-decorators.md) নিয়ে অংশের সব ধারণা এখানেও প্রযোজ্য, তবে এই ক্ষেত্রে অ্যাপের সব *পাথ অপারেশনে*।

## একদল *পাথ অপারেশনের* জন্য ডিপেন্ডেন্সি { #dependencies-for-groups-of-path-operations }

পরে, বড় অ্যাপ্লিকেশন কীভাবে সাজাবেন ([বড় অ্যাপ্লিকেশন - একাধিক ফাইল](../../tutorial/bigger-applications.md)) সে বিষয়ে পড়ার সময়, সম্ভবত একাধিক ফাইলসহ, শিখবেন কীভাবে একদল *পাথ অপারেশনের* জন্য একটিমাত্র `dependencies` প্যারামিটার ঘোষণা করবেন।

/// check | সংক্ষেপে মনে রাখুন

* সব পাথ অপারেশনে প্রয়োগ: `app = FastAPI(dependencies=[Depends(...)])`।
* তিন স্তর: একটি পাথ অপারেশনে, একদল (রাউটার) পাথ অপারেশনে, পুরো অ্যাপে।
