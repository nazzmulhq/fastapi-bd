# পাথ অপারেশন ডেকোরেটরে ডিপেন্ডেন্সি { #dependencies-in-path-operation-decorators }

/// note | এই পেজে যা শিখবেন

* যে ডিপেন্ডেন্সির ফলাফল দরকার নেই, শুধু চালানো দরকার (যেমন টোকেন যাচাই), সেটি ডেকোরেটরে যোগ করা।
* এমন ডিপেন্ডেন্সি থেকে এরর ছোড়া।

///

কিছু ক্ষেত্রে আপনার *পাথ অপারেশন ফাংশনের* ভেতরে একটি ডিপেন্ডেন্সির রিটার্ন মান আসলে দরকার হয় না।

অথবা ডিপেন্ডেন্সিটি কোনো মান রিটার্নই করে না।

কিন্তু তবুও আপনার দরকার যে এটি চলুক/সমাধান হোক।

যেমন একটি দারোয়ান, যে শুধু দেখে আপনার কাছে বৈধ টোকেন আছে কিনা। টোকেন ঠিক থাকলে ঢুকতে দেয়, না থাকলে আটকে দেয়। আপনার কাজের জন্য দারোয়ানের কাছ থেকে কিছু নেওয়ার নেই।

এসব ক্ষেত্রে, `Depends` দিয়ে একটি *পাথ অপারেশন ফাংশনের* প্যারামিটার ঘোষণা না করে, *পাথ অপারেশন ডেকোরেটরে* `dependencies`-এর একটি `list` যোগ করতে পারেন।

## *পাথ অপারেশন ডেকোরেটরে* `dependencies` যোগ করুন { #add-dependencies-to-the-path-operation-decorator }

*পাথ অপারেশন ডেকোরেটর* একটি ঐচ্ছিক আর্গুমেন্ট `dependencies` গ্রহণ করে।

এটি `Depends()`-এর একটি `list` হতে হবে:

{* ../../docs_src/dependencies/tutorial006_an_py310.py hl[19] *}

এই ডিপেন্ডেন্সিগুলো সাধারণ ডিপেন্ডেন্সির মতোই চলবে/সমাধান হবে। কিন্তু এদের মান (যদি কিছু রিটার্ন করে) আপনার *পাথ অপারেশন ফাংশনে* পাঠানো হবে না।

/// tip | পরামর্শ

কিছু এডিটর অব্যবহৃত ফাংশন প্যারামিটার খুঁজে বের করে আর সেগুলোকে এরর হিসেবে দেখায়।

*পাথ অপারেশন ডেকোরেটরে* এই `dependencies` ব্যবহার করে আপনি এডিটর/টুলের এরর এড়িয়েই সেগুলো চলা নিশ্চিত করতে পারেন।

এটি নতুন ডেভেলপারদের বিভ্রান্তি এড়াতেও সাহায্য করতে পারে, যারা আপনার কোডে একটি অব্যবহৃত প্যারামিটার দেখে ভাবতে পারে এটি অপ্রয়োজনীয়।

///

/// note | নোট

এই উদাহরণে আমরা বানানো কাস্টম হেডার `X-Key` আর `X-Token` ব্যবহার করছি।

কিন্তু বাস্তবে সিকিউরিটি ইমপ্লিমেন্ট করার সময় একীভূত [সিকিউরিটি টুলগুলো (পরের অধ্যায়)](../security/index.md) ব্যবহার করলে বেশি সুবিধা পাবেন।

## ডিপেন্ডেন্সির এরর ও রিটার্ন মান { #dependencies-errors-and-return-values }

### রিটার্ন মান { #return-values }

আর এগুলো মান রিটার্ন করতেও পারে, না-ও পারে, মানগুলো ব্যবহার হবে না।

তাই অন্য কোথাও ইতিমধ্যে ব্যবহার করছেন এমন একটি সাধারণ ডিপেন্ডেন্সি (যা একটি মান রিটার্ন করে) পুনরায় ব্যবহার করতে পারেন, আর মানটি ব্যবহার না হলেও ডিপেন্ডেন্সিটি চলবে:

{* ../../docs_src/dependencies/tutorial006_an_py310.py hl[11,16] *}

/// info | পুরো কোডটি সহজ ভাষায়

* `verify_token`: `X-Token` হেডার পড়ে, `"fake-super-secret-token"` না হলে ৪০০ এরর ছোড়ে।
* `verify_key`: `X-Key` হেডার পড়ে, ভুল হলে এরর ছোড়ে, ঠিক হলে সেটি ফেরত দেয় (কিন্তু কেউ ব্যবহার করবে না)।
* লাইন ১৯: `dependencies=[Depends(verify_token), Depends(verify_key)]`: `/items/`-এ রিকোয়েস্ট এলে আগে এই দুটি যাচাই চলে। দুটোই পাস করলে তবেই `read_items` চলে।

## একদল *পাথ অপারেশনের* জন্য ডিপেন্ডেন্সি { #dependencies-for-a-group-of-path-operations }

পরে, বড় অ্যাপ্লিকেশন কীভাবে সাজাবেন ([বড় অ্যাপ্লিকেশন - একাধিক ফাইল](../../tutorial/bigger-applications.md)) সে বিষয়ে পড়ার সময়, সম্ভবত একাধিক ফাইলসহ, শিখবেন কীভাবে একদল *পাথ অপারেশনের* জন্য একটিমাত্র `dependencies` প্যারামিটার ঘোষণা করবেন।

## গ্লোবাল ডিপেন্ডেন্সি { #global-dependencies }

এরপর আমরা দেখব কীভাবে পুরো `FastAPI` অ্যাপ্লিকেশনে ডিপেন্ডেন্সি যোগ করবেন, যাতে সেগুলো প্রতিটি *পাথ অপারেশনে* প্রযোজ্য হয়।

/// check | সংক্ষেপে মনে রাখুন

* ফলাফল দরকার নেই, শুধু চালানো দরকার: `@app.get("/items/", dependencies=[Depends(f)])`।
* এমন ডিপেন্ডেন্সি এরর ছুড়ে রিকোয়েস্ট আটকে দিতে পারে, এটাই এর প্রধান ব্যবহার (যেমন টোকেন যাচাই)।
