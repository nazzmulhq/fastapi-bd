# রেসপন্স স্ট্যাটাস কোড { #response-status-code }

/// note | এই পেজে যা শিখবেন

* HTTP স্ট্যাটাস কোড কী, আর কোন সংখ্যার কী মানে।
* `status_code` দিয়ে রেসপন্সের স্ট্যাটাস কোড ঠিক করা।
* সংখ্যা মুখস্থ না করে `status.HTTP_201_CREATED` এর মতো নাম ব্যবহার করা।

///

যেভাবে একটি রেসপন্স মডেল নির্দিষ্ট করতে পারেন, সেভাবেই যেকোনো *পাথ অপারেশনে* `status_code` প্যারামিটার দিয়ে রেসপন্সের HTTP স্ট্যাটাস কোডও ঘোষণা করতে পারেন:

* `@app.get()`
* `@app.post()`
* `@app.put()`
* `@app.delete()`
* ইত্যাদি।

{* ../../docs_src/response_status_code/tutorial001_py310.py hl[6] *}

এখানে নতুন আইটেম তৈরি হলে রেসপন্সের স্ট্যাটাস কোড হবে `201` ("Created", মানে "তৈরি হয়েছে"), ডিফল্ট `200`-এর বদলে।

/// note | নোট

খেয়াল করুন, `status_code` হলো "ডেকোরেটর" মেথডের (`get`, `post` ইত্যাদি) একটি প্যারামিটার। আপনার *পাথ অপারেশন ফাংশনের* নয়, যেমনটা সব প্যারামিটার আর বডির ক্ষেত্রে হয়।

///

`status_code` প্যারামিটার HTTP স্ট্যাটাস কোডের একটি সংখ্যা নেয়।

/// note | নোট

বিকল্প হিসেবে `status_code` একটি `IntEnum`-ও নিতে পারে, যেমন Python-এর [`http.HTTPStatus`](https://docs.python.org/3/library/http.html#http.HTTPStatus)।

///

এটি:

* রেসপন্সে ওই স্ট্যাটাস কোড ফেরত দেবে।
* OpenAPI স্কিমাতে (আর তাই ইউজার ইন্টারফেসেও) সেভাবেই ডকুমেন্ট করবে:

<img src="/img/tutorial/response-status-code/image01.png">

/// note | নোট

কিছু রেসপন্স কোড (পরের অংশ দেখুন) নির্দেশ করে যে রেসপন্সে কোনো বডি নেই।

FastAPI এটি জানে, আর এমন OpenAPI ডকুমেন্টেশন তৈরি করবে যেখানে বলা থাকবে যে কোনো রেসপন্স বডি নেই।

## HTTP স্ট্যাটাস কোড সম্পর্কে { #about-http-status-codes }

/// note | নোট

HTTP স্ট্যাটাস কোড কী তা যদি আগে থেকেই জানেন, তাহলে পরের অংশে চলে যান।

///

HTTP-তে রেসপন্সের অংশ হিসেবে ৩ অঙ্কের একটি সংখ্যাসূচক স্ট্যাটাস কোড পাঠানো হয়।

এই স্ট্যাটাস কোডগুলোর একটি সংশ্লিষ্ট নাম আছে চেনার সুবিধার জন্য, তবে আসল জরুরি অংশ হলো সংখ্যাটি।

সংক্ষেপে:

* `100 - 199` হলো "তথ্য"-এর জন্য। এগুলো আপনি কদাচিৎ সরাসরি ব্যবহার করবেন। এই স্ট্যাটাস কোডওয়ালা রেসপন্সে বডি থাকতে পারে না।
* **`200 - 299`** হলো "সফল" রেসপন্সের জন্য। এগুলোই আপনি সবচেয়ে বেশি ব্যবহার করবেন।
    * `200` হলো ডিফল্ট স্ট্যাটাস কোড, মানে সব "ঠিক আছে" (OK)।
    * আরেকটি উদাহরণ `201`, "Created" (তৈরি হয়েছে)। ডেটাবেসে নতুন রেকর্ড তৈরির পরে সাধারণত এটি ব্যবহার হয়।
    * একটি বিশেষ ক্ষেত্র হলো `204`, "No Content" (কোনো বিষয়বস্তু নেই)। ক্লায়েন্টকে ফেরত দেওয়ার মতো কোনো বিষয়বস্তু না থাকলে এই রেসপন্স ব্যবহার হয়, তাই রেসপন্সে বডি থাকা চলবে না। যেমন কিছু মুছে ফেলার পরে।
* **`300 - 399`** হলো "রিডাইরেকশন" (অন্য ঠিকানায় পাঠানো)-এর জন্য। এই স্ট্যাটাস কোডওয়ালা রেসপন্সে বডি থাকতেও পারে, না-ও থাকতে পারে, তবে `304` "Not Modified" (পরিবর্তন হয়নি)-এ বডি থাকা চলবে না।
* **`400 - 499`** হলো "ক্লায়েন্টের ভুল" রেসপন্সের জন্য। এগুলো সম্ভবত দ্বিতীয় সর্বাধিক ব্যবহৃত ধরন।
    * একটি উদাহরণ `404`, "Not Found" (পাওয়া যায়নি) রেসপন্সের জন্য।
    * ক্লায়েন্টের সাধারণ ভুলের জন্য শুধু `400` ব্যবহার করতে পারেন।
* `500 - 599` হলো সার্ভারের ভুলের জন্য। এগুলো প্রায় কখনোই সরাসরি ব্যবহার করবেন না। আপনার অ্যাপ্লিকেশন কোড বা সার্ভারের কোনো অংশে কিছু ভুল হলে স্বয়ংক্রিয়ভাবে এগুলোর একটি ফেরত যাবে।

/// tip | সবচেয়ে প্রচলিত কোডগুলো এক নজরে

| কোড | নাম | কখন |
|---|---|---|
| `200` | OK | সাধারণ সফল রেসপন্স |
| `201` | Created | নতুন কিছু তৈরি হয়েছে (`POST`) |
| `204` | No Content | সফল, কিন্তু ফেরত দেওয়ার কিছু নেই (যেমন `DELETE`) |
| `400` | Bad Request | ক্লায়েন্টের সাধারণ ভুল |
| `401` | Unauthorized | লগইন করা নেই / টোকেন নেই |
| `403` | Forbidden | লগইন আছে, কিন্তু অনুমতি নেই |
| `404` | Not Found | যা চাওয়া হয়েছে তা নেই |
| `422` | Unprocessable Content | ডেটা যাচাইয়ে ব্যর্থ (FastAPI স্বয়ংক্রিয়ভাবে দেয়) |
| `500` | Internal Server Error | সার্ভারের কোডে সমস্যা |

///

/// tip | পরামর্শ

প্রতিটি স্ট্যাটাস কোড আর কোনটা কীসের জন্য সে সম্পর্কে আরও জানতে [<abbr title="Mozilla Developer Network">MDN</abbr>-এর HTTP স্ট্যাটাস কোড ডকুমেন্টেশন](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status) দেখুন।

///

## নামগুলো মনে রাখার শর্টকাট { #shortcut-to-remember-the-names }

আগের উদাহরণটি আবার দেখা যাক:

{* ../../docs_src/response_status_code/tutorial001_py310.py hl[6] *}

`201` হলো "Created"-এর স্ট্যাটাস কোড।

কিন্তু এই কোডগুলোর প্রতিটির মানে মুখস্থ রাখার দরকার নেই।

`fastapi.status` থেকে সুবিধাজনক ভেরিয়েবলগুলো ব্যবহার করতে পারেন।

{* ../../docs_src/response_status_code/tutorial002_py310.py hl[1,6] *}

এগুলো শুধু সুবিধার জন্য, এগুলোতে একই সংখ্যা থাকে, কিন্তু এভাবে এডিটরের অটোকমপ্লিট দিয়ে খুঁজে পেতে পারেন:

<img src="/img/tutorial/response-status-code/image02.png">

`status.HTTP_201_CREATED` পড়েই বোঝা যায় কী বোঝানো হচ্ছে, শুধু `201` দেখে হয়তো সবাই বুঝত না। তাই কোড পড়তেও সহজ হয়।

/// note | কারিগরি বিবরণ

`from starlette import status`-ও ব্যবহার করতে পারতেন।

**FastAPI** ডেভেলপার হিসেবে আপনার সুবিধার জন্যই একই `starlette.status`-কে `fastapi.status` হিসেবে দেয়। কিন্তু এটি সরাসরি Starlette থেকে আসে।

## ডিফল্ট বদলানো { #changing-the-default }

পরে [অ্যাডভান্সড ইউজার গাইডে](../advanced/response-change-status-code.md) দেখবেন, এখানে যে ডিফল্ট ঘোষণা করছেন তার থেকে ভিন্ন একটি স্ট্যাটাস কোড কীভাবে ফেরত দেবেন।

/// check | সংক্ষেপে মনে রাখুন

* `@app.post("/items/", status_code=201)` দিয়ে সফল রেসপন্সের স্ট্যাটাস কোড বদলান।
* ২xx সফল, ৩xx রিডাইরেক্ট, ৪xx ক্লায়েন্টের ভুল, ৫xx সার্ভারের ভুল।
* সংখ্যার বদলে `status.HTTP_201_CREATED` এর মতো নাম ব্যবহার করলে কোড পড়া সহজ হয়।
