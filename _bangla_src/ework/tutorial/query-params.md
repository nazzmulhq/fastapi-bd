# কুয়েরি প্যারামিটার { #query-parameters }

/// note | এই পেজে যা শিখবেন

* URL-এর `?` চিহ্নের পরের অংশ (কুয়েরি প্যারামিটার) কীভাবে ফাংশনে নেবেন।
* ডিফল্ট মান, ঐচ্ছিক মান আর আবশ্যক মান কীভাবে ঘোষণা করবেন।
* `bool` টাইপের কুয়েরি প্যারামিটার কোন কোন লেখাকে `True` ধরে।
* পাথ প্যারামিটার আর কুয়েরি প্যারামিটার একসাথে ব্যবহার করা।

///

ফাংশনে এমন প্যারামিটার ঘোষণা করলে যা পাথ প্যারামিটারের অংশ নয়, সেগুলো স্বয়ংক্রিয়ভাবে "কুয়েরি" প্যারামিটার হিসেবে ধরা হয়।

{* ../../docs_src/query_params/tutorial001_py310.py hl[9] *}

কুয়েরি হলো URL-এ `?` চিহ্নের পরে থাকা "কী=মান" জোড়াগুলোর সেট, যেগুলো `&` চিহ্ন দিয়ে আলাদা করা।

যেমন এই URL-এ:

```
http://127.0.0.1:8000/items/?skip=0&limit=10
```

...কুয়েরি প্যারামিটারগুলো হলো:

* `skip`: যার মান `0`
* `limit`: যার মান `10`

/// info | কোডটি সহজ ভাষায়

* লাইন ৫: `fake_items_db` হলো তিনটি জিনিসের একটি তালিকা, আসল ডেটাবেসের বদলে নকল ডেটা।
* লাইন ৮: পাথ `/items/`-এ কোনো `{ }` নেই, তাই কোনো পাথ প্যারামিটার নেই।
* লাইন ৯: `skip: int = 0` আর `limit: int = 10` পাথে নেই, তাই FastAPI এগুলোকে কুয়েরি প্যারামিটার ধরে। `= 0` আর `= 10` হলো ডিফল্ট মান।
* লাইন ১০: `fake_items_db[skip : skip + limit]` তালিকা থেকে `skip` নম্বর জায়গা থেকে শুরু করে `limit` সংখ্যক জিনিস কেটে নেয়।

এটাই "পেজিনেশন" (পাতা ভাগ করা)-এর সাধারণ কৌশল: `skip` মানে কতগুলো বাদ দিয়ে শুরু করব, `limit` মানে সর্বোচ্চ কতগুলো দেখাব। যেমন অনলাইন দোকানে প্রতি পাতায় ১০টি পণ্য, দ্বিতীয় পাতার জন্য `?skip=10&limit=10`।

///

যেহেতু এগুলো URL-এর অংশ, তাই "স্বাভাবিকভাবেই" এগুলো টেক্সট (string)।

কিন্তু যখন Python টাইপ দিয়ে ঘোষণা করেন (ওপরের উদাহরণে `int` হিসেবে), তখন এগুলো সেই টাইপে রূপান্তরিত হয় এবং সেই অনুযায়ী যাচাই করা হয়।

পাথ প্যারামিটারের ক্ষেত্রে যা যা প্রযোজ্য, কুয়েরি প্যারামিটারের ক্ষেত্রেও ঠিক সেগুলোই প্রযোজ্য:

* এডিটরের সাহায্য (অবশ্যই)
* ডেটা <dfn title="HTTP রিকোয়েস্ট থেকে আসা স্ট্রিংকে Python ডেটায় রূপান্তর করা">"পার্সিং"</dfn>
* ডেটা যাচাই
* স্বয়ংক্রিয় ডকুমেন্টেশন

## ডিফল্ট মান { #defaults }

কুয়েরি প্যারামিটার পাথের কোনো স্থায়ী অংশ নয়, তাই এগুলো ঐচ্ছিক হতে পারে এবং এদের ডিফল্ট মান থাকতে পারে।

ওপরের উদাহরণে ডিফল্ট মান হলো `skip=0` আর `limit=10`।

তাই এই URL-এ যাওয়া:

```
http://127.0.0.1:8000/items/
```

আর এখানে যাওয়া একই কথা:

```
http://127.0.0.1:8000/items/?skip=0&limit=10
```

কিন্তু যদি যান, যেমন:

```
http://127.0.0.1:8000/items/?skip=20
```

তাহলে আপনার ফাংশনে প্যারামিটারের মান হবে:

* `skip=20`: কারণ আপনি URL-এ এটি দিয়েছেন
* `limit=10`: কারণ এটিই ছিল ডিফল্ট মান

## ঐচ্ছিক প্যারামিটার { #optional-parameters }

একইভাবে ডিফল্ট মান `None` দিয়ে ঐচ্ছিক কুয়েরি প্যারামিটার ঘোষণা করতে পারেন:

{* ../../docs_src/query_params/tutorial002_py310.py hl[7] *}

এই ক্ষেত্রে ফাংশনের প্যারামিটার `q` ঐচ্ছিক হবে, আর ডিফল্টভাবে এর মান হবে `None`।

/// info | কোডটি সহজ ভাষায়

* `item_id: str` পাথে আছে (`{item_id}`), তাই এটি পাথ প্যারামিটার।
* `q: str | None = None` পাথে নেই, তাই কুয়েরি প্যারামিটার। `str | None` মানে টেক্সট অথবা কিছুই না, আর `= None` মানে না দিলে `None`।
* লাইন ৮-৯: `q` দেওয়া থাকলে (`if q:`) রেসপন্সে `q`-ও থাকবে।
* লাইন ১০: না থাকলে শুধু `item_id` ফেরত যাবে।

তাই `/items/foo` আর `/items/foo?q=hello` দুটোই কাজ করবে।

///

/// tip | পরামর্শ

এটাও খেয়াল করুন যে **FastAPI** যথেষ্ট বুদ্ধিমান, এটি বোঝে যে `item_id` একটি পাথ প্যারামিটার আর `q` তা নয়, তাই সেটি একটি কুয়েরি প্যারামিটার।

///

## কুয়েরি প্যারামিটারের টাইপ রূপান্তর { #query-parameter-type-conversion }

`bool` টাইপও ঘোষণা করতে পারেন, সেগুলোও রূপান্তরিত হবে:

{* ../../docs_src/query_params/tutorial003_py310.py hl[7] *}

এই ক্ষেত্রে যদি যান:

```
http://127.0.0.1:8000/items/foo?short=1
```

অথবা

```
http://127.0.0.1:8000/items/foo?short=True
```

অথবা

```
http://127.0.0.1:8000/items/foo?short=true
```

অথবা

```
http://127.0.0.1:8000/items/foo?short=on
```

অথবা

```
http://127.0.0.1:8000/items/foo?short=yes
```

অথবা অক্ষরের অন্য যেকোনো রূপে (সব বড় হাতের, প্রথম অক্ষর বড় হাতের ইত্যাদি), আপনার ফাংশন `short` প্যারামিটারটি `bool` মান `True` হিসেবে পাবে। একইভাবে `0`, `false`, `off`, `no` হলে পাবে `False`। আর অর্থহীন কিছু (যেমন `short=abc`) দিলে যাচাই এরর আসবে।

/// info | কোডটি সহজ ভাষায়

* `short: bool = False`: কিছু না দিলে `short` হবে `False`।
* লাইন ১১-১৪: `if not short:` মানে `short` `False` হলে রেসপন্সে লম্বা একটি `description` যোগ করা হয়।
* তাই `?short=true` দিলে ছোট রেসপন্স, না দিলে বিবরণসহ বড় রেসপন্স।

///

## একাধিক পাথ ও কুয়েরি প্যারামিটার { #multiple-path-and-query-parameters }

একই সাথে একাধিক পাথ প্যারামিটার আর কুয়েরি প্যারামিটার ঘোষণা করতে পারেন, **FastAPI** জানে কোনটা কী।

আর এগুলো কোনো নির্দিষ্ট ক্রমে ঘোষণা করার দরকার নেই।

এগুলো নাম দেখে শনাক্ত করা হবে:

{* ../../docs_src/query_params/tutorial004_py310.py hl[6,8] *}

এখানে `user_id` ও `item_id` পাথে আছে, তাই পাথ প্যারামিটার। `q` ও `short` পাথে নেই, তাই কুয়েরি প্যারামিটার। যেমন: `/users/3/items/pen?q=blue&short=true`।

## আবশ্যক কুয়েরি প্যারামিটার { #required-query-parameters }

পাথের নয় এমন প্যারামিটারের (আপাতত আমরা শুধু কুয়েরি প্যারামিটার দেখেছি) ডিফল্ট মান ঘোষণা করলে সেটি আর আবশ্যক থাকে না।

যদি কোনো নির্দিষ্ট মান দিতে না চান, শুধু ঐচ্ছিক করতে চান, তাহলে ডিফল্ট হিসেবে `None` দিন।

কিন্তু যখন একটি কুয়েরি প্যারামিটারকে আবশ্যক করতে চান, তখন শুধু কোনো ডিফল্ট মান না দিলেই হয়:

{* ../../docs_src/query_params/tutorial005_py310.py hl[6:7] *}

ব্রাউজারে যদি এমন একটি URL খোলেন:

```
http://127.0.0.1:8000/items/foo-item
```

* `skip`, একটি `int`, যার ডিফল্ট মান `0`।
* `limit`, একটি ঐচ্ছিক `int`।

/// tip | এক নজরে নিয়ম

| আপনি যা লেখেন | মানে |

| `skip: int = 0` | ঐচ্ছিক, না দিলে `0` |
| `limit: int \| None = None` | ঐচ্ছিক, না দিলে `None` |
