# কুকি প্যারামিটার মডেল { #cookie-parameter-models }

/// note | এই পেজে যা শিখবেন

* সম্পর্কিত কয়েকটি কুকি একটি Pydantic মডেলে একসাথে পড়া।
* অপরিচিত বাড়তি কুকি এলে নিষেধ করা।

///

আপনার যদি পরস্পর সম্পর্কিত একগুচ্ছ **কুকি** থাকে, তাহলে সেগুলো ঘোষণা করতে একটি **Pydantic মডেল** তৈরি করতে পারেন। 🍪

এতে **মডেলটি** **একাধিক জায়গায়** **পুনরায় ব্যবহার** করতে পারবেন, আর সব প্যারামিটারের যাচাই ও মেটাডেটা একবারে ঘোষণা করতে পারবেন। 😎

/// note | নোট

এটি FastAPI সংস্করণ `0.115.0` থেকে সাপোর্টেড। 🤓

## Pydantic মডেলসহ কুকি { #cookies-with-a-pydantic-model }

আপনার প্রয়োজনীয় **কুকি** প্যারামিটারগুলো একটি **Pydantic মডেলে** ঘোষণা করুন, তারপর প্যারামিটারটিকে `Cookie` হিসেবে ঘোষণা করুন:

{* ../../docs_src/cookie_param_models/tutorial001_an_py310.py hl[9:12,16] *}

**FastAPI** রিকোয়েস্টের সাথে আসা **কুকিগুলো** থেকে **প্রতিটি ফিল্ডের** ডেটা **বের করে** আপনার সংজ্ঞায়িত Pydantic মডেলটি দেবে।

/// info | কোডটি সহজ ভাষায়

* লাইন ৯-১২: `Cookies` মডেলে তিনটি কুকি: `session_id` (আবশ্যক, লগইন সেশনের আইডি) আর দুটি ঐচ্ছিক ট্র্যাকার কুকি।
* লাইন ১৬: `Annotated[Cookies, Cookie()]`: `Cookie()` বলে দেয় যে মডেলের ফিল্ডগুলো কুকি থেকে আসবে।
* `session_id` কুকি না থাকলে FastAPI এরর দেবে, কারণ এটি আবশ্যক।

`/docs`-এর **API ডকুমেন্টেশন UI**-তে গেলে আপনার *পাথ অপারেশনগুলোর* কুকির **ডকুমেন্টেশন** দেখতে পাবেন।

কিন্তু **ডেটা পূরণ করে** "Execute" চাপলেও, যেহেতু ডকুমেন্টেশন UI **JavaScript** দিয়ে চলে, তাই কুকিগুলো পাঠানো হবে না, আর আপনি এমন একটি **এরর** বার্তা দেখবেন যেন কোনো মানই লেখেননি।

## বাড়তি কুকি নিষেধ করুন { #forbid-extra-cookies }

কিছু বিশেষ ক্ষেত্রে (সম্ভবত খুব প্রচলিত নয়), আপনি হয়তো যে কুকিগুলো গ্রহণ করবেন সেগুলো **সীমিত** করতে চাইবেন।

আপনার API-এর এখন নিজের <dfn title="এটা নিছক মজা করে বলা। কুকি-সম্মতির সাথে এর কোনো সম্পর্ক নেই, তবে মজার ব্যাপার যে এখন API-ও বেচারা কুকিদের প্রত্যাখ্যান করতে পারে। একটা কুকি খান। 🍪">কুকি-সম্মতি</dfn> নিয়ন্ত্রণের ক্ষমতা আছে। 🤪🍪

যেকোনো `extra` (বাড়তি) ফিল্ড `forbid` (নিষেধ) করতে Pydantic-এর মডেল কনফিগারেশন ব্যবহার করতে পারেন:

{* ../../docs_src/cookie_param_models/tutorial002_an_py310.py hl[10] *}

কোনো ক্লায়েন্ট যদি কিছু **বাড়তি কুকি** পাঠানোর চেষ্টা করে, তাহলে সে একটি **এরর** রেসপন্স পাবে।

বেচারা কুকি ব্যানারগুলো এত চেষ্টা করে আপনার সম্মতি আদায় করে, আর শেষে <dfn title="এটাও একটা মজা। আমাকে গুরুত্ব দেবেন না। কুকির সাথে একটু কফি খান। ☕">API সেটি প্রত্যাখ্যান করে</dfn>। 🍪

যেমন, ক্লায়েন্ট যদি `good-list-please` মানসহ একটি `santa_tracker` কুকি পাঠানোর চেষ্টা করে, তাহলে সে একটি **এরর** রেসপন্স পাবে, যেখানে বলা থাকবে যে `santa_tracker` <dfn title="কুকির অভাবে সান্তা অসন্তুষ্ট। 🎅 ঠিক আছে, আর কুকি নিয়ে মজা নয়।">কুকি অনুমোদিত নয়</dfn>:
