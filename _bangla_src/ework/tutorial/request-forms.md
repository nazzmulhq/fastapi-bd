# ফর্ম ডেটা { #form-data }

/// note | এই পেজে যা শিখবেন

* JSON-এর বদলে HTML ফর্মের ডেটা (যেমন লগইন ফর্ম) কীভাবে গ্রহণ করবেন।
* ফর্ম ডেটা আর JSON-এর পার্থক্য।

///

JSON-এর বদলে ফর্ম ফিল্ড গ্রহণ করতে হলে `Form` ব্যবহার করতে পারেন।

ফর্ম মানে ওয়েবপেজে থাকা সেই ঘরগুলো যেখানে নাম, পাসওয়ার্ড ইত্যাদি লিখে "জমা দিন" চাপা হয়। ব্রাউজার এই ডেটা JSON হিসেবে নয়, আলাদা একটি ফরম্যাটে পাঠায়।

/// note | নোট

ফর্ম ব্যবহার করতে প্রথমে [`python-multipart`](https://github.com/Kludex/python-multipart) ইনস্টল করুন।

আপনার প্রজেক্টে এটি যোগ করুন:

```console
$ uv add python-multipart
```

(`fastapi[standard]` দিয়ে ইনস্টল করলে এটি আগে থেকেই থাকে।)

/// info | কোডটি সহজ ভাষায়

`username: Annotated[str, Form()]` আর `password: Annotated[str, Form()]` মানে: এই দুটি মান ফর্ম থেকে আসবে, দুটিই আবশ্যক টেক্সট। এটি একটি সাধারণ লগইন ফর্মের মতো।

///

যেমন, OAuth2 স্পেসিফিকেশন যেসব উপায়ে ব্যবহার করা যায় তার একটিতে (যাকে "password flow" বলে) `username` আর `password` ফর্ম ফিল্ড হিসেবে পাঠাতে হয়।

<dfn title="স্পেসিফিকেশন">স্পেক</dfn> অনুযায়ী ফিল্ডগুলোর নাম হুবহু `username` আর `password` হতে হবে, আর JSON নয়, ফর্ম ফিল্ড হিসেবে পাঠাতে হবে।

`Form` দিয়ে `Body` (আর `Query`, `Path`, `Cookie`)-এর মতো একই কনফিগারেশন ঘোষণা করতে পারেন, যার মধ্যে আছে যাচাই, উদাহরণ, একটি alias (যেমন `username`-এর বদলে `user-name`) ইত্যাদি।

/// note | নোট

`Form` এমন একটি ক্লাস যা সরাসরি `Body` থেকে ইনহেরিট করে।

///

/// tip | পরামর্শ

ফর্ম বডি ঘোষণা করতে স্পষ্টভাবে `Form` ব্যবহার করতেই হবে, কারণ এটি ছাড়া প্যারামিটারগুলো কুয়েরি প্যারামিটার বা বডি (JSON) প্যারামিটার হিসেবে ধরা হবে।

## "ফর্ম ফিল্ড" সম্পর্কে { #about-form-fields }

HTML ফর্ম (`<form></form>`) যেভাবে সার্ভারে ডেটা পাঠায়, তাতে সাধারণত ওই ডেটার জন্য একটি "বিশেষ" এনকোডিং ব্যবহার হয়, যা JSON থেকে আলাদা।

**FastAPI** নিশ্চিত করবে যে ওই ডেটা JSON-এর বদলে সঠিক জায়গা থেকে পড়া হচ্ছে।

যেমন JSON দেখতে `{"username": "rahim", "password": "123"}`, কিন্তু ফর্ম ডেটা দেখতে `username=rahim&password=123`।

/// note | কারিগরি বিবরণ

ফর্মের ডেটা সাধারণত "মিডিয়া টাইপ" `application/x-www-form-urlencoded` দিয়ে এনকোড করা হয়।

কিন্তু ফর্মে ফাইল থাকলে এটি `multipart/form-data` হিসেবে এনকোড হয়। পরের অধ্যায়ে ফাইল সামলানো নিয়ে পড়বেন।

এই এনকোডিং আর ফর্ম ফিল্ড নিয়ে আরও পড়তে চাইলে [`POST`-এর জন্য <abbr title="Mozilla Developer Network">MDN</abbr> ওয়েব ডকুমেন্টেশনে](https://developer.mozilla.org/en-US/docs/Web/HTTP/Methods/POST) যান।

///

/// warning | সতর্কতা

একটি *পাথ অপারেশনে* একাধিক `Form` প্যারামিটার ঘোষণা করতে পারেন, কিন্তু একই সাথে JSON হিসেবে গ্রহণের জন্য `Body` ফিল্ড ঘোষণা করতে পারবেন না। কারণ রিকোয়েস্টের বডি তখন `application/json`-এর বদলে `application/x-www-form-urlencoded` দিয়ে এনকোড করা থাকবে।

এটি **FastAPI**-এর কোনো সীমাবদ্ধতা নয়, এটি HTTP প্রোটোকলেরই অংশ। একটি রিকোয়েস্টের বডি একসাথে দুই ফরম্যাটে হতে পারে না।
