# মেটাডেটা ও ডকুমেন্টেশনের URL { #metadata-and-docs-urls }

/// note | এই পেজে যা শিখবেন

* `/docs`-এ আপনার API-এর নাম, বিবরণ, সংস্করণ, যোগাযোগ আর লাইসেন্স দেখানো।
* ট্যাগগুলোর বিবরণ আর ক্রম ঠিক করা।
* `/openapi.json`, `/docs`, `/redoc` এর ঠিকানা বদলানো বা বন্ধ করা।

///

আপনার **FastAPI** অ্যাপ্লিকেশনে মেটাডেটার বেশ কয়েকটি কনফিগারেশন নিজের মতো সাজাতে পারেন। মেটাডেটা মানে API সম্পর্কে তথ্য, যেমন নাম, বিবরণ, কে বানিয়েছে।

## API-এর মেটাডেটা { #metadata-for-api }

OpenAPI স্পেসিফিকেশন আর স্বয়ংক্রিয় API ডকুমেন্টেশন UI-তে ব্যবহৃত এই ফিল্ডগুলো সেট করতে পারেন:

| প্যারামিটার | টাইপ | বিবরণ |
|------------|------|-------------|
| `title` | `str` | API-এর শিরোনাম। |
| `summary` | `str` | API-এর একটি ছোট সারাংশ। <small>OpenAPI 3.1.0, FastAPI 0.99.0 থেকে উপলব্ধ।</small> |
| `description` | `str` | API-এর একটি ছোট বিবরণ। এতে Markdown ব্যবহার করা যায়। |
| `version` | `str` | API-এর সংস্করণ। এটি আপনার নিজের অ্যাপ্লিকেশনের সংস্করণ, OpenAPI-এর নয়। যেমন `2.5.0`। |
| `terms_of_service` | `str` | API-এর ব্যবহারের শর্তাবলির (Terms of Service) একটি URL। দেওয়া হলে এটি অবশ্যই একটি URL হতে হবে। |

| `license_info` | `dict` | প্রকাশিত API-এর লাইসেন্সের তথ্য। এতে কয়েকটি ফিল্ড থাকতে পারে। <details><summary><code>license_info</code>-এর ফিল্ডগুলো</summary><table><thead><tr><th>প্যারামিটার</th><th>টাইপ</th><th>বিবরণ</th></tr></thead><tbody><tr><td><code>name</code></td><td><code>str</code></td><td><strong>আবশ্যক</strong> (যদি একটি <code>license_info</code> সেট করা থাকে)। API-এর জন্য ব্যবহৃত লাইসেন্সের নাম।</td></tr><tr><td><code>identifier</code></td><td><code>str</code></td><td>API-এর জন্য একটি [SPDX](https://spdx.org/licenses/) লাইসেন্স এক্সপ্রেশন। <code>identifier</code> ফিল্ড আর <code>url</code> ফিল্ড একসাথে ব্যবহার করা যায় না। <small>OpenAPI 3.1.0, FastAPI 0.99.0 থেকে উপলব্ধ।</small></td></tr><tr><td><code>url</code></td><td><code>str</code></td><td>API-এর জন্য ব্যবহৃত লাইসেন্সের একটি URL। অবশ্যই URL ফরম্যাটে হতে হবে।</td></tr></tbody></table></details> |

## ট্যাগের মেটাডেটা { #metadata-for-tags }

আপনার পাথ অপারেশনগুলো দলে ভাগ করতে ব্যবহৃত বিভিন্ন ট্যাগের জন্য `openapi_tags` প্যারামিটার দিয়ে বাড়তি মেটাডেটাও যোগ করতে পারেন।

এটি একটি তালিকা নেয়, যাতে প্রতিটি ট্যাগের জন্য একটি করে ডিকশনারি থাকে।

প্রতিটি ডিকশনারিতে থাকতে পারে:

* `name` (**আবশ্যক**): একটি `str`, যাতে আপনার *পাথ অপারেশন* আর `APIRouter`-এর `tags` প্যারামিটারে ব্যবহৃত একই ট্যাগের নাম।
* `description`: ট্যাগের জন্য একটি ছোট বিবরণসহ একটি `str`। এতে Markdown থাকতে পারে আর ডকুমেন্টেশন UI-তে দেখানো হবে।
* `externalDocs`: বাইরের ডকুমেন্টেশন বর্ণনাকারী একটি `dict`, যাতে আছে:
    * `description`: বাইরের ডকুমেন্টেশনের জন্য একটি ছোট বিবরণসহ একটি `str`।
    * `url` (**আবশ্যক**): বাইরের ডকুমেন্টেশনের URL-সহ একটি `str`।

## OpenAPI URL { #openapi-url }

ডিফল্টভাবে OpenAPI স্কিমা `/openapi.json`-এ সার্ভ করা হয়।

কিন্তু `openapi_url` প্যারামিটার দিয়ে এটি কনফিগার করতে পারেন।

যেমন, এটিকে `/api/v1/openapi.json`-এ সার্ভ করতে:

{* ../../docs_src/metadata/tutorial002_py310.py hl[3] *}

OpenAPI স্কিমা পুরোপুরি বন্ধ করতে চাইলে `openapi_url=None` সেট করতে পারেন, এতে এটি ব্যবহার করা ডকুমেন্টেশন ইউজার ইন্টারফেসগুলোও বন্ধ হয়ে যাবে।

/// tip | কখন বন্ধ করবেন?

কিছু প্রতিষ্ঠান প্রোডাকশনে API-এর পুরো তালিকা সবার কাছে উন্মুক্ত রাখতে চায় না। তখন `/docs` আর `/openapi.json` বন্ধ রাখা হয়। এ নিয়ে আরও আছে [শর্তসাপেক্ষ OpenAPI](../how-to/conditional-openapi.md) পেজে। তবে মনে রাখবেন, ডকুমেন্টেশন লুকানো আসল নিরাপত্তা নয়, API-এর সুরক্ষা আলাদাভাবে করতে হবে।

## ডকুমেন্টেশনের URL { #docs-urls }

সাথে থাকা দুটি ডকুমেন্টেশন ইউজার ইন্টারফেস কনফিগার করতে পারেন:

* **Swagger UI**: `/docs`-এ সার্ভ হয়।
    * `docs_url` প্যারামিটার দিয়ে এর URL সেট করতে পারেন।
    * `docs_url=None` সেট করে এটি বন্ধ করতে পারেন।
* **ReDoc**: `/redoc`-এ সার্ভ হয়।
    * `redoc_url` প্যারামিটার দিয়ে এর URL সেট করতে পারেন।
    * `redoc_url=None` সেট করে এটি বন্ধ করতে পারেন।

যেমন, Swagger UI-কে `/documentation`-এ সার্ভ করতে আর ReDoc বন্ধ করতে:

{* ../../docs_src/metadata/tutorial003_py310.py hl[3] *}

/// check | সংক্ষেপে মনে রাখুন

* `FastAPI(title=..., description=..., version=..., contact=..., license_info=...)` দিয়ে ডকুমেন্টেশনে API-এর পরিচয় দিন।
* `openapi_tags=[...]` দিয়ে ট্যাগের বিবরণ আর ক্রম ঠিক করুন।
* `openapi_url`, `docs_url`, `redoc_url` দিয়ে ঠিকানা বদলান, `None` দিলে বন্ধ।
