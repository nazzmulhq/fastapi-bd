# বডি - ফিল্ড { #body-fields }

/// note | এই পেজে যা শিখবেন

* Pydantic-এর `Field` দিয়ে মডেলের ভেতরের প্রতিটি অ্যাট্রিবিউটে যাচাই ও বিবরণ যোগ করা।
* `Field` আর `Query`/`Path`/`Body`-এর মিল।

///

*পাথ অপারেশন ফাংশনের* প্যারামিটারে `Query`, `Path` আর `Body` দিয়ে যেমন বাড়তি যাচাই ও মেটাডেটা ঘোষণা করা যায়, তেমনই Pydantic মডেলের ভেতরে Pydantic-এর `Field` ব্যবহার করে যাচাই ও মেটাডেটা ঘোষণা করা যায়।

তারপর মডেলের অ্যাট্রিবিউটে `Field` ব্যবহার করতে পারেন:

{* ../../docs_src/body_fields/tutorial001_an_py310.py hl[11:14] *}

`Field` ঠিক `Query`, `Path` আর `Body`-এর মতোই কাজ করে, এর সব একই প্যারামিটার আছে, ইত্যাদি।

/// info | কোডটি সহজ ভাষায়

* লাইন ১১-১৩: `description` ঐচ্ছিক (`default=None`), ডকুমেন্টেশনে শিরোনাম "The description of the item", আর সর্বোচ্চ ৩০০ অক্ষর।
* লাইন ১৪: `price` আবশ্যক (কোনো ডিফল্ট নেই), শূন্যের চেয়ে বড় হতে হবে (`gt=0`), আর একটি বিবরণ দেওয়া আছে যা ডকুমেন্টেশনে দেখাবে।
* লাইন ১৯: `Body(embed=True)` তাই বডিটি `{"item": {...}}` আকারে আসবে।

এখন কেউ `"price": -5` পাঠালে FastAPI জানাবে যে দাম শূন্যের চেয়ে বড় হতে হবে।

///

/// note | কারিগরি বিবরণ

আসলে `Query`, `Path` আর পরে যেগুলো দেখবেন সেগুলো একটি সাধারণ `Param` ক্লাসের সাব-ক্লাসের অবজেক্ট তৈরি করে, যা নিজেই Pydantic-এর `FieldInfo` ক্লাসের একটি সাব-ক্লাস।

আর Pydantic-এর `Field`-ও `FieldInfo`-এর একটি ইনস্ট্যান্স রিটার্ন করে।

`Body`-ও সরাসরি `FieldInfo`-এর একটি সাব-ক্লাসের অবজেক্ট রিটার্ন করে। আর পরে আরও কিছু দেখবেন যেগুলো `Body` ক্লাসের সাব-ক্লাস।

মনে রাখবেন, `fastapi` থেকে `Query`, `Path` ইত্যাদি ইমপোর্ট করলে সেগুলো আসলে এমন ফাংশন যা বিশেষ ক্লাস রিটার্ন করে।

সহজ কথায়: এরা সবাই একই পরিবারের সদস্য, তাই সবার নিয়ম লেখার ধরন একই।

///

/// tip | পরামর্শ

খেয়াল করুন, টাইপ, ডিফল্ট মান আর `Field`-সহ মডেলের প্রতিটি অ্যাট্রিবিউটের গঠন একটি *পাথ অপারেশন ফাংশনের* প্যারামিটারের মতোই, শুধু `Path`, `Query` আর `Body`-র জায়গায় `Field`।

///

## বাড়তি তথ্য যোগ করুন { #add-extra-information }

`Field`, `Query`, `Body` ইত্যাদিতে বাড়তি তথ্য ঘোষণা করতে পারেন। আর সেটি তৈরি হওয়া JSON Schema-তে অন্তর্ভুক্ত হবে।

পরে ডকুমেন্টেশনে উদাহরণ ঘোষণা করা শেখার সময় বাড়তি তথ্য যোগ করা সম্পর্কে আরও জানবেন।

/// warning | সতর্কতা

`Field`-এ দেওয়া বাড়তি কী-গুলো আপনার অ্যাপ্লিকেশনের তৈরি হওয়া OpenAPI স্কিমাতেও থাকবে।
যেহেতু এই কী-গুলো OpenAPI স্পেসিফিকেশনের অংশ নাও হতে পারে, তাই কিছু OpenAPI টুল, যেমন [OpenAPI validator](https://validator.swagger.io/), আপনার তৈরি স্কিমার সাথে কাজ নাও করতে পারে।

///

## সংক্ষেপে { #recap }

মডেলের অ্যাট্রিবিউটে বাড়তি যাচাই ও মেটাডেটা ঘোষণা করতে Pydantic-এর `Field` ব্যবহার করতে পারেন।

বাড়তি JSON Schema মেটাডেটা দিতে বাড়তি কিওয়ার্ড আর্গুমেন্টও ব্যবহার করতে পারেন।

/// check | সংক্ষেপে মনে রাখুন

* ফাংশনের প্যারামিটারে নিয়ম দিতে `Query`/`Path`/`Body`, মডেলের ভেতরে নিয়ম দিতে `Field`।
* `Field` আসে `pydantic` থেকে, `fastapi` থেকে নয়।
* `Field`-এ একই প্যারামিটার: `gt`, `le`, `max_length`, `title`, `description` ইত্যাদি।
