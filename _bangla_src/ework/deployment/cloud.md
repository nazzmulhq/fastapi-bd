# ক্লাউড প্রোভাইডারে FastAPI ডিপ্লয় { #deploy-fastapi-on-cloud-providers }

/// note | এই পেজে যা শিখবেন

* FastAPI প্রায় যেকোনো ক্লাউড প্রোভাইডারে চালানো যায়।
* FastAPI Cloud আর FastAPI-কে স্পনসর করা অন্যান্য ক্লাউড প্রোভাইডার।

///

আপনার FastAPI অ্যাপ্লিকেশন ডিপ্লয় করতে কার্যত **যেকোনো ক্লাউড প্রোভাইডার** ব্যবহার করতে পারেন।

বেশিরভাগ ক্ষেত্রে, প্রধান ক্লাউড প্রোভাইডারদের কাছে তাদের প্ল্যাটফর্মে FastAPI ডিপ্লয় করার গাইড থাকে।

/// tip | উদাহরণ দিয়ে বুঝি

ক্লাউড প্রোভাইডার হলো ভাড়া বাড়ির মালিকের মতো: নিজের কম্পিউটার ২৪ ঘণ্টা চালু রাখার বদলে আপনি তাদের সার্ভারে জায়গা ভাড়া নেন। FastAPI যেহেতু স্ট্যান্ডার্ড Python অ্যাপ, তাই যেকোনো "বাড়িতেই" উঠতে পারে।

///

## FastAPI Cloud { #fastapi-cloud }

**[FastAPI Cloud](https://fastapicloud.com)** তৈরি করেছেন **FastAPI**-এর পেছনের একই লেখক আর দল।

এটি খুব কম পরিশ্রমে একটি API **তৈরি**, **ডিপ্লয়** আর **ব্যবহার** করার প্রক্রিয়াকে সহজ করে।

FastAPI দিয়ে অ্যাপ তৈরির যে **ডেভেলপার অভিজ্ঞতা**, সেটিই এটি ক্লাউডে **ডিপ্লয়** করার ক্ষেত্রেও নিয়ে আসে। 🎉

FastAPI Cloud হলো *FastAPI and friends* ওপেন সোর্স প্রজেক্টগুলোর প্রধান স্পনসর আর অর্থায়নকারী। ✨
