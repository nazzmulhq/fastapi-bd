# FastAPI সংস্করণ সম্পর্কে { #about-fastapi-versions }

/// note | এই পেজে যা শিখবেন

* সংস্করণ নম্বর (যেমন `0.112.0`) কীভাবে পড়তে হয়।
* কেন FastAPI-এর সংস্করণ "pin" (আটকে) রাখা উচিত, আর কীভাবে।
* নিরাপদে নতুন সংস্করণে আপগ্রেড করার পদ্ধতি।
* Starlette আর Pydantic-এর সংস্করণ নিয়ে কী করবেন।

///

**FastAPI** ইতিমধ্যে অনেক অ্যাপ্লিকেশন আর সিস্টেমে প্রোডাকশনে ব্যবহার হচ্ছে। আর টেস্ট কভারেজ ১০০% রাখা হয়। কিন্তু এর ডেভেলপমেন্ট এখনো দ্রুত এগোচ্ছে।

নতুন ফিচার প্রায়ই যোগ হয়, বাগ নিয়মিত ঠিক করা হয়, আর কোড এখনো ক্রমাগত উন্নত হচ্ছে।

এই কারণেই বর্তমান সংস্করণগুলো এখনো `0.x.x`, যা প্রকাশ করে যে প্রতিটি সংস্করণে সম্ভাব্যভাবে breaking change (এমন পরিবর্তন যা আগের কোড ভেঙে দিতে পারে) থাকতে পারে। এটি [Semantic Versioning](https://semver.org/) নিয়ম অনুসরণ করে।

আপনি এখনই **FastAPI** দিয়ে প্রোডাকশন অ্যাপ্লিকেশন তৈরি করতে পারেন (আর সম্ভবত কিছুদিন ধরে তা করছেনও), শুধু নিশ্চিত করতে হবে যে আপনি এমন একটি সংস্করণ ব্যবহার করছেন যা আপনার বাকি কোডের সাথে সঠিকভাবে কাজ করে।

## আপনার `fastapi` সংস্করণ pin করুন { #pin-your-fastapi-version }

প্রথমে যা করা উচিত তা হলো, আপনি যে **FastAPI** সংস্করণ ব্যবহার করছেন সেটিকে নির্দিষ্ট সর্বশেষ সংস্করণে "pin" (আটকে) রাখা, যেটি আপনার অ্যাপ্লিকেশনের জন্য সঠিকভাবে কাজ করে বলে আপনি জানেন।

/// tip | উদাহরণ দিয়ে বুঝি

ধরুন আপনার রান্নার রেসিপিতে লেখা "যেকোনো কোম্পানির মশলা"। একদিন দোকান নতুন ব্র্যান্ড দিল, স্বাদ বদলে গেল। "pin" করা মানে রেসিপিতে লিখে দেওয়া "শুধু অমুক কোম্পানির, অমুক প্যাকেটের মশলা"। এতে আজ আর ছয় মাস পরে, আপনার কম্পিউটারে আর সার্ভারে, সবখানে একই ফলাফল পাবেন।

///

যেমন, ধরা যাক আপনি আপনার অ্যাপে `0.112.0` সংস্করণ ব্যবহার করছেন।

যদি একটি `requirements.txt` ফাইল ব্যবহার করেন, তাহলে সংস্করণটি এভাবে নির্দিষ্ট করতে পারেন:

```txt
fastapi[standard]==0.112.0
```

এর মানে আপনি হুবহু `0.112.0` সংস্করণটিই ব্যবহার করবেন।

অথবা এভাবেও pin করতে পারেন:

```txt
fastapi[standard]>=0.112.0,<0.113.0
```

এর মানে আপনি `0.112.0` বা তার ওপরের সংস্করণ ব্যবহার করবেন, কিন্তু `0.113.0`-এর চেয়ে কম। যেমন `0.112.2` সংস্করণও গ্রহণযোগ্য হবে।

যদি ইনস্টলেশন পরিচালনার জন্য অন্য কোনো টুল ব্যবহার করেন, যেমন `uv`, Poetry, Pipenv বা অন্যান্য, সবগুলোতেই আপনার প্যাকেজের নির্দিষ্ট সংস্করণ নির্ধারণ করার একটি উপায় আছে।

## উপলব্ধ সংস্করণ { #available-versions }

উপলব্ধ সংস্করণগুলো (যেমন বর্তমান সর্বশেষটি কোনটি তা দেখতে) [রিলিজ নোট](../release-notes.md)-এ দেখতে পারেন।

## সংস্করণ সম্পর্কে { #about-versions }

Semantic Versioning নিয়ম অনুযায়ী, `1.0.0`-এর নিচের যেকোনো সংস্করণে সম্ভাব্যভাবে breaking change যোগ হতে পারে।

FastAPI এই নিয়মও অনুসরণ করে যে যেকোনো "PATCH" সংস্করণ পরিবর্তন হয় বাগ ঠিক করা আর এমন পরিবর্তনের জন্য যা কিছু ভাঙে না।

/// tip | পরামর্শ

"PATCH" হলো শেষ সংখ্যাটি, যেমন `0.2.3`-এ PATCH সংস্করণ হলো `3`।

///

তাই আপনি এমন একটি সংস্করণে pin করতে পারবেন:

```txt
fastapi>=0.45.0,<0.46.0
```

breaking change আর নতুন ফিচার যোগ হয় "MINOR" সংস্করণে।

/// tip | পরামর্শ

"MINOR" হলো মাঝের সংখ্যাটি, যেমন `0.2.3`-এ MINOR সংস্করণ হলো `2`।

///

/// info | সংস্করণ নম্বর এক নজরে

`0.112.3` সংখ্যাটিকে তিন ভাগে পড়ুন: `MAJOR.MINOR.PATCH`

* `0` = MAJOR: `1.0.0`-এর আগে সবই `0`।
* `112` = MINOR: এটি বাড়লে নতুন ফিচার আসে, পুরনো কোড ভাঙতেও পারে। তাই সাবধান।
* `3` = PATCH: এটি বাড়লে শুধু বাগ ঠিক হয়, নিশ্চিন্তে আপডেট করা যায়।

তাই `>=0.112.0,<0.113.0` মানে "PATCH আপডেট নাও, MINOR আপডেট নিও না।"

///

## FastAPI সংস্করণ আপগ্রেড করা { #upgrading-the-fastapi-versions }

আপনার অ্যাপের জন্য টেস্ট যোগ করা উচিত।

**FastAPI**-তে এটি খুবই সহজ (Starlette-কে ধন্যবাদ), ডকস দেখুন: [টেস্টিং](../tutorial/testing.md)

টেস্ট থাকার পরে, **FastAPI** সংস্করণ আরও নতুন একটিতে আপগ্রেড করতে পারেন, আর টেস্টগুলো চালিয়ে নিশ্চিত করতে পারেন যে আপনার সব কোড সঠিকভাবে কাজ করছে।

যদি সব কাজ করে, বা দরকারি পরিবর্তন করার পরে সব টেস্ট পাস করে, তাহলে আপনার `fastapi` সেই নতুন সংস্করণে pin করতে পারেন।

## Starlette সম্পর্কে { #about-starlette }

`starlette`-এর সংস্করণ pin করা উচিত নয়।

**FastAPI**-এর বিভিন্ন সংস্করণ Starlette-এর একটি নির্দিষ্ট নতুন সংস্করণ ব্যবহার করবে।

তাই আপনি শুধু **FastAPI**-কে সঠিক Starlette সংস্করণ ব্যবহার করতে দিন।

## Pydantic সম্পর্কে { #about-pydantic }

Pydantic তার নিজের টেস্টের সাথে **FastAPI**-এর টেস্টগুলোও রাখে, তাই Pydantic-এর নতুন সংস্করণগুলো (`1.0.0`-এর ওপরে) সবসময় FastAPI-এর সাথে মানানসই।

আপনার জন্য কাজ করে এমন `1.0.0`-এর ওপরের যেকোনো সংস্করণে Pydantic pin করতে পারেন।

যেমন:

```txt
pydantic>=2.7.0,<3.0.0
```

/// check | সংক্ষেপে মনে রাখুন

* প্রোডাকশনে `fastapi`-এর সংস্করণ pin করুন, যেমন `fastapi[standard]>=0.112.0,<0.113.0`।
* আপগ্রেডের আগে টেস্ট লিখুন, আপগ্রেডের পরে টেস্ট চালান, পাস করলে নতুন সংস্করণে pin করুন।
* Starlette pin করবেন না, FastAPI নিজেই ঠিকটা বেছে নেয়। Pydantic একটি বড় সীমার মধ্যে pin করুন।
