# শিখুন { #learn }

**FastAPI** শেখার জন্য পরিচিতিমূলক অংশ আর টিউটোরিয়ালগুলো এখানে আছে।

এটিকে একটি **বই** বা একটি **কোর্স** হিসেবে ভাবতে পারেন। FastAPI শেখার এটাই **অফিসিয়াল** ও সুপারিশকৃত পথ। 😎

/// note | এই অংশটি কীভাবে পড়বেন

বাম পাশের মেনুতে অধ্যায়গুলো ধারাবাহিকভাবে সাজানো। ওপর থেকে নিচে, একটির পর একটি পড়ুন। প্রতিটি অধ্যায় আগেরটির ওপর ভিত্তি করে লেখা।

প্রতিটি পেজের শুরুতে "এই পেজে যা শিখবেন" আর শেষে "সংক্ষেপে মনে রাখুন" অংশ আছে। কোডের পরে "কোডটি সহজ ভাষায়" অংশে প্রতিটি লাইনের ব্যাখ্যা দেওয়া আছে।

///

## কোন ক্রমে পড়বেন { #bn-reading-order }

1. **[সহজ শব্দকোষ](glossary.md)**: API, রিকোয়েস্ট, রেসপন্স, JSON এমন শব্দগুলোর সহজ মানে। অপরিচিত শব্দ পেলেই এখানে ফিরে আসুন।
2. **[Python টাইপের পরিচিতি](../python-types.md)**: FastAPI পুরোপুরি Python-এর টাইপ হিন্টের ওপর দাঁড়িয়ে। এটি আগে বুঝে নিলে বাকি সব সহজ হবে।
3. **[কনকারেন্সি ও async / await](../async.md)**: `async def` কখন লিখবেন আর কখন সাধারণ `def`। তাড়া থাকলে শুধু প্রথম অংশটুকু পড়ুন।
4. **[এনভায়রনমেন্ট ভেরিয়েবল](../environment-variables.md)** ও **[ভার্চুয়াল এনভায়রনমেন্ট](../virtual-environments.md)**: প্রজেক্ট সেটআপের দুটি জরুরি ধারণা।
5. **[টিউটোরিয়াল - ইউজার গাইড](../tutorial/index.md)**: আসল শেখা এখান থেকে শুরু। প্রথম API থেকে শুরু করে ডেটাবেস, সিকিউরিটি, টেস্টিং পর্যন্ত, ধাপে ধাপে।
6. **[অ্যাডভান্সড ইউজার গাইড](../advanced/index.md)**: টিউটোরিয়াল শেষ করার পরে, বিশেষ প্রয়োজনের জন্য আরও গভীর বিষয়।
7. **[ডিপ্লয়মেন্ট](../deployment/index.md)**: আপনার অ্যাপকে ইন্টারনেটে চালু করার পদ্ধতি ও ধারণা।
8. **[কীভাবে করবেন - রেসিপি](../how-to/index.md)**: নির্দিষ্ট সমস্যার ছোট ছোট সমাধান।

/// tip | শেখার পরামর্শ

* শুধু পড়বেন না, প্রতিটি উদাহরণ নিজের কম্পিউটারে লিখে চালিয়ে দেখুন।
* কোড একটু বদলে দেখুন কী হয়। যেমন একটি টাইপ বদলে দিন বা ভুল ডেটা পাঠান, তারপর `/docs`-এ গিয়ে ফলাফল দেখুন।
* প্রথমবার সব বুঝতে না পারলে চিন্তা নেই। এগিয়ে যান, পরে আবার ফিরে এলে অনেক বেশি পরিষ্কার লাগবে।

///
