# রিপোজিটরি ব্যবস্থাপনা { #repository-management }

/// note | এই পেজটি কী

FastAPI-এর সোর্স কোড (GitHub রিপোজিটরি) কে পরিচালনা করেন আর সিদ্ধান্ত কীভাবে নেওয়া হয়, তার সংক্ষিপ্ত বিবরণ।

///

FastAPI রিপোজিটরি কীভাবে পরিচালনা আর রক্ষণাবেক্ষণ করা হয় তার একটি সংক্ষিপ্ত বিবরণ এখানে দেওয়া হলো।

## মালিক { #owner }

আমি, [@tiangolo](https://github.com/tiangolo), FastAPI রিপোজিটরির নির্মাতা আর মালিক। 🤓

সাধারণত প্রতিটি PR (Pull Request, অর্থাৎ কোড পরিবর্তনের প্রস্তাব) মার্জ করার আগে আমি চূড়ান্ত রিভিউ করি। প্রজেক্টের চূড়ান্ত সিদ্ধান্তগুলো আমি নিই, আমি হলাম [<abbr title="Benevolent Dictator For Life: আজীবন দয়ালু একনায়ক">BDFL</abbr>](https://en.wikipedia.org/wiki/Benevolent_dictator_for_life)। 😅

(BDFL হলো ওপেন সোর্স জগতের একটি মজার উপাধি: প্রজেক্টের নির্মাতা, যিনি সবার মতামত শোনেন কিন্তু শেষ সিদ্ধান্ত নিজে নেন। Python-এর নির্মাতা Guido van Rossum-কেও এভাবে ডাকা হতো।)

## দল { #team }

একদল মানুষ আছেন যারা প্রজেক্টটি পরিচালনা আর রক্ষণাবেক্ষণে সাহায্য করেন। 😎

এ সম্পর্কে আরও জানুন [tiangolo.com - GitHub FastAPI](https://tiangolo.com/github-fastapi/)-এ।
