# এডিটর সাপোর্ট { #editor-support }

/// note | এই পেজে যা শিখবেন

* অফিসিয়াল FastAPI এক্সটেনশন কী, আর এটি কোন এডিটরে চলে।
* এক্সটেনশন কীভাবে আপনার অ্যাপ খুঁজে পায়।
* এর প্রধান সুবিধাগুলো: পাথ অপারেশন এক্সপ্লোরার, রাউট খোঁজা, টেস্ট থেকে কোডে লাফ দেওয়া, ডিপ্লয় আর লগ দেখা।

///

অফিসিয়াল [FastAPI এক্সটেনশন](https://marketplace.visualstudio.com/items?itemName=FastAPILabs.fastapi-vscode) আপনার FastAPI ডেভেলপমেন্টের কাজকে আরও সহজ করে: *পাথ অপারেশন* খুঁজে বের করা, সেগুলোর মধ্যে যাতায়াত, সাথে FastAPI Cloud-এ ডিপ্লয় আর সরাসরি (লাইভ) লগ দেখা।

(এক্সটেনশন মানে এডিটরে যোগ করা একটি ছোট বাড়তি প্রোগ্রাম, যেমন ফোনে একটি অ্যাপ ইনস্টল করা।)

এক্সটেনশনটি সম্পর্কে আরও বিস্তারিত জানতে [GitHub রিপোজিটরির](https://github.com/fastapi/fastapi-vscode) README দেখুন।

## সেটআপ এবং ইনস্টলেশন { #setup-and-installation }

**FastAPI এক্সটেনশন** [VS Code](https://code.visualstudio.com/) আর [Cursor](https://www.cursor.com/) দুটোর জন্যই পাওয়া যায়। প্রতিটি এডিটরের Extensions প্যানেল থেকে "FastAPI" লিখে খুঁজে **FastAPI Labs**-এর প্রকাশ করা এক্সটেনশনটি বেছে নিয়ে সরাসরি ইনস্টল করা যায়। এক্সটেনশনটি [vscode.dev](https://vscode.dev) আর [github.dev](https://github.dev) এর মতো ব্রাউজার-ভিত্তিক এডিটরেও কাজ করে।

/// tip | ধাপে ধাপে

1. VS Code বা Cursor খুলুন।
2. বাঁ পাশের Extensions আইকনে ক্লিক করুন (অথবা <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd>)।
3. "FastAPI" লিখে খুঁজুন, প্রকাশক **FastAPI Labs** কিনা দেখে নিন।
4. Install চাপুন। এরপর বাঁ পাশে একটি FastAPI প্যানেল দেখতে পাবেন।

///

### অ্যাপ্লিকেশন খুঁজে পাওয়া { #application-discovery }

ডিফল্টভাবে, এক্সটেনশনটি আপনার ওয়ার্কস্পেসে `FastAPI()` তৈরি করে এমন ফাইল স্ক্যান করে স্বয়ংক্রিয়ভাবে FastAPI অ্যাপ্লিকেশন খুঁজে বের করবে। যদি আপনার প্রজেক্টের কাঠামোয় স্বয়ংক্রিয় শনাক্তকরণ কাজ না করে, তাহলে `pyproject.toml`-এ `[tool.fastapi]` দিয়ে, অথবা VS Code-এর `fastapi.entryPoint` সেটিং দিয়ে, মডিউল নোটেশন ব্যবহার করে (যেমন `myapp.main:app`) একটি entrypoint নির্দিষ্ট করে দিতে পারেন।

(`entrypoint` কীভাবে লিখতে হয় তা বিস্তারিত দেখুন [FastAPI CLI](fastapi-cli.md) পেজে।)

## বৈশিষ্ট্যসমূহ { #features }

- **পাথ অপারেশন এক্সপ্লোরার** - সাইডবারে আপনার অ্যাপ্লিকেশনের সব <dfn title="routes, endpoints">*পাথ অপারেশনের*</dfn> একটি গাছের মতো তালিকা। যেকোনো রাউট বা রাউটারের সংজ্ঞায় সরাসরি যেতে ক্লিক করুন।
- **রাউট খোঁজা** - <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> (macOS-এ: <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd>) দিয়ে পাথ, মেথড বা নাম দিয়ে খুঁজুন।
- **CodeLens নেভিগেশন** - টেস্ট ক্লায়েন্টের কলের (যেমন `client.get('/items')`) ওপরে ক্লিকযোগ্য লিংক, যা মিলে যাওয়া *পাথ অপারেশনে* নিয়ে যায়, ফলে টেস্ট আর আসল কোডের মধ্যে দ্রুত যাতায়াত করা যায়।
- **FastAPI Cloud-এ ডিপ্লয়** - এক ক্লিকে আপনার অ্যাপ [FastAPI Cloud](https://fastapicloud.com/)-এ ডিপ্লয় করা।
- **অ্যাপ্লিকেশনের লগ স্ট্রিম** - FastAPI Cloud-এ ডিপ্লয় করা অ্যাপ্লিকেশনের লগ সরাসরি (real-time) দেখা, লেভেল অনুযায়ী ফিল্টার আর টেক্সট দিয়ে খোঁজার সুবিধাসহ।

/// tip | উদাহরণ দিয়ে বুঝি

বড় প্রজেক্টে শত শত রাউট থাকতে পারে, ছড়িয়ে আছে অনেক ফাইলে। পাথ অপারেশন এক্সপ্লোরার হলো একটি বইয়ের সূচিপত্রের মতো: কোন রাউট কোথায় আছে এক নজরে দেখায়, আর ক্লিক করলেই সেই পাতায় নিয়ে যায়। ফাইল খুলে খুলে খুঁজতে হয় না।

///

এক্সটেনশনের বৈশিষ্ট্যগুলোর সাথে পরিচিত হতে চাইলে, Command Palette খুলে (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> বা macOS-এ: <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>) "Welcome: Open walkthrough..." বেছে নিন, তারপর "Get started with FastAPI" walkthrough বেছে নিয়ে এক্সটেনশনের পরিচিতি-ভ্রমণটি দেখতে পারেন।
