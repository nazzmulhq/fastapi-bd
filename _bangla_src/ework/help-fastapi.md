# সাহায্য { #help }

/// note | এই পেজে যা জানবেন

* আটকে গেলে কোথায় আর কীভাবে প্রশ্ন করবেন।
* FastAPI-এর খবর কোথায় পাবেন।
* খুব সহজ কিছু কাজ (যেমন GitHub-এ স্টার দেওয়া) দিয়ে কীভাবে প্রজেক্টটিকে সাহায্য করবেন।

///

আপনি কি FastAPI-কে সাহায্য করতে চান, বা FastAPI নিয়ে সাহায্য পেতে চান?

সাহায্য করার আর সাহায্য পাওয়ার খুবই সহজ কিছু উপায় আছে।

আপনি GitHub-এ FastAPI-কে "স্টার" দিতে পারেন (ওপরে ডান দিকের তারকা বোতামে ক্লিক করে): [https://github.com/fastapi/fastapi](https://github.com/fastapi/fastapi)। ⭐️

একটি স্টার দিলে অন্য ব্যবহারকারীরা এটি আরও সহজে খুঁজে পাবেন, আর দেখতে পাবেন যে এটি ইতিমধ্যে অন্যদের কাজে লেগেছে।

(স্টার অনেকটা ফেসবুকের "লাইক"-এর মতো। এর জন্য একটি বিনামূল্যের GitHub অ্যাকাউন্ট লাগে।)

## রিলিজের জন্য GitHub রিপোজিটরি "watch" করুন { #watch-the-github-repository-for-releases }

আপনি GitHub-এ FastAPI-কে "watch" করতে পারেন (ওপরে ডান দিকের "watch" বোতামে ক্লিক করে): [https://github.com/fastapi/fastapi](https://github.com/fastapi/fastapi)। 👀

## প্রশ্ন করুন { #ask-questions }

GitHub রিপোজিটরিতে আপনি [একটি নতুন প্রশ্ন তৈরি করতে](https://github.com/fastapi/fastapi/discussions/new?category=questions) পারেন, যেমন:

* একটি **প্রশ্ন** করতে বা কোনো **সমস্যা** নিয়ে জানতে।
* একটি নতুন **ফিচার** প্রস্তাব করতে।

/// tip | ভালো প্রশ্ন কীভাবে করবেন

* প্রশ্ন ইংরেজিতে লিখুন, যাতে সারা বিশ্বের মানুষ সাহায্য করতে পারে।
* একটি ছোট, সম্পূর্ণ কোড উদাহরণ দিন যা চালালেই সমস্যাটি দেখা যায়।
* কী আশা করেছিলেন আর আসলে কী হলো (পুরো এরর বার্তাসহ) লিখুন।
* আপনার FastAPI, Pydantic আর Python সংস্করণ জানান।
* প্রশ্ন করার আগে একবার খুঁজে দেখুন, হয়তো কেউ আগেই একই প্রশ্ন করেছেন।

### প্রশ্নের জন্য চ্যাট ব্যবহার করবেন না { #dont-use-the-chat-for-questions }

মনে রাখবেন, যেহেতু চ্যাটে আরও "খোলামেলা আলাপ" চলে, তাই খুব সাধারণ আর উত্তর দেওয়া কঠিন এমন প্রশ্ন করে ফেলা সহজ, ফলে আপনি হয়তো উত্তর পাবেন না।

GitHub-এ, টেমপ্লেট আপনাকে সঠিক প্রশ্ন লিখতে পথ দেখাবে, যাতে আপনি আরও সহজে একটি ভালো উত্তর পান, বা এমনকি প্রশ্ন করার আগেই নিজে সমস্যার সমাধান করে ফেলেন।

চ্যাট ব্যবস্থার আলাপগুলো GitHub-এর মতো সহজে খোঁজাও যায় না, সেগুলো হারিয়ে যায়।

## FastAPI Cloud ব্যবহার করে দেখুন { #try-fastapi-cloud }

FastAPI আর সহযোগী প্রজেক্টগুলোর প্রধান অর্থায়ন আসে [**FastAPI Cloud**](https://fastapicloud.com) থেকে, যা একটি মাত্র কমান্ড `fastapi deploy` দিয়ে সহজে আর দ্রুত FastAPI অ্যাপ্লিকেশন ডিপ্লয় করার একটি প্ল্যাটফর্ম।

FastAPI Cloud তৈরি করেছে FastAPI-এর পেছনের একই দল। আপনি এটি ব্যবহার করে দেখতে পারেন আর আপনার প্রজেক্টের জন্য বিবেচনা করতে পারেন।
