# সরাসরি একটি Response ফেরত দিন { #return-a-response-directly }

/// note | এই পেজে যা শিখবেন

* FastAPI সাধারণত রিটার্ন করা ডেটাকে কীভাবে রেসপন্সে রূপান্তর করে।
* সরাসরি `Response`/`JSONResponse` ফেরত দিলে কী হয়, আর কী দায়িত্ব আপনার।
* XML এর মতো JSON নয় এমন রেসপন্স পাঠানো।

///

একটি **FastAPI** *পাথ অপারেশন* তৈরি করলে সাধারণত এটি থেকে যেকোনো ডেটা ফেরত দিতে পারেন: একটি `dict`, একটি `list`, একটি Pydantic মডেল, একটি ডেটাবেস মডেল ইত্যাদি।

আপনি যদি একটি [রেসপন্স মডেল](../tutorial/response-model.md) ঘোষণা করেন, তাহলে FastAPI এটি ব্যবহার করে Pydantic দিয়ে ডেটা JSON-এ সিরিয়ালাইজ করবে।

রেসপন্স মডেল ঘোষণা না করলে FastAPI [JSON-সামঞ্জস্যপূর্ণ এনকোডার](../tutorial/encoder.md)-এ বোঝানো `jsonable_encoder` ব্যবহার করবে, আর ফলাফল একটি `JSONResponse`-এ রাখবে।

আপনি নিজেও সরাসরি একটি `JSONResponse` তৈরি করে ফেরত দিতে পারেন।

/// tip | পরামর্শ

সরাসরি একটি `JSONResponse` ফেরত দেওয়ার চেয়ে একটি [রেসপন্স মডেল](../tutorial/response-model.md) ব্যবহার করলে সাধারণত অনেক ভালো পারফরম্যান্স পাবেন, কারণ তাতে ডেটা Pydantic দিয়ে, Rust-এ সিরিয়ালাইজ হয়।

///

## একটি `Response` ফেরত দিন { #return-a-response }

আপনি একটি `Response` বা এর যেকোনো সাব-ক্লাস ফেরত দিতে পারেন।

/// note | নোট

`JSONResponse` নিজেই `Response`-এর একটি সাব-ক্লাস।

///

আর আপনি যখন একটি `Response` ফেরত দেন, **FastAPI** সেটি সরাসরি পাঠিয়ে দেবে।

এটি Pydantic মডেল দিয়ে কোনো ডেটা রূপান্তর করবে না, বিষয়বস্তুকে কোনো টাইপে রূপান্তর করবে না, ইত্যাদি।

এতে আপনি অনেক **নমনীয়তা** পান। যেকোনো ডেটা টাইপ ফেরত দিতে পারেন, যেকোনো ডেটা ঘোষণা বা যাচাই ওভাররাইড করতে পারেন, ইত্যাদি।

আবার এতে আপনার অনেক **দায়িত্বও** আসে। আপনাকে নিশ্চিত করতে হবে যে ফেরত দেওয়া ডেটা সঠিক, সঠিক ফরম্যাটে আছে, সিরিয়ালাইজ করা যায়, ইত্যাদি।

/// tip | উদাহরণ দিয়ে বুঝি

সাধারণভাবে FastAPI আপনার রান্না করা খাবার (ডেটা) প্লেটে সাজিয়ে (JSON) পরিবেশন করে। সরাসরি `Response` ফেরত দেওয়া মানে আপনি নিজেই প্লেট সাজিয়ে দিচ্ছেন, FastAPI সেটি যেমন আছে তেমনই টেবিলে দিয়ে আসে। ভুল থাকলে তা আপনার দায়।

///

## একটি `Response`-এ `jsonable_encoder` ব্যবহার { #using-the-jsonable-encoder-in-a-response }

যেহেতু আপনার ফেরত দেওয়া `Response`-এ **FastAPI** কোনো পরিবর্তন করে না, তাই এর বিষয়বস্তু প্রস্তুত আছে কিনা তা আপনাকেই নিশ্চিত করতে হবে।

যেমন, একটি Pydantic মডেলকে আগে সব ডেটা টাইপসহ (যেমন `datetime`, `UUID` ইত্যাদি) JSON-সামঞ্জস্যপূর্ণ টাইপে রূপান্তরিত একটি `dict`-এ না বদলে একটি `JSONResponse`-এ রাখতে পারবেন না।

এসব ক্ষেত্রে, ডেটা একটি রেসপন্সে দেওয়ার আগে রূপান্তর করতে `jsonable_encoder` ব্যবহার করতে পারেন:

{* ../../docs_src/response_directly/tutorial001_py310.py hl[5:6,20:21] *}

/// note | কারিগরি বিবরণ

`from starlette.responses import JSONResponse`-ও ব্যবহার করতে পারতেন।

**FastAPI** ডেভেলপার হিসেবে আপনার সুবিধার জন্যই একই `starlette.responses`-কে `fastapi.responses` হিসেবে দেয়। কিন্তু উপলব্ধ বেশিরভাগ রেসপন্স সরাসরি Starlette থেকে আসে।

## একটি কাস্টম `Response` ফেরত দেওয়া { #returning-a-custom-response }

ওপরের উদাহরণে প্রয়োজনীয় সব অংশ দেখানো হয়েছে, কিন্তু এটা এখনো খুব একটা কাজের নয়, কারণ আপনি সরাসরি `item` ফেরত দিতে পারতেন, আর **FastAPI** নিজেই সেটিকে `dict`-এ রূপান্তর করে একটি `JSONResponse`-এ রেখে দিত। এসব ডিফল্টভাবেই হয়।

এবার দেখা যাক কীভাবে এটি ব্যবহার করে একটি কাস্টম রেসপন্স ফেরত দিতে পারেন।

ধরা যাক আপনি একটি [XML](https://en.wikipedia.org/wiki/XML) রেসপন্স ফেরত দিতে চান। (XML হলো `<ট্যাগ>` দিয়ে ডেটা লেখার একটি পুরোনো ফরম্যাট, অনেক পুরোনো সিস্টেম এখনো এটি ব্যবহার করে।)

আপনার XML বিষয়বস্তু একটি স্ট্রিংয়ে রেখে, সেটি একটি `Response`-এ রেখে ফেরত দিতে পারেন:

## রেসপন্স মডেল কীভাবে কাজ করে { #how-a-response-model-works }

একটি পাথ অপারেশনে [রেসপন্স মডেল - রিটার্ন টাইপ](../tutorial/response-model.md) ঘোষণা করলে **FastAPI** এটি ব্যবহার করে Pydantic দিয়ে ডেটা JSON-এ সিরিয়ালাইজ করবে।

{* ../../docs_src/response_model/tutorial001_01_py310.py hl[16,21] *}

যেহেতু এটি Rust-এর দিকে ঘটবে, তাই সাধারণ Python আর `JSONResponse` ক্লাস দিয়ে করার চেয়ে পারফরম্যান্স অনেক ভালো হবে।

`response_model` বা রিটার্ন টাইপ ব্যবহার করলে FastAPI ডেটা রূপান্তরে `jsonable_encoder` (যা ধীর হতো) বা `JSONResponse` ক্লাস ব্যবহার করবে না।

এর বদলে এটি রেসপন্স মডেল (বা রিটার্ন টাইপ) দিয়ে Pydantic-এর তৈরি JSON বাইটগুলো নেয়, আর JSON-এর সঠিক মিডিয়া টাইপসহ (`application/json`) সরাসরি একটি `Response` ফেরত দেয়।

## নোট { #notes }

সরাসরি একটি `Response` ফেরত দিলে এর ডেটা স্বয়ংক্রিয়ভাবে যাচাই, রূপান্তর (সিরিয়ালাইজ) বা ডকুমেন্ট করা হয় না।

তবে [OpenAPI-তে বাড়তি রেসপন্স](additional-responses.md)-এ বর্ণিত উপায়ে আপনি এটি তবুও ডকুমেন্ট করতে পারেন।

পরের অংশগুলোতে দেখবেন কীভাবে স্বয়ংক্রিয় ডেটা রূপান্তর, ডকুমেন্টেশন ইত্যাদি বজায় রেখেই এই কাস্টম `Response` ব্যবহার/ঘোষণা করা যায়।

/// check | সংক্ষেপে মনে রাখুন

* সাধারণত ডেটা ফেরত দিন, FastAPI নিজে JSON বানাবে। দ্রুততম উপায় রেসপন্স মডেল।
* `return Response(content=..., media_type=...)` দিলে FastAPI কিছুই বদলায় না, যাচাইও করে না।
* `JSONResponse`-এ দেওয়ার আগে Pydantic মডেলকে `jsonable_encoder` দিয়ে রূপান্তর করুন।
