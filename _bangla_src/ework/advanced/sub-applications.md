# সাব-অ্যাপ্লিকেশন - Mount { #sub-applications-mounts }

/// note | এই পেজে যা শিখবেন

* একটি FastAPI অ্যাপের ভেতরে আরেকটি সম্পূর্ণ আলাদা FastAPI অ্যাপ "mount" করা।
* প্রতিটির আলাদা ডকুমেন্টেশন পাওয়া।

///

আপনার যদি নিজস্ব স্বাধীন OpenAPI আর নিজস্ব ডকুমেন্টেশন UI-সহ দুটি স্বাধীন FastAPI অ্যাপ্লিকেশন দরকার হয়, তাহলে একটি মূল অ্যাপ রেখে এক (বা একাধিক) সাব-অ্যাপ্লিকেশন "mount" করতে পারেন।

/// tip | APIRouter নাকি mount?

* **APIRouter**: একই অ্যাপের অংশ, একটিই ডকুমেন্টেশন (`/docs`)-এ সব পাথ দেখায়। সাধারণত এটিই দরকার।
* **mount**: সম্পূর্ণ আলাদা অ্যাপ, নিজস্ব `/docs`, নিজস্ব সেটিংস। যেমন একটি পাবলিক API আর একটি আলাদা অভ্যন্তরীণ অ্যাডমিন API একই সার্ভারে।

///

## একটি **FastAPI** অ্যাপ্লিকেশন mount করা { #mounting-a-fastapi-application }

"Mount" করা মানে একটি নির্দিষ্ট পাথে একটি সম্পূর্ণ "স্বাধীন" অ্যাপ্লিকেশন যোগ করা, যা তারপর ওই সাব-অ্যাপ্লিকেশনে ঘোষিত _পাথ অপারেশন_ দিয়ে ওই পাথের নিচের সবকিছু সামলানোর দায়িত্ব নেয়।

আপনার সবচেয়ে ওপরের অ্যাপ্লিকেশন `app`-এ সাব-অ্যাপ্লিকেশন `subapi` mount করুন।

এই ক্ষেত্রে এটি `/subapi` পাথে mount হবে:

এখন `/app` সামলাবে মূল অ্যাপ, আর `/subapi/...` দিয়ে শুরু সব পাথ (যেমন `/subapi/sub`) সামলাবে সাব-অ্যাপ।

আপনি সাব-অ্যাপ্লিকেশনের স্বয়ংক্রিয় API ডকুমেন্টেশন দেখবেন, যাতে শুধু এর নিজস্ব _পাথ অপারেশনগুলো_ আছে, সবগুলো সঠিক সাব-পাথ prefix `/subapi`-এর অধীনে:

দুটি ইউজার ইন্টারফেসের যেকোনোটি ব্যবহার করে দেখলে সেগুলো সঠিকভাবে কাজ করবে, কারণ ব্রাউজার প্রতিটি নির্দিষ্ট অ্যাপ বা সাব-অ্যাপের সাথে কথা বলতে পারবে।

### কারিগরি বিবরণ: `root_path` { #technical-details-root-path }

ওপরে বর্ণিত উপায়ে একটি সাব-অ্যাপ্লিকেশন mount করলে, FastAPI ASGI স্পেসিফিকেশনের `root_path` নামের একটি ব্যবস্থা ব্যবহার করে সাব-অ্যাপ্লিকেশনকে তার mount পাথ জানানোর দায়িত্ব নেবে।

এভাবে সাব-অ্যাপ্লিকেশন জানবে যে ডকুমেন্টেশন UI-এর জন্য ওই পাথ prefix ব্যবহার করতে হবে।

আর সাব-অ্যাপ্লিকেশনেরও নিজস্ব mount করা সাব-অ্যাপ্লিকেশন থাকতে পারে, আর সবকিছু সঠিকভাবে কাজ করবে, কারণ FastAPI এই সব `root_path` স্বয়ংক্রিয়ভাবে সামলায়।

`root_path` আর এটি স্পষ্টভাবে কীভাবে ব্যবহার করতে হয় সে সম্পর্কে আরও শিখবেন [প্রক্সির পেছনে](behind-a-proxy.md) অংশে।

/// check | সংক্ষেপে মনে রাখুন

* `subapi = FastAPI()` বানিয়ে `app.mount("/subapi", subapi)`।
* সাব-অ্যাপের নিজস্ব ডকুমেন্টেশন থাকে `/subapi/docs`-এ।
* একই অ্যাপের অংশ ভাগ করতে চাইলে mount নয়, `APIRouter` ব্যবহার করুন।
