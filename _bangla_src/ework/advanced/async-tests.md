# অ্যাসিঙ্ক টেস্ট { #async-tests }

/// note | এই পেজে যা শিখবেন

* টেস্ট ফাংশনকে `async def` হিসেবে লেখা, যাতে টেস্টের ভেতরে `await` ব্যবহার করা যায়।
* `@pytest.mark.anyio` মার্কার কী করে।
* `TestClient`-এর বদলে HTTPX-এর `AsyncClient` দিয়ে রিকোয়েস্ট পাঠানো।

///

আপনি ইতিমধ্যে দেখেছেন দেওয়া `TestClient` দিয়ে কীভাবে আপনার **FastAPI** অ্যাপ্লিকেশন টেস্ট করতে হয়। এখন পর্যন্ত আপনি শুধু সিঙ্ক্রোনাস টেস্ট লেখা দেখেছেন, `async` ফাংশন ব্যবহার না করে।

টেস্টে অ্যাসিঙ্ক্রোনাস ফাংশন ব্যবহার করতে পারা কাজে লাগতে পারে, যেমন যখন আপনি অ্যাসিঙ্ক্রোনাসভাবে ডেটাবেসে কোয়েরি করছেন। ধরুন আপনি আপনার FastAPI অ্যাপ্লিকেশনে রিকোয়েস্ট পাঠিয়ে তারপর যাচাই করতে চান যে আপনার ব্যাকএন্ড ডেটাবেসে সঠিক ডেটা সফলভাবে লিখেছে, আর আপনি একটি অ্যাসিঙ্ক ডেটাবেস লাইব্রেরি ব্যবহার করছেন।

চলুন দেখি কীভাবে এটি কাজ করানো যায়।

/// tip | উদাহরণ দিয়ে বুঝি

`async`/`await` মানে "অপেক্ষার সময় অন্য কাজ করা" (বিস্তারিত দেখুন [Concurrency এবং async / await](../async.md))। সাধারণ (`def`) টেস্ট ফাংশনের ভেতরে `await` লেখা যায় না, ঠিক যেমন রান্নাঘরে না ঢুকে চুলায় ভাত বসানো যায় না। তাই টেস্টের ভেতরে অ্যাসিঙ্ক ডেটাবেস কল `await` করতে হলে টেস্ট ফাংশনকেও `async def` বানাতে হয়।

///

## pytest.mark.anyio { #pytest-mark-anyio }

টেস্টে অ্যাসিঙ্ক্রোনাস ফাংশন কল করতে চাইলে আমাদের টেস্ট ফাংশনগুলোকেও অ্যাসিঙ্ক্রোনাস হতে হবে। AnyIO এর জন্য একটি চমৎকার প্লাগইন দেয়, যা দিয়ে আমরা নির্দিষ্ট করে দিতে পারি যে কিছু টেস্ট ফাংশন অ্যাসিঙ্ক্রোনাসভাবে কল হবে।

## HTTPX { #httpx }

আপনার **FastAPI** অ্যাপ্লিকেশন `async def`-এর বদলে সাধারণ `def` ফাংশন ব্যবহার করলেও, ভেতরে এটি তবুও একটি `async` অ্যাপ্লিকেশন।

`TestClient` ভেতরে কিছু জাদু করে, যাতে সাধারণ pytest দিয়ে আপনার সাধারণ `def` টেস্ট ফাংশনে অ্যাসিঙ্ক্রোনাস FastAPI অ্যাপ্লিকেশন কল করা যায়। কিন্তু অ্যাসিঙ্ক্রোনাস ফাংশনের ভেতরে ব্যবহার করলে সেই জাদু আর কাজ করে না। টেস্ট অ্যাসিঙ্ক্রোনাসভাবে চালালে আমরা আর টেস্ট ফাংশনের ভেতরে `TestClient` ব্যবহার করতে পারি না।

`TestClient` তৈরি [HTTPX](https://www.python-httpx.org)-এর ওপর ভিত্তি করে, আর সৌভাগ্যক্রমে আমরা API টেস্ট করতে সরাসরি এটিই ব্যবহার করতে পারি।

`@pytest.mark.anyio` মার্কারটি pytest-কে বলে যে এই টেস্ট ফাংশনটি অ্যাসিঙ্ক্রোনাসভাবে কল করতে হবে:

{* ../../docs_src/async_tests/app_a_py310/test_main.py hl[7] *}

/// tip | পরামর্শ

লক্ষ্য করুন, টেস্ট ফাংশনটি এখন `async def`, `TestClient` ব্যবহারের সময়ের মতো শুধু `def` নয়।

///

তারপর অ্যাপ দিয়ে একটি `AsyncClient` তৈরি করে `await` ব্যবহার করে এটিতে অ্যাসিঙ্ক রিকোয়েস্ট পাঠাতে পারি।

{* ../../docs_src/async_tests/app_a_py310/test_main.py hl[9:12] *}

/// info | কোডটি সহজ ভাষায়

* লাইন ২: HTTPX থেকে `ASGITransport` আর `AsyncClient` ইমপোর্ট।
* লাইন ৭: `@pytest.mark.anyio` জানায় যে টেস্টটি অ্যাসিঙ্কভাবে চলবে।
* লাইন ৯–১০: `ASGITransport(app=app)` রিকোয়েস্টগুলো সত্যিকারের নেটওয়ার্কে না পাঠিয়ে সরাসরি আপনার FastAPI অ্যাপে পৌঁছে দেয়। `base_url="http://test"` শুধু একটি নামমাত্র ঠিকানা।
* লাইন ১২: `await ac.get("/")` রিকোয়েস্ট পাঠায় আর উত্তরের জন্য অপেক্ষা করে।
* লাইন ১৩–১৪: আগের মতোই `assert` দিয়ে status code আর JSON যাচাই।

///

এটি এর সমতুল্য:

```Python
response = client.get('/')
```

...যা দিয়ে আমরা `TestClient` ব্যবহার করে রিকোয়েস্ট পাঠাতাম।

/// tip | পরামর্শ

লক্ষ্য করুন, নতুন `AsyncClient`-এর সাথে আমরা async/await ব্যবহার করছি - রিকোয়েস্টটি অ্যাসিঙ্ক্রোনাস।

///

/// warning | সতর্কতা

আপনার অ্যাপ্লিকেশন যদি lifespan ইভেন্টের ওপর নির্ভর করে, তাহলে `AsyncClient` এই ইভেন্টগুলো চালু করবে না। এগুলো চালু নিশ্চিত করতে [florimondmanca/asgi-lifespan](https://github.com/florimondmanca/asgi-lifespan#usage) থেকে `LifespanManager` ব্যবহার করুন।

## অন্যান্য অ্যাসিঙ্ক্রোনাস ফাংশন কল { #other-asynchronous-function-calls }

যেহেতু টেস্ট ফাংশন এখন অ্যাসিঙ্ক্রোনাস, তাই টেস্টে আপনার FastAPI অ্যাপ্লিকেশনে রিকোয়েস্ট পাঠানো ছাড়াও অন্যান্য `async` ফাংশন কল (আর `await`) করতে পারেন, ঠিক যেমন কোডের অন্য যেকোনো জায়গায় করতেন।

/// tip | পরামর্শ

টেস্টে অ্যাসিঙ্ক্রোনাস ফাংশন কল যুক্ত করার সময় যদি `RuntimeError: Task attached to a different loop` পান (যেমন [MongoDB-এর MotorClient](https://stackoverflow.com/questions/41584243/runtimeerror-task-attached-to-a-different-loop) ব্যবহারের সময়), মনে রাখবেন যে event loop দরকার এমন অবজেক্টগুলো শুধু async ফাংশনের ভেতরেই তৈরি করুন, যেমন একটি `@app.on_event("startup")` কলব্যাকে।

///

/// check | সংক্ষেপে মনে রাখুন

* টেস্টের ভেতরে `await` লাগলে টেস্ট ফাংশনকে `async def` বানান আর `@pytest.mark.anyio` দিন।
* `TestClient`-এর বদলে `AsyncClient(transport=ASGITransport(app=app), base_url="http://test")` ব্যবহার করুন।
* `AsyncClient` lifespan চালায় না, দরকার হলে `LifespanManager` ব্যবহার করুন।
