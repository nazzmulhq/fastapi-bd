# রেসপন্স - স্ট্যাটাস কোড বদলানো { #response-change-status-code }

/// note | এই পেজে যা শিখবেন

* ফাংশনের ভেতরে পরিস্থিতি অনুযায়ী স্ট্যাটাস কোড বদলানো, অথচ `response_model`-এর সুবিধা বজায় রাখা।

///

আপনি হয়তো আগে পড়েছেন যে একটি ডিফল্ট [রেসপন্স স্ট্যাটাস কোড](../tutorial/response-status-code.md) সেট করা যায়।

কিন্তু কিছু ক্ষেত্রে ডিফল্টের চেয়ে ভিন্ন একটি স্ট্যাটাস কোড ফেরত দিতে হয়।

## ব্যবহারের ক্ষেত্র { #use-case }

যেমন, কল্পনা করুন আপনি ডিফল্টভাবে HTTP স্ট্যাটাস কোড "OK" `200` ফেরত দিতে চান।

কিন্তু ডেটা না থাকলে আপনি তা তৈরি করতে চান, আর HTTP স্ট্যাটাস কোড "CREATED" `201` ফেরত দিতে চান।

কিন্তু তবুও আপনি একটি `response_model` দিয়ে ফেরত দেওয়া ডেটা ফিল্টার আর রূপান্তর করতে পারতে চান।

এসব ক্ষেত্রে একটি `Response` প্যারামিটার ব্যবহার করতে পারেন।

## একটি `Response` প্যারামিটার ব্যবহার করুন { #use-a-response-parameter }

আপনার *পাথ অপারেশন ফাংশনে* `Response` টাইপের একটি প্যারামিটার ঘোষণা করতে পারেন (কুকি আর হেডারের ক্ষেত্রে যেমন করা যায়)।

তারপর ওই *অস্থায়ী* রেসপন্স অবজেক্টে `status_code` সেট করতে পারেন।

/// info | কোডটি সহজ ভাষায়

* লাইন ৮: ডিফল্ট স্ট্যাটাস কোড `200`।
* লাইন ১০-১২: টাস্ক না থাকলে তৈরি করা হয়, আর `response.status_code = status.HTTP_201_CREATED` দিয়ে স্ট্যাটাস কোড ২০১ করা হয়।
* লাইন ১৩: দুই ক্ষেত্রেই সাধারণ মান ফেরত।

তাই `/get-or-create-task/foo` (আগে থেকে আছে) → ২০০, `/get-or-create-task/new` (নতুন) → ২০১।

///

তারপর সাধারণত যেমন করেন, তেমনই প্রয়োজনীয় যেকোনো অবজেক্ট ফেরত দিতে পারেন (একটি `dict`, একটি ডেটাবেস মডেল ইত্যাদি)।

আর আপনি যদি একটি `response_model` ঘোষণা করে থাকেন, তাহলে ফেরত দেওয়া অবজেক্টটি ফিল্টার আর রূপান্তর করতে এটি তখনও ব্যবহার হবে।

**FastAPI** ওই *অস্থায়ী* রেসপন্স থেকে স্ট্যাটাস কোড (কুকি আর হেডারও) বের করে, আর আপনার ফেরত দেওয়া মানসহ চূড়ান্ত রেসপন্সে সেগুলো রাখবে, যেকোনো `response_model` দিয়ে ফিল্টার করে।

ডিপেন্ডেন্সিতেও `Response` প্যারামিটার ঘোষণা করে সেখানে স্ট্যাটাস কোড সেট করতে পারেন। তবে মনে রাখবেন, সবশেষে যেটি সেট করা হবে সেটিই জিতবে।

/// check | সংক্ষেপে মনে রাখুন

* `response: Response` প্যারামিটার নিয়ে `response.status_code = 201` এর মতো সেট করুন।
* ফেরত দেওয়া ডেটা তখনও `response_model` দিয়ে যাচাই ও ফিল্টার হয়, যা সরাসরি `JSONResponse` ফেরত দিলে হতো না।
