# অ্যাডভান্সড ইউজার গাইড { #advanced-user-guide }

/// note | এই অংশে যা পাবেন

টিউটোরিয়ালের বাইরে বিশেষ প্রয়োজনের সমাধান: কাস্টম রেসপন্স, কুকি ও হেডার, উন্নত ডিপেন্ডেন্সি, OAuth2 scope, প্রক্সির পেছনে চালানো, টেমপ্লেট, WebSocket, লাইফস্প্যান ইভেন্ট, সেটিংস, টেস্টিংয়ের উন্নত কৌশল, ক্লায়েন্ট কোড তৈরি ইত্যাদি। প্রতিটি পেজ আলাদাভাবে পড়া যায়, দরকার অনুযায়ী বেছে নিন।

///

## বাড়তি ফিচার { #additional-features }

মূল [টিউটোরিয়াল - ইউজার গাইড](../tutorial/index.md) **FastAPI**-এর সব প্রধান ফিচারের সাথে পরিচয় করিয়ে দেওয়ার জন্য যথেষ্ট হওয়া উচিত।

পরের অংশগুলোতে আপনি আরও অপশন, কনফিগারেশন আর বাড়তি ফিচার দেখবেন।

/// tip | পরামর্শ

পরের অংশগুলো **যে খুব "অ্যাডভান্সড" (কঠিন) তা কিন্তু নয়**।

আর হতে পারে আপনার নির্দিষ্ট প্রয়োজনের সমাধান এগুলোর কোনো একটিতেই আছে। তাই ভয় না পেয়ে বাম পাশের তালিকা থেকে শিরোনামগুলো একবার দেখে নিন।

///

## আগে টিউটোরিয়াল পড়ুন { #read-the-tutorial-first }

মূল [টিউটোরিয়াল - ইউজার গাইড](../tutorial/index.md)-এর জ্ঞান দিয়েই আপনি **FastAPI**-এর বেশিরভাগ ফিচার ব্যবহার করতে পারবেন।

আর পরের অংশগুলো ধরে নেয় যে আপনি সেটি ইতিমধ্যে পড়েছেন, আর সেই মূল ধারণাগুলো জানেন।

/// check | সংক্ষেপে মনে রাখুন

* আগে টিউটোরিয়াল শেষ করুন, তারপর দরকার অনুযায়ী অ্যাডভান্সড গাইডের পেজগুলো দেখুন।
* অপরিচিত শব্দ পেলে [সহজ শব্দকোষ](../learn/glossary.md) দেখুন।
