# বাড়তি স্ট্যাটাস কোড { #additional-status-codes }

/// note | এই পেজে যা শিখবেন

* একই পাথ অপারেশন থেকে পরিস্থিতি অনুযায়ী ভিন্ন ভিন্ন সফল স্ট্যাটাস কোড (যেমন ২০০ বা ২০১) ফেরত দেওয়া।

///

ডিফল্টভাবে **FastAPI** একটি `JSONResponse` ব্যবহার করে রেসপন্স ফেরত দেয়, আপনার *পাথ অপারেশন* থেকে ফেরত দেওয়া বিষয়বস্তু ওই `JSONResponse`-এর ভেতরে রেখে।

এটি ডিফল্ট স্ট্যাটাস কোড, অথবা আপনার *পাথ অপারেশনে* সেট করা কোডটি ব্যবহার করবে।

## বাড়তি স্ট্যাটাস কোড { #additional-status-codes_1 }

মূল স্ট্যাটাস কোড ছাড়াও যদি আরও স্ট্যাটাস কোড ফেরত দিতে চান, তাহলে সরাসরি একটি `Response`, যেমন একটি `JSONResponse`, ফেরত দিয়ে বাড়তি স্ট্যাটাস কোডটি সরাসরি সেট করতে পারেন।

যেমন, ধরা যাক আপনি এমন একটি *পাথ অপারেশন* চান যা আইটেম আপডেট করতে দেয়, আর সফল হলে HTTP স্ট্যাটাস কোড ২০০ "OK" ফেরত দেয়।

কিন্তু আপনি চান এটি নতুন আইটেমও গ্রহণ করুক। আর আইটেমগুলো আগে না থাকলে এটি সেগুলো তৈরি করে, আর HTTP স্ট্যাটাস কোড ২০১ "Created" ফেরত দেয়। (এই ধরনকে বলা হয় "upsert" = update + insert।)

এটি করতে `JSONResponse` ইমপোর্ট করুন, আর আপনার বিষয়বস্তু সরাসরি সেখানে ফেরত দিন, যে `status_code` চান সেটি সেট করে:

{* ../../docs_src/additional_status_codes/tutorial001_an_py310.py hl[4,25] *}

/// info | কোডটি সহজ ভাষায়

* লাইন ১৭-২১: আইটেম আগে থেকে থাকলে হালনাগাদ করে সাধারণভাবে ফেরত, তাই ডিফল্ট ২০০।
* লাইন ২২-২৫: না থাকলে নতুন তৈরি করে `JSONResponse(status_code=201, content=item)` সরাসরি ফেরত, তাই ২০১।

///

/// warning | সতর্কতা

ওপরের উদাহরণের মতো সরাসরি একটি `Response` ফেরত দিলে, সেটি সরাসরিই ফেরত যাবে।

এটি কোনো মডেল দিয়ে সিরিয়ালাইজ হবে না, ইত্যাদি।

নিশ্চিত করুন যে এতে আপনার কাঙ্ক্ষিত ডেটা আছে, আর মানগুলো বৈধ JSON (যদি `JSONResponse` ব্যবহার করেন)।

///

/// note | কারিগরি বিবরণ

`from starlette.responses import JSONResponse`-ও ব্যবহার করতে পারতেন।

**FastAPI** ডেভেলপার হিসেবে আপনার সুবিধার জন্যই একই `starlette.responses`-কে `fastapi.responses` হিসেবে দেয়। কিন্তু উপলব্ধ বেশিরভাগ রেসপন্স সরাসরি Starlette থেকে আসে। `status`-এর ক্ষেত্রেও একই কথা।

///

## OpenAPI আর API ডকুমেন্টেশন { #openapi-and-api-docs }

আপনি যদি বাড়তি স্ট্যাটাস কোড আর রেসপন্স সরাসরি ফেরত দেন, তাহলে সেগুলো OpenAPI স্কিমাতে (API ডকুমেন্টেশনে) অন্তর্ভুক্ত হবে না, কারণ আপনি কী ফেরত দেবেন তা আগে থেকে জানার কোনো উপায় FastAPI-এর নেই।

তবে আপনি আপনার কোডে সেটি ডকুমেন্ট করতে পারেন, এটি ব্যবহার করে: [বাড়তি রেসপন্স](additional-responses.md)।

/// check | সংক্ষেপে মনে রাখুন

* ভিন্ন স্ট্যাটাস কোড দিতে `return JSONResponse(status_code=201, content=...)`।
* সরাসরি `Response` ফেরত দিলে FastAPI যাচাই বা রূপান্তর করে না, আর ডকুমেন্টেশনে নিজে থেকে আসে না।
