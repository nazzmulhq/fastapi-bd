# রেসপন্স কুকি { #response-cookies }

## একটি `Response` প্যারামিটার ব্যবহার করুন { #use-a-response-parameter }

আপনার *পাথ অপারেশন ফাংশনে* আপনি `Response` টাইপের একটি প্যারামিটার ঘোষণা করতে পারেন।

তারপর ওই *অস্থায়ী* রেসপন্স অবজেক্টে আপনি কুকি সেট করতে পারেন।

{* ../../docs_src/response_cookies/tutorial002_py310.py hl[1, 8:9] *}

তারপর আপনি স্বাভাবিকভাবেই যেকোনো প্রয়োজনীয় অবজেক্ট রিটার্ন করতে পারেন (একটি `dict`, একটি ডেটাবেস মডেল ইত্যাদি)।

আর আপনি যদি একটি `response_model` ঘোষণা করে থাকেন, তাহলে আপনার রিটার্ন করা অবজেক্ট ফিল্টার ও রূপান্তর করতে সেটি তখনও ব্যবহার হবে।

**FastAPI** ওই *অস্থায়ী* রেসপন্স থেকে কুকিগুলো (এবং হেডার ও স্ট্যাটাস কোডও) বের করবে, এবং সেগুলো চূড়ান্ত রেসপন্সে রাখবে, যাতে যেকোনো `response_model` দিয়ে ফিল্টার করা আপনার রিটার্ন করা ভ্যালুটি থাকবে।

আপনি ডিপেন্ডেন্সিতেও `Response` প্যারামিটার ঘোষণা করে সেগুলোতে কুকি (এবং হেডার) সেট করতে পারেন।

## সরাসরি একটি `Response` রিটার্ন করুন { #return-a-response-directly }

আপনার কোডে সরাসরি একটি `Response` রিটার্ন করার সময়ও আপনি কুকি তৈরি করতে পারেন।

এটি করতে [সরাসরি একটি Response রিটার্ন করুন](response-directly.md)-এ বর্ণিত উপায়ে একটি রেসপন্স তৈরি করতে পারেন।

তারপর এতে কুকি সেট করে রিটার্ন করুন:

{* ../../docs_src/response_cookies/tutorial001_py310.py hl[10:12] *}

/// tip | পরামর্শ

মনে রাখবেন, `Response` প্যারামিটার ব্যবহার না করে আপনি যদি সরাসরি একটি রেসপন্স রিটার্ন করেন, তাহলে FastAPI সেটি সরাসরি রিটার্ন করবে।

তাই আপনাকে নিশ্চিত করতে হবে যে আপনার ডেটা সঠিক টাইপের। যেমন, আপনি যদি একটি `JSONResponse` রিটার্ন করেন, তাহলে এটি JSON-এর সাথে সামঞ্জস্যপূর্ণ।

আর এটাও নিশ্চিত করতে হবে যে আপনি এমন কোনো ডেটা পাঠাচ্ছেন না যা একটি `response_model` দিয়ে ফিল্টার হওয়া উচিত ছিল।

### আরও তথ্য { #more-info }

/// note | কারিগরি বিবরণ

আপনি `from starlette.responses import Response` বা `from starlette.responses import JSONResponse`-ও ব্যবহার করতে পারতেন।

**FastAPI** শুধু আপনার, অর্থাৎ ডেভেলপারের সুবিধার জন্য একই `starlette.responses`-কে `fastapi.responses` হিসেবে দেয়। তবে উপলব্ধ বেশিরভাগ রেসপন্স সরাসরি Starlette থেকে আসে।

আর যেহেতু হেডার ও কুকি সেট করতে `Response` প্রায়ই ব্যবহার হতে পারে, তাই **FastAPI** এটি `fastapi.Response`-এও দেয়।
