# ওভাররাইড দিয়ে ডিপেন্ডেন্সি টেস্টিং { #testing-dependencies-with-overrides }

## টেস্টিংয়ের সময় ডিপেন্ডেন্সি ওভাররাইড করা { #overriding-dependencies-during-testing }

কিছু পরিস্থিতিতে আপনি হয়তো টেস্টিংয়ের সময় একটি ডিপেন্ডেন্সি ওভাররাইড করতে চাইবেন।

আপনি চান না মূল ডিপেন্ডেন্সিটি চলুক (বা এর থাকতে পারে এমন কোনো সাব-ডিপেন্ডেন্সিও)।

তার বদলে আপনি একটি ভিন্ন ডিপেন্ডেন্সি দিতে চান যা কেবল টেস্টের সময় (সম্ভবত কেবল কিছু নির্দিষ্ট টেস্টে) ব্যবহার হবে, এবং এমন একটি ভ্যালু দেবে যা মূল ডিপেন্ডেন্সির ভ্যালু যেখানে ব্যবহার হতো সেখানে ব্যবহার করা যায়।

### ব্যবহারের ক্ষেত্র: বাহ্যিক সার্ভিস { #use-cases-external-service }

একটি উদাহরণ হতে পারে, আপনার একটি বাহ্যিক অথেনটিকেশন প্রোভাইডার আছে যাকে আপনার কল করতে হয়।

আপনি এটিকে একটি টোকেন পাঠান এবং এটি একজন অথেনটিকেটেড ইউজার রিটার্ন করে।

এই প্রোভাইডার হয়তো প্রতি রিকোয়েস্টে আপনার কাছ থেকে টাকা নেয়, আর টেস্টের জন্য একটি নির্দিষ্ট নকল ইউজার রাখার তুলনায় এটি কল করতে কিছু বাড়তি সময় লাগতে পারে।

আপনি সম্ভবত বাহ্যিক প্রোভাইডারটি একবার টেস্ট করতে চান, কিন্তু চলা প্রতিটি টেস্টের জন্য এটি কল করার প্রয়োজন নেই।

এক্ষেত্রে আপনি ওই প্রোভাইডারকে কল করা ডিপেন্ডেন্সিটি ওভাররাইড করতে পারেন, এবং কেবল আপনার টেস্টের জন্য একটি নকল ইউজার রিটার্ন করা একটি কাস্টম ডিপেন্ডেন্সি ব্যবহার করতে পারেন।

### `app.dependency_overrides` অ্যাট্রিবিউট ব্যবহার করুন { #use-the-app-dependency-overrides-attribute }

এসব ক্ষেত্রের জন্য আপনার **FastAPI** অ্যাপ্লিকেশনের একটি অ্যাট্রিবিউট আছে `app.dependency_overrides`, এটি একটি সাধারণ `dict`।

টেস্টিংয়ের জন্য একটি ডিপেন্ডেন্সি ওভাররাইড করতে কী হিসেবে মূল ডিপেন্ডেন্সিটি (একটি ফাংশন) এবং ভ্যালু হিসেবে আপনার ডিপেন্ডেন্সি ওভাররাইড (আরেকটি ফাংশন) রাখুন।

আর তখন **FastAPI** মূল ডিপেন্ডেন্সির বদলে ওই ওভাররাইডটি কল করবে।

/// tip | পরামর্শ

আপনার **FastAPI** অ্যাপ্লিকেশনের যেকোনো জায়গায় ব্যবহৃত একটি ডিপেন্ডেন্সির জন্য আপনি একটি ডিপেন্ডেন্সি ওভাররাইড সেট করতে পারেন।

মূল ডিপেন্ডেন্সিটি একটি *পাথ অপারেশন ফাংশনে*, একটি *পাথ অপারেশন ডেকোরেটরে* (যখন আপনি রিটার্ন ভ্যালু ব্যবহার করেন না), একটি `.include_router()` কলে ইত্যাদিতে ব্যবহার হতে পারে।

FastAPI তবুও এটি ওভাররাইড করতে পারবে।
