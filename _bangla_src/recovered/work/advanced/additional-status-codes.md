# অতিরিক্ত স্ট্যাটাস কোড { #additional-status-codes }

ডিফল্টভাবে **FastAPI** একটি `JSONResponse` ব্যবহার করে রেসপন্স রিটার্ন করবে, আপনার *পাথ অপারেশন* থেকে রিটার্ন করা কনটেন্টটি ওই `JSONResponse`-এর ভেতরে রেখে।

এটি ডিফল্ট স্ট্যাটাস কোড ব্যবহার করবে, অথবা আপনার *পাথ অপারেশনে* আপনি যেটি সেট করেছেন সেটি।

## অতিরিক্ত স্ট্যাটাস কোড { #additional-status-codes_1 }

আপনি যদি প্রধান স্ট্যাটাস কোড ছাড়াও অতিরিক্ত স্ট্যাটাস কোড রিটার্ন করতে চান, তাহলে সরাসরি একটি `Response` রিটার্ন করে, যেমন একটি `JSONResponse`, এবং সরাসরি অতিরিক্ত স্ট্যাটাস কোড সেট করে তা করতে পারেন।

যেমন, ধরা যাক আপনি এমন একটি *পাথ অপারেশন* চান যা আইটেম আপডেট করতে দেয়, এবং সফল হলে 200 "OK" HTTP স্ট্যাটাস কোড রিটার্ন করে।

কিন্তু আপনি এটাও চান যে এটি নতুন আইটেম গ্রহণ করুক। আর আইটেমগুলো আগে না থাকলে এটি সেগুলো তৈরি করে এবং 201 "Created" HTTP স্ট্যাটাস কোড রিটার্ন করে।

এটি অর্জন করতে `JSONResponse` ইম্পোর্ট করুন, এবং আপনার পছন্দের `status_code` সেট করে সরাসরি সেখানে আপনার কনটেন্ট রিটার্ন করুন:

আপনি যখন সরাসরি একটি `Response` রিটার্ন করেন, যেমন ওপরের উদাহরণে, তখন এটি সরাসরি রিটার্ন হবে।

এটি কোনো মডেল ইত্যাদি দিয়ে সিরিয়ালাইজ হবে না।

নিশ্চিত করুন যে এতে আপনার কাঙ্ক্ষিত ডেটা আছে, এবং ভ্যালুগুলো বৈধ JSON (আপনি যদি `JSONResponse` ব্যবহার করেন)।

/// note | কারিগরি বিবরণ

আপনি `from starlette.responses import JSONResponse`-ও ব্যবহার করতে পারতেন।

**FastAPI** শুধু আপনার, অর্থাৎ ডেভেলপারের সুবিধার জন্য একই `starlette.responses`-কে `fastapi.responses` হিসেবে দেয়। তবে উপলব্ধ বেশিরভাগ রেসপন্স সরাসরি Starlette থেকে আসে। `status`-এর ক্ষেত্রেও তাই।

## OpenAPI ও API ডকুমেন্টেশন { #openapi-and-api-docs }

আপনি যদি সরাসরি অতিরিক্ত স্ট্যাটাস কোড ও রেসপন্স রিটার্ন করেন, তাহলে সেগুলো OpenAPI স্কিমায় (API ডকুমেন্টেশনে) অন্তর্ভুক্ত হবে না, কারণ আপনি কী রিটার্ন করবেন তা আগে থেকে জানার কোনো উপায় FastAPI-এর নেই।

তবে আপনি আপনার কোডে এটি ডকুমেন্ট করতে পারেন, এটি ব্যবহার করে: [অতিরিক্ত রেসপন্স](additional-responses.md)।
