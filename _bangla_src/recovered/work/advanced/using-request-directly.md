# সরাসরি Request ব্যবহার { #using-the-request-directly }

এ পর্যন্ত আপনি রিকোয়েস্টের প্রয়োজনীয় অংশগুলো তাদের টাইপসহ ঘোষণা করে এসেছেন।

ডেটা নিয়েছেন:

* প্যারামিটার হিসেবে পাথ থেকে।
* হেডার থেকে।
* কুকি থেকে।
* ইত্যাদি।

আর এভাবে করে **FastAPI** স্বয়ংক্রিয়ভাবে সেই ডেটা ভ্যালিডেট করছে, রূপান্তর করছে এবং আপনার API-এর জন্য ডকুমেন্টেশন তৈরি করছে।

তবে এমন পরিস্থিতি আছে যেখানে আপনাকে সরাসরি `Request` অবজেক্ট অ্যাক্সেস করতে হতে পারে।

## `Request` অবজেক্ট সম্পর্কে বিবরণ { #details-about-the-request-object }

যেহেতু **FastAPI** আসলে ভেতরে ভেতরে **Starlette**, ওপরে কিছু টুলের একটি স্তরসহ, তাই প্রয়োজন হলে আপনি সরাসরি Starlette-এর [`Request`](https://starlette.dev/requests/) অবজেক্ট ব্যবহার করতে পারেন।

এর মানে এটাও যে আপনি যদি সরাসরি `Request` অবজেক্ট থেকে ডেটা নেন (যেমন বডি পড়েন), তাহলে FastAPI সেটি ভ্যালিডেট, রূপান্তর বা ডকুমেন্ট (OpenAPI দিয়ে, স্বয়ংক্রিয় API ইউজার ইন্টারফেসের জন্য) করবে না।

যদিও স্বাভাবিকভাবে ঘোষিত অন্য যেকোনো প্যারামিটার (যেমন Pydantic মডেলসহ বডি) তখনও ভ্যালিডেট, রূপান্তর, অ্যানোটেট ইত্যাদি হবে।

তবে নির্দিষ্ট কিছু ক্ষেত্রে `Request` অবজেক্ট পাওয়া কাজে আসে।

## সরাসরি `Request` অবজেক্ট ব্যবহার করুন { #use-the-request-object-directly }

কল্পনা করা যাক আপনি আপনার *পাথ অপারেশন ফাংশনের* ভেতরে ক্লায়েন্টের IP ঠিকানা/হোস্ট পেতে চান।

এর জন্য আপনাকে সরাসরি রিকোয়েস্ট অ্যাক্সেস করতে হবে।

{* ../../docs_src/using_request_directly/tutorial001_py310.py hl[1,7:8] *}

`Request` টাইপসহ একটি *পাথ অপারেশন ফাংশনের* প্যারামিটার ঘোষণা করলে **FastAPI** জানবে যে ওই প্যারামিটারে `Request` পাঠাতে হবে।

/// tip | পরামর্শ

লক্ষ করুন, এক্ষেত্রে আমরা রিকোয়েস্ট প্যারামিটারের পাশাপাশি একটি পাথ প্যারামিটারও ঘোষণা করছি।

তাই পাথ প্যারামিটারটি বের করা হবে, ভ্যালিডেট হবে, নির্দিষ্ট টাইপে রূপান্তরিত হবে এবং OpenAPI দিয়ে অ্যানোটেট হবে।

একইভাবে আপনি অন্য যেকোনো প্যারামিটার স্বাভাবিকভাবে ঘোষণা করতে পারেন, এবং সাথে `Request`-ও পেতে পারেন।

///

## `Request` ডকুমেন্টেশন { #request-documentation }

[অফিসিয়াল Starlette ডকুমেন্টেশন সাইটে `Request` অবজেক্ট](https://starlette.dev/requests/) সম্পর্কে আরও বিস্তারিত পড়তে পারেন।

/// note | কারিগরি বিবরণ

আপনি `from starlette.requests import Request`-ও ব্যবহার করতে পারতেন।

**FastAPI** এটি শুধু আপনার, অর্থাৎ ডেভেলপারের সুবিধার জন্য সরাসরি দেয়। তবে এটি সরাসরি Starlette থেকে আসে।
