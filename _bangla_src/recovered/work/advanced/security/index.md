# অ্যাডভান্সড সিকিউরিটি { #advanced-security }

## অতিরিক্ত ফিচার { #additional-features }

[টিউটোরিয়াল - ইউজার গাইড: সিকিউরিটি](../../tutorial/security/index.md)-এ আলোচিত ফিচারগুলো ছাড়াও সিকিউরিটি সামলানোর জন্য আরও কিছু অতিরিক্ত ফিচার আছে।

/// tip | পরামর্শ

পরের অংশগুলো **অবশ্যই "অ্যাডভান্সড" নয়**।

আর এমনও হতে পারে যে আপনার ব্যবহারের ক্ষেত্রের সমাধান এগুলোর কোনো একটিতে আছে।

///

## প্রথমে টিউটোরিয়াল পড়ুন { #read-the-tutorial-first }

পরের অংশগুলো ধরে নেয় যে আপনি মূল [টিউটোরিয়াল - ইউজার গাইড: সিকিউরিটি](../../tutorial/security/index.md) ইতিমধ্যে পড়েছেন।

এগুলো সবই একই ধারণার ওপর ভিত্তি করে তৈরি, তবে কিছু অতিরিক্ত কার্যকারিতা দেয়।
