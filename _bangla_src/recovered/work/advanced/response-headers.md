# রেসপন্স হেডার { #response-headers }

## একটি `Response` প্যারামিটার ব্যবহার করুন { #use-a-response-parameter }

আপনার *পাথ অপারেশন ফাংশনে* আপনি `Response` টাইপের একটি প্যারামিটার ঘোষণা করতে পারেন (যেমনটা কুকির জন্য করতে পারেন)।

তারপর ওই *অস্থায়ী* রেসপন্স অবজেক্টে আপনি হেডার সেট করতে পারেন।

{* ../../docs_src/response_headers/tutorial002_py310.py hl[1, 7:8] *}

তারপর আপনি স্বাভাবিকভাবেই যেকোনো প্রয়োজনীয় অবজেক্ট রিটার্ন করতে পারেন (একটি `dict`, একটি ডেটাবেস মডেল ইত্যাদি)।

আর আপনি যদি একটি `response_model` ঘোষণা করে থাকেন, তাহলে আপনার রিটার্ন করা অবজেক্ট ফিল্টার ও রূপান্তর করতে সেটি তখনও ব্যবহার হবে।

**FastAPI** ওই *অস্থায়ী* রেসপন্স থেকে হেডারগুলো (এবং কুকি ও স্ট্যাটাস কোডও) বের করবে, এবং সেগুলো চূড়ান্ত রেসপন্সে রাখবে, যাতে যেকোনো `response_model` দিয়ে ফিল্টার করা আপনার রিটার্ন করা ভ্যালুটি থাকবে।

আপনি ডিপেন্ডেন্সিতেও `Response` প্যারামিটার ঘোষণা করে সেগুলোতে হেডার (এবং কুকি) সেট করতে পারেন।

## সরাসরি একটি `Response` রিটার্ন করুন { #return-a-response-directly }

সরাসরি একটি `Response` রিটার্ন করার সময়ও আপনি হেডার যোগ করতে পারেন।

**FastAPI** শুধু আপনার, অর্থাৎ ডেভেলপারের সুবিধার জন্য একই `starlette.responses`-কে `fastapi.responses` হিসেবে দেয়। তবে উপলব্ধ বেশিরভাগ রেসপন্স সরাসরি Starlette থেকে আসে।

## কাস্টম হেডার { #custom-headers }

মনে রাখবেন, কাস্টম মালিকানাধীন হেডার [`X-` উপসর্গ ব্যবহার করে](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers) যোগ করা যায়।

তবে আপনার যদি এমন কাস্টম হেডার থাকে যা আপনি চান একটি ব্রাউজারের ক্লায়েন্ট দেখতে পাক, তাহলে [Starlette-এর CORS ডকুমেন্টেশনে](https://starlette.dev/middleware/#corsmiddleware) ডকুমেন্ট করা `expose_headers` প্যারামিটার ব্যবহার করে সেগুলো আপনার CORS কনফিগারেশনে যোগ করতে হবে (আরও পড়ুন [CORS (Cross-Origin Resource Sharing)](../tutorial/cors.md)-এ)।
