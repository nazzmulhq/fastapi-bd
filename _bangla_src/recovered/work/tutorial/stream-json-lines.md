আপনার কাছে হয়তো ডেটার এমন একটি ক্রম আছে যা আপনি একটি "**স্ট্রিম**"-এ পাঠাতে চান, তাহলে এটি **JSON Lines** দিয়ে করতে পারেন।

FastAPI 0.134.0-এ যোগ করা হয়েছে।

## স্ট্রিম কী? { #what-is-a-stream }

ডেটা "**স্ট্রিমিং**" মানে আপনার অ্যাপ আইটেমগুলোর পুরো ক্রম তৈরি হওয়ার অপেক্ষা না করেই ক্লায়েন্টকে ডেটা আইটেম পাঠানো শুরু করবে।

তাই এটি প্রথম আইটেমটি পাঠাবে, ক্লায়েন্ট সেটি পেয়ে প্রসেস করা শুরু করবে, আর আপনি হয়তো তখনও পরের আইটেমটি তৈরি করছেন।

⟦CODE1⟧

এটি এমনকি একটি অসীম স্ট্রিমও হতে পারে, যেখানে আপনি ক্রমাগত ডেটা পাঠিয়ে যান।

## JSON Lines { #json-lines }

এসব ক্ষেত্রে "**JSON Lines**" পাঠানো প্রচলিত, যা এমন একটি ফরম্যাট যেখানে আপনি প্রতি লাইনে একটি JSON অবজেক্ট পাঠান।

একটি রেসপন্সের কনটেন্ট টাইপ হবে `application/jsonl` (`application/json`-এর বদলে) এবং বডি হবে এরকম কিছু:

⟦CODE2⟧

এটি একটি JSON অ্যারের (Python লিস্টের সমতুল্য) খুবই অনুরূপ, তবে `[]`-এ মোড়ানো এবং আইটেমগুলোর মাঝে `,` থাকার বদলে এতে **প্রতি লাইনে একটি JSON অবজেক্ট** থাকে, সেগুলো একটি নতুন লাইন অক্ষর দিয়ে আলাদা করা।

/// note | নোট

গুরুত্বপূর্ণ বিষয় হলো, ক্লায়েন্ট আগের লাইনগুলো গ্রহণ করতে থাকার সময়েই আপনার অ্যাপ একে একে প্রতিটি লাইন তৈরি করতে পারবে।

///

/// note | কারিগরি বিবরণ

যেহেতু প্রতিটি JSON অবজেক্ট একটি নতুন লাইন দিয়ে আলাদা থাকবে, তাই এগুলোর বিষয়বস্তুতে আক্ষরিক নতুন লাইন অক্ষর থাকতে পারে না, তবে এস্কেপ করা নতুন লাইন (`\n`) থাকতে পারে, যা JSON স্ট্যান্ডার্ডের অংশ।

তবে সাধারণত এ নিয়ে আপনাকে চিন্তা করতে হবে না, এটি স্বয়ংক্রিয়ভাবে হয়ে যায়, পড়তে থাকুন। 🤓

## ব্যবহারের ক্ষেত্র { #use-cases }

**AI LLM** সার্ভিস থেকে, **লগ** বা **টেলিমেট্রি** থেকে, অথবা **JSON** আইটেমে সাজানো যায় এমন অন্যান্য ধরনের ডেটা স্ট্রিম করতে আপনি এটি ব্যবহার করতে পারেন।

## FastAPI দিয়ে JSON Lines স্ট্রিম করুন { #stream-json-lines-with-fastapi }

FastAPI দিয়ে JSON Lines স্ট্রিম করতে আপনার *পাথ অপারেশন ফাংশনে* `return` ব্যবহারের বদলে একে একে প্রতিটি আইটেম তৈরি করতে `yield` ব্যবহার করতে পারেন।

আপনি যে প্রতিটি JSON আইটেম ফেরত পাঠাতে চান তা যদি `Item` (একটি Pydantic মডেল) টাইপের হয় এবং ফাংশনটি async হয়, তাহলে রিটার্ন টাইপ `AsyncIterable[Item]` হিসেবে ঘোষণা করতে পারেন:

{* ../../docs_src/stream_json_lines/tutorial001_py310.py ln[1:24] hl[9:11,22] *}

আপনি রিটার্ন টাইপ ঘোষণা করলে FastAPI এটি ব্যবহার করে Pydantic দিয়ে ডেটা **ভ্যালিডেট** করবে, OpenAPI-তে **ডকুমেন্ট** করবে, **ফিল্টার** করবে এবং **সিরিয়ালাইজ** করবে।

/// tip | পরামর্শ

যেহেতু Pydantic এটি **Rust**-এর দিকে সিরিয়ালাইজ করবে, তাই রিটার্ন টাইপ ঘোষণা না করার তুলনায় আপনি অনেক বেশি **পারফরম্যান্স** পাবেন।
