# কুয়েরি প্যারামিটার { #query-parameters }

আপনি যখন এমন অন্য ফাংশন প্যারামিটার ঘোষণা করেন যেগুলো পাথ প্যারামিটারের অংশ নয়, তখন সেগুলো স্বয়ংক্রিয়ভাবে "কুয়েরি" প্যারামিটার হিসেবে ধরা হয়।

{* ../../docs_src/query_params/tutorial001_py310.py hl[9] *}

কুয়েরি হলো একটি URL-এ `?`-এর পরে আসা কী-ভ্যালু জোড়ার সেট, যেগুলো `&` চিহ্ন দিয়ে আলাদা করা থাকে।

যেমন, এই URL-এ:

⟦CODE1⟧

...কুয়েরি প্যারামিটারগুলো হলো:

* `skip`: যার ভ্যালু `0`
* `limit`: যার ভ্যালু `10`

যেহেতু এগুলো URL-এর অংশ, তাই এগুলো "স্বাভাবিকভাবেই" স্ট্রিং।

কিন্তু আপনি যখন এগুলো Python টাইপ দিয়ে ঘোষণা করেন (ওপরের উদাহরণে `int` হিসেবে), তখন এগুলো ওই টাইপে রূপান্তরিত হয় এবং সেই অনুযায়ী ভ্যালিডেট হয়।

পাথ প্যারামিটারের ক্ষেত্রে যে প্রক্রিয়াগুলো প্রযোজ্য, কুয়েরি প্যারামিটারের ক্ষেত্রেও সেগুলোই প্রযোজ্য:

* এডিটর সাপোর্ট (অবশ্যই)
* ডেটা <dfn title="HTTP রিকোয়েস্ট থেকে আসা স্ট্রিংকে Python ডেটায় রূপান্তর করা">"পার্সিং"</dfn>
* ডেটা ভ্যালিডেশন
* স্বয়ংক্রিয় ডকুমেন্টেশন

## ডিফল্ট { #defaults }

যেহেতু কুয়েরি প্যারামিটার পাথের নির্দিষ্ট অংশ নয়, তাই এগুলো ঐচ্ছিক হতে পারে এবং এগুলোর ডিফল্ট ভ্যালু থাকতে পারে।

ওপরের উদাহরণে এগুলোর ডিফল্ট ভ্যালু হলো `skip=0` এবং `limit=10`।

আর এখানে যাওয়া একই হবে:

⟦CODE3⟧

কিন্তু আপনি যদি যান, ধরা যাক, এখানে:

⟦CODE4⟧

তাহলে আপনার ফাংশনে প্যারামিটারের ভ্যালুগুলো হবে:

* `skip=20`: কারণ আপনি এটি URL-এ সেট করেছেন
* `limit=10`: কারণ সেটাই ছিল ডিফল্ট ভ্যালু

আরও লক্ষ করুন, **FastAPI** যথেষ্ট বুদ্ধিমান, তাই এটি বুঝতে পারে যে পাথ প্যারামিটার `item_id` একটি পাথ প্যারামিটার আর `q` তা নয়, তাই এটি একটি কুয়েরি প্যারামিটার।
