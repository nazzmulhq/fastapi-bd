## নেস্টেড মডেল { #nested-models }

কিন্তু সেই টাইপ নিজেই আরেকটি Pydantic মডেল হতে পারে।

তাই আপনি নির্দিষ্ট অ্যাট্রিবিউটের নাম, টাইপ ও ভ্যালিডেশনসহ গভীরভাবে নেস্টেড JSON "অবজেক্ট" ঘোষণা করতে পারেন।

## বিশেষ টাইপ ও ভ্যালিডেশন { #special-types-and-validation }

`str`, `int`, `float` ইত্যাদির মতো সাধারণ একক টাইপ ছাড়াও আপনি `str` থেকে ইনহেরিট করা আরও জটিল একক টাইপ ব্যবহার করতে পারেন।

আপনার কাছে কী কী অপশন আছে তা দেখতে [Pydantic-এর টাইপ ওভারভিউ](https://pydantic.dev/docs/validation/latest/concepts/types/) দেখুন। পরের অধ্যায়ে আপনি কিছু উদাহরণ দেখবেন।

তবে সেগুলো নিয়েও আপনাকে চিন্তা করতে হবে না, আগত dict-গুলো স্বয়ংক্রিয়ভাবে রূপান্তরিত হয় এবং আপনার আউটপুটও স্বয়ংক্রিয়ভাবে JSON-এ রূপান্তরিত হয়।

## যেকোনো `dict`-এর বডি { #bodies-of-arbitrary-dicts }

আপনি একটি বডিকে এমন একটি `dict` হিসেবেও ঘোষণা করতে পারেন যার কী-গুলো এক টাইপের আর ভ্যালুগুলো অন্য টাইপের।

এভাবে আপনাকে আগে থেকে জানতে হবে না বৈধ ফিল্ড/অ্যাট্রিবিউটের নামগুলো কী (যেমনটা Pydantic মডেলের ক্ষেত্রে হতো)।

আপনি যদি এমন কী গ্রহণ করতে চান যা আগে থেকে জানেন না, তাহলে এটি কাজে আসবে।

## সংক্ষেপে { #recap }

**FastAPI**-তে আপনি Pydantic মডেলের দেওয়া সর্বোচ্চ নমনীয়তা পান, আর আপনার কোড থাকে সহজ, সংক্ষিপ্ত ও মার্জিত।

সাথে থাকে সব সুবিধা:

* এডিটর সাপোর্ট (সব জায়গায় কমপ্লিশন!)
* ডেটা রূপান্তর (অর্থাৎ পার্সিং / সিরিয়ালাইজেশন)
* ডেটা ভ্যালিডেশন
* স্কিমা ডকুমেন্টেশন
* স্বয়ংক্রিয় ডকুমেন্টেশন
