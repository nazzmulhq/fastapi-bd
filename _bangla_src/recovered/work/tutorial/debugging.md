## ডিবাগার দিয়ে আপনার কোড চালান { #run-your-code-with-your-debugger }

যেহেতু আপনি আপনার কোড থেকে সরাসরি Uvicorn সার্ভার চালাচ্ছেন, তাই আপনি ডিবাগার থেকে সরাসরি আপনার Python প্রোগ্রাম (আপনার FastAPI অ্যাপ্লিকেশন) কল করতে পারেন।

---

যেমন, Visual Studio Code-এ আপনি পারেন:

* "Debug" প্যানেলে যান।
* "Add configuration..."।
* "Python" বেছে নিন
* "`Python: Current File (Integrated Terminal)`" অপশন দিয়ে ডিবাগার চালান।

এটি তখন আপনার **FastAPI** কোডসহ সার্ভার চালু করবে, আপনার ব্রেকপয়েন্টে থামবে ইত্যাদি।

এটি দেখতে এরকম হতে পারে:

<img src="/img/tutorial/debugging/image01.png">

---

আপনি যদি PyCharm ব্যবহার করেন, তাহলে পারেন:

* "Run" মেনু খুলুন।
* "Debug..." অপশনটি বেছে নিন।
* তারপর একটি কনটেক্সট মেনু দেখা যাবে।
* ডিবাগ করার ফাইলটি বেছে নিন (এক্ষেত্রে `main.py`)।

এটি তখন আপনার **FastAPI** কোডসহ সার্ভার চালু করবে, আপনার ব্রেকপয়েন্টে থামবে ইত্যাদি।
