# ব্যাকগ্রাউন্ড টাস্ক { #background-tasks }

রেসপন্স রিটার্ন করার *পরে* চালানোর জন্য আপনি ব্যাকগ্রাউন্ড টাস্ক সংজ্ঞায়িত করতে পারেন।

এটি এমন অপারেশনের জন্য কাজের যা একটি রিকোয়েস্টের পরে হওয়া দরকার, কিন্তু রেসপন্স পাওয়ার আগে অপারেশনটি শেষ হওয়ার জন্য ক্লায়েন্টকে আসলে অপেক্ষা করতে হয় না।

এর মধ্যে আছে, যেমন:

* কোনো কাজ করার পরে পাঠানো ইমেইল নোটিফিকেশন:
    * যেহেতু একটি ইমেইল সার্ভারে কানেক্ট করে ইমেইল পাঠানো সাধারণত "ধীর" (কয়েক সেকেন্ড) হয়, তাই আপনি সাথে সাথে রেসপন্স রিটার্ন করে ব্যাকগ্রাউন্ডে ইমেইল নোটিফিকেশন পাঠাতে পারেন।
* ডেটা প্রসেসিং:
    * যেমন, ধরা যাক আপনি এমন একটি ফাইল পেলেন যা একটি ধীর প্রক্রিয়ার মধ্য দিয়ে যেতে হবে, আপনি "Accepted" (HTTP 202) রেসপন্স রিটার্ন করে ব্যাকগ্রাউন্ডে ফাইলটি প্রসেস করতে পারেন।

## একটি টাস্ক ফাংশন তৈরি করুন { #create-a-task-function }

ব্যাকগ্রাউন্ড টাস্ক হিসেবে চালানোর জন্য একটি ফাংশন তৈরি করুন।

এটি শুধু একটি স্ট্যান্ডার্ড ফাংশন যা প্যারামিটার গ্রহণ করতে পারে।

এটি একটি `async def` বা সাধারণ `def` ফাংশন হতে পারে, **FastAPI** জানবে কীভাবে এটি সঠিকভাবে সামলাতে হয়।

এক্ষেত্রে টাস্ক ফাংশনটি একটি ফাইলে লিখবে (ইমেইল পাঠানোর অনুকরণে)।

আর যেহেতু লেখার অপারেশনটি `async` ও `await` ব্যবহার করে না, তাই আমরা ফাংশনটি সাধারণ `def` দিয়ে সংজ্ঞায়িত করি:

## ব্যাকগ্রাউন্ড টাস্ক যোগ করুন { #add-the-background-task }

আপনার *পাথ অপারেশন ফাংশনের* ভেতরে `.add_task()` মেথড দিয়ে আপনার টাস্ক ফাংশনটি *background tasks* অবজেক্টে দিন:

{* ../../docs_src/background_tasks/tutorial001_py310.py hl[14] *}

`.add_task()` আর্গুমেন্ট হিসেবে গ্রহণ করে:

* ব্যাকগ্রাউন্ডে চালানোর জন্য একটি টাস্ক ফাংশন (`write_notification`)।
* টাস্ক ফাংশনে ক্রমানুসারে পাঠানো উচিত এমন যেকোনো আর্গুমেন্টের ক্রম (`email`)।
* টাস্ক ফাংশনে পাঠানো উচিত এমন যেকোনো কিওয়ার্ড আর্গুমেন্ট (`message="some notification"`)।

## ডিপেন্ডেন্সি ইনজেকশন { #dependency-injection }

`BackgroundTasks` ব্যবহার ডিপেন্ডেন্সি ইনজেকশন সিস্টেমের সাথেও কাজ করে, আপনি একাধিক স্তরে `BackgroundTasks` টাইপের একটি প্যারামিটার ঘোষণা করতে পারেন: একটি *পাথ অপারেশন ফাংশনে*, একটি ডিপেন্ডেন্সিতে (dependable), একটি সাব-ডিপেন্ডেন্সিতে ইত্যাদি।

**FastAPI** জানে প্রতিটি ক্ষেত্রে কী করতে হবে এবং কীভাবে একই অবজেক্ট পুনরায় ব্যবহার করতে হবে, যাতে সব ব্যাকগ্রাউন্ড টাস্ক একসাথে মিলিত হয় এবং পরে ব্যাকগ্রাউন্ডে চলে:


{* ../../docs_src/background_tasks/tutorial002_an_py310.py hl[13,15,22,25] *}


এই উদাহরণে রেসপন্স পাঠানোর *পরে* মেসেজগুলো `log.txt` ফাইলে লেখা হবে।

রিকোয়েস্টে যদি কোনো কুয়েরি থাকে, তাহলে সেটি একটি ব্যাকগ্রাউন্ড টাস্কে লগে লেখা হবে।

আর তারপর *পাথ অপারেশন ফাংশনে* তৈরি হওয়া আরেকটি ব্যাকগ্রাউন্ড টাস্ক `email` পাথ প্যারামিটার ব্যবহার করে একটি মেসেজ লিখবে।

## কারিগরি বিবরণ { #technical-details }

`BackgroundTasks` ক্লাসটি সরাসরি [`starlette.background`](https://starlette.dev/background/) থেকে আসে।

এটি সরাসরি FastAPI-তে ইম্পোর্ট/অন্তর্ভুক্ত করা হয়েছে যাতে আপনি এটি `fastapi` থেকে ইম্পোর্ট করতে পারেন এবং ভুলবশত `starlette.background` থেকে বিকল্প `BackgroundTask` (শেষে `s` ছাড়া) ইম্পোর্ট করা এড়াতে পারেন।

কেবল `BackgroundTasks` ব্যবহার করে (`BackgroundTask` নয়), এটিকে একটি *পাথ অপারেশন ফাংশনের* প্যারামিটার হিসেবে ব্যবহার করা এবং বাকিটা **FastAPI**-কে সামলাতে দেওয়া সম্ভব, ঠিক যেমন সরাসরি `Request` অবজেক্ট ব্যবহার করার সময় হয়।

FastAPI-তে শুধু `BackgroundTask` ব্যবহার করাও সম্ভব, তবে আপনাকে কোডে অবজেক্টটি তৈরি করে সেটি অন্তর্ভুক্ত করে একটি Starlette `Response` রিটার্ন করতে হবে।

আরও বিস্তারিত দেখতে পারেন [ব্যাকগ্রাউন্ড টাস্কের জন্য Starlette-এর অফিসিয়াল ডকুমেন্টেশনে](https://starlette.dev/background/)।

## সতর্কতা { #caveat }

আপনার যদি ভারী ব্যাকগ্রাউন্ড হিসাব-নিকাশ করতে হয় এবং এটি একই প্রসেসে চালানোর বাধ্যবাধকতা না থাকে (যেমন, আপনার মেমরি, ভেরিয়েবল ইত্যাদি শেয়ার করার দরকার নেই), তাহলে [Celery](https://docs.celeryq.dev)-এর মতো অন্যান্য বড় টুল ব্যবহার করে আপনি উপকৃত হতে পারেন।

এগুলোতে সাধারণত আরও জটিল কনফিগারেশন লাগে, যেমন RabbitMQ বা Redis-এর মতো একটি মেসেজ/জব কিউ ম্যানেজার, তবে এগুলো আপনাকে একাধিক প্রসেসে, এবং বিশেষ করে একাধিক সার্ভারে ব্যাকগ্রাউন্ড টাস্ক চালাতে দেয়।

তবে আপনার যদি একই **FastAPI** অ্যাপের ভেরিয়েবল ও অবজেক্ট অ্যাক্সেস করতে হয়, অথবা ছোট ব্যাকগ্রাউন্ড টাস্ক (যেমন একটি ইমেইল নোটিফিকেশন পাঠানো) করতে হয়, তাহলে শুধু `BackgroundTasks` ব্যবহার করলেই চলে।

## সংক্ষেপে { #recap }

ব্যাকগ্রাউন্ড টাস্ক যোগ করতে *পাথ অপারেশন ফাংশন* ও ডিপেন্ডেন্সিতে প্যারামিটারসহ `BackgroundTasks` ইম্পোর্ট করে ব্যবহার করুন।
