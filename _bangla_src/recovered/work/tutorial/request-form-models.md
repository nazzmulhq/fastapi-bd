## ফর্মের জন্য Pydantic মডেল { #pydantic-models-for-forms }

আপনাকে শুধু **ফর্ম ফিল্ড** হিসেবে যে ফিল্ডগুলো গ্রহণ করতে চান সেগুলোসহ একটি **Pydantic মডেল** ঘোষণা করতে হবে, তারপর প্যারামিটারটিকে `Form` হিসেবে ঘোষণা করতে হবে:

{* ../../docs_src/request_form_models/tutorial001_an_py310.py hl[9:11,15] *}

**FastAPI** রিকোয়েস্টের **ফর্ম ডেটা** থেকে **প্রতিটি ফিল্ডের** ডেটা **বের করে** আপনার সংজ্ঞায়িত Pydantic মডেলটি আপনাকে দেবে।

## অতিরিক্ত ফর্ম ফিল্ড নিষিদ্ধ করুন { #forbid-extra-form-fields }

কিছু বিশেষ ক্ষেত্রে (সম্ভবত খুব একটা প্রচলিত নয়) আপনি হয়তো ফর্ম ফিল্ডগুলোকে কেবল Pydantic মডেলে ঘোষিতগুলোর মধ্যে **সীমিত** রাখতে চাইবেন। আর যেকোনো **অতিরিক্ত** ফিল্ড **নিষিদ্ধ** করতে চাইবেন।

/// note | নোট

এটি FastAPI ভার্সন `0.114.0` থেকে সাপোর্টেড। 🤓

///

যেকোনো `extra` ফিল্ড `forbid` করতে আপনি Pydantic-এর মডেল কনফিগারেশন ব্যবহার করতে পারেন:

{* ../../docs_src/request_form_models/tutorial002_an_py310.py hl[12] *}

কোনো ক্লায়েন্ট যদি কিছু অতিরিক্ত ডেটা পাঠানোর চেষ্টা করে, তাহলে সে একটি **এরর** রেসপন্স পাবে।

যেমন, ক্লায়েন্ট যদি এই ফর্ম ফিল্ডগুলো পাঠানোর চেষ্টা করে:

* `username`: `Rick`
* `password`: `Portal Gun`
* `extra`: `Mr. Poopybutthole`
