# কুকি প্যারামিটার মডেল { #cookie-parameter-models }

আপনার যদি পরস্পর সম্পর্কিত একদল **কুকি** থাকে, তাহলে সেগুলো ঘোষণা করতে আপনি একটি **Pydantic মডেল** তৈরি করতে পারেন। 🍪

এতে আপনি **মডেলটি** **একাধিক জায়গায়** **পুনরায় ব্যবহার** করতে পারবেন, আর সব প্যারামিটারের জন্য একবারে ভ্যালিডেশন ও মেটাডেটাও ঘোষণা করতে পারবেন। 😎

/// note | নোট

এটি FastAPI ভার্সন `0.115.0` থেকে সাপোর্টেড। 🤓

///

/// tip | পরামর্শ

এই একই কৌশল `Query`, `Cookie` ও `Header`-এর ক্ষেত্রেও প্রযোজ্য। 😎

///

/// note | নোট

মনে রাখবেন, যেহেতু **ব্রাউজারগুলো কুকি** বিশেষ উপায়ে এবং পর্দার আড়ালে **সামলায়**, তাই এগুলো **JavaScript**-কে সহজে সেগুলো স্পর্শ করতে **দেয় না**।

আপনি যদি `/docs`-এ **API ডকুমেন্টেশন UI**-তে যান, তাহলে আপনার *পাথ অপারেশনগুলোর* কুকির **ডকুমেন্টেশন** দেখতে পাবেন।

কিন্তু আপনি **ডেটা পূরণ করে** "Execute" ক্লিক করলেও, ডকুমেন্টেশন UI যেহেতু **JavaScript** দিয়ে কাজ করে, তাই কুকিগুলো পাঠানো হবে না, আর আপনি এমন একটি **এরর** মেসেজ দেখবেন যেন আপনি কোনো ভ্যালুই লেখেননি।
