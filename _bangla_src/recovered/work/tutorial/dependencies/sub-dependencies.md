# সাব-ডিপেন্ডেন্সি { #sub-dependencies }

আপনি এমন ডিপেন্ডেন্সি তৈরি করতে পারেন যেগুলোর **সাব-ডিপেন্ডেন্সি** আছে।

এগুলো আপনার প্রয়োজনমতো যত **গভীর** খুশি হতে পারে।

**FastAPI** এগুলো সমাধান করার দায়িত্ব নেবে।

আপনি এভাবে একটি প্রথম ডিপেন্ডেন্সি ("dependable") তৈরি করতে পারেন:

{* ../../docs_src/dependencies/tutorial005_an_py310.py hl[8:9] *}

এটি একটি `str` হিসেবে একটি ঐচ্ছিক কুয়েরি প্যারামিটার `q` ঘোষণা করে, তারপর শুধু সেটি রিটার্ন করে।

এটি বেশ সহজ (খুব একটা কাজের নয়), তবে সাব-ডিপেন্ডেন্সি কীভাবে কাজ করে তাতে মনোযোগ দিতে আমাদের সাহায্য করবে।

## দ্বিতীয় ডিপেন্ডেন্সি, "dependable" এবং "dependant" { #second-dependency-dependable-and-dependant }

তারপর আপনি আরেকটি ডিপেন্ডেন্সি ফাংশন (একটি "dependable") তৈরি করতে পারেন যা একই সাথে নিজের একটি ডিপেন্ডেন্সি ঘোষণা করে (তাই এটি একটি "dependant"-ও):

{* ../../docs_src/dependencies/tutorial005_an_py310.py hl[13] *}

ঘোষিত প্যারামিটারগুলোতে মনোযোগ দেওয়া যাক:

* যদিও এই ফাংশনটি নিজেই একটি ডিপেন্ডেন্সি ("dependable"), এটি আরেকটি ডিপেন্ডেন্সিও ঘোষণা করে (এটি অন্য কিছুর ওপর "নির্ভর করে")।
    * এটি `query_extractor`-এর ওপর নির্ভর করে, এবং সেটি যে ভ্যালু রিটার্ন করে তা `q` প্যারামিটারে অ্যাসাইন করে।
* এটি একটি `str` হিসেবে একটি ঐচ্ছিক `last_query` কুকিও ঘোষণা করে।
    * ইউজার যদি কোনো কুয়েরি `q` না দেন, তাহলে আমরা সর্বশেষ ব্যবহৃত কুয়েরিটি ব্যবহার করি, যা আমরা আগে একটি কুকিতে সংরক্ষণ করেছিলাম।

## একই ডিপেন্ডেন্সি একাধিকবার ব্যবহার { #using-the-same-dependency-multiple-times }

আপনার কোনো ডিপেন্ডেন্সি যদি একই *পাথ অপারেশনের* জন্য একাধিকবার ঘোষণা করা হয়, যেমন একাধিক ডিপেন্ডেন্সির একটি সাধারণ সাব-ডিপেন্ডেন্সি থাকে, তাহলে **FastAPI** জানবে যে প্রতি রিকোয়েস্টে ওই সাব-ডিপেন্ডেন্সিটি কেবল একবারই কল করতে হবে।

আর এটি রিটার্ন করা ভ্যালুটি একটি <dfn title="হিসাব করা/তৈরি করা ভ্যালু সংরক্ষণের একটি ইউটিলিটি/সিস্টেম, যাতে আবার হিসাব না করে সেগুলো পুনরায় ব্যবহার করা যায়।">"ক্যাশে"</dfn>-তে সংরক্ষণ করবে এবং একই রিকোয়েস্টের জন্য ডিপেন্ডেন্সিটি একাধিকবার কল না করে ওই নির্দিষ্ট রিকোয়েস্টে যেসব "dependant"-এর এটি দরকার তাদের সবাইকে পাঠাবে।

কোনো অ্যাডভান্সড পরিস্থিতিতে আপনি যদি জানেন যে "ক্যাশ করা" ভ্যালু ব্যবহার না করে একই রিকোয়েস্টে প্রতিটি ধাপে (সম্ভবত একাধিকবার) ডিপেন্ডেন্সিটি কল করা দরকার, তাহলে `Depends` ব্যবহারের সময় `use_cache=False` প্যারামিটার সেট করতে পারেন:

## সংক্ষেপে { #recap }

এখানে ব্যবহৃত সব গালভরা শব্দ বাদ দিলে, **ডিপেন্ডেন্সি ইনজেকশন** সিস্টেমটি বেশ সহজ।

শুধু কিছু ফাংশন, যেগুলো দেখতে *পাথ অপারেশন ফাংশনের* মতোই।

তবুও এটি খুবই শক্তিশালী, এবং আপনাকে যত গভীর পর্যন্ত খুশি নেস্টেড ডিপেন্ডেন্সি "গ্রাফ" (ট্রি) ঘোষণা করতে দেয়।

/// tip | পরামর্শ

এই সহজ উদাহরণগুলো দেখে হয়তো এর সবকিছু ততটা কাজের মনে হবে না।

তবে **সিকিউরিটি** সম্পর্কিত অধ্যায়গুলোতে আপনি দেখবেন এটি কতটা কাজের।

আর এটি আপনার কতটা কোড বাঁচাবে তাও দেখবেন।
