আর আমরা জানি যে এডিটরগুলো `dict`-এর জন্য খুব বেশি সাপোর্ট (যেমন কমপ্লিশন) দিতে পারে না, কারণ সেগুলো এর কী ও ভ্যালুর টাইপ জানতে পারে না।

## কী একটি ডিপেন্ডেন্সি তৈরি করে { #what-makes-a-dependency }

এ পর্যন্ত আপনি ফাংশন হিসেবে ঘোষিত ডিপেন্ডেন্সি দেখেছেন।

তবে ডিপেন্ডেন্সি ঘোষণা করার এটিই একমাত্র উপায় নয় (যদিও সম্ভবত এটিই বেশি প্রচলিত)।

মূল বিষয় হলো একটি ডিপেন্ডেন্সিকে একটি "callable" হতে হবে।

Python-এ একটি "**callable**" হলো এমন যেকোনো কিছু যা Python একটি ফাংশনের মতো "কল" করতে পারে।

## ক্লাসকে ডিপেন্ডেন্সি হিসেবে ব্যবহার { #classes-as-dependencies_1 }

আপনি হয়তো লক্ষ করবেন যে একটি Python ক্লাসের ইনস্ট্যান্স তৈরি করতে আপনি এই একই সিনট্যাক্স ব্যবহার করেন।

যেমন:

⟦CODE3⟧

এক্ষেত্রে `fluffy` হলো `Cat` ক্লাসের একটি ইনস্ট্যান্স।

আর `fluffy` তৈরি করতে আপনি `Cat`-কে "কল" করছেন।

তাই একটি Python ক্লাসও একটি **callable**।

তাহলে **FastAPI**-তে আপনি একটি Python ক্লাসকে ডিপেন্ডেন্সি হিসেবে ব্যবহার করতে পারেন।

FastAPI আসলে যা যাচাই করে তা হলো এটি একটি "callable" (ফাংশন, ক্লাস বা অন্য কিছু) কিনা এবং কোন প্যারামিটারগুলো সংজ্ঞায়িত করা আছে।

আপনি যদি **FastAPI**-তে একটি "callable"-কে ডিপেন্ডেন্সি হিসেবে দেন, তাহলে এটি ওই "callable"-এর প্যারামিটারগুলো বিশ্লেষণ করবে, এবং একটি *পাথ অপারেশন ফাংশনের* প্যারামিটারের মতোই সেগুলো প্রসেস করবে। সাব-ডিপেন্ডেন্সিসহ।

কোনো প্যারামিটারই নেই এমন callable-এর ক্ষেত্রেও এটি প্রযোজ্য। প্যারামিটার ছাড়া *পাথ অপারেশন ফাংশনের* ক্ষেত্রে যেমন হতো।

দুই ক্ষেত্রেই এতে থাকবে:

* একটি ঐচ্ছিক `q` কুয়েরি প্যারামিটার, যা একটি `str`।
* একটি `skip` কুয়েরি প্যারামিটার, যা একটি `int`, ডিফল্ট `0`।
* একটি `limit` কুয়েরি প্যারামিটার, যা একটি `int`, ডিফল্ট `100`।

দুই ক্ষেত্রেই ডেটা রূপান্তরিত, ভ্যালিডেটেড, OpenAPI স্কিমায় ডকুমেন্টেড ইত্যাদি হবে।
