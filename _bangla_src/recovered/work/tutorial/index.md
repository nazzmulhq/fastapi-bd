# টিউটোরিয়াল - ইউজার গাইড { #tutorial-user-guide }

এই টিউটোরিয়ালে ধাপে ধাপে দেখানো হয়েছে কীভাবে **FastAPI**-এর বেশিরভাগ ফিচার ব্যবহার করতে হয়।

প্রতিটি অংশ আগের অংশগুলোর ওপর ধীরে ধীরে গড়ে উঠেছে, তবে বিষয়গুলো এমনভাবে আলাদা করে সাজানো যাতে আপনি আপনার নির্দিষ্ট API প্রয়োজন মেটাতে সরাসরি যেকোনো নির্দিষ্ট অংশে চলে যেতে পারেন।

এটি ভবিষ্যতের রেফারেন্স হিসেবেও কাজ করার মতো করে তৈরি, যাতে আপনি পরে ফিরে এসে ঠিক যা দরকার তা দেখে নিতে পারেন।

## FastAPI ইনস্টল করুন { #install-fastapi }

`uv add` প্রজেক্টের ভার্চুয়াল এনভায়রনমেন্ট `.venv`-এ তৈরি করে, `pyproject.toml`-এ FastAPI যোগ করে এবং `uv.lock` তৈরি করে, যাতে পরে একই প্যাকেজ ভার্সনগুলো ইনস্টল করা যায়।

/// details | এই কমান্ডগুলো কী করে

* `uv init`: একটি নতুন Python প্রজেক্ট তৈরি করে।
* `awesome-project`: এই নামের একটি নতুন ডিরেক্টরিতে প্রজেক্টটি তৈরি করে।
* `--bare`: শুধু ন্যূনতম `pyproject.toml` ফাইলটি তৈরি করে, নমুনা `main.py`, `README.md` বা অন্য কোনো ফাইল তৈরি না করে। এই টিউটোরিয়ালের পরের ধাপগুলোতে আপনি নিজেই অ্যাপ্লিকেশনের ফাইলগুলো তৈরি করবেন।

এরপর FastAPI যোগ করার আগে `cd awesome-project` নতুন প্রজেক্ট ডিরেক্টরিতে প্রবেশ করে।

`uv` আপনার সিস্টেমে আগে থেকে ইনস্টল করা একটি সামঞ্জস্যপূর্ণ Python ভার্সন ব্যবহার করবে, অথবা প্রয়োজনে একটি ডাউনলোড করে নেবে।

আপনি যখন `uv add` চালান, এটি FastAPI এবং FastAPI যেসব প্যাকেজের ওপর নির্ভর করে তাদের সামঞ্জস্যপূর্ণ ভার্সন বেছে নেয়। এটি সঠিক ভার্সনগুলো `uv.lock`-এ লিখে রাখে, ফলে পরে অন্য কম্পিউটারে বা অ্যাপ্লিকেশন ডিপ্লয় করার সময় একই প্যাকেজ ভার্সনগুলো ইনস্টল করা সম্ভব হয়।

এই ফাইল তৈরি বা আপডেট করাকে বলা হয় [প্রজেক্টের ডিপেন্ডেন্সিগুলো **লক** করা](https://docs.astral.sh/uv/concepts/projects/sync/)। আপনি কোনো প্যাকেজ যোগ করলে `uv` স্বয়ংক্রিয়ভাবে এটি করে।

///

/// details | FastAPI ইনস্টলেশনের বিকল্পগুলো

যখন আপনি `uv add "fastapi[standard]"` দিয়ে ইনস্টল করেন, তখন এর সাথে কিছু ডিফল্ট ঐচ্ছিক স্ট্যান্ডার্ড ডিপেন্ডেন্সি আসে, যার মধ্যে আছে `fastapi-cloud-cli`, যা দিয়ে আপনি [FastAPI Cloud](https://fastapicloud.com)-এ ডিপ্লয় করতে পারেন।

আপনি যদি এই ঐচ্ছিক ডিপেন্ডেন্সিগুলো না চান, তাহলে এর বদলে `uv add fastapi` দিয়ে ইনস্টল করতে পারেন।

আপনি যদি স্ট্যান্ডার্ড ডিপেন্ডেন্সিগুলো চান কিন্তু `fastapi-cloud-cli` ছাড়া, তাহলে `uv add "fastapi[standard-no-fastapi-cloud-cli]"` দিয়ে ইনস্টল করতে পারেন।

///

/// details | এর বদলে `pip` ব্যবহার

আপনি যদি ভার্চুয়াল এনভায়রনমেন্ট ও প্যাকেজগুলো নিজে হাতে পরিচালনা করতে চান, তাহলে একটি ভার্চুয়াল এনভায়রনমেন্ট তৈরি ও অ্যাক্টিভেট করুন, তারপর `pip install "fastapi[standard]"` দিয়ে FastAPI ইনস্টল করুন।

বিস্তারিত ধাপগুলোর জন্য [ভার্চুয়াল এনভায়রনমেন্ট গাইড](https://tiangolo.com/guides/virtual-environments/) পড়ুন।

## অ্যাডভান্সড ইউজার গাইড { #advanced-user-guide }

এই **টিউটোরিয়াল - ইউজার গাইড** পড়ার পরে পড়ার জন্য একটি **অ্যাডভান্সড ইউজার গাইড**-ও আছে।

**অ্যাডভান্সড ইউজার গাইড** এটির ওপর ভিত্তি করে তৈরি, একই ধারণাগুলো ব্যবহার করে এবং আপনাকে কিছু অতিরিক্ত ফিচার শেখায়।

তবে প্রথমে আপনার **টিউটোরিয়াল - ইউজার গাইড** পড়া উচিত (যা আপনি এখন পড়ছেন)।

এটি এমনভাবে ডিজাইন করা যে শুধু **টিউটোরিয়াল - ইউজার গাইড** দিয়েই আপনি একটি সম্পূর্ণ অ্যাপ্লিকেশন বানাতে পারবেন, তারপর আপনার প্রয়োজন অনুযায়ী **অ্যাডভান্সড ইউজার গাইড**-এর কিছু অতিরিক্ত ধারণা ব্যবহার করে সেটিকে বিভিন্নভাবে বাড়াতে পারবেন।
