# সার্ভার ওয়ার্কার - ওয়ার্কারসহ Uvicorn { #server-workers-uvicorn-with-workers }

আগের সেই ডিপ্লয়মেন্টের ধারণাগুলো আবার দেখে নেওয়া যাক:

* সিকিউরিটি - HTTPS
* startup-এ চালু হওয়া
* রিস্টার্ট
* **রেপ্লিকেশন (চলমান প্রসেসের সংখ্যা)**
* মেমরি
* শুরুর আগের ধাপগুলো

এ পর্যন্ত ডকুমেন্টেশনের সব টিউটোরিয়ালে আপনি সম্ভবত একটি **সার্ভার প্রোগ্রাম** চালিয়ে এসেছেন, যেমন Uvicorn চালানো `fastapi` কমান্ড ব্যবহার করে, যা একটি **একক প্রসেস** চালায়।

অ্যাপ্লিকেশন ডিপ্লয় করার সময় আপনি সম্ভবত **একাধিক কোরের** সুবিধা নিতে এবং আরও বেশি রিকোয়েস্ট সামলাতে পারার জন্য **প্রসেসের কিছু রেপ্লিকেশন** রাখতে চাইবেন।

[ডিপ্লয়মেন্টের ধারণাসমূহ](concepts.md) নিয়ে আগের অধ্যায়ে যেমন দেখেছেন, আপনি একাধিক কৌশল ব্যবহার করতে পারেন।

এখানে আমি আপনাকে দেখাব কীভাবে `fastapi` কমান্ড বা সরাসরি `uvicorn` কমান্ড ব্যবহার করে **ওয়ার্কার প্রসেসসহ** **Uvicorn** ব্যবহার করতে হয়।

/// note | নোট

আপনি যদি কন্টেইনার ব্যবহার করেন, যেমন Docker বা Kubernetes দিয়ে, তাহলে পরের অধ্যায়ে আমি এ সম্পর্কে আরও বলব: [কন্টেইনারে FastAPI - Docker](docker.md)।

বিশেষ করে, **Kubernetes**-এ চালানোর সময় আপনি সম্ভবত ওয়ার্কার ব্যবহার করতে চাইবেন **না**, বরং **প্রতি কন্টেইনারে একটি Uvicorn প্রসেস** চালাতে চাইবেন, তবে সে সম্পর্কে ওই অধ্যায়ে পরে বলব।

## ডিপ্লয়মেন্টের ধারণাসমূহ { #deployment-concepts }

এখানে আপনি দেখলেন কীভাবে একাধিক **ওয়ার্কার** ব্যবহার করে অ্যাপ্লিকেশনের এক্সিকিউশন **প্যারালাল** করতে হয়, CPU-র **একাধিক কোরের** সুবিধা নিতে হয়, এবং **আরও বেশি রিকোয়েস্ট** সার্ভ করতে হয়।

ওপরের ডিপ্লয়মেন্ট ধারণার লিস্ট থেকে, ওয়ার্কার ব্যবহার প্রধানত **রেপ্লিকেশন** অংশে সাহায্য করবে, আর একটু **রিস্টার্টে**, তবে বাকিগুলোর দিকে আপনাকে তবুও খেয়াল রাখতে হবে:

* **সিকিউরিটি - HTTPS**
* **startup-এ চালু হওয়া**
* ***রিস্টার্ট***
* রেপ্লিকেশন (চলমান প্রসেসের সংখ্যা)
* **মেমরি**
* **শুরুর আগের ধাপগুলো**

## কন্টেইনার ও Docker { #containers-and-docker }

[কন্টেইনারে FastAPI - Docker](docker.md) নিয়ে পরের অধ্যায়ে আমি ব্যাখ্যা করব বাকি **ডিপ্লয়মেন্টের ধারণাগুলো** সামলাতে আপনি কী কী কৌশল ব্যবহার করতে পারেন।

আমি আপনাকে দেখাব কীভাবে একটি একক Uvicorn প্রসেস চালাতে **একদম শুরু থেকে নিজের ইমেজ তৈরি** করতে হয়। এটি একটি সহজ প্রক্রিয়া এবং **Kubernetes**-এর মতো একটি ডিস্ট্রিবিউটেড কন্টেইনার ম্যানেজমেন্ট সিস্টেম ব্যবহারের সময় সম্ভবত আপনি এটিই করতে চাইবেন।

## সংক্ষেপে { #recap }

**মাল্টি-কোর CPU**-এর সুবিধা নিতে, **একাধিক প্রসেস প্যারালালভাবে** চালাতে আপনি `fastapi` বা `uvicorn` কমান্ডের সাথে `--workers` CLI অপশন দিয়ে একাধিক ওয়ার্কার প্রসেস ব্যবহার করতে পারেন।

আপনি যদি বাকি ডিপ্লয়মেন্ট ধারণাগুলোর দিকে নিজে খেয়াল রেখে **নিজের ডিপ্লয়মেন্ট সিস্টেম** সেট আপ করেন, তাহলে এই টুল ও ধারণাগুলো ব্যবহার করতে পারেন।

কন্টেইনারসহ (যেমন Docker ও Kubernetes) **FastAPI** সম্পর্কে জানতে পরের অধ্যায়টি দেখুন। আপনি দেখবেন যে ওই টুলগুলোতে বাকি **ডিপ্লয়মেন্টের ধারণাগুলো** সমাধানেরও সহজ উপায় আছে। ✨
