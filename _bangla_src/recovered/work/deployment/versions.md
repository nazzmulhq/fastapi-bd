# FastAPI-এর ভার্সন প্রসঙ্গে { #about-fastapi-versions }

**FastAPI** ইতিমধ্যে অনেক অ্যাপ্লিকেশন ও সিস্টেমে প্রোডাকশনে ব্যবহার হচ্ছে। আর টেস্ট কভারেজ ১০০%-এ রাখা হয়। তবে এর ডেভেলপমেন্ট এখনো দ্রুত এগিয়ে চলেছে।

ঘন ঘন নতুন ফিচার যোগ হয়, নিয়মিত বাগ ঠিক করা হয়, এবং কোড এখনো ক্রমাগত উন্নত হচ্ছে।

এ কারণেই বর্তমান ভার্সনগুলো এখনো `0.x.x`, এটি প্রতিফলিত করে যে প্রতিটি ভার্সনে সম্ভাব্য ভাঙন-সৃষ্টিকারী পরিবর্তন (breaking changes) থাকতে পারে। এটি [Semantic Versioning](https://semver.org/) রীতি অনুসরণ করে।

আপনি এখনই **FastAPI** দিয়ে প্রোডাকশন অ্যাপ্লিকেশন তৈরি করতে পারেন (এবং সম্ভবত কিছুদিন ধরে তা করেও আসছেন), আপনাকে শুধু নিশ্চিত করতে হবে যে আপনি এমন একটি ভার্সন ব্যবহার করছেন যা আপনার বাকি কোডের সাথে সঠিকভাবে কাজ করে।

## আপনার `fastapi` ভার্সন পিন করুন { #pin-your-fastapi-version }

প্রথমে আপনার যা করা উচিত তা হলো আপনি যে **FastAPI** ভার্সন ব্যবহার করছেন সেটিকে সেই নির্দিষ্ট সর্বশেষ ভার্সনে "পিন" করা, যা আপনার অ্যাপ্লিকেশনের জন্য সঠিকভাবে কাজ করে বলে আপনি জানেন।

যেমন, ধরা যাক আপনি আপনার অ্যাপে ভার্সন `0.112.0` ব্যবহার করছেন।

আপনি যদি একটি `requirements.txt` ফাইল ব্যবহার করেন, তাহলে এভাবে ভার্সনটি উল্লেখ করতে পারেন:

এর মানে আপনি হুবহু ভার্সন `0.112.0` ব্যবহার করবেন।

অথবা আপনি এভাবেও পিন করতে পারেন:

⟦CODE2⟧

এর মানে আপনি `0.112.0` বা তার ওপরের, কিন্তু `0.113.0`-এর চেয়ে কম ভার্সনগুলো ব্যবহার করবেন, যেমন একটি ভার্সন `0.112.2` তখনও গৃহীত হবে।

আপনি যদি আপনার ইনস্টলেশন পরিচালনার জন্য অন্য কোনো টুল ব্যবহার করেন, যেমন `uv`, Poetry, Pipenv বা অন্যান্য, সেগুলোর সবগুলোতেই আপনার প্যাকেজের জন্য নির্দিষ্ট ভার্সন সংজ্ঞায়িত করার একটি উপায় আছে।

## ভার্সন প্রসঙ্গে { #about-versions }

Semantic Versioning রীতি অনুসরণ করে, `1.0.0`-এর নিচের যেকোনো ভার্সনে সম্ভাব্য ভাঙন-সৃষ্টিকারী পরিবর্তন যোগ হতে পারে।

FastAPI এই রীতিও অনুসরণ করে যে যেকোনো "PATCH" ভার্সন পরিবর্তন বাগ ফিক্স ও ভাঙন-সৃষ্টি করে না এমন পরিবর্তনের জন্য।

/// tip | পরামর্শ

"PATCH" হলো শেষ সংখ্যাটি, যেমন `0.2.3`-এ PATCH ভার্সন হলো `3`।

///

তাই আপনি এরকম একটি ভার্সনে পিন করতে পারবেন:

⟦CODE3⟧

ভাঙন-সৃষ্টিকারী পরিবর্তন ও নতুন ফিচার যোগ হয় "MINOR" ভার্সনে।

/// tip | পরামর্শ

"MINOR" হলো মাঝের সংখ্যাটি, যেমন `0.2.3`-এ MINOR ভার্সন হলো `2`।

///

## FastAPI ভার্সন আপগ্রেড করা { #upgrading-the-fastapi-versions }

আপনার অ্যাপের জন্য টেস্ট যোগ করা উচিত।

**FastAPI**-তে এটি খুবই সহজ (Starlette-কে ধন্যবাদ), ডকুমেন্টেশন দেখুন: [টেস্টিং](../tutorial/testing.md)

আপনার টেস্ট হয়ে গেলে তারপর আপনি **FastAPI** ভার্সন আরও সাম্প্রতিক একটিতে আপগ্রেড করতে পারেন, এবং আপনার টেস্টগুলো চালিয়ে নিশ্চিত করতে পারেন যে আপনার সব কোড সঠিকভাবে কাজ করছে।

যদি সবকিছু কাজ করে, অথবা প্রয়োজনীয় পরিবর্তন করার পরে আপনার সব টেস্ট পাস করে, তাহলে আপনি আপনার `fastapi`-কে সেই নতুন সাম্প্রতিক ভার্সনে পিন করতে পারেন।

## Starlette প্রসঙ্গে { #about-starlette }

আপনার `starlette`-এর ভার্সন পিন করা উচিত নয়।

**FastAPI**-এর বিভিন্ন ভার্সন Starlette-এর একটি নির্দিষ্ট নতুন ভার্সন ব্যবহার করবে।

তাই আপনি শুধু **FastAPI**-কে সঠিক Starlette ভার্সন ব্যবহার করতে দিতে পারেন।

## Pydantic প্রসঙ্গে { #about-pydantic }

Pydantic তার নিজস্ব টেস্টের সাথে **FastAPI**-এর টেস্টগুলোও অন্তর্ভুক্ত করে, তাই Pydantic-এর নতুন ভার্সনগুলো (`1.0.0`-এর ওপরে) সবসময় FastAPI-এর সাথে সামঞ্জস্যপূর্ণ।

আপনি Pydantic-কে `1.0.0`-এর ওপরের যেকোনো ভার্সনে পিন করতে পারেন যা আপনার জন্য কাজ করে।
