# ডিপ্লয়মেন্ট { #deployment }

একটি **FastAPI** অ্যাপ্লিকেশন ডিপ্লয় করা তুলনামূলকভাবে সহজ।

## ডিপ্লয়মেন্ট মানে কী { #what-does-deployment-mean }

একটি অ্যাপ্লিকেশন **ডিপ্লয়** করা মানে এটিকে **ইউজারদের জন্য উপলব্ধ** করতে প্রয়োজনীয় ধাপগুলো সম্পন্ন করা।

একটি **ওয়েব API**-এর ক্ষেত্রে এর মানে সাধারণত এটিকে একটি **রিমোট মেশিনে** রাখা, ভালো পারফরম্যান্স, স্থিতিশীলতা ইত্যাদি দেয় এমন একটি **সার্ভার প্রোগ্রাম** দিয়ে, যাতে আপনার **ইউজাররা** দক্ষতার সাথে এবং কোনো বাধা বা সমস্যা ছাড়াই অ্যাপ্লিকেশনটি **অ্যাক্সেস** করতে পারেন।

এটি **ডেভেলপমেন্ট** পর্যায়ের বিপরীত, যেখানে আপনি ক্রমাগত কোড পরিবর্তন করছেন, ভাঙছেন ও ঠিক করছেন, ডেভেলপমেন্ট সার্ভার থামাচ্ছেন ও আবার চালু করছেন, ইত্যাদি।

## ডিপ্লয়মেন্ট কৌশল { #deployment-strategies }

আপনার নির্দিষ্ট ব্যবহারের ক্ষেত্র এবং আপনার ব্যবহৃত টুলের ওপর নির্ভর করে এটি করার বেশ কয়েকটি উপায় আছে।

আপনি টুলের একটি সমন্বয় ব্যবহার করে নিজেই **একটি সার্ভার ডিপ্লয়** করতে পারেন, আপনার হয়ে কাজের একটি অংশ করে দেয় এমন একটি **ক্লাউড সার্ভিস** ব্যবহার করতে পারেন, বা অন্যান্য সম্ভাব্য অপশন বেছে নিতে পারেন।

যেমন, আমরা, FastAPI-এর পেছনের টিম, FastAPI নিয়ে কাজ করার মতো একই ডেভেলপার অভিজ্ঞতাসহ ক্লাউডে FastAPI অ্যাপ ডিপ্লয় করাকে যথাসম্ভব সহজ করতে [**FastAPI Cloud**](https://fastapicloud.com) তৈরি করেছি।

একটি **FastAPI** অ্যাপ্লিকেশন ডিপ্লয় করার সময় আপনার সম্ভবত মনে রাখা উচিত এমন কিছু প্রধান ধারণা আমি আপনাকে দেখাব (যদিও এর বেশিরভাগই অন্য যেকোনো ধরনের ওয়েব অ্যাপ্লিকেশনের ক্ষেত্রেও প্রযোজ্য)।

পরের অংশগুলোতে আপনি মনে রাখার মতো আরও বিবরণ এবং এটি করার কিছু কৌশল দেখবেন। ✨
