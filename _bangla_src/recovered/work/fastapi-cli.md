# FastAPI CLI { #fastapi-cli }

**FastAPI <abbr title="command line interface - কমান্ড লাইন ইন্টারফেস">CLI</abbr>** হলো একটি কমান্ড লাইন প্রোগ্রাম, যা দিয়ে আপনি আপনার FastAPI অ্যাপ সার্ভ করতে, আপনার FastAPI প্রজেক্ট পরিচালনা করতে এবং আরও অনেক কিছু করতে পারেন।

## `fastapi dev` { #fastapi-dev }

`fastapi dev` চালালে ডেভেলপমেন্ট মোড শুরু হয়।

ডিফল্টভাবে **অটো-রিলোড** চালু থাকে, যা আপনি আপনার কোডে পরিবর্তন করলে স্বয়ংক্রিয়ভাবে সার্ভার রিলোড করে। এটি রিসোর্স-নির্ভর এবং বন্ধ থাকার তুলনায় কম স্থিতিশীল হতে পারে। আপনার এটি কেবল ডেভেলপমেন্টের জন্য ব্যবহার করা উচিত। এটি IP ঠিকানা `127.0.0.1`-এ শোনে, যা আপনার মেশিনের কেবল নিজের সাথে যোগাযোগের IP (`localhost`)।

আপনার অ্যাপ ইম্পোর্ট করার আগে `fastapi dev` `FASTAPI_ENV` এনভায়রনমেন্ট ভেরিয়েবলকে `development`-এ সেট করে। `FASTAPI_ENV` আগে থেকে সেট করা থাকলে এর বিদ্যমান ভ্যালু রাখা হয়। এতে অ্যাপের startup কোড ডেভেলপমেন্ট-বান্ধব আচরণ বেছে নিতে পারে, আবার আপনি `staging`-এর মতো একটি অ্যাপ-নির্দিষ্ট এনভায়রনমেন্টও দিতে পারেন।

প্রচলিত `FASTAPI_ENV` ভ্যালুগুলো হলো `development` ও `production`। `fastapi run` বর্তমানে `FASTAPI_ENV` অপরিবর্তিত রাখে, তাই আপনার অ্যাপের যদি প্রোডাকশন মোড শনাক্ত করতে হয়, তাহলে এটি স্পষ্টভাবে সেট করুন।

## `fastapi run` { #fastapi-run }

`fastapi run` এক্সিকিউট করলে FastAPI প্রোডাকশন মোডে শুরু হয়।

ডিফল্টভাবে **অটো-রিলোড** বন্ধ থাকে। এটি IP ঠিকানা `0.0.0.0`-এ শোনে, অর্থাৎ সব উপলব্ধ IP ঠিকানায়, এভাবে মেশিনটির সাথে যোগাযোগ করতে পারে এমন যে কারো কাছে এটি পাবলিকভাবে অ্যাক্সেসযোগ্য হবে। প্রোডাকশনে, যেমন একটি কন্টেইনারে, সাধারণত আপনি এভাবেই এটি চালাবেন।

বেশিরভাগ ক্ষেত্রে আপনার ওপরে একটি "termination proxy" থাকবে (এবং থাকা উচিত) যা আপনার হয়ে HTTPS সামলায়, এটি নির্ভর করবে আপনি কীভাবে আপনার অ্যাপ্লিকেশন ডিপ্লয় করেন তার ওপর, আপনার প্রোভাইডার হয়তো আপনার হয়ে এটি করবে, অথবা আপনাকে নিজেই সেট আপ করতে হতে পারে।
