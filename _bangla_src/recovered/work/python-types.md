# Python টাইপ পরিচিতি { #python-types-intro }

Python-এ ঐচ্ছিক "টাইপ হিন্ট" (যাকে "টাইপ অ্যানোটেশন"-ও বলা হয়) সাপোর্ট করে।

এই **"টাইপ হিন্ট"** বা অ্যানোটেশন হলো একটি বিশেষ সিনট্যাক্স, যা দিয়ে একটি ভেরিয়েবলের <dfn title="যেমন: str, int, float, bool">টাইপ</dfn> ঘোষণা করা যায়।

আপনার ভেরিয়েবলগুলোর টাইপ ঘোষণা করলে এডিটর ও টুলগুলো আপনাকে আরও ভালো সাপোর্ট দিতে পারে।

এটি Python টাইপ হিন্ট নিয়ে কেবল একটি **ছোট টিউটোরিয়াল / ঝালাই**। এতে **FastAPI**-এর সাথে এগুলো ব্যবহারের জন্য ন্যূনতম যতটুকু দরকার কেবল ততটুকুই আছে... যা আসলে খুবই সামান্য।

**FastAPI** পুরোটাই এই টাইপ হিন্টগুলোর ওপর ভিত্তি করে তৈরি, এগুলো একে অনেক সুবিধা ও উপকারিতা দেয়।

তবে আপনি কখনো **FastAPI** ব্যবহার না করলেও এগুলো সম্পর্কে একটু শিখে রাখলে উপকৃত হবেন।

/// note | নোট

আপনি যদি Python বিশেষজ্ঞ হন এবং টাইপ হিন্ট সম্পর্কে সবকিছু আগে থেকেই জানেন, তাহলে পরের অধ্যায়ে চলে যান।

## টাইপ ঘোষণা { #declaring-types }

আপনি এইমাত্র টাইপ হিন্ট ঘোষণা করার প্রধান জায়গাটি দেখলেন: ফাংশনের প্যারামিটার হিসেবে।

**FastAPI**-এর সাথেও এগুলো আপনি প্রধানত এখানেই ব্যবহার করবেন।

যেমন, আপনি ব্যবহার করতে পারেন:

### জেনেরিক টাইপ { #generic-types }

কিছু টাইপ তাদের ভেতরের টাইপ নির্ধারণ করতে বর্গাকার বন্ধনীতে "টাইপ প্যারামিটার" নিতে পারে। যেমন, "স্ট্রিংয়ের একটি লিস্ট" ঘোষণা করা হবে `list[str]` হিসেবে।

যেসব টাইপ টাইপ প্যারামিটার নিতে পারে, সেগুলোকে বলা হয় **জেনেরিক টাইপ** বা **জেনেরিক**।

একই বিল্টইন টাইপগুলো আপনি জেনেরিক হিসেবে ব্যবহার করতে পারেন (বর্গাকার বন্ধনী ও ভেতরে টাইপসহ):

* `list`
* `tuple`
* `set`
* `dict`

টাইপ হিসেবে `list` দিন।

যেহেতু লিস্ট এমন একটি টাইপ যার ভেতরে কিছু টাইপ থাকে, সেগুলো বর্গাকার বন্ধনীতে দিন:

আপনি ডেটার "আকৃতি" ঘোষণা করেন অ্যাট্রিবিউটসহ ক্লাস হিসেবে।

আর প্রতিটি অ্যাট্রিবিউটের একটি টাইপ থাকে।

তারপর আপনি কিছু ভ্যালু দিয়ে ওই ক্লাসের একটি ইনস্ট্যান্স তৈরি করেন, আর এটি ভ্যালুগুলো ভ্যালিডেট করবে, (প্রয়োজন হলে) উপযুক্ত টাইপে রূপান্তর করবে এবং সব ডেটাসহ একটি অবজেক্ট দেবে।

আর সেই ফলাফলের অবজেক্টের সাথে আপনি সব এডিটর সাপোর্ট পান।

## মেটাডেটা অ্যানোটেশনসহ টাইপ হিন্ট { #type-hints-with-metadata-annotations }

Python-এ এমন একটি ফিচারও আছে যা দিয়ে `Annotated` ব্যবহার করে এই টাইপ হিন্টগুলোতে **অতিরিক্ত <dfn title="ডেটা সম্পর্কে ডেটা, এক্ষেত্রে টাইপ সম্পর্কে তথ্য, যেমন একটি বিবরণ।">মেটাডেটা</dfn>** রাখা যায়।

আপনি `typing` থেকে `Annotated` ইম্পোর্ট করতে পারেন।

{* ../../docs_src/python_types/tutorial013_py310.py hl[1,4] *}

Python নিজে এই `Annotated` দিয়ে কিছুই করে না। আর এডিটর ও অন্যান্য টুলের কাছে টাইপটি এখনো `str`।

তবে আপনার অ্যাপ্লিকেশন কেমন আচরণ করবে সে সম্পর্কে **FastAPI**-কে অতিরিক্ত মেটাডেটা দিতে আপনি `Annotated`-এর এই জায়গাটি ব্যবহার করতে পারেন।

মনে রাখার মতো গুরুত্বপূর্ণ বিষয় হলো, `Annotated`-এ আপনি যে **প্রথম *টাইপ প্যারামিটার*** দেন সেটিই **আসল টাইপ**। বাকিগুলো অন্যান্য টুলের জন্য কেবল মেটাডেটা।

আপাতত আপনার শুধু এটুকু জানলেই চলবে যে `Annotated` আছে, এবং এটি স্ট্যান্ডার্ড Python। 😎

পরে আপনি দেখবেন এটি কতটা **শক্তিশালী** হতে পারে।

/// tip | পরামর্শ

এটি **স্ট্যান্ডার্ড Python** হওয়ার মানে হলো, আপনার এডিটরে, কোড বিশ্লেষণ ও রিফ্যাক্টর করার টুলগুলোতে ইত্যাদিতে আপনি এখনো **সম্ভাব্য সেরা ডেভেলপার অভিজ্ঞতা** পাবেন। ✨

আর এটাও যে আপনার কোড আরও অনেক Python টুল ও লাইব্রেরির সাথে খুব ভালোভাবে সামঞ্জস্যপূর্ণ থাকবে। 🚀

## **FastAPI**-তে টাইপ হিন্ট { #type-hints-in-fastapi }

**FastAPI** এই টাইপ হিন্টগুলোর সুবিধা নিয়ে বেশ কয়েকটি কাজ করে।

**FastAPI**-তে আপনি টাইপ হিন্টসহ প্যারামিটার ঘোষণা করেন এবং পান:

* **এডিটর সাপোর্ট**।
* **টাইপ চেক**।

...আর **FastAPI** একই ঘোষণাগুলো ব্যবহার করে:

* **প্রয়োজনীয়তা নির্ধারণ করে**: রিকোয়েস্টের পাথ প্যারামিটার, কুয়েরি প্যারামিটার, হেডার, বডি, ডিপেন্ডেন্সি ইত্যাদি থেকে।
* **ডেটা রূপান্তর করে**: রিকোয়েস্ট থেকে প্রয়োজনীয় টাইপে।
* **ডেটা ভ্যালিডেট করে**: প্রতিটি রিকোয়েস্ট থেকে আসা ডেটা:
    * ডেটা অবৈধ হলে ক্লায়েন্টকে ফেরত পাঠানোর জন্য **স্বয়ংক্রিয় এরর** তৈরি করে।
* OpenAPI ব্যবহার করে API **ডকুমেন্ট করে**:
    * যা পরে স্বয়ংক্রিয় ইন্টারঅ্যাকটিভ ডকুমেন্টেশনের ইউজার ইন্টারফেসগুলো ব্যবহার করে।

এসব হয়তো বিমূর্ত শোনাচ্ছে। চিন্তা করবেন না। [টিউটোরিয়াল - ইউজার গাইড](tutorial/index.md)-এ আপনি এর সবকিছু বাস্তবে দেখতে পাবেন।

গুরুত্বপূর্ণ বিষয় হলো, এক জায়গাতেই স্ট্যান্ডার্ড Python টাইপ ব্যবহার করে (আরও ক্লাস, ডেকোরেটর ইত্যাদি যোগ করার বদলে) **FastAPI** আপনার অনেক কাজ করে দেবে।
