# ডেটাবেস টেস্টিং { #testing-a-database }

ডেটাবেস, SQL ও SQLModel সম্পর্কে আপনি [SQLModel ডকুমেন্টেশনে](https://sqlmodel.tiangolo.com/) পড়াশোনা করতে পারেন। 🤓

[FastAPI-এর সাথে SQLModel ব্যবহার নিয়ে](https://sqlmodel.tiangolo.com/tutorial/fastapi/) একটি মিনি টিউটোরিয়াল আছে। ✨

ওই টিউটোরিয়ালে [SQL ডেটাবেস টেস্টিং](https://sqlmodel.tiangolo.com/tutorial/fastapi/tests/) নিয়ে একটি অংশ আছে। 😎
