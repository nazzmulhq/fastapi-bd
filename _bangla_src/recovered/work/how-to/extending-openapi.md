# OpenAPI সম্প্রসারণ { #extending-openapi }

কিছু ক্ষেত্রে আপনাকে তৈরি হওয়া OpenAPI স্কিমা পরিবর্তন করতে হতে পারে।

এই অংশে আপনি দেখবেন কীভাবে।

## স্বাভাবিক প্রক্রিয়া { #the-normal-process }

স্বাভাবিক (ডিফল্ট) প্রক্রিয়াটি নিচের মতো।

একটি `FastAPI` অ্যাপ্লিকেশনের (ইনস্ট্যান্স) একটি `.openapi()` মেথড আছে, যা OpenAPI স্কিমা রিটার্ন করবে বলে আশা করা হয়।

অ্যাপ্লিকেশন অবজেক্ট তৈরির অংশ হিসেবে `/openapi.json`-এর জন্য (বা আপনার `openapi_url` যা সেট করেছেন তার জন্য) একটি *পাথ অপারেশন* রেজিস্টার হয়।

এটি শুধু অ্যাপ্লিকেশনের `.openapi()` মেথডের ফলাফলসহ একটি JSON রেসপন্স রিটার্ন করে।

ডিফল্টভাবে `.openapi()` মেথড যা করে তা হলো `.openapi_schema` প্রপার্টিতে কোনো বিষয়বস্তু আছে কিনা দেখে সেগুলো রিটার্ন করা।

যদি না থাকে, তাহলে এটি `fastapi.openapi.utils.get_openapi`-এর ইউটিলিটি ফাংশন ব্যবহার করে সেগুলো তৈরি করে।

আর সেই `get_openapi()` ফাংশনটি প্যারামিটার হিসেবে গ্রহণ করে:

* `title`: OpenAPI শিরোনাম, ডকুমেন্টেশনে দেখানো হয়।
* `version`: আপনার API-এর ভার্সন, যেমন `2.5.0`।
* `openapi_version`: ব্যবহৃত OpenAPI স্পেসিফিকেশনের ভার্সন। ডিফল্টভাবে সর্বশেষটি: `3.1.0`।
* `summary`: API-এর একটি সংক্ষিপ্ত সারাংশ।
* `description`: আপনার API-এর বিবরণ, এতে markdown থাকতে পারে এবং ডকুমেন্টেশনে দেখানো হবে।
* `routes`: অ্যাপ্লিকেশনের রাউটগুলো, `app.routes` থেকে নেওয়া। অন্তর্ভুক্ত রাউটারের গুলোসহ রেজিস্টার করা *পাথ অপারেশনগুলো* সংগ্রহ করতে FastAPI এগুলো ব্যবহার করে।

/// tip | কারিগরি বিবরণ

`app.routes` হলো একটি নিম্ন-স্তরের রাউট ট্রি। এতে কেবল চূড়ান্ত `APIRoute` অবজেক্ট নয়, অন্তর্ভুক্ত রাউটারের জন্য FastAPI ভেতরে ভেতরে ব্যবহার করে এমন রাউট প্রার্থীও থাকতে পারে।

আপনি তবুও `get_openapi()`-তে `app.routes` দিতে পারেন। কার্যকর পাথ অপারেশনগুলো সংগ্রহ করতে FastAPI সেই রাউট ট্রি ঘুরে দেখবে।

///

/// note | নোট

`summary` প্যারামিটারটি OpenAPI 3.1.0 ও তার ওপরে উপলব্ধ, FastAPI 0.99.0 ও তার ওপরে সাপোর্টেড।

## ডিফল্টগুলো ওভাররাইড করা { #overriding-the-defaults }

### OpenAPI স্কিমা ক্যাশ করুন { #cache-the-openapi-schema }

আপনার তৈরি স্কিমা সংরক্ষণ করতে আপনি `.openapi_schema` প্রপার্টিটিকে একটি "ক্যাশে" হিসেবে ব্যবহার করতে পারেন।

এভাবে প্রতিবার কোনো ইউজার আপনার API ডকুমেন্টেশন খুললে আপনার অ্যাপ্লিকেশনকে স্কিমা তৈরি করতে হবে না।

এটি কেবল একবারই তৈরি হবে, তারপর পরের রিকোয়েস্টগুলোর জন্য একই ক্যাশ করা স্কিমা ব্যবহার হবে।
