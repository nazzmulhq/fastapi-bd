# কাস্টম ডকুমেন্টেশন UI স্ট্যাটিক অ্যাসেট (সেলফ-হোস্টিং) { #custom-docs-ui-static-assets-self-hosting }

API ডকুমেন্টেশন **Swagger UI** ও **ReDoc** ব্যবহার করে, এবং এগুলোর প্রতিটির কিছু JavaScript ও CSS ফাইল দরকার।

ডিফল্টভাবে ওই ফাইলগুলো একটি <abbr title="Content Delivery Network - কনটেন্ট ডেলিভারি নেটওয়ার্ক: সাধারণত কয়েকটি সার্ভার নিয়ে গঠিত একটি সার্ভিস, যা JavaScript ও CSS-এর মতো স্ট্যাটিক ফাইল দেয়। পারফরম্যান্স উন্নত করতে এটি সাধারণত ক্লায়েন্টের কাছাকাছি সার্ভার থেকে ওই ফাইলগুলো সার্ভ করতে ব্যবহার হয়।">CDN</abbr> থেকে সার্ভ করা হয়।

তবে এটি কাস্টমাইজ করা সম্ভব, আপনি একটি নির্দিষ্ট CDN সেট করতে পারেন, বা ফাইলগুলো নিজেই সার্ভ করতে পারেন।

## JavaScript ও CSS-এর জন্য কাস্টম CDN { #custom-cdn-for-javascript-and-css }

ধরা যাক আপনি একটি ভিন্ন <abbr title="Content Delivery Network - কনটেন্ট ডেলিভারি নেটওয়ার্ক">CDN</abbr> ব্যবহার করতে চান, যেমন আপনি `https://unpkg.com/` ব্যবহার করতে চান।

এটি কাজে আসতে পারে, যেমন আপনি যদি এমন কোনো দেশে থাকেন যেখানে কিছু URL সীমাবদ্ধ।

### স্বয়ংক্রিয় ডকুমেন্টেশন বন্ধ করুন { #disable-the-automatic-docs }

সেগুলো বন্ধ করতে আপনার `FastAPI` অ্যাপ তৈরির সময় সেগুলোর URL `None` সেট করুন:

### কাস্টম ডকুমেন্টেশন অন্তর্ভুক্ত করুন { #include-the-custom-docs }

এবার আপনি কাস্টম ডকুমেন্টেশনের জন্য *পাথ অপারেশন* তৈরি করতে পারেন।

ডকুমেন্টেশনের HTML পেজ তৈরি করতে আপনি FastAPI-এর অভ্যন্তরীণ ফাংশনগুলো পুনরায় ব্যবহার করে সেগুলোতে প্রয়োজনীয় আর্গুমেন্ট দিতে পারেন:

* `openapi_url`: সেই URL যেখান থেকে ডকুমেন্টেশনের HTML পেজ আপনার API-এর OpenAPI স্কিমা পেতে পারে। এখানে আপনি `app.openapi_url` অ্যাট্রিবিউট ব্যবহার করতে পারেন।
* `title`: আপনার API-এর শিরোনাম।
* `oauth2_redirect_url`: ডিফল্টটি ব্যবহার করতে এখানে আপনি `app.swagger_ui_oauth2_redirect_url` ব্যবহার করতে পারেন।
* `swagger_js_url`: সেই URL যেখান থেকে আপনার Swagger UI ডকুমেন্টেশনের HTML **JavaScript** ফাইলটি পেতে পারে। এটিই কাস্টম CDN URL।
* `swagger_css_url`: সেই URL যেখান থেকে আপনার Swagger UI ডকুমেন্টেশনের HTML **CSS** ফাইলটি পেতে পারে। এটিই কাস্টম CDN URL।

## ডকুমেন্টেশনের জন্য JavaScript ও CSS সেলফ-হোস্টিং { #self-hosting-javascript-and-css-for-docs }

JavaScript ও CSS সেলফ-হোস্ট করা কাজে আসতে পারে, যেমন যদি আপনার অ্যাপকে অফলাইনে থাকা অবস্থায়ও, খোলা ইন্টারনেট অ্যাক্সেস ছাড়া, বা একটি লোকাল নেটওয়ার্কে কাজ চালিয়ে যেতে হয়।
