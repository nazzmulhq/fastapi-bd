রিকোয়েস্টের Content-Type হেডারের জন্য কঠোর যাচাই চালু করুন।

`True` হলে (ডিফল্ট), `Content-Type` হেডার ছাড়া বডিসহ রিকোয়েস্টগুলো JSON হিসেবে পার্স **হবে না**।

এটি সম্ভাব্য cross-site request forgery (CSRF) আক্রমণ প্রতিরোধ করে, যেগুলো Content-Type হেডার ছাড়া রিকোয়েস্ট পাঠানোর ব্রাউজারের ক্ষমতার সুযোগ নিয়ে CORS প্রিফ্লাইট যাচাই এড়িয়ে যায়। বিশেষ করে লোকালি (localhost-এ) চালাতে হয় এমন অ্যাপের জন্য এটি প্রযোজ্য।

`False` হলে `Content-Type` হেডার ছাড়া রিকোয়েস্টগুলোর বডি JSON হিসেবে পার্স হবে, যা `Content-Type` হেডার পাঠায় না এমন কিছু ক্লায়েন্টের সাথে সামঞ্জস্য বজায় রাখে।

এ সম্পর্কে আরও পড়ুন
[কঠোর Content-Type-এর জন্য FastAPI ডকুমেন্টেশনে](https://fastapi.tiangolo.com/advanced/strict-content-type/)।

এটি যেকোনো বৈধ Pydantic *ফিল্ড* টাইপ হতে পারে। তাই এটিকে Pydantic মডেল হতেই হবে এমন নয়, এটি অন্য কিছুও হতে পারে, যেমন একটি `list`, `dict` ইত্যাদি।

এটি ব্যবহার হবে:

* ডকুমেন্টেশন: তৈরি হওয়া OpenAPI (এবং `/docs`-এর UI) এটিকে রেসপন্স হিসেবে (JSON Schema) দেখাবে।
* সিরিয়ালাইজেশন: আপনি যেকোনো অবজেক্ট রিটার্ন করতে পারেন, আর `response_model` সেই অবজেক্টকে সংশ্লিষ্ট JSON-এ সিরিয়ালাইজ করতে ব্যবহার হবে।
* ফিল্টারিং: ক্লায়েন্টকে পাঠানো JSON-এ কেবল `response_model`-এ সংজ্ঞায়িত ডেটা (ফিল্ড) থাকবে। আপনি যদি এমন একটি অবজেক্ট রিটার্ন করেন যাতে একটি `password` অ্যাট্রিবিউট আছে কিন্তু `response_model`-এ ওই ফিল্ডটি নেই, তাহলে ক্লায়েন্টকে পাঠানো JSON-এ ওই `password` থাকবে না।
* ভ্যালিডেশন: আপনি যা রিটার্ন করবেন তা `response_model` দিয়ে সিরিয়ালাইজ হবে, সংশ্লিষ্ট JSON তৈরি করতে প্রয়োজনমতো যেকোনো ডেটা রূপান্তর করে। কিন্তু রিটার্ন করা অবজেক্টের ডেটা বৈধ না হলে তার মানে ক্লায়েন্টের সাথে চুক্তির লঙ্ঘন, তাই এটি API ডেভেলপারের একটি এরর। তাই FastAPI একটি এরর রেইজ করে 500 এরর কোড (Internal Server Error) রিটার্ন করবে।

FastAPI OpenAPI ভার্সন 3.1.0 তৈরি করবে, এবং OpenAPI ভার্সন হিসেবে সেটিই আউটপুট দেবে। কিন্তু কিছু টুল, OpenAPI 3.1.0-এর সাথে সামঞ্জস্যপূর্ণ হলেও, হয়তো এটিকে বৈধ হিসেবে চিনতে পারবে না।

তাই তৈরি হওয়া OpenAPI ব্যবহার করাতে ওই টুলগুলোকে ধোঁকা দিতে আপনি এই ভ্যালুটি ওভাররাইড করতে পারেন। মনে রাখবেন, এটি একটি কৌশল মাত্র (hack)। তবে আপনি যদি OpenAPI 3.1.0-এ যোগ হওয়া ফিচারগুলো ব্যবহার এড়িয়ে চলেন, তাহলে আপনার ব্যবহারের ক্ষেত্রে এটি কাজ করতে পারে।

FastAPI একটি ভিন্ন OpenAPI স্কিমা তৈরি করবে এমন ভুল ধারণা না দিতে এটি `FastAPI` ক্লাসে প্যারামিটার হিসেবে দেওয়া হয় না। এটি কেবল একটি অ্যাট্রিবিউট হিসেবে উপলব্ধ।
