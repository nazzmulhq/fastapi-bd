কাস্টম ডকস UI স্ট্যাটিক অ্যাসেট (নিজে হোস্ট করা)¶

🌐 সহজ বাংলায় ব্যাখ্যাসহ সংস্করণ

এটি শুধু অনুবাদ নয়: প্রতিটি পেজে সহজ ভাষায় ব্যাখ্যা, বাস্তব জীবনের উদাহরণ, কোডের লাইন-ধরে-ধরে ব্যাখ্যা, সাধারণ ভুল আর শেষে সারসংক্ষেপ যোগ করা হয়েছে। 🤝

কোড, প্যারামিটারের নাম আর কমান্ড ইংরেজিতেই রাখা হয়েছে, কারণ এগুলো ঠিক এভাবেই লিখতে হয়। অচেনা শব্দের মানে জানতে মেনুর "শিখুন" অংশে "সহজ শব্দকোষ" পেজটি দেখুন।

এটি মানুষের নির্দেশনায় AI দিয়ে তৈরি, তাই কোথাও ভুল থাকতে পারে। সন্দেহ হলে মূল ইংরেজি সংস্করণ মিলিয়ে নিন। 🤖

ইংরেজি সংস্করণ

এই পেজে যা শিখবেন

  • /docs আর /redoc পেজগুলো কোথা থেকে JavaScript/CSS ফাইল আনে।
  • ভিন্ন একটি CDN ব্যবহার করা (যেমন কোনো দেশে ডিফল্ট CDN বন্ধ থাকলে)।
  • ফাইলগুলো নিজের অ্যাপ থেকেই পরিবেশন করা, যাতে ইন্টারনেট ছাড়াও ডকস কাজ করে।

API ডকস Swagger UI আর ReDoc ব্যবহার করে, আর এদের প্রত্যেকের কিছু JavaScript আর CSS ফাইল লাগে।

ডিফল্টভাবে, সেই ফাইলগুলো একটি CDN থেকে পরিবেশন করা হয়।

কিন্তু এটি নিজের মতো করা সম্ভব: আপনি একটি নির্দিষ্ট CDN সেট করতে পারেন, বা ফাইলগুলো নিজেই পরিবেশন করতে পারেন।

উদাহরণ দিয়ে বুঝি

/docs পেজটি একটি খালি থিয়েটার মঞ্চের মতো, আর Swagger UI-এর JavaScript/CSS হলো সাজসজ্জা আর আলো। ডিফল্টভাবে এগুলো দূরের একটি গুদাম (CDN) থেকে আসে। গুদামের রাস্তা বন্ধ থাকলে (ইন্টারনেট নেই বা ব্লক) মঞ্চ অন্ধকার থাকে। সমাধান: অন্য গুদাম থেকে আনা (কাস্টম CDN), অথবা সাজসজ্জা নিজের থিয়েটারেই রেখে দেওয়া (self-hosting)।

JavaScript আর CSS-এর জন্য কাস্টম CDN¶

ধরা যাক আপনি একটি ভিন্ন CDN ব্যবহার করতে চান, যেমন আপনি https://unpkg.com/ ব্যবহার করতে চান।

এটি কাজে লাগতে পারে যদি, যেমন, আপনি এমন একটি দেশে থাকেন যেখানে কিছু URL সীমাবদ্ধ।

স্বয়ংক্রিয় ডকস বন্ধ করুন¶

প্রথম ধাপ হলো স্বয়ংক্রিয় ডকস বন্ধ করা, কারণ ডিফল্টভাবে সেগুলো ডিফল্ট CDN ব্যবহার করে।

এগুলো বন্ধ করতে, আপনার FastAPI অ্যাপ তৈরির সময় এদের URL None সেট করুন:

from fastapi import FastAPI
from fastapi.openapi.docs import (
    get_redoc_html,
    get_swagger_ui_html,
    get_swagger_ui_oauth2_redirect_html,
)

কাস্টম ডকস যুক্ত করুন¶

এখন কাস্টম ডকসের জন্য পাথ অপারেশন তৈরি করতে পারেন।

ডকসের HTML পেজ তৈরি করতে FastAPI-এর অভ্যন্তরীণ ফাংশনগুলো আবার ব্যবহার করতে পারেন, আর দরকারি আর্গুমেন্টগুলো দিতে পারেন:

  • openapi_url: সেই URL যেখান থেকে ডকসের HTML পেজ আপনার API-র OpenAPI স্কিমা পেতে পারে। এখানে app.openapi_url অ্যাট্রিবিউটটি ব্যবহার করতে পারেন।
  • title: আপনার API-র শিরোনাম।
  • oauth2_redirect_url: ডিফল্টটি ব্যবহার করতে এখানে app.swagger_ui_oauth2_redirect_url ব্যবহার করতে পারেন।
  • swagger_js_url: সেই URL যেখান থেকে আপনার Swagger UI ডকসের HTML JavaScript ফাইলটি পেতে পারে। এটি কাস্টম CDN-এর URL।
  • swagger_css_url: সেই URL যেখান থেকে আপনার Swagger UI ডকসের HTML CSS ফাইলটি পেতে পারে। এটি কাস্টম CDN-এর URL।

কোডটি সহজ ভাষায়

  • লাইন ৮: docs_url=None, redoc_url=None দিয়ে FastAPI-এর নিজস্ব /docs আর /redoc বন্ধ।
  • লাইন ১১–১৯: নিজের /docs রাউট, যা get_swagger_ui_html() দিয়ে HTML বানায়, কিন্তু JS আর CSS আনে unpkg.com থেকে। include_in_schema=False মানে এই রাউটটি নিজে API ডকসে দেখাবে না।
  • লাইন ২২–২৪: OAuth2 লগইনের পরে ফিরে আসার জন্য সাহায্যকারী পেজ।
  • লাইন ২৭–৩৩: একইভাবে নিজের /redoc রাউট।

পরামর্শ

swagger_ui_redirect-এর পাথ অপারেশনটি OAuth2 ব্যবহারের সময়ের জন্য একটি সাহায্যকারী।

যদি আপনার API একটি OAuth2 প্রোভাইডারের সাথে যুক্ত করেন, তাহলে আপনি অথেনটিকেট করে পাওয়া লগইন তথ্যসহ API ডকসে ফিরে আসতে পারবেন। আর আসল OAuth2 অথেনটিকেশন ব্যবহার করে এর সাথে কাজ করতে পারবেন।

Swagger UI পর্দার আড়ালে আপনার জন্য এটি সামলাবে, কিন্তু এর এই "redirect" সাহায্যকারীটি লাগে।

ডকসের জন্য JavaScript আর CSS নিজে হোস্ট করা¶

JavaScript আর CSS নিজে হোস্ট করা কাজে লাগতে পারে যদি, যেমন, আপনার অ্যাপকে অফলাইনে, খোলা ইন্টারনেট ছাড়া, বা একটি লোকাল নেটওয়ার্কে কাজ চালিয়ে যেতে হয়।

এখানে দেখবেন কীভাবে একই FastAPI অ্যাপে নিজেই সেই ফাইলগুলো পরিবেশন করবেন, আর ডকসকে সেগুলো ব্যবহার করতে কনফিগার করবেন।

প্রজেক্টের ফাইল কাঠামো¶

ধরা যাক আপনার প্রজেক্টের ফাইল কাঠামো দেখতে এমন:

.
├── app
│   ├── __init__.py
│   ├── main.py

এখন সেই স্ট্যাটিক ফাইলগুলো রাখার জন্য একটি ডিরেক্টরি তৈরি করুন।

আপনার নতুন ফাইল কাঠামো দেখতে এমন হতে পারে:

.
├── app
│   ├── __init__.py
│   ├── main.py
└── static/

ফাইলগুলো ডাউনলোড করুন¶

ডকসের জন্য দরকারি স্ট্যাটিক ফাইলগুলো ডাউনলোড করে সেই static/ ডিরেক্টরিতে রাখুন।

সম্ভবত প্রতিটি লিংকে রাইট-ক্লিক করে "Save link as..." এর মতো একটি অপশন বেছে নিতে পারেন।

Swagger UI এই ফাইলগুলো ব্যবহার করে:

  • swagger-ui-bundle.js
  • swagger-ui.css

আর ReDoc এই ফাইলটি ব্যবহার করে:

  • redoc.standalone.js

এরপর, আপনার ফাইল কাঠামো দেখতে এমন হতে পারে:

.

│   ├── __init__.py
│   ├── main.py
└── static
    ├── redoc.standalone.js
    ├── swagger-ui-bundle.js
    └── swagger-ui.css

আপনার অ্যাপ্লিকেশন চালু করে http://127.0.0.1:8000/static/redoc.standalone.js-এ যান।

যদি আপনার API একটি OAuth2 প্রোভাইডারের সাথে যুক্ত করেন, তাহলে আপনি অথেনটিকেট করে পাওয়া লগইন তথ্যসহ API ডকসে ফিরে আসতে পারবেন। আর আসল OAuth2 অথেনটিকেশন ব্যবহার করে এর সাথে কাজ করতে পারবেন।

Swagger UI পর্দার আড়ালে আপনার জন্য এটি সামলাবে, কিন্তু এর এই "redirect" সাহায্যকারীটি লাগে।

স্ট্যাটিক ফাইল পরীক্ষা করতে একটি পাথ অপারেশন তৈরি করুন¶

এখন, সবকিছু কাজ করছে কিনা পরীক্ষা করতে, একটি পাথ অপারেশন তৈরি করুন:

from fastapi import FastAPI
from fastapi.openapi.docs import (
    get_redoc_html,
    get_swagger_ui_html,
    get_swagger_ui_oauth2_redirect_html,
)
from fastapi.staticfiles import StaticFiles

app = FastAPI(docs_url=None, redoc_url=None)

app.mount("/static", StaticFiles(directory="static"), name="static")


@app.get("/docs", include_in_schema=False)
async def custom_swagger_ui_html():
    return get_swagger_ui_html(
        openapi_url=app.openapi_url,
        title=app.title + " - Swagger UI",
        oauth2_redirect_url=app.swagger_ui_oauth2_redirect_url,
        swagger_js_url="/static/swagger-ui-bundle.js",
        swagger_css_url="/static/swagger-ui.css",
    )


@app.get(app.swagger_ui_oauth2_redirect_url, include_in_schema=False)
async def swagger_ui_redirect():
    return get_swagger_ui_oauth2_redirect_html()


@app.get("/redoc", include_in_schema=False)
async def redoc_html():
    return get_redoc_html(
        openapi_url=app.openapi_url,
        title=app.title + " - ReDoc",
        redoc_js_url="/static/redoc.standalone.js",
    )


@app.get("/users/{username}")
async def read_user(username: str):
    return {"message": f"Hello {username}"}

স্ট্যাটিক ফাইলের UI পরীক্ষা করুন¶

এখন আপনি আপনার WiFi বন্ধ করে, http://127.0.0.1:8000/docs-এ আপনার ডকসে গিয়ে পেজটি রিলোড করতে পারবেন।

আর ইন্টারনেট ছাড়াও আপনি আপনার API-র ডকস দেখতে আর এর সাথে কাজ করতে পারবেন।

সংক্ষেপে মনে রাখুন

  • প্রথমে FastAPI(docs_url=None, redoc_url=None) দিয়ে ডিফল্ট ডকস বন্ধ করুন।
  • তারপর get_swagger_ui_html() আর get_redoc_html() দিয়ে নিজের /docs, /redoc রাউট বানান, JS/CSS-এর URL নিজের পছন্দমতো দিন।
  • অফলাইনে চালাতে ফাইলগুলো static/ ফোল্ডারে রেখে StaticFiles দিয়ে mount করুন।
