Test Client - TestClient¶

🌐 সহজ বাংলায় ব্যাখ্যাসহ সংস্করণ

এটি শুধু অনুবাদ নয়: প্রতিটি পেজে সহজ ভাষায় ব্যাখ্যা, বাস্তব জীবনের উদাহরণ, কোডের লাইন-ধরে-ধরে ব্যাখ্যা, সাধারণ ভুল আর শেষে সারসংক্ষেপ যোগ করা হয়েছে। 🤝

কোড, প্যারামিটারের নাম আর কমান্ড ইংরেজিতেই রাখা হয়েছে, কারণ এগুলো ঠিক এভাবেই লিখতে হয়। অচেনা শব্দের মানে জানতে মেনুর "শিখুন" অংশে "সহজ শব্দকোষ" পেজটি দেখুন।

এটি মানুষের নির্দেশনায় AI দিয়ে তৈরি, তাই কোথাও ভুল থাকতে পারে। সন্দেহ হলে মূল ইংরেজি সংস্করণ মিলিয়ে নিন। 🤖

ইংরেজি সংস্করণ

এই পেজে যা পাবেন

  • TestClient দিয়ে সার্ভার না চালিয়েই অ্যাপ টেস্ট করা।
  • constructor-এর প্যারামিটার (base_url, raise_server_exceptions, headers, cookies, follow_redirects ইত্যাদি)।
  • রিকোয়েস্ট মেথড (get, post, put, patch, delete...) আর তাদের সাধারণ আর্গুমেন্ট (params, json, data, files, headers, cookies)।
  • lifespan চালাতে with ব্লক, WebSocket টেস্ট, ডিপেন্ডেন্সি বদলে টেস্ট।
  • সবশেষে স্বয়ংক্রিয়ভাবে তৈরি পূর্ণ API তালিকা।

আসল HTTP আর সকেট সংযোগ তৈরি না করে, শুধু সরাসরি FastAPI কোডের সাথে যোগাযোগ করে FastAPI অ্যাপ্লিকেশন টেস্ট করতে TestClient ক্লাস ব্যবহার করতে পারেন।

এ সম্পর্কে আরও পড়ুন টেস্টিং নিয়ে FastAPI ডকসে।

আপনি এটি সরাসরি fastapi.testclient থেকে ইম্পোর্ট করতে পারেন:

from fastapi.testclient import TestClient

এক নজরে¶

উদাহরণ দিয়ে বুঝি

TestClient হলো একজন নকল গ্রাহক যে দোকানের ভেতরেই থাকে। দরজা খুলে রাস্তায় যেতে হয় না (নেটওয়ার্ক নেই), তাই কেনাকাটা (রিকোয়েস্ট) খুব দ্রুত হয়, আর আপনি দেখে নিতে পারেন দোকানদার ঠিক জিনিস দিচ্ছে কিনা।

pip install httpx করে নিন (TestClient এর ওপর ভিত্তি করে তৈরি), আর টেস্ট চালাতে pytest।

from fastapi import FastAPI
from fastapi.testclient import TestClient

app = FastAPI()


@app.get("/")
def home():
    return {"msg": "Hello"}


client = TestClient(app)


def test_home():
    response = client.get("/")
    assert response.status_code == 200
    assert response.json() == {"msg": "Hello"}

রিকোয়েস্ট মেথড আর আর্গুমেন্ট¶

client.get(), client.post(), client.put(), client.patch(), client.delete(), client.head(), client.options(), আর সাধারণ client.request(method, url)। গুরুত্বপূর্ণ আর্গুমেন্ট:

আর্গুমেন্ট কী পাঠায়
params কোয়েরি প্যারামিটার, যেমন {"q": "বই"}
json JSON বডি
data ফর্ম ডেটা
files আপলোড ফাইল, যেমন {"file": ("a.txt", b"hello", "text/plain")}
headers, cookies এই রিকোয়েস্টের হেডার/কুকি

রেসপন্স অবজেক্টে: status_code, json(), text, content, headers, cookies।

নিচের উদাহরণগুলোতে ধরে নিচ্ছি অ্যাপে /items/ আর /upload/ রাউট আছে (যেমন UploadFile পেজের উদাহরণ)।

def test_create_item():
    response = client.post(
        "/items/",
        json={"name": "কলম", "price": 10},
        headers={"X-Token": "secret"},
    )
    assert response.status_code == 201
    assert response.json()["name"] == "কলম"


def test_upload():
    response = client.post("/upload/", files={"file": ("hello.txt", b"hello", "text/plain")})
    assert response.json()["filename"] == "hello.txt"

with ব্লক: lifespan চালানো¶

অ্যাপের lifespan (শুরু/বন্ধের কোড, যেমন ডেটাবেস সংযোগ) চালাতে client-কে with ব্লকে ব্যবহার করুন:

def test_with_startup():
    with TestClient(app) as client:  # এখানে lifespan-এর শুরুর অংশ চলে
        response = client.get("/")
        assert response.status_code == 200
    # ব্লক শেষে বন্ধের অংশ চলে

WebSocket টেস্ট¶

ধরে নিচ্ছি অ্যাপে WebSockets পেজের echo রাউটটি আছে:

def test_ws():
    with client.websocket_connect("/ws") as websocket:
        websocket.send_text("হ্যালো")
        assert websocket.receive_text() == "আপনি লিখেছেন: হ্যালো"

ডিপেন্ডেন্সি বদলে টেস্ট¶

from fastapi import Depends, FastAPI
from fastapi.testclient import TestClient

app = FastAPI()


def get_current_user():
    raise RuntimeError("আসল লগইন সার্ভার লাগবে")


@app.get("/me")
def me(user: str = Depends(get_current_user)):
    return {"user": user}


def test_me():
    app.dependency_overrides[get_current_user] = lambda: "test-user"
    client = TestClient(app)
    assert client.get("/me").json() == {"user": "test-user"}
    app.dependency_overrides.clear()

বিস্তারিত: ডিপেন্ডেন্সি ওভাররাইড দিয়ে টেস্টিং।

সংক্ষেপে মনে রাখুন

  • client = TestClient(app), তারপর client.get(...), client.post(..., json=...)।
  • lifespan চালাতে with TestClient(app) as client:।
  • WebSocket: client.websocket_connect("/ws"); ডিপেন্ডেন্সি বদলাতে app.dependency_overrides।

def build_request(
    self,
    method: str,
    url: URL | str,
    *,
    content: RequestContent | None = None,
    data: RequestData | None = None,
    files: RequestFiles | None = None,
    json: typing.Any | None = None,
    params: QueryParamTypes | None = None,
    headers: HeaderTypes | None = None,
    cookies: CookieTypes | None = None,
    timeout: TimeoutTypes | UseClientDefault = USE_CLIENT_DEFAULT,
    extensions: RequestExtensions | None = None,
) -> Request:
    """
    একটি রিকোয়েস্ট ইনস্ট্যান্স তৈরি করে রিটার্ন করুন।

    * `params`, `headers` ও `cookies` আর্গুমেন্টগুলো ক্লায়েন্টে সেট করা যেকোনো ভ্যালুর সাথে একত্রিত হয়।
    * `url` আর্গুমেন্টটি ক্লায়েন্টে সেট করা যেকোনো `base_url`-এর সাথে একত্রিত হয়।

    আরও দেখুন: [Request instances][0]

    [0]: https://www.python-httpx.org/advanced/clients/#request-instances
    """
    url = self._merge_url(url)
    headers = self._merge_headers(headers)
    cookies = self._merge_cookies(cookies)
    params = self._merge_queryparams(params)
    extensions = {} if extensions is None else extensions
    if "timeout" not in extensions:
        timeout = (
            self.timeout
            if isinstance(timeout, UseClientDefault)
            else Timeout(timeout)
        )

    """
    `httpx.request()`-এর বিকল্প, যা রেসপন্স বডি একবারে মেমরিতে লোড না করে স্ট্রিম করে।

        method=method,
        url=url,
        content=content,
        data=data,
        files=files,
        json=json,
        params=params,
        headers=headers,
        cookies=cookies,
        timeout=timeout,
        extensions=extensions,
    )
    response = self.send(
        request=request,
        auth=auth,
        follow_redirects=follow_redirects,
        stream=True,

    finally:
        response.close()

    একটি রিকোয়েস্ট পাঠান।

    রিকোয়েস্টটি যেমন আছে তেমনই, অপরিবর্তিত অবস্থায় পাঠানো হয়।

    সাধারণত আপনি `Client.build_request()` দিয়ে একটি তৈরি করতে চাইবেন, যাতে ক্লায়েন্ট-লেভেলের যেকোনো কনফিগারেশন রিকোয়েস্টে একত্রিত হয়, তবে একটি স্পষ্ট `httpx.Request()` দেওয়াও সাপোর্টেড।

    আরও দেখুন: [Request instances][0]

    [0]: https://www.python-httpx.org/advanced/clients/#request-instances
    """
    if self._state == ClientState.CLOSED:
        raise RuntimeError("Cannot send a request, as the client has been closed.")

    self._state = ClientState.OPENED
    follow_redirects = (
        self.follow_redirects
        if isinstance(follow_redirects, UseClientDefault)
        else follow_redirects
    )

    self._set_timeout(request)

    auth = self._build_request_auth(request, auth)

    response = self._send_handling_auth(
        request,
        auth=auth,
        follow_redirects=follow_redirects,
        history=[],
    )
    try:
        if not stream:
            response.read()

        return response

    except BaseException as exc:
        response.close()
        raise exc
