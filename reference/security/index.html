সিকিউরিটি টুল¶

🌐 AI এবং মানুষের যৌথ অনুবাদ

এই অনুবাদটি মানুষের নির্দেশনায় AI দিয়ে করা হয়েছে। 🤝

এতে মূল অর্থ ভুল বোঝা বা অস্বাভাবিক শোনানোর মতো ভুল থাকতে পারে। 🤖

ইংরেজি সংস্করণ

আপনার যখন OAuth2 scopes-সহ ডিপেন্ডেন্সি ঘোষণা করতে হয়, তখন আপনি Security() ব্যবহার করেন।

তবে আপনাকে তবুও সংজ্ঞায়িত করতে হবে dependable কোনটি, অর্থাৎ Depends() বা Security()-এ প্যারামিটার হিসেবে আপনি যে callable দেন সেটি।

ওই dependable-গুলো তৈরি করতে আপনি একাধিক টুল ব্যবহার করতে পারেন, আর সেগুলো OpenAPI-তে যুক্ত হয়, তাই সেগুলো স্বয়ংক্রিয় ডকুমেন্টেশন UI-তে দেখানো হয়, স্বয়ংক্রিয়ভাবে তৈরি ক্লায়েন্ট ও SDK সেগুলো ব্যবহার করতে পারে, ইত্যাদি।

আপনি এগুলো fastapi.security থেকে ইম্পোর্ট করতে পারেন:

from fastapi.security import (
    APIKeyCookie,
    APIKeyHeader,
    APIKeyQuery,
    HTTPAuthorizationCredentials,
    HTTPBasic,
    HTTPBasicCredentials,
    HTTPBearer,
    HTTPDigest,
    OAuth2,
    OAuth2AuthorizationCodeBearer,
    OAuth2PasswordBearer,
    OAuth2PasswordRequestForm,
    OAuth2PasswordRequestFormStrict,
    OpenIdConnect,
    SecurityScopes,
)

এগুলো সম্পর্কে আরও পড়ুন সিকিউরিটি নিয়ে FastAPI ডকুমেন্টেশনে।

def make_not_authenticated_error(self) -> HTTPException:
    """
    API Key অথেনটিকেশনের জন্য WWW-Authenticate হেডার স্ট্যান্ডার্ড করা নয়, তবে HTTP স্পেসিফিকেশন অনুযায়ী 401 "Unauthorized" এররে অবশ্যই একটি WWW-Authenticate হেডার থাকতে হবে।

    Ref: https://datatracker.ietf.org/doc/html/rfc9110#name-401-unauthorized

    এ কারণে এই মেথডটি একটি কাস্টম challenge `APIKey` পাঠায়।
    """
    return HTTPException(
        status_code=HTTP_401_UNAUTHORIZED,
        detail="Not authenticated",
        headers={"WWW-Authenticate": "APIKey"},
    )

def check_api_key(self, api_key: str | None) -> str | None:
    if not api_key:
        if self.auto_error:

একটি ডিপেন্ডেন্সিতে HTTPBearer বা HTTPDigest ব্যবহারের ফলাফলে থাকা HTTP অথরাইজেশন ক্রেডেনশিয়াল।

HTTP অথরাইজেশন হেডারের ভ্যালু প্রথম স্পেস দিয়ে ভাগ করা হয়।
